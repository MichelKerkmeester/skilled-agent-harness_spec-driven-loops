# v1.8.8.0, The Council Artifact Folders Read as Runtime Output

The persist steps and the audit-trail answer name two folders. Both exist only after a council run. One holds the per-seat proposals under `seats/round-NNN/`. The other holds the archive a failed round moves into under `failed/`. The reference check read both as paths in this skill folder. It found none. So it failed the README.

Both names stay. That is because they are the layout a reader will see inside their packet's `ai-council/` tree. The README now declares each one in its `readme-check` block. The reason is that the persist helper and the round rollback create them under a packet. They never create them in this repository. Nothing is deleted and nothing is rewritten, exactly as before.

&nbsp;

## What's New at a Glance

- **The README passes the reference check again.** Two `allow-ref` entries name the folders' owners. They are the persist helper and the round rollback.
- **The audit-trail answer is unchanged.** The append-only state log, the per-seat proposals, the deliberation and critique notes and the failed-round archive all stay where they were.
- **The README edition is raised.** The body changed. So its own edition moves with it.
