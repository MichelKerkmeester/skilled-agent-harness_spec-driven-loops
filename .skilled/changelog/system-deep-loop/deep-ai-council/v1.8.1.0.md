# v1.8.1.0 - README rewritten purpose-first

The deep-ai-council README now meets the refined skill README standard. It uses the mcp-obsidian pilot as its exemplar. It opens with the reader's problem. It presents council information in a purpose-first structure.

## What's New at a Glance

- **The README meets the refined skill README standard.** It opens with a one-line pitch and a problem-first overview. It then presents every council fact in narrative voice. Those facts are the round flow, six strategy lenses, three critique roles, the two-of-three convergence rule, artifact tree and command surface.
- **Lens guidance appears before the workflow details.** A capability table covers the six lenses in HOW IT WORKS. So readers see what each lens applies before the workflow details. The task-type lens mapping becomes a two-row table. Critique roles become a bullet list.
- **The prose clears measured HVR drift.** The old text had two semicolons and nine Oxford comma patterns. Both are removed. The old README also carried reference-card residue. It had a tabular tone in the long FAQ, troubleshooting and integration sections.
- **The `version:` field advances to 1.8.1.0.** It moves from 1.8.0.0. The changelog entry follows the folder convention. The `SKILL.md` version is unchanged. That is because no runtime behavior changed.

## Upgrade

No migration required. Commands, expected outputs and reference links carry over unchanged. Every command, trigger phrase and reference path in the README behaves exactly as before.
