# v1.5.1.0: Deep-Mode Docs + Script Tests

After the v1.5.0.0 release cleanup, this follow-on closes five follow-ons. The 004 phase-5 deep-research loop deferred them. Documentation and tests are the only changes. So deep-mode runtime and script logic did not change. There are no backward-incompatible changes.

## What's New at a Glance

- **The deep-mode session hierarchy now has a guide.** `references/deep-mode.md` describes the session-to-topic-to-round hierarchy. It covers the `session-state.jsonl` and `round-state.jsonl` state files. It also covers cost guards and the `deep-loop-runtime/lib/council/` dependency.
- **The findings registry now has a guide.** `references/findings-registry.md` documents the cross-topic schema. It also documents fingerprint-based deduplication, cross-topic priors and filesystem locking.
- **The new guides are wired into the skill.** `SKILL.md` moves from version `1.5.0.0` to `1.5.1.0`. It adds both references to RESOURCE_MAP and REFERENCES. `README.md` links them from RELATED DOCUMENTS. The router pseudocode did not change.
- **Recovery guidance now links graph replay.** `references/graph-support.md` connects `replay-graph-from-artifacts.cjs` with its derivation. The link appears in the recovery path and in cross-references.
- **The runtime agent rename note now matches the names.** Agent files use `ai-council.*` under the `@ai-council` identity. That follows the `deep-` prefix drop in v1.2.0.0. The skill keeps the `deep-ai-council` name.
- **Five previously untested scripts now have coverage.** The full `vitest run` is deferred to the project's standard test invocation. That is because the skill's `scripts/` has no local vitest config. The existing `.vitest.ts` tests share this setup.

## Upgrade

No migration required.
