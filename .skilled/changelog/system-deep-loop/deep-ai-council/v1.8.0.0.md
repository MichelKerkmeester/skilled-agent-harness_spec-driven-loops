# v1.8.0.0, Mode Packet Renamed to deep-ai-council

The `ai-council` mode packet folder is renamed to `deep-ai-council`. The new name matches the `SKILL.md` name. It also matches the convention the rest of the deep-loop family follows. That match is the invariant `package_skill.py --check` enforces. The rename is structural only. It preserves the workflow mode, command, agent and artifact root.

## What's New at a Glance

- **The packet folder moves to `deep-loop-workflows/deep-ai-council/`.** The former path was `deep-loop-workflows/ai-council/`. The `workflowMode` key, `/deep:ai-council` command, `@ai-council` agent and `<packet>/ai-council/` artifact root are unchanged. Only the skill packet path changed. So no command, agent or stored-artifact path breaks.

## Upgrade

No migration required.
