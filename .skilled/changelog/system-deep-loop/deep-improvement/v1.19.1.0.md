The D4 agreement and verdict fallback scorers measured a Deem backend beside Jev. The Deem arm and the Deem docs are removed, so cli-jev is the only classifier these measurements score, and every default run and Jev arm is unchanged.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/046-deem-deprecation/004-references-sweep-and-verification` (Level 2)

## What's New at a Glance

- **The two measurements run Jev alone.** `score-d4-agreement.cjs` and `score-verdict-fallback.cjs` each keep one Jev arm and reject the removed switch as an unknown flag.
- **The packet docs name Jev only.** The README, the skill doc, the feature catalog and the manual-testing playbook describe the Jev arm alone.

## Upgrade

Drop `--deem` from any measurement command that still passes it. Every default run prints what it printed before.
