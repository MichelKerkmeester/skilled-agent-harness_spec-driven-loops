# v4.0.0.12, The Advisor Sends You to the Right Doctor

v4.0.0.12 connects the skill advisor to the doctor commands. A prompt like "help me set up skilled" used to get no suggestion, and now it names the doctor command to run. A new `/doctor:setup` command gives a fresh clone one place to start.

> Spec folder: `specs/system-skill-advisor/035-doctor-command-routing` (Level 2)

&nbsp;

## What's New at a Glance

- **Setup and health prompts name a doctor command.** "Help me set up skilled" suggests `/doctor:setup` and "check my environment variables" suggests `/doctor:env list`, as lines you can paste and run.
- **A matching skill stays first.** When a skill fits, it keeps first place and the doctor command shows as a second line, so no prompt that routed correctly before changed its answer.
- **A setup prompt with no match gets a hint.** It names `/doctor:setup`, even when the advisor itself is down, and an unrelated prompt gets no hint. Claude, Pi and OpenCode show the same text.
- **One command to start with.** `/doctor:setup` lists all 17 doctor commands and targets and runs five read-only setup checks, naming the doctor command that fixes each failing one.
- **The skill-advisor doctor steps run again.** They called the advisor status check without the workspace root it requires and failed. They now pass it.

&nbsp;

## Upgrade

No migration required. Rebuild the advisor runtime (`npm --prefix .skilled/skills/system-skill-advisor/runtime run build`), then run `/doctor:setup` to check a fresh clone.
