Memory save now finds its spec folder automatically. This release also simplifies the memory save workflow.

## What's New at a Glance

- **Memory save detects the spec folder from Gate 3 conversation context.** A 5-priority detection cascade checks an explicit path first, then Gate 3, then a recent spec, then cwd. As the last step it asks the user.
- **The change is minimal.** Only 2 files were modified.

## Upgrade

No migration required.
