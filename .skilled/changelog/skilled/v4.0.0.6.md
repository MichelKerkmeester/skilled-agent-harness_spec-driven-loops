# v4.0.0.6, Code Reviews Say What They Skipped

v4.0.0.6 makes a code review say what it skipped.

- Every finding it reports must show the input that produces it.
- Reviews read your code's real surface and cache outside it.
- Unknown code is no longer called Webflow.

The code agents say what they left unchecked as well.

- Requests for restraint reach the mode built for them.
- The drift guards stop hiding their warnings.
- The repository rules ask for the risk a change leaves behind.

> [!IMPORTANT]
> One change can break an existing setup. Read it before you update.
>
> 1. Repoint the renamed drift-guard scripts. [Drift-Guard Scripts Use Kebab-Case Names](#c-driftguard-scripts-use-kebabcase-names)

&nbsp;

## Why This Release

A code review could end without saying what it skipped. A finding could arrive with no case showing the input that produces it.

- The review mode also called unknown code Webflow.
- Its re-review cache wrote into the repository it was reviewing.
- The code agents did not report what they left unchecked.
- A deep review in strict mode failed on a missing config.
- It gave a corrupt-line error instead of naming the file it could not read.
- Prompts that asked for restraint did not reach the quality mode.
- The drift guards printed a bare PASS over hundreds of warnings.
- The repository rules left the full reach of a change unstated. They left its residual risk unstated.

## Code Reviews

#### Reviews End on Their Status Line <a id="c-reviews-end-on-their-status-line"></a>

- A code review now ends on its status line.
- Nothing follows it.
- One `Not checked:` line sits directly above it, one blank line apart.
- It names what mattered but could not be checked.
- Each finding carries a `Case` line with the input that shows it.
- A finding with no case is not reported.
- Findings are numbered once across the severity groups.
- The review reads the callers, callees and tests of the changed code. It does this before it judges the change.
- `check-review-final-line.js` and `check-review-findings.js` sit in the review mode's `scripts/` folder. They check a saved review against these rules.

#### Reviews Detect Obsidian and Cache Outside Your Repository <a id="c-reviews-detect-obsidian-and-cache-outside-your-repository"></a>

- The review mode detects OpenCode, Obsidian, Webflow or unknown code. It does so with the hub's shared detection rules.
- It used to call unknown code Webflow.
- Its re-review cache now lives at `${XDG_CACHE_HOME:-$HOME/.cache}/sk-code-review/`.
- So a review never writes into the repository it reviews.

#### Review Findings Show Their Case <a id="c-review-findings-show-their-case"></a>

- Every `/deep:review` finding now carries one line. The line carries the input or situation that produces the wrong result.
- That holds at every severity.
- The reducer reads findings written as numbered lines and keeps each one once.
- That holds even when an iteration restates a structured row.
- A review folder without `deep-review-config.json` now reduces on defaults in lenient mode.
- Strict mode fails with "could not read deep-review-config.json" instead of a corrupt-line error.
- The hint says `--lenient` reduces past it.

#### Code Agents Say What They Skipped <a id="c-code-agents-say-what-they-skipped"></a>

- `@code` lists the callers, tests, fixtures, config and exports a change must reach.
- Its return carries a required `not_checked` field.
- `@debug` reads the test setup and build config before it reproduces a bug.
- It says how many hypotheses it left out.
- It ends each response with a Not checked line.
- `@orchestrate` task briefs gain a Reach field.

## Code Skill

#### One Surface Order Everywhere <a id="c-one-surface-order-everywhere"></a>

- Every sk-code file that ranks the code surfaces now says OpenCode. Then Obsidian, then Webflow.
- A prompt that matches two surfaces lists them in that order.
- When keywords tie between surfaces, the surface of the session's current work can lead.
- `compiled-route.cjs --surface-hint` moves a hinted surface the prompt already matched to the front.
- An unknown hint is ignored.
- A hint never adds or drops a target.

#### Callers Can Pass the Code Surface <a id="c-callers-can-pass-the-code-surface"></a>

- `advisor_recommend` accepts a `surfaceHint` of 1 to 64 characters.
- It passes it to the compiled route.
- The OpenCode plugin sends the surface that its workspace markers name.
- It sends OpenCode only for a workspace inside this repository's `.skilled` folder.
- The Claude and Codex hooks send no hint.

#### Restraint Requests Reach the Quality Mode <a id="c-restraint-requests-reach-the-quality-mode"></a>

- Prompts that ask for restraint, such as "yagni", "simplify", "over-engineering" or "bloat". They now route to the quality mode.
- The restraint ladder checks what the codebase already has. It does so before it reaches for the standard library.
- Restraint never cuts a P0 item.
- Accessibility is now one of them.

#### Marked Shortcuts Have a Report <a id="c-marked-shortcuts-have-a-report"></a>

- `ceiling-report.sh` in the quality mode lists the `ceiling:` and `intentional-limit:` comments in your code.
- It flags any that names no upgrade trigger or no measurable signal.
- It only reports, so a valid run exits 0.
- The quality mode also maps Obsidian plugin changes. It maps them to the checklists the Obsidian packet ships.

#### Drift Guards Check the Docs and Show Warnings <a id="c-drift-guards-check-the-docs-and-show-warnings"></a>

- The sk-code-skilled drift guards run four guards now.
- The router-sync guard is back.
- It also reports reference docs that no router names.
- A new documentation claim checker flags dead paths and retired names. It also flags wrong surface counts and dead anchors.
- The summary shows each guard's warning count on its PASS line.
- It used to print a bare PASS over hundreds of warnings.
- The router-sync guard skips files git ignores.
- So a local cache folder no longer fails it.

#### Drift-Guard Scripts Use Kebab-Case Names <a id="c-driftguard-scripts-use-kebabcase-names"></a>

> [!WARNING]
> Three scripts in sk-code-skilled's `assets/scripts/` were renamed. Call `router-replay-lib.cjs`, `verify-doc-claims.cjs` and `verify-router-sync.cjs` in place of their snake_case names.

- `router_replay_lib.cjs` is now `router-replay-lib.cjs`.
- `verify_doc_claims.cjs` is now `verify-doc-claims.cjs`.
- `verify_router_sync.cjs` is now `verify-router-sync.cjs`.
- Their tests moved with them.

#### Webflow Runtime Checks Catch Late Errors <a id="c-webflow-runtime-checks-catch-late-errors"></a>

- The minified-runtime check used to swallow errors. They came from deferred `setTimeout`, `requestAnimationFrame` and `Webflow.push` callbacks.
- So a script that crashed after load still passed.
- It now fails that file and names the first error.
- Callbacks it skips at its depth cap of 20 are counted in a warning. That warning sits under the PASS line.

## Repo Rules

#### Rules Add Restraint Floors and Residual Risk <a id="c-rules-add-restraint-floors-and-residual-risk"></a>

- `prevent-overengineering.md` adds a floor against a short diff the reader has to decode.
- It adds a tiebreak between equal-cost moves.
- It adds the full reach set of tests, fixtures, config and exports.
- It also covers restraint in moves and merges.
- It lists accessibility among what restraint never cuts.
- The close-out status gains a fifth part for known residual risk.
- It now lives in one place, section 1 of `communication-handoff.md`.
- `AGENTS.md` and `evidence-and-proof.md` point to it.
