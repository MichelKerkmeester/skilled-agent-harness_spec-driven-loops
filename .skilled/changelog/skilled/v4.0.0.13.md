# v4.0.0.13, Fewer False Alarms

v4.0.0.13 removes two sources of misleading results. `/doctor:git setup` stops failing an adapter that exports itself by name, and the drift guards stop burying real warnings under throwaway spec scripts.

> Spec folder: `specs/sk-git/033-git-setup-customization/011-remaining-limits` (Level 1)

&nbsp;

## What's New at a Glance

- **`export default plugin;` counts as registered.** `/doctor:git setup` follows the name to its declaration in the same file, so an OpenCode plugin or Pi extension written that way passes when it really binds the advisory.
- **Drift-guard warnings point at real code.** The sk-code drift guards skip `scratch/` and archived folders under `specs/`, and the shipped files they flagged are fixed, so warnings fall from 278 to 8.

&nbsp;

## Upgrade

No migration required. Rerun `/doctor:git setup`.
