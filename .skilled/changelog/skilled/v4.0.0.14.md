# v4.0.0.14, Short Prompts Route Again and the Setup Checks Hold Everywhere

v4.0.0.14 fixes two problems left in the doctor releases. The doctor routing from v4.0.0.12 had made short prompts like "git hooks" route to nothing, and the setup checks gave wrong verdicts outside the repository they ship in.

> Spec folders: `specs/system-skill-advisor/035-doctor-command-routing` (Level 2) and `specs/sk-git/033-git-setup-customization/009-second-review-remediation` (Level 1)

&nbsp;

## What's New at a Glance

- **Short prompts route again.** "git hooks", "git setup", "git standards" and "git rules" reach sk-git again, and eleven short prompts that never routed, such as "pre-push hook", "squash commits" and "validate spec", now reach their skill.
- **The git setup check holds in any repository.** Clones get the right trust verdict, the rules check reads the repository's own rules file, every repair path is quoted and Hermes is supported with `--tool=hermes`.
- **`/doctor:setup` names a stale advisor.** A stale advisor build now fails with the build command instead of reading as a harmless SKIP.
- **The doctor line survives a busy result.** When three skills match, the `Also: /doctor:...` line still shows, and "run /doctor:x" counts as typing the command.

&nbsp;

## Upgrade

No migration required. Rebuild the advisor runtime (`npm --prefix .skilled/skills/system-skill-advisor/runtime run build`), then rerun `/doctor:setup`.
