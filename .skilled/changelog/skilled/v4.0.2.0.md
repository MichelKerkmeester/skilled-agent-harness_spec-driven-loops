# v4.0.2.0, DeepSeek CLI Joins External Dispatch

The `cli-deepseek-harness` route is configured as an experimental external target for one-task headless runs. No keyed run exists, so live execution is not verified.

> Spec folder: `specs/cli-external-orchestration/085-cli-deepseek-harness-creation/014-playbook-docs-and-closeout`

&nbsp;

## What's New at a Glance

- **`cli-deepseek-harness` joins external dispatch.** The configured route is experimental. A keyed run is still needed to verify live execution.
- **ClickUp pages are tidied in the user's own browser.** `mcp-click-up` removes the empty line ClickUp leaves under each divider in a background tab, in Aside or in the user's Chrome through the new `chrome_devtools_live` manual, and checks the ClickUp approval and browser login before the first write. Add the `chrome_devtools_live` manual from `.utcp_config.json` for the Chrome route.

&nbsp;

## Upgrade

No migration required.

Implementation details are in the `cli-external-orchestration` and `deep-loop-runtime` changelogs. The ClickUp and browser changes are in `mcp-click-up` 1.2.12.0 to 1.2.16.0, `mcp-chrome-devtools` 1.0.21.0 to 1.0.23.0, `mcp-aside-devtools` 1.1.8.0 and 1.1.9.0, and `mcp-tooling` 1.9.7.0 and 1.9.8.0. The `system-deep-loop` entry covers its runtime integration. The `system-spec-kit` entry covers its generators. The `sk-prompt` entry covers its persona guidance.
