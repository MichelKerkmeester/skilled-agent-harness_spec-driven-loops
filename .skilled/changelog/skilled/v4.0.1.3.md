# v4.0.1.3, A Thirteenth Doctor Command and the Counts That Follow It

The doctor family gains an entry point. `/doctor:helper` takes a problem in plain words and names the doctor commands that fit it, with the mutation class and the matched wording on every line. Adding a doctor command moves several counts at once, so this release also carries the mirrors, prompt stubs and indexes that follow it.

&nbsp;

## What's New at a Glance

- **`/doctor:helper` is the way in.** It ranks the doctor commands against a described problem, runs a read-only pick in place and prints a writing pick as one line for you to run, so a command that writes still asks for its own yes.
- **Every runtime carries the new command.** The five mirror trees gained their links and generated prompts, so Claude Code, Codex, Cursor, Hermes, Pi and OpenCode all reach it.
- **The command index is corrected.** The doctor group count and the prose count beside it read thirteen, and the group's row names the new command.
- **The root README's doctor section reads thirteen and lists every command once.** It had said twelve, which matched the twelve router files, and it already carried `/doctor:sk-skill`. The count moves to thirteen for the new command, and the stale second `/doctor:sk-skill` block that a draft of this release appended beside the correct one is removed, so the section holds one bullet per command.
- **The command library total follows the tree.** It now reads forty-one commands: forty in six groups plus the OpenCode-only utility.
