Five independent bugs silently discarded all candidates at different stages of the search pipeline, so every memory search query returned zero results while the health check still reported healthy. This release fixes candidate loss and makes the workflow easier to follow and trust.

> Spec folder: `.opencode/specs/system-spec-kit/023-hybrid-rag-fusion-refinement/007-hybrid-search-null-db-fix/` (Level 2)

## What's New at a Glance

- **Search now returns 8+ results.** Vector, FTS5 and graph channels all contribute.
- **Scope enforcement now defaults to off.** Normal single-user searches without tenant, user or agent IDs return results. Set `SPECKIT_MEMORY_SCOPE_ENFORCEMENT=true` to require those identity parameters.
- **The `WARM` state filter no longer removes every memory.** The `minState = 'WARM'` default and hardcoded `minState: 'WARM'` and `'COLD'` requirements were removed because the warmth-state database column was never created, leaving memories as `UNKNOWN` below the threshold.
- **Unclassified memories now pass state thresholds.** `UNKNOWN_STATE_PRIORITY = 0` changed to `6`, above `HOT = 5`, so unclassified memories pass even the lowest filter, `ARCHIVED = 1`, until the `memoryState` column is implemented.
- **Governance guardrails now default to opt-in.** This prevents similar silent failures in memory save and ingest operations.
- **Rollouts no longer disable search features when identity is absent.** With `SPECKIT_ROLLOUT_PERCENT < 100`, the feature check now uses `return true` rather than `false`, which silently disabled search fallback, embedding expansion, cross-encoder reranking and dozens of other features.
- **Search channel failures now produce warnings.** Vector, graph and degree searches use `console.warn` with the error message instead of silently swallowing errors, so operators can distinguish an empty result from a crashed channel.
- **MCP tool schemas avoid operators rejected by Claude Code.** The client rejects top-level `oneOf`, `anyOf`, `allOf` or `not`. `oneOf` and `not` were removed from `shared_space_upsert`, `shared_space_membership_set` and `shared_memory_status`. Nested `oneOf` was simplified in `memory_drift_why` and `memory_causal_link`.

## Upgrade

No migration required. Restart the MCP server to pick up the fix by killing existing `context-server.js` processes. Claude Code will restart them automatically.
