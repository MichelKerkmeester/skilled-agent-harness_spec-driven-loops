Five independent bugs silently discarded all candidates. Each bug hit a different stage of the search pipeline. So every memory search query returned zero results. The health check still reported healthy. This release fixes candidate loss. It also makes the workflow easier to follow and trust.

## What's New at a Glance

- **Search now returns 8+ results.** Vector, FTS5 and graph channels all contribute.
- **Scope enforcement now defaults to off.** Normal single-user searches return results. That holds when no tenant, user or agent IDs are given. Set `SPECKIT_MEMORY_SCOPE_ENFORCEMENT=true` to require those identity parameters.
- **The `WARM` state filter no longer removes every memory.** The `minState = 'WARM'` default was removed. So were the hardcoded `minState: 'WARM'` and `'COLD'` requirements. That is because the warmth-state database column was never created. So memories were left as `UNKNOWN`, below the threshold.
- **Unclassified memories now pass state thresholds.** `UNKNOWN_STATE_PRIORITY = 0` changed to `6`. That is above `HOT = 5`. So unclassified memories pass even the lowest filter, `ARCHIVED = 1`. That holds until the `memoryState` column is implemented.
- **Governance guardrails now default to opt-in.** This prevents similar silent failures in memory save and ingest operations.
- **Rollouts no longer disable search features when identity is absent.** With `SPECKIT_ROLLOUT_PERCENT < 100`, the feature check now uses `return true` rather than `false`. The old `false` silently disabled search fallback, embedding expansion, cross-encoder reranking and dozens of other features.
- **Search channel failures now produce warnings.** Vector, graph and degree searches use `console.warn` with the error message. They do this instead of silently swallowing errors. So operators can tell an empty result from a crashed channel.
- **MCP tool schemas avoid operators rejected by Claude Code.** The client rejects top-level `oneOf`, `anyOf`, `allOf` or `not`. `oneOf` and `not` were removed from `shared_space_upsert`, `shared_space_membership_set` and `shared_memory_status`. Nested `oneOf` was simplified in `memory_drift_why` and `memory_causal_link`.

## Upgrade

No migration required. Restart the MCP server to pick up the fix by killing existing `context-server.js` processes. Claude Code will restart them automatically.
