# v3.2.0.1, Post-Release Hardening

This post-release pass on v3.2.0.0 hardens graph enrichment and compact recovery.

- Graph enrichment now rejects paths that escape the workspace root.
- Compact-recovery sanitization catches more prompt-injection patterns.
- `SPECKIT_VRULE_OPTIONAL` no longer bypasses memory quality validation.

Session recovery now carries the full context forward.

- `session_bootstrap` now returns the full resume payload.
- Server instructions recommend `session_bootstrap`.
- The compact-recovery description is corrected.

Duplicate detection does less I/O and the shared package resolves again.

- Duplicate detection pre-filters candidates by file size.
- Explicit session IDs pass through the workflow.
- The shared package's broken symlink is fixed.

&nbsp;

## Why This Release

The goal is a workflow that is easier to follow and easier to trust.

## Security

Graph enrichment and recovery now refuse unsafe input.

#### Paths Cannot Escape the Workspace <a id="c-paths-cannot-escape-the-workspace"></a>

- `normalizeGraphFilePath` checks that the resolved path stays inside the workspace root.
- Paths that escape through `../` or absolute jumps are rejected.
- The rejection happens before any file-system operation.

#### Recovery and Validation Resist Abuse <a id="c-recovery-and-validation-resist-abuse"></a>

- The compact-recovery sanitizer strips system-instruction lines from recovered transcripts.
- It now catches more patterns than the single regex previously covered:
  - `[developer]:`
  - `Role:`
  - `Ignore previous instructions`
  - `## Instructions`
  - Markdown headings that name system roles.
- The `SPECKIT_VRULE_OPTIONAL` environment variable could skip memory quality validation entirely.
- That escape hatch is gone.
- So validation always runs or reports when unavailable.

&nbsp;

## Code Graph

Query-time graph reads no longer trigger write-path indexing.

#### Edge Filters Follow the Request <a id="c-edge-filters-follow-the-request"></a>

- The resolved edge filter comes from the explicit `edgeType` argument.
- Otherwise it falls back to the operation prefix.
- The `calls_*` prefix resolves to `CALLS`.
- The `imports_*` prefix resolves to `IMPORTS`.

&nbsp;

## Session Recovery

Session recovery now carries the full context forward.

#### Bootstrap Carries Full Context <a id="c-bootstrap-carries-full-context"></a>

- Previously, `session_bootstrap` passed `minimal: true` to `session_resume`.
- That stripped useful context.
- It now returns the full resume payload.
- It reports completeness as `'full'` instead of `'minimal'`.

#### Recovery Instructions Point to Bootstrap <a id="c-recovery-instructions-point-to-bootstrap"></a>

- The recovery hint in server instructions previously pointed to the session resume helper.
- It now recommends the main composite tool, `session_bootstrap`.

#### Recovery Text Matches Its Content <a id="c-recovery-text-matches-its-content"></a>

- The earlier description was `3-source merge (Memory + Code Graph + CocoIndex)`.
- That was inaccurate.
- The instruction now calls the content a `cached compact brief`.

&nbsp;

## Saving Memories

Memory saves do less I/O and keep caller-supplied IDs.

#### Memory Saves Reduce I/O and Preserve IDs <a id="c-memory-saves-reduce-io-and-preserve-ids"></a>

- Overlap detection previously read up to 20 prior context files.
- It hashed each one.
- It now checks the 12 most recent candidates.
- It skips a full hash when file size does not match the new content's byte length.
- This preserves correctness with less I/O.
- The caller may provide an explicit session ID.
- That ID propagates through the workflow into the session-data collector.
- It is not replaced by a generated one.

&nbsp;

## Package Resolution

The shared package resolves again after a symlink fix.

#### The Shared Package Resolves <a id="c-the-shared-package-resolves"></a>

- The shared package could not resolve because its symlink was broken.
- The link now points to relative `../shared/dist`.
- It no longer points to the broken absolute target.
- So the package can resolve.

&nbsp;

## Upgrade Notes

No upgrade needed. All changes are backward-compatible.
