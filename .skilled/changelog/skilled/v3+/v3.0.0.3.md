This release gives research and review artifacts a consistent home, then aligns the commands, workflows and agent definitions that use them. A predictable layout makes the workflow easier to follow and trust.

> Spec folder: `.opencode/specs/03--commands-and-skills/035-sk-deep-research-path-migration/` (Level 3)

## Why This Release

Research files had been split between spec-folder roots and `scratch/`, while review iterations sat beside final reports.

## What's New at a Glance

- **Research files and review iterations have separate homes.** Research artifacts use `research/` while review iterations use `review/iterations/`, apart from final reports.
- **Deep-research commands and workflows use the new paths.** The main command, four workflow variations and `.agents` wrappers now follow the layout.
- **Deep-research and deep-review agent definitions use consistent paths.** Their path references align across OpenCode, Claude, Codex and Agents.
- **The migration script's same-folder path error was fixed.** References to files within a spec folder no longer become incorrectly nested.

## Research and Review Paths

#### Research and Review Get Clear Homes

Research iteration logs, config, strategy and state had been split between a spec folder's root and `scratch/`, with no clear convention. Review iterations sat beside the final review report. The new layout puts research artifacts under `research/`, including `research/research.md` and `research/iterations/iteration-001.md`, and review iterations under `review/iterations/`, apart from `review/review-report.md`. The system's indexing logic treats iteration folders as working artifacts rather than formal spec documents. The layout change covered 790 files.

**Breaking:** If you maintain custom spec folders outside this repo that use the old layout, move root-level `research.md`, `scratch/iteration-*` and direct `review/iteration-*` paths to `research/` and `review/iterations/` before relying on the updated system.

&nbsp;

#### Commands Follow the New Layout

The main deep-research command file and its workflow files now use the updated paths. This covers `auto`, `confirm`, `review:auto` and `review:confirm`, plus the workflow wrappers used by `.agents`. The first migration pass rewrote references to files within the same spec folder into incorrectly nested paths, so the script was fixed and a second pass cleaned up the 300 affected files.

&nbsp;

#### Agent Paths Agree Across Runtimes

The deep-research and deep-review agent definitions could previously reference different paths depending on the system. Their paths now match across OpenCode, Claude, Codex and Agents.
