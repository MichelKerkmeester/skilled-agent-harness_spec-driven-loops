# Skilled v3.0.0.3

Research and review artifacts now share one consistent home.

- Research artifacts use `research/`.
- Review iterations use `review/iterations/`, apart from final reports.
- A predictable layout makes the workflow easier to follow and trust.

The commands, workflows and agent definitions now use the new layout.

- Deep-research commands and workflows use the new paths.
- The main command, four workflow variations and `.agents` wrappers now follow the layout.
- Deep-research and deep-review agent definitions use consistent paths.
- Their path references align across OpenCode, Claude, Codex and Agents.

The migration script's same-folder path error is fixed.

- The first migration pass made same-folder paths incorrectly nested.
- References to files within a spec folder no longer become incorrectly nested.

> [!IMPORTANT]
> 1 change can break an existing setup. Read it before you update.
>
> 1. Custom spec folders outside this repo using the old layout are affected. [Research and Review Get Clear Homes](#c-research-and-review-get-clear-homes)

&nbsp;

Research and review files lacked a consistent home.

## Research and Review Paths

Research artifacts and review iterations now live in separate folders. The commands, workflows and agent definitions point to them.

#### Research and Review Get Clear Homes <a id="c-research-and-review-get-clear-homes"></a>

> [!WARNING]
> If you maintain custom spec folders outside this repo that use the old layout, this applies to you.
> Move root-level `research.md`, `scratch/iteration-*` and direct `review/iteration-*` paths to `research/` and `review/iterations/` before relying on the updated system.

- Research iteration logs, config, strategy and state had been split between a spec folder's root and `scratch/`.
- There was no clear convention.
- Review iterations sat beside the final review report.
- The new layout puts research artifacts under `research/`.
- That includes `research/research.md` and `research/iterations/iteration-001.md`.
- Review iterations go under `review/iterations/`, apart from `review/review-report.md`.
- The system's indexing logic treats iteration folders as working artifacts, not formal spec documents.
- The layout change covered 790 files.

#### Commands Follow the New Layout <a id="c-commands-follow-the-new-layout"></a>

- The main deep-research command file and its workflow files now use the updated paths.
- This covers `auto`, `confirm`, `review:auto` and `review:confirm`.
- It also covers the workflow wrappers used by `.agents`.

#### Agent Paths Agree Across Runtimes <a id="c-agent-paths-agree-across-runtimes"></a>

- The deep-research and deep-review agent definitions could previously reference different paths.
- That depended on the system.
- Their paths now match across OpenCode, Claude, Codex and Agents.

#### Same Folder Paths Fixed <a id="c-same-folder-paths-fixed"></a>

- The first migration pass rewrote references to files within the same spec folder.
- It made them incorrectly nested paths.
- So the script was fixed.
- A second pass cleaned up the 300 affected files.
