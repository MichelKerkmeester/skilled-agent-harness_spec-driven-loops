This release gives research and review artifacts a consistent home. It then aligns the commands, workflows and agent definitions that use them. A predictable layout makes the workflow easier to follow and trust.

## Why This Release

Research files had been split between spec-folder roots and `scratch/`. Review iterations sat beside final reports.

## What's New at a Glance

- **Research files and review iterations have separate homes.** Research artifacts use `research/`. Review iterations use `review/iterations/`, apart from final reports.
- **Deep-research commands and workflows use the new paths.** The main command, four workflow variations and `.agents` wrappers now follow the layout.
- **Deep-research and deep-review agent definitions use consistent paths.** Their path references align across OpenCode, Claude, Codex and Agents.
- **The migration script's same-folder path error was fixed.** References to files within a spec folder no longer become incorrectly nested.

---

## Research and Review Paths

#### Research and Review Get Clear Homes

Research iteration logs, config, strategy and state had been split between a spec folder's root and `scratch/`. There was no clear convention. Review iterations sat beside the final review report. The new layout puts research artifacts under `research/`. That includes `research/research.md` and `research/iterations/iteration-001.md`. Review iterations go under `review/iterations/`, apart from `review/review-report.md`. The system's indexing logic treats iteration folders as working artifacts, not formal spec documents. The layout change covered 790 files.

**Breaking:** If you maintain custom spec folders outside this repo that use the old layout, this applies to you. Move root-level `research.md`, `scratch/iteration-*` and direct `review/iteration-*` paths to `research/` and `review/iterations/` before relying on the updated system.

&nbsp;

#### Commands Follow the New Layout

The main deep-research command file and its workflow files now use the updated paths. This covers `auto`, `confirm`, `review:auto` and `review:confirm`. It also covers the workflow wrappers used by `.agents`. The first migration pass rewrote references to files within the same spec folder. It made them incorrectly nested paths. So the script was fixed. A second pass cleaned up the 300 affected files.

&nbsp;

#### Agent Paths Agree Across Runtimes

The deep-research and deep-review agent definitions could previously reference different paths. That depended on the system. Their paths now match across OpenCode, Claude, Codex and Agents.
