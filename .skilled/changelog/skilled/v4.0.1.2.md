# v4.0.1.2, A Format Doctor for Skills, With Check and Convert

A skill that has drifted from the Skilled format used to be a question you answered by reading the format rules and comparing them to a folder by hand. `/doctor:sk-skill` answers it twice: `check` reports how far one skill or the whole fleet is from the format, row by row. `convert` moves one skill onto it, printing the plan and waiting for a yes before it writes a line.

> Spec folder: `specs/sk-doc/075-doctor-sk-skill-command` (Level 2)

&nbsp;

## What's New at a Glance

- **The format has a doctor of its own.** A bare `/doctor:sk-skill` runs the read-only `check` target, so the writing target is only reached when someone types `convert` and names a skill.
- **Check reports the distance, not a verdict.** Each skill gets rows `C1` to `C13` in their shipped order with the repair for every finding, `--json` prints the engine's report alone, and `--into-hub <hub>` swaps the rows for the eleven surfaces a skill must land on under that hub.
- **A skill in another repository is judged against its own repository.** The rows read the changelog index and the mirrors of the repository that owns the target, and each row names the repository it read, so a borrowed tool is named as borrowed.
- **Both skill shapes convert.** An older Skilled skill has its inline router moved into a sibling `ROUTER.md` where it sits, and a plain skill is staged as a copy under `.skilled/skills/<name>` while its source folder is left exactly as it was.
- **Each question is asked on its own.** A plain skill needs at least eight intent phrases of three or more words, a description over the budget needs its trim written out in full, and a missing `allowed-tools` list is proposed and then approved or edited. A no at any of them ends the run with nothing written.
- **The body is proved to survive before the format gate.** Every non-heading line of the source has to appear in the new `SKILL.md`, `ROUTER.md` or a reference document, so a rewrite that loses a line stops there instead of shipping.
- **Wiring follows the format, and every row reports.** The advisor scan, the compiled skill graph, a reach probe against three approved phrases, the regression cases, the Hermes mirror and the changelog entry with its relative link each print their own result, and a failing row keeps the conversion and names the repair.
- **The way back is printed, never run.** The engine ends with an undo block that restores the files it overwrote and removes the ones it created, and it says that rescuing the advisor graph after an undo is a rescan rather than a copy.

&nbsp;

## Upgrade

No migration required. `/doctor:setup` lists both targets, and nothing converts until someone runs the `convert` target and answers its questions. A repository that keeps its own copy of `.skilled/commands` picks the command up when it refreshes that copy.
