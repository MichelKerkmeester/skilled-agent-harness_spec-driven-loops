# v4.0.0.4, Related Work Stays Together, Answers Hold

v4.0.0.4 stops a run of small fixes to one file from turning into a run of separate top-level packets, and it regroups 21 packets that had already scattered. Agents now keep a checked answer when you push back with no new fact, and Devin reads the current rules of the checkout it works in. The communication rules state each norm once, and the bundled runtimes pick up security fixes.

&nbsp;

## What's New at a Glance

- **A second change to the same artifact joins a series parent.** A new fix to a file, script or command that an existing packet in the same track already changed now becomes a child of one series parent instead of another top-level packet. Gate 3 option C names it, and `phase-definitions.md` sets the three conditions.
- **New packets show their neighbors and can be found.** `create.sh` lists the packets made in the same track in the last 14 days before it numbers a new one. It also writes trigger phrases from the packet's name and description, so search finds a new packet by its topic instead of four template placeholders.
- **21 small packets moved under four parents.** The spec-folder tooling, the write-recipe fixes, the advisor defect fixes and the deep-loop review work each sit under one parent now. Each parent carries a `timeline.md` that maps the old numbers to the new ones.
- **A checked answer holds under pushback.** A new section in `uncertainty-and-honesty.md` says a settled conclusion reopens only for a reason you can name, such as a failing check or a contradicting fact. Pushback with no new fact gets checked, not adopted, and a decision you reaffirm stays yours. One line in `AGENTS.md` keeps the rule in view on every turn.
- **The communication rules state each norm once.** Agents lead with the answer instead of restating the request, and the rules now follow their own punctuation bans. A time estimate before a long stretch rests on how long a similar run took or says it is an assumption. The question-tool guidance also names Codex's `request_user_input`.
- **Devin reads the current rules.** Devin used to load the main checkout's `AGENTS.md` through `~/.claude/CLAUDE.md`, so a worktree session followed old rules. `.devin/config.json` now turns that import off and `.devin/skills` gives Devin every skill directly.
- **The bundled runtimes carry patched dependencies.** The fixes cover a critical advisory in proxy-addr and high ones in the MCP SDK, sharp, source-map-js and nanoid. A moderate one in fast-uri is fixed too. The fixes land in six lockfiles: spec-kit, the skill advisor, deep-loop, the Code Mode server, the design-md generator backend and `.skilled` itself.

&nbsp;

## Upgrade

- **Repoint moved packet paths.** A link or note that names one of the 21 moved packets by its old path needs the new one. The parent's `timeline.md` lists both.
- **Move personal skills Devin should see.** Devin no longer reads `~/.claude/`, so a personal skill kept only in `~/.claude/skills` stops reaching it. Put that skill in `~/.agents/skills` instead.
- **Reinstall dependencies.** An existing install keeps the vulnerable versions until it reinstalls. Rerun the `npm --prefix <package> install` commands from the README setup for each package you installed.
