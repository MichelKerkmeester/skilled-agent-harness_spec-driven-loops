# v4.0.1.1, A Neutral Launch Agent Label and Portable Paths

The launch agent template that schedules the orphan sweep now carries a neutral label, `com.skilled.orphan-sweep`, instead of one that named a personal account. Its install step fills in your repository and home paths, so a copy works on any machine without hand edits. Skill docs, playbooks and recorded benchmark evidence also name repository-relative paths now instead of one machine's home folder, and no recorded result changed.

> Spec folder: `specs/sk-git/036-personal-name-scrub` (Level 1)

&nbsp;

## What's New at a Glance

- **The template file has a new name.** It lives at `.skilled/scripts/launchagents/com.skilled.orphan-sweep.plist`, and every doc and check that named the old file points at the new one.
- **The install command fills in two placeholders.** `/absolute/path/to/repo` and `/absolute/path/to/home` become your repository root and home directory as the template is copied. The copy still keeps `--dry-run` until you remove it.
- **The trigger-phrase migration finds its own memory folder.** It works out the Claude Code memory folder from the repository it runs in, where it used to name one fixed checkout.

&nbsp;

## Upgrade

An agent you installed from the old template keeps running under its old label. To move it to the new one, follow the upgrade step in `.skilled/scripts/launchagents/README.md`, which unloads the old agent, removes its plist and installs a fresh copy.
