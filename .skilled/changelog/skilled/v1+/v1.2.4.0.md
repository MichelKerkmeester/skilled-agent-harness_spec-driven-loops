This release fixes an API naming mismatch and suppresses template warnings. It focuses on making the instructions and release notes easier for non-developers to follow. The goal is to make the workflow easier to follow and easier to trust.

## What's New at a Glance

- **The vector index adds snake_case export aliases.** `initialize_db`, `get_db`, `get_memory` and `get_db_path` provide backward compatibility with the retry manager and fix the `vector_index.get_db is not a function` error during retry processing. This reduces confusing failures and makes the system more dependable.
- **The template renderer gains `OPTIONAL_PLACEHOLDERS`.** The set suppresses warnings for V2.2 spec'd-but-unimplemented placeholders: Session Integrity Checks (8), Memory Classification (6), Session Deduplication (3) and Postflight Learning Delta (9). This makes the release notes and instructions easier to read and trust.
