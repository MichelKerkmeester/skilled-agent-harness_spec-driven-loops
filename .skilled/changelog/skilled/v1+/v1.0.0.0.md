This release sets down some core rules. The spec kit uses them to judge whether work is ready to move forward. The release also reorganizes a few internal scripts. That makes the project easier to maintain.

## What's New at a Glance

- **A two-part check decides when to continue.** It weighs confidence and uncertainty before work moves ahead. That makes decisions more consistent. It also lowers the chance of pushing ahead on weak assumptions.
- **The Five Checks Framework reviews bigger changes.** Larger specs get more structure than a quick yes-or-no check. Fit, quality and maintainability are reviewed before the work moves forward.
- **A session learning handler feeds the memory workflow.** `session-learning.js` remembers what happened during a working session. Later steps get more context. Follow-up work is easier.
- **A script cleanup puts helpers in fitting folders.** `decision-tree-generator.js` and `opencode-capture.js` moved into `lib/` and `extractors/`. The move undoes a layout that made the codebase harder to navigate.
