## Memory Commands

Memory commands cover database, checkpoint and maintenance operations. This release consolidates the set and changes search and causal tracing.

#### Operations Share One Command <a id="c-operations-share-one-command"></a>

- `/memory:manage` is the unified command for these operations.
- `/memory:database` is consolidated into `/memory:manage`.
- `/memory:checkpoint` is consolidated into `/memory:manage`.
- Both are marked deprecated.

#### Corrections Move Into Learn <a id="c-corrections-move-into-learn"></a>

- `/memory:learn` now includes the `correct` subcommand for corrections.
- `/memory:correct` is consolidated into `/memory:learn correct`.
- `/memory:correct` is marked deprecated.

#### Search and Causal Tracing Change <a id="c-search-and-causal-tracing-change"></a>

- `/memory:search` is replaced by `/memory:context`.
- `/memory:search` is marked deprecated.
- `/memory:why` is removed and marked deprecated.
- Causal tracing is available via MCP tools.

#### Intent and Temporary-File Handling <a id="c-intent-and-temporaryfile-handling"></a>

- Intent detection now uses phrase-based matching, which avoids false positives.
- Temporary-file handling is added across platforms.

&nbsp;

## Checkpoint Operations

Checkpoint operations cover restores and cleanup. This release adds safeguards to both.

#### Restores and Cleanup Gain Safeguards <a id="c-restores-and-cleanup-gain-safeguards"></a>

- Rollback is added for checkpoint restore operations.
- Checkpoint validation is added before cleanup operations.

&nbsp;

## Memory References and Guidance

This section covers tool names and details in learn and context.

#### Tool References Match Names <a id="c-tool-references-match-names"></a>

- `memory_drift_context` is corrected to `memory_context`.
- References to the nonexistent `memory_drift_learn` tool are removed.

#### Learning and Context Details Are Corrected <a id="c-learning-and-context-details-are-corrected"></a>

- The `AutoImportance` type inconsistency is fixed in learn.
- The example numbering gap is fixed in learn.
- The context date typo changes from 2026 to 2025.

&nbsp;

## Upgrade Notes

These steps cover the command changes.

#### Before You Start <a id="c-before-you-start"></a>

1. Use `/memory:manage` for database, checkpoint and maintenance operations.
2. Use `/memory:learn correct` for corrections.
3. Use `/memory:context` instead of `/memory:search`.
4. Use MCP tools for causal tracing rather than `/memory:why`.
