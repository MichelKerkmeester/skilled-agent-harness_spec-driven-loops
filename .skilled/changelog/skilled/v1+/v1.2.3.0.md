This release brings post-modularization alignment to the test suite, correcting file paths and the README exclusion logic. It focuses on instructions and release notes that non-developers can follow. The goal is a workflow that is easier to follow and easier to trust.

## What's New at a Glance

- **File paths now match the modular lib structure.** The vector index, memory parser and generate context modules moved and the rate limiting and database check functions now live in db state, with query validation in validators. This change reduces confusing failures and makes the system more dependable.
- **The file counting logic now leaves README files out.** They no longer add to the template counts. This makes the release notes and instructions easier to read and trust.
