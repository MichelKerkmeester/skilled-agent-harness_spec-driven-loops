# v1.1.1.0, Authoring Steps Numbered and Checks Itemized

The packet's `SKILL.md`, `README.md`, conversation template and references were read file by file for readability, layout and structure. Text moved and split, and every claim was kept. No command, contract or template behavior changed.

> Spec folder: `specs/sk-doc/066-skill-readability-refinement/008-sk-doc` (Level 1)

&nbsp;

## What's New at a Glance

- **The authoring sequence is numbered.** The README now walks eleven steps, from confirming the target system to spot-checking per-feature files, and its When to Use moved up beside What It Does.
- **Choosing a scenario style comes earlier.** `SKILL.md`'s section on single-prompt versus conversation scenarios now follows the authoring sequence, with its four ordered questions and runner command unchanged.
- **The two check sections have distinct names.** The two "Automated Checks" headings are now "Shared Document Validation" and "Operator Contract Validator".
- **Per-feature checks are itemized.** The operator validator's checks, from five-section ordering to placeholder exclusion, read one per bullet.
- **Small duplicates are gone.** The common-pitfalls reference gained a Purpose, a When to Use and a Core Principle heading, the reference map dropped its closing footer, and the conversation template no longer repeats its use line.
