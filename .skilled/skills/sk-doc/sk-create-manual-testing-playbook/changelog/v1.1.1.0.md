# v1.1.1.0, Authoring Steps Numbered and Checks Itemized

The packet's `SKILL.md`, `README.md`, conversation template and references were read file by file. The read looked at readability, layout and structure. Text moved and split. Every claim was kept. No command, contract or template behavior changed.

&nbsp;

## What's New at a Glance

- **The authoring sequence is numbered.** The README now walks eleven steps. They run from confirming the target system to spot-checking per-feature files. Its When to Use moved up beside What It Does.
- **Choosing a scenario style comes earlier.** `SKILL.md`'s section on single-prompt versus conversation scenarios now follows the authoring sequence. Its four ordered questions and runner command are unchanged.
- **The two check sections have distinct names.** The two "Automated Checks" headings are now "Shared Document Validation" and "Operator Contract Validator".
- **Per-feature checks are itemized.** The operator validator's checks read one per bullet. They run from five-section ordering to placeholder exclusion.
- **Small duplicates are gone.** The common-pitfalls reference gained a Purpose, a When to Use and a Core Principle heading. The reference map dropped its closing footer. The conversation template no longer repeats its use line.

No migration required.
