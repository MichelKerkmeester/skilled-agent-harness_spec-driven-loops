# v1.3.2.0, The Runner Submits Claude Code's Newer Review Screen

When Claude Code asks several questions in one dialog, it ends on a review screen. Version 2.1.316 asked "Ready to submit your answers?" there. Version 2.1.330 shows only "Review your answers" above the same Submit row, so the runner never pressed Submit and the turn timed out.

&nbsp;

## What's New at a Glance

- The Claude Code adapter in `scripts/run-conversation-scenario.cjs` confirms a review screen with either wording, followed by `❯ 1. Submit answers`.
- A new fixture, `scripts/tests/fixtures/question-screens/claude-code-review-unprompted.txt`, records the 2.1.330 screen. The runner suite checks that it is confirmed and not read as a question.
- `setup`, `launch_setup` and `check` commands now get `CONVERSATION_SANDBOX`, the sandbox mode the runner records. A Chrome started inside the macOS seatbelt crashes on launch, and a Bladebro daemon relaunched it in a loop during a live run. `references/conversation-scenarios.md` (1.0.7.0) says a scenario that may open a browser skips under `seatbelt` and stops the browser daemons it started.

&nbsp;

## Upgrade

No action is needed. A conversation scenario that timed out on Claude Code's review screen can be run again. A scenario that opens a browser runs with `--no-sandbox`.
