# v1.1.2.0, The validator runs on a package in another repository

The package validator failed on a vendored package. Every local link read as outside the repository, and the corpus manifest stopped the run.

> Spec folder: `AI Systems/Product Owner/specs/system/032-fresh-review-fixes`

&nbsp;

## What's New at a Glance

- **A foreign root works.** With `--repo-root`, links resolve against that root. Manifest roots missing there are skipped and named in a note.
- **A supplied manifest stays strict.** `--manifest` still fails on a root that does not exist.
- **The hint is printed.** A package outside the root with no `--repo-root` names the flag.
