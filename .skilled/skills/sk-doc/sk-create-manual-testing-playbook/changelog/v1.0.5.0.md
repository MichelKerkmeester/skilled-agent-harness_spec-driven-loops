# v1.0.5.0, The Router Moves to Its Own Section

`SKILL.md` now states its routing in four plain sentences: what selects this packet, the resources it loads before writing and where the machine router lives. The decision rule, the family boundary and the router pseudocode that followed it moved unchanged into a final `## 11. MACHINE ROUTER` section, which closes the file.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/006-sk-doc-hub` (Level 2)

## What's New at a Glance

- **The routing section reads at a glance.** A reader sees the selection rule, the resources loaded before writing and the pointer to the router without scrolling through pseudocode.
- **The router itself is unchanged.** Every machine block moved byte for byte, so the same requests reach the same leaves.
- **Nothing else moved.** Section numbers and order are as they were, and the new section is appended at the end.
