# v1.0.5.0, The Router Moves to Its Own Section

`SKILL.md` now states its routing in four plain sentences. They say what selects this packet. They name the resources it loads before writing. They say where the machine router lives.

The decision rule, the family boundary and the router pseudocode followed it. They moved unchanged into a final `## 11. MACHINE ROUTER` section. That section closes the file.

&nbsp;

## What's New at a Glance

- The routing section reads at a glance.
  - A reader sees the selection rule.
  - A reader sees the resources loaded before writing.
  - A reader sees the pointer to the router.
  - All of it comes without scrolling through pseudocode.
- The router itself is unchanged.
  - Every machine block moved byte for byte.
  - So the same requests reach the same leaves.
- Nothing else moved.
  - Section numbers and order are as they were.
  - The new section is appended at the end.

&nbsp;

## Upgrade

No migration required. The routing behavior is identical.
