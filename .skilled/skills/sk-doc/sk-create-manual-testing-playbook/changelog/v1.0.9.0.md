# v1.0.9.0, Conversation Scenarios

The playbook skill now documents multi-turn conversation scenarios as a closed JSON script embedded in each per-feature scenario file.

&nbsp;

## What's New at a Glance

- **The conversation contract is documented.** `references/conversation-scenarios.md` defines the allowed keys, turn outcomes, evidence, and authoring rules.
- **The per-feature scaffold has a filled script.** The first `send` matches the natural-human prompt example, and the notes keep scripts aligned with scenario prompts.
- **The skill routes conversation work.** `SKILL.md` explains when a conversation scenario is needed and names the `CONVERSATION_SCRIPT_INVALID` check.
- **The reference is discoverable.** `ROUTER.md` and `references/README.md` include the new resource.

&nbsp;

## Upgrade

Use `references/conversation-scenarios.md` when authoring or reviewing a multi-turn scenario.
