# v1.0.9.0, The Machine Router Moves to ROUTER.md

The machine router now lives in a sibling `ROUTER.md`. `SKILL.md` keeps SMART ROUTING as short prose that ends with a link to it. The parsed router is identical to the previous edition, so routing stays the same.

&nbsp;

## What's New at a Glance

- **The machine router keeps its full structure.** `ROUTER.md` starts with a short overview and intent model. Its `MACHINE ROUTER` section holds the intent map, resource map, default resource, loading levels and routing pseudocode.
- **References point to the new file.** All router references now point to `ROUTER.md`, including links in testing playbooks and feature catalog entries.
- **The router description names what the file holds.** It now describes the intent model, the resilience rules and the resource loading sequence instead of an intent map and a resource map the file never declares.
