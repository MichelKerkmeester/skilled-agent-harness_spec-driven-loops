# v1.0.5.0, The Doctor Family Registers the CI Command

The command contract now describes `/doctor:ci` inside the doctor family. A reader of the contract can see the command's router, its arguments, the route it resolves to and the writes each gated route may perform.

&nbsp;

## What's New at a Glance

- **`/doctor:ci` has a router entry.** The contract points at `.skilled/commands/doctor/ci.md`, which lists GitHub Actions workflows with their switch state, scaffolds a new workflow or toggles one CI switch.
- **Its routes are named.** The argument hint and the invocation aliases name `report`, `scaffold` and `toggle`. The `list` alias works as well.
- **Its writes are gated.** Scaffold writes one new workflow file after an approved plan and refuses an existing or protected name. After approval, toggle either sets one documented CI variable to off or deletes it. It refuses to turn `SKILLED_CI` or `SKILLED_CI_MESSAGES` off while the README forbids it.
- **The violation check is for phased commands.** The template asks for the self-detection section only in a workflow command that has blocking phases. A command without them can leave it out.
- **Compiled deep contracts end in `.markdown`.** The contract lists the deep family's compiled contract files under `.skilled/commands/deep/` with that extension, where it used to name them `.md`.
