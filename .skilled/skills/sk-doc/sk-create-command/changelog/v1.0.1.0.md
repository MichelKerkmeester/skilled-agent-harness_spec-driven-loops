The command-authoring packet now satisfies the shared skill packager's required-section contract.

## What's New at a Glance

- **Discovery and routing now have separate headings.** The old `WHEN TO USE + SMART_ROUTING` heading in `SKILL.md` is now `## 1. WHEN TO USE`. That heading covers use and do-not-use boundaries. Next comes `## 2. SMART ROUTING` for keyword triggers and the sibling-packet hand-off rule. No prose was removed. The routing keyword-trigger line moved under `SMART ROUTING`. Its space-separated heading is recognized as distinct by the canonical section matcher.
- **The H2 sections now run consecutively from 1 through 6.** The new `## 5. SUCCESS CRITERIA` section states when a command produced through this packet is complete. It fills the recommended-section gap.

## Upgrade

No migration required. This is structural normalization only. The authoring workflow, rules and references are unchanged.
