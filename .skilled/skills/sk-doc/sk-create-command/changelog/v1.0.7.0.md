# v1.0.7.0, The Routing Prose Is Short and the Router Moved to the End

A reader now meets the command-authoring workflow sooner. `SMART ROUTING` is five lines of plain prose. They say what selects this packet, what it loads first and where the router is. The router resilience rules and the resource loading sequence sit unchanged in a final section. That section is `## 7. MACHINE ROUTER`. Nothing about what routes where changed.

&nbsp;

## What's New at a Glance

- **The routing section is prose.** Five lines name the request that selects this packet. They name the resource that loads first and the section that holds the router. So the creation workflow starts sooner.
- **The router is at the end.** The router resilience rules and the resource loading sequence moved byte for byte. They sit in `## 7. MACHINE ROUTER`. That is the last H2 of the file. Both sit under the headings they already carried.

&nbsp;

## Upgrade

No action is needed. The packet routes and loads exactly the resources it did before. Only the section that holds the routing detail changed.
