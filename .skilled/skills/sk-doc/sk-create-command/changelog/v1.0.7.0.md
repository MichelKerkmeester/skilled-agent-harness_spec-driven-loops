# v1.0.7.0, The Routing Prose Is Short and the Router Moved to the End

A reader now meets the command-authoring workflow sooner. `SMART ROUTING` is five lines of plain prose that say what selects this packet, what it loads first and where the router is, and the router resilience rules and the resource loading sequence sit unchanged in a final `## 7. MACHINE ROUTER` section. Nothing about what routes where changed.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/006-sk-doc-hub` (Level 2)

&nbsp;

## What's New at a Glance

- **The routing section is prose.** Five lines name the request that selects this packet, the resource that loads first and the section that holds the router, so the creation workflow starts sooner.
- **The router is at the end.** The router resilience rules and the resource loading sequence moved byte for byte into `## 7. MACHINE ROUTER`, the last H2 of the file, under the headings they already carried.

&nbsp;

## Upgrade

No action is needed. The packet routes and loads exactly the resources it did before; only the section that holds the routing detail changed.
