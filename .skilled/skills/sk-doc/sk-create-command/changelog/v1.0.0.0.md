## Command Authoring

The packet's command authoring spans a creation workflow, reference documents and two templates.

#### A Defined Creation Workflow <a id="c-a-defined-creation-workflow"></a>

- The workflow scaffolds and refactors OpenCode slash commands.
- They live under `.opencode/commands/`.
- Command work follows a 13-step process.
- It decides whether a command is warranted.
- It resolves its invocation path.
- It reads existing files first.
- It then classifies the command type.
- It chooses the output package shape.
- It authors frontmatter with the fields `description`, `argument-hint` and `allowed-tools`.
- The workflow's remaining steps add mandatory input gates for required arguments.
- They write the command body.
- They implement argument dispatch and `:auto`/`:confirm` mode routing.
- Then they enforce the thin-router and presentation-asset split.
- That split applies to larger mode-based commands.
- They also add destructive-action safety.
- They validate before delivery.
- The rules require least-privilege `allowed-tools`.
- They require mandatory gates for required arguments.
- They require presentation text outside thin routers.
- Unclear invocation contracts are escalation conditions.

#### References Guide Authoring <a id="c-references-guide-authoring"></a>

- `references/README.md` is the overflow route map.
- It indexes the single-concern references.
- `references/worked-example.md` provides the canonical file contract.
- It also provides a fully worked split command.
- The command has a router `.md` and presentation `.txt`.
- `references/router-presentation-split.md` covers router and presentation ownership.
- It covers the before-and-after transformation and the behavior-preserving rule.
- `references/argument-hints-and-modes.md` covers argument-hint design patterns.
- It covers `:auto`/`:confirm` mode design and frontmatter/description budget tips.
- `references/common-pitfalls.md` covers command-vs-skill-vs-agent selection.
- It covers the common command-authoring mistakes table.

#### Templates for Command Families <a id="c-templates-for-command-families"></a>

- `assets/command/command-template.md` provides command-type templates, examples, vocabulary and a validation checklist.
- `assets/command/command-presentation-template.md` is the full `_presentation.txt` skeleton.
- It is for split mode-based command families.
