# v1.0.4.0, One Place for the Input Gate

The packet gave two different positions for a command's input gate, so a new command could follow either. It now states one rule everywhere, taken from the commands that already ship.

> Spec folder: `specs/sk-git/033-git-setup-customization/008-out-of-scope-cleanup` (Level 1)

&nbsp;

## What's New at a Glance

- **One rule.** The gate sits after the H1 and its purpose line, before any workflow step. The skill, README, references, template and playbook all say so.
- **The examples follow it.** Four example skeletons in the template and worked example moved their gate below the H1.
- **Every shipped command matches.** `/doctor:git` moved its gate to the same place, so all nine commands with an input gate agree.

&nbsp;

## Upgrade

No migration required. A command whose gate sits above its H1 still works, and moving it below the H1 matches the rule.
