# v1.0.2.0, The Validation Example Names the Agent File as a Placeholder

The validate step ran the checker against a path that read like a real agent file, so a reader who copied it got an error about a missing file instead of the clean verdict the page promised. The path now shows the name as yours to fill in.

## What's New at a Glance

- **The example path reads as a placeholder.** The angle brackets say the file name is yours, so the command looks unfinished on purpose rather than broken.
- **A copied command points at your agent.** Fill in your own name and the checker reads the file you wrote.
