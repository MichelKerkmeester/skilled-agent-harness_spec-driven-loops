This release documents a clear choice between an agent, skill and command. The choice covers ambiguous requests. It also records why the packet uses flat resource folders. Mixed requests get a defined route.

&nbsp;

## What's New at a Glance

- Ambiguous requests resolve to a clear owner.
  - The agent-vs-skill-vs-command decision path lives in `references/agent-vs-skill-vs-command.md`.
  - That file holds the distinguishing signals, the lighter-alternative cues and the decision rule.
  - The file is loaded when a request could plausibly be a skill or command.
  - The file also loads when a request mixes responsibilities.
  - So ambiguity does not default to an agent.
- The packet adds no per-key resource subfolders.
  - The packet uses flat `references/` and `assets/` folders.
  - The packet has no keyed `references/<key>/` directories.
  - The resource set is small.
  - So the route map in `references/README.md` is clearer than keyed runtime discovery.
