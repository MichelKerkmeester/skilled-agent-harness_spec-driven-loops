# v1.0.10.0, a Binding Read From a File Follows That Read

The template said every setup binding comes before any read. Some values only exist after a read. The deep-review agent takes its bindings from the config. The markdown agent takes its template path from the template it reads. Both had to break the rule.

&nbsp;

## What's New at a Glance

- **A read-sourced binding follows its read.** The binding comes right after the config or template read. It still comes before any other step.
- **Other bindings keep their place.** A value known from the dispatch is still bound before any read.
- **Both copies agree.** The section 4 contract and the section 8 skeleton carry the same rule.

&nbsp;

## Upgrade

No migration required. Agents that bind before any read stay valid.
