# v1.0.8.0, the Creation Workflow Names the Agent Registry

The ordered creation workflow in `SKILL.md` told an author to run the roster check and never told them to add the registry record the check requires. A new agent file with no record failed the check with an error the skill did not mention. The workflow now has the step.

> Spec folder: `specs/agents/007-agent-alignment-follow-ups/004-agent-authoring-registry-step` (Level 1)

&nbsp;

## What's New at a Glance

- **A registry step before validation.** Step 13 tells the author to add a record for the new agent to `.skilled/agents/agent-registry.json`, names the fields a record carries and says to run `node .skilled/bin/sync-agent-roster.cjs` so the generated rosters pick the agent up.
- **The error is quoted.** The validation step, now step 14, quotes `agent file without a registry record: <name>`, the line the roster check prints for an agent file that has no record.
- **Delivery is step 15.** The two later steps moved down by one, with their wording unchanged.
