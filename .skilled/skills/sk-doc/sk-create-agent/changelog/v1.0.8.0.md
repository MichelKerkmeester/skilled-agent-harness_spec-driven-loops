# v1.0.8.0, the Creation Workflow Names the Agent Registry

The creation workflow in `SKILL.md` told an author to run the roster check. It never said to add the registry record that check requires. A new agent file with no record failed the check. The skill did not mention that error. The workflow now has the step.

> Spec folder: `specs/agents/007-agent-alignment-follow-ups/004-agent-authoring-registry-step`

&nbsp;

## What's New at a Glance

- **A registry step before validation.** Step 13 tells the author to add a record to `.skilled/agents/agent-registry.json`. It names the fields a record carries. It says to run `node .skilled/bin/sync-agent-roster.cjs`. That command rewrites the generated rosters.
- **The error is quoted.** The validation step is now step 14. It gained one sentence that quotes `agent file without a registry record: <name>`. The roster check prints that line for an agent file with no record.
- **Delivery is step 15.** The delivery step moved down by one. Its wording did not change.
