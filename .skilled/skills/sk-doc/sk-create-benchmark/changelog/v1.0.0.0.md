# v1.0.0.0, Benchmark Evidence for Skills

The initial release makes `create-benchmark` one of the ten workflow-only packets under the `sk-doc` parent hub. It promotes a shipped spec packet's curated MCP benchmark evidence into a consuming skill's `mcp-server/benchmarks/benchmark-<YYYY-MM-DD>/` folder, where operators can find the winner without leaving the skill tree.

## What's New at a Glance

- **A dated folder brings benchmark evidence into the consuming skill.** `mcp-server/benchmarks/benchmark-<YYYY-MM-DD>/` holds a ten-section `benchmark_report.md`, a `SOURCE.md` wayfinding pointer back to the authoritative spec packet and the supporting `results.csv`, `per-probe.jsonl` and `runtime-measurements.md` artifacts.
- **`SKILL.md` is the primary contract.** It defines the adoption gate, required package shape and ten-step authoring workflow. It also sets the fixed ten-section `benchmark_report.md` report contract, date and naming conventions for dated folders, re-runs and retirements, authority hierarchy and ALWAYS/NEVER/ESCALATE rules.
- **`references/benchmark_creation.md` provides deep overflow for benchmark promotion.** It covers case studies, sibling examples and uncommon edge cases.
- **The report and source pointer each have a template.** `assets/benchmark/benchmark-report-template.md` is the template for the ten-section `benchmark_report.md`. `assets/benchmark/source-template.md` is the template for the `SOURCE.md` wayfinding file.
- **The packet has no packet-local `graph-metadata.json` or bound `/create:` slash command.** The single advisor identity lives at the `sk-doc` hub root.
- **The shared create-quality-control backbone is loaded from `../shared/`.** It carries validation, frontmatter templates and core standards.

## Upgrade

No migration required.
