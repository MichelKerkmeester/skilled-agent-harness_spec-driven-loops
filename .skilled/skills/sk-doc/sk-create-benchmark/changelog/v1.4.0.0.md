# v1.4.0.0, Conformance Benchmark Authoring

By adding `conformance_benchmark`, `create-benchmark` now authors five benchmark families.

## What's New at a Glance

- **`conformance_benchmark` provides stable input scaffolding.** It supplies inputs for deterministic artifact-conformance checks run later through a deep-alignment peer adapter.
- **The authoring command adds a conformance family branch.** `/create:benchmark --family=conformance_benchmark` fills the family index, benchmark contract, lane config and fixture manifest, validates them and stops before execution.
- **Conformance routing now appears in both routing projections.** The packet README and sk-doc hub include the family and its peer-adapter and deep-alignment trigger vocabulary. `SKILL.md` adds activation triggers, the guarded `FAMILIES` discriminator, a family-table row and a concise package contract for the family.
- **Behavior authoring has one authoritative procedure.** The duplicated behavior template/workflow/naming block moved out of SKILL.md, and the existing behavior authoring guide is now authoritative for that procedure.
- **`SKILL.md` advances below the packaging ceiling.** Its version advanced from `1.3.0.0` to `1.4.0.0` while remaining below the 5,000-word packaging ceiling.
- **The family templates supply stable inputs only.** Adapter implementation, dimensions, severities, discovery, convergence, scoring, reduction, reports and scorecards remain lane-owned and are never invoked by the authoring command.

## Upgrade

No migration required.
