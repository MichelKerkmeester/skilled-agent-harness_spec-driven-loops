# v1.6.3.0, An Example That Cannot Go Stale

The "fits no family" example named a report that sat in another skill, so the sentence aged as soon as that skill reorganized its references. It now describes the shape of the experiment, a one-off image audit kept beside the skill that ran it. The rule it illustrates is unchanged: a one-off stays lane-local, because there is no catch-all family.

The README also says why four paths it names are not files in this packet. A benchmark report, the consuming skill's benchmarks tree, the dated folder a run creates and a hub's benchmark index are all written by a run somewhere else. A reader who went looking in this folder found nothing and no sentence said why.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/012-alignment-remediation` (Level 2)

## What's New at a Glance

- **The one-off example lost its stale anchor.** The sentence names a kind of experiment rather than a report that used to exist elsewhere.
- **The README's output paths carry their reason.** One marker block names each absent path and why a run, not this packet, owns it.
