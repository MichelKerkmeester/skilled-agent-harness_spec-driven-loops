# The Benchmark Vocabulary Follows the Hub

`create-benchmark` no longer advertises `MCP bake-off` in its keyword triggers. The `sk-doc` hub stopped routing that phrase to this mode because its token `off` was pulling unrelated requests, such as `kick off another deep-review wave`, into sk-doc. The mode keeps its other benchmark terms and now routes `behavior_benchmark` too, with a new check holding the line to `hub-router.json`.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/004-single-vocabulary-source` (Level 2)

&nbsp;

## What's New at a Glance

- **`MCP bake-off` leaves the trigger line.** A prompt that only happens to contain `off` no longer scores as a benchmark authoring request.
- **`behavior_benchmark` now routes here.** The hub alias list names the key the trigger line already advertised, so behavior-benchmark requests reach this packet.
- **A new check holds the line to the router.** `.skilled/skills/sk-doc/sk-create-skill/scripts/ci-hub-vocabulary-source.cjs` fails when the keyword line and `hub-router.json` disagree.
