# v1.6.0.0: two benchmark families

`create-benchmark` removes the `model_benchmark` family and the `agent_improvement` guide-only family. They existed only to feed the retired deep-loop `model-benchmark` and `agent-improvement` modes, so they are removed with those modes. The packet routes and documents two families: MCP promotion and behavior.

## What's New at a Glance

- **The `model_benchmark` family is gone.** Its fixture guide, the code-task, pattern/capability and run-profile templates, and the Lane B playbook scenario are deleted. The router carries no `MODEL_BENCHMARK` intent or resource set.
- **The `agent_improvement` family is gone.** Its authoring guide and the Lane A playbook scenario are deleted, along with the guide-only family class in the family registry test.
- **The packet documents two families.** The README capability layer, the playbook and the shared reference map now cover MCP promotion and behavior only.
- **The SKILL and README versions are resynced.** Both frontmatter versions move to `1.6.0.0`, matching this changelog.

## Upgrade

Behavior and MCP-promotion authoring are unchanged. No migration is required.
