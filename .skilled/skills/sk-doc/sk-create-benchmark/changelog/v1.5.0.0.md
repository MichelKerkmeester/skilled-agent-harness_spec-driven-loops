# v1.5.0.0: purpose-first README rewrite

`create-benchmark` ships a README that reads like a person wrote it for a person. It follows the refined standalone skill README template and the mcp-obsidian exemplar.

## What's New at a Glance

- **The README leads with its purpose.** A one-line pitch sits under the title, and OVERVIEW opens with the reader's problem. The pitch, AT A GLANCE table and OVERVIEW name the outcome before any tool. The six-family capability layer replaces the old tabular reference-card middle.
- **The README prose is HVR-clean.** The rewritten body has no em dashes, semicolons or Oxford commas. The old text failed the HVR grep in six places.
- **After the family capability layer, the README runs from quick start to related documents.** Navigation, troubleshooting, FAQ and verification come between them.
- **The README frontmatter version is resynced.** It changes from `1.0.0.0` to `1.5.0.0`, matching the packet changelog sequence for the first time.
- **A changelog entry records the rewrite.** It is at `changelog/v1.5.0.0.md`.
- **The rewrite is limited to documentation.** It touches the README and changelog entry only. The family router behavior and authoring-not-scoring boundary are unchanged. This skill still never runs a benchmark or writes a scorer or rubric.
