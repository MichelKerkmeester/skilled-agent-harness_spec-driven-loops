# v1.5.0.0: purpose-first README rewrite

`create-benchmark` ships a README that reads like a person wrote it for a person. The rewrite follows the refined standalone skill README template and the mcp-obsidian exemplar: a one-line pitch under the title, a problem-first OVERVIEW, a family capability layer, then quick start, navigation, troubleshooting, FAQ, verification and related documents. The frontmatter version field resyncs to the changelog for the first time, moving from 1.0.0.0 to 1.5.0.0.

## What Added

- **Version field resync.** The README frontmatter now reads `1.5.0.0`, matching the packet changelog sequence for the first time.
- **Changelog entry.** This file records the rewrite at `changelog/v1.5.0.0.md`.

## What Changed

- **Purpose-first README.** The title now leads with a one-line pitch, the OVERVIEW opens with the reader's problem and the six-family capability layer replaces the old tabular reference-card middle. The pitch, the AT A GLANCE table and the OVERVIEW all name the outcome before any tool.
- **HVR-clean prose.** The rewritten body is clean of em dashes and semicolons. No Oxford comma survives either. The old text failed the HVR grep in six places.

## Boundary Held

The rewrite touches the README and the changelog entry only. `SKILL.md`, the family router behavior, the templates under `assets/` and the guides under `references/` stay untouched. The authoring-not-scoring boundary is unchanged. This skill still never runs a benchmark or writes a scorer or rubric.
