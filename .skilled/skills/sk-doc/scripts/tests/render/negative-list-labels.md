## 2. RULE FIELDS

- **Rule:** Resolve the value before it is stored.
- **Why:** A stored value that was never resolved hides a rounding defect.
- **When not to:** Skip the resolution when the caller already resolved it.
- **Pitfall:** Resolving twice rounds twice.
- **Support:** Judgment, no version gate.
