# v1.0.2.0, Every Doc Carries Its Own Version

Skill docs stop sharing the skill's version. `SKILL.md` keeps the skill edition and matches the newest changelog entry, and the two hub comparisons that tied other docs to it are retired.

&nbsp;

## What's New at a Glance

- **Every doc carries its own version.** A README, reference, asset, feature catalog or testing playbook starts its own edition at `1.0.0.0`. The old per-doc number came from a git edit count and a two-pass amend ritual. Both are gone.
- **The bump rule is written down.** A change to a doc's body raises the third segment and resets the fourth, so `1.2.3.4` becomes `1.2.4.0`. A frontmatter-only change raises nothing. A version raised by hand is left alone.
- **The gates raise the version for you.** The pre-commit gate raises each doc whose body changed and re-stages it, with `SPECKIT_SKIP_DOC_VERSION_BUMP=1` as the bypass. On a pull request, a changed doc whose version did not go up fails the check. The failure prints the command that fixes it.
- **The hub README check is retired.** The parent-skill doctor no longer compares a hub `README.md` version with `SKILL.md`. A README follows the bump rule like any other doc.
- **A hub `ROUTER.md` keeps its own edition.** It is not a release copy. No gate compares it with `SKILL.md`. The doctor's version check compares the three hub JSON files with `SKILL.md`.

&nbsp;

## Upgrade

No migration required.
