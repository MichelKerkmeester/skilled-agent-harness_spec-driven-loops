# v1.0.3.0, Packet Changelogs Leave the Frontmatter Guide

Spec folders no longer get changelogs, so the frontmatter templates stop pointing packet entries at the spec-kit nested changelog templates. The README also named the description budget file by a path that only resolved from the hub folder. Only these two docs changed.

> Spec folder: `specs/system-speckit/054-weak-model-spec-authoring/027-alignment-preexisting-gaps` (Level 2)

&nbsp;

## What's New at a Glance

- **Changelog frontmatter has one home.** `assets/frontmatter-templates.md` sends skill and release entries to the Frontmatter Contract in `sk-create-changelog`, says packet changelogs are deprecated and says an existing one keeps the block the nested generator renders.
- **The budget file path resolves.** The README FAQ names `../shared/assets/skill-contract.json`, the path from this folder, instead of a path that only worked from the sk-doc hub.

&nbsp;

## Upgrade

Nothing to do. This is a documentation-only fix. The deprecation itself is recorded in `system-spec-kit` v2.12.13.0.
