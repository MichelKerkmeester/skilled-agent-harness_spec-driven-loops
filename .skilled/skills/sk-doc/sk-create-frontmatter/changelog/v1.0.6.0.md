# v1.0.6.0, Long Prose Lines Are Short Sentences

Every prose line in the packet `SKILL.md` that ran past 400 characters is now a few short sentences, or a short bullet list where the line carried several rules or steps. The instruction comes before the background it needs, and instructions address you.

The facts did not move. Every inline code span, path, link target, number and command still appears, and the keyword trigger terms still advertise what they did. The 28-term trigger line is the one line that had to wrap, so it now reads as two `Keyword triggers:` lines with the same terms in the same order. No route changed and no behavior changed.
