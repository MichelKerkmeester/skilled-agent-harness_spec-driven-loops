# v1.0.0.0, Frontmatter Gets an Owning Mode

The contract gets an owner.

- `create-frontmatter` gives the YAML frontmatter contract an owning mode.
- It connects the contract through both routing stages.

Frontmatter packets share one specification.

- Six sibling packets emit frontmatter.
- Every one of their templates defers to the same specification.

&nbsp;

## Why This Release

The hub's shared tier let any mode read the specification. But it left none accountable for it.

- Many producers read the contract and no producer owns it.
- Whoever passes edits it.
- It drifts from the validators enforcing it.
- This is the third correction of the hub's ownership pattern.
- It is the largest.

## Frontmatter Contract

Both complete references move into `create-frontmatter`.

#### Two Complete References <a id="c-two-complete-references"></a>

- `assets/frontmatter-templates.md` carries the eleven-section field reference.
- It carries the per-class templates, description budget and common fixes.
- `references/frontmatter-versioning.md` carries the 4-part `X.Y.Z.W` standard.
- It covers scope and format.
- It covers changelog-anchored derivation.
- It covers the numstat gate and the insertion rule.
- Neither document splits.
- Because no section of either has a second constituency.

&nbsp;

## Routing

The advisor and the hub router select different targets.

#### Two Stages Select Different Targets <a id="c-two-stages-select-different-targets"></a>

- For a frontmatter request, the advisor selects the hub.
- It does so at confidence 0.95.
- The hub router then selects this mode.
- It selects from a lone target.

#### Registration Is Only the Start <a id="c-registration-is-only-the-start"></a>

- A registry entry alone is not a route.
- The mode carries its registry entry and hub vocabulary.
- It carries router intents and a resource map.
- It carries leaf-manifest entries.

#### Qualified Keywords Protect Routes <a id="c-qualified-keywords-protect-routes"></a>

- `agent-creation` already owns `agent frontmatter`.
- A bare `frontmatter` token would have tied with it.
- It would have bundled that mode's exclusive route.
- All seventeen candidate keywords were checked for substring collisions.
- Every existing keyword in both routing surfaces was compared.
- This happened before they were added.

## Operator Guidance

The playbook sets out what the scenarios cover. It shows where they stop.

#### Scenario Coverage and Limits <a id="c-scenario-coverage-and-limits"></a>

- The scenarios cover field-and-class resolution.
- They cover the description budget and version derivation.
- This playbook is like every other `sk-doc` mode packet.
- It is not visible to the benchmark scenario loader.
- The loader recognises a scenario only by a routing-gold key.
- The operator contract excludes that key.

&nbsp;

## Shared Rules and History

The rules move while enforcement stays in the shared tier.

#### Enforcement Stays Shared <a id="c-enforcement-stays-shared"></a>

- `frontmatter-version.mjs`, its corpus-gate wrapper and `quick_validate.py` stay in `shared/scripts/`.
- A post-edit hook sits outside this hub.
- It resolves one of them by literal path.
- It does so on every qualifying edit.
- Enforcement serves many consumers in the shared tier.
- The rules belong to this mode.

#### No Alias Bridges the Mismatch <a id="c-no-alias-bridges-the-mismatch"></a>

- The hub's alias table maps leaf ids to disk paths.
- It does so when the two disagree.
- Adding an alias here would have preserved the mismatch.
- This packet exists to remove that mismatch.

#### Historical Wording Stays Accurate <a id="c-historical-wording-stays-accurate"></a>

- The old location survives only where it stays true.
- The released changelog entry records where the file sat.
- It sat there at `v1.8.0.0`.
- The entry is history and keeps its wording.
- Three dated benchmark report bundles keep their wording.
- They do so for the same reason.

#### The Changelog Link Finds Its Reference <a id="c-the-changelog-link-finds-its-reference"></a>

- The changelog template pointed at a same-directory copy.
- It was a copy of the field reference.
- That copy has never existed there.
- Repointing it changed link failures across the hub.
- They went from 113 to 112.
