# v1.0.5.0, The Routing Summary Is Short Prose

The SMART ROUTING section now opens with a short prose summary. It says what selects this packet and what it loads first. It also says where the machine router lives. The resource domains, the loading levels and the discovery pseudocode moved unchanged into a final MACHINE ROUTER section. No routing decision changed.

&nbsp;

## What's New at a Glance

- **The summary fits the canon.** Eight lines of plain prose name the mode signal. They name the first resources and the section that holds the router.
- **The router blocks are untouched.** Every machine line still appears once, in the final MACHINE ROUTER section, so no route changed.
