# v1.4.1.0, One Model Arm for the Criteria Lint

The Deem arm and its docs are removed from `score-goal-lint.cjs`, and cli-jev is the only classifier the scorer calls. The `--jev` arm keeps its two questions per labeled criterion, its three reruns each and its `--out <dir>` requirement.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/046-deem-deprecation/004-references-sweep-and-verification` (Level 2)

## What's New at a Glance

- **One model arm remains.** `--jev` still prints a per-rule column and a keep-or-kill verdict and writes `calls.jsonl` and `report.json` under `--out`.
- **The default run is untouched.** Without the switch the scorer prints the same lines as before and writes nothing.
- **The packet docs match the code.** The README and the goal-criteria lint page describe the Jev-only arm.

## Upgrade

No migration required.
