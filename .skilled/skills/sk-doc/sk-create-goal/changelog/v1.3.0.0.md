Rules 4 and 5 of this mode ask for completion criteria. Each criterion must stand alone. A reader must check it without opening another file. Until now nothing checked them. So a criterion that points at "the report" could reach the objective. It could leave completion open. The same holds for "every row in the spec". This release adds an advisory lint that flags those lines.

## What's New at a Glance

- **An advisory lint for criteria.** `lint-goal-criteria.cjs` reads every active goal. It can also read one packet. It flags two kinds of line. The first is a reference such as "the report" that the line itself never names. The second is wording such as "as described in". That wording needs another document to check. It makes no model call. It always exits 0.
- **Fixture goals stay out of the count.** Goals under a `scratch` folder are fixtures. They are not authored criteria. So the lint skips them. It prints how many it skipped. Archived goals stay out as before.
- **The checker is unchanged.** `check-goal.cjs` keeps its five checks. It keeps its output and its exit codes. The lint is a separate script. It blocks nothing.

## Upgrade

No migration required. Run `node .skilled/skills/sk-doc/sk-create-goal/scripts/lint-goal-criteria.cjs <packet>`. That shows the flagged lines for one goal.
