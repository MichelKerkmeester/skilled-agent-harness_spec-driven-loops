# v1.4.6.0, Machine Routing Moves to ROUTER.md

The machine router now lives in sibling `ROUTER.md`. `SKILL.md` keeps a short SMART ROUTING section that ends with one link to that file. The parsed router remains identical to the previous edition.

&nbsp;

## What's New at a Glance

- **Context comes before the machine map.** `ROUTER.md` starts with a short overview and intent model, then groups the intent map, resource map, default resource, loading levels and routing pseudocode under `## 3. MACHINE ROUTER`.
- **Related guidance follows the new location.** Testing playbooks and feature catalog entries now point to `ROUTER.md`. References that pointed into `SKILL.md` now point to `ROUTER.md`.
- **The router description names what the file holds.** It now describes the intent model, the default resource and the no-match checklist instead of an intent map and a resource map the file never declares.
