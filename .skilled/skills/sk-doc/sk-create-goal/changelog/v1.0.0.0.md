Writing a spec packet's goal now has one home. `create-goal`, a new mode in the `sk-doc` hub, writes a packet's `goal.md` from the packet's own documents, so every session bound to that packet works toward the same objective, decisions and completion criteria. It never sets, binds or resends a session's own objective.

> Spec folder: `specs/sk-doc/060-create-goal-mode` (Level 2)

## What's New at a Glance

- **One command writes every kind of goal.** `/create:goal <packet> [operation]` covers six operations: top-level, phase-parent, child, retrofit, phase-add and amend. When the operation is missing, it picks one from the packet's own files instead of guessing from the conversation.
- **A goal holds what later work must honor.** Each goal states one objective sentence, the frozen decisions and three to seven completion criteria, all drawn from the packet's documents.
- **A phase parent binds every child.** Its binding table has one row per direct phase child, and the mode checks the phase map, the child folders and the rows against each other before it writes anything.
- **Goals stay inside a 4,000-character budget.** `goal.cjs packet` measures a top-level or parent goal. When one runs over, a fixed cut order trims repeated child detail and decision prose first and never drops a criterion.
- **A checker catches the common mistakes.** `check-goal.cjs` is read-only and flags a missing binding row, a leftover template placeholder, a criteria count outside three to seven and a parent over budget.
- **Rendering stays with system-spec-kit.** Every goal starts from system-spec-kit's own goal template, so the mode keeps no copy of it that could drift.
- **Session goals stay with the goal hooks.** A request to set a session objective is sent to the host's goal command, and no goal file is written. After a parent goal changes, the mode prints the text to resend and leaves the resend to you.
- **A playbook covers the mode.** Eight scenarios run against throwaway packets, including the two cases where the right outcome is a refusal or a failed check.

## Upgrade

No migration required. This is the first release of the mode.
