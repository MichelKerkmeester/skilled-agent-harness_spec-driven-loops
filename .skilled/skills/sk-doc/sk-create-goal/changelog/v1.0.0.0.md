Initial release of `create-goal`, a workflow mode in the `sk-doc` parent hub. It authors a spec packet's `goal.md` from that packet's own documents: one objective sentence, the frozen decisions later work must honor and three to seven completion criteria. A phase parent also gets the binding table that names every direct phase child. It runs through `/create:goal <packet path> [top-level|phase-parent|child|retrofit|phase-add|amend] [:auto|:confirm]` and it never sets, binds or resends a session objective.

> Spec folder: `specs/sk-doc/060-create-goal-mode` (Level 2, nine phases)

---

## What Changed

#### New Features

- **Six operations that name the job instead of guessing it.** Top-level, phase-parent, child, retrofit, phase-add and amend. The command takes the operation as a token and, when it is missing, resolves it from the packet's own files rather than from conversation history.
- **Rendering owned by system-spec-kit end to end.** Every goal comes from `goal.md.tmpl` through `create.sh --with-goal` for a new child packet or `inline-gate-renderer.sh --level <L>` for an existing one. A phase parent renders at the `phase` level.
- **A binding table that cannot drift from disk.** One row per direct phase-child directory, each targeting that child's `goal.md`. The workflow compares the map's folder names, the directories and the binding rows as three sets before anything is written.
- **A budget contract with a cut order.** A top-level goal or phase parent stays at or under 4,000 durable characters, measured by `goal.cjs packet`. When a parent runs over, the cut order removes repeated child detail and compresses decision prose first and never drops a criterion.
- **`check-goal.cjs`, a read-only conformance checker.** Four checks: a missing binding row, a leftover template placeholder, a criteria count outside three to seven and a parent durable slice over budget. Its own suite runs 8 tests with `node --test`.
- **A manual testing playbook with eight scenarios in one category.** Goal authoring against disposable scratch packets, including the two boundary cases where the passing outcome is a refusal or a failed goal check. The package validator reports `PASS` with 8 scenarios and 0 violations.

#### Notes

- The mode authors packet files. Session objective state stays with the goal hooks and the host's native goal command, and a session-goal request is redirected there with no goal file written.
- The durable slice covers the text between the frontmatter and the log, so edits to either do not lower the count. Phase children are exempt from the cap.
- After a parent goal changes, the mode prints the file-derived `chat_slice` and stops. The operator holds that copy and decides what to resend.
- The authoring standards, the exemplars, the six workflows and the budget rules live in `references/` and `assets/`, so the workflow contract in `SKILL.md` stays short.
