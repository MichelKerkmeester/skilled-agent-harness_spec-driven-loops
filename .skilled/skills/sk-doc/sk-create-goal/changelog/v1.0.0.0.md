Writing a spec packet's goal now has one home. `create-goal` is a new mode in the `sk-doc` hub. It writes a packet's `goal.md` from the packet's own documents. So every session bound to that packet works toward the same objective, decisions and completion criteria. It never sets, binds or resends a session's own objective.

## What's New at a Glance

- **One command writes every kind of goal.** `/create:goal <packet> [operation]` covers six operations. They are top-level, phase-parent, child, retrofit, phase-add and amend. When the operation is missing, it picks one from the packet's own files. It does not guess from the conversation.
- **A goal holds what later work must honor.** Each goal states one objective sentence. It states the frozen decisions and three to seven completion criteria. All of these come from the packet's documents.
- **A phase parent binds every child.** Its binding table has one row per direct phase child. The mode checks the phase map, the child folders and the rows against each other. It does this before it writes anything.
- **Goals stay inside a 4,000-character budget.** `goal.cjs packet` measures a top-level or parent goal. When one runs over, a fixed cut order trims repeated child detail and decision prose first. It never drops a criterion.
- **A checker catches the common mistakes.** `check-goal.cjs` is read-only. It flags a missing binding row. It flags a leftover template placeholder. It flags a criteria count outside three to seven. It flags a parent over budget.
- **Rendering stays with system-spec-kit.** Every goal starts from system-spec-kit's own goal template. So the mode keeps no copy of it that could drift.
- **Session goals stay with the goal hooks.** A request to set a session objective goes to the host's goal command. No goal file is written. After a parent goal changes, the mode prints the text to resend. It leaves the resend to you.
- **A playbook covers the mode.** Eight scenarios run against throwaway packets. Two of them are cases where the right outcome is a refusal or a failed check.

## Upgrade

No migration required. This is the first release of the mode.
