# v2.9.8.0, Test Results Allowed in One Changelog Section

The validator flagged every test count in a changelog. Release notes now carry a section that shows what was checked, and that section needs those numbers.

> Spec folder: `specs/sk-doc/authoring-modes-and-playbooks/006-release-writing-defaults`

&nbsp;

## What's New at a Glance

- **Test results pass in one place.** A count inside `## How It Was Checked` is no longer flagged.
- **Everywhere else is unchanged.** A test count in any other section still raises `changelog_test_count`.
- **The hint says where to put it.** The message now points at that section.

&nbsp;

## Upgrade

No migration required.
