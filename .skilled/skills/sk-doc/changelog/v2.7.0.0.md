# v2.7.0.0, One REFERENCES Name and Wider Inventory Checks

The skill contract and the sk-create-skill templates now agree on how a SKILL.md closes, and a flat code folder can list its files the way most READMEs already do.

> Spec folder: `specs/sk-doc/066-skill-readability-refinement/014-sk-create-skill-refinements/003-templates-and-fleet` (Level 3)

&nbsp;

## What's New at a Glance

- **One closing section name.** `shared/assets/skill-contract.json` lists `REFERENCES AND RELATED RESOURCES` as the last entry of the skill section order, matching the SKILL.md template and scaffold, and its recommended list drops RELATED RESOURCES, which that section carries.
- **Wider inventory headings.** `validate_document.py` accepts a WHAT IS IN THE PACKAGE or STRUCTURE heading as a flat folder's file inventory, and counts a file named in a fenced structure tree inside that section. Both names count only as a Markdown heading, and a list that leaves a file out still fails `code_folder_flat_inventory`.
- **Size table drift test.** `scripts/tests/test_skill_size_table.py` fails when the SKILL.md template's Size Limits table and the `package_skill.py` constants disagree.
- **A heading for an orienting table.** The human-voice reference index opens its OVERVIEW with `### When to Use` above its load table.
