# v2.3.6.0, Typo-Proof Script Options

Many sk-doc scripts read only the options they expected. They ignored the rest. A misspelled `--check` or `--format` ran the default mode. It reported success. Each script now names the unknown option. It exits with its usage error code. That code is 64 for `frontmatter-version.mjs` and 2 for the rest.

&nbsp;

## What's New at a Glance

- **CI checks refuse unknown options.** These checks sit under `sk-create-skill`. They cover the leaf manifest, derived freshness, root metadata and router vocabulary. Their generators exit 2 on an unknown option. So do the playbook and routing scenario validators.
- **`--format` takes only `text` or `json`.** The freshness and root metadata checks reject any other value. They do not fall back to text.
- **Repo rule, goal and doc model scripts follow suit.** These scripts fail on an unknown option: `build-rule-cards.cjs`, `check-repo-rules.cjs`, `lint-goal-criteria.cjs` and `validate-doc-model-refs.js`. `lint-goal-criteria.cjs` exits 2 when its input cannot be parsed.

&nbsp;

## Upgrade

Replace any misspelled option with the one the script's usage line lists.
