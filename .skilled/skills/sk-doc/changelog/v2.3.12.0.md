# v2.3.12.0, The Citation Scan No Longer Hangs on a Stuck Git Monitor

The citation scan in `shared/scripts/cite-drift-scan.mjs` could sit at 0% CPU with no error. That happened in a checkout whose git file-system monitor had stopped answering. That is because each git call it made waited on that monitor.

Every git call the scan makes now turns the monitor off. That costs a plain index scan. It returns the same output.

&nbsp;

## What's New at a Glance

- **The tools that reuse the scan stop hanging with it.** The cite-drift advisory in `validate_document.py` reads through the scan's git helpers. The spec validator's source-tag rule does too.

&nbsp;

## Upgrade

No migration required.
