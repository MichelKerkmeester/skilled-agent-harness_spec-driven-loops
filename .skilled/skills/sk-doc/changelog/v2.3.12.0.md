# v2.3.12.0, The Citation Scan No Longer Hangs on a Stuck Git Monitor

The citation scan in `shared/scripts/cite-drift-scan.mjs` could sit at 0% CPU with no error in a checkout whose git file-system monitor had stopped answering, because each git call it made waited on that monitor. Every git call the scan makes now turns the monitor off, which costs a plain index scan and returns the same output.

> Spec folder: `specs/hooks/023-session-relaunch-loop/035-known-gap-fixes` (Level 2)

&nbsp;

## What's New at a Glance

- **The tools that reuse the scan stop hanging with it.** The cite-drift advisory in `validate_document.py` and the spec validator's source-tag rule both read through the scan's git helpers.
