# v2.4.3.0, The Compiled-Routing Directive Returns to the Machine Router

The skill-package validator reads that directive only from the `## MACHINE ROUTER` section, so the hub failed its compiled routing readiness check from then on. The directive is back in section 5, word for word, as in `sk-design` and `sk-code`.
