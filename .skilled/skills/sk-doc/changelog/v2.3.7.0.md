# v2.3.7.0, A Version on Every Skill Doc

The 4-part `version` field had been limited to `SKILL.md`. So a reference, asset, catalog or playbook doc could change with no record of it. Each skill doc now carries its own edition. `SKILL.md` keeps the skill edition. Every other doc tracks its own changes.

&nbsp;

## What's New at a Glance

- Every skill doc is versioned.
  - `frontmatter-version.mjs verify` requires a valid 4-part `version` on every hand-authored doc with frontmatter.
  - Changelogs, tests, fixtures, runtime and benchmark output stay out of scope.
  - So do the spec-doc examples.
- A body change raises the version at commit.
  - The new `bump` mode compares each staged doc's body with the base.
  - Frontmatter is excluded.
  - The `bump` mode raises the third segment, so `1.2.3.4` becomes `1.2.4.0`.
  - A frontmatter-only change raises nothing.
  - A hand raise is kept.
- The pre-commit hook runs it.
  - The `doc-version-bump` gate raises and re-stages each changed doc.
  - `SPECKIT_SKIP_DOC_VERSION_BUMP=1` skips it.
  - A pull request runs `bump --check` against its base.
- Odd cases fail loudly.
  - `bump` refuses an empty `version:` key.
  - `bump` refuses a staged path with a line break.
  - `bump` refuses a doc that is a symlink in the working tree.
  - `bump` names each one.
  - A leading-zero version such as `01.2.0.0` reads as `1.2.0.0`.
- The packager and the post-edit check agree.
  - `package_skill.py --check --strict` and the post-edit quality router apply the same scope rule as the engine.
- The removed version lines are back.
  - Every child doc that lost its `version` line has it again.
  - The docs that never had one start at `1.0.0.0`.
- Templates seed `version: 1.0.0.0`.
  - The README, code README and architecture templates write the field.
  - So does the playbook index generator.
  - `frontmatter-versioning.md` states the contract and the bump rule.

&nbsp;

## Upgrade

Add `version: 1.0.0.0` to a new skill doc. Or let `frontmatter-version.mjs apply` add it. Commit as usual. The hook raises the version of any doc whose body changed.
