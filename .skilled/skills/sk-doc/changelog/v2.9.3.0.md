# v2.9.3.0, Section citations checked in every doc type, render features catalogued

A playbook, catalog, command or agent doc can cite a section number its target does not have. That is now reported. The feature catalog lists the render checks and the render ledger.

&nbsp;

## What's New at a Glance

- Citations are checked everywhere.
  - `validate_document.py` runs `render_section_reference` for every document type.
  - The shape checks still run only where `renderChecks` is set.
  - Changelog and spec set the new `sectionReferenceChecks` rule to false.
  - So their citations stay as written.
  - No current doc carries a broken citation.
  - Two new tests cover the playbook and changelog cases.
- The feature catalog gains entries.
  - The feature catalog gains Render Checks and Render Ledger And Rewrite Guard under Document Validation.
  - Each has its own feature file.
  - Its description and intro name them.
