# v2.9.3.0, Section citations checked in every doc type, render features catalogued

A playbook, catalog, command or agent doc that cites a section number its target does not have is now reported, and the feature catalog lists the render checks and the render ledger.

> Spec folder: `specs/sk-doc/066-skill-readability-refinement/014-sk-create-skill-refinements/004-alignment-fixes` (Level 2)

&nbsp;

## What's New at a Glance

- **Citations checked everywhere.** `validate_document.py` runs `render_section_reference` for every document type, while the shape checks still run only where `renderChecks` is set. Changelog and spec set the new `sectionReferenceChecks` rule to false, so their citations stay as written. No current doc carries a broken citation, and two new tests cover the playbook and changelog cases.
- **Catalog entries.** The feature catalog gains Render Checks and Render Ledger And Rewrite Guard under Document Validation, each with its own feature file, and its description and intro name them.
