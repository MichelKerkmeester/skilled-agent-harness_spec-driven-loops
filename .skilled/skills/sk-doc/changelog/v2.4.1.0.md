# v2.4.1.0, Hub Docs Read in Order and Style References Skip the Validator

The hub's `SKILL.md`, `ROUTER.md`, `README.md` and `shared/` docs were read file by file for readability, layout and structure. Text moved and split, and every claim was kept or corrected to match the code. One validator rule changed: `validate_document.py` now skips a mode's Style Reference file. No command or template contract changed.

> Spec folder: `specs/sk-doc/066-skill-readability-refinement/008-sk-doc` (Level 1)

&nbsp;

## What's New at a Glance

- **Style References skip the document validator.** `validate_document.py` now excludes a file named `DESIGN.md` that sits directly in an `assets/style-reference/<name>/` folder, because its scripts find each section by its literal heading. A sibling README, other files in that folder and style-library bundles are still validated, and two new tests pin both sides.
- **Shared references open with their purpose.** The core standards, validation, evergreen packet-id, filesystem naming, quick reference and shared scripts docs each gained a Purpose and a When to Use, and the quick reference's closing footer moved into its Related Resources.
- **The README reads one surface per line.** What It Does lists the hub's seven surfaces as bullets, When to Use moved up into the overview, and the script roles are a list.
- **The router leads with its compiled-routing directive.** `ROUTER.md` gained a short intro and moved the compiled-routing note to the top of its routing section.
- **Facts match the code.** The core standards list every `--type` value the validator accepts, including `skill_router` and `benchmark_companion`, the shared README counts five leaf aliases, four of them `shared/` paths, and the shared scripts index lists `cite-drift-labels.jsonl`, `cite-drift-gate.mjs` and `git_env.py`.
