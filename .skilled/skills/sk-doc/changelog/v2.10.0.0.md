# v2.10.0.0, The Create Skill Command Is Now sk-skill

The create skill command has a new name on every runtime.

- `/create:skill` is now `/create:sk-skill` with no alias.
- The typed, plain and slash variants all reach it.
- The old file name caused the bug.

An old file name made Claude Code hide most commands.

- A command file named `skill.md` makes Claude Code read its folder as one skill.
- Every other command in that folder disappears from the listing.

Claude Code now lists every tracked command.

- Claude Code lists all 44 commands.
- No command file has the old name.
- The skill advisor reads a typed `/create:skill` as `/create:sk-skill`.

> [!IMPORTANT]
> 1 change can break an existing setup. Read this before you update.
>
> 1. No command file answers to `/create:skill` now. [Breaking: The Old Name Is Gone](#c-breaking-the-old-name-is-gone)

&nbsp;

## Why This Release

Claude Code showed only part of the command list before this release.

- Claude Code showed 32 of the 44 tracked commands.
- The create folder held a file named `skill.md` beside twelve other commands.
- Claude read the folder as one skill named `create`, so those twelve names never appeared.
- The cause is an open bug in Claude Code (`anthropics/claude-code#85786`).
- It holds for any capitalisation of `skill.md` and on any filesystem.
- The only documented way out is another file name.
- So no command file may carry that name now.
- An alias would keep a `skill.md` file alive, and the bug with it.
- The old name is retired with no alias, on every runtime.

## Create Skill Command

The command file and its assets carry the new name. Only the name a reader types changed.

#### Type the New Name <a id="c-type-the-new-name"></a>

- `/create:sk-skill` replaces `/create:skill` in the command file and its three assets.
- It replaces the name in the two command catalogs and the sk-doc hub metadata.
- The command behaves as before.
- Only the name a reader types changed.
- The mode id, the packet folder and the `create-skill-*` asset file names keep their old spelling.

#### Breaking: The Old Name Is Gone <a id="c-breaking-the-old-name-is-gone"></a>

> [!WARNING]
> No command file answers to `/create:skill` now. Anything that names it needs the new spelling.

- The skill advisor reads a typed `/create:skill` as `/create:sk-skill`.
- Any script, saved prompt or doc that still names it needs the new spelling.
- There is no alias to fall back on.

&nbsp;

## Claude Code Reach

The regenerated Claude tree carries the new file name and no `skill.md` file.

#### All 44 Commands Appear <a id="c-all-44-commands-appear"></a>

- The regenerated Claude tree holds `create/sk-skill.md` and twelve siblings.
- No file under `.claude/commands` is named `skill.md` in any capitalisation.
- The runtime mirror check reads `visibility claude 44/44`, up from `32/44`.

#### The Check Has No Exception <a id="c-the-check-has-no-exception"></a>

- The mirror check now fails any command folder that holds a `skill.md` file, whatever its capitalisation.
- Its old allowlist is gone.
- That stops a future command from bringing the collapsed folder back.
