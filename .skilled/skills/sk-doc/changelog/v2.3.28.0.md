# v2.3.28.0, Long Prose Lines Are Short Sentences

The four prose lines in the hub `SKILL.md` ran past 400 characters. They are now short sentences and short lists. The opening states the hub's shape in four lines. The shared backbone lists its three held kinds as bullets. The surface-router paragraph lists what `ROUTER.md` defines. The keyed-discovery note reads as four sentences.

The facts did not move. Every path, command, mode name and count still appears. The routing prose keeps the order a reader needs. The fenced machine blocks and the compiled-routing directive are byte for byte what they were. So no route changed and no behavior changed.

The hub also carries a Terms glossary. It is the first subsection of How It Works. Each routing term it uses is defined once there.

## What's New at a Glance

- **The long lines are split.** The hub `SKILL.md` carries no prose line over 400 characters.
- **The backbone and the leaf model read as lists.** The three `shared/` holdings are bullets now. So are the three things `ROUTER.md` defines. Both keep their original order.
- **The machine blocks are untouched.** Every fenced block still appears. So do the `INTENT_SIGNALS` and `RESOURCE_MAP` names and the compiled-routing directive. The fenced and quoted lines compare identical to the previous release.
