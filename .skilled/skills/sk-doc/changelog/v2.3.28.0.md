# v2.3.28.0, Long Prose Lines Are Short Sentences

The four prose lines in the hub `SKILL.md` that ran past 400 characters are now short sentences and short lists. The opening states the hub's shape in four lines, the shared backbone lists its three held kinds as bullets, the surface-router paragraph lists what `ROUTER.md` defines, and the keyed-discovery note reads as four sentences.

The facts did not move. Every path, command, mode name and count still appears, and the routing prose keeps the order a reader needs. The fenced machine blocks and the compiled-routing directive are byte for byte what they were, so no route changed and no behavior changed.

The hub also carries a Terms glossary as the first subsection of How It Works, where each routing term it uses is defined once.
