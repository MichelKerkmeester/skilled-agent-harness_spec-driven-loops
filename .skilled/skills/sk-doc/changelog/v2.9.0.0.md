# v2.9.0.0, README Render Checks On

`validate_document.py` now runs the render checks on README files, and every README in the fleet already passes them.

> Spec folder: `specs/sk-doc/066-skill-readability-refinement/014-sk-create-skill-refinements/003-templates-and-fleet` (Level 3)

&nbsp;

## What's New at a Glance

- **README render checks.** `template-rules.json` sets `renderChecks` for the readme type, and the README verdict baseline was rewritten for the 977 READMEs it covers.
- **llms.txt templates.** `shared/assets/llmstxt-templates.md` names its second OVERVIEW subsection `### Usage`, the name an asset uses.
- **Test fixtures.** The routing-shape, packaging and create-skill fixtures open with an intro and an OVERVIEW and number their sections, so they test the rule they name instead of tripping a render check.
