# v2.3.9.0, Root Playbook Paths Checked

The playbook validator's backticked path report read scenario files only, so a root `manual-testing-playbook.md` could keep citing a path its scenario had already corrected, and nothing reported it. The root file is now checked the same way, and the warning stays report-only.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/022-doc-version-and-playbook-paths/003-playbook-root-and-stale-refs` (Level 2)

&nbsp;

## What's New at a Glance

- **Root files are checked.** A backticked path in a package's root playbook file that resolves from no base prints `BACKTICK_PATH_UNRESOLVED` under the file name `manual-testing-playbook.md`.
- **A regression case covers it.** The validator test appends a missing path to a fixture root and expects exactly that one warning.
