# v2.9.14.0, Release Notes Have No Line Ceiling

A release note can now run as long as its release needs. The sk-create-changelog mode carries the change.

&nbsp;

## What's New at a Glance

- The mode it routes to changed.
  - sk-create-changelog v1.5.1.0 shipped.
  - Routing is unchanged.
- The shape check has no line ceiling.
  - An expanded entry past 280 lines now passes.
- `/create:changelog` stops naming a line target.
  - Both workflow files drop the 240-line draft target.

&nbsp;

## Upgrade

No migration required.
