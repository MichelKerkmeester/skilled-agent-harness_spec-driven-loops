# v2.3.14.0, The Validator Flags Internal Ids in Changelogs

The changelog mode tells authors to leave out internal labels and test counts, but nothing checked it. `validate_document.py` now warns on a changelog entry whose prose carries an id such as a requirement or scenario label, or a count of tests or cases. The spec-folder line and the frontmatter are exempt.

> Spec folder: `specs/sk-code/015-quality-agnostic-gate` (Level 2)

&nbsp;

## What's New at a Glance

- **The omission rule has a check.** A changelog that names an internal id or a test count gets a warning with a hint on how to rephrase it.
- **Released entries keep passing.** The check warns and never blocks, because older entries already carry some of these.

&nbsp;

## Upgrade

No migration required. A warning on an existing entry needs no action unless you edit that entry.
