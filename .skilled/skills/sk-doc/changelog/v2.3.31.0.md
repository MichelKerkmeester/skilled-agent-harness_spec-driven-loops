# v2.3.31.0, Skill Routers Move to Their Own File

The sk-create-skill packet now moves to v1.8.0.0. Skills and mode packets created from this release on keep their machine router in a sibling `ROUTER.md`, so `SKILL.md` stays short. The packets that predate this release keep passing on the known-debt ledger until each one migrates.

&nbsp;

## What's New at a Glance

- **New packets start with a router file.** The scaffold writes `ROUTER.md` next to `SKILL.md`, so a new mode packet begins with the file the check requires.
- **Existing packets keep their recorded debt.** Each packet that predates this release stays on the known-debt ledger until it moves, so the hub's routing checks keep passing.
- **Both routing shape checks now agree.** `package_skill.py --strict` and doctor check 12b apply the same link and router rules, so a tree passes or fails both.

&nbsp;

## Upgrade

No action is needed in this hub. A skill outside this repository follows the upgrade steps in sk-create-skill v1.8.0.0.
