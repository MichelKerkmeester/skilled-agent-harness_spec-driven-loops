# v2.2.5.0, ARCHITECTURE Docs Have a Template

A request to write a skill's ARCHITECTURE.md now routes to a template instead of starting from nothing. The README-authoring mode lists the new template, and the hub's surface router names it as a leaf.

> Spec folder: `specs/system-deep-loop/036-deep-loop-innovation/029-align-runtime-code-with-sk-code-opencode` (Level 2)

## What's New at a Glance

- **The README mode now offers an ARCHITECTURE template.** It sits beside the README templates in `sk-create-readme`.
- **Compiled routing serves the new leaf.** The sk-doc activation manifest was re-minted, so routing stays on the compiled path.
