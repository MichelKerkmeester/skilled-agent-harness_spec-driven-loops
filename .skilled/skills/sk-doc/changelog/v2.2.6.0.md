# v2.2.6.0, One Classifier Behind the Scans

The Deem arm and its docs are removed from the shared citation drift scan, and the hub pages that describe the sk-doc scans now name cli-jev alone. The zero-call default and the `--jev` arm keep their behavior.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/046-deem-deprecation/004-references-sweep-and-verification` (Level 2)

## What's New at a Glance

- **The citation drift scan keeps one arm.** `shared/scripts/cite-drift-scan.mjs` still resolves every citation with zero model calls by default, and `--jev` still needs `--out <dir>` to record each call.
- **The hub docs describe what exists now.** The feature catalog and the SD-021 playbook name the Jev-only scan, so no page offers a switch that is gone.
- **cli-jev is the only classifier named.** Every sk-doc page that described two backends now describes one.

No migration required.
