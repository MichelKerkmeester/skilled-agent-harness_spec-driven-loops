# v2.3.19.0, The README Says Where the Node Scripts Find Their Dependency

The README described what each script does and never said where the Node scripts find the one package they load. A reader who ran one and hit a missing dependency had to go hunting for it. The README now names the `package.json` at the skill root and explains why it sits there.

> Spec folder: `specs/sk-doc/070-repo-doc-debt/005-reference-and-coverage-fixes` (Level 2)

## What's New at a Glance

- **A reader finds the dependency in one line.** The README names `@spec-kit/shared` and the `package.json` at the skill root that supplies it.
- **The placement is explained too.** That file sits at the skill root so both `scripts/` and `shared/scripts/` can resolve it.
