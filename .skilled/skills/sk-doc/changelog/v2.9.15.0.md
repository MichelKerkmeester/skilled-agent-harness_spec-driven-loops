# v2.9.15.0, Release Notes Have No Item Ceilings

A release note can now hold as many sections and glance bullets as its release needs. The sk-create-changelog mode carries the change.

> Spec folder: `specs/sk-doc/document-standards/003-changelog-system/006-remove-release-size-limit`

&nbsp;

## What's New at a Glance

- **The mode it routes to changed.** sk-create-changelog v1.5.2.0 shipped. Routing is unchanged.
- **The shape check counts no items.** An entry past 32 H4 items or 14 glance bullets now passes.

No migration required.
