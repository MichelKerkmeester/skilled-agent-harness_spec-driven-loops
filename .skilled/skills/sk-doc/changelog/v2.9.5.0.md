# v2.9.5.0, The Changelog Mode Checks Its Own Shape

`/create:changelog` now keeps a release with many changes short. The `sk-create-changelog` mode bounds the expanded format and runs a shape gate on every draft, and its own v1.4.0.0 entry has the detail.

> Spec folder: `specs/sk-doc/055-changelog-system/005-concise-release-format`

&nbsp;

## What's New at a Glance

- **Long changelog entries stay short.** An expanded entry stays within 240 lines and 26 items, and a draft past either ceiling is not written.
- **Two release entries model the format.** v4.0.1.0 sets the length and shape of a release with many changes, and v4.0.0.0 sets the voice of a major one.
