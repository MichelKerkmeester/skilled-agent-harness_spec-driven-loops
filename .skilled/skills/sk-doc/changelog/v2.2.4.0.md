# v2.2.4.0, A Citation Drift Scan for Skill Docs

The skill docs can now be checked for citation drift. A new scan counts the `<path>.<ext>:<line>` citations in the prose of every tracked skill doc, reports the ones that no longer resolve and measures offline whether a Jev or Deem call flags a drifted citation better than two fixed comparators. The scan makes no model call and writes no file unless a run asks for one.

## What's New at a Glance

- **The dead citations print with no call.** The scan reads every tracked skill doc at HEAD, counts the `<path>.<ext>:<line>` citations in its prose with fenced code skipped and resolves each against the tracked files. A target that is missing on disk or cited past its last line prints as `cite dead: <doc>:<line> -> <target>:<line>`, and the per-skill and total counts print before anything else.
- **The default run makes zero model calls.** `node .skilled/skills/sk-doc/shared/scripts/cite-drift-scan.mjs` with no switch prints the citation counts and the dead citations and writes no file and reaches no backend. Logging stubs for `cli-deem` and `jev` placed first on `PATH` were never called.
- **Each backend runs behind its own switch.** `--jev` and `--deem` each need `--out <dir>` so every call is recorded, and with both switches the Jev gate and arm run first. A backend check runs before its arm and calls no model, and a failed check prints its skip line while every earlier line stays byte-identical.
- **The measurement sits behind a label gate.** `--draw --seed <n>` writes 40 rows to the labels file, 20 live citations for the operator to label and 20 constructed drifts, and no model writes a label. Fewer than 40 labeled rows prints `stop: fewer than 40 labeled rows` and stops there.

## Upgrade

No migration required. The scan is a new script and the default run changes no citation, no validator and no cited file.
