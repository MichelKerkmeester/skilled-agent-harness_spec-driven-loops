# v2.3.15.0, The Omission Check Skips Quoted Code

The changelog omission check warns when an entry's prose carries an internal id or a test count. It read quoted text the same as prose, so a changelog that quoted a literal, such as a comment that a fix stopped accepting, drew a warning for words it only repeated. The check now skips inline code spans. The same words in plain prose still warn.

> Spec folder: `specs/sk-code/015-quality-agnostic-gate/010-alignment-audit` (Level 2)

&nbsp;

## What's New at a Glance

- **Quoted literals stop warning.** Text inside inline code no longer counts toward the internal-id or test-count check.
- **Plain prose still warns.** The same id or count written outside a code span gets the warning as before.
