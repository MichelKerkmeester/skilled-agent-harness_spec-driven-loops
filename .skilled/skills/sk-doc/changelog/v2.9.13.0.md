# v2.9.13.0, Standalone Skills May Own Slash Commands

A standalone skill can now record the slash commands it owns. The sk-create-skill mode carries the rule.

> Spec folder: `specs/system-skill-advisor/routing-and-scoring/008-command-surfacing-build/002-command-inventory-and-risk-metadata`

&nbsp;

## What's New at a Glance

- **The mode it routes to changed.** sk-create-skill v1.16.0.0 shipped. Routing is unchanged.
- **`/create:changelog` now asks first.** Its `--release` flag pushes a tag and publishes a GitHub release, so its command metadata lists `outside-repo` as an ask-first reason.
