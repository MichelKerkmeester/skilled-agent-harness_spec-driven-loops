# v2.9.9.0, An Autonomous Release Stops on an Uncommitted Changelog

The autonomous changelog release could tag a release whose changelog was still uncommitted, and it skipped the checks the confirm path runs.

&nbsp;

## What's New at a Glance

- **No tag without the changelog.** The autonomous `/create:changelog` release stops when the changelog file is not committed.
- **Every release step has its rollback.** Both changelog workflows print the command that undoes a step next to the step.
- **The checks run in both modes.** The voice gate, `validate_document.py` and `extract_structure.py` run in the autonomous and the confirm workflow.
- **The goal checker asks for a target.** `check-goal.cjs` with no packet and no `--all` prints its usage and exits 2. It used to scan every packet.
- **Create docs match the folder.** The create README no longer lists two design commands, the workflow file pattern is spelled with hyphens, the presentation names the `Updated` release state and three commands say where their checkpoint questions are defined.

&nbsp;

## Upgrade

No migration required. A script that called `check-goal.cjs` with no argument to scan everything now passes `--all`.
