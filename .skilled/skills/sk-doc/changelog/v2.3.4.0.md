# v2.3.4.0, Pull requests check citations and catalogs

v2.3.4.0 adds a citation gate that blocks only the citations a pull request breaks, and runs the feature-catalog validator in CI.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/020-open-ends-research/006-ci-truth-checks` (Level 1)

&nbsp;

## What's New at a Glance

- **New broken citations block a pull request.** `.skilled/skills/sk-doc/shared/scripts/cite-drift-gate.mjs` resolves every `path:line` citation in the skill docs at the head and at the merge base, with the scanner's own resolver. It exits 1 only for an unresolved or past-end citation the base does not have, and prints the older ones as one count.
- **The catalog validator runs in CI.** The sk-doc script-tests workflow runs `validate_catalog_package.py` over every package, plus its fixture test, and a failure blocks.

&nbsp;

## Upgrade

No migration required. To see what a branch would add, run `node .skilled/skills/sk-doc/shared/scripts/cite-drift-gate.mjs --base <ref>` from the repository root.
