# v1.6.0.0, Benchmark Folder Creation Joins sk-doc

This release gives sk-doc a sixth mode. The mode creates skill-local benchmark folders. So curated bake-off results from a spec packet can reach the consuming skill. The release also consolidates benchmark-format guidance into `references/benchmark_creation.md`. It adds a `SOURCE.md` scaffold. The scaffold points readers from benchmark folders to evidence in the originating packet.

The mode is the scope of Packet 006. Packet 006 is a Level 2 packet. Packet 012 shipped in the same session. It added literal-naming guidance to the system-spec-kit plan and complete commands. That work touches system-spec-kit only. It is orthogonal to this release. Even so, both packets landed in the same commit window.

## Why This Release

Benchmark-format mechanics had been spread across three locations in system-spec-kit and sk-doc.

## What's New at a Glance

- **Benchmark folder creation is sk-doc's sixth mode.** It gives curated bake-off results from a spec packet a skill-local destination.
- **Benchmark-format guidance moves to `references/benchmark_creation.md`.** The new reference follows sk-doc's `*_creation.md` pattern.
- **A `SOURCE.md` scaffold joins the benchmark templates.** It directs readers to the relevant files in the originating spec packet.
- **BENCHMARK routing now serves benchmark-folder work.** Matching requests reach the benchmark guide and templates.

---

## Benchmark Folder Creation

#### Results Reach Skill Folders

The new mode scaffolds `mcp-server/benchmarks/benchmark-<YYYY-MM-DD>/` folders in the consuming skill. `benchmark_report_template.md` in `assets/benchmark/` provides the ten-section curated narrative. That narrative holds headline metrics and recommendations. `SKILL.md` and `README.md` update to reflect the six-mode surface.

&nbsp;

#### Evidence Has a Wayfinding Page

`assets/benchmark/source-template.md` is a 135 LOC fillable scaffold. It provides the complete `SOURCE.md` structure. The `source_template.md` scaffold supports wayfinding from a skill-local benchmark folder to its authoritative spec packet. It covers frontmatter, overview and packet location. It also covers a when-to-read-what table mapping questions to files. It covers an evidence file map, follow-on packets and update rules. It is not a duplicate of the benchmark report. It points operator questions to the right files in the originating packet. Those questions include which candidate won. They also include whether the production default is safe and which fixture was used.

---

## Benchmark Format

#### One Guide Holds the Mechanics

The benchmark-format trio collapsed into the canonical `references/benchmark_creation.md`. The 414 LOC guide has ten numbered sections. They run from OVERVIEW through RELATED RESOURCES. It combines `references/benchmarks/FORMAT.md` (384 LOC), `references/benchmarks_format.md` (205 LOC) and the asset template.

It generalizes the Section 5 example and Q7. That removes stack-specific references like `Ollama`, `cat-24/409` and `sentence-transformers`. The resulting guidance is portable across MCP skills. The mid-flight redesign was an operator decision. It came after the first author pass.

&nbsp;

#### Old Paths Have No Fallback

The old `references/benchmarks/FORMAT.md` and `references/benchmarks_format.md` paths no longer exist. Both sibling skill `FORMAT.md` symlinks were dropped. **Breaking:** There is no symlink fallback. So direct reads of `mcp-server/benchmarks/FORMAT.md` return a file-not-found error.

---

## BENCHMARK Routing

#### The Intent Finds Its Resources

**BENCHMARK routing adds three request phrases.** The BENCHMARK intent gains `benchmark creation`, `benchmark folder` and `source.md template`. It drops the deprecated `benchmarks format` phrase. Its `RESOURCE_MAP` entry changes from two resources to `references/benchmark_creation.md`, `assets/benchmark/benchmark-report-template.md` and `assets/benchmark/source-template.md`. Section 2's Resource Domains list adds `assets/benchmark/` as a tracked domain. That domain holds benchmark folder templates.
