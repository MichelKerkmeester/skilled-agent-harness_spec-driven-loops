# v2.3.16.0, Released Entries Use Words Instead of Ids

A released entry used to name a scenario or a decision by an internal id. So a reader without the packet met a label they could not follow. The released entries in the hub now name the scenario and the decision in words. The benchmark, changelog, diff and goal modes now do the same. No released fact changed.

&nbsp;

## What's New at a Glance

- **A released entry says which scenario and which decision it means.** The hub's entries point at the scenario and the decision in words. So do those of the benchmark, changelog, diff and goal modes. The story reads without a lookup.
- **No released fact changed.** Only the naming moved. Every entry still says what shipped and why it mattered.
- **Two READMEs follow the template.** The sk-create-goal playbook run report starts with an overview section. The sk-create-with-human-voice scripts README numbers its sections from 1.

No migration required.
