# v2.3.16.0, Released Entries Use Words Instead of Ids

A released entry used to name a scenario or a decision by an internal id, so a reader without the packet met a label they could not follow. The released entries in the hub and in the benchmark, changelog, diff and goal modes now name the scenario and the decision in words. No released fact changed.

> Spec folder: `specs/sk-doc/070-repo-doc-debt` (Level 2)

&nbsp;

## What's New at a Glance

- **A released entry says which scenario and which decision it means.** The hub's entries and those of the benchmark, changelog, diff and goal modes point at the scenario and the decision in words, so the story reads without a lookup.
- **No released fact changed.** Only the naming moved. Every entry still says what shipped and why it mattered.
- **Two READMEs follow the template.** The sk-create-goal playbook run report starts with an overview section, and the sk-create-with-human-voice scripts README numbers its sections from 1.
