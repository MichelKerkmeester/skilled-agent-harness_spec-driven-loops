# v2.10.1.0, The Front Door Takes the Task on Stdin

The hub put the task in `--prompt "<task>"`. That is a double-quoted shell argument. A quote, `$( )` or backtick in the task reached the shell. Every hub now reads the task from stdin.

&nbsp;

## What's New at a Glance

- `SKILL.md`, `ROUTER.md` and the feature catalog now use `--prompt-stdin <<'TASK'`.
- The task goes on the next lines. A `TASK` line closes it.
- The quoted heredoc keeps the shell from expanding the task.
- The `sk-create-skill` scaffold (1.16.1.0) writes the stdin form too. A new hub starts safe.
- The activation manifest was re-minted.

&nbsp;

## How It Was Checked

A task holding `$(touch …)` and backticks created no file. The bin tests pass 197 of 197. The sk-doc tests pass 462. This hub's routing canary exits 0.

&nbsp;

## Upgrade

No migration required. Replace any copied `--prompt "<task>"` line with the stdin form.
