# v2.9.4.0, A Badge No Longer Reads as a Bare URL

A README badge is an image inside a link. The bare-URL check stripped one link per match, so the outer link of a badge was left behind with its URL and warned. The image is now masked first, so the outer link matches as a whole.

&nbsp;

## What's New at a Glance

- **Badges pass.** `[![Stars](image-url)](link-url)` raises no warning, and a URL in running text or a blockquote still does
- **A regression test pins it.** `scripts/tests/test_bare_url_badge.py` holds six cases, and the README verdict baseline is rebuilt for the three READMEs whose badge warnings went away

&nbsp;

No migration required.
