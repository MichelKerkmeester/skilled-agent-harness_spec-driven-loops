# sk-doc changelog: v2.1.0.0

The hub gains a mode that runs the Human Voice Rules instead of restating them, taking `sk-doc` to fourteen modes across thirteen packets.

## Added

- `sk-create-with-human-voice/` — applies the Human Voice Rules to a draft, or scores prose against them, at `/create:with-human-voice`. Its scope gate runs first and decides what the standard governs: quotations, error strings, commands, code, generated files, released changelog entries and byte-pinned fixtures are never in scope, so a voice edit to any of them is a defect rather than an improvement.
- `references/scope-and-exemptions.md` — the scope decision, and the three classes the standard never covered: text you are carrying, text something else pins, and text that is *about* the banned words. The last is exempt because the standard lists every blocked term and so scores catastrophically against itself.
- `scripts/hvr_scan.py` — reads the punctuation bans, hard blocker words, phrase blockers and soft deductions out of `hvr-rules.md` on every run, so the packet holds no copy of any term list. It keys on section titles, which survives renumbering and fails closed with an error on a rename rather than reporting a clean scan.
- Precedence arithmetic that stops double-charging: one occurrence costs one penalty, the longest matching term claims the span, a word listed as both an extended blocker and context-dependent is charged once as the blocker, and a transition costs a point only from its third use onward.
- `hub-router.json` — the `sk-create-with-human-voice` signal at weight 4, the `create-with-human-voice-aliases` vocabulary class, and the tie-break slot.

## Changed

- `SKILL.md`, `README.md`, `description.json` (v2.0.1.0 → v2.1.0.0): the hub now declares fourteen modes across thirteen packets, the mode table carries the new row, and the routing prose names the human-voice pass among the stage-two leaf intents.
- `mode-registry.json`, `graph-metadata.json`, `leaf-manifest.json`: the new mode entry, its intent signals and domains, and the regenerated leaf set.

## Notes

The release was recorded in the packet's own changelog when it shipped, and the hub entry that a `SKILL.md` version bump owes was not authored with it. This entry closes that gap so the hub's newest changelog entry names the version its routing artifacts carry.

## Not Changed

- Routing behavior outside the new mode: the stage-one default, the bundle rules, and every pre-existing mode keep their contracts.
- Historical changelog entries.
