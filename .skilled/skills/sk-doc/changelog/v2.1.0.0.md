`sk-doc` gains the `sk-create-with-human-voice/` mode, which applies the Human Voice Rules to a draft or scores prose against them. The mode is available at `/create:with-human-voice`.

## Why This Release

The release was recorded in the packet's own changelog when it shipped, but the hub entry owed by the `SKILL.md` version bump was not authored with it. This entry closes that gap so the hub's newest changelog entry names the version its routing artifacts carry.

## What's New at a Glance

- **The scope gate runs first.** It decides which text the standard governs.
- **`scripts/hvr_scan.py` reads the standard at runtime.** It does not carry a copied term list.
- **Penalty precedence settles overlapping matches.** Each occurrence is charged once.
- **`hub-router.json` adds a signal for the new mode.** The signal has weight 4.
- **The hub adds the new mode to its routing records.** Its `SKILL.md` version advances to v2.1.0.0.
- **Routing behavior outside the new mode is unchanged.** The stage-one default and bundle rules keep their contracts.

## Human Voice Rules

#### The Scope Gate Protects Exempt Text

The standard does not govern quotations, error strings, commands, code, generated files, released changelog entries or byte-pinned fixtures. A voice edit to any of them is a defect rather than an improvement.

`references/scope-and-exemptions.md` records the scope decision and three classes the standard never covered: text you are carrying, text something else pins and text that is about the banned words. The last class is exempt because the standard lists every blocked term and so scores catastrophically against itself.

&nbsp;

#### The Scanner Reads One Standard

On every run, `scripts/hvr_scan.py` parses punctuation bans, hard blocker words, phrase blockers and soft deductions from `hvr-rules.md`. The packet holds no copy of any term list.

The scanner keys on section titles, which survive renumbering. A renamed section produces a fail-closed error instead of a clean scan.

&nbsp;

#### Penalty Rules Prevent Double Charges

One occurrence costs one penalty. The longest matching term claims the span. A term listed as both an extended blocker and context-dependent is charged once as the blocker.

A transition costs a point only from its third use onward.

## sk-doc Routing

#### The Hub Documents Its Mode

`SKILL.md` moves from v2.0.1.0 to v2.1.0.0. The same version change applies to `README.md` and `description.json`. The hub now declares fourteen modes across thirteen packets. Its mode table gains a row for `sk-create-with-human-voice`. The routing prose names the human-voice pass among the stage-two leaf intents.

&nbsp;

#### Routing Gains Mode Signals

`hub-router.json` adds a `sk-create-with-human-voice` signal at weight 4. It adds the `create-with-human-voice-aliases` vocabulary class and a tie-break slot. `mode-registry.json`, `graph-metadata.json` and `leaf-manifest.json` carry the new mode entry. They include its intent signals and domains. They also carry the regenerated leaf set.

&nbsp;

#### Existing Routing Keeps Its Contract

Every pre-existing mode keeps its contract. Historical changelog entries are unchanged.
