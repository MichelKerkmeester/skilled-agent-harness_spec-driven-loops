# v2.4.0.0, The Validator Reads How a Reference Renders

The document validator now reads the body it used to skip. Ten checks report the shapes that render wrong or mislead a reader, and each one lands as a warning, so no existing document starts failing.

> Spec folder: `specs/sk-code/018-frontend-upstream-proposals/010-reference-readability-research` (Level 2)

&nbsp;

## Why This Release

A reference could pass every check while rendering a bold label as a paragraph, a divider as a setext heading or a URL as plain text, because no check read a paragraph. The same blind spot accepted a compound overview heading, an overview that opened with a rule id and a related section that was not last. The validator now names those shapes, and strict packaging can promote them where a skill publishes guidance.

&nbsp;

## What's New at a Glance

- **Ten render checks.** They cover a joined bold label, a setext underline, a bare URL, a compound overview heading, an overview without orientation, a repeated sentence, a repeated label, an H2 number with a letter suffix, a related section that is not last and an intro that restates its Purpose.
- **They read the body, not the fence.** Every check skips frontmatter and fenced code, so an example inside a fence is never a finding.
- **Each finding is a warning.** A document that already renders this way stays valid, and only a strict packaging run turns the finding into an error.
- **Four document types opt in.** Reference, asset, skill and router documents declare the checks, and a router keeps MACHINE ROUTER as its permitted last section.
- **A related section is now last.** Reference, asset and skill documents declare the pattern, and a trailing MACHINE ROUTER is the one exception.
- **Both directions have fixtures.** A known-bad control raises the checks and look-alike documents that must stay clean do not.

&nbsp;

## Upgrade

No action is needed for validation. A strict packaging run now reports these findings as errors unless the skill records them in the render known-debt ledger.
