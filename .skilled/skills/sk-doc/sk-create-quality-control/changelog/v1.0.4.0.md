# v1.0.4.0, The Skill Stops Describing a Command That Does Not Exist

v1.0.3.0 took the retired `/doc:quality` command out of the README, but `SKILL.md` and the workflows reference still described running it. They now speak of a doc-quality request or a report-only audit, which is how the packet is reached through sk-doc hub routing.

> Spec folder: `specs/system-speckit/054-weak-model-spec-authoring/028-changelog-release-extension` (Level 2)

&nbsp;

## What's New at a Glance

- **SKILL.md describes the audit, not a command.** The activation trigger, the report-only mode, the always-rule and the escalation rule name a doc-quality request or a report-only audit.
- **The workflows reference matches.** The report-only row of the mode table is the default for doc-quality requests.
- **Old wording still routes here.** `/doc:quality` stays in the trigger list and the router keywords, and the note that calls it historical vocabulary is unchanged.

Nothing to do. This is a documentation-only fix.
