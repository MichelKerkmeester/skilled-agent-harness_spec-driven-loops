The initial release of `create-quality-control` adds a workflow. It audits and optimizes existing Markdown documents in the `sk-doc` parent hub's ten-packet workflow-only architecture.

## What's New at a Glance

- **The audit scores document quality.** It extracts structure and metrics. Then it computes a Document Quality Index (DQI) score and quality band. It applies Human Voice Rules (HVR) for natural writing.
- **Choose a workflow mode.** Select a target Markdown document. Then choose report-only audit, structure validation, content optimization or batch snapshot. The workflow interprets blocking failures, warnings and recommendations. Then it reports findings.
- **Optimization targets the same document.** The workflow makes targeted improvements only when explicitly requested. It improves the same document's structure, clarity and AI-friendliness. `SKILL.md` has a separate content-optimization path. That path covers question-answering transformation patterns when edits are in scope. `references/optimization.md` gives full transformation-pattern examples and AI-friendly documentation heuristics for that path.
- **`references/workflows.md` gives extended mode examples.** It also covers phase interactions, batch patterns and troubleshooting. Those apply to the core workflow.
- **The packet uses shared scripts and standards.** It has no packet-local `assets/` or `scripts/` directories. It runs the shared `../shared/scripts/extract_structure.py`, `validate_document.py` and `quick_validate.py`. It reads the shared `../shared/references/` standards rather than duplicating them locally. They cover core standards, validation bands and HVR rules.
