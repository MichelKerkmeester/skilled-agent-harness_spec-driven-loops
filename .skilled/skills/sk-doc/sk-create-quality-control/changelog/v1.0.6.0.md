# v1.0.6.0, A Short Routing Summary With the Router at the End

The SMART ROUTING section used to carry the family boundary and the router pseudocode. It is now a short prose summary that says what selects this packet, what it loads first and where the router lives. The detail moved unchanged into a final MACHINE ROUTER section, so nothing routes differently.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/006-sk-doc-hub` (Level 2)

&nbsp;

## What's New at a Glance

- **The routing section reads in five lines.** It names the `sk-create-quality-control` mode signal, the reference set's route map and the section that holds the router.
- **The family boundary and the router block moved, word for word.** They now sit under the final `MACHINE ROUTER` section.
- **No routing change.** The same requests reach the packet, and the same resources load.

&nbsp;

## Upgrade

No action is needed. The packet is reached and read exactly as it was before.
