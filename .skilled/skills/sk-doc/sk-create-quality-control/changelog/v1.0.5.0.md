# v1.0.5.0, One Vocabulary for Doc Quality Routing

The Keyword triggers line on this packet now advertises only the terms the sk-doc hub routes here, so it no longer competes for voice work another packet owns. A new check keeps that line and hub-router.json from drifting apart.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/004-single-vocabulary-source` (Level 2)

&nbsp;

## What's New at a Glance

- **`HVR` and `human voice` are gone from the triggers line.** The sk-doc hub routes both to `sk-create-with-human-voice`, where a voice request belongs.
- **`/doc:quality` now routes here.** The hub sends that command to this packet, and the triggers line keeps it.
- **A new check catches the line drifting from the router.** `.skilled/skills/sk-doc/sk-create-skill/scripts/ci-hub-vocabulary-source.cjs` compares every packet's `Keyword triggers:` line with the vocabulary hub-router.json authors for it and fails on a term the hub does not route.

&nbsp;

## Upgrade

No action is needed. The packet is reached the same way it was before.
