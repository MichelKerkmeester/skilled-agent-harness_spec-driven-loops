# v1.1.8.0, The README Names the Store the Script Creates

The script keeps baselines under `.create-diff/` in the working directory, the default that `references/cli-reference.md` documents. The README called that folder `.create-diff/`, so a reader who snapshotted a file went looking for a folder no run ever creates. The sentence now names the folder the run writes, and a marker entry records that a checkout holds one only after a snapshot.

The bundle paragraph also dropped "multiple" from "a bundle of multiple files". The sentence still says one call can carry several files, and it no longer reads as a count of files in a folder.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/012-alignment-remediation` (Level 2)

## What's New at a Glance

- **The store path matches the script.** The README, SKILL.md, the workflow reference, the feature catalog and the playbook all name `.create-diff/`, the folder the script writes, so a reader who snapshots a file knows where to look afterwards.
- **The bundle sentence stays prose.** It describes an ability rather than an inventory, so nothing reads it as a file count.
