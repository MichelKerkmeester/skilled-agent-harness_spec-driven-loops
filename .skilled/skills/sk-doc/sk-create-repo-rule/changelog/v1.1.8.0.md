# v1.1.8.0, The Scripts Follow a Ten-Rule Set

Three reply rules were retired, so the rule set holds ten files. The packet's scripts and scenarios still named the retired files. They now follow the set as it is. The retire path has now been performed once, and the wiring reference says so.

> Spec folder: `specs/agents-md/repo-rule-operations/005-reply-rule-pruning`

&nbsp;

## What's New at a Glance

- **The scripts read one reply rule.** `measure-rule-compliance.py` and `rule-experiment.py` counted a reply as covered after two files were read. They now ask for `communication.md` alone.
- **The punctuation checks follow their rule.** The em dash and semicolon checks were keyed to `communication-prose.md`. That file is gone, so both now report under `communication.md`.
- **Both experiment inputs build again.** The card arm edited router rows for retired rules and stopped. The table-wording arm looked for wording the live rule had already replaced. Each build now prints four `built <arm>` lines.
- **The build scenario states real output.** Its expected lines came from an older corpus. All four arms now pass 11 of 11 checks. The ambiguous edit uses `§1` and aborts with `found 2`.
- **The card scenarios count ten cards.** The byte check names the two reply cards that remain. `AGENTS.md` plus those cards is 31,394 bytes, under the 32,768 budget.
- **One guard row covers two misreadings.** The creation standards listed `communication-decisions.md` as its own row. Its misreading now sits on the `communication.md` row.
