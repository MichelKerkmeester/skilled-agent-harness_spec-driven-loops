# v1.1.1.0, A Title Alone Is Not Delivery

`measure-rule-compliance.py` used to credit a rule as delivered. The title line alone was enough. So a mention or a cut-off copy passed. A rule kept that status for the rest of the session. That happened after a compaction dropped its text. Delivery now needs the rule's title, as the rule or its card. It also needs the first line of its rule section. A compaction ends delivery until the rule arrives again in the new window.

> Spec folder: `specs/agents/018-communication-rules-consolidation` (Level 1)

&nbsp;

## What's New at a Glance

- **Delivery needs the rule text.** Injected text credits a rule only when its title appears. The first line of its rule section must appear too. A title line alone is a mention or a cut-off copy.
- **The card form counts.** A rule that arrives as its generated card is credited like the rule itself. That card is titled `# Card: <rule title>`.
- **A compaction ends delivery.** The next window starts undelivered. So a reply counts as coming after its rule in one case only. The rule must have arrived again in that window.

&nbsp;

## Upgrade

No migration required. A rule whose title and rule line both arrive is credited as before.
