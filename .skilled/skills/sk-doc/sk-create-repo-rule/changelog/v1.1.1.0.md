# v1.1.1.0, A Title Alone Is Not Delivery

`measure-rule-compliance.py` used to credit a rule as delivered on its title line alone, so a mention or a cut-off copy passed, and a rule kept that status for the rest of the session after a compaction dropped its text. Delivery now needs the rule's title, as the rule or its card, and the first line of its rule section. A compaction ends delivery until the rule arrives again in the new window.

> Spec folder: `specs/agents/018-communication-rules-consolidation` (Level 1)

&nbsp;

## What's New at a Glance

- **Delivery needs the rule text.** Injected text credits a rule only when its title and the first line of its rule section both appear. A title line on its own is a mention or a cut-off copy.
- **The card form counts.** A rule that arrives as its generated card, titled `# Card: <rule title>`, is credited like the rule itself.
- **A compaction ends delivery.** The next window starts undelivered, so a reply counts as coming after its rule only when the rule arrived again in that window.

&nbsp;

## Upgrade

No migration required. A rule whose title and rule line both arrive is credited as before.
