# v1.0.9.0, The Catalog Path Says Where It Lands

The overview promises a `feature-catalog/feature-catalog.md` package, a path relative to the skill being inventoried. This packet ships the templates that build one rather than a catalog of its own, so the path resolved nowhere and a reader could not tell a stale README from a missing folder.

A marker entry now records that a run writes the package into the target skill. The promise itself is unchanged.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/012-alignment-remediation` (Level 2)

&nbsp;

## What's New at a Glance

- **The produced path carries its owner.** The README says the catalog lands in the skill a run inventories rather than in this packet.
- **The document map names the router.** The related-documents table gains a `ROUTER.md` row and `SKILL.md` no longer claims routing.
