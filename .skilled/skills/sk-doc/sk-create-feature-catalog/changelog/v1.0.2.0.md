# v1.0.2.0, Template-Name Anchor Retired

v1.0.2.0 stops new feature catalog files from carrying a template-name comment under their heading. Every catalog file used to open with `<!-- sk-doc-template: skill_asset_feature_catalog -->`, a label no validator, router or script ever read, and no other authoring mode stamped one.

> Spec folder: `specs/sk-doc/066-feature-catalog-template-anchor-deprecation` (Level 2)

&nbsp;

## What's New at a Glance

- **The root and per-feature scaffolds no longer include the template-name comment.** A new catalog file goes straight from its H1 to `## 1. OVERVIEW`.
- **The per-feature checklist no longer asks for the comment.** A catalog file without it is complete, and the worked examples show the heading without it.

&nbsp;

## Upgrade

No migration required. Existing catalogs validate the same with or without the comment.
