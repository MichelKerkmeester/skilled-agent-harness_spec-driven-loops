# v1.0.1.2, README Rewrite on the Refined Template

v1.0.1.2 rewrites the create-feature-catalog README on the refined skill README template. It brings the README version into line with the changelog. It also explains the catalog package and its authoring order. It explains the boundary between the root catalog and feature files.

## What's New at a Glance

- **The README now follows the refined skill README template.** It is purpose-first. It opens with a one-line pitch and a problem-first OVERVIEW. Its catalog-package capability table covers the root catalog, per-feature files and category folders. The README then documents the authoring order and root-versus-leaf boundary. It closes with troubleshooting, FAQ, verification and related documents.
- **The README frontmatter now says version 1.0.1.2.** It moved from 1.0.0.0 to re-align the README with the changelog top.
- **The README voice now follows the Human Voice Rules.** Three Oxford-comma constructions and two forced three-item enumerations were rewritten. That leaves the body free of em dashes, semicolons and Oxford commas.
- **The skill contract and reference surface did not change.** `/create:feature-catalog` and `feature-catalog/feature-catalog.md` are preserved. The per-feature file shape with source and validation anchors is preserved. The kebab-case category folder rule is preserved. The playbook boundary and the validation workflow are preserved. All six relative links resolve to the same targets as before. They are `SKILL.md`, `references/README.md`, `references/examples.md`, `references/common-pitfalls.md`, `assets/feature-catalog-template.md` and `assets/feature-catalog-snippet-template.md`.
- **The specifically named content did not move.** No `SKILL.md` content, template asset, reference file, vault file or runtime data moved.
