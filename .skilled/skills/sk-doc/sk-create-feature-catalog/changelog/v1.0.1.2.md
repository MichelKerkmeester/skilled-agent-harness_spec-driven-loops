# v1.0.1.2, README Rewrite on the Refined Template

v1.0.1.2 rewrites the create-feature-catalog README on the refined skill README template. It brings the README version into line with the changelog while explaining the catalog package, its authoring order and the boundary between the root catalog and feature files.

## What's New at a Glance

- **The README now follows the refined skill README template.** It is purpose-first, opening with a one-line pitch and a problem-first OVERVIEW, and its catalog-package capability table covers the root catalog, per-feature files and category folders. The README then documents the authoring order and root-versus-leaf boundary before closing with troubleshooting, FAQ, verification and related documents.
- **The README frontmatter now says version 1.0.1.2.** It moved from 1.0.0.0 to re-align the README with the changelog top.
- **The README voice now follows the Human Voice Rules.** Three Oxford-comma constructions and two forced three-item enumerations were rewritten, leaving the body free of em dashes, semicolons and Oxford commas.
- **The skill contract and reference surface did not change.** `/create:feature-catalog`, `feature-catalog/feature-catalog.md`, the per-feature file shape with source and validation anchors, the kebab-case category folder rule, the playbook boundary and the validation workflow are preserved. All six relative links (`SKILL.md`, `references/README.md`, `references/examples.md`, `references/common-pitfalls.md`, `assets/feature-catalog-template.md`, `assets/feature-catalog-snippet-template.md`) resolve to the same targets as before.
- **The specifically named content did not move.** No `SKILL.md` content, template asset, reference file, vault file or runtime data moved.
