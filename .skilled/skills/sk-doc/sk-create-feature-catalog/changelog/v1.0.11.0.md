# v1.0.11.0, Authoring Order Numbered and Package Checks Named

The packet's `SKILL.md`, `ROUTER.md`, `README.md` and references were read file by file for readability, layout and structure. Text moved and split, every claim was kept and a few statements were corrected to match the tree. No command, contract or template behavior changed.

> Spec folder: `specs/sk-doc/066-skill-readability-refinement/008-sk-doc` (Level 1)

&nbsp;

## What's New at a Glance

- **The authoring order is numbered.** The README now walks five steps, from reading the target system to validating the root and every leaf, and its When to Use moved up beside What It Does.
- **The package validator is named.** The README's checks table gained a row for `scripts/validate_catalog_package.py`, which reports root and leaf bijection, source-file existence and the validation taxonomy, so the manual review row now covers links and source anchors only.
- **The router lists its resources.** `ROUTER.md` names the scaffolds under `assets/` and the overflow references under `references/` as two bullets, and states that `references/README.md` is the default and fallback.
- **The fallback is spelled out.** `SKILL.md` now says to report `UNKNOWN_FALLBACK` with the router's disambiguation checklist when nothing matches.
- **References point where they resolve.** The route map now names `system-skill-advisor/feature-catalog/` as the walked-through catalog, and the pitfalls and examples references point at `../assets/` for the templates.
