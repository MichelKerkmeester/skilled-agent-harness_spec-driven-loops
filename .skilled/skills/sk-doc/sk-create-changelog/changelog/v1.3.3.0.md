# v1.3.3.0, Sections Breathe and Items Run Together

`/create:changelog` now spaces an entry by its sections rather than its items. An `&nbsp;` line, a forced blank line, sits before every top-level section, and the items inside a section follow each other directly, so the page reads as a few clear blocks instead of a column of rules.

> Spec folder: `specs/sk-doc/065-changelog-section-spacing` (Level 1)

&nbsp;

## What's New at a Glance

- **A forced blank line before every section.** It separates the opening from Why This Release, Why This Release from What's New at a Glance and every later section from the one before.
- **Items inside a section run together.** The `&nbsp;` lines between items are gone, and so are the `---` rules between sections.
- **Release notes keep the same spacing.** The GitHub release body carries the entry's layout and ends with an `&nbsp;` line before the full-changelog pointer.
- **The published v4 releases match.** The four v4 Skilled entries and the three published v4 release notes now use the new spacing.

&nbsp;

## Upgrade

No migration required. Older entries in the `v1+`, `v2+` and `v3+` folders keep their spacing.
