# v1.3.3.0, Sections Breathe and Items Run Together

`/create:changelog` now spaces an entry by its sections, not its items. A forced blank line sits before every top-level section. That line is an `&nbsp;` line. The items inside a section follow each other directly. So the page reads as a few clear blocks, not a column of rules.

&nbsp;

## What's New at a Glance

- **A forced blank line before every section.** It separates the opening from Why This Release. It separates Why This Release from What's New at a Glance. It separates every later section from the one before.
- **Items inside a section run together.** The `&nbsp;` lines between items are gone. The `---` rules between sections are gone too.
- **Release notes keep the same spacing.** The GitHub release body carries the entry's layout. It ends with an `&nbsp;` line before the full-changelog pointer.
- **The published v4 releases match.** The four v4 Skilled entries and the three published v4 release notes now use the new spacing.

&nbsp;

## Upgrade

No migration required. Older entries in the `v1+`, `v2+` and `v3+` folders keep their spacing.
