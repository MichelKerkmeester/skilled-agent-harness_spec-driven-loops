# v1.3.12.0, References Say When to Open Them

The packet's `SKILL.md`, `README.md` and references were read file by file. The reading covered readability, layout and structure. Text moved and split. Every claim was kept. Two statements were corrected to match the code. No command, contract or template behavior changed.

&nbsp;

## What's New at a Glance

- **The validator row says what it checks.** The README now says what `validate_document.py --type changelog` checks. It checks the frontmatter keys, a trigger phrase and the version phrase. Order, tier sections, the spec-folder line and upgrade guidance are checked by hand.
- **Diagrams point to their owner.** The SKILL.md list of out-of-scope artifacts drops the flowchart. It says a flowchart or any other diagram belongs to the `sk-design` hub.
- **Topology rules read one per line.** The topology reference's opening rules are now four bullets. They run from global placement to tie handling.
- **References say when to open them.** The topology, version-bump and worked-examples references each gained a When to Use list.
- **The README opens with what it does.** "What It Does" now comes before "Why This Skill Exists". The document table lists `ROUTER.md`. The section 4 heading dropped its duplicated label.
