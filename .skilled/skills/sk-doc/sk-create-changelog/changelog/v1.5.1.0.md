# v1.5.1.0, Release Notes Have No Line Ceiling

The shape check failed an expanded entry past 280 lines. The v4.0.2.1 entry sat at 278, so any new line meant cutting an old one first. That ceiling is gone. An entry now runs as long as the release needs.

&nbsp;

## What's New at a Glance

- **No `file-total` rule.** `check_changelog_shape.py` no longer counts the lines of an entry.
- **The template drops both file totals.** The 280-line expanded ceiling and the 40-line compact guidance are gone.
- **The other ceilings stay.** An expanded entry still holds at most 32 H4 items and 14 glance bullets.
- **The sentence gates stay.** No sentence past 22 words, and 10 words a sentence at most on average.

&nbsp;

## Upgrade

No migration required.
