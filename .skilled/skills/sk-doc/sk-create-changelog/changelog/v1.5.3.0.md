# v1.5.3.0, The Docs Drop the Removed Nested Generator

The spec-kit nested changelog generator is removed. This mode's docs no longer point to it.

> Spec folder: `specs/system-speckit/spec-folder-tooling/006-remove-nested-changelog`

&nbsp;

## What's New at a Glance

- **The docs say the generator is removed.** SKILL, README, the template and the references no longer say it renders old files.
- **Scenario CHG-012 is gone.** It tested the generator's identity phrase. Its index block and test rows are removed too.
- **A nested request is still refused.** The `packet_local` route still offers a global entry instead.
