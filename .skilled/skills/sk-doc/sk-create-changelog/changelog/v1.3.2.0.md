# v1.3.2.0, Shorter Entries That Say Each Thing Once

`/create:changelog` now writes shorter entries in the same voice. It chooses content by what matters to the reader, and it stops repeating a fact across the opening, the glance list and the detail.

> Spec folder: `specs/sk-doc/057-sk-create-changelog-v4-style` (Level 1)

## What's New at a Glance

- **Content is chosen before it is written.** A change stays only when the reader would notice it or act on it, so test changes, internal IDs and follow-up housekeeping stay in the spec packet.
- **Every section has one job.** The opening names the themes, the glance list gives one payoff per theme, the detail sections explain and the upgrade notes list only actions.
- **The workflow checks for the two usual habits.** Its validation step now looks for task or scenario IDs in the prose and for a sentence restated from another section.
- **The skill's own docs are a quarter shorter.** Each rule lives in one place, and the worked example shows a lean entry beside what it left out.

## Upgrade

No migration required. Existing entries stay as written.
