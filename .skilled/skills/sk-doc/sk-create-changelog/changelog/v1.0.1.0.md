The `create-changelog` `SKILL.md` now aligns its section structure with the shared contract. That contract is used across `sk-doc` workflow packets. The contract can now identify the routing and references sections. It could not resolve them before.

## What's New at a Glance

- **The opening now has separate `WHEN TO USE` and `SMART ROUTING` sections.** The old heading combined `WHEN TO USE + SMART_ROUTING`. It used an underscore. So the contract could not match its standalone routing check. This release keeps every existing activation trigger, exclusion and family-boundary note. It adds an explicit output-mode routing summary. That summary points at the detailed workflow sections.
- **`REFERENCES` now has a top-level section.** The list was nested under rules before. So the contract could not resolve its references check. The promotion leaves all referenced paths unchanged.
- **Second-level headings are renumbered contiguously.** The new sections fit without changing cross-references. That is because the prose contains no section-number citations.

## Upgrade

No migration required. This structural documentation normalization changes no packet workflow behavior. It changes neither the packet workflow's inputs, workflow steps nor its output behavior.
