The `create-changelog` `SKILL.md` now aligns its section structure with the shared contract used across `sk-doc` workflow packets. The contract can identify the routing and references sections it previously could not resolve.

## What's New at a Glance

- **The opening now has separate `WHEN TO USE` and `SMART ROUTING` sections.** The former combined `WHEN TO USE + SMART_ROUTING` heading used an underscore, so the contract could not match its standalone routing check. This release keeps every existing activation trigger, exclusion and family-boundary note and adds an explicit output-mode routing summary that points at the detailed workflow sections.
- **`REFERENCES` now has a top-level section.** Previously, the list was nested under rules, so the contract could not resolve its references check. The promotion leaves all referenced paths unchanged.
- **Second-level headings are renumbered contiguously.** The new sections fit without changing cross-references because the prose contains no section-number citations.

## Upgrade

No migration required. This structural documentation normalization changes neither packet workflow behavior nor its inputs, workflow steps or output behavior.
