# v1.6.0.0, The v4.1.0.0 Layout Is the Default

A new changelog now reads like the v4.1.0.0 release notes. Short bullets carry the detail. One short paragraph opens each section. Long detail folds away until a reader opens it.

&nbsp;

## What's New at a Glance

- The opening is two to four lead sentences, each with short bullets.
- An important box lists every breaking change, linked to its item.
- The glance list is a table of Change, What It Means and Section.
- Each item heading carries an anchor the table links to.
- Warning boxes replace the inline breaking marker.
- Smaller fixes, tests and upgrade groups fold away.
- Each paragraph is one source line.
- A release page then wraps cleanly on a phone.
- The shape check reads the glance table's order.
- A folded spec-folder list still closes the entry.
- HTML tag lines no longer count as sentences.

&nbsp;

## Upgrade

No migration required. Older entries keep their layout.
