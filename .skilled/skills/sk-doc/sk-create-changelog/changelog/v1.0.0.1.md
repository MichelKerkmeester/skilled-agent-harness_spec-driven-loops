This release fixes a structural conformance issue so the create-changelog packet passes the canonical section contract enforced across the `sk-doc` family.

## What's New at a Glance

- **`WHEN TO USE` and `SMART ROUTING` now have separate H2 sections.** The underscore-joined heading kept the automated section check from detecting `SMART ROUTING`. Keyword triggers and family-boundary routing rules now sit under `SMART ROUTING`.
- **`REFERENCES` is now a top-level section.** The reference route-map moved out from under `RULES`, with the same links and guidance.
- **H2 sections are numbered consecutively from one.** Splitting the heading and promoting references shifted the section count.

## Upgrade

No migration required. Section content is unchanged. Only headings and their numbering moved. Workflow behavior does not change.
