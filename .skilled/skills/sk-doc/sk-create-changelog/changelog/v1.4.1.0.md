# v1.4.1.0, Glance Order Checked Without Visible Tags

The shape check could only test glance order when each bullet carried a visible section tag, and the v4.0.1.0 model entry carries none. Each glance bullet now ends with a section comment that a rendered page and the release notes never show, so the model entry reads the same and the order rule runs on it.

> Spec folder: `specs/sk-doc/055-changelog-system/005-concise-release-format`

&nbsp;

## What's New at a Glance

- **Section tags are hidden.** A glance bullet ends with `<!-- section: Topical Domain -->`, and a visible tag still works.
- **The model entry is checked in full.** v4.0.1.0 carries the comments and passes every rule, glance order included.
- **The ceilings cannot drift.** A test fails when the template's ceiling table and the check's numbers disagree.
- **A playbook scenario covers the check.** It passes the model entry and fails a copy with its glance order broken.

&nbsp;

## Upgrade

No migration required. A draft with visible tags still passes.
