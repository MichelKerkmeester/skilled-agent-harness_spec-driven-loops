# v1.4.3.0, One Release Body Builder and an Amend Path

The release body was built by hand from prose steps. A published release had no way to take a corrected entry. The v4.0.2.0 notes were amended four times, each one rebuilt by hand.

> Spec folder: `specs/sk-doc/067-doc-tooling-prose-and-release-amend`

&nbsp;

## What's New at a Glance

- **One script builds the release body.** `build_release_notes.py` drops the frontmatter and title and adds the pointer.
- **A published release can be amended.** Rebuild the body and run `gh release edit`. The tag stays put.
- **Entries lead with what matters most.** Sections and the glance list follow reader impact, and an extension can retitle.
- **The publish step uses the script.** Both workflows call it instead of listing strip steps.
