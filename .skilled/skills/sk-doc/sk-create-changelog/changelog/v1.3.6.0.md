# v1.3.6.0, Changelogs Are Global Only

Spec folders no longer hold changelogs, so `/create:changelog` has one output mode. A spec folder can still be the source of an entry, and the entry goes to the component its changed files belong to.

> Spec folder: `specs/system-speckit/054-weak-model-spec-authoring/025-deprecate-nested-changelogs` (Level 2)

&nbsp;

## What's New at a Glance

- **A `--nested` run is refused.** Step 1 stops with a message that names the deprecation and offers the global entry, and the run reports `STATUS=FAIL` before it writes anything.
- **Every entry lands in a global folder.** Both workflows lost their nested branch, the release step's nested path included.
- **A packet-local request still reaches this mode.** Its routing keywords stay so the mode can refuse the request and offer the global entry.
- **The template, references and playbook match.** Template section 7 is marked deprecated, and the phase-child scenario now fails a run that writes a packet changelog.

&nbsp;

## Upgrade

Drop `--nested` from any script that passes it. Run `/create:changelog` without it to write the global entry.
