# v1.5.4.0, The Spec-Folder Line Closes the Entry

An entry now opens with the change and ends with its spec folder. The reader no longer meets a packet path before they learn what changed.

&nbsp;

## What's New at a Glance

- **The template puts the line last.** Both shapes end with the spec-folder line, after an `&nbsp;` line.
- **Every existing changelog moved too.** 2,814 entries now end with their spec-folder line. One already did.
- **Dated entries keep their own line.** An older file with one section per date keeps each line at the end of its own section.

&nbsp;

## Upgrade

No migration required.
