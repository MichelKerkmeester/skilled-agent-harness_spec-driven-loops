# v1.3.2.0, A README Audit That Stops Crying Wolf

The README audit flagged hundreds of references that were never broken, such as slash commands, file-type names and paths on the reader's own machine, so a real broken link was hard to spot among them. Narrow rules now clear each known case, and a README can record the rare deliberate exception in a marker block that must give a reason. The root README went from 298 unresolved references to none, and across all 987 tracked READMEs no line that passed before now fails.

> Spec folder: `specs/sk-doc/071-readme-reference-debt` (Level 2)

&nbsp;

## What's New at a Glance

- **Words that only look like paths stop counting as broken.** Slash commands, bare names of tracked files, slashed words such as "read/write", file-type tokens and `REPO RULES.md` all resolve.
- **Paths that live somewhere else are read as such.** System paths, home paths, paths relative to another base, runtime folders, ignored paths and config the doctor commands create on demand no longer fail a clean checkout.
- **Built output resolves through its source.** A compiled `.js` file clears when its tracked `.ts` source exists, and a per-mode path inside a parent hub resolves against that hub.
- **Output arguments are not references.** A path given after `-o`, `--output` or `--out` names a file the command will write, so the audit skips it.
- **Only real count claims are checked.** `check_derived_readme_counts.py` no longer reads a label such as "Level 2", a threshold such as "more than 100" or a number in another clause from its noun as a count. A count next to a folder in a code span is checked against that folder.
- **A README can declare its own exceptions.** A `<!-- readme-check -->` block lists `allow-ref` and `allow-count` entries, each with a reason after a `|`. An entry that no longer matches anything fails, so the marker cannot outlive its cause.

&nbsp;

## Upgrade

No migration required. Add a `readme-check` block only for a reference or count that is correct but no rule can prove, and see the docstring in `scripts/check_readme_references.py` for the syntax.
