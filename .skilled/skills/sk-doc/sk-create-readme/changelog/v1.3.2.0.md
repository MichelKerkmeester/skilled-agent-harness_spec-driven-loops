# v1.3.2.0, A README Audit That Stops Crying Wolf

The README audit flagged hundreds of references that were never broken. These included slash commands, file-type names and paths on the reader's own machine. So a real broken link was hard to spot among them. Narrow rules now clear each known case. A README can record the rare deliberate exception in a marker block. That block must give a reason. The root README went from 298 unresolved references to none. Across all 987 tracked READMEs, no line that passed before now fails.

> Spec folder: `specs/sk-doc/071-readme-reference-debt` (Level 2)

&nbsp;

## What's New at a Glance

- **Words that only look like paths stop counting as broken.** Slash commands now resolve. So do bare names of tracked files. So do slashed words such as "read/write". File-type tokens and `REPO RULES.md` resolve too.
- **Paths that live somewhere else are read as such.** System paths no longer fail a clean checkout. So do home paths and paths relative to another base. Runtime folders and ignored paths also pass. So does config the doctor commands create on demand.
- **Built output resolves through its source.** A compiled `.js` file clears when its tracked `.ts` source exists. A per-mode path inside a parent hub resolves against that hub.
- **Output arguments are not references.** A path after `-o`, `--output` or `--out` names a file the command will write. So the audit skips it.
- **Only real count claims are checked.** `check_derived_readme_counts.py` no longer reads these as a count. One is a label such as "Level 2". Another is a threshold such as "more than 100". A third is a number in another clause from its noun. A count next to a folder in a code span is checked against that folder.
- **A README can declare its own exceptions.** A `<!-- readme-check -->` block lists `allow-ref` and `allow-count` entries, each with a reason after a `|`. An entry that no longer matches anything fails. So the marker cannot outlive its cause.

&nbsp;

## Upgrade

No migration required. Add a `readme-check` block only for a reference or count that is correct but no rule can prove. See the docstring in `scripts/check_readme_references.py` for the syntax.
