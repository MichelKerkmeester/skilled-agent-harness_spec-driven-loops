# v1.3.12.0, Lifecycle Numbered and Every Output Named

The packet's `SKILL.md`, `ROUTER.md`, `README.md`, README template and references were read file by file. The reading looked at readability, layout and structure. Text moved and split. Every claim was kept. The README now lists files the packet already ships. No command, contract or template behavior changed.

&nbsp;

## What's New at a Glance

- **The lifecycle is numbered.** The README walks four steps. They run from reading local evidence to validating links. The skill has two failures behind it. One is a README from memory. The other is one template for everything. Both are now bullets.
- **Every output is named.** The README says the packet also writes a skill package's `ARCHITECTURE.md`. `ROUTER.md` lists its three templates. They are the general, code-folder and architecture scaffolds.
- **The README lists the packet's checks.** Its checks table gained the reference-integrity and derived-count scripts. Its document table gained the architecture template and the manual testing playbook.
- **The rule blocks have headings.** `SKILL.md`'s Always, Never, Human Voice Rules and Escalate If blocks are now subsections. It also says to report `UNKNOWN_FALLBACK` when nothing matches.
- **References open with their purpose.** The quality, types-and-voice and writing-patterns references each open the same way. Each has a Purpose, a When to Use and a Core Principle heading. Their packed formatting rules became bullets.
