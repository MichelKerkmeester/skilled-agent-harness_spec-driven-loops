# v1.3.10.0, Filename Templates and Count Phrases

README reference checks now resolve a bracketed token in a file basename. They treat it as a filename template against that folder. Bracketed route folders such as `app/[id]` stay literal paths. So the checker continues to verify the route file itself.

Count checks recognize known file categories. These include shell scripts and Node test files. Compound concept phrases stay prose. Examples are reader tests and example scripts. This prevents design and test concepts from being mistaken for inventories of files.

&nbsp;

## What's New at a Glance

- **Filename placeholders resolve by folder.** A reference such as
  `changelog/v[version].md` passes when a matching file exists in that folder.
- **Compound concepts stay prose.** Only direct file counts and recognized
  category modifiers count as README inventory claims.
