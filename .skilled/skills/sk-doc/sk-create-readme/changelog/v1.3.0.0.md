# v1.3.0.0, An ARCHITECTURE.md Template

Skills can now describe how their code fits together in one fixed shape. `assets/architecture-template.md` carries eight sections: overview, package topology, canonical flows, runtime subsystems, hook and plugin integration, enforcement and verification, decision records and related documents. The deep-loop, skill-advisor and spec-kit skills now all follow it.

> Spec folder: `specs/system-deep-loop/036-deep-loop-innovation/029-align-runtime-code-with-sk-code-opencode` (Level 2)

## What's New at a Glance

- **One template covers every skill's architecture.** It explains what belongs in each section and gives a fillable scaffold.
- **The package tree is part of the contract.** Section 2 shows the real folder layout and the allowed dependency directions, so a stale tree is easy to spot.

## Upgrade

No migration required. Use the template when a skill gains its first ARCHITECTURE.md.
