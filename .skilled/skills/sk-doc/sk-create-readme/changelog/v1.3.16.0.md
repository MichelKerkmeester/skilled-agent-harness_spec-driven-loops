# v1.3.16.0, A path written from the repository root resolves

A README often writes a path the way the repository lays it out. The checker read it from the README folder only, so the path looked missing.

> Spec folder: `AI Systems/Product Owner/specs/system/032-fresh-review-fixes`

&nbsp;

## What's New at a Glance

- **A root folder head resolves.** `scripts/sync.py` in a nested README is also read from the repository root.
- **A stale path still fails.** A bare file name stays tied to the README folder. So does a first segment the root does not hold.
- **Dot folders stay tied.** `.git/hooks/` is still allowed by marker, as before.
- **Skilled is unchanged.** All 1005 READMEs give the same result as before.
