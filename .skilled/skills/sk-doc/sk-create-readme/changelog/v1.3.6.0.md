# v1.3.6.0, The Examples Count Reports Example Fences

Every verdict line from the reference checker ends with an `examples=` figure, but it always printed 0. The checker skipped the lines of an example fence before reading them, so it never recorded a reference there to count. It now reads those lines like any other fence, tags each reference it finds as an example and resolves it as "example: not checked", so the figure counts them and none of them can fail.

> Spec folder: `specs/sk-doc/071-readme-reference-debt` (Level 2)

&nbsp;

## What's New at a Glance

- **The examples figure is real.** A path inside a fence marked `example`, such as ```` ```bash example ````, now adds to `examples=` on that README's verdict line.
- **Example references still never fail.** They resolve as "example: not checked". Across all 987 tracked READMEs the pass and fail verdicts are the same as before the change.
- **One self-test case covers it.** A README with one example fence and one plain fence counts the example path and fails only on the plain one.
