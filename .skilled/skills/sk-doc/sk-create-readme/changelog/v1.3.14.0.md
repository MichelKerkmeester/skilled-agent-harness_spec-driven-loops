# v1.3.14.0, Paragraphs First and Bullets Where They Help

The README rules turned any paragraph with several points into a bullet list. The root README grew to 537 bullet lines and read like notes. Explanation now reads as short paragraphs, and bullets hold what a reader scans.

> Spec folder: `specs/sk-doc/067-doc-tooling-prose-and-release-amend`

&nbsp;

## What's New at a Glance

- **Paragraphs carry the explanation.** Short sentences, about 60 words a paragraph.
- **Bullets are for scanning.** Commands, options, steps and parallel facts stay as lists.
- **A long install gets its own document.** The front-page README keeps the minimum commands and links a root install document.
- **The checklist matches.** Its paragraph item checks the new balance.
- **Section spacing is one rule.** A spacer line goes above every H2, H3 and H4, so sibling sections get the same gap.

&nbsp;

## Upgrade

No migration required. Rewrite a bullet-heavy README section when you next touch it.
