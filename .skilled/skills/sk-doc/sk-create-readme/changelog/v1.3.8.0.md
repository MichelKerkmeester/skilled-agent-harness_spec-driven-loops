# v1.3.8.0, The Routing Section Becomes a Short Summary

The routing section held the artifact table, the resilience rules, the prompt-intent projection and a decision tree. A reader who wanted the template for one artifact met all of it first. The section now says what selects this packet, which template each artifact loads and where the router lives. Everything else moved without a text change to a final `MACHINE ROUTER` section at the end of the file. No route changed.
