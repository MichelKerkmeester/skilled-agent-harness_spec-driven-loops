# v1.3.13.0, README Checks Know the dsh Folder

The DeepSeek Harness runtime folder `.dsh/` is now a repository root the README tools understand, so a README that links into it is checked instead of flagged.

> Spec folder: `specs/cli-external-orchestration/085-cli-deepseek-harness-creation`

&nbsp;

## What's New at a Glance

- **Links into `.dsh/` resolve.** `check_readme_references.py` treats `.dsh/` as a repository root beside the other runtime folders.
- **The README audit covers `.dsh/`.** `audit_readmes.py` counts it among the durable roots, and the README verdict baselines include its folders.

&nbsp;

No migration required.
