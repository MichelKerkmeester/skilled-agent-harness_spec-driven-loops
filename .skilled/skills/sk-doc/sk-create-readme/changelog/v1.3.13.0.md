# v1.3.13.0, README Checks Know the dsh Folder

The DeepSeek Harness runtime folder `.dsh/` is now a repository root. The README tools understand it. So a README that links into it is checked. It is not flagged.

&nbsp;

## What's New at a Glance

- Links into `.dsh/` resolve.
  - `check_readme_references.py` treats `.dsh/` as a repository root.
  - It sits beside the other runtime folders.
- The README audit covers `.dsh/`.
  - `audit_readmes.py` counts it among the durable roots.
  - The README verdict baselines include its folders.

&nbsp;

## Upgrade

No migration required.
