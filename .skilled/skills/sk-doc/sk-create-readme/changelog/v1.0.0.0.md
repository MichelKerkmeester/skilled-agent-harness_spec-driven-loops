# v1.0.0.0, README and Install-Guide Authoring

The first `create-readme` release provides a workflow. It writes current-state folder `README.md` files and install guides. It uses local evidence only. It routes work by artifact type and folder purpose. It does not rely on one fixed template.

&nbsp;

## What's New at a Glance

- `create-readme` is one of `sk-doc`'s ten workflow packets.
  - It follows the parent hub's workflow-only architecture.
  - It handles README and install-guide authoring only.
- The README workflow defines general and code-folder output shapes.
  - It writes general project, skill, feature and component READMEs.
  - It also writes source-code folder orientation.
- Fillable scaffolds cover both README shapes.
  - The fillable `assets/readme/readme-template.md` covers project, skill, feature and component READMEs.
  - The fillable `assets/readme/readme-code-template.md` covers source-code folder READMEs.
  - It includes diagram examples.
- Install guides follow five phases across sections 0 through 10.
  - The phases run from prerequisites through verification.
  - They include validation checkpoints and STOP blocks.
  - A fillable `assets/readme/install-guide-template.md` provides the 11-section guide scaffold.
- README and install-guide references extend the workflow guidance.
  - `references/readme_creation.md` extends README quality criteria.
  - It adds progressive-disclosure guidance, analogy patterns and table patterns beyond the inline `SKILL.md`.
  - `references/install_guide_creation.md` provides extended install-guide examples.
  - These include validation-checkpoint patterns and troubleshooting standards.
- The writing rules keep content current-state only.
  - They prohibit fabricated commands and metrics.
  - They follow Human Voice Rules.
  - The workflow also defines validation and audit procedures.
- `scripts/audit_readmes.py` checks repository README quality.
  - It checks template alignment, broken local references and key artifact coverage.
- The nested packet does not carry `graph-metadata.json`.
  - Advisor identity, skill graph metadata and cross-packet routing live at the `sk-doc` hub root.
