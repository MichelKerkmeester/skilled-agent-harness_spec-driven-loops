# v1.15.1.0, Artifact Examples Keep Their Own Shape

An AI system ships worked examples of its deliverables, such as a ClickUp ticket that opens on its title and then an About section. The render checks asked those files for a prose intro and an Overview, which would have changed the shape the model copies. `package_skill.py --check --strict` now leaves files under `assets/examples/` out of the render scan.

&nbsp;

## What's New at a Glance

- **One skipped prefix.** `RENDER_SKIPPED_PREFIXES` holds `assets/examples/`, read relative to the skill folder
- **Nothing else moves.** No Skilled skill has an `assets/examples/` folder today, and the other validator checks still read these files

&nbsp;
