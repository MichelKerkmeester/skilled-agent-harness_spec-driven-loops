# Hook References as Routed Leaves

Standalone skills can now declare `hooks` as a leaf root in `leaf-manifest.config.json`, so their hook reference documents can be routed. Previously the leaf contract and generator rejected that root with an unsupported-root error.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/002-baseline-and-routing-correctness` (Level 2)

&nbsp;

## What's New at a Glance

- **Hook paths are admitted.** The new root expands the allowed paths without changing existing manifests. A unit test covers it.

&nbsp;

## Upgrade

No action is needed.
