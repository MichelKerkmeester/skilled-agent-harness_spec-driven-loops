# v1.7.6.0, A Missing Machine Router Now Fails

`package_skill.py --strict` now fails a SKILL.md with no `## MACHINE ROUTER` section. `parent-skill-check.cjs` does the same. Before this, a skill with short SMART ROUTING prose and no router block passed every count. That held even while its routing detail stayed inline.

&nbsp;

## What's New at a Glance

- **A missing router section now fails.** The routing shape check rejects a SKILL.md with no `## MACHINE ROUTER` section. `--strict` makes that rejection an error.
- **The canon names all five codes.** The validation reference and the skill template now list every routing shape code. So do the `/create:skill` workflow steps. They also say a packet with no router block still ends with the section.
- **The known-debt ledger is empty.** No skill is listed as tolerated for this check. So every skill must pass it.

&nbsp;

## Upgrade

A skill outside this repo with no `## MACHINE ROUTER` section now fails `--strict`. Add a final `## MACHINE ROUTER` section. It holds the skill's routing detail.
