# v1.7.6.0, A Missing Machine Router Now Fails

`package_skill.py --strict` and `parent-skill-check.cjs` now fail a SKILL.md with no `## MACHINE ROUTER` section. Before this, a skill with short SMART ROUTING prose and no router block passed every count, even while its routing detail stayed inline.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/013-mcp-tooling-routing-canon` (Level 2)

&nbsp;

## What's New at a Glance

- **A missing router section now fails.** The routing shape check rejects a SKILL.md with no `## MACHINE ROUTER` section, and `--strict` makes that rejection an error.
- **The canon names all five codes.** The validation reference, the skill template and the `/create:skill` workflow steps now list every routing shape code. They also say that a packet with no router block still ends with the section.
- **The known-debt ledger is empty.** No skill is listed as tolerated for this check, so every skill must pass it.

&nbsp;

## Upgrade

A skill outside this repo that has no `## MACHINE ROUTER` section now fails `--strict`. Add a final `## MACHINE ROUTER` section that holds its routing detail.
