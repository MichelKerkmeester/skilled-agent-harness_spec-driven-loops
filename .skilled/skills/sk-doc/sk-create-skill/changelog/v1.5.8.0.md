# v1.5.8.0, The Validate and Package Examples Name the Skill Folder as a Placeholder

The validate and package steps ran against a folder called `my-skill`, which reads like a folder that already exists. A reader following the quickstart had to guess whether to keep that name or swap in their own. Both commands now write the folder as `<skill-name>`.

> Spec folder: `specs/sk-doc/070-repo-doc-debt/005-reference-and-coverage-fixes` (Level 2)

&nbsp;

## What's New at a Glance

- **Both example commands write the folder as a placeholder.** The angle brackets say the name is yours. The same one appears at each step.
- **The quickstart reads in order.** Validate checks the folder the first step created and package bundles that same folder, with no invented name in between.

&nbsp;

## Upgrade

No action is needed. This is a documentation change, so the scripts behave exactly as they did before.
