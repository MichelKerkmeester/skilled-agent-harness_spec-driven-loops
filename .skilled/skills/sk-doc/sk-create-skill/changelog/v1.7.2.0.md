# v1.7.2.0, Templates Share One Prose Checklist

SKILL.md and README authoring now share one short clarity checklist. It defines sentence, voice and layout rules in a single place.
The standalone and hub templates link to it. Their placeholders use shorter, direct prose.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/010-prose-clarity-pass` (Level 2)

&nbsp;

## What's New at a Glance

- **One clarity checklist.** The workflow guidance covers instruction order, facts, sentence length, second-person voice, project history, code fences, line length and hub terms.
- **Templates start closer to the target.** Skill and hub templates link to the checklist. README placeholders name current reader problems and use shorter sentences.
- **Parent-hub reference revised.** `references/parent-skill/parent-skills-nested-packets.md` is now version `1.2.8.0`; it lists the hub layout in a table and explains `stage1-only` and `active` router states separately.
- **README flow diagrams use Mermaid.** The skill and hub README templates now request Mermaid diagrams for multi-step flows.

&nbsp;

## Upgrade

No action is needed. Use the checklist when you create or update a skill.
