# v1.3.0.0 - README template value-first and emoji-register alignment

**Released:** 2026-09-20

The README templates taught an engaging narrative opening but anchored it to the root README's old problem-first shape, and neither template said a word about emoji. The root README has since moved to a value-first SUMMARY opening and the two-register emoji policy landed in `sk-create-readme` v1.2.0.0. This release aligns both templates: the opening teaches value-first, the problem narrative becomes optional and the emoji rule is explicit.

## What Changed

- The OVERVIEW now opens with `### What It Does` first: what the skill is and what the reader gets, modeled on the root README SUMMARY section and its benefit bullets. Value-first replaces the problem-first mandate.
- `### Why This Skill Exists` became an optional problem narrative, used when the pain needs telling before the mechanism lands. The scaffold's amnesia example comment, which quoted the root README section the operator removed, is gone.
- Added the emoji rule to the writing rules: semantic emoji only (✅ ❌ ⚠️ 🔒 🚨) for rules and status markers, decorative section emoji never. Formatting follows the technical register per `core-standards.md`.
- Updated the stale root-README references: the writing-rule bullet that described the removed problem opening, the "Reasons to try it" model name (now "Why it earns a place") and the triage-nurse analogy quote.
- Updated the validation checklist: the OVERVIEW row now checks a value-first opening, and the problem-narrative row applies only when the optional subsection is present.
- Mirrored the same changes into the parent-hub template: `### What It Does` first, `### Why This Hub Exists` optional, the emoji rule and the checklist row.
- Bumped `skill-readme-template.md` from `1.2.0.15` to `1.3.0.0` and `parent-skill-readme-template.md` from `1.2.0.4` to `1.3.0.0`.
- `sk-create-readme`'s register reference now states the same deal from the other side: technical formatting, engaging voice allowed. Its `types-and-voice.md` moved to `1.2.1.0`.

## Not Changed

- The section model, the numbered ALL-CAPS structure, the AT A GLANCE table and OVERVIEW as the only required section stay in place.
- The Human Voice Rules hard blockers stay exactly as they were.
- `SKILL.md`, the reference templates, scripts and the mode registries stay untouched. The change is template guidance only.
- No shipped skill README was rewritten. The guidance applies to new and updated documents.
