# v1.5.1.0, One Gate for the Replay Scorer

The Deem arm and its docs are removed from `leaf-route-replay.cjs`, and cli-jev is the only classifier the scorer calls. Its `--jev` arm keeps its three answers per row in rotated option order and its `--out <dir>` requirement.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/046-deem-deprecation/004-references-sweep-and-verification` (Level 2)

## What's New at a Glance

- **The replay keeps its Jev tie-break.** `--jev` still asks for three answers per tied row and ends its column in a `verdict jev:` line.
- **The packet docs match the code.** The README, SKILL and playbook describe the Jev-only replay.
