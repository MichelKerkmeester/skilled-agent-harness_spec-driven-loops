# v1.5.1.0, One Gate for Two Scorers

The Deem arms and their docs are removed from `score-clarify-default.cjs` and `leaf-route-replay.cjs`, and cli-jev is the only classifier each scorer calls. Each `--jev` arm keeps its three answers per row in rotated option order and its `--out <dir>` requirement.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/046-deem-deprecation/004-references-sweep-and-verification` (Level 2)

## What's New at a Glance

- **The clarify scorer keeps its Jev gate.** `--score` still stops below 30 labeled rows, and `--jev` runs past that gate through `--out <dir>`.
- **The replay keeps its Jev tie-break.** `--jev` still asks for three answers per tied row and ends its column in a `verdict jev:` line.
- **The packet docs match the code.** The README, SKILL and playbook describe the Jev-only runs.
