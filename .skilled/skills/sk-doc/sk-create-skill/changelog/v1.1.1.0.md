# v1.1.1.0 - README rewrite

**Released:** 2026-08-04

The create-skill README now reads like the rest of the pilot README family: a one-line pitch, a problem-first overview and narrative sections that name the outcome before the tooling. The old reference-card layout opened with a tabular AT A GLANCE and no human entry point, so anyone learning the skill from the README had to assemble the story themselves. Every capability, command and navigation fact survives the rewrite, the frontmatter version moves to `1.1.1.0` and this entry keeps the README and the changelog in sync.

## What Changed

- Rewrote the README purpose-first on the refined README template: one-line pitch, problem-first OVERVIEW, numbered ALL-CAPS sections with dividers and a capability table for the two workflow modes.
- Kept every fact the old README carried: both modes, the validation and packaging gate, the legacy and ready compiled-routing shapes, the quick start commands, troubleshooting rows, FAQ answers, verification rows and all related document links.
- Bumped the frontmatter `version` field from `1.1.0.1` to `1.1.1.0`.
- Added this changelog entry at `changelog/v1.1.1.0.md`.

## Not Changed

- `SKILL.md` content and frontmatter stay untouched. The runtime contract still owns routing and workflow rules.
- Templates, scripts, references and assets stay untouched. The README documents current state only.
- No behavior change. The rewrite is documentation-only and requires no migration.
