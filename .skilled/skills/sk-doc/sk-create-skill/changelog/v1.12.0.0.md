# v1.12.0.0, One Strict Gate, a Wider Render Scan and a Ledger Ratchet

The packaging gate now reads every doc a skill hands a reader. The docs name one command for it. New render checks and newly scanned files report as advisory until the fleet is cleared. So no skill fails today.

> Spec folder: `specs/sk-doc/066-skill-readability-refinement/014-sk-create-skill-refinements/001-render-checks-and-gate` (Level 3)

&nbsp;

## What's New at a Glance

- **One completion gate.** `SKILL.md`, `README.md` and `references/skill/creation-workflow.md` name `scripts/validate_skill_package.py <path> --strict`. The stale line is gone. It said the gate reads resource frontmatter only. That is because the gate runs the render checks.
- **The render scan reads more of a skill.** `package_skill.py` now checks `SKILL.md`, `ROUTER.md`, `shared/references/` and `runtime/references/`. It checks them besides `references/` and `assets/`. It records the scope of each finding.
- **New codes and scopes start advisory.** `RENDER_STAGED_CODES` and `RENDER_STAGED_SCOPES` hold the render codes and scan scopes added in this release. They also hold `README.md`. Their findings print as `render advisory:`. `--strict` does not promote them. `RENDER_STAGED_OFF=1` enforces them. That lists a skill's findings before fixing them.
- **A stale debt entry fails strict.** A ledger entry can record more findings than remain. The message for it now starts `render check: stale known debt:`. So `--strict` promotes it.
- **The ledger and the staged sets can only shrink.** `scripts/tests/render-known-debt-ratchet.test.cjs` compares them with a frozen fixture. It fails on a new debt key or a raised count. It also fails on a new exempt key, or a new staged code or scope.
- **Fenced headings no longer satisfy a required section.** The SKILL.md section scan skips headings inside fences. So `references/shared/common-pitfalls.md` drops its `\##` escapes. It also drops the note that explained them.
- **CI runs the gate.** `.github/workflows/sk-doc-script-tests.yml` gained a `render-gate` job. It runs the ratchet. It packages every skill and mode under `--strict`.

&nbsp;

## Upgrade

No migration required. Run `validate_skill_package.py <path> --strict` where `validate_skill_package.py <path>` ran before.
