# v1.5.12.0, Every Scaffold and Template Seeds Parseable Frontmatter

The scaffolds and templates are read by whoever builds the next skill, so a value a strict YAML parser rejects is copied onward. Five of them carried such a value, a description with a colon in the middle and a placeholder name or tool list written bare. Every one is now quoted, so a generated file parses as soon as it is written.

> Spec folder: `specs/sk-code/017-portable-code-modes/015-frontmatter-yaml-validity` (Level 2)

&nbsp;

## What's New at a Glance

- **A generated skill starts from valid YAML.** The hub and packet scaffolds quote the placeholder name, one of them quotes the allowed-tools placeholder, and a filled scaffold still parses after a new skill fills the values in.
- **The templates teach the quoted shape.** The skill scaffold, the skill README template and the parent skill root router template show a quoted value wherever one holds a colon, so a copy carries the fix.
