# v1.5.12.0, Every Scaffold and Template Seeds Parseable Frontmatter

The scaffolds and templates are read by whoever builds the next skill. So a value a strict YAML parser rejects is copied onward. Five of them carried such a value. One was a description with a colon in the middle. Another was a placeholder name or tool list written bare. Every one is now quoted. So a generated file parses as soon as it is written.

> Spec folder: `specs/sk-code/017-portable-code-modes/015-frontmatter-yaml-validity` (Level 2)

&nbsp;

## What's New at a Glance

- **A generated skill starts from valid YAML.** The hub and packet scaffolds quote the placeholder name. One of them quotes the allowed-tools placeholder. A filled scaffold still parses after a new skill fills the values in.
- **The templates teach the quoted shape.** The skill scaffold shows a quoted value wherever one holds a colon. So do the skill README template and the parent skill root router template. So a copy carries the fix.
