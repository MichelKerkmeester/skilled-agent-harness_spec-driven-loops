# v1.2.1.0, The Reader-Needed Lens Measures Jev Alone

The Deem arm and its docs are removed from `hvr_reader_lens.py`, and cli-jev is the only classifier the lens calls. The `--jev` arm keeps its `--out <dir>` requirement and its gate, which runs before any call.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/046-deem-deprecation/004-references-sweep-and-verification` (Level 2)

## What's New at a Glance

- **One measurement arm remains.** `--jev` with `--out <dir>` is the only way the lens calls a classifier, and a failed gate still prints its skip line.
- **The default run is untouched.** It still makes no model call, writes no file and stops at the label gate until 150 rows carry a label.
- **The packet docs match the code.** The README, SKILL and the HVT-004 scenario describe the Jev-only run.
