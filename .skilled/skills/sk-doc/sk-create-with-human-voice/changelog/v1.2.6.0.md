# v1.2.6.0, Product Names Are Not Blocker Words

`harness` is a hard blocker word. So every mention of the DeepSeek Harness CLI counted as one. The root README lost 9 hard blockers to the name alone.

> Spec folder: `specs/sk-doc/067-doc-tooling-prose-and-release-amend`

&nbsp;

## What's New at a Glance

- **Listed names are exempt.** The rules file's Proper names line lists them, exact and case-sensitive.
- **The word still counts.** `harness the power` is a hard blocker as before.
- **A test pins both.** It fails on the old scanner and passes on the new one.

&nbsp;

## Upgrade

No migration required. Add a product name to the Proper names line when its name holds a blocker word.
