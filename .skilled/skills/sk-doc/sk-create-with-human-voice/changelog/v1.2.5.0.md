# v1.2.5.0, Scope Comes Before the Scan

The packet's `SKILL.md`, `ROUTER.md`, `README.md` and references were read file by file. The reading looked at readability, layout and structure. Text moved and split. Every claim was kept. A few cross-references were corrected to match the files they name. No command, contract or template behavior changed.

> Spec folder: `specs/sk-doc/066-skill-readability-refinement/008-sk-doc` (Level 1)

&nbsp;

## What's New at a Glance

- **Scope comes before the scan.** The README's quick start now puts scope first. Deciding what the scanner may not touch is Step 1. Scanning is Step 2. That is the same order `SKILL.md` follows.
- **The precedence order is numbered.** The scoring reference lists the six penalty tiers as an ordered list. They run from hard phrase blocker to advisory flag.
- **Cross-references name the right file.** The scoring reference now says the precedence rule lives in the publish supplement. So do the category-share tables. It gives their section numbers there.
- **The publish supplement opens with its purpose.** It gained a Purpose and a When to Use. It lists the three precedence consequences as bullets. It drops a scoring line that repeated the paragraph below it.
- **Small fixes elsewhere.** `SKILL.md` says an unmatched request returns `UNKNOWN_FALLBACK`. The scope reference splits its template-detection note into two bullets. The references index says which file to read first.
