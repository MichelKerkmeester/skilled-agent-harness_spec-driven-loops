# v1.2.5.0, Scope Comes Before the Scan

The packet's `SKILL.md`, `ROUTER.md`, `README.md` and references were read file by file for readability, layout and structure. Text moved and split, every claim was kept and a few cross-references were corrected to match the files they name. No command, contract or template behavior changed.

> Spec folder: `specs/sk-doc/066-skill-readability-refinement/008-sk-doc` (Level 1)

&nbsp;

## What's New at a Glance

- **Scope comes before the scan.** The README's quick start now makes deciding what the scanner may not touch Step 1 and scanning Step 2, the same order `SKILL.md` follows.
- **The precedence order is numbered.** The scoring reference lists the six penalty tiers, from hard phrase blocker to advisory flag, as an ordered list.
- **Cross-references name the right file.** The scoring reference now says the precedence rule and the category-share tables live in the publish supplement, and gives their section numbers there.
- **The publish supplement opens with its purpose.** It gained a Purpose and a When to Use, lists the three precedence consequences as bullets and drops a scoring line that repeated the paragraph below it.
- **Small fixes elsewhere.** `SKILL.md` says an unmatched request returns `UNKNOWN_FALLBACK`, the scope reference splits its template-detection note into two bullets, and the references index says which file to read first.
