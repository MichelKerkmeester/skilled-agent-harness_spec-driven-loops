# v1.2.7.0, A Retrofit May Reword a Released Changelog

A released changelog entry was always out of scope for a voice edit. That left no way to shorten the sentences in old entries. Now one kind of edit is allowed.

&nbsp;

## What's New at a Glance

- **An approved retrofit may reword a released entry.** The operator must approve it, and a spec packet must record that approval.
- **The retrofit keeps every fact.** It changes how a sentence reads, never what it claims.
- **Every other edit stays forbidden.** NEVER rule 2 in `SKILL.md` and the scope table in `references/scope-and-exemptions.md` say the same thing.

&nbsp;

## Upgrade

No migration required.
