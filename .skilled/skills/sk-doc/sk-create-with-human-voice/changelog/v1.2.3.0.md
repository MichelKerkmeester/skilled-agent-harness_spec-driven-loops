# v1.2.3.0, The Routing Section Becomes a Short Summary

The routing section held the family boundary, the resource list, the loading-level table and the router pseudocode. It held them before it said what selects this packet. It now says that first. Then it names the two operations. It also names the scope reference that loads first on every path. And it names the rules file the scanner parses. The detail moved to a final `MACHINE ROUTER` section. The text did not change. No route changed.

## What's New at a Glance

- The routing section is prose.
  - It names the packet selector.
  - It names the two operations.
  - It also names the resources that load first.
- The router detail moved as it was.
  - The family boundary, the resource domains, the loading levels and the pseudocode now sit under `## 9. MACHINE ROUTER`.
- No route changed.
  - Apply and score resolve to the same resources.
