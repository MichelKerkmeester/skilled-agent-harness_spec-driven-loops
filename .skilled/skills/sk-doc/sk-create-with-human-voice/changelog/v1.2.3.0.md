# v1.2.3.0, The Routing Section Becomes a Short Summary

The routing section held the family boundary, the resource list, the loading-level table and the router pseudocode before it said what selects this packet. It now says that first, then names the two operations, the scope reference that loads first on every path and the rules file the scanner parses. The detail moved without a text change to a final `MACHINE ROUTER` section. No route changed.
