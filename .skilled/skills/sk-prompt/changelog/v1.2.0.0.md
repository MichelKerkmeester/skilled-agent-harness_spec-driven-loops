This release makes sk-prompt easier to understand and use by updating its request-routing and prompt-writing guidance.

## What's New at a Glance

- **The Smart Router is rewritten.** `SKILL.md` gets the new router and a visual cleanup.
- **Two references are removed.** Individual assets replace the consolidated `format_guides.md` reference, and the `interactive_mode.md` content moves into the command files.
- **Evaluation guidance gains deep dives.** `patterns-evaluation.md` drops its visual content and adds four deep dives with CLEAR rubrics, and `depth-framework.md` removes the Creative energy level.
- **The prompt command gains an interactive step.** Both `create/prompt` command definitions fix stale references and add a Step 1a interactive behavior.
- **The READMEs follow the changes.** The skill README drops references to the deleted files and updates its counts, and the skills README updates its version, framework list and folder signals.
