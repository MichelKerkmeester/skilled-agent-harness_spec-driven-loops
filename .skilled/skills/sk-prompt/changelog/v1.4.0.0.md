# sk-prompt v1.4.0.0, Per-Model Framework Guidance and Prompt Composition

This release makes per-model framework guidance first-class and clarifies prompt composition while eliminating duplication with the `sk-prompt-models` hub. It adds the ranked `recommended_frameworks` field to all 8 active model profiles and updates the model profile reference and CLI prompt quality card.

> Spec folder: `.opencode/specs/skilled-agent-orchestration/130-sk-prompt-model-profiles/`

## What's New at a Glance

- **All 8 active model profiles gain an additive `recommended_frameworks` field.** In `assets/model-profiles.json`, it ranks the frameworks each model responds to best, bringing guidance previously scattered across prose into the profile data.
- **The model profile reference has a corrected count and field guide.** The rebuilt `references/model-profiles.md` fixes the stale model count, which read 10, and documents the field schema with an example. It separates Architecture-A data rows from explanatory prose.
- **The prompt quality card sets a three-tier composition order.** A new Prompt-Composition Precedence section in `assets/cli-prompt-quality-card.md` orders framework selection, density and per-model override. It points per-model overrides to `sk-prompt-models` as the canonical hub for model-specific profiles. The Mirror Sync section is refreshed with a duplication-guard description so readers know where each concern lives.
