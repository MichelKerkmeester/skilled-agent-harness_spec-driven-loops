# v3.0.9.0, Long Prose Lines Are Now Short Sentences

Two paragraphs in the `MACHINE ROUTER` section each carried a full argument in one line. The detection signal and the resource domains now read one sentence at a time. No fact was dropped.

&nbsp;

## What's New at a Glance

- **The detection signal paragraph is a sentence per line.** The command prefix stands on its own line. So does the keyword fallback, with its top-2 tie rule. The zero-score default does too.
- **The resource domain note split in two.** One sentence says what the flat resources are. Another says what the router does with them.

&nbsp;

## Upgrade

No action is needed. Every prefix, intent label, confidence name and fallback word is the same. The router loads exactly what it did before.
