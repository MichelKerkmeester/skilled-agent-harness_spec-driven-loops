# v3.0.5.0, The Entries Name Their Scenarios

Two changelog entries in the sk-prompt family pointed at playbook scenarios by id alone, so a reader could not place one without a search. Each entry now names the scenario by what it covers. The releases themselves report the same behavior as before.

- **No released fact changed.** Every entry still reports the same behavior, the same playbook identifiers and the same upgrade step.
