The skill now agrees with itself. It also agrees with the current Claude and GPT-6 prompting guides. Five of its own rules contradicted each other or the prompts they produce. A model that follows instructions literally had to pick one. This release settles each of them. It adds two input techniques from Anthropic's guide.

> Spec folder: `specs/agents/013-prompting-guide-alignment` (Level 2)

## What's New at a Glance

- **The one-question rule applies to interactive runs.** A run with nobody to answer now proceeds on stated assumptions. It flags them. `@prompt-improver` is one such run. It does not read a rule it cannot follow.
- **Enhanced prompts may address the model as "you".** The old ban on second person contradicted the skill's own dispatch card. That card opens with "You are dispatched AS". The rule now keeps the operator's voice out of the prompt.
- **The Success Rate column is gone.** Seven percentages appeared in two framework tables. No measurement stood behind them. Both vendors say to re-check any such figure on your own workload. Framework choice rests on task fit.
- **Chain-of-thought asks for conclusions, not reasoning transcripts.** Claude Opus 5.5 can decline a prompt. That prompt pushes it to reproduce its reasoning in the response.
- **Few-shot examples are tagged and varied.** The pattern now asks for three to five cases. Each case goes in `<example>` tags.
- **Long source material goes first.** The card's Arrangement check asks for long embedded material ahead of the task. The ask comes last. Its Expression check asks for what to do. A bare "don't" would leave the model guessing.
- **An improvement loop retries once.** The skill allowed up to three cycles. `@prompt-improver` retried once. Both now retry once. Then they deliver the best version with a quality note. So a prompt that misses the CLEAR floor costs at most one extra pass, not up to three. The iteration-cap scenario and the below-threshold improvement-cycle scenario test the new cap.
- **RICCE has one definition.** `depth-framework.md` expanded it as five scoring criteria. Every other file named the five prompt parts. It now names the parts.

## Upgrade

No migration required. A prompt that embeds long source material after its task can now lose Arrangement points. So re-score such prompts before reusing them.
