The skill now agrees with itself and with the current Claude and GPT-6 prompting guides. Five of its own rules contradicted each other or the prompts they produce, and a model that follows instructions literally had to pick one. This release settles each of them and adds two input techniques from Anthropic's guide.

> Spec folder: `specs/agents/013-prompting-guide-alignment` (Level 2)

## What's New at a Glance

- **The one-question rule applies to interactive runs.** A run with nobody to answer, such as `@prompt-improver`, now proceeds on stated assumptions and flags them, instead of reading a rule it cannot follow.
- **Enhanced prompts may address the model as "you".** The old ban on second person contradicted the skill's own dispatch card, which opens with "You are dispatched AS". The rule now keeps the operator's voice out of the prompt.
- **The Success Rate column is gone.** Seven percentages appeared in two framework tables with no measurement behind them, and both vendors say to re-check any such figure on your own workload. Framework choice rests on task fit.
- **Chain-of-thought asks for conclusions, not reasoning transcripts.** Claude Opus 5.5 can decline a prompt that pushes it to reproduce its reasoning in the response.
- **Few-shot examples are tagged and varied.** The pattern now asks for three to five cases in `<example>` tags.
- **Long source material goes first.** The card's Arrangement check asks for long embedded material ahead of the task, with the ask last. Its Expression check asks for what to do where a bare "don't" would leave the model guessing.
- **An improvement loop retries once.** The skill allowed up to three cycles while `@prompt-improver` retried once. Both now retry once, then deliver the best version with a quality note, so a prompt that misses the CLEAR floor costs at most one extra pass instead of up to three. Scenarios SP-011 and SP-017 test the new cap.
- **RICCE has one definition.** `depth-framework.md` expanded it as five scoring criteria while every other file named the five prompt parts. It now names the parts.

## Upgrade

No migration required. A prompt that embeds long source material after its task can now lose Arrangement points, so re-score such prompts before reusing them.
