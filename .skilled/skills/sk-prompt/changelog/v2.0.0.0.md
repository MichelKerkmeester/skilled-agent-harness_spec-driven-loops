# sk-prompt v2.0.0.0: A Forkable Prompt Framework Engine

Model-specific content has moved to `sk-prompt-models`.

- `sk-prompt-models` is the single source of truth for the model registry and benchmark data.
- `sk-prompt` no longer carries model names, profile paths or small-model guidance.

The framework engine is unchanged.

- DEPTH and CLEAR are unchanged.
- `framework-registry.json` is unchanged.

> [!IMPORTANT]
> 1 change can break an existing setup. Read it before you update.
>
> 1. Some consumers must repoint to the new path. [Repoint to the New Path](#c-repoint-to-the-new-path)

&nbsp;

## Why This Release

`sk-prompt` is now a standalone, forkable prompt-framework engine.

&nbsp;

&nbsp;

## Model Content

#### Profile Data Has a New Home <a id="c-profile-data-has-a-new-home"></a>

- Before the move, this skill stored model profiles in `assets/model-profiles.json`.
- They now live at `sk-prompt-models/assets/model-profiles.json`.
- No model-profile data is retained here.
- The advisor continues to co-surface `sk-prompt-models` alongside executor skills.
- The JSON schema is unchanged.
- All 8 active profiles resolve at the new path.

#### Reference Guidance Moves With It <a id="c-reference-guidance-moves-with-it"></a>

- `references/model-profiles.md` is deleted.
- Its schema and adoption content are now covered by `sk-prompt-models`'s pattern-index §4 and the JSON itself.

&nbsp;

## Prompt Quality Guidance

#### The Card Drops Model Guidance <a id="c-the-card-drops-model-guidance"></a>

- Before this release, `assets/cli-prompt-quality-card.md` included a per-model-override note.
- It included a Budget-Awareness (small-model) section.
- The note and section are removed.
- All small-model references are gone.
- The Tier-2 entry in its 3-tier Prompt-Composition Precedence section is now generic.
- It names no `sk-prompt-models` path or model.
- The card now contains only framework selection, DEPTH density and CLEAR scoring guidance.

&nbsp;
