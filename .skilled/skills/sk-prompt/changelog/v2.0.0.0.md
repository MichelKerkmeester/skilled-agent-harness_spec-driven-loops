# sk-prompt v2.0.0.0: A Forkable Prompt Framework Engine

Model-specific content has moved to `sk-prompt-models`, the single source of truth for the model registry and benchmark data. `sk-prompt` no longer carries model names, profile paths or small-model guidance. The framework engine (DEPTH / CLEAR / framework-registry.json) is unchanged.

> Spec folder: `.opencode/specs/skilled-agent-orchestration/131-registry-benchmark-consolidation/`

## Why This Release

`sk-prompt` is now a standalone, forkable prompt-framework engine.

## What's New at a Glance

- **`assets/model-profiles.json` moved to `sk-prompt-models`.** The framework skill no longer holds model-profile data.
- **`references/model-profiles.md` has been removed.** Its schema and adoption content are covered by `sk-prompt-models`.
- **`assets/cli-prompt-quality-card.md` no longer carries small-model guidance.** Its Tier-2 precedence wording is generic.

---

## Model Content

#### Profile Data Has a New Home

Before the move, this skill stored model profiles in `assets/model-profiles.json`. They now live at `sk-prompt-models/assets/model-profiles.json`, and no model-profile data is retained here. The advisor continues to co-surface `sk-prompt-models` alongside executor skills.

&nbsp;

#### Reference Guidance Moves With It

`references/model-profiles.md` is deleted. Its schema and adoption content are now covered by `sk-prompt-models`'s pattern-index §4 and the JSON itself.

---

## Prompt Quality Guidance

#### The Card Drops Model Guidance

Before this release, `assets/cli-prompt-quality-card.md` included a per-model-override note and a Budget-Awareness (small-model) section. The note and section are removed, and all small-model references are gone. The Tier-2 entry in its 3-tier Prompt-Composition Precedence section is now generic: it names no `sk-prompt-models` path or model. The card now contains only framework selection, DEPTH density and CLEAR scoring guidance.

---

## Upgrade Notes

- **Breaking:** Consumers who read `sk-prompt/assets/model-profiles.json` or `sk-prompt/references/model-profiles.md` must repoint to `sk-prompt-models/assets/model-profiles.json`. The JSON schema is unchanged, and all 8 active profiles resolve at the new path.
