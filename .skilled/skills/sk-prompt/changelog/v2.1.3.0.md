After the phase-013 card relocation and phase-015 path repoint, the `sk-prompt` manual-testing-playbook still depended on sibling skills. This release makes it fully forkable by removing that dependence. The playbook now tests only `sk-prompt`'s own surface, so a standalone fork runs clean.

> Spec folder: `.opencode/specs/skilled-agent-orchestration/130-prompt-knowledge-layering/016-sk-prompt-playbook-forkability-decouple/` (Level 1)

## What's New at a Glance

- **SP-023 tests the inline fast path and SP-024 tests escalation.** They previously tested the CLI prompt-quality card's fast-path and escalation thresholds, a CLI-dispatch concern that left `sk-prompt` when the card moved to the hub. SP-023 verifies that a low-complexity prompt passes the CLEAR check inline, anchored on `references/patterns-evaluation.md`, without dispatching `@prompt-improver`. SP-024 verifies that a high-risk prompt escalates to `@prompt-improver`, anchored on the `SKILL.md` §7 contract and §4 ESCALATE IF. Both `rg` steps now target files under `sk-prompt/`.
- **The playbook drops nine hub-card references.** It removes its references to `sk-prompt-models` and the relocated `cli_prompt_quality_card.md`. Source-ref rows for `SP-019` and `SP-021`, plus `SP-025` and `SP-026`, were removed as redundant with the adjacent `patterns_evaluation.md` row or repointed to `SKILL.md` §7. Card references are gone from the root playbook's coverage note and Realistic Test Model. The Global Preconditions disk-resolution list and §12/§15 descriptions also drop the card.
- **Stale and cross-skill references are scrubbed.** The root playbook's reference to the `§8 fast-path asset section`, removed from `SKILL.md` in phase 014, now points to §7. The wave-planning operational rules replace the `cli-claude-code`/`cli-codex`/`cli-opencode`/`cli-copilot` names with "available executor skills".

## Upgrade

No migration required. The two reframed scenarios keep their SP-023/SP-024 IDs. The `cli-card-five-question-fast-path.md` filename slug is retained to avoid catalog-link churn, while its title and content now describe the inline fast path.
