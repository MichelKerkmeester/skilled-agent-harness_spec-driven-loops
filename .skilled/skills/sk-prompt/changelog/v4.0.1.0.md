# v4.0.1.0, The Description Stops Claiming One Pass

A description is routing vocabulary before it is a summary. The words `in one pass` pulled research prompts that record every pass into this skill, so the description drops them and the scorer hands those prompts back to the skill that owns them.

> Spec folder: `specs/sk-prompt/010-sk-prompt-improvements` (Level 1)

&nbsp;

## What's New at a Glance

- **The description describes the work, not the round count.** A reader still learns that a request becomes a checked prompt, and the phrase that competed with a research sweep is gone.
- **A research prompt that records every pass routes elsewhere.** Those prompts were reaching this skill on the strength of that phrase, and they now reach the skill whose work they describe.
- **The router fixture runner is `benchmark/router/run-fixtures.sh`.** Its old snake-case name failed the strict package check, which wants kebab-case file names, so the script is renamed and the README command row follows it.
- **Nothing else about the skill changed.** The ten-row checklist, the effort levels and the repair cycles work as they did.
