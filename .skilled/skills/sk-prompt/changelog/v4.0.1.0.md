# v4.0.1.0, The Description Stops Claiming One Pass

A description is routing vocabulary before it is a summary. The words `in one pass` pulled research prompts into this skill. Those prompts record every pass. So the description drops the words. The scorer hands those prompts back to the skill that owns them.

&nbsp;

## What's New at a Glance

- The description describes the work, not the round count.
  - A reader still learns that a request becomes a checked prompt.
  - The phrase that competed with a research sweep is gone.
- A research prompt that records every pass routes elsewhere.
  - Those prompts were reaching this skill on the strength of that phrase.
  - They now reach the skill whose work they describe.
- The router fixture runner is `benchmark/router/run-fixtures.sh`.
  - Its old snake-case name failed the strict package check.
  - That check wants kebab-case file names.
  - So the script is renamed.
  - The README command row follows it.
- Nothing else about the skill changed.
  - The ten-row checklist works as it did.
  - The effort levels work as they did.
  - The repair cycles work as they did.

No migration required.
