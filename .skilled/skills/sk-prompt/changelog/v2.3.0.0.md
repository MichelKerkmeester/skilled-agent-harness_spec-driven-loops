This release narrows the design-generation prompt pattern to a single tool.

## What's New at a Glance

- **The `mcp-magicpath` skill is removed.** `references/design-generation-patterns.md` drops MagicPath canvas authoring. The `mcp-open-design` `start_run` usecase is unchanged and is now the reference's only usecase, which also covers the `sk-code` handoff.
- **The Open Design practices are unchanged.** The grounded anti-default brief, String Seed of Thought variation technique and pre-answer to the multi-turn discovery form are unchanged. Frameworks, DEPTH and CLEAR scoring are unchanged.
- **`DESIGN_GEN` no longer keys on `magicpath`.** In `SKILL.md`, the `INTENT_MODEL` `DESIGN_GEN` entry drops the keyword while keeping signals for open design, start_run, design generation, generate ui, canvas, design brief and variations. Design-generation routing still engages only on design-generation signals.
- **Design-generation pointers now lead to Open Design.** The design-generation use case, resource list and §9 references point to open-design only, as does the README RELATED DOCUMENTS row. The MagicPath-parallel front-loading note is removed, and the design-system-ground row drops `get-theme` while keeping `od tools design-systems read`.

## Upgrade

No migration required. Only the MagicPath usecase and keyword are gone.
