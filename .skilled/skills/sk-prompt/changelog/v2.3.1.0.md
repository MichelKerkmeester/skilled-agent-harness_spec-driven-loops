# v2.3.1.0 - README rewrite

The sk-prompt-improve README now matches the pilot README family. It replaces a reference-card layout. That layout led with tables before explaining why.

## What's New at a Glance

- **The README follows the refined README template.** It uses a one-line pitch. It uses a problem-first OVERVIEW. Sections are numbered and in ALL-CAPS, with dividers. Narrative sections name outcomes before tooling. It also has a framework capability layer.
- **The README preserves its existing content.** It covers the seven frameworks, DEPTH phases, CLEAR rubric and operating modes. It also covers the agent escalation path and quick start commands. It keeps the troubleshooting rows, FAQ answers and related document links.
- **The verification path is corrected.** It now uses `sk-prompt-improve` instead of the legacy `prompt:improve` folder name.
- **The release adds `changelog/v2.3.1.0.md`.** The README version field changes from `2.3.0.21` to `2.3.1.0`. That matches this entry.
- **The runtime contract still owns routing and workflow rules.** `SKILL.md` content and frontmatter are unchanged. So are templates, scripts, references, assets and the manual testing playbook. The README documents current state only.
