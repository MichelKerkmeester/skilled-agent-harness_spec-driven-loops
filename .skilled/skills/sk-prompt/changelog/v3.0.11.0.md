# v3.0.11.0, The Machine Router Moves to ROUTER.md

The machine router from `SKILL.md` now lives in sibling `ROUTER.md`. Its intent map, resource map, default resource, loading levels and routing pseudocode sit under the `MACHINE ROUTER` heading, after a short overview and intent model. The parsed router is identical to the previous edition, so routing remains unchanged.

&nbsp;

## What's New at a Glance

- **SMART ROUTING stays concise.** The prose in `SKILL.md` ends with one line linking to `ROUTER.md`.
- **Supporting documents follow the new path.** Testing playbooks, feature catalog entries and references that pointed to the router in `SKILL.md` now point to `ROUTER.md`.
- **RAW says it loads nothing.** `ROUTER.md` names RAW in `NO_LOAD_INTENTS = ("RAW",)` beside its empty `RESOURCE_MAP` entry, so the router check can tell the deliberate passthrough from an intent that lost its resources. RAW still skips DEPTH and every reference.
