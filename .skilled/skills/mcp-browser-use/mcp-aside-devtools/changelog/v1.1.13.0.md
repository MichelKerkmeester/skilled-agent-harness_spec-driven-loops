# v1.1.13.0, The Docs Match the Live Runs

Two alignment passes and a deep review found Aside docs that disagreed with the live runs on 1.26.626.1517. Some taught calls that throw there. Others still called settled questions unknown. This release brings them in line and records changes that shipped without a version.

&nbsp;

## What's New at a Glance

- Console and network capture are taught as gaps, not as working calls.
  - `page.on('console' | 'request' | 'response')` throws on 1.26.626.1517.
  - The capture entry now shows a guarded probe that records each event's outcome.
  - Aside's error points to `page.console.logs()`. That call has not been run.
  - HAR export is a gap with no workaround here: with no network events, there is nothing to assemble a HAR-equivalent from.
- Cookie guidance uses only what ran live.
  - Page-visible cookie names and storage keys come from `page.evaluate`.
  - `page.context()` is undefined, so context cookies and `addCookies()` are gaps.
- The evidence script now runs in one `aside repl` evaluation.
  - It opens the tab, writes `./tmp/` in the session folder and checks the file with `fs`.
  - The old `/tmp` default failed, because the REPL removes session files on exit.
  - The script has not yet been run against a live Aside.
- Settled questions are no longer marked unknown.
  - Both `-m provider/model` and `--model` with `--provider` work on 1.26.626.1517.
  - A fresh `aside mcp` process is bound when the app runs signed in.
- Smaller fixes.
  - The install check now awaits `openTab` and prints `page.url()`.
  - The doctor scenario names the full `scripts/doctor.sh` path.
  - The MCP example calls `aside.aside_repl` without top-level `await`.
  - The screenshot and PDF example writes inside the session folder and checks bytes in place.
  - The playbook root no longer hand-types its scenario count.

&nbsp;

## Upgrade

Do not script `page.on` capture or `page.context()` cookies on Aside 1.26.626.1517.

The evidence script's second argument must now stay under `./tmp`. An absolute path is rejected.

The screenshot does not survive the run. Keep the logged JSON line as the evidence.
