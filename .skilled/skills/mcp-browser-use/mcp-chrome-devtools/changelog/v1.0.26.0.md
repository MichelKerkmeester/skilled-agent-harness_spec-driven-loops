# v1.0.26.0, Moved Into the Browser Hub

The packet now lives at `.skilled/skills/mcp-browser-use/mcp-chrome-devtools/`. It used to sit under `mcp-tooling`. The move used `git mv`, so its history came with it.

&nbsp;

## What's New at a Glance

- The mode id is still `mcp-chrome-devtools`. Its content did not change in the move.
- The advisor reaches it through the `mcp-browser-use` hub, not `mcp-tooling`.
- Every path that named the old folder was rewritten.
  - That covers the pre-commit hook, the mutation-class guard and its manifest and the installer tests.
  - It also covers the Code Mode and sk-doc references.
- Its changelog is linked from `.skilled/changelog/mcp-browser-use/mcp-chrome-devtools`.
