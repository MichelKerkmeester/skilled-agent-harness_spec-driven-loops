# v1.0.18.0, The Script Count Names Its Folder

Two README lines failed their checks for different reasons. The headless-mode line said "all three scripts" and named no folder. So the count check had nothing to count against. The reference check read `performance-baselines/` as a repository folder. It found none.

The count now reads "all three scripts under `examples/`". Those are the same three scripts the bullets above it name. So the check counts the folder itself. `performance-baselines/` is declared in the `readme-check` block. It is the output folder for `performance-baseline.sh`. The script writes its timestamped metrics, HAR, screenshot and console logs there. That is what it always was.

&nbsp;

## What's New at a Glance

- The three-script claim is provable.
  - The sentence names `examples/`.
  - So the count is checked against the folder.
  - The count does not pass unchecked.
- The baseline output folder is declared.
  - One `allow-ref` entry says the script creates the folder.
  - The repository does not hold it.
- The README edition is raised.
  - The body changed.
  - So its own edition moves with it.
