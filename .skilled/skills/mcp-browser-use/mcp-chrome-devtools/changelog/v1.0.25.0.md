# v1.0.25.0, Lighthouse and Performance Trace Get a Catalog Leaf

The router sent Lighthouse requests to this packet, but the feature catalog had no entry for them. The capability was real: `lighthouse_audit` is a registered Chrome DevTools MCP tool. The catalog simply never named it.

&nbsp;

## What's New at a Glance

- A new leaf names the two audit families.
  - `feature-catalog/mcp-parallel-instances/lighthouse-and-performance-trace.md` covers `lighthouse_audit` and `performance_start_trace` / `performance_stop_trace` / `performance_analyze_insight`.
  - It says Lighthouse excludes performance, so Core Web Vitals go to the trace tools.
  - It says both run in the MCP lane only, because `bdg` ships no Lighthouse command.
- The catalog counts it.
  - MCP Parallel Instances reads 7 and the Feature Count Summary totals 31.
- The hub router loads it.
  - A Lighthouse or performance-trace request loads this leaf through the hub's stage-two map.
