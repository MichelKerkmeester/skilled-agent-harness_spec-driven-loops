# v1.0.15.0, Safe JSON Helper Values

v1.0.15.0 stops the shared install helpers from pasting values into embedded Python source. So quotes and backslashes stay data.

&nbsp;

## What's New at a Glance

- `scripts/_utils.sh` passes values to Python as arguments.
  - The JSON helpers built Python source from shell values.
  - So a path or value with a quote broke the script or ran as code.
  - The JSON helpers now read the values from `sys.argv`.
- `scripts/_utils.sh` catches only the errors it expects.
  - The bare `except:` clauses now catch read and parse errors.
  - The clauses let interrupts through.
- `backup_file` no longer masks a failing command.
  - Its declaration and assignment are split.
- The JSON helpers work without their optional arguments.
  - The args and env defaults kept their quotes, `'[]'` and `'{}'`.
  - No JSON parser reads those.
  - The defaults are now plain `[]` and `{}`.
- The file stays byte-identical to the `mcp-code-mode` copy.
  - The installer test checks that.

&nbsp;
