# v1.0.27.0, the dom eval Port Note

In bdg 0.6.10, `bdg dom eval` only finds the session's tab when the session runs on port 9222. On any other port it exits with code 83 and prints `Session target not found`, even though the tab is open. The troubleshooting guide now names that error and says what to do.

&nbsp;

## What's New at a Glance

- A new entry in `references/troubleshooting.md` §6 shows the error, its cause and a check for the session's port.
- The first fix starts the session without `-p`, so it uses 9222, when that port is free.
- The second fix reads page values with `bdg cdp Runtime.evaluate --params '{…,"returnByValue":true}'`, which works on any session port.
- The guide is now version 1.0.5.0 and adds "session target not found" to its trigger phrases.
