# v1.0.27.0, the dom eval Port Note

bdg 0.6.10 has a port defect in `bdg dom eval` and in the form commands `dom click`, `dom fill`, `dom submit` and `dom pressKey`. They find the session's tab only on port 9222. On any other port they exit with code 83. They print `Session target not found`, yet the tab is still open. The troubleshooting guide now names that error. It also says what to do.

&nbsp;

## What's New at a Glance

- A new entry in `references/troubleshooting.md` §6 shows the error and its cause. It also shows how to check the session's port.
- The first fix starts the session without `-p` when 9222 is free. The session then uses 9222. It is the only fix for the form commands, which take no `-p` option.
- The second fix reads page values with `bdg cdp Runtime.evaluate --params '{…,"returnByValue":true}'`. That works on any session port. It reads values only and gives no route for a click or a fill.
- The guide is now version 1.0.5.0. Its trigger phrases now include "session target not found".
