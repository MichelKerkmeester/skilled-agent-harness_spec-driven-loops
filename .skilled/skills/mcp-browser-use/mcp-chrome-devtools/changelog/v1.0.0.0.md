This first release gives the team a shared way to use browser developer tools from AI workflows. It covers everyday browser checks, visual capture and troubleshooting in one package.

&nbsp;

## What's New at a Glance

- Two routes cover different browser jobs.
  - The lightweight command-line path suits routine tasks.
  - The fuller integration path handles more complex workflows.
  - So people can choose the simplest route without extra setup every time.
- One skill bundles common browser actions.
  - Common testing and debugging tasks were spread across separate tools and notes.
  - The skill brings page control, clicks, screenshots, network checks, console viewing and storage access together.
  - That covers most browser work operators do day to day.
- Starter guides support setup and use.
  - The main guide and install help give new users clear setup and usage instructions.
  - That comes before they can trust the workflow.
  - Focused notes cover common browser patterns.
  - This helps new users get started faster.
  - New users can find details without digging through code.
