# v1.0.28.0, the Docs Match bdg 0.6.10

Many commands in this packet failed on bdg 0.6.10. The docs, examples and setup scripts now match its real behavior. The installer also stops pulling the moving `alpha` tag. It now installs 0.6.10, the version the docs describe.

&nbsp;

## What's New at a Glance

- bdg is pinned at 0.6.10.
  - `install.sh` and every install line in the docs name `browser-debugger-cli@0.6.10`.
  - The `alpha` tag now points at 0.7.2 and `latest` at 0.23.0.
  - `doctor.sh` warns when the installed bdg is a different version.
  - It compares the whole version token, so 0.6.100 no longer passes as 0.6.10.
- `bdg cdp` takes its JSON through `--params`.
  - bdg 0.6.10 rejects JSON as a second argument with `too many arguments`.
  - Every doc and example script now uses the `--params` form.
- Code Mode examples drop the top-level `await`.
  - Code Mode rejects it, and tool calls return their result directly.
  - Parallel testing drives each isolated browser one call after another.
- The example scripts count console errors again.
  - They save output with `bdg console --list --json`.
  - They read errors from `.messages[]` where `type` is `error`.
  - A console error now fails a viewport in the viewport matrix.
- `install.sh` finds Chrome on macOS again.
  - It checked the wrong platform name, so it never found Chrome there.
  - It now needs Node.js 20, as bdg 0.6.10 does.
  - Its install hint for a missing Node.js names that same minimum.
  - It counts CDP domains with `bdg cdp --list` and logs 53.
- The port defect covers more commands.
  - `dom click`, `dom fill`, `dom submit` and `dom pressKey` also look for the tab on port 9222 only.
  - These form commands take no `-p` option, so the only fix is a session on 9222.
- The docs give the real `bdg status --json` shape.
  - It has no `state` key. It always carries `version` and `active`.

&nbsp;

## Upgrade

Run `bdg --version`. If it is not 0.6.10, run `npm install -g browser-debugger-cli@0.6.10`. `install.sh` keeps an existing bdg unless you pass `--force`.
