# v1.2.1.0, Gated npx Path and Verified Launcher

A deep review found that the lane rule still offered an unpinned `npx` launch. It also found that the installer ran unchecked code. This release closes both gaps.

&nbsp;

## What's New at a Glance

- The lane rule no longer offers `npx -y bladebro mcp` when the binary is missing.
  - A missing binary now routes to the operator-yes install through `scripts/install.sh`.
  - Every remaining `npx` mention names `bladebro@4.8.2` and says it is an install that needs an operator yes.
- `scripts/install.sh` runs `npm install -g --ignore-scripts bladebro@4.8.2`.
  - No lifecycle script runs before the digests are checked. The pinned release declares none.
  - It now checks the two JS launcher files, `bin.js` and `binary.cjs`, as well as the native binary.
  - Every check runs before `--version` first runs installed code.
  - The install playbook scenario and the install catalog entry name the same `--ignore-scripts` command and the launcher digests.
  - A missing file or a mismatch removes the install and exits 1, as the binary check already did.
- `scripts/doctor.sh` checks the same launcher digests read-only.
  - It reads the installed version from the package manifest, so no `bladebro` call runs before the digests are checked.
  - A mismatch on 4.8.2 exits 1 before any `bladebro` call. On another version it only warns.
  - A standalone binary skips the launcher check.
- BB-015 states its browser precondition.
  - Branded Google Chrome 136 and later refuses remote debugging on its default data directory.
  - Use the Aside browser, Chromium, Chrome for Testing or a signed-in non-default `--user-data-dir`.
  - A new triage row covers a closed port on branded Chrome.
- The packet's routing prose names `bladebro rb` and a caller-owned or already-open browser, matching the narrowed hub aliases. Bare `rb attach` no longer selects this mode.
- The ClickUp run report says its raw output was not retained. Its verdicts and tally are unchanged.

&nbsp;

## Upgrade

No migration required. Run `bash scripts/doctor.sh` to check the launcher digests on an existing install.
