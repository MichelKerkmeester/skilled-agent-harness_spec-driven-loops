# v1.1.0.0, Bladebro Mode Packet

The placeholder is gone. The packet now says when to use the Bladebro CLI. It says when to fall back to the MCP server through Code Mode. It names the browser lane to drive. It hands known gaps to the sibling modes. It lists the actions to refuse.

&nbsp;

## What's New at a Glance

- The lane rule picks the CLI first.
  - The MCP server through Code Mode is the fallback.
- Browser lanes are documented.
  - The default agent browser uses its own profile.
  - Real-browser lanes run only on an explicit operator request.
- Limits name the sibling mode that covers each gap.
- Three safety rules are quoted word for word.
  - Stealth runs need operator authorization.
  - No stealth run has been made from this packet.
- Four reference leaves cover the CLI, browser lanes, MCP wiring and install checks.
- The root `.utcp_config.json` gains a `bladebro` stdio manual.
- The packet is pinned to upstream Bladebro v4.8.2.
  - Upstream released v4.8.3 the next day.
  - That release changed no docs and no flag this packet quotes.
  - The pin stays v4.8.2 because the safety rules name it.
- Upstream reports 68 of 80 protected sites passed its stealth bench.
  - That figure measures anti-bot evasion, not task completion.

&nbsp;

## Upgrade

No migration required. Install Bladebro before using the CLI lane.
