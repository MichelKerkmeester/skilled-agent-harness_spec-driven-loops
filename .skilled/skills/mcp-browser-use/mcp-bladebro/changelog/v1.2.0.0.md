# v1.2.0.0, Install Guide, Manual Asset and Scripts

Bladebro now has the same setup surface as Aside and Chrome DevTools. Its docs also say what the live run found, not what upstream promised.

&nbsp;

## What's New at a Glance

- `scripts/install.sh` installs the pinned release.
  - It runs `npm install -g bladebro@4.8.2` only after an operator yes.
  - It checks the native binary against the recorded SHA-256 digest.
  - On a mismatch it removes the install and exits 1.
  - It refuses every platform without a recorded digest.
  - It leaves an existing install alone and never runs `npm update`.
- `scripts/doctor.sh` is read-only.
  - Every call runs with `BLADE_NO_UPDATE_CHECK=1`, a switch in the binary itself.
  - So `--version` and `bladebro doctor` never reach the release registry.
  - It checks the version, the digest, a stdio MCP handshake and the registered manual.
  - A live run printed `✓ tools/list: act, see, state, run, vision` and exited 0.
- The mutation-class guard covers both scripts. Its manifest gained a `mcp-bladebro` row.
- `assets/utcp-bladebro-manual.md` holds the manual JSON, byte-true to `.utcp_config.json`.
  - `references/mcp-wiring.md` links to it instead of copying it.
  - The router loads it for MCP intent.
- `INSTALL-GUIDE.md` walks the install through the scripts.
  - It keeps the pin and digests in `references/install-and-verify.md`.
  - It warns that only the arm64 digest has matched an installed binary.
- The live macOS run is now in the docs.
  - Install, MCP and every agent-browser probe passed.
  - Real-browser reads in `clone` mode failed with the Aside binary.
  - Attaching to a running Aside passed 3 of 3.
  - The operator chose to keep Bladebro installed, so the uninstall step stays skipped.
  - Code Mode calls must be synchronous.

&nbsp;

## Upgrade

No migration required. Run `bash scripts/doctor.sh` from the packet to check an existing install.
