# v1.0.0.0, Browser Use Hub With Three Modes

`mcp-browser-use` gives the browser tools one advisor identity. Chrome DevTools and Aside used to sit inside a broader tool hub. Bladebro had no home at all. The three mode packets are placeholders in this release.

&nbsp;

## What's New at a Glance

- The hub resolves one `workflowMode` for each request.
- Generic browser-automation phrasing defers. The hub then asks which mode you mean.
- All three modes are workflow packets on the `cli-plus-mcp` backend.
- Each mode routes by hub membership.
- The hub `SKILL.md` names the three modes in its mode table.
- The root `ROUTER.md` starts in the `stage1-only` state. Stage one owns every routing decision.
- Each placeholder has a status leaf with its own file name. Shared leaf names would make the generated manifest treat the modes as duplicates.

&nbsp;

## Upgrade

No migration required. The mode content arrives in later releases.
