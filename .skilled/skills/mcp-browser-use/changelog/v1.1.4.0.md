# v1.1.4.0, A Mode Named by Its Short Name Stays in the Bundle

The second follow-up review found that v1.1.3.0 fixed the three-id bundle but not the general case. "use mcp-chrome-devtools and bladebro" routed to Chrome DevTools alone, because the full id also contains the alias "chrome devtools" and counted twice. It also found Aside install docs that still piped the vendor script into bash, an Aside request in plain prose that deferred, and a front-door instruction that put the user's task inside a double-quoted shell argument.

&nbsp;

## What's New at a Glance

- The hub router counts a keyword once when it sits inside a longer keyword the prompt also matched. A mode named by its id and a mode named by its alias now score alike.
  - "use mcp-chrome-devtools and bladebro" and "use mcp-bladebro and aside browser" route as ordered bundles.
  - The canary corpus gains `mixed-id-and-alias-bundle`, which fails without the change, and `aside-in-prose`.
- `in aside` joins Aside's vocabulary, so "open it in aside" routes to Aside. "set that aside" and "as an aside" still defer.
- Every Aside install surface points at `scripts/install.sh`, which checks the pinned installer digest: the install guide, the Aside and server READMEs, the feature catalog, `SKILL.md`, troubleshooting, the doctor hint and the missing-binary playbook scenario.
- `SKILL.md` and the hub playbook pass the task to the front door on stdin through a quoted heredoc, so a quote, `$()` or backtick in the task is never run.
- The bdg Node fix installs Node 20, matching the Node 20 requirement above it.

&nbsp;

## How It Was Checked

The replay under `benchmark/reports/compiled-routing/2026-11-24--two-stage-replay--compiled--second-follow-up/` passes 55 of 56 rows. Every out-of-domain prompt scores 0 for the hub at the advisor stage. MBU-PB-04 still gets no advisor recommendation.

&nbsp;

## Upgrade

No migration required. The activation manifest was re-minted. The `ROUTER.md` machine-router callout keeps its `--prompt "<task>"` form, because the fleet-wide lockstep check pins that wording across every hub.
