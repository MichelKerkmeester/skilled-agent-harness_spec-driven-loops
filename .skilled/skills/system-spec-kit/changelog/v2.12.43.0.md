# v2.12.43.0, per-file ripgrep flood control

The ripgrep wrapper now spreads structured search results across files. Each returned row is the file's highest-ranked match. The report shows what the file limit hides.

> Spec folder: `specs/hooks-plugins-extensions/028-sweet-search-integration/006-rg-flood-control`

&nbsp;

## What's New at a Glance

- **Each file contributes its highest-ranked match.** JSON adds `moreInFile`. Human rows show `(+N more in this file)` when matches were collapsed.
- **The file limit is adjustable.** `--limit` defaults to 20 files. `--limit 0` includes every matching file. Human output names dropped files and matches in its tail.
- **Hidden results stay measurable.** JSON uses `schemaVersion: 2`. The record includes `matchCount` and `fileCount`. The `hidden` object carries file and match totals. It also includes `limit` and `truncated`.
- **The unused capped recipe builder is gone.** It stopped each file at its earliest matching line rather than its best-ranked one, and nothing called it. The retrofit baseline now counts every match through `matchCount`.
