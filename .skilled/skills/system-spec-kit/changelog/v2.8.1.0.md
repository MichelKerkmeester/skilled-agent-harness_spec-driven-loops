# v2.8.1.0, The Setup Check Works in Every Runtime

`/doctor:setup` ran its sk-git leg without naming the AI tool, so on any runtime but Claude Code a healthy install came back as FAIL. It now names the tool and reads the answer the way `/doctor:git setup` does.

> Spec folders: `specs/system-skill-advisor/035-doctor-command-routing` (Level 2) and `specs/sk-git/033-git-setup-customization/008-out-of-scope-cleanup` (Level 1)

&nbsp;

## What's New at a Glance

- **A healthy install passes outside Claude Code.** The sk-git leg passes `--tool` for Codex, Pi, OpenCode, Cursor and Devin, and runs without it on Hermes.
- **DEGRADED is not a failure.** When the sk-git check ends DEGRADED, the leg shows DEGRADED and names `/doctor:git setup`, instead of failing the run. The verdicts are now PASS, FAIL, DEGRADED and SKIP.
- **What the run writes is stated exactly.** It writes nothing in the repository. The advisor CLI creates `/tmp/system-skill-advisor` when it is missing.
- **A stale advisor build is caught.** The doctor phrase-reach probe exits 2 when the built scorer is older than its source, instead of reporting OK on old code.

&nbsp;

## Upgrade

No migration required. Run `/doctor:setup` again from the runtime you use.
