# v2.12.2.0, Two CI Gates Go Green on Main

Two CI gates failed on main after the weak-model authoring work landed: changed-packet validation graded benchmark copies kept under `scratch/`, and the routing divergence ratchet saw `/deep:research :auto` prompts go to spec-kit. This patch fixes both at the source and clears the docs findings from the same audit.

> Spec folder: `specs/system-speckit/054-weak-model-spec-authoring/021-ci-gate-regressions` (Level 2)

&nbsp;

## What's New at a Glance

- **Changed-packet validation skips `scratch/`.** A `spec.md` under a packet's `scratch/` folder is evidence, not a packet, so the gate no longer grades it, as the validator's own discovery never has. A packet whose name only contains the word scratch is still graded.
- **`/deep:research :auto` routes to deep-loop again.** The advisor phrase `draft auto-repair` gave spec-kit the token `auto`; it is now `spec docs`, and the compiled skill graph is rebuilt.
- **The authoring card passes the document validator.** It gained section separators and an `OVERVIEW AND BOUNDS` heading, with no wording change to any step.
- **Level docs call `decision-record.md` a lazy add-on.** The validation rules, the path-scoped rules, the level guide and `validate.sh --help` match what a Level 3 scaffold creates.
- **Lint stops counting build output.** ESLint ignores every `dist/` folder, not only the top-level one.

&nbsp;

## Upgrade

No migration required. No validation rule changed, so every packet keeps its verdict. A prompt that names Draft auto-repair without naming the spec packet may now rank another skill first.
