# v2.12.2.0, Two CI Gates Go Green on Main

Two CI gates failed on main. This came after the weak-model authoring work landed. Changed-packet validation graded benchmark copies kept under `scratch/`. The routing divergence ratchet saw `/deep:research :auto` prompts go to spec-kit. This patch fixes both at the source. It also clears the docs findings from the same audit.

&nbsp;

## What's New at a Glance

- Changed-packet validation skips `scratch/`.
  - A `spec.md` under a packet's `scratch/` folder is evidence, not a packet.
  - So the gate no longer grades it.
  - The validator's own discovery never has.
  - A packet whose name only contains the word scratch is still graded.
- `/deep:research :auto` routes to deep-loop again.
  - The advisor phrase `draft auto-repair` gave spec-kit the token `auto`.
  - The advisor phrase is now `spec docs`.
  - The compiled skill graph is rebuilt.
- The authoring card passes the document validator.
  - It gained section separators and an `OVERVIEW AND BOUNDS` heading.
  - No step changed its wording.
- Level docs call `decision-record.md` a lazy add-on.
  - The validation rules, the path-scoped rules, the level guide and `validate.sh --help` match what a Level 3 scaffold creates.
- Lint stops counting build output.
  - ESLint ignores every `dist/` folder, not only the top-level one.

&nbsp;

## Upgrade

No migration required. No validation rule changed. So every packet keeps its verdict. A prompt that names Draft auto-repair without naming the spec packet may now rank another skill first.
