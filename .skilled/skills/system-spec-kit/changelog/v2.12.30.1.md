# v2.12.30.1, Decision Routing Stops Taking Other Skills' Requests

A follow-up to v2.12.30.0 added "decision capture" and "chat candidate" to the DECISION routing intent. Any request that named the feature then went to spec-kit. That included a request to research it. It also included a request to dispatch it to a CLI. Or a request to build a component for it.

Both phrases are replaced with four narrower ones. They are "decision capture queue" and "decision capture folder". The other two are "decision capture state" and "this chat candidate".

&nbsp;

## What's New at a Glance

- Other skills get their requests back.
  - "Dispatch this decision capture work to the Claude Code CLI" routes to the CLI skill again.
  - "Research how other tools handle decision capture" no longer routes to spec-kit.
  - So does "Add a chat candidate list component".
- Requests about the feature's own objects still reach spec-kit.
  - "Which folder holds the decision capture state for this project?" reaches spec-kit through the new phrases.
  - So do "Clear the answers left in the shared decision capture folder".
  - And "Why did the save skip this chat candidate?".
  - "Record this as a decision" routes through the original four.
  - Show and list questions about the queue reach spec-kit through system-skill-advisor v0.18.1.0.
- The hook core and the save agree on the project folder.
  - Both now ask git for the project root.
  - They do it with the file-system monitor turned off.
  - Before, only the save did.
  - So a stalled monitor could send the hook to a different answer folder.
  - That folder was not the one the save reads.
- The off switch is documented.
  - `SYSTEM_DECISION_CAPTURE_DISABLED` is now in `.env.example`, `hook-flags.env.example` and the runtime env reference.
  - Every capture hook and plugin already read it.
  - None of them listed it.
- Playbook checks catch a failed folder lookup.
  - The live-conversation and sibling re-proof playbooks now require an absolute path.
  - That path is the answer folder.
  - So a lookup that prints `undefined` stops the check.
  - The transcript-sweeps scenario lists the chat-candidate evidence rows in its pass criteria.
- Tests cover the older answer folder.
  - A session-stop test seeds answers in the shared root folder.
  - Saves used that folder before folders were per project.
  - The nudge counts them.
  - The test that seeds the project folder fails when its temp folder sits inside a git checkout.
  - Otherwise that would point it at that checkout's live answers.

&nbsp;

## Upgrade

No migration required.
