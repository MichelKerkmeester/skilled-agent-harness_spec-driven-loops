A post-release hardening pass on v3.2.0.0. It hardens graph enrichment and compact recovery, gives session bootstrap the full resume payload and trims duplicate-detection I/O through file-size pre-filtering. It also restores shared-package resolution after a broken symlink.

> Spec folder: `.opencode/specs/system-spec-kit/023-hybrid-rag-fusion-refinement/` and `.opencode/specs/system-spec-kit/024-compact-code-graph/`

## Why This Release

The goal is a workflow that is easier to follow and easier to trust.

## What's New at a Glance

- **Graph enrichment now rejects paths that escape the workspace root.** Escaping paths are rejected before file-system operations.
- **Compact-recovery sanitization catches more prompt-injection patterns.** The sanitizer strips more system-instruction lines from recovered transcripts.
- **`SPECKIT_VRULE_OPTIONAL` no longer bypasses memory quality validation.** Validation always runs or reports when unavailable.
- **Graph query results include the resolved `edgeType`.** The result shows which filter was applied.
- **`session_bootstrap` now returns the full resume payload.** The response reports completeness as `'full'` instead of `'minimal'`.
- **Server instructions recommend `session_bootstrap`.** They point to the main composite helper instead of the session resume helper.
- **The compact-recovery description is corrected.** It now says `cached compact brief` instead of `3-source merge (Memory + Code Graph + CocoIndex)`.
- **Duplicate detection pre-filters candidates by file size.** It checks recent files before hashing them.
- **Explicit session IDs pass through the workflow.** A supplied ID is no longer silently replaced by a generated one.
- **The shared package's broken symlink is fixed.** The package can resolve again.

## Security

#### Paths Cannot Escape the Workspace

`normalizeGraphFilePath` checks that the resolved path stays inside the workspace root. Paths that escape through `../` or absolute jumps are rejected before any file-system operation.

&nbsp;

#### Recovery and Validation Resist Abuse

The compact-recovery sanitizer strips system-instruction lines from recovered transcripts. It now catches more patterns than the single regex previously covered:

- `[developer]:`
- `Role:`
- `Ignore previous instructions`
- `## Instructions`
- Markdown headings that name system roles.

The `SPECKIT_VRULE_OPTIONAL` environment variable could skip memory quality validation entirely. That escape hatch is gone, so validation always runs or reports when unavailable.

---

## Code Graph

Query-time graph reads no longer trigger write-path indexing.

#### Edge Filters Follow the Request

The resolved edge filter comes from the explicit `edgeType` argument or falls back to the operation prefix. The `calls_*` prefix resolves to `CALLS`, while `imports_*` resolves to `IMPORTS`.

---

## Session Recovery

#### Bootstrap Carries Full Context

Previously, `session_bootstrap` passed `minimal: true` to `session_resume`, which stripped useful context. It now returns the full resume payload and reports completeness as `'full'` instead of `'minimal'`.

&nbsp;

#### Recovery Instructions Point to Bootstrap

The recovery hint in server instructions previously pointed to the session resume helper. It now recommends the main composite tool, `session_bootstrap`.

&nbsp;

#### Recovery Text Matches Its Content

The earlier description was `3-source merge (Memory + Code Graph + CocoIndex)`, which was inaccurate. The instruction now calls the content a `cached compact brief`.

---

## Saving Memories

#### Memory Saves Reduce I/O and Preserve IDs

Overlap detection previously read up to 20 prior context files and hashed each one. It now checks the 12 most recent candidates and skips a full hash when file size does not match the new content's byte length. This preserves correctness with less I/O.

When the caller provides an explicit session ID, it propagates through the workflow into the session-data collector instead of being replaced by a generated one.

---

## Package Resolution

#### The Shared Package Resolves

The shared package could not resolve because its symlink was broken. The link now points to relative `../shared/dist` instead of the broken absolute target, allowing the package to resolve.

## Upgrade Notes

No upgrade needed. All changes are backward-compatible.
