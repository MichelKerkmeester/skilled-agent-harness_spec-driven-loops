This release adopts the spec-folder authoring docs into system-spec-kit, relocated from sk-code into their proper home. Spec-folder authoring is system-spec-kit's domain.

## What's New at a Glance

- **The spec-folder write recipe is now part of system-spec-kit.** `references/workflows/spec-folder-write-recipe.md` is the step-by-step recipe for writing a new spec folder that satisfies `validate.sh --strict` on the first try.
- **The companion authoring checklist comes with it.** `references/workflows/spec-folder-authoring-checklist.md` covers the Level contract, `_memory.continuity` frontmatter, metadata files and strict validation.
- **Both docs are indexed.** The SKILL RESOURCE_MAP lists them under the COMPLETE intent.
- **`/speckit:complete` loads the authoring docs from their new home.** Its authoring-time cross-skill load now sources the spec-folder recipe and checklist from system-spec-kit directly rather than from sk-code.
- **The docs leave sk-code.** sk-code keeps only a cross-reference pointer for implementers routed there.

## Upgrade

No migration required.
