# v2.12.3.0, The Dist-Freshness Test Survives a Path With Spaces

The dist-freshness test cleared its cache files through an unquoted glob held in a variable, which splits on spaces and fails in a checkout whose path contains one. It now keeps the cache folder in a variable and quotes it, so the same files are removed wherever the repository sits.

> Spec folder: `specs/sk-code/015-quality-agnostic-gate` (Level 2)

&nbsp;

## What's New at a Glance

- **The cache cleanup is quoted.** The test removes the runtime-scoped cache files from the validation folder under the runtime build, with the folder path quoted.
