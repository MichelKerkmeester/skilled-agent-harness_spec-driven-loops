# v2.12.3.0, The Dist-Freshness Test Survives a Path With Spaces

The dist-freshness test cleared its cache files through an unquoted glob. The glob sat in a variable. It splits on spaces. So the test failed in a checkout whose path contains one. The test now keeps the cache folder in a variable and quotes it. The same files are removed wherever the repository sits.

&nbsp;

## What's New at a Glance

- **The cache cleanup is quoted.** The test removes the runtime-scoped cache files from the validation folder. That folder sits under the runtime build. The folder path is quoted.

No migration required.
