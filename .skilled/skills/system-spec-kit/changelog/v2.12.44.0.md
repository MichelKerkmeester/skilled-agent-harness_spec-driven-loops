# v2.12.44.0, the search command runs the ripgrep wrapper

`/speckit:search` now gets the per-file flood control that v2.12.43.0 gave the ripgrep wrapper. A common phrase returns 20 ranked files and a count of what the limit hides.

> Spec folder: `specs/hooks-plugins-extensions/028-sweet-search-integration/007-search-routing-followups`

&nbsp;

## What's New at a Glance

- **The default free-text lane runs the wrapper.** `/speckit:search` runs `rg-wrapper.mjs structured '<QUERY>' --json`. On the phrase `trigger index` that is 20 rows where the raw recipe printed 2,614 match lines.
- **The raw recipe is the exception.** The wrapper reads a phrase that starts with `--` as a flag and exits 2, so the command runs the Section 2.1 recipe for that phrase. The path-only, count and context modes still run their recipe directly.
- **Spec-doc search prompts route here.** `intent_signals` gains `spec docs`, `spec and skill docs`, `ripgrep retrieval` and `ripgrep wrapper`. A prompt that asks to search the spec and skill docs now ranks `system-spec-kit` first.
