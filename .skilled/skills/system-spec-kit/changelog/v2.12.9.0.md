# v2.12.9.0, The Mirror Orphan Skip Has a Test

The runtime mirror sync skips a private `local-*` entry when it looks for orphans to report or prune, but nothing tested that skip. A regression would have reported, or with a write run deleted, a private entry. It now has a test.

> Spec folder: `specs/sk-code/013-private-surface-skills/009-alignment-fixes` (Level 2)

&nbsp;

## What's New at a Glance

- **`findOrphans` is exported.** It takes an optional root, and the script runs its entry point only when invoked directly, so the CLI behaves as before.
- **`sync-runtime-mirrors.test.mjs` pins the skip.** It checks that an unexpected entry is an orphan and that a private file or link is not.
