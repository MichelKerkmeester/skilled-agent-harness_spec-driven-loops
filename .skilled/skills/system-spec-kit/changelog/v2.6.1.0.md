# v2.6.1.0, Tests Under tests/ and a Documented Runtime

Spec-kit's code is now easier to find your way around. Every file in the runtime carries a module header. So does every file in the shared package. Long files are split into numbered sections. Every code folder has a README. Every test now sits under a `tests/` tree. It no longer sits beside its source. The completion-evidence sentinel moved next to the other hook helpers. No behavior changed.

## What's New at a Glance

- **The completion sentinel now lives in `hooks/lib/`.** Its five runtime adapters import it from there. The Pi extension and the OpenCode plugin do too.
- **Tests sit under `tests/` everywhere.** The shared package's tests moved to `shared/tests/`. The hook tests moved to `runtime/tests/hooks/`. Golden snapshots moved to `cli/tests/snapshots/`.
- **No double-underscore folders remain.** `__helpers__` became `helpers`. `__fixtures__` became `fixtures`. `__snapshots__` became `snapshots`.
- **A profile test checks what it claims.** Its source-file paths had never resolved. So it always took its fallback. It now reads the real file. Its checks pass.

Repoint any out-of-tree import of `runtime/lib/hooks/completion-evidence-sentinel.cjs` to `runtime/hooks/lib/completion-evidence-sentinel.cjs`.
