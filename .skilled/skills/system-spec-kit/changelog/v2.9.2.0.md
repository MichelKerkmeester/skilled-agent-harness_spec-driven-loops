# v2.9.2.0, Embeddings Fail Fast and Private Skills Stay Local

Local embedding calls stop waiting on a model server that nothing can start. This release also keeps operator-private skills out of the Hermes mirror. It corrects the `/speckit:complete` guidance.

&nbsp;

## What's New at a Glance

- Embedding calls give up after about five seconds when no model server can start.
  - In that case the client does not wait out the default ready timeout.
  - That timeout is 45 seconds.
  - The error tells you to restart or reconnect the owning MCP server.
- Private skills stay out of the Hermes mirror.
  - The Hermes mirror is a tracked copy of the skills.
  - The mirror now skips every top-level operator-private skill, whether a folder or a symlink.
- The completion guidance matches the current layout.
  - `/speckit:complete` no longer names the removed Webflow route.
  - `/speckit:complete` now says it is not for targets outside `.skilled/`.
  - `/speckit:complete` is also not for targets a private skill owns.

&nbsp;
