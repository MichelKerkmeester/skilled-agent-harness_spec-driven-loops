# v2.9.2.0, Embeddings Fail Fast and Private Skills Stay Local

Local embedding calls stop waiting on a model server that nothing can start. This release also keeps operator-private skills out of the Hermes mirror and corrects the `/speckit:complete` guidance.

&nbsp;

## What's New at a Glance

- **Embedding calls give up after about five seconds when no model server can start.** The client does not wait out the 45 second default ready timeout in that case. The error tells you to restart or reconnect the owning MCP server.
- **Private skills stay out of the Hermes mirror.** The Hermes mirror is a tracked copy of the skills. It now skips every top-level operator-private skill, folder or symlink.
- **The completion guidance matches the current layout.** `/speckit:complete` no longer names the removed Webflow route. It now says it is not for targets outside `.skilled/` or for targets a private skill owns.

&nbsp;

No migration required.
