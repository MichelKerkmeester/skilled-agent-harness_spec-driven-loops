# v2.8.2.0, The Setup Check Names a Stale Advisor

`/doctor:setup` treated every advisor exit 75 as a harmless SKIP. But the advisor also exits 75 when its build is stale. That is the moment every prompt's routing breaks. The advisor check now tells those cases apart.

&nbsp;

## What's New at a Glance

- **A stale advisor build fails.** The advisor check reports FAIL and names the build command. That replaces a SKIP that reads as healthy.
- **The other advisor states are named.** A stopped daemon is SKIP. A skill graph that is not live is DEGRADED.
- **A crashed sk-git check is ERROR.** It is no longer reported as an ordinary FAIL. On Hermes the sk-git check now runs with `--tool=hermes`.
- **The docs give working commands.** Every `advisor_status` example passes `--workspace-root`. The README Quick Start and spec-kit docs list `/doctor:setup`.
- **Short spec-kit prompts route here.** The prompts "env vars", "runtime mirrors", "resume spec" and "validate spec" now reach system-spec-kit instead of nothing.

&nbsp;

## Upgrade

No migration required. Rebuild the advisor runtime. Then rerun `/doctor:setup`.
