# v2.14.0.0, The Shared Modules Drop the Retired Advisor Lane

The skill advisor retired its embedding scoring lane. This release removes the shared code only that lane used. A new check fails CI when the lane's names come back.

&nbsp;

## What's New at a Glance

- The shared embedding package is gone.
  - It chose an embedding provider and built it for the advisor.
  - Its provider adapters, profiles and registry left with it.
- Two shared helpers left with it.
  - `shared/chunking.ts` held the text length limits for embedding.
  - `shared/utils/retry.ts` retried failed provider calls.
- `package.json` no longer lists the transformers package.
  - Its `sharp`, `protobufjs` and `@protobufjs/utf8` version pins went with it, since nothing else installs those packages.
- `runtime/cli/retrieval/sweep-lane-residue.mjs` finds what the lane left.
  - `repo` lists tracked files outside `specs/` that still name the lane.
  - `machine` lists what the lane left on this machine.
  - `apply` deletes what this checkout owns. It asks before it deletes the pulled shared model.
  - `fixtures/lane-residue-allowlist.json` names the exact files allowed to keep lane names.
- CI runs `repo` as the blocking `lane-residue` job in `advisory-checks.yml`.
- `rebuild-native-modules.sh` no longer offers to delete the global model cache. Other tools keep their models there.
  - Its marker step now finds `record-node-version.js` under `runtime/cli/setup/`. It had pointed at the old `cli/setup/` path and failed.

&nbsp;

## Upgrade

Run `npm ci` in `.skilled/skills/system-spec-kit` to drop the transformers package from `node_modules`. Code that imported the embedding package, `chunking` or `utils/retry` from `shared/` must stop. The `system-skill-advisor` v2.0.0.0 entry covers the advisor side and the machine cleanup. The `system-skilled-doctor` v1.3.0.0 entry covers the doctor commands.
