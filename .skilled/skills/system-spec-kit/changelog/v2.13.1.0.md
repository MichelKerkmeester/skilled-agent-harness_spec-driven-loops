# v2.13.1.0, Stopped Moves Finish and Restores Report Honestly

Version 2.13.0.0 added one command that moves a spec packet. Two reviews then found the gaps. A run that stopped part-way could end as finished. A renumbered phase kept its old name in its parent's tables.

This release closes those gaps. A rerun now finishes what the first run left. Phase tables follow the phase. A restore says plainly whether it landed.

Search and the sub-track proposal get smaller fixes. Archived paths are listed in the path recipe's JSON. A proposed map now passes the relocation check.

> Spec folder: `specs/system-speckit/spec-folder-tooling/005-subtrack-proposal-and-archive-reach`

&nbsp;

## Why This Release

A move tool is only safe when a stopped run can be finished. Before this release, some stops looked finished and were not. A rerun found nothing to do while records still named the old path.

Restores had a similar problem. A restore whose packet failed its own checks was reported as failed. The packet had in fact moved.

&nbsp;

## What's New at a Glance

- **A rerun finishes a stopped move.** Each late step is recorded when it lands. Until all are recorded, a rerun treats the move as unfinished. <!-- section: Moving Packets -->
- **Phase tables follow a moved phase.** A renumber or a re-parent rewrites the parent's map, handoff and binding rows. <!-- section: Moving Packets -->
- **Exit 3 means the move landed.** Only the moved packet's own validation failed, so a rerun has nothing to do. <!-- section: Moving Packets -->
- **A restore reports what happened.** A landed restore exits 0 with a warning. A restore beside sub-tracks is refused. <!-- section: Archives -->
- **Search marks archived paths in JSON.** The path recipe adds `archivedPaths` beside the plain `paths` list. <!-- section: Search and Proposals -->

&nbsp;

## Moving Packets

#### A Rerun Finishes a Stopped Move

The last steps of a move rebuild the redirect table and the trigger index. Then a sweep checks the track roots. Each step now marks the move's ledger record when it lands. Until every mark is set, a rerun treats the move as unfinished. It runs those steps again, which is safe.

A failed identity step is retried the same way. The rerun reads the packet's recorded parent chain and sees it is stale.

#### Unrecorded Moves Are Refused

A source folder can go missing between runs. The rerun now trusts that only when the ledger or git records the move. Otherwise it refuses and asks you to move the folder back first.

One case still needs that manual step. An untracked packet that stopped before the ledger step leaves no record. The refusal names both paths.

#### Two Spellings of One Folder Are Caught

Some disks treat `Specs` and `specs` as one folder. A map could name one folder twice in different case. The preflight now compares folders by their identity on disk. It refuses the second spelling before anything moves.

#### Phase Tables Follow a Renumber

A renumber inside a phase parent now rewrites the child's bare folder name. That covers the parent's map, handoff and goal rows. It also covers each sibling's neighbour rows.

A bare name behind another folder's path is left alone. For example, `other-track/003-gamma` stays as written. The name is rewritten only behind `./`, `../` or the parent's own folder name.

#### A Re-Parented Phase Changes Parents

A phase moved between two parents leaves the old parent's rows. It gains the same rows in the new parent. Its own neighbour rows name its new siblings. The run prints one line per row it changes.

A re-parent that stopped after the folder moved is finished by a rerun. The new parent is written first. The old parent's rows then stay as the signal until the rerun.

#### A Restored Packet Loses Its Old Id

A packet restored from `z_archive/` under a new number had a stale id. Documents written before the archive still named it. The rewrite now covers that pre-archive id too.

#### Exit 3 Separates a Landed Move

Before, any failed check at the end exited 2. That included a packet failing its own strict validation after a clean move. Now that case exits 3:

```text
close validate specs/demo/005-gamma: RESULT: FAILED
```

Exit 3 needs that `RESULT: FAILED` line. A validator that fails without printing a result gives exit 2. The rerun then asks it again. When one packet earns 2 and another 3, the run exits 2.

## Archives

#### A Restore Reports What Happened

A restore onto a taken number moves the packet through `relocate.mjs`. When that run exits 3, the move landed. The restore now prints `Restored:` and one warning, then exits 0. Any other failure still exits 1 with the command to rerun.

#### Restores Beside Sub-Tracks Are Refused

A track holds either flat packets or sub-tracks, never both. A restore into a track with a declared sub-track would break that rule. It is now refused with exit 1. The message names the `relocate.mjs` command that moves the packet into a sub-track instead.

The check reads the sub-track declarations directly. It no longer starts a `relocate.mjs` dry run. `archive.sh --help` now names both outcomes.

#### New Phases Skip Archived Numbers

`create.sh --phase --parent` now reads the parent's `z_archive/` too. With phases `001` and `002` live and `003` archived, the next new phase is `004`. The link to the previous phase still points at the highest live one.

## Search and Proposals

#### Archived Paths Are Listed in JSON

The path recipe's JSON keeps `paths` as plain strings. With `--include-archive` it now adds `archivedPaths`, the archived subset. Without the flag the record is unchanged.

#### Proposed Maps Pass the Relocation Check

`suggest-subtracks.mjs` could propose a group name an existing folder already held. The relocation check then refused the map. Proposed names now avoid existing folders.

A packet whose folder name is not `NNN-slug` now stops the proposal. Each such packet is named, then `no map` is printed.

#### Smaller Fixes

- **Review prompts no longer route to spec-kit by accident.** An archive search signal matched the word "findings". It now reads "quote a phrase in archived spec packets".
- **The published next-number command counts archives.** The `SKILL.md` command now reads one root and its `z_archive/`, as `create.sh` does.

&nbsp;

## How It Was Checked

#### Before and After

| Check | Before | After |
|---|---|---|
| A re-parent stopped after its folder moved, then rerun | Rerun ended as finished, old rows left | Exit 0, both parents correct, then `nothing to do` |
| A move whose trigger index step fails once, then rerun | Rerun found nothing to do, step left undone | Exit 2, then exit 0 with `finished 1 earlier move(s)` |
| A move whose packet is missing a required file | Exit 2 | Exit 3, then `relocate: nothing to do` |
| `archive.sh --restore` when relocation exits 3 | Exit 1 | `Restored:` with a warning, exit 0 |
| A restore into a track with a sub-track | Asked `relocate.mjs` for a dry run | Refused in the shell, no `relocate.mjs` process |
| Renumber `003-gamma` with `other-track/003-gamma` in the parent | Both rewritten | Only the parent's own name rewritten |
| Path recipe `--json --include-archive` | No archived marker | `archivedPaths` lists the archived file |

#### Tests and Scenarios

- **The relocation and archive suites pass.** The three suites ran 115 tests: 115 passed, 0 failed.
- **The full command-line suite passes.** 2613 passed, 0 failed. Every new case failed before its fix.
- **A real-pipeline suite runs the true writers.** A manual check removed one pipeline step, and the suite failed as it should.
- **Three manual scenarios ran as written.** The relocation, proposal and archive search scenarios each matched their expected output.

&nbsp;

## Upgrade Notes

- **Scripts that read the `relocate.mjs` exit status:** Treat 3 as a landed move whose packet needs attention, not as a failure.
- **Scripts that read `archive.sh --restore`:** A restore into a track with sub-tracks now exits 1. Move the packet into a sub-track instead.
