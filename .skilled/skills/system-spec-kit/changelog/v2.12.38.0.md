# v2.12.38.0, a track root lists only folders with a spec.md

A numbered folder under a track is now a packet only when it holds a `spec.md`.

> Spec folder: `specs/cli-external-orchestration/085-cli-deepseek-harness-creation/016-ci-red-check-repairs` (Level 1)

&nbsp;

## What's New at a Glance

- **Empty folders are not packets.** `track-roots.mjs` skips a numbered folder without `spec.md`, in the working tree and in a commit. An ignored or half-made folder on disk no longer makes the pre-push track-root gate disagree with the commit.
- **Both tools agree.** `refresh-track-roots.mjs` and `sweep-track-roots.mjs` read the same rule, and their READMEs and the track-root catalog entry say so.

&nbsp;

## Upgrade

Run `node .skilled/skills/system-spec-kit/runtime/cli/spec/refresh-track-roots.mjs --apply` once if a track root still lists a folder that has no `spec.md`.
