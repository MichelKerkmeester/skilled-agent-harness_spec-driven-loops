# v2.12.50.0, The Lookup Shows Which Phrases Matched

A trigger lookup printed its hits without the phrases that produced them, and a handoff could follow a save that wrote nothing.

&nbsp;

## What's New at a Glance

- **The lookup shows its phrases.** The text output of the trigger-index lookup prints a `phrases:` line under each hit and a note when a hit scored zero. The JSON output is unchanged.
- **Handoff saves for real.** `/speckit:handoff` names the save's full-auto mode, the one that writes, so the handoff no longer follows a save that only planned.
- **The auto-recursion message names sub-tracks.** `validate.sh` says "child phase or sub-track folders detected" when it recurses, and the playbook quotes the same words.
- **One description of the coverage switch.** The two places that describe when acceptance-criteria coverage is enforced now agree.
- **The handback contract counts seven CLI modes.** It listed the modes from before the DeepSeek harness joined and cli-hermes left.

&nbsp;

## Upgrade

No migration required. A script that matches the old auto-recursion message text needs the new wording.
