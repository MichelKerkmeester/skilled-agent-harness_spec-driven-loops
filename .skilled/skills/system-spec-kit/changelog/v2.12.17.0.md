# v2.12.17.0, The Env Reference Lists the Worktree and Git Time-Limit Settings

Eight settings had no row in `runtime/ENV-REFERENCE.md`. The worktree cleanup reads them. So do the git time limits and the private skills. Each setting now has a row. The row gives its default, the values it accepts and the files that read it. `/doctor:env` takes a setting's default and description from this file.

&nbsp;

## What's New at a Glance

- **The switch that turns off the worktree sweep is documented.** `SPECKIT_WORKTREE_AUTOREAP` set to `0`, `off`, `false` or `no` stops only the session-start sweep. That sweep removes merged, idle and clean numbered worktrees. The worktree warning keeps running.
- **The git time limits are documented.** `SPECKIT_GIT_TIMEOUT` caps each index-reading git call at 20 seconds by default. Those calls run in the hooks, the launcher and the worktree reaper. `SPECKIT_WORKTREE_ADD_TIMEOUT` gives creating a worktree 60 seconds. `FSMON_PROBE_TIMEOUT` gives one process listing 15.
- **The worktree folder and the reaper overrides are documented.** `SPECKIT_WORKTREE_BASE` moves worktrees outside the checkout. It outranks the `speckit.worktreeBase` git setting. `SPECKIT_FSMON_REAPER` and `SPECKIT_WORKTREE_REAPER` point the launcher, the guard and the doctor at another reaper script.
- **Private skill roots are documented.** `SPECKIT_PRIVATE_SKILL_ROOTS` names extra folders a private `local-*` skill link may point into. Without it the skill advisor indexes no private skill whose link leaves the skills folder.
