# v4.1.2.0, Packet Changelogs Answer to Their Own Name

A packet changelog can now be found through the packet it belongs to. The nested changelog generator derives a search phrase from each changelog's path, such as `skilled release changelog findability changelog`, in place of the fixed phrases every packet changelog used to share.

> Part of [Skilled v4.0.0.2](../../../changelog/skilled/v4.0.0.2.md).
>
> Spec folder: `specs/sk-doc/061-skilled-release-changelog/002-changelog-findability` (Level 3)

## What's New at a Glance

- **Each packet changelog names its packet.** The generator builds the phrase from the packet and phase folder names without their number prefixes, then ends it with `changelog`.
- **The shared phrases are gone.** The root and phase templates each wrote the same three fixed phrases into every changelog they produced, so a search for one of them could never single out a packet. One placeholder that the generator fills now takes their place.
- **Long names stay searchable.** A phrase keeps at most nine words before `changelog`. The generator trims the packet words from their end before it touches the phase words.
- **The reference documents the rule.** The nested changelog reference gains a Search Metadata section with the steps and a worked example.

## Upgrade

Regenerate a packet changelog with `nested-changelog.js <spec-folder> --write` to give it its identity phrase. Existing packet changelogs already carry theirs, and the retired phrases are gone from them.
