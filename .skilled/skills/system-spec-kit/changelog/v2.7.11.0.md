# v2.7.11.0, An Unbuilt Runtime Says So

A fresh clone has no built spec-kit runtime. That lasts until someone runs `npm --prefix .skilled/skills/system-spec-kit run build`. Two runtimes hid that. Pi dropped its session-start context without a word. Codex's fallback message sent users to its hooks installer. That installer reports OK while the hooks still fail. Both now name the build.

&nbsp;

## What's New at a Glance

- **Pi names the missing build.** The built session-prime hook can be absent. Then Pi shows one warning with the build command. It does that instead of starting with no context and no reason.
- **Codex's fallback points at the fix.** A Codex hook prints a message when its adapter cannot run. That message now names the spec-kit runtime build. The Claude, Cursor and Devin messages already did.

&nbsp;

## Upgrade

Nothing to do. If Pi or Codex shows the new message, run the build once.
