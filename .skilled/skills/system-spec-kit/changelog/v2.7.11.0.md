# v2.7.11.0, An Unbuilt Runtime Says So

A fresh clone has no built spec-kit runtime until someone runs `npm --prefix .skilled/skills/system-spec-kit run build`. Two runtimes hid that. Pi dropped its session-start context without a word, and Codex's fallback message sent users to its hooks installer, which reports OK while the hooks still fail. Both now name the build.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/021-open-ends-remediation/002-onboarding-fixes` (Level 1)

&nbsp;

## What's New at a Glance

- **Pi names the missing build.** When the built session-prime hook is absent, Pi shows one warning with the build command instead of starting with no context and no reason.
- **Codex's fallback points at the fix.** The message a Codex hook prints when its adapter cannot run now names the spec-kit runtime build, the way the Claude, Cursor and Devin messages already did.

&nbsp;

## Upgrade

Nothing to do. If Pi or Codex shows the new message, run the build once.
