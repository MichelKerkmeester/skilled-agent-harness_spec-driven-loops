# v4.6.1.0, Tests Under tests/ and a Documented Runtime

Spec-kit's code is now easier to find your way around. Every file in the runtime and the shared package carries a module header, long files are split into numbered sections, and every code folder has a README. Every test now sits under a `tests/` tree instead of beside its source, and the completion-evidence sentinel moved next to the other hook helpers. No behavior changed.

> Spec folder: `specs/system-speckit/046-align-runtime-code-with-sk-code-opencode` (Level 2)

## What's New at a Glance

- **The completion sentinel now lives in `hooks/lib/`.** Its five runtime adapters, the Pi extension and the OpenCode plugin all import it from there.
- **Tests sit under `tests/` everywhere.** The shared package's tests moved to `shared/tests/` and the hook tests to `runtime/tests/hooks/`. Golden snapshots moved to `cli/tests/snapshots/`.
- **No double-underscore folders remain.** `__helpers__`, `__fixtures__` and `__snapshots__` became `helpers`, `fixtures` and `snapshots`.
- **A profile test checks what it claims.** Its source-file paths had never resolved, so it always took its fallback. It now reads the real file, and its checks pass.

## Upgrade

Repoint any out-of-tree import of `runtime/lib/hooks/completion-evidence-sentinel.cjs` to `runtime/hooks/lib/completion-evidence-sentinel.cjs`.
