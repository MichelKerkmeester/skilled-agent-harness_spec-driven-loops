# v2.12.13.0, Spec Folders No Longer Hold Changelogs

Changelogs now live in two places only. One is `.skilled/changelog/`. The other is each skill's own `changelog/` folder. `/create:changelog` writes both. The closing workflows and the phase scaffold stopped creating a third copy inside the spec folder. That copy repeated what `implementation-summary.md` already records.

&nbsp;

## What's New at a Glance

- **Closing a packet writes no changelog.** `/speckit:implement` and `/speckit:complete` end at `implementation-summary.md`. The closeout display drops its changelog line.
- **A new phase child names no changelog.** `create.sh --phase` stops writing the `**Changelog**:` line. It also stops writing the note that told the phase to refresh one.
- **The generator says it is deprecated.** `nested-changelog.js` prints a notice on stderr on every run. That includes `--help`. Its stdout is unchanged, so `--json` callers still parse it. A test pins the notice.
- **The generator only re-renders.** `nested-changelog.js --write` refuses a packet that has no changelog. It throws an error that points at `/create:changelog`. It writes nothing. So the generator can no longer start a new packet changelog.
- **The docs say where changelogs live now.** The skill, README, references, template guide, feature catalog and playbook mark packet changelogs deprecated. They point at `/create:changelog`. The level-change steps now record the change in `implementation-summary.md` or in the spec.md CHANGE LOG section at Level 3+. The skill router loads the deprecated changelog page for research requests. It no longer loads it on every `/speckit:complete`. `SKILL.md` is back under its 5000-word cap.
- **The README matches the tree.** It no longer lists the removed `shared/contracts/` folder. It no longer lists the deleted `evidence-marker-lint.ts`. It no longer claims an `.opencode/specs` compat symlink either. It names that folder as a legacy root the resolvers still accept. It names the retrieval scripts by role. `lookup-trigger-index.mjs` handles the trigger index and `rg-wrapper.mjs` handles free text.

&nbsp;

## Upgrade

No migration required. The changelogs already inside spec folders stay and still validate. The generator can still re-render them.
