# v2.1.4.0, Hooks That Leave the Advisor Time to Answer

The hook shim that runs the skill advisor hook in Claude, Codex, Cursor and Devin stopped the hook at the same moment the hook gave up on its advisor call, so a slow advisor left the turn with nothing. The shim now leaves the hook time to deliver its fallback. The adapters also name the runtime that ran the hook, and `create.sh` gives a phase added to an existing parent its real number.

> Part of [Skilled v4.0.0.2](../../../changelog/skilled/v4.0.0.2.md).
>
> Spec folder: `specs/system-skill-advisor/030-pi-skill-orchestrator-based-research-refinement` (Level 2)

## What's New at a Glance

- **The advisor's fallback lands before the shim stops it.** The Claude shim still stops the advisor hook after 2,500 ms, and it now gives the hook 2,200 ms for its own advisor call. An operator's `SPECKIT_CLAUDE_HOOK_TIMEOUT_MS` is capped at 2,200, and a value that is unset or does not parse to a positive whole number counts as 2,200.
- **Each adapter names its runtime.** The Codex, Cursor and Devin adapters set `SPECKIT_RUNTIME`, so the advisor's diagnostics stop recording their turns as Claude.
- **`create.sh` numbers an appended phase by its folder.** A phase added to an existing parent came out as Phase 1, because the script counted phases within one run. It now labels the phase with the number its folder carries, which continues after the parent's highest existing phase.
- **The hook docs describe the advisor path as it runs.** The hook READMEs name each adapter's runtime label and the shim's budget cap. The feature catalog covers the prompt check and the status line on a turn without a suggestion, and its hook fallback entry now says the hook runs the advisor with `--no-warm-only`, so the advisor may start its daemon.
- **Scenario 433 tests the outage it names.** It sent `hello`, which the advisor's prompt check turns away before any advisor call, so it tested nothing. It now sends a prompt the advisor routes and runs its advisor in a sandbox that it clears without sending a signal.
- **Scenario 457 runs as written.** It runs the Pi suite from `.skilled` through the hooks test config, and it has the operator record each result by hand, because the tool that saved results was retired.

## Upgrade

- **The hook budget.** A `SPECKIT_CLAUDE_HOOK_TIMEOUT_MS` value above 2,200 now counts as 2,200. Lower values behave as before.
