# v2.12.53.0, A Plan Names Its Files and Chat Sessions Meet the Authoring Card

A plan could pass every gate and still leave the implementer to pick the file. The authoring card that prevents this loads on a `/speckit` command. Most people chat and never type one. This release puts the card in front of a chat session and tightens the plan it asks for.

> Spec folder: `specs/system-speckit/spec-authoring-and-continuity/005-goldfish-cold-read-plan-review`

&nbsp;

## What's New at a Glance

- **The plan example names a file in each phase.** The template and the card showed three phases with no file. Each phase now names the file it reads or changes. Proof still belongs on the task lines.
- **A new spec folder points at the card.** `create.sh` prints it as step 0 of its next steps, for a standard folder and for a phase parent.
- **The spec-folder notice points at the card too.** The notice a write triggers ends with one sentence naming the card. All seven runtime adapters print it.
- **A plain write request loads the card in the router.** Six write verbs form a new `WRITE` intent that loads only the card. Its weight is 1, so a stronger intent such as `PLAN` still comes first. This reaches only a session that has opened the skill. The skill advisor still does not pick `system-spec-kit` for such a request.
- **`/speckit:implement` stops on an open design choice.** Its prerequisite step checks that the plan leaves none. A failure sends the work back to planning.
- **`/speckit:implement` stops on a failing test.** Its completion step named no outcome for one.
- **`plan_clarity` has a definition.** The gate scored it at 25 points and defined it nowhere. A plan with no clarity could pass at 75.
- **`/speckit:complete` wants a technical approach.** Its phase gate checked only that `plan.md` exists.
- **Clarification runs in passes of three.** The old wording read as three markers in total.

&nbsp;

## Upgrade

No migration required. A test that compares `create.sh` output will see one more line. A plan written from the template should name a file in each phase.
