# v2.13.3.0, The Nested Changelog Generator Is Removed

Spec folders stopped getting changelogs in an earlier release. The generator stayed only to render the old files. No command called it. Now it is gone.

&nbsp;

## What's New at a Glance

- **The generator is gone.** `nested-changelog.js` and its test are deleted. The `spec-folder` barrel no longer exports its three functions.
- **Its templates and workflow page are gone.** `templates/changelog/` and `references/workflows/nested-changelog.md` are deleted. The router no longer loads that page.
- **Its catalog entry and playbook scenario are gone.** Scenario 458 and the feature entry are deleted with their index rows.
- **Old packet changelogs stay.** The files under `specs/**/changelog/` are kept as history and still validate.

&nbsp;

## Upgrade

- **If a script runs `nested-changelog.js`:** it no longer exists. Write release notes with `/create:changelog`.
- **If you built the CLI before:** run `npm run build` in `runtime/cli` and delete `dist/spec-folder/nested-changelog.*`.
