# v2.13.3.0, No Command File May Be Named skill.md

Claude Code reads a command folder that holds `skill.md` as one skill. It then hides every other command in that folder. The mirror check used to allow one such file, `create/skill.md`. That command is now `/create:sk-skill`, so the check allows none.

> Spec folder: `specs/system-skill-advisor/routing-and-scoring/008-command-surfacing-build`

&nbsp;

## What's New at a Glance

- **The mirror check fails on any command file named `skill.md`.** It matches every capitalisation, so `SKILL.md` fails too. The failure reads `COLLAPSE design/SKILL.md hides 1 sibling commands on Claude Code`.
- **The mirror check keeps no allowlist.** The old exception for `create/skill.md` is gone.
- **`/speckit:search` answers plain search requests.** It gained four intent phrases, such as "search our spec notes for a topic".

&nbsp;

## Upgrade

No migration required. Rename any command file named `skill.md` in your own command folders before you run the mirror sync.
