# Mirror Checks Follow Git Ignore Rules

Runtime mirror checks and shared setup guidance now match what a fresh checkout can use. This prevents Git-ignored roots from causing parity failures and gives command authors a clear entry point to the shared setup rules.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/012-alignment-remediation` (Level 2)

&nbsp;

## What's New at a Glance

- **Git ignore rules shape mirror expectations.** The checker skips ignored mirror paths, still expects tracked roots and does not create ignored links.
- **The shared setup rules now start with an overview.** Command authors can see what the contract covers before reading its tiers.
- **The plugin scope note matches the active tree.** It no longer says the removed plugin path is still indexed.
