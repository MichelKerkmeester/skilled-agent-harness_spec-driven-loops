This release updates the system-spec-kit SKILL and README with agent-routing documentation from spec 014 (Command Agent Utilization Audit), focusing on fixing important problems and explaining the results more clearly. Its goal is to make the workflow easier to follow and easier to trust.

> Spec folder: `.claude/specs/system-spec-kit/z_archive/002-agent-routing-doc-update/`

## What's New at a Glance

- **Agent Dispatch is now a table.** A new subsection documents all agent routing in `spec_kit` commands.
- **Debug delegation targets `@debug` only.** It joins the existing `@handover` and `@research` Agent Exclusivity exceptions.
- **`@debug` and `@review` have defined routes.** `@debug` handles implement/complete at failure >= 3. For `@review`, implement/complete uses Mode 2 Pre-Commit and Mode 4 Gate Validation, with post-fix debug as advisory.
- **`@research` and `@handover` have defined routing conditions.** `@research` handles plan at confidence < 60%, while `@handover` handles plan, implement, complete and research at session end.
- **The Mode Suffixes table adds `:with-research` and `:auto-debug`.** Its "Applies To" column shows `/spec_kit:complete` exclusivity.
- **Recent Changes adds a spec 014 compliance summary.** The summary covers agent routing.

## Upgrade

No migration required. Pull latest to get updated documentation.
