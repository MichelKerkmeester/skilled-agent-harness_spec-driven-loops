This release completes the TypeScript conversion in `mcp-server/` and corrects inaccurate project documentation. It makes the workflow easier to follow and trust.

## Why This Release

People needed clearer guidance and more accurate documentation. The release focuses on fixing important problems and explaining the results in clearer terms.

## What's New at a Glance

- **The TypeScript conversion is complete.** The remaining source code moved to strict TypeScript.
- **Project documentation was corrected.** Specs 106 and 107 cover the accuracy audit and fixes.
- **Stale `mcp-narsil` references were removed.** The skill documents no longer contain the 39 ghost references.
- **Version and guide details were updated.** The project and SKILL versions now identify v2.2.0.0.
- **The CHANGELOG now covers Specs 104–107.** The entries address conversion, cleanup and documentation accuracy.
