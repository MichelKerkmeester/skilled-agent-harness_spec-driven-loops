This release adds 4 new README files for shared modules and the tool dispatch layer. It focuses on making the instructions and release notes easier for non-developers to follow. The goal is to make the workflow easier to follow and easier to trust.

## What's New at a Glance

- **Composite folder scoring has its own README.** `shared/scoring/README.md` documents the formula breakdown, the weight tables, the archive multiplier rules and the design decision references. The reference also covers 8 function exports and 5 constants.
- **Shared utilities have their own README.** `shared/utils/README.md` gives the path-security module and the retry module the clearer guidance people needed.
- **Session type definitions have their own README.** `scripts/types/README.md` lays out 16 interfaces across 4 sections with an ASCII type architecture diagram. The `SessionData` root type has 35+ fields.
- **The tool dispatch layer has its own README.** `mcp-server/tools/README.md` maps 22 MCP tools across 5 domains and draws the dispatcher architecture as an ASCII flow diagram. The guide also shows the `parseArgs<T>()` utility and how to extend the tools.
- **Section headers now carry emoji prefixes.** All 37 of them match the project README styling conventions.
