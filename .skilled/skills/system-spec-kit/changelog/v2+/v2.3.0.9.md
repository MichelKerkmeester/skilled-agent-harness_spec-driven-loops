Adaptive fusion gained bounded channel weighting and deterministic merge behavior, and the graph-channel contract was tightened. Memory search hardened its ranking and routing diagnostics and its confidence rationale. Memory CRUD gained post-mutation consistency safeguards, and the memory index hardened its invariants and health probe. Storage gained deterministic recovery and ledger consistency controls, telemetry gained a canonical trace-schema validation contract and the alignment validator gained schema and documentation drift checks.
