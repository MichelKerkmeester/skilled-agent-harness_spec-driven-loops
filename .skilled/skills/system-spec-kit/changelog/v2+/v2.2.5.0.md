This release aligns README anchors, memory command documentation, shared styles and routing references. It also shortens `SKILL` without removing features and restores command files after an over-reduced state.

## Why This Release

Readers needed clearer guidance about README anchors, memory command READMEs and style alignment. Reliability problems affected command files and YAML assets. The release aims to make instructions and release notes easier for non-developers to follow and the workflow easier to follow and trust.

## What's New at a Glance

- **README anchor tags support precise memory retrieval.** Memory retrieval filters content by anchor.
- **Memory command READMEs were part of the documentation alignment.** Five command READMEs were included.
- **Shared rules now shape README presentation.** The rules came from the readme template.
- **`SKILL` was shortened.** All features were preserved.
- **Command files were restored after over-reduction.** This corrected a reliability problem.
- **Command headings received template styling.** The update addressed a need for clearer style guidance.
- **Routing references and YAML subagent types were updated.** These changes make the workflow easier to trust.

---

## README Guidance

#### Anchors Support Retrieval

About 473 anchor tags were added across 74 READMEs using `<!-- anchor:tag-name -to`. The tags cover all `.opencode/` skill, command, agent and infrastructure READMEs (Spec 111).

&nbsp;

#### Memory Commands Follow Standards

Save, learn, manage, continue and context command READMEs were aligned with documentation standards (Spec 112). People needed clearer guidance about these memory command READMEs.

&nbsp;

#### Shared Rules Shape README Style

Seven style rules from the readme template were applied to 75 active README files (Spec 113). They standardize H1 format, badge placement, section ordering, table formatting, link style, frontmatter and dividers.

---

## Command Guidance

#### Skill Keeps Its Features

`SKILL` was shortened (Spec 114). The release is clearer and easier to work with.

&nbsp;

#### Command Files Recover

Twelve command files were restored to 600 lines or fewer after an over-reduced state (Spec 114). This addressed a reliability problem, reducing confusing failures and making the system more dependable.

&nbsp;

#### Command Headings Match Their Template

About 160 H2 headings across all 12 command files received the command template style (Spec 114). People needed clearer guidance about style alignment.

---

## Routing Guidance

#### Routing Updates Align References

Four YAML assets changed from `Subagent_type: explore` to `subagent_type: context` (Spec 114). Five `.md` command files added `@context` and `@speckit` routing references. Two YAML assets added `@speckit` routing for debug delegation. All 19 commands properly route per the `AGENTS` agent table (Spec 114).

No upgrade needed.
