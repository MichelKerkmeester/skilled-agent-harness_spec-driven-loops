Spec 128 defines and integrates a mandatory AI workflow for spec upgrades. The agent uses existing spec context to replace placeholders added by an upgrade level, and the release explains the changes in simple language so it is easier to understand.

## What's New at a Glance

- **Spec upgrades now fill injected placeholders from existing context.** After an upgrade level runs, the AI agent reads existing spec files and replaces `[placeholder]` patterns in newly injected sections with context-derived content.
- **`check-placeholders.sh` finds remaining bracket placeholders.** It scans Markdown files in the spec folder and returns exit code 0 when the scan passes or 1 when it fails. It supports `--json` and `--verbose`.
- **`/spec_kit:complete` includes auto-population in Step 10.** Its scope-growth guidance now includes the full four-step procedure and check-placeholders verification.
- **The SKILL escalation guidance covers auto-population.** It gives explicit instructions, handles missing context and cross-references the level specifications.
- **ADR-001 records the AI-side workflow choice.** The workflow runs on the AI side rather than through script modification because shell cannot reason about content.
- **ADR-002 gives missing context an explicit fallback.** The workflow uses "N/A" instead of fabricating content when source context is missing.

## Upgrade

No migration required. The changes are to workflow documentation only, and the new `check-placeholders.sh` script is immediately available.
