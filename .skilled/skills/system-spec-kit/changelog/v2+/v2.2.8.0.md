This release makes YAML prompt assets and `.md` command files more compact, making the main changes easier to understand and the project easier to maintain.

## What's New at a Glance

- **YAML prompt assets use compact flow notation.** The 13 YAML prompt assets in `command/spec_kit/assets/` use `{key: value}` and `[a, b]` notation to compress the YAML. The update removed decorative separators, verbose description fields and Mermaid diagrams that were never rendered in CLI.
- **The `.md` command files are more compact.** The 7 `.md` command files in `command/spec_kit/`, together with the YAML changes, account for 20 files total. All routing logic, workflow steps and config keys were preserved. Step counts and asset paths were preserved too.

## Upgrade

No migration required.
