This release is a comprehensive feature, bug and documentation audit across the entire MCP server. It fixes P0 and P1 issues, restores non-functional features and improves documentation-code alignment.

## Why This Release

The release focuses on making the instructions and release notes easier for non-developers to follow. The goal is to make the workflow easier to follow and easier to trust.

## What's New at a Glance

- **P0 and P1 issues are fixed.** The release fixes 10 P0 issues and 18 P1 issues.
- **Non-functional features work again.** 12 non-functional features are restored to working state.
- **Documentation matches the code more closely.** Documentation-code alignment improved from 67.9% to 95.5%.
