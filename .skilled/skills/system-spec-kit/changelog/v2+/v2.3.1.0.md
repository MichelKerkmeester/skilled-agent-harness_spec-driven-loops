## What's New at a Glance

- **Save quality gate tracks each active database handle.** It tracks config-table ensure state per handle and reruns the database schema safely after handle changes.
- **Activation timestamp initialization handles restarts.** `ensureActivationTimestampInitialized` preserves the persisted warn-only window state across restart.
- **The save quality gate gains two focused regressions.** They are WO6 and WO7 in save quality gate.vitest.
- **Canonical ID dedup now spans both search paths.** It applies in `combinedLexicalSearch()` and legacy `hybridSearch()` for `42`, `"42"` and `mem:42`.
- **Tier-2 fallback forces all retrieval channels.** It uses `forceAllChannels` and bypasses simple-route channel reduction.
- **Hybrid search gains three regressions.** They are T031-LEX-05, T031-BASIC-04 and C138-P0-FB-T2 in hybrid search.vitest.
- **Parent summary wording is corrected.** It covers RSF/shadow/fallback semantics, the R11 default and shadow-period wording, TM-05 hook scope and dead-code references.
- **S5/entity-linking wording is corrected.** It covers global density checks, database batching and MPAB naming. It also corrects PI-B3 labeling and active search-flag count.
- **Child Level 2 docs now show tranche status.** The docs in `016-refinement-phase-5` mark tranche-1 through tranche-4 as completed.
