This release unifies the Memory Dashboard Visual Design System across all five memory commands and updates their instructions.

> Spec folder: `Folder 036` (Level 2)

## Why This Release

The changes focus on making instructions and release notes easier for non-developers to follow. The goal is a workflow that is easier to follow and easier to trust.

---

## What's New at a Glance

- **Memory commands now use `MEMORY:<COMMAND>` headers.** They replace five different header styles.
- **Section labels now use Title Case across all commands.** They replace ad-hoc dividers and mixed formatting.
- **Numeric output now uses block charts.** The bars are drawn with the `█░` characters.
- **Status indicators now use plain words.** They read `PASS` / `WARN` / `FAIL`.
- **Interactive prompts now share one choice format.** Each choice reads `[key] verb` instead of the pipe-separated styles.
- **A shared vocabulary now defines 10 output components.** The same names describe the output in every memory command.
- **Folder 036 is now a full Level 2 spec folder.** It makes the release notes and instructions easier to read and trust.
- **Save now enforces its required argument.** The command takes `<spec-folder>` as its first action.
- **Continue's opening sections now sit in a new order.** `PURPOSE` precedes `MCP ENFORCEMENT MATRIX`.
- **MCP tables in Continue and Context now use Markdown pipe syntax.** They replace the box-drawing tables.
- **Manage's instructional prose no longer uses emoji markers.** The project becomes smaller and easier to maintain.

---

## Memory Command Output

#### Shared Command Headers

The replaced styles included box-drawing, emoji-prefixed and mixed-case forms. Each header uses ALL CAPS with a thick `━━━` separator.

&nbsp;

#### Section Labels Use a Shared Format

Each label is arrow-prefixed and pairs its Title Case name with a `────────────` rule and a count. Their format replaces ad-hoc dividers and mixed formatting.

&nbsp;

#### Numeric Displays Use Bars

Across all numeric displays, the bars visualize:

- Scores
- Progress
- Tier distribution
- Confidence
- Stability

&nbsp;

#### Status Indicators Use Words

The replaced emoji indicators were:

- `✓`
- `⚠`
- `❌`
- `🔄`
- `✅`

&nbsp;

#### Action Menus Use One Pattern

The previous prompts used inconsistent forms such as `[a]ction | [b]ction`. Choices follow a thin `───` separator.

&nbsp;

#### Ten Components Share a Vocabulary

The vocabulary names command header, section label, key-value pair, bar chart, result item, status line, action menu, indicators, inline lists and empty state. Key-value formatting is consistent. Approximately 29 output templates were standardized.

## Memory Command Instructions

#### Folder 036 Has a Full Record

The folder contains:

- A spec
- A plan
- An implementation summary
- A checklist

&nbsp;

#### Save Gets a First-Action Gate

The new block is titled `# MANDATORY FIRST ACTION`. The change separately removes the redundant `CRITICAL RULES` section and renumbers sections 1-15.

&nbsp;

#### Continue and Context Match Templates

Continue swapped its sections 1 and 2 to match the template standard. Continue's box-drawing MCP table and Context's box-drawing MCP enforcement matrix were converted to Markdown pipe tables.

&nbsp;

#### Manage Drops Emoji Markers

The removed markers appeared in:

- Gate headers: `🔒`
- Status markers: `☐` and `⏭️`
- HARD STOP indicators: `⛔`

---

## Upgrade Notes

No upgrade needed. All changes are documentation-only output-template formatting in command instruction files. The release changes no runtime code, MCP tool signatures or database schema.
