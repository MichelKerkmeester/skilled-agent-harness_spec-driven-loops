# v2.2.20.0, One Runtime Database Path Documented

This release documents the main runtime database path for System Spec Kit and hardens split-path guidance. It makes the access rules clearer and safer. The main changes are explained in simple language so the release is easier to understand.

## What's New at a Glance

- **The main runtime database path is now explicit.** Core System Spec Kit docs name `mcp-server/dist/database/context-index.sqlite` as the authoritative runtime location.
- **Compatibility behavior is documented.** `mcp-server/database/context-index.sqlite` can exist as a symlink for backward compatibility.
- **The continue and save workflows are covered.** Their memory command docs now reference the main database path and sidecar handling.
- **Mixed-path guidance is gone.** Memory architecture and environment-variable references no longer point at two different database locations.

## Upgrade

No migration required. Documentation/config alignment only.
