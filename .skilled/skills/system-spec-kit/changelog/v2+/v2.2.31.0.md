This release fixes a tier mis-assignment in the memory parser that sent SESSION SUMMARY memories to constitutional tier by mistake. The affected entries are corrected and the parser takes each importance tier from the actual YAML metadata block.

> Spec folder: `.opencode/specs/system-spec-kit/140-fix-constitutional-tier`

## What's New at a Glance

- **extractImportanceTier() strips HTML comments before regex matching.** The function previously scanned the entire file including HTML comments, where the context template instructional comment (importanceTier: 'constitutional') was matched before the actual YAML metadata block.
- **A bulk re-tier corrected the wrongly tiered memories.** 595 SESSION SUMMARY entries moved from constitutional to normal tier in the SQLite database. Only 2 legitimate constitutional memories (IDs 567, 568) were preserved.
- **The parsing README was updated.** Its description of extractImportanceTier now documents the HTML comment stripping behavior.

## Upgrade

No migration required. The parser fix takes effect immediately on next MCP server restart. Existing mis-tiered entries were already corrected via bulk database update.
