This release expands the Spec Kit Memory MCP runtime with typed retrieval traces, artifact-aware routing, intent-adaptive fusion, append-only mutation logging and extended telemetry, delivered through the Level 3+ rollout in `136-mcp-working-memory-hybrid-rag`. It addresses important problems, explains results more clearly and makes the workflow easier to follow and trust.

> Spec folder: `.opencode/specs/system-spec-kit/020-mcp-working-memory-hybrid-rag/`

## What's New at a Glance

- **Retrieval responses carry typed traces.** They carry a typed ContextEnvelope with explicit pipeline trace and degraded-mode metadata for explainable ranking behavior. The MCP server runtime also gained extraction adapters and causal/session boost modules.
- **Search adapts to artifact class.** Routing adjusts for spec, plan, decision-record, memory, research and other artifact classes to improve relevance by document type.
- **Weighted fusion supports intent profiles.** Profiles cover fix_bug, add_feature, understand, refactor, security_audit, find_spec and find_decision, behind feature-flag control.
- **Memory operations enter an audit trail.** Memory CRUD and re-index operations are captured in an append-only, tamper-evident audit trail.
- **Retrieval telemetry is extended.** Search and context handlers report richer latency, mode, fallback and quality-proxy telemetry for evaluation and operations.
- **Cognitive config parsing is hardened.** It uses schema-validated paths and deterministic working-memory pressure and eviction behavior, making setup and maintenance easier to manage.
- **Eval/KPI scripts support staged rollout checks.** They also support quality backfill, performance benchmarks and calibration workflows.

## Upgrade

No migration required. Pull latest to get the new retrieval/runtime capabilities. Keep `SPECKIT_ADAPTIVE_FUSION` disabled for baseline parity, then enable it deliberately when ready to trial adaptive ranking behavior.
