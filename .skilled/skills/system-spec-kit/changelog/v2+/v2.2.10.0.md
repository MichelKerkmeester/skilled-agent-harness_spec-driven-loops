This release reorganizes where project dependencies are installed and updates the setup guidance and checks that use those dependency paths.

> Spec folder: `.opencode/specs/system-spec-kit/z_archive/003-node-modules-relocation/`

## Why This Release

People working on the server needed clearer setup paths and less confusion. The goal was to make the workflow easier to follow and trust.

## What's New at a Glance

- **A new `.npmrc` file sets `install-strategy=nested`.** The setting changes how npm installs dependencies.
- **The root package drops `better-sqlite3`.** The dependency was redundant there.
- **`sqlite-vec-darwin-arm64` is added as an optional dependency.** It supports nested-install compatibility.
- **The `lib/cache/cognitive` symlink is corrected.** It fixes TypeScript build paths.
- **The install guide updates its package references.** The instructions are easier to read and trust.
- **Install spec kit memory commands change targets.** Install, rebuild and verify commands are affected.
- **`Check native modules` updates its probe path.** `better-sqlite3` is the package being probed.
- **`Rebuild native modules` updates its location.** It now targets `mcp-server/`.
- **`Folder detector` and `Test folder detector functional` paths change together.** The test paths now match the detector.

---

## Dependency Installation

#### Workspace Installs Stay Local

npm installs dependencies per workspace instead of hoisting them to the root. This makes setup and maintenance easier to manage. `mcp-server/package.json` adds `sqlite-vec-darwin-arm64` as an optional dependency for nested-install compatibility.

---

## Setup Paths

#### Build and Setup Paths Align

`lib/cache/cognitive` points to `../cognitive`, fixing TypeScript build paths. The install guide changes all `system-spec-kit/node_modules/` references to `mcp-server/node_modules/`. Install, rebuild and verify commands in Install spec kit memory now target `mcp-server/`.

---

## Dependency Checks

#### Checks Follow Dependency Paths

`Check native modules` updates the `better-sqlite3` probe path. `Rebuild native modules` changes its rebuild location to `mcp-server/`. `Folder detector` now requires `better-sqlite3` from `mcp-server/node_modules/`. `Test folder detector functional` updates its paths to match.

## Upgrade Notes

No action required. Pull latest. If running a linked project, restart the MCP server to pick up the new dependency paths.
