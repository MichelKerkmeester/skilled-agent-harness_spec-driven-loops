This release is the spec Kit Memory bug audit, the most comprehensive bug-fix release in project history with 85+ bugs fixed across all severity levels. It focuses on fixing important problems and explaining the results in clearer terms. The goal is to make the workflow easier to follow and easier to trust.

## What's New at a Glance

- **The memory decay rate is corrected.** The FSRS formula carried an 18.45x decay rate error, so memories were decaying at the wrong rate because of an incorrect factor calculation.
- **The MacOS crash in database operations is fixed.** During SQLite operations a platform-specific crash could happen while concurrent database access was underway.
- **Silent database writes are fixed.** Some writes silently did nothing, causing data loss without errors.
