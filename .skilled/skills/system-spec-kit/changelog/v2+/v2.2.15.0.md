This release adds a script for upgrading existing spec folders between documentation levels while preserving user content. It brings the upgrade into a repeatable workflow with a preview before changes are made.

> Spec folder: `specs/system-spec-kit/z_archive/007-upgrade-level-script/`

## Why This Release

The release focuses on making instructions and release notes easier for non-developers to follow. Its goal is a workflow that is easier to follow and trust.

## What's New at a Glance

- **Existing spec folders can move between documentation levels.** User content is preserved through the upgrade.
- **A dry run previews planned changes.** `--dry-run` shows all planned changes without modifying files.
- **New files and level records update together.** SpecKit addendum templates create new files, while markers and metadata table level fields are updated across modified files.
- **Reruns avoid duplicate sections.** The upgrade operation is idempotent.
- **`--json` produces machine-parseable output.** This supports toolchain integration.
- **The script supports stock macOS.** It is compatible with Bash 3.2+ without requiring brew-installed Bash 5 and handles macOS and GNU `sed -i` differences.
- **Modified standard headings can still be matched.** Fuzzy matching finds approximate insertion points and falls back to the end of the file.
- **Backup cleanup is automatic.** The three most recent backups are kept and older ones are removed.

## Spec Folder Upgrades

#### Level Changes Follow a Clear Path

The script supports L1toL2, L2toL3 and L3toL3+ upgrades. A skip-level L1toL3 upgrade runs L1toL2 first, followed by L2toL3.

&nbsp;

#### Templates and Level Records Update

New files are generated from SpecKit addendum templates. `SPECKIT_LEVEL` markers plus metadata table level fields are updated across all modified files.

&nbsp;

#### Compatible with Stock macOS

The script works on stock macOS with Bash 3.2+ and does not require brew-installed Bash 5. It uses no associative arrays or bashisms. Portable sed handling abstracts the differences between macOS and GNU `sed -i`.

&nbsp;

#### A Script Built in Six Phases

The 1,490+ LOC script has 22 functions and creates backups. It works through input validation, level detection, backup creation, file upgrade, marker updates and output generation. Automatic cleanup keeps the three most recent and removes older ones.
