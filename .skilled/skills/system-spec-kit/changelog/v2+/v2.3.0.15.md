Sprint 8 of the MCP server remediation fixes 15 critical bugs. It also removes dead code, applies 13 performance improvements and makes 4 test quality fixes. The work ran as three waves of parallel agent delegation.

> Spec folder: `.opencode/specs/system-spec-kit/022-hybrid-rag-fusion-refinement/010-comprehensive-remediation/`

## Why This Release

Sprint 8 focuses on fixing important problems. Its goal is a workflow that is easier to follow and easier to trust.

## What's New at a Glance

- **Storage bugs are fixed in reconsolidation, checkpoints, causal edges and memory save.** The fixes reduce confusing failures and make the system more dependable.
- **Scores stay in range and stop over-counting.** The corrections span composite scoring, citation scoring, causal boost, the ablation framework and temporal contiguity.
- **Search filters and tokenization are fixed.** Stage 1 candidate generation, channel representation, the bm25 index and sqlite fts each get a correction.
- **The extraction adapter no longer falls back to the wrong memory.** The entity extractor now imports single shared helpers from the entity linker.
- **Dead shadow-scoring and RSF branches leave hybrid search.** Dead state, functions and exports go too, so the project is smaller and easier to maintain.
- **13 performance improvements land.** Queries get bounds and batching, lookups use a `Set` and the spec folder hierarchy gains a cache.
- **Four test quality fixes land.** They give the team clearer proof that the changes work.

## Storage

#### Reconsolidation Uses a Real Column

Reconsolidation referenced a `frequency_counter` column that does not exist. It now uses `importance_weight` merge logic instead.

&nbsp;

#### Checkpoint Restores Keep Their Transactions

SQLite silently auto-commits when it meets a database schema statement. During a restore in checkpoints, that corrupted the transaction boundaries. The schema statements now run before `BEGIN`.

&nbsp;

#### Causal Edge Queries Group Their Conditions

A query in causal edges had an operator precedence bug. It read `WHERE a AND b OR c` and now reads `WHERE a AND (b OR c)`.

&nbsp;

#### Memory Save Checks That Updates Landed

Memory save reported success on `UPDATE` statements that changed zero rows. A `.changes > 0` guard on those statements now catches them.

---

## Scoring and Search

#### Composite Scores Stay Between 0 and 1

A composite score could fall outside the [0,1] range. Composite scoring now clamps it with `Math.max(0, Math.min(1, composite))`.

&nbsp;

#### Citation Scores Stop Using Recency

Citation scoring had a fallback chain that conflated recency with citation authority. That chain is removed, and the score is 0 when there is no citation data.

&nbsp;

#### Cycles and Pairs No Longer Inflate Boosts

The recursive CTE in causal boost used `UNION ALL`, which let cycles amplify the boost. It now uses `UNION`. In temporal contiguity, the inner loop now starts at `j = i + 1`, which eliminates the double-counting of pair boosts.

&nbsp;

#### Ablation Math Handles Large Inputs

The ablation framework computed binomial coefficients the naive way, which could overflow for n>50. It now computes them in log space.

&nbsp;

#### Quality Filters Screen the Right Candidates

Summary candidates in Stage 1 now pass through the `minQualityScore` filter in stage1 candidate gen. In channel representation, `QUALITY_FLOOR` drops from 0.2 to 0.005, because RRF scores sit around 0.01 to 0.03 and the old floor filtered them out.

&nbsp;

#### One Tokenizer for Both Text Indexes

The bm25 index and sqlite fts did not share their FTS5 (built-in text search) tokenization. Both now run through one shared `sanitizeQueryTokens()` array.

&nbsp;

#### Entity Resolution and Shared Helpers

In the extraction adapter, a failed entity resolution now returns null. `normalizeEntityName` existed as divergent functions, and `computeEdgeDensity` was duplicated. Each is now consolidated into one version, and the surviving `normalizeEntityName` is Unicode-aware.

## Dead Code

#### Dead Flags, State and Exports Removed

The dead feature flag functions `isShadowScoringEnabled()`, `isRsfEnabled()` and `isInShadowPeriod()` are removed with the branches. So is the dead module-level state `stmtCache`, `lastComputedAt`, `activeProvider` and `flushCount`, along with 3 dead config fields. The dead functions and exports removed are the single-node `computeCausalDepth`, `getSubgraphWeights`, `RECOVERY_HALF_LIFE_DAYS` and `logCoActivationEvent`.

`computeStructuralFreshness` and `computeGraphCentrality` in fsrs are preserved, because they are planned features and not dead code.

## Performance

#### Summaries and Counts Scale Safely

The tfidf summarizer replaces `Math.max(...spread)` with a reduce-based max, which prevents a RangeError. The unbounded query in memory summaries gains a `LIMIT` clause. The mutation ledger now counts with a database `COUNT(*)` and `json_extract` instead of an O(n) JS scan.

&nbsp;

#### The Entity Linker Looks Up Less

The entity linker used O(n) `.includes()` checks and now uses a `Set` for O(1) lookups. Its edge counts ran as N+1 queries and now come from a batch query.

&nbsp;

#### Fewer Round-Trips and a Cached Tree

Causal edges drops the SELECT that followed each upsert and reads `lastInsertRowid` instead, which cuts 3 round-trips to 2. `buildHierarchyTree()` in spec folder hierarchy now sits behind a WeakMap TTL cache that lasts 60 seconds.

---

## Test Quality

#### A Longer Timeout and Rewritten Tests

The timeout in memory save extended.vitest rises from 5000 to 15000ms. The entity linker.vitest suite now calls `db.close()` in `afterEach`. Four tautological tests in integration search pipeline.vitest are rewritten. `isMemoryFile()` in memory parser now excludes `/z_archive/` paths.

---

## Upgrade Notes

No upgrade needed. No schema migration is required, and every change is a backward-compatible source-level fix. Dead code removal reduces the codebase's surface area, and the performance improvements are additive: caching, `Set` conversion and database optimization. Tests for the removed dead-code features were deleted.
