# v2.12.28.0, Operator Answers Reach the Decision Record

An answer the operator gives to an AI question used to reach a decision record only when someone retyped it, so the exact wording and the reason for a choice got lost. A full-auto `/speckit:save` now writes each captured answer into the bound packet's `decision-record.md` as a short decision, and keeps the question, the offered options and the answer verbatim in the same file under the same `Q` id.

> Spec folder: `specs/system-speckit/043-decision-capture/001-decision-capture-build` (Level 3)

&nbsp;

## What's New at a Glance

- **Claude answers are queued as you give them.** A PostToolUse hook on `AskUserQuestion` appends each answer to a gitignored queue, and drops questions about Gate 3, spec folders, worktrees, branches and commit or push permission. `SYSTEM_DECISION_CAPTURE_DISABLED=1` turns it off.
- **The save sweeps what the hook missed.** On Claude the sweep reads the session transcript and also offers plain chat questions you answered directly. On OpenCode it reads the SQLite store, and on Devin the stored transcripts.
- **The writer upserts, it never rewrites.** Each answer keeps one `Q` id across saves, a repeat save changes no byte, and hand-written ADRs and appendix items stay as they are. A hand-written row without a source key is matched by its question and answer text, so a later sweep does not add it twice.
- **A new record cannot move the packet's level.** The writer can create `decision-record.md` at any level. When `spec.md` carries no level marker, it first stamps the level the validator already detects.
- **The template names the two new sections.** `operator-decisions` holds the decision table and `operator-answers-verbatim` holds the exact exchanges.
- **The Stop hook tells you when answers are waiting.** It reports a rising count once, and a save that records only some answers lowers the count, so the next new answer is reported again.
- **The consumed log holds each key once.** A repeat save no longer appends the same keys to `consumed.jsonl`.

&nbsp;

## Upgrade

No migration required. An existing `decision-record.md` gains the two operator sections the first time a full-auto save writes a decision into it. A Claude Code session that was already running may need `/hooks` approval or a restart before the new hook fires. The save-time sweep covers the gap.
