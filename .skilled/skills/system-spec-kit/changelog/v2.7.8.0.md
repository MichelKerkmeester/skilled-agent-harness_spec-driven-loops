# v2.7.8.0, Short-Host Late-Write Coverage

v2.7.8.0 extends the stdin deadline suite from one short-deadline entry to all seven, and the hooks README now states what a host that writes late loses.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/015-closeout/005-stdin-late-write-coverage` (Level 1)

&nbsp;

## What's New at a Glance

- **Every short-deadline entry is covered both ways.** One table drives two tests: each of the seven entries acts on a payload written at once and drops the same payload written at 800 ms, past its 500 ms deadline. A third test fails when a short-deadline entry has no row.
- **The three copies of the 500 ms deadline are checked.** `shared-stdin.ts`, `lib/hook-adapter-shared.mjs` and the Claude prompt shim must agree, or the suite fails.
- **The residual risk is written down.** `runtime/hooks/README.md` names the seven entries and what each skips when a host writes after the deadline without closing stdin.
