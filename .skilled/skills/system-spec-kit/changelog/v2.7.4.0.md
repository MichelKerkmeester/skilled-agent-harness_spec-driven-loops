# v2.7.4.0, Changelog entries carry their version

v2.7.4.0 adds the version key to the frontmatter of every older changelog entry that lacked one, so each entry states its version the way newer entries do.

> Spec folder: `specs/sk-doc/066-feature-catalog-template-anchor-deprecation/005-changelog-version-keys` (Level 2)

&nbsp;

## What's New at a Glance

- **Every changelog entry now names its version in its frontmatter.** The value matches the entry's file name, and no entry text changed.

No migration required.
