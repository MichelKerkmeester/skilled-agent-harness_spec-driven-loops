# v2.12.49.0, the sweep names a numbered folder left without spec.md

A packet that moves into a sub-track can leave its ignored files behind under the old name. Git does not see that folder, so the mixed-track check missed it. One such folder sat in a local checkout as `specs/hooks-plugins-extensions/026-context-paging`.

> Spec folder: `specs/system-speckit/spec-folder-tooling/002-named-subtracks-and-host-repos/010-mixed-track-sweep-guard`

&nbsp;

## What's New at a Glance

- **The leftover is named.** In the working tree, `sweep-track-roots.mjs` prints `<track>/<folder>: numbered folder without spec.md beside sub-tracks`.
- **It is a warning.** The exit code does not change. Ignored local files are not the repository's state, and `--rev` never sees them.
- **Only tracks with sub-tracks are checked.** A flat track keeps its reference clones beside its packets as before.
