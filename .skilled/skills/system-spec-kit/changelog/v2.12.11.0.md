# v2.12.11.0, The Changed-Packet Gate Test Reads Its Event Values From the Step

The changed-packet gate used to write the pull request and push SHAs into its script. It now passes them through `env:` entries on the step. It reads them as shell variables. That keeps event text out of the script itself. The rule-set comparison test runs that same script against a fixture repository. So the test now reads the step's `env:` entries. It supplies them the way the runner would. The gate's real comparison is still what the test exercises.

&nbsp;

## What's New at a Glance

- **The test follows the workflow's own shape.** It takes the event values from the step. It does not take them from text written into the script. So a later change to those entries reaches the test without an edit. That holds as long as it uses an event value the test already substitutes.

&nbsp;

## Upgrade

No action is needed. No hook or CLI command changed behaviour.
