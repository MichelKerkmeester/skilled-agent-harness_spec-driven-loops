# Hermes Copies Carry the Router File

The Hermes agent runtime reads its own generated copy of each skill. Before this release, that copy held only `SKILL.md`, so a router kept in `ROUTER.md` never reached Hermes.

&nbsp;

## What's New at a Glance

- **Each copy carries its router.** A skill with a `ROUTER.md` gets that file beside its `SKILL.md` copy, written exactly as the source has it.
- **The seven hub skills reach Hermes with their routing maps.** Their `ROUTER.md` files now come across with their instructions.
- **The check catches a stale router copy.** `--check` reports a router copy that differs from its source, and a copy left behind after its source router was removed.

&nbsp;

## Upgrade

Run the Hermes sync once so existing copies pick up their router files: `node .skilled/skills/system-spec-kit/runtime/cli/hermes/sync-skills-hermes.cjs`. Then run it with `--check` to confirm the copies match.
