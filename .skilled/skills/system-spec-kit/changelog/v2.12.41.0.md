# v2.12.41.0, total candidates for trigger lookup

Gate 1 now shows how many documents matched before a result limit. A visible truncated line makes limited output easier to interpret.

> Spec folder: `specs/hooks-plugins-extensions/028-sweet-search-integration/004-total-candidate-count`

&nbsp;

## What's New at a Glance

- **JSON retains the full candidate count.** `totalCandidates` counts documents after `--scoring-only` and before `--limit`.
- **Limited results show when they are truncated.** The human line reads `candidates : 2 of 14 (truncated) from 9 phrase(s)` only when `totalCandidates` exceeds a non-zero `--limit`.
- **Research output differs by retrieval lane.** Trigger indexing skips `specs/**/research/**` except each packet's `research/research.md`. Ripgrep still searches those run outputs.
