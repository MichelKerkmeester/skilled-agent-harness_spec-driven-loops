# v2.6.2.0, Jev as the Only Classifier

Spec-kit's offline measurements and audits now support Jev alone. Four scorers drop their Deem arms and Deem docs, and `cli-jev` is the only classifier.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/046-deem-deprecation` (Level 2)

## What's New at a Glance

- **Track narrowing is Jev only.** `score-track-narrowing.mjs` drops its `--deem` arm and keeps its zero-call default and `--jev` arm.
- **Alignment suggestion is Jev only.** `score-alignment-suggestion.ts` drops its Deem arm and keeps its zero-call default and label gate.
- **The completion-claim audit is Jev only.** `score-completion-claims.mjs` drops its `--deem` arm, and its planned-calls line now counts Jev calls alone.
- **The debug next-check measurement is Jev only.** `score-debug-next-check.mjs` drops its `--deem` arm and keeps its payload gate on the `--jev` path.
- **The reference docs name Jev alone.** The feature catalog, manual testing playbook and READMEs no longer describe a second backend.

## Upgrade

No migration required. Every default run, label gate and `--jev` arm behaves as before.
