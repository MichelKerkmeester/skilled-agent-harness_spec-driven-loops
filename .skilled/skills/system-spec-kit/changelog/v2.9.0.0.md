# v2.9.0.0, Templates a Weak Model Can Follow

A weak model can now see what a template still needs. Every hint in the five core templates is a value token. That token fails validation once the packet leaves Draft. The four authoring intents also load a short card rather than the long guide. The examples no longer teach the defects the old text carried. The before and after benchmark found fewer leftover hints. Its missing-anchor criterion failed three times before it passed, as described below.

&nbsp;

## What's New at a Glance

- An unfilled hint can no longer pass as finished.
  - A doc stamped v2.3 warns while the spec is Draft.
  - That doc fails strict validation at any other status.
- Every core section says how to fill it.
  - Each section carries a short instruction and a good and weak example.
- Authoring starts on one page.
  - The router loads a short card for the four authoring intents.
- The examples stop teaching the old defects.
  - Their descriptions, stale checklist lines and anchors now match the templates.
- Commands and agents name the new gate and the card.
  - A speckit or doctor run describes the same authoring path a worker follows.
- The playbook and catalog cover the new behavior.
  - A focused run of eight scenarios passed on a disposable worktree.
- The `L3+` label says what it means.
  - The `tasks.md` template has six `## L3+:` headings.
  - The fill note under each one now opens with 'L3+ means Level 3 and above, so this section stays at Level 3.'
- The result is measured, and one criterion failed three times before it passed.
  - Leftover hints fell.
  - Every run passed strict validation.
  - The missing-anchor criterion passed on the fourth final set.
  - That came after the `tasks.md` fill notes were corrected (full record in `benchmark/reports/2026-10-25--model-eval--authoring-baseline/`).

&nbsp;

## Upgrade

No migration required. Existing packets keep their verdict. That is because the token gate applies only to docs stamped v2.3. Scaffold a new packet to get the new templates and the authoring card.
