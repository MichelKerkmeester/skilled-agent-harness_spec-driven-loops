# v2.12.15.0, The Implement Dashboard Uses the Quality Runner's Verdicts

The `/speckit:implement` dashboard printed its quality gate as `not-run`, `pass` or `blocked`. The sk-code quality runner never reports a pass, because its clean result says only that no blocker was found.

> Spec folder: `specs/sk-code/017-portable-code-modes/009-integration-fixes` (Level 2)

&nbsp;

## What's New at a Glance

- **The quality gate field copies the runner's gate.** It reads `NO_BLOCKER_FOUND`, `BLOCKED`, `UNVERIFIED`, `NOTHING_CHECKED` or `ERROR` from the last verdict read during the run, and `not-run` when none was read.
- **`pass` is gone from the dashboard.** A note under the dashboard says why, and that `NOTHING_CHECKED` never means the files are clean.
