# v2.1.5.0, Spec Validation You Can Switch Off

Some people do not care whether their spec folders match this repository's formats. They can now turn validation off once and keep working. `SPECKIT_SKIP_VALIDATION` used to trap commits. With it set, `validate.sh --json` printed nothing. So the pre-commit metadata gate read every staged packet as unreadable. It blocked the commit. A switched-off run now prints a report that says it skipped. Every local tool that reads that report counts the folder as skipped. It never counts it as passed.

> Part of [Skilled v4.0.0.2](../../../changelog/skilled/v4.0.0.2.md).

&nbsp;

## What's New at a Glance

- One switch, set where you like.
  - `SPECKIT_SKIP_VALIDATION` reads the environment first.
  - It reads `.skilled/hooks/hook-flags.env` second, so it can be saved once.
  - A set environment value wins even when it is `0` or empty.
  - That brings validation back for one run.
- Only truthy values turn it on.
  - `1`, `true`, `yes` and `on` skip validation.
  - Any other value leaves it on.
  - `SPECKIT_VALIDATION=false` takes the same path.
- A skipped run says so.
  - `validate.sh` prints one notice on stderr.
  - `validate.sh` names where the switch was set and exits 0.
  - Under `--json` it prints a report with `skipped: true`.
  - So the pre-commit metadata gate reads it as nothing to repair.
  - The commit goes through.
- The progressive wrapper keeps its JSON clean.
  - `progressive-validate.sh --json` used to mix the skip notice into its output.
  - So at level 1 the output did not parse.
  - The notice now stays on stderr.
  - The report carries `skipped: true`.
- Audits count a skip apart.
  - `quality-audit.sh` reports a switched-off folder as skipped.
  - `quality-audit.sh` totals it on its own line.
  - The strict-pass freshness sweep gives it a `skipped` status.
  - A skipped row in a baseline never makes a later failure look like a known one.
- CI keeps enforcing.
  - No workflow sets the switch.
  - The flags file is personal and ignored by git.

&nbsp;

## Upgrade

- Values that used to skip.
  - Any non-empty `SPECKIT_SKIP_VALIDATION` used to skip validation.
  - Now only `1`, `true`, `yes` or `on` do.
- Scripts that read the audit or the sweep.
  - A switched-off folder now reports `skipped`.
  - A switched-off folder used to count as a pass.
