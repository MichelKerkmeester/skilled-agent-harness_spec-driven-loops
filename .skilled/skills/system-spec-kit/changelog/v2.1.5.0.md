# v2.1.5.0, Spec Validation You Can Switch Off

Someone who does not care whether their spec folders match this repository's formats can now turn validation off once and keep working. `SPECKIT_SKIP_VALIDATION` used to trap commits: with it set, `validate.sh --json` printed nothing, so the pre-commit metadata gate read every staged packet as unreadable and blocked. A switched-off run now prints a report that says it skipped, and every local tool that reads that report counts the folder as skipped, never as passed.

> Part of [Skilled v4.0.0.2](../../../changelog/skilled/v4.0.0.2.md).
>
> Spec folder: `specs/sk-doc/062-doc-validation-off-switches` (Level 2)

## What's New at a Glance

- **One switch, set where you like.** `SPECKIT_SKIP_VALIDATION` reads the environment first and `.skilled/hooks/hook-flags.env` second, so it can be saved once. A set environment value wins even when it is `0` or empty, which brings validation back for one run.
- **Only truthy values turn it on.** `1`, `true`, `yes` and `on` skip validation, and any other value leaves it on. `SPECKIT_VALIDATION=false` takes the same path.
- **A skipped run says so.** `validate.sh` prints one notice on stderr naming where the switch was set and exits 0. Under `--json` it prints a report with `skipped: true`, so the pre-commit metadata gate reads it as nothing to repair and the commit goes through.
- **The progressive wrapper keeps its JSON clean.** `progressive-validate.sh --json` used to mix the skip notice into its output, so at level 1 the output did not parse. The notice now stays on stderr, and the report carries `skipped: true`.
- **Audits count a skip apart.** `quality-audit.sh` reports a switched-off folder as skipped and totals it on its own line. The strict-pass freshness sweep gives it a `skipped` status, and a skipped row in a baseline never makes a later failure look like a known one.
- **CI keeps enforcing.** No workflow sets the switch, and the flags file is personal and ignored by git.

## Upgrade

- **Values that used to skip.** Any non-empty `SPECKIT_SKIP_VALIDATION` used to skip validation. Now only `1`, `true`, `yes` or `on` do.
- **Scripts that read the audit or the sweep.** A switched-off folder now reports `skipped`, where it used to count as a pass.
