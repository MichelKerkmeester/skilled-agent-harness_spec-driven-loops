This release lays down some of the core rules the spec kit uses to judge whether work is ready to move forward. It also reorganizes a few internal scripts so the project is easier to maintain.

## What's New at a Glance

- **A two-part check decides when to continue.** It weighs both confidence and uncertainty before work moves ahead, which makes decisions more consistent and reduces the chance of pushing ahead on weak assumptions.
- **The Five Checks Framework reviews bigger changes.** Larger specs get more structure than a quick yes-or-no check, with fit, quality and maintainability reviewed before the work moves forward.
- **A session learning handler feeds the memory workflow.** `session-learning.js` remembers what happened during a working session, so later steps get more context and follow-up work is easier.
- **A script cleanup puts helpers in fitting folders.** `decision-tree-generator.js` and `opencode-capture.js` moved into `lib/` and `extractors/`. The move undoes a layout that made the codebase harder to navigate.
