# v1.7.0.0, Honest Verdicts, Earned Flags and a Search That Surfaces

v1.7 makes search more trustworthy. That runs from the verdict through the rows a reader receives. It also repairs generated spec records. It makes code-graph history safe to read.

A live query returned one result. It should have found many spec folders. The connected graph-history path could also expose closed edges in live reads. So the release fixes both read paths. It measures result-changing flags against real data.

Four dark-flag families earned graduation. Structural protections now run by default. Those dark-flag graduates keep their existing default-off flags until enabled. The true-citation ledger stays at refine until it can clear the reranker bar.

## Why This Release

Similarity scores, response limits and closed graph edges could each leave a result less reliable than it appeared. The release checks those paths against actual queries and data. It keeps dark-flag graduates behind their existing default-off flags. The honesty suite and safety protections run by default.

## What's New at a Glance

- **Search confidence follows evidence.** Keyword support, adjusted relevance and evidence depth now shape the verdict. A build gate refuses to pass when search returns a good verdict on a term it should know nothing about.
- **Matching folders stay in the response.** Trigger-lane matches reach the reader. Budget overflow becomes compact rows.
- **Generated spec records stay consistent.** Status and lineage rules prevent drift. Unchanged reads leave metadata alone.
- **Advisor outages are visible.** A lane that could not run is reported as degraded. Stale embeddings fail closed.
- **Code-graph answers keep their history.** Callers can request an earlier generation. Live reads show current edges.
- **Deep Loop preserves useful state.** Merges stay stable. Recovery exposes broken state. Interrupted work leaves a summary.
- **Dark-flag graduates stay opt-in.** Their existing flags remain default-off. Safety checks run by default. Unsupported work stays out.

## Search

#### Keyword Evidence Comes First

A high similarity score alone can no longer produce a good verdict. The top result needs a matching term in its title, trigger phrases or body. A BM25 keyword score already on the row also counts. A fluent but absent term such as `kubernetes` once earned a confident citation. That came from a single spurious high-cosine hit. It now reads weak. The lexical-grounding floor shipped quietly earlier. It graduated to on for everyone this cycle.

&nbsp;

#### Relevance Shows True Signal

Search subtracts a measured corpus noise floor for `nomic-embed-text-v1.5`. It does this before deciding whether a match is real. Embedder drift no longer pushes a marginal match into looking good. A semantic result now reports the same number the system ranks on. That is the calibrated absolute relevance on a 0-to-1 cosine scale. It is not the compressed RRF fusion magnitude that clusters low near 0.03. This fixes a residual path that was still reporting the wrong figure for semantic rows. Relationship and degree rows display their relevance rather than a blank dash.

&nbsp;

#### Thin Evidence Lowers Confidence

When evidence is thin, search caps a good verdict down to weak. The evidence-gap warning beside the verdict now always agrees with it. Both had been broken. The cap was wired to a signal nothing ever set. So it never fired. A known gap could surface beside a confident verdict. The warning was driven by a peakedness statistic. That statistic measured how far the top result stood above the pack. It was not driven by relevance. So a strong, tightly clustered set of good matches got the warning. A flat spread of weak off-topic matches slipped through clean. The cap is now connected. The warning keys off the same noise-floor-subtracted relevance the verdict uses. So a search for a real term like `graph` stays quiet. A genuine gap is flagged once, consistently. A benchmark of the old warning found it raised false alarms on two of every three strong queries. The redesign brought that to zero.

&nbsp;

#### A Guard Against Confident Hallucination

A build gate now refuses to pass when search returns good verdicts on terms it should know nothing about. Six bare off-corpus queries run through the production verdict path: kubernetes, oauth, kafka, terraform, graphql and webpack. The gate fails if too many false confirms slip through. The ceiling is set at zero. It is the regression net under the grounding and noise-floor work above.

&nbsp;

#### Results Keep Their Meaning

The dashboard header count now matches the rows actually shown. It does not match a pre-trim total. A long folder path displays its leaf title. It is not cut off mid-string. A status field that had reported an unrelated mechanism now reports the expected status.

&nbsp;

#### Search Works Through Outages

The embedding service can be unavailable. It can also return no embedding. Then search falls back to keyword matching. It marks the dense channel as skipped. So an outage returns the best lexical answer rather than an empty result. The healthy path stays unchanged.

&nbsp;

#### Budget Trimming Keeps Answers

Tail-appended backfill rows are now exempt from the response-serialization token budget. So a backfill row added past the limit is not the first thing cut. Trimming can threaten the primary results. Then the response now reserves at least one primary row. It keeps a pinned constitutional rule ahead of additive backfill. So the squeeze can thin the result set. It never sacrifices the answer you asked for.

&nbsp;

#### Multi-Hop Fills Deep Results

The deterministic multi-hop and lane-champion backfill appends were measured. They graduated for deep-K readers. They now reach readers who request deep result sets. Complete recall at twenty rose from just over half to almost all on labelled multi-target queries. Shallow rankings stayed flat.

&nbsp;

#### Query Shape Controls Expansion

Every query is classified once by its retrieval shape. That happens before the pipeline runs. The five-class query classifier is on for everyone. Shape routing can be enabled. Then a single-hop lookup skips graph-relation expansion. A multi-hop question keeps graph-aware ranking. How you call search does not change. Shape routing stays opt-in behind `SPECKIT_RETRIEVAL_CLASS_ROUTING`, which is off by default. The per-class weight profiles stay opt-in too.

&nbsp;

#### More Matching Folders Surface

Trigger-lane matches had been excluded from the surfaced results, even when they ranked. They now reach them. A display floor of ten now holds. Budget overflow becomes compact rows at both the pipeline and envelope levels. It is not deleted outright. The folder-discovery listing also excludes `z_future` folders. So future-staged folders stop diluting the live result set. The same live `memory_search` query had returned one result. It now returns six, with one full row and five compact rows.

&nbsp;

#### Valid Inputs Reach Search

An empty-string filter now reads as a no-op. It is not rejected as malformed. Search also accepts `retrievalLevel` instead of rejecting it. So either input can reach the query.

&nbsp;

#### A Probe Shows Citation Readiness

The true-citation emitter is sound. It stays at refine until real session-carrying traffic accumulates. This release adds a density probe. It surfaces through the health check. It reports when the ledger has accumulated enough session-scoped pairs. Its per-class floor and minority-ratio floor keep a lopsided ledger from graduating the reranker on a count alone. The probe observes without flipping anything on.

&nbsp;

#### Citation Holds Across Models

A 144-cell benchmark drove `/memory:search` with four models, MiMo, Kimi, DeepSeek and gpt-5.5 fast. It ran across twelve deliberately vague queries. The verdict held up where it should. On clearly aligned and clearly empty queries every model agreed. The citation rule was obeyed wherever a model emitted a full verdict. The divergence is on borderline queries. Two of the twelve split the verdict there. That is because each model refined the vague search differently and landed on different results. It is not because the verdict logic wavered. The benchmark also isolated the off-corpus false confidence. The grounding and noise-floor graduations then closed it. DeepSeek came out the most efficient and stable driver. Kimi over-explores expensively on the vaguest queries.

&nbsp;

#### Follow-Up Fixes Hold Their Contract

The forty-one spec-kit P1 items shipped a cluster of real fixes. The evaluator now reads the DB path it was handed. It does not read a shared reference. A BM25 sync guard keeps the keyword index aligned with the rows it scores. `QUALITY_FLOOR` documentation now describes the floor the code enforces.

Three further fixes that had been deferred were completed. Query surrogates now sit under their own `SPECKIT_QUERY_SURROGATES` gate. So the feature is opt-in. Reorganizing a folder now repoints its index rows. It does not drop its embeddings. The global `retrievalLevel` branch now honors the `SPECKIT_DUAL_RETRIEVAL` kill switch. It does so alongside the archived-deny default and constitutional injection.

## Spec Records

The generated `description.json` and `graph-metadata.json` files feed memory search and graph traversal. They had been hand-driftable and noisy.

#### Statuses Stay Within Their Set

Generated spec metadata now uses a closed status set. It does not use free-form prose. A first-class validator checks `description.json` and `graph-metadata.json`. Legacy hand-edited statuses are re-derived into safe values. They are surfaced for review rather than left to leak through.

&nbsp;

#### Reads Leave Files Clean

Generated content can be unchanged. Then the generator skips the write, even if volatile timestamps differ. A targeted cache update can refresh one folder without rebuilding its neighbors.

Access and freshness telemetry now lives in the index layer. It does not live in generated JSON. So reading or resuming no longer dirties unchanged metadata.

&nbsp;

#### Refreshes Stay Scoped

The backfill tool now takes a folder argument. It defaults to that single folder. So a one-folder intent no longer quietly dirties the whole tree. A repository-wide run requires `--all`. Archived and future-staged folders stay out of the descriptions cache under one policy. Archive memory behavior remains intact.

&nbsp;

#### Lineage Survives Partial Refresh

Parent and child relationships reconcile across partial rescans. So a valid parent survives when a subscan misses it. Child lists grow safely unless an operator explicitly prunes them.

The description and causal-summary fields now derive from one shared synopsis rule. So they stop drifting apart. A drift checker re-derives them on read against a stored source-document hash. It reports staleness without writing anything. A saved source fingerprint shows freshness without rereading the document.

&nbsp;

#### Backfill Damage Was Corrected

A backfill against the wrong base path polluted eleven `description.json` files. It wrote incorrect `parentChain` values. The cleanup restored correct lineage. It corrected four earlier remediation claims against the real state. It restored four missing `children_ids` to a phase parent.

&nbsp;

#### The Migration Settles Cleanly

The whole spec tree was regenerated under the new metadata contracts. That is 2,049 spec folders, including archives. The second run produced byte-identical output with no validation violations. A graduation benchmark then measured every default-off flag against the migrated tree. Twelve flags earned their way to default-on or enforcing. They cover the metadata integrity gates and the search-honesty suite.

&nbsp;

#### Pending Refreshes Stay Open

The local embedding provider remains degraded. Its retry circuit breaker is open. That blocks a `parentChain` index refresh until the provider recovers. A `validate.sh` global-index-reconciliation preventive is deferred to a later cycle.

## Skill Advisor

#### Down Lanes Are Not Empty

A scoring lane can be runtime-degraded. Then the advisor no longer counts it against a skill as if it had run and found no match. Degraded lanes leave the confidence denominator. A lane that ran without a match still counts.

Advisor output and abstention explanations now name the degraded state plainly. They do not hide it inside a low score.

&nbsp;

#### Old Embeddings Fail Closed

The advisor records which vector model produced each semantic projection. It checks that against the active embedder on every read. A mismatch marks the semantic shadow lane degraded. The lane then follows the same lane-health rule. It does not quietly trust a projection built by a different model. Legacy projections without a model signature now fail closed. They are not assumed safe.

&nbsp;

#### Fusion Keeps Its Safety Net

Reciprocal-rank fusion (RRF) lifted top-one by one on a widened forty-two-prompt set. It had no regressions and near-total deterministic agreement. It graduated with conflict reranking. That repairs a case plain fusion would otherwise break.

&nbsp;

#### The Alias Penalty Covers Both

The separate self-recommendation guard was cut as behaviorally redundant. The generic explainer floor and an un-flagged penalty already did its work. The remaining implicit penalty was the only thing stopping the advisor from recommending itself. That held on an audit or explainer prompt. That penalty was undocumented. So a future refactor could have removed it without anyone noticing. It now carries a durable explanation. It had also matched only the advisor's exact id and missed its alias. The alias still recommended itself to the top in the default configuration. The penalty now matches the canonical ID set. So both the exact name and the alias are demoted. The penalty value is unchanged. This behavior change is not flag-gated.

## Code Graph

#### Parser Hiccups Can Recover

A parser hiccup no longer condemns a file to permanent invisibility. Transient parse failures now retry up to `SPECKIT_PARSER_SKIP_LIST_MAX_RETRIES`. That defaults to 5. A successful reparse clears the skip-list entry. A fatal entry still skips immediately for human review.

&nbsp;

#### Graph Order Stays Stable

Equal-trust context edges now sort by stable content-derived keys. They do not sort by database return order. Repeating a query over the same data produces the same order across scan rebuilds. There is no phantom reordering in a diff.

&nbsp;

#### Documents Join Graph Search

The documentation lane now indexes Markdown headings as graph symbols. It also indexes JSON, JSONC, YAML and TOML config keys. All of that comes from local parsing, so nothing leaves your machine. Config indexing runs by default. Markdown extraction is opt-in through globs.

&nbsp;

#### Generation Shows Freshness

Each promoted scan advances a generation number that only increases. Freshness envelopes expose it as `metadata.freshness.generation`. Failed promotions and no-op scans leave the number unchanged.

Reads continue serving the generation that is present, even when it is stale. A hard gate that rejects stale-generation reads remains deferred.

&nbsp;

#### Reparse Cost Has a Bound

The reverse-dependency degree cap decides how many importers get re-bound. That happens when a high-fan-in dependency is renamed. Before this release it defaulted to uncapped. So renaming a thirty-importer module re-parsed all thirty. It now defaults to fifteen. That fully repairs the common-to-moderate refactor at negligible cost. It also bounds the unmeasured hundred-plus-importer tail. The cap is read only inside the force-parse branch, which is off by default. A high-fan-in rename above the cap leaves overflow importer edges stale. They stay stale until each importer is next edited.

A cost sweep found rebinding grew linearly. It ran at about a third of a millisecond to under a millisecond per importer over a seventeen-millisecond scan floor.

&nbsp;

#### Historical Queries Return Past State

The first wiring left the as-of reader with no caller. So the feature was held out of scope. It was not claimed as done. Code-graph queries now accept an optional as-of generation. So a historical read can include edges to nodes deleted since that generation. A query without the parameter returns the current graph exactly as before. The history surface stays byte-identical while its flag is off.

&nbsp;

#### Live Reads Keep Current Edges

The bitemporal close-and-insert writer was built but never wired into the reindex path. So it was held at refine. The production-readiness pass wired it in. Before the fix, turning its flag on would have corrupted every live read. The live edge readers had no filter for closed edges. So after a reindex they returned both the superseded edge and its replacement. The full-scan prune deleted dangling edges regardless of the flag. Node replacement deleted a symbol's edges before the close path could run. So an as-of query came back empty. History can be enabled. Then node replacement and full-scan pruning close old edges instead of deleting them. Live readers return only current edges. A generation-stamp correction gives every superseded edge a real readable window. It is not a zero-width one.

## Deep Loop and Release Decisions

The deep-research and deep-review loops are the multi-iteration `/deep:*` workflows. They fan work out across parallel model workers. They gained determinism, recovery and observability fixes.

#### New Runs Can Reduce State

A brand-new deep-research run no longer crashes on its first pass. The strategy template now includes the anchors where carried-forward state is written. A fresh deep-research run has somewhere to land its first reduction. It can carry state into the next pass.

&nbsp;

#### Parallel Results Merge Consistently

Research and review registries now sort lineage labels and worker identity. They do this before merging parallel results. The combined output no longer depends on which worker finishes first.

&nbsp;

#### Stops Need Outside Evidence

Deep-research can accept a STOP for lack of new ground. Before that, it compares the run's novelty report with graph-observed changes. Those changes cover stored questions, findings and evidence. It blocks a stop the graph cannot support.

&nbsp;

#### Conflicts Remain Visible

Workers can return the same finding ID with different content. Then the merge keeps both as conflicting variants. It does not let the first arrival erase the other. A person can review the actual disagreement.

&nbsp;

#### Retries Keep Their Budget

Fan-out timeouts, exits and salvage misses are tracked as separate failure types. A salvage miss means recoverable output went missing. Only transient failures retry. Durable run logs preserve retry counts across crashes.

&nbsp;

#### Recovery Shows Broken State

A state file can be missing or corrupt. Then recovery stops instead of treating the run as new. It also marks worker lineages that started but never reported back. So partial state remains visible.

&nbsp;

#### Interrupted Runs Keep Their Work

Live fan-outs report pending, failed and lag gauges from real run state. An interrupted run leaves a partial summary. That summary covers the work completed before it stopped.

&nbsp;

#### Open Questions Carry Forward

Deep-research carries unresolved questions into the next iteration without another model call. The reducer builds a continuity thread from the previous pass. It derives the next focus from those questions or the latest finding.

&nbsp;

#### Dedup Checks the Title

The near-duplicate finding collapse graduated on a clean benchmark. It was then scale-validated past its original handful of synthetic records on a larger free-text set. That scale test showed the dedup key ignored the finding title. So two distinct findings collapsed into one. They shared a body but differed only in their title. The key now applies a title-overlap gate. So disjoint titles stay separate. A true restatement still merges. Title-only false collapses fell from one in two to zero. Exact duplicates still collapse. Distinct-finding recall holds.

&nbsp;

#### Lag Measures Real Stalls

The old lag gauge counted time since a worker was queued. That is queue back-pressure. So any healthy fan-out wider than its concurrency tripped the alarm. It now measures time since the last completion while work remains pending. That keeps healthy busy pools quiet. It fires once for a genuinely hung worker.

The recommended ceiling dropped from five minutes to two. That is because it no longer drifts on healthy load. The committed default stays off. Turning the gauge on is the separate graduation step.

&nbsp;

#### Graduates Keep Their Boundaries

Four of the eight dark-flag families earned graduation on the real graph and corpus. They are multi-hop appends, code-graph staleness repair, advisor RRF fusion and Deep Loop deduplication. The code-graph staleness degree cap graduated with a benchmarked default. The bitemporal edge writer graduated after the review caught its corruption and the repair closed it. The Deep Loop dedup graduated with its lag and heartbeat gauges. These result-changing graduates keep their existing default-off flags. They remain byte-identical while off. So the production flip stays a separate, evidence-gated decision.

&nbsp;

#### Protections Run by Default

Lexical grounding, noise-floor subtraction, evidence-gap handling, relevance-aware warnings and calibrated scores run on. They run with the cite-with-caveat tier, the envelope-fidelity guard, spec-metadata integrity gates and the false-confirm build gate. The type-safe status validator runs in a non-blocking report mode. That lasts during the migration window before it enforces.

Three flags also ship on without a headline. They make the records safer rather than the verdicts smarter. Derived-id provenance gives every causal edge a content-addressed ID. Retention-forgetting is a deletion safety guardrail. It keeps a cleanup from removing more than it should. The world-summary grounding prelude seeds a search with a short factual frame before it runs. None of them change a number you read.

&nbsp;

#### Measured Cuts Stay Out

A large body of work was built in full. It was measured against the corpus and then declined. It did not earn its place. The entire semantic-edge layer family went this way. That covers the edge vector index, edge triplet search, edge semantic dedup and invalidation, edge presence currentness and bitemporal recall. Agentic recall went this way too. So did sleeptime consolidation, the procedural-reliability lane, the cardinality penalty, summary fusion, the grounding-signal field and deterministic ranking.

The dark-flag reckoning then cut five more on a measured loss or tie. The per-class retrieval weights hurt single-hop precision. They guarded a cost that did not exist. The save reconsolidation cosine band merged almost nothing it should have. The seeded PageRank tied the flat walk on every metric. A later revisit reconfirmed the cut with a wider margin. That revisit ran once the prerequisite the original benchmark record had named was built. The closed-vocabulary edge governance was cut too. The advisor self-recommendation guard was redundant with logic already running. A purely informational flag was removed. It showed no measured gain.

&nbsp;

#### Freshness Unblocked Two Flags

- The first metadata migration did not write the freshness field two flags needed.
- A rerun wrote that field. That allowed both flags to graduate.

&nbsp;

#### Remaining Advisories Stay Scoped

The two surviving advisories concern only the as-of read surface. That holds while its flag is enabled. Neither applies to a live read.

## The Follow-Up Deep Review

#### Code-Graph P1s Were Already Resolved

A follow-up deep review surfaced fourteen P0, sixty-nine P1 and eighty-four P2 findings. The P1 backlog was then remediated area by area. It was not done in a single sweep. So each fix carries its own evidence. The six code-graph P1 items were already resolved by the committed gating. They were confirmed rather than re-fixed.

## Upgrade Notes

No migration is required. Nothing changed on the common path.

- Stop setting `SPECKIT_DETERMINISTIC_RANKING` if you used it. The flag was removed. Ranking follows recency as it did by default.
- Choose whether to enable the dark-flag graduates.
- Bitemporal edge reads can be enabled. The recommended degree cap is fifteen. Code-graph queries accept the optional as-of generation.
- Deep Loop gauges can be enabled. Use a two-minute lag ceiling and a thirty-second heartbeat.
- The advisor self-recommendation penalty change is the one deliberate behavior shift that is not flag-gated. That is because demoting the advisor's own alias on an audit prompt is a correctness fix. The un-aliased path already applied it.
- The search-surfacing fix is a correctness change on the live read path. So a query that under-surfaced before now returns its full match set. Overflow degrades into compact rows.
