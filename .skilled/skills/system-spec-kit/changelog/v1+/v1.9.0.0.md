# v1.9.0.0, Leaner Templates and Bounded Search

v1.9.0.0 brings five template-and-context optimizations from a deep-research packet.

- The research template renders less at low documentation levels.
- The spec, plan, tasks and implementation-summary templates render byte-for-byte identically to before at every level.

The release adds default acceptance advice and an opt-in scope check.

- It adds default acceptance-coverage advice.
- It adds an opt-in scope check.

Search and documentation round out the release.

- It adds a response budget for `memory_search`.
- References cover the new rules.
- Originating research is consolidated into packet 034.

&nbsp;

## Why This Release

The release closes two template gaps.

- The research template rendered in full at every documentation level.
- The spec templates repeated full copies across levels.

## Templates and Guidance

This section covers template rendering and agent guidance.

#### Low-Level Research Stays Focused <a id="c-low-level-research-stays-focused"></a>

- The `research.md.tmpl` template rendered its full document at every documentation level.
- So a Level 1 packet carried the complete document.
- It now renders an essentials-only scaffold at Level 1.
- Level 3, Level 3+ and phase still render the complete document byte-for-byte identically to before.

#### Spec Templates Share a Core <a id="c-spec-templates-share-a-core"></a>

- The spec, plan, tasks and implementation-summary templates each held four near-identical full copies.
- They now use one shared core with per-level additions.
- The *Reading a Template (Agents)* guide directs agents to use the rendered, level-appropriate view.
- Agents use that view instead of the raw `.tmpl` file.
- Every level still renders byte-for-byte identically to before.

&nbsp;

## Acceptance and Scope Checks

This section covers the two advisory checks added in this release.

#### Acceptance Coverage Runs by Default <a id="c-acceptance-coverage-runs-by-default"></a>

- The `AC_COVERAGE` rule was implemented but disabled by default.
- It now runs by default as a non-blocking INFO advisory.
- Under-coverage shows a message.
- It never warns, errors or blocks `--strict`.
- The manual-infeasible escape hatch and the 0.9 floor are unchanged.

#### Scope Checks Flag Out-of-Scope Changes <a id="c-scope-checks-flag-out-of-scope-changes"></a>

- The new opt-in `check-scope-adherence.sh` (`SCOPE_ADHERENCE`) advisory warns when changed files fall outside a packet's declared *Files to Change*.
- Supply a change-set through `SYSTEM_SCOPE_CHANGED_FILES` or `SYSTEM_SCOPE_BASE`.
- Packet documentation is always in scope.
- With no supplied change-set, the rule does nothing.

## Memory Search

This section covers how search results fit the caller's context.

#### Search Fits Its Budget <a id="c-search-fits-its-budget"></a>

- Large `memory_search` result sets could flood the caller's context.
- The search now enforces a token budget.
- It drops lowest-score results first, mirroring `memory_context`.
- It truncates before feedback telemetry is emitted.
- So telemetry records only the results actually returned.
