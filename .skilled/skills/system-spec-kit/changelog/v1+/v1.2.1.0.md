This release simplifies memory work by consolidating its commands, improving intent detection and adding cross-platform temporary-file handling. It also adds checkpoint safeguards, updates memory commands and corrects memory guidance.

## Why This Release

The smaller command set gives users a simpler mental model.

## What's New at a Glance

- **Memory commands are consolidated.** The set falls from 9 to 5.
- **Intent detection is updated.** It avoids false positives.
- **Checkpoint operations gain safeguards.** They cover checkpoint restores and cleanup.
- **Temporary-file handling is added.** It works across platforms.
- **Search and causal-tracing commands change.** `/memory:search` gives way to `/memory:context`, and `/memory:why` is removed.
- **Memory guidance is corrected.** The changes cover MCP tool references and details in learn and context.

---

## Memory Commands

#### Operations Share One Command

`/memory:manage` is the unified command for database, checkpoint and maintenance operations. `/memory:database` and `/memory:checkpoint` are consolidated into `/memory:manage` and marked deprecated.

&nbsp;

#### Corrections Move Into Learn

`/memory:learn` now includes the `correct` subcommand for corrections. `/memory:correct` is consolidated into `/memory:learn correct` and marked deprecated.

&nbsp;

#### Search and Causal Tracing Change

`/memory:search` is replaced by `/memory:context` and marked deprecated. `/memory:why` is removed and marked deprecated, and causal tracing is available via MCP tools.

&nbsp;

#### Intent and Temporary-File Handling

Intent detection now uses phrase-based matching, which avoids false positives. Temporary-file handling is added across platforms.

---

## Checkpoint Operations

#### Restores and Cleanup Gain Safeguards

Rollback is added for checkpoint restore operations. Checkpoint validation is added before cleanup operations.

---

## Memory References and Guidance

#### Tool References Match Names

`memory_drift_context` is corrected to `memory_context`. References to the nonexistent `memory_drift_learn` tool are removed.

&nbsp;

#### Learning and Context Details Are Corrected

The `AutoImportance` type inconsistency is fixed in learn. The example numbering gap is fixed in learn, and the context date typo changes from 2026 to 2025.

## Upgrade Notes

- **Use `/memory:manage`** for database, checkpoint and maintenance operations.
- **Use `/memory:learn correct`** for corrections and `/memory:context` instead of `/memory:search`.
- **Use MCP tools** for causal tracing rather than `/memory:why`.
