This patch release fixes session isolation problems in the review-improvement bundle. It also fixes wave-state and optimizer-boundary problems there. It aligns board merging, replay metrics and coverage-graph behavior.

## Why This Release

These changes make day-to-day use safer and more predictable. The release scope does not change.

---

## What's New at a Glance

- **Coverage-graph reads now enforce session scope.** Cross-session aggregation requires explicit admin scope. Non-admin reads require `sessionId`.
- **Optimizer output and search stay within declared limits.** Corpus helpers no longer hide integrity failures.
- **Hotspot scoring and wave transitions now block false positives and illegal jumps.** Wave decisions follow composite scoring. They also follow a controlled phase order.
- **Board merging and replay metrics now use consistent contracts.** Finding identity and replay metric shape are aligned.
- **Coverage-graph session normalization is centralized.** Auto-created nodes propagate `metadata.sessionId`. Cycle handling implements the documented fallback.

---

## Session and Optimizer Safety

#### Coverage Queries Stay Session-Bound

Coverage-gap, unresolved-finding and contradiction queries used bare IDs in subqueries. So records from another session could satisfy them. The queries now apply the full `spec_folder`, `loop_type` and `session_id` identity. They do this in their `NOT EXISTS` subqueries and contradiction joins.

Read tools allowed cross-session aggregation without explicit admin scope. Non-admin reads now require `sessionId`. A shared query helper applies the same scope everywhere. `coverage-graph-signals.ts` carries it through nested edge lookups.

&nbsp;

#### Optimizer Changes Stay Bounded

The promotion-report save path could write to arbitrary repository locations. Promotion output is now limited to a dedicated audit directory. It rejects symlinks.

Config search accepted out-of-bounds changes and changes to locked fields. The evaluator now requires a manifest. It takes the search space from that manifest. It rejects unknown or locked fields. Corpus helpers hid integrity failures. They now fail loudly when integrity checks break.

---

## Wave Behavior

#### Hotspots Need Composite Evidence

The hotspot spread calculation treated every directory at median complexity as a hotspot. That produced false waves in otherwise uniform inventories. Hotspots now need a composite score strictly above baseline. That score includes churn and issues. It is not `complexity >= median` alone.

&nbsp;

#### Research Domains Cluster Correctly

Cluster assignment relied on the TLD. That grouped unrelated research domains together. Fallback clusters now use a registrable-domain or topic-based rule.

&nbsp;

#### Wave Phases Follow Required Order

Phase advancement enforced forward progress. But it allowed jumps straight to merge, skipping required phases. An allowed-transition matrix now restricts the phase order. Non-adjacent jumps need an explicit audited API.

---

## Board and Replay

#### Finding Merges Keep Their Identity

Deduplicating by `findingId` alone collapsed distinct segment findings. Storage and replay now use `(sessionId, generation, segment, wave, findingId)` as the full composite key.

&nbsp;

#### One Merge Path Preserves Provenance

Lifecycle, board and segment-state each implemented merge and provenance rules differently. The board module now owns a shared merge path. Lifecycle and segment-state call it instead of carrying separate versions.

&nbsp;

#### Board Status Follows Lifecycle

The board transition API existed. But the main board did not advance its own status. `updateBoard()` now routes lifecycle updates through `transitionBoardStatus()`. That lets the board advance its own status.

&nbsp;

#### Replay Metrics Match

Corpus extraction and the runner expected different replay metric shapes. The corpus builder now emits the shape the replay runner expects.

---

## Coverage Graph

#### Session Scope Reaches Auto-Created Nodes

Session handling in `coverage-graph-core.cjs` now uses a shared normalization helper. Auto-created nodes propagate `metadata.sessionId`.

&nbsp;

#### Edge Activity Has One Name

The helper was called `computeMomentum`. It is now called `computeRecentEdgeActivity` in `coverage-graph-signals.cjs`. The compatibility alias was removed. The TypeScript export adds a `sessionId` parameter.

&nbsp;

#### Graph Rules Match Their Contracts

Cycle handling in `coverage-graph-signals.cjs` skipped the documented fallback for cyclic components. It now uses that fallback. `coverage-graph-session.cjs` rejects mixed-session edges without explicit `edge.sessionId` or documents the precedence rule.
