This release adds test coverage across cognitive memory, MCP handlers, session learning, validation rules and the Five Checks Framework. It also corrects the `IsValidTier` import mismatch by changing the name to `is_valid_tier`. The release explains its main changes in simple language to make them easier to understand.

## Why This Release

The added coverage gives stronger proof that the tested areas work as expected. Correcting the memory import mismatch reduces confusing failures and makes the system more dependable.

## What's New at a Glance

- **The test suite covers more of the system.** Coverage reaches memory operations, MCP handlers, session learning, validation, templates, data loading and Five Checks.
- **The memory import name is corrected.** `IsValidTier` changes to `is_valid_tier`.
- **The test READMEs are updated.** The scripts test README also corrects its file count.
