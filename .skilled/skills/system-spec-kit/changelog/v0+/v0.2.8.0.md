This release makes YAML prompt assets and `.md` command files more compact. Because of that, the main changes are easier to understand. The project is easier to maintain too.

## What's New at a Glance

- **YAML prompt assets use compact flow notation.** The 13 YAML prompt assets in `command/spec_kit/assets/` use `{key: value}` and `[a, b]` notation. This compresses the YAML. The update removed decorative separators. It removed verbose description fields. It also removed Mermaid diagrams never rendered in CLI.
- **The `.md` command files are more compact.** The 7 `.md` command files in `command/spec_kit/` and the YAML changes make 20 files. All routing logic, workflow steps and config keys were preserved. Step counts and asset paths were preserved too.

No migration required.
