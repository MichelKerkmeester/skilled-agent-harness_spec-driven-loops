# system-spec-kit v0.0.0.1

This release does deep analysis and remediation across the whole project.

- It improves memory-conflict reliability.
- Memory-conflict handling is more reliable.
- Three critical bugs are fixed.

It aligns the schema, gate guidance and project naming.

- Migration v12 updates `memory_conflicts`.
- The schema moves from version 11 to version 12.
- Gate numbering is standardized.
- Project naming changes.

It also updates the instructions and release notes that guide the workflow.

- Skill references and capability lists are refreshed.
- The Skill advisor, context server and access tracker are updated.

&nbsp;

## Why This Release

The release focuses on instructions and release notes.

- It makes them easier for non-developers to follow.
- The goal is a workflow that is easier to follow and trust.

## Memory Schema

#### One Conflict Schema <a id="c-one-conflict-schema"></a>

- The vector index, `create_schema()` and prediction error gate used incompatible column names.
- The names were for `memory_conflicts`.
- They were unified in a 14-column schema.
- The schema was applied with DROP+CREATE.

<details>
<summary><b>Smaller fixes</b></summary>

- The schema migration test now uses the v12 column names.
- README schema references were also updated.

</details>

#### Conflict Writes Fail Clearly <a id="c-conflict-writes-fail-clearly"></a>

- A `CREATE_LINKED` database constraint was added to the `memory_conflicts` CHECK constraint.
- It went into the migration v4 schema and `create_schema()`.
- `Ensure_conflicts_table()` became a no-op in the prediction error gate.
- Silent try/catch was replaced with `console.error()` logging.
- Both INSERT paths now use `similarity` instead of `Similarity_score`.
- They use `reason` instead of `notes`.
- These changes reduce confusing failures.
- They make the system more dependable.

&nbsp;

## Workflow Guidance

#### Gate Guidance Matches <a id="c-gate-guidance-matches"></a>

- Gate enforcement now maps Gate 1 to Understanding.
- It maps Gate 2 to Skill Routing and Gate 3 to Spec Folder.
- Stale Gate 4/5/6 references were removed.
- The legacy install guide changed from seven gates to three gates.
- It also gained three behavioral rules.
- Decision format and epistemic vectors received gate-number corrections.

#### Project Naming Matches AGENTS <a id="c-project-naming-matches-agents"></a>

- Fifty-nine files were updated with about 218 replacements.
- The replacements change CLAUDE to AGENTS.
- This standardizes the naming used across the project.

&nbsp;

## Skill References

#### References and Lists Align <a id="c-references-and-lists-align"></a>

- Five section references were fixed.
- Template file counts were standardized across speckit, SKILL and README.
- The Capability Scan gained 4 missing commands and 3 scripts.
- SKILL's Key Scripts table gained 3 scripts.

#### A Complete Tool Architecture <a id="c-a-complete-tool-architecture"></a>

- The speckit tool layers were rewritten.
- The wrong 5-layer structure became a 7-layer, 22-tool architecture.
- References to `memory_drift_context` and `memory_drift_learn` were removed.

&nbsp;

## Runtime Behavior

#### Intent Support and Shutdown <a id="c-intent-support-and-shutdown"></a>

- The Skill advisor's memory/context intent boost passes the 0.8 threshold.
- Debug disambiguation was added.
- In the context server, `toolCache.shutdown()` was added.
- It covers shutdown signal, termination signal and `uncaughtException`.
- The access tracker no longer has duplicate handlers.
- The duplicates were for shutdown signal and termination signal.
