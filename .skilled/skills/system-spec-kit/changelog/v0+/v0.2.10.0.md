# v0.2.10.0, Dependencies Install per Workspace

Dependencies install inside each workspace instead of at the root.

- A new `.npmrc` file sets `install-strategy=nested`.
- npm installs dependencies per workspace instead of hoisting them to the root.
- The root package drops `better-sqlite3`.
- `mcp-server/package.json` adds `sqlite-vec-darwin-arm64` as an optional dependency.

Setup paths point at the workspace dependency folder.

- The `lib/cache/cognitive` symlink is corrected.
- The install guide updates its package references.
- Install spec kit memory commands change targets.

The dependency checks probe the workspace folders.

- `Check native modules` updates its probe path.
- `Rebuild native modules` updates its location.
- `Folder detector` and `Test folder detector functional` paths change together.

&nbsp;

## Why This Release

People working on the server needed clearer setup paths and less confusion.

- The goal was to make the workflow easier to follow and trust.

## Dependency Installation

Dependency installation changes where npm puts packages. Installs stay local to each workspace.

#### Dependencies Install per Workspace <a id="c-dependencies-install-per-workspace"></a>

- A new `.npmrc` file sets `install-strategy=nested`.
- The setting changes how npm installs dependencies.
- npm installs dependencies per workspace instead of hoisting them to the root.
- This makes setup and maintenance easier to manage.

#### The Root Package Drops a Dependency <a id="c-the-root-package-drops-a-dependency"></a>

- The root package drops `better-sqlite3`.
- The dependency was redundant there.

#### A Native Dependency Is Added <a id="c-a-native-dependency-is-added"></a>

- `mcp-server/package.json` adds `sqlite-vec-darwin-arm64` as an optional dependency.
- It supports nested-install compatibility.

&nbsp;

## Setup Paths

Setup paths change where build and install steps look. They point at `mcp-server/`.

#### Build and Setup Paths Align <a id="c-build-and-setup-paths-align"></a>

- The `lib/cache/cognitive` symlink is corrected.
- It points to `../cognitive`, fixing TypeScript build paths.

#### The Install Guide Updates References <a id="c-the-install-guide-updates-references"></a>

- The install guide updates its package references.
- It changes all `system-spec-kit/node_modules/` references to `mcp-server/node_modules/`.
- The instructions are easier to read and trust.

#### Memory Commands Change Targets <a id="c-memory-commands-change-targets"></a>

- Install spec kit memory commands change targets.
- Install, rebuild and verify commands are affected.
- In Install spec kit memory, install, rebuild and verify commands now target `mcp-server/`.

&nbsp;

## Dependency Checks

These checks verify native modules and detector paths. Each one follows the new dependency locations.

#### Checks Follow Dependency Paths <a id="c-checks-follow-dependency-paths"></a>

- `Check native modules` updates the `better-sqlite3` probe path.
- `better-sqlite3` is the package being probed.

#### Rebuild Moves to the Workspace <a id="c-rebuild-moves-to-the-workspace"></a>

- `Rebuild native modules` updates its location.
- It now targets `mcp-server/`.

#### Detector Paths Move Together <a id="c-detector-paths-move-together"></a>

- `Folder detector` and `Test folder detector functional` paths change together.
- The test paths now match the detector.
- `Folder detector` now requires `better-sqlite3` from `mcp-server/node_modules/`.
- `Test folder detector functional` updates its paths to match.
