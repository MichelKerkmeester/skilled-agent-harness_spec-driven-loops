# v0.2.15.0, Spec Folders Move Between Levels

This release adds a script that moves existing spec folders between documentation levels.

- User content is preserved through the upgrade.
- New files come from SpecKit addendum templates.
- Markers and level fields update across modified files.

The upgrade runs as a repeatable workflow.

- A dry run previews planned changes before files are modified.
- Reruns avoid duplicate sections.
- `--json` produces machine-parseable output.

The script runs on stock macOS.

- It needs no brew-installed Bash 5.
- Modified standard headings can still be matched.
- Backup cleanup keeps the three most recent backups.

## Spec Folder Upgrades

The script upgrades existing spec folders while preserving user content.

#### Level Changes Follow a Clear Path <a id="c-level-changes-follow-a-clear-path"></a>

- The script supports L1toL2, L2toL3 and L3toL3+ upgrades.
- A skip-level L1toL3 upgrade runs L1toL2 first.
- It is followed by L2toL3.
- User content is preserved through the upgrade.

#### Templates and Level Records Update <a id="c-templates-and-level-records-update"></a>

- New files are generated from SpecKit addendum templates.
- `SPECKIT_LEVEL` markers and metadata table level fields are updated.
- Both apply across all modified files.

#### Dry Run Previews Planned Changes <a id="c-dry-run-previews-planned-changes"></a>

- `--dry-run` shows all planned changes.
- It modifies no files.

#### Reruns Avoid Duplicate Sections <a id="c-reruns-avoid-duplicate-sections"></a>

- Reruns avoid adding duplicate sections.
- The upgrade operation is idempotent.

#### JSON Output Supports Toolchains <a id="c-json-output-supports-toolchains"></a>

- `--json` produces machine-parseable output.
- This supports toolchain integration.

#### Compatible with Stock macOS <a id="c-compatible-with-stock-macos"></a>

- The script works on stock macOS with Bash 3.2+.
- It does not require brew-installed Bash 5.
- It uses no associative arrays or bashisms.
- Portable sed handling abstracts the differences between macOS and GNU `sed -i`.

#### Fuzzy Matching Finds Insertion Points <a id="c-fuzzy-matching-finds-insertion-points"></a>

- Modified standard headings can still be matched.
- Fuzzy matching finds approximate insertion points.
- It falls back to the end of the file.

#### A Script Built in Six Phases <a id="c-a-script-built-in-six-phases"></a>

- The script has 1,490+ LOC and 22 functions.
- It creates backups.
- It works through input validation, level detection, backup creation, file upgrade, marker updates and output generation.
- Automatic cleanup keeps the three most recent backups.
- It removes older ones.
