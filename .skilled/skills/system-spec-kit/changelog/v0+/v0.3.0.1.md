# system-spec-kit v0.3.0.1

This release unifies the Memory Dashboard Visual Design System across all five memory commands.

- Memory commands now use `MEMORY:<COMMAND>` headers.
- Section labels now use Title Case across all commands.
- Numeric output now uses block charts with `█░` characters.

It also updates their instructions.

- Save now enforces its required argument.
- Continue's opening sections now sit in a new order.
- Manage's instructional prose no longer uses emoji markers.

&nbsp;

## Why This Release

The changes focus on instructions and release notes.

- They aim to make both easier for non-developers to follow.
- The goal is a workflow that is easier to follow and easier to trust.

## Memory Command Output

These changes unify output across the five memory commands.

#### Shared Command Headers <a id="c-shared-command-headers"></a>

- Memory commands now use `MEMORY:<COMMAND>` headers.
- They replace five different header styles.
- The replaced styles included box-drawing, emoji-prefixed and mixed-case forms.
- Each header uses ALL CAPS with a thick `━━━` separator.

#### Section Labels Use a Shared Format <a id="c-section-labels-use-a-shared-format"></a>

- Section labels now use Title Case across all commands.
- Each label is arrow-prefixed.
- It pairs its Title Case name with a `────────────` rule and a count.
- Their format replaces ad-hoc dividers and mixed formatting.

#### Numeric Displays Use Bars <a id="c-numeric-displays-use-bars"></a>

- Numeric output now uses block charts.
- The bars are drawn with the `█░` characters.
- Across all numeric displays, the bars visualize:
  - Scores
  - Progress
  - Tier distribution
  - Confidence
  - Stability

#### Status Indicators Use Words <a id="c-status-indicators-use-words"></a>

- Status indicators now use plain words.
- They read `PASS` / `WARN` / `FAIL`.
- The replaced emoji indicators were:
  - `✓`
  - `⚠`
  - `❌`
  - `🔄`
  - `✅`

#### Action Menus Use One Pattern <a id="c-action-menus-use-one-pattern"></a>

- Interactive prompts now share one choice format.
- Each choice reads `[key] verb` instead of the pipe-separated styles.
- The previous prompts used inconsistent forms such as `[a]ction | [b]ction`.
- Choices follow a thin `───` separator.

#### Ten Components Share a Vocabulary <a id="c-ten-components-share-a-vocabulary"></a>

- A shared vocabulary now defines 10 output components.
- The same names describe the output in every memory command.
- The vocabulary names command header, section label, key-value pair, bar chart and result item.
- It also names status line, action menu, indicators, inline lists and empty state.
- Key-value formatting is consistent.
- Approximately 29 output templates were standardized.

## Memory Command Instructions

These changes update the command instruction files.

#### Folder 036 Has a Full Record <a id="c-folder-036-has-a-full-record"></a>

- Folder 036 is now a full Level 2 spec folder.
- It makes the release notes and instructions easier to read and trust.
- The folder contains:
  - A spec
  - A plan
  - An implementation summary
  - A checklist

#### Save Gets a First-Action Gate <a id="c-save-gets-a-first-action-gate"></a>

- Save now enforces its required argument.
- The command takes `<spec-folder>` as its first action.
- The new block is titled `# MANDATORY FIRST ACTION`.
- The change separately removes the redundant `CRITICAL RULES` section and renumbers sections 1-15.

#### Continue and Context Match Templates <a id="c-continue-and-context-match-templates"></a>

- Continue's opening sections now sit in a new order.
- `PURPOSE` precedes `MCP ENFORCEMENT MATRIX`.
- Continue swapped its sections 1 and 2 to match the template standard.
- MCP tables in Continue and Context now use Markdown pipe syntax.
- They replace the box-drawing tables.
- Continue's box-drawing MCP table and Context's box-drawing MCP enforcement matrix were converted to Markdown pipe tables.

#### Manage Drops Emoji Markers <a id="c-manage-drops-emoji-markers"></a>

- Manage's instructional prose no longer uses emoji markers.
- The project becomes smaller and easier to maintain.
- The removed markers appeared in:
  - Gate headers: `🔒`
  - Status markers: `☐` and `⏭️`
  - HARD STOP indicators: `⛔`

&nbsp;

## Upgrade Notes

No upgrade needed.

- All changes are documentation-only output-template formatting in command instruction files.
- The release changes no runtime code, MCP tool signatures or database schema.
