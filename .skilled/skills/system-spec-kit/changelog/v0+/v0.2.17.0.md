## Spec Document Indexing

Spec 126 adds full spec-folder document indexing. Schema v13 adds document metadata to the index.

#### Simplify Index Maintenance <a id="c-simplify-index-maintenance"></a>

- Schema v13 adds `Document_type TEXT DEFAULT 'memory'` to `memory_index`.
- It adds `spec_level INTEGER` to `memory_index`.
- This makes setup and maintenance easier to manage.

#### Identify Document Types <a id="c-identify-document-types"></a>

- The index recognizes 11 document types.
- The set spans specs, plans, memory and other documentation.
- The types are:
  - `Spec`
  - `plan`
  - `tasks`
  - `checklist`
  - `decision_record`
  - `implementation_summary`
  - `research`
  - `handover`
  - `memory`
  - `readme`
  - `constitutional`

#### Score by Document Type <a id="c-score-by-document-type"></a>

- Document types receive different scoring multipliers.
- The type decides how much a document adds to the score.
- The multipliers are:
  - `spec`: 1.4x
  - `plan`: 1.3x
  - `constitutional`: 2.0x
  - `memory`: 1.0x
  - `readme`: 0.8x
  - `scratch`: 0.6x

#### Find Specs and Decisions <a id="c-find-specs-and-decisions"></a>

- Search adds two intents.
- The new intents are `Find_spec` and `find_decision`.
- The total rises from 5 to 7.
- Search can now target specifications and decisions.

#### Crawl Spec Folders <a id="c-crawl-spec-folders"></a>

- `FindSpecDocuments()` is the crawler for spec-folder documents.
- It walks `.opencode/specs/` to find them.

#### Connect Spec Records <a id="c-connect-spec-records"></a>

- Causal chains connect spec documents.
- `CreateSpecDocumentChain()` creates `spectoplantotaskstoimpl_summary` edges.
- The chain runs from spec to plan to tasks to `impl_summary`.
- The links follow the spec-to-implementation path.

#### Control Spec-Document Scans <a id="c-control-spec-document-scans"></a>

- Scans can include spec-folder documents.
- You can control whether a scan includes them.
- The `SPECKIT_INDEX_SPEC_DOCS` environment variable controls spec-document indexing.
- The `memory_index_scan` tool accepts the `includeSpecDocs` parameter.

#### Expand the Source Set <a id="c-expand-the-source-set"></a>

- Indexing adds a new document source.
- It brings spec-folder documents into the content it can index.
- Spec-folder documents join memory, constitutional material, skill READMEs and project READMEs.
- They are an indexing source.
- They are the fifth source.
