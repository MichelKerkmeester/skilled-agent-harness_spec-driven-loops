# v0.2.5.0, Clearer Docs and Restored Commands

This release aligns README anchors, memory command documentation and shared styles.

- About 473 anchor tags were added across 74 READMEs.
- Five command READMEs were included.
- Seven style rules were applied to 75 active README files.

It also shortens `SKILL` without removing features and restores command files after an over-reduced state.

- `SKILL` was shortened and all features were preserved.
- Twelve command files were restored to 600 lines or fewer.
- About 160 H2 headings received the command template style.

Routing references and YAML subagent types were updated.

- Four YAML assets changed from `Subagent_type: explore` to `subagent_type: context`.
- Five `.md` command files added `@context` and `@speckit` routing references.
- Two YAML assets added `@speckit` routing for debug delegation.
- All 19 commands properly route per the `AGENTS` agent table.

&nbsp;

## Why This Release

The release aims to make instructions and release notes easier for non-developers to follow. It aims to make the workflow easier to follow and trust.

- Readers needed clearer guidance about README anchors.
- Readers needed clearer guidance about memory command READMEs.
- Readers needed clearer guidance about style alignment.
- Reliability problems affected command files and YAML assets.
