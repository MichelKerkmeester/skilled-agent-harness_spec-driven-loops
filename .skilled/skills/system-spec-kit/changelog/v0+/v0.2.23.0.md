# v0.2.23.0, Template and Voice Guidance

This release revises HVR references and implementation-summary guidance across templates.

- HVR references now point to `references/`.
- The path update covers all 8 templates.
- Implementation-summary guidance follows spec 136 patterns.

It also changes how writers open and organize summaries.

- Templates now guide openings and feature sections.
- The new direction covers all levels.
- Files Changed tables now depend on level.

It adds guidance for verification, limitations and delivery stages.

- The voice guide standardizes verification and limitations.
- Level 3+ also gains delivery-stage guidance.

&nbsp;

## Why This Release

The changes aim to make instructions easier for non-developers to follow.

- They aim to do the same for release notes.
- They also aim to make the workflow easier to follow and trust.

## Template Guidance

This release revises HVR references and implementation-summary guidance across templates.

#### HVR References Point to Their New Location <a id="c-hvr-references-point-to-their-new-location"></a>

- HVR_REFERENCE comments and footer paths were updated.
- This came after the HVR rules moved to `references/`.
- The 137 implementation summary had a stale HVR_REFERENCE path.
- It now points to the new `references/` location.

#### Summary Templates Use Reference Patterns <a id="c-summary-templates-use-reference-patterns"></a>

- Spec 136 reference patterns informed improvements to the core implementation-summary template.
- They also informed the other implementation-summary templates, including the Level 3+ version.
- Decision-record guidance was updated in both the general and Level 3+ decision records.
- Spec 136 was also added as a reference in voice guide comments.

#### Openings Lead With Impact <a id="c-openings-lead-with-impact"></a>

- Opening-hook guidance was added at all levels.
- Templates now guide writers to lead with impact in 2-4 sentences.

#### Summary Tables Follow Levels <a id="c-summary-tables-follow-levels"></a>

- Level 3/3+ templates now use `### [Feature Name]` subsections for each feature, instead of file tables.
- The Files Changed table was removed for Level 3/3+.
- There, narrative carries the summary at higher documentation levels.
- Level 1-2 retains the table.

&nbsp;

## Voice and Delivery Guidance

It adds guidance for verification, limitations and delivery stages.

#### Verification Shows Failures <a id="c-verification-shows-failures"></a>

- The voice guide now says: "Be honest. Show failures alongside passes."
- This gives writers direct guidance for reporting verification.

#### Limitations and Delivery Stages <a id="c-limitations-and-delivery-stages"></a>

- All levels now use `1. [Limitation] [Specific detail with workaround.]` for numbered limitations.
- Level 3+ guidance now covers delivery stages: testing, rollout and verification.
