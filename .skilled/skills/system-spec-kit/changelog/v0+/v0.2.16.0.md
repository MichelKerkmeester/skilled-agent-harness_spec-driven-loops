# v0.2.16.0, Safer Upgrades and Clearer Output

This release is a system-wide audit of upgrade level.

- It covers 2 P0 fail-fast fixes and 7 P1 hardening patches.
- It hardens failure handling.
- It preserves nested backup folders.
- It restores the spec folder when an upgrade fails.

The release also clarifies output, matching and history.

- It removes confusing generated output.
- It tightens upgrade matching.
- It resolves cross-run history contradictions.
- Full Level 3+ documentation gains an evidence-cited checklist with complete traceability.

&nbsp;

## Why This Release

The release focuses on fixing important problems and explaining results more clearly. The result is a workflow that is easier to follow and trust.

## Upgrade Reliability

#### Missing Libraries Stop Early <a id="c-missing-libraries-stop-early"></a>

- `Upgrade level` now exits immediately if the shared library cannot be sourced.
- This reduces confusing failures.
- This makes the system more dependable.

#### Failed Upgrades Restore the Spec Folder <a id="c-failed-upgrades-restore-the-spec-folder"></a>

- Backup logic preserves nested directory structures under `memory/` instead of silently skipping them.
- When an upgrade fails, the new `restore_from_backup()` function restores the spec folder to its pre-upgrade state.

&nbsp;

## Clearer Upgrade Output

#### Plans and Warnings Reach the Reader <a id="c-plans-and-warnings-reach-the-reader"></a>

- `Upgrade_plan()` and `upgrade_checklist()` no longer inject stray comment lines into generated output.
- The `OPEN QUESTIONS` warning is now emitted to stderr so it surfaces visibly during upgrades.

&nbsp;

## More Reliable Matching

#### Matching Avoids False Results <a id="c-matching-avoids-false-results"></a>

- Multi-Agent detection is anchored to a table-row pattern to prevent false positives.
- The complexity flag exit pattern is tightened to avoid partial matches.

#### Search Has a Clear Limit <a id="c-search-has-a-clear-limit"></a>

- `find_insert_point()` is capped at 200 iterations to prevent infinite loops.
- Level detection is anchored to the start of a line for reliable matching.
