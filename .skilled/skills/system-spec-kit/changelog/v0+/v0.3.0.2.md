Hybrid RAG Fusion Workstream A delivers the Unified Context Engine baseline. The baseline is for the memory MCP search pipeline. It brings tri-channel retrieval, adaptive fusion, evidence-gap detection and diversity reranking together.

## What's New at a Glance

- **Hybrid search uses graph retrieval by default.** It applies intent-aware adaptive fusion. It runs co-activation with MMR in the main flow.
- **Memory search surfaces low-confidence warnings.** It uses TRM scoring from the evidence gap detector.
- **Deep mode expands queries with deterministic synonyms.** The variants support multi-query retrieval.
- **`pagerank` and the structure-aware chunker were created as foundation modules for Phase 4.** Both were implemented but are still intentionally not wired into ingest.
- **This folder was synchronized as the main active RAG track.** Supplemental command-alignment and non-skill-graph consolidation notes were indexed.

## Upgrade

No schema migration is required. v15 SQLite is unchanged. No new runtime dependencies were introduced for the shipped path. Restart the MCP runtime to pick up the new pipeline behavior. PageRank ingest wiring and structure-aware ingest chunking remain deferred follow-up items. Empirical 120ms latency profiling remains a deferred follow-up item too.
