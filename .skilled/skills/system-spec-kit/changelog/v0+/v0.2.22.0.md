This release expands the Spec Kit Memory MCP runtime. It adds typed retrieval traces and artifact-aware routing. It adds intent-adaptive fusion, append-only mutation logging and extended telemetry. All of it arrives through the Level 3+ rollout in `136-mcp-working-memory-hybrid-rag`. The release addresses important problems. It explains results more clearly. It makes the workflow easier to follow and trust.

&nbsp;

## What's New at a Glance

- Retrieval responses carry typed traces.
  - They carry a typed ContextEnvelope.
  - The ContextEnvelope holds an explicit pipeline trace and degraded-mode metadata for explainable ranking behavior.
  - The MCP server runtime also gained extraction adapters and causal/session boost modules.
- Search adapts to artifact class.
  - Routing adjusts for spec, plan, decision-record, memory, research and other artifact classes.
  - This improves relevance by document type.
- Weighted fusion supports intent profiles.
  - The profiles cover fix_bug, add_feature, understand, refactor, security_audit, find_spec and find_decision.
  - They sit behind feature-flag control.
- Memory operations enter an audit trail.
  - Memory CRUD and re-index operations are captured in an audit trail.
  - That trail is append-only and tamper-evident.
- Retrieval telemetry is extended.
  - Search and context handlers report richer latency, mode, fallback and quality-proxy telemetry.
  - That telemetry serves evaluation and operations.
- Cognitive config parsing is hardened.
  - Config parsing uses schema-validated paths.
  - Working-memory pressure and eviction behavior are deterministic.
  - That makes setup and maintenance easier to manage.
- Eval/KPI scripts support staged rollout checks.
  - They also support quality backfill, performance benchmarks and calibration workflows.

&nbsp;

## Upgrade

No migration required. Pull latest to get the new retrieval/runtime capabilities. Keep `SPECKIT_ADAPTIVE_FUSION` disabled for baseline parity. Then enable it deliberately when you are ready to trial adaptive ranking behavior.
