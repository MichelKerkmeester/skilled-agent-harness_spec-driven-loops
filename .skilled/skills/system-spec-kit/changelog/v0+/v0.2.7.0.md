This release aligns `/create:folder_readme` YAML and command guidance. It also fixes broken references in `folder_readme`. Non-developers can follow and trust the instructions and release notes more easily.

&nbsp;

## What's New at a Glance

- `Create folder readme` follows the main README structure.
  - Four README types now follow the nine-section structure in `readme_template.md` §13.
  - Embedded templates are replaced by reference stubs.
  - The update fixed emoji inconsistencies.
  - The update added `template_references` cross-references.
  - The update changed the workflow to `sequential_6_step`.
- `Folder readme` references are corrected.
  - YAML key references in the §4 REFERENCE table were fixed.
  - The update aligns the DQI target to 75+ (Good).
  - The update standardizes `/create:folder_readme` as the command name.
  - The update adds a step numbering explanation in §3.

No migration required.
