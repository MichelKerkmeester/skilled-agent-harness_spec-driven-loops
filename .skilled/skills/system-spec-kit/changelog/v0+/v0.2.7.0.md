This release aligns `/create:folder_readme` YAML and command guidance. It also fixes broken references in `folder_readme`. Non-developers can follow and trust the instructions and release notes more easily.

## What's New at a Glance

- **`Create folder readme` follows the main README structure.** Four README types now follow the nine-section structure in `readme_template.md` §13. Embedded templates are replaced by reference stubs. The update fixed emoji inconsistencies. It added `template_references` cross-references. It changed the workflow to `sequential_6_step`.
- **`Folder readme` references are corrected.** YAML key references in the §4 REFERENCE table were fixed. The update aligns the DQI target to 75+ (Good). It standardizes `/create:folder_readme` as the command name. It adds a step numbering explanation in §3.

## Upgrade

No migration required.
