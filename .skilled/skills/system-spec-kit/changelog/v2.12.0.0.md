# v2.12.0.0, Neutral Examples, Leaner Scaffolds and Measured Behavior

Blind grading of benchmark packets showed models copying the template examples into their own specs. They filled boilerplate sections with filler. They stated current behavior they never measured. They spent most failed validate rounds on generated metadata. This release fixes each of those at the template and validator level.

&nbsp;

## What's New at a Glance

- Examples are now neutral.
  - 87 example lines in 12 template and card files now use one unrelated example.
  - That example is a `--keep <n>` option for a log rotation script.
- The scaffold has fewer filler sections.
  - The plan drops effort estimation and enhanced rollback.
  - Edge cases are three token lines.
  - Sign-off is one row and the definition of done is a token.
  - In `tasks.md` the fix-completeness section is optional.
  - The fix-completeness check is conditional.
  - The two deploy-ready checks became one token row.
- spec.md gains a Measured Behavior block.
  - `spec.md` holds a block with one command and its verbatim output.
  - The new warn-only `MEASURED_BEHAVIOR` rule checks it on v2.4 specs.
  - The rule never errors.
  - Older specs are not checked.
  - The registry now holds 42 rules.
- Draft packets repair their own metadata.
  - A `--strict` validate of a Draft packet runs `repair-derived.cjs --apply` once and validates again.
  - This happens when its only errors are derived metadata.
  - The repair does not run under `CI`.
  - The repair does not run with a `SPECKIT_RULES` subset.
  - The repair does not run without `--strict`.
  - Tools that run the validator as a child switch it off.
  - So they stay read-only.
- The template version is v2.4.
  - The files are `spec.md`, `plan.md`, `tasks.md`, `implementation-summary.md` and `acceptance-criteria.md`.

&nbsp;

## Upgrade

No migration required. New scaffolds carry the v2.4 stamps and the Measured Behavior block. Existing packets keep their stamps. The new rule does not check them. Set `SPECKIT_DRAFT_AUTO_REPAIR=0` to keep a strict validate read-only on a Draft packet. A strict census over 4,757 existing folders and the six-rule census were identical before and after. Both showed 4,562 PASS and 195 FAIL. `MEASURED_BEHAVIOR` raised no warning on any of them.
