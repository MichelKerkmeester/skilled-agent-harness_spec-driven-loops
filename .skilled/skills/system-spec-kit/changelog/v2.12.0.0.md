# v2.12.0.0, Neutral Examples, Leaner Scaffolds and Measured Behavior

Blind grading of benchmark packets showed models copying the template examples into their own specs, filling boilerplate sections with filler, stating current behavior they never measured and spending most failed validate rounds on generated metadata. This release fixes each of those at the template and validator level.

> Spec folders: `specs/system-speckit/054-weak-model-spec-authoring/015-template-example-neutralization`, `016-scaffold-filler-section-trim` and `017-measured-behavior-and-draft-metadata` (Level 2)

&nbsp;

## What's New at a Glance

- **Neutral examples.** 87 example lines in 12 template and card files now use one unrelated example, a `--keep <n>` option for a log rotation script.
- **Fewer filler sections.** The plan drops effort estimation and enhanced rollback, edge cases are three token lines, sign-off is one row and the definition of done is a token. In `tasks.md` the fix-completeness section is optional, its check is conditional and the two deploy-ready checks became one token row.
- **Measured Behavior.** `spec.md` holds a block with one command and its verbatim output, and the new warn-only `MEASURED_BEHAVIOR` rule checks it on v2.4 specs. It never errors, older specs are not checked and the registry now holds 42 rules.
- **Draft packets repair their own metadata.** A `--strict` validate of a Draft packet whose only errors are derived metadata runs `repair-derived.cjs --apply` once and validates again. It does not run under `CI`, with a `SPECKIT_RULES` subset or without `--strict`, and tools that run the validator as a child switch it off so they stay read-only.
- **Template version v2.4** for `spec.md`, `plan.md`, `tasks.md`, `implementation-summary.md` and `acceptance-criteria.md`.

&nbsp;

## Upgrade

No migration required. New scaffolds carry the v2.4 stamps and the Measured Behavior block. Existing packets keep their stamps and are not checked by the new rule. Set `SPECKIT_DRAFT_AUTO_REPAIR=0` to keep a strict validate read-only on a Draft packet. Strict census over 4,757 existing folders and the six-rule census: identical before and after, 4,562 PASS and 195 FAIL. `MEASURED_BEHAVIOR` raised no warning on any of them.
