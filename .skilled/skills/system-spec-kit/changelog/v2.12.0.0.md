# v2.12.0.0, Neutral Examples, Leaner Scaffolds and Measured Behavior

Blind grading of benchmark packets showed models copying the template examples into their own specs, filling boilerplate sections with filler, stating current behavior they never measured and spending most failed validate rounds on generated metadata. This release fixes each of those at the template and validator level.

> Spec folders: `specs/system-speckit/054-weak-model-spec-authoring/015-template-example-neutralization`, `016-scaffold-filler-section-trim` and `017-measured-behavior-and-draft-metadata` (Level 2)

&nbsp;

## Why This Release

The template examples described the same kind of change the benchmark asked for, so the graders could not tell what a model wrote from what it copied. The plan template asked for an effort estimate and an enhanced rollback that packets filled with guesses. Specs claimed numbers about current behavior with no command behind them. In the speed loop, 33 of 36 failed validate rounds failed only on generated metadata.

&nbsp;

## What's New at a Glance

- **Neutral examples.** 87 example lines in 12 template and card files now use one unrelated example, a `--keep <n>` option for a log rotation script.
- **Fewer filler sections.** The plan drops effort estimation and enhanced rollback, edge cases are three token lines, sign-off is one row and the definition of done is a token.
- **Measured Behavior.** `spec.md` holds a block with one command and its verbatim output, and the new warn-only `MEASURED_BEHAVIOR` rule checks it on v2.4 specs.
- **Draft packets repair their own metadata.** A `--strict` validate of a Draft packet whose only errors are derived metadata runs `repair-derived.cjs --apply` once and validates again.
- **Template version v2.4** for `spec.md`, `plan.md`, `tasks.md`, `implementation-summary.md` and `acceptance-criteria.md`.

&nbsp;

## Templates

#### One Neutral Example

Every example that named a quiet flag or a flag parser now uses `scripts/rotate-logs.sh --keep <n>`, which deletes all but the newest n archives. The authoring card's task line, the implementation-summary decision example and the `research.md` add-on use it too, so no template example matches a task a model is likely to be given.

#### Sections Models Padded

`plan.md` no longer has the effort-estimation or enhanced-rollback sections, its phase dependencies are a skeleton and its definition of done is a token. `spec.md` edge cases are three token lines per level; the Level 3 edge-case block carries no anchor, so it stays optional. `tasks.md` signs off in one token row, its fix-completeness section is the optional `## FIX ADDENDUM: FIX COMPLETENESS`, CHK-100 is conditional and the deploy-ready checks CHK-121 and CHK-122 became one token row. The card's plan step names three phases in one line each.

&nbsp;

## Validation

#### Measured Behavior Rule

`spec.md` has a `Measured Behavior` block after the problem statement: a fill note and a text fence for one command and its output. `MEASURED_BEHAVIOR` warns when a v2.4 spec leaves the block missing or the fence empty, and passes on a filled fence or an `N/A:` line with a reason. It never errors, and older specs are not checked. The registry now holds 42 rules.

#### Draft Auto-Repair

When `spec.md` says `Status: Draft` and every error is a derived-metadata one, `validate.sh --strict` applies `repair-derived.cjs --apply` once, prints each file it rewrote and validates again. It does not run under `CI`, with a `SPECKIT_RULES` subset or without `--strict`, and `SPECKIT_DRAFT_AUTO_REPAIR=0` turns it off. Tools that run the validator as a child, such as `repair-derived.cjs`, `upgrade-legacy.mjs`, `quality-audit.sh`, `progressive-validate.sh` and the strict-pass freshness sweep, set it to `0` so they stay read-only.

&nbsp;

## Verification

- Strict census over 4,757 existing folders and the six-rule census: identical before and after, 4,562 PASS and 195 FAIL. `MEASURED_BEHAVIOR` raised no warning on any of them.
- 24 affected test files pass, including the new `measured-behavior-rule` (7) and `draft-auto-repair` (15) suites and the regenerated golden snapshots.
- `check-card-sync.sh` and `check-example-drift.sh` pass, the Hermes copy check passes and no markdown link is broken.

&nbsp;

## Upgrade Notes

No migration required. New scaffolds carry the v2.4 stamps and the Measured Behavior block. Existing packets keep their stamps and are not checked by the new rule. Set `SPECKIT_DRAFT_AUTO_REPAIR=0` to keep a strict validate read-only on a Draft packet.
