# v2.12.8.0, Dependencies Move Past the Open Advisories

An install of this skill used to pull package versions that the security audit flagged. The runtime and the CLI now pin current releases, so those versions are gone. Nothing about how the skill runs is different.

> Spec folder: `specs/sk-code/015-quality-agnostic-gate/010-alignment-audit` (Level 2)

&nbsp;

## What's New at a Glance

- **The flagged packages leave the tree.** The lockfile was rebuilt from the audit fixes, so a fresh install resolves the fixed version of each package the advisories named.
- **Validation runs on zod 4.6.7.** The runtime moves from the 4.1 line. No call site needed a change to follow it.
- **The test runner and its coverage reporter move as one.** The CLI and the runtime had pinned different vitest versions. Both now sit at 4.1.12.
- **The trigger-index test follows the upload pin.** The workflow test names the artifact action by its pinned revision, so it moved to the new revision with the workflow.

&nbsp;

## Upgrade

No action is needed. The next install picks up the newer packages. No runtime source file changed in the process.
