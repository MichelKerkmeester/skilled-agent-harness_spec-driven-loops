# v2.12.36.0, A level upgrade leaves the spec valid

Upgrading a spec from Level 1 to Level 2 now leaves it valid. `upgrade-level.sh` used to insert the new sections inside the questions anchor, so strict validation failed until someone moved them by hand.

> Spec folder: `specs/system-speckit/045-upgrade-level-anchor-insert`

&nbsp;

## What's New at a Glance

- **The new sections land above the questions anchor.** The anchor goes back directly above the renumbered OPEN QUESTIONS heading.
- **Specs without the anchor upgrade as before.** Their output is unchanged.

&nbsp;

## Upgrade

A spec already upgraded with the old script may still hold sections inside its questions anchor. Strict validation names it under `ANCHORS_VALID`. Move those sections above the anchor.
