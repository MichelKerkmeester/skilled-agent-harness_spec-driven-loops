# v2.13.5.0, The Optimizer Locks the Research Depth Mode

Deep research gained an opt-in expansive depth mode. Its switch is `antiConvergence.depthMode` in the research config. The optimizer must never tune it, so the manifest locks it.

&nbsp;

## What's New at a Glance

- **`antiConvergence.depthMode` is a locked field.** `optimizer-manifest.json` lists it in the anti-convergence contract.
- **The anti-convergence invariant group locks it too.** It joins the two convergence mode fields in `lockedFields`.
- **Its default value is `default`.** A run without `--depth-mode` keeps that value.

&nbsp;

No migration required. A dist freshness check reports the CLI dist stale after this change. Run `npm run build` in `runtime/cli` to rebuild it.
