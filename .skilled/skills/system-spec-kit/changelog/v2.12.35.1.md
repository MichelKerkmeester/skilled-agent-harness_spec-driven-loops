# v2.12.35.1, Backfill Counts Only What It Wrote

A graph-metadata backfill reports how many folders it changed. A folder whose write was refused used to show up twice in that report, once as failed and once as changed. It now counts as failed only.

> Spec folder: `specs/system-speckit/037-symlinked-runtime-root`

&nbsp;

## What's New at a Glance

- **The changed count matches the disk.** A folder joins the count only after its write goes through, so a refused write reads as failed and nothing else.
