This release rewrites the mcp-code-mode README. It uses the purpose-first voice of standalone skill READMEs. It puts the skill's outcome before invocation guidance. It keeps every load-bearing fact from the prior text. It leaves runtime behavior unchanged.

&nbsp;

## What's New at a Glance

- The README now follows the refined skill README template.
  - It replaces the tool-first execution description.
  - It also replaces the older tabular reference-card style.
  - The new text has a one-line pitch blockquote, an AT A GLANCE table and a problem-first OVERVIEW.
  - That OVERVIEW has WHY THIS SKILL EXISTS and WHAT IT DOES.
- The README adds a Tool Surface capability table.
  - It names the tool families Code Mode operates.
  - The mcp-obsidian README supplies the reference shape.
  - Numbered ALL-CAPS H2 sections with `---` dividers organize usage guidance.
