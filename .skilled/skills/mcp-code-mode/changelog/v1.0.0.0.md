This first release adds a shared tool runner. It is written in TypeScript. Many connected tools can be used through one workflow. It is designed to reduce repeated setup. It is designed to make multi-tool work feel more coherent.

&nbsp;

## Why This Release

Managing each connected tool separately made larger tasks awkward. Large tool lists also made prompts heavy and follow-up steps harder. Teams needed install help and a clear map of what the runner could do.

&nbsp;

## What's New at a Glance

- One runner handles connected tools.
  - It calls many tools from the same flow.
  - Complex tasks become easier to chain together.
  - Complex tasks are also easier to explain to new users.
- Tool details load when needed.
  - The system keeps state between steps.
  - Everyday use feels lighter.
  - Multi-step work is easier to continue.
- Guides support setup and discovery.
  - The release shipped guides, templates and reference documents.
  - The guides, templates and reference documents cover configuration and tool discovery.
  - People can onboard faster.
  - People can find the right capability without guesswork.
