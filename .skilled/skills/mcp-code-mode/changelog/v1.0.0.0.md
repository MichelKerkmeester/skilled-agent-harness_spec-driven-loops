This first release introduces a shared tool runner written in TypeScript so many connected tools can be used through one workflow. It is designed to reduce repeated setup and make multi-tool work feel more coherent.

## Why This Release

Managing each connected tool separately made larger tasks awkward. Large tool lists also made prompts heavy and follow-up steps harder. Teams needed install help and a clear map of what the runner could do.

## What's New at a Glance

- **One runner handles connected tools.** It calls many tools from the same flow, making complex tasks easier to chain together and explain to new users.
- **Tool details load when needed.** The system keeps state between steps. Everyday use feels lighter and multi-step work is easier to continue.
- **Guides support setup and discovery.** The release shipped guides, templates and reference documents for configuration and tool discovery. People can onboard faster and find the right capability without guesswork.

## Upgrade

No migration required.
