# v1.0.19.0, One Helper Library Again

Code Mode and Chrome DevTools each ship a copy of the same installer helper library. The two copies had drifted apart, and the installer test that guards them failed. They match again.

&nbsp;

## What's New at a Glance

- The missing Node.js hint names the minimum the installer asks for.
  - The Code Mode installer asks for 18, so its message still reads `Install Node.js 18+`.
- The helper's own default minimum stays at 18.
- The installer test passes again on the two identical copies.

&nbsp;

No migration required.
