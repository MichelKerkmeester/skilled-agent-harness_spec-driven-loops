# v1.0.11.0, Fresh install fix

v1.0.11.0 scopes the js-yaml override so a fresh install of the server starts.

&nbsp;

## What's New at a Glance

- The `js-yaml` override is now scoped to one package.
  - The global `js-yaml` override in `mcp-server/package.json` forced `@apidevtools/json-schema-ref-parser` 15.5.1 onto 4.3.2.
  - That package needs `js-yaml` 5.
  - So a clean `npm ci` built a server that crashed at start-up.
  - The crash was a missing `binaryTag` export.
  - A scoped override now gives that package `^5.2.2`.
  - The other three dependents keep `^4.3.2`.
  - `package-lock.json` is regenerated to match.

&nbsp;

## Upgrade

An existing `node_modules` keeps working. Run `npm ci` under Node 24. Then run `npm run build` to install the locked versions.
