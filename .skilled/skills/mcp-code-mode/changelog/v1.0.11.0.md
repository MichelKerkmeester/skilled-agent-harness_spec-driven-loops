# v1.0.11.0, Fresh install fix

v1.0.11.0 scopes the js-yaml override so a fresh install of the server starts.

> Spec folder: `specs/mcp-tooling/024-code-mode-js-yaml-override` (Level 2)

&nbsp;

## What's New at a Glance

- The global `js-yaml` override in `mcp-server/package.json` forced `@apidevtools/json-schema-ref-parser` 15.5.1, which needs `js-yaml` 5, onto 4.3.2, so a clean `npm ci` built a server that crashed at start-up on a missing `binaryTag` export. A scoped override now gives that package `^5.2.2`, the other three dependents keep `^4.3.2`, and `package-lock.json` is regenerated to match.

&nbsp;

## Upgrade

An existing `node_modules` keeps working. Run `npm ci` under Node 24, then `npm run build`, to install the locked versions.
