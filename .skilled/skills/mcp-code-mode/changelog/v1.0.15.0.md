# v1.0.15.0, Router Details Move to ROUTER.md

The machine router now lives in `ROUTER.md`. `SKILL.md` keeps SMART ROUTING short, and that section ends with one line that links to `ROUTER.md`. The parsed router is identical to the previous edition.

&nbsp;

## What's New at a Glance

- **The machine router is in a sibling file.** `ROUTER.md` puts the intent map, resource map, default resource, loading levels and routing pseudocode under `## 3. MACHINE ROUTER` after a short overview and intent model.
- **Router references follow the move.** `SKILL.md` links `ROUTER.md` from its SMART ROUTING section and `README.md` lists it in the document table, while the playbook anchors that cited `SKILL.md` now cite their recomputed line ranges.
- **The playbook's `SKILL.md` line citations now resolve.** Five anchors across four scenarios cited ranges the shortened file does not hold, so each one now names the section that carries the rule.
- **The tool catalog and workflow references now follow the reference format.** Each opens with an overview and numbers its sections.
