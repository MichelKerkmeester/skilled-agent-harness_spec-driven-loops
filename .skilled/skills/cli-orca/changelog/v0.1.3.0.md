# v0.1.3.0, The README Description Parses Under Strict YAML

The cli-orca README description carries a colon and a space. That ends an unquoted YAML scalar early. So a strict parser rejected the block, while the rendered page read normally.

The value is quoted now. The sentence says exactly what it said before.
