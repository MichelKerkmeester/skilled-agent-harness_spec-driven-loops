# v0.1.11.0, Browser handoffs name the mcp-browser-use hub

Browser work that Orca does not own now goes to the `mcp-browser-use` hub, because a repository may have any of its three browser modes installed.

&nbsp;

## What's New at a Glance

- Browser handoffs name the hub.
  - Both browser keys in the `FOREIGN_OWNERS` map in `ROUTER.md` now point to `mcp-browser-use`.
  - `SKILL.md`, `README.md`, the browser boundary reference and the feature catalog say the hub routes to its Chrome DevTools, Aside or Bladebro mode.
  - CDP inspection, HAR capture and Lighthouse stay with the hub's Chrome DevTools mode.

&nbsp;

## Upgrade

No migration required.
