# v0.1.1.0, Template-Name Comment Removed from the Feature Catalog

v0.1.1.0 removes the `sk-doc-template` comment from 4 feature catalog files. The comment sat under each file's heading. It named the template a file was scaffolded from. No validator, router or script ever read it. The catalog template no longer adds it.

&nbsp;

## What's New at a Glance

- **Each catalog file now goes straight from its title to its overview.** The heading, sections and links are otherwise unchanged.
- **Catalog validation reports the same results as before.** Removing the comment changed no check outcome.

&nbsp;

## Upgrade

No migration required.
