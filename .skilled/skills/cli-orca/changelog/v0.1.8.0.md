# v0.1.8.0, Docs Read in Order and Render as Written

The skill's `SKILL.md`, `ROUTER.md`, `README.md`, the provenance asset and its references were read file by file. The reading checked readability, layout and structure. No routing behavior, command, source citation or snapshot changed.

## What's New at a Glance

- Overviews open with their purpose and when to use them.
  - Six guide files gain the Purpose and When to Use subsections their template asks for.
  - Three of them gain a Core Principle.
- Dense paragraphs became lists.
  - The official-skill references now list their targeting rules, constraints and neighbouring skills one per line.
  - The references are for the emulators, computer use, Linear tickets and per-workspace environments.
- Every section is numbered.
  - The README's at-a-glance block is now section 1.
  - `SKILL.md` splits references from related resources into sections 5 and 8.
- The orchestration reference warns first.
  - Its name-collision warning now opens the file as section 2.
  - The warning sits ahead of the role routing it qualifies.
