# v0.1.4.0, The Lane Summary Comes First

The routing lane table stood between an agent and the first Orca instruction. It answered the routing question correctly and it delayed the work. A short prose summary now says what selects this skill and what loads first, while the full routing detail waits at the end of the file for the reader who needs it.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/009-standalone-skills` (Level 2)

&nbsp;

## What's New at a Glance

- **The routing summary is short prose.** Five lines say what selects this skill, what loads first and where the rest of the routing lives.
- **The machine blocks moved unchanged.** The lane table, the phase table, the loading levels and the router pseudocode sit in the final `MACHINE ROUTER` section. No lane, keyword or resource changed.
- **The version-matched guide stays authoritative.** The router still defers flag detail to the guide served by the installed binary and keeps only the routing contract here.
