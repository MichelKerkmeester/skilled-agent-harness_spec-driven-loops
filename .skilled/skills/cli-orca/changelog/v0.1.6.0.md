# Orca Worktree Phrases Now Match

The advisor missed requests phrased as "Orca worktrees" and "managed worktrees in Orca" because those forms did not match its singular signals. The metadata now includes both Orca-qualified phrases, so these requests route to cli-orca without widening generic worktree signals.

## What's New at a Glance

- **Plural worktree requests match.** `orca worktrees` now selects cli-orca.
- **Managed-worktree requests match.** `managed worktrees in orca` now selects cli-orca.
