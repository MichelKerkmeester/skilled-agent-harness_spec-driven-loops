# v0.2.0.0 - cli-jev joins the compiled serving closure

## Added

- **The rollout child `009-parent-hub-rollout/008-cli-jev`.** The hub now has a compiled-routing
  shadow child: a harness that compiles `SKILL.md`, `hub-router.json` and `mode-registry.json` into a
  policy, its own registry compiler, a router that replays a request against the compiled contract, a
  policy card, and a `fixtures/canary-cases.v1.json` corpus of seven cases (four judgment requests
  that must route, three that must not).
- **The hub's activation manifest, generation 1.** `013-live-activation/activation/cli-jev/manifest.json`
  pins the compiled policy hash of this hub's routing inputs and declares `servingAuthority: "compiled"`,
  so an unset `SPECKIT_COMPILED_ROUTING` serves the compiled route. `fence-state.json` records the first
  activation flip (epoch 1), and the authored mirror under the router-unification program carries the
  pre-activation manifest, the rollback copy and both records.
- **The hub in the default-on cohort.** The hub is registered in the engine's dispatch map and in all
  cohort copies, so `compiled-route.cjs --hub cli-jev --prompt "<task>"` returns a compiled decision
  rather than the legacy sentinel.

## Changed

- **Version 0.2.0.0** across `SKILL.md`, `ROUTER.md`, `hub-router.json`, `mode-registry.json` and
  `description.json`, because the hub's serving state changed.
- **The hub `SKILL.md` no longer carries the scaffold paragraph** that declared the directive inert while
  the hub had no manifest and named the then-five serving hubs. The directive above it is now the live
  behavior, which is what every other serving hub's `SKILL.md` states.
- **The hub-level routing corpus resolves under the compiled router.** CJ-001 asks with a phrase the hub
  vocabulary actually carries (`jev judgment`), and CJ-003's gold names the no-route label instead of a
  null mode. Both changes were forced by replaying the gold through the compiled contract: the old CJ-001
  phrasing deferred, and a null gold label is unparseable to the admission check.

## Not Changed

- The transport contract: one `packetKind: "transport"` mode, `mutatesWorkspace: false`, `Write`/`Edit`/
  `Task` forbidden, `routingClass: metadata`, and the eight hard rules the dispatch guards enforce.
- The judgment surface, the JEV scenario ids and the recorded verdicts inside `cli-usage/`.
