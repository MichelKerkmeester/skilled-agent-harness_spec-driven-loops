# cli-jev v1.0.0.0

## Added

- **`cli-jev`, the hub's first `packetKind: "transport"` mode.** The TypeSafe Jev CLI (`jev`, pinned
  at 0.6.2) is dispatched for typed judgments — `noul` probabilities, `choice` selections, `score`
  positions and batched `run` requests — through the hub's `transport-axis` extension. The mode
  declares `mutatesWorkspace: false` and forbids `Write`, `Edit` and `Task`, because Jev reads state
  and prints a value: it edits nothing and runs nothing.
- **Eight hard rules with implemented checks**: availability, stdin bounding, `choice` and `score`
  cardinality, `--value` against `run`, `custom` endpoint requirement, no inline credential, and
  `jev-mcp` host-only. Each check lives in the runtime-neutral dispatch engine and carries a fixture
  pair, so an unimplemented rule and an undeclared implementation both fail the guard.
- **Four references and one asset**: the CLI contract with its exit-code taxonomy, the provider and
  model table with per-provider translation, the four integration patterns, the `jev-mcp` server
  contract with the operator step, and the question-shaping card.
- **A dispatch shape in the audit and the enforcement guards**: `jev` and `jev-mcp` resolve to
  `cli-jev` from the command, not from text that merely contains the word.

## Notes

- **No deep-loop executor kind.** Jev has no file tools, no loop and no lineage, so
  `EXECUTOR_KINDS` gains no entry and `/deep:research` cannot pin it.
- **No repository MCP config change.** `jev-mcp` ships in the same installation and is documented,
  not wired; the operator chooses the host and the config file.
- **No authenticated claims.** The workspace holds no Jev provider key, so every statement about a
  live provider response is tagged unconfirmed in `references/providers-and-models.md`. The
  reachability answer — an OpenAI-compatible LLM Gateway key cannot front Jev without a translating
  proxy, because the request and response are the native System One contract — is derived from the
  vendored source and recorded there with its receipts.
