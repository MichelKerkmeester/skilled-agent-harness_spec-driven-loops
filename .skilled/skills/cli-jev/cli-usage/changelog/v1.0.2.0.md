# cli-usage v1.0.2.0

## Changed

- **The packet moved and was renamed.** The Jev transport left the `cli-external-orchestration`
  family and is now `cli-usage`, the first mode of its own `cli-jev` hub, at
  `.skilled/skills/cli-jev/cli-usage/`. The entries below are preserved as written: v1.0.0.0 and
  v1.0.1.0 record the mode while it lived under the old family name.
- **The packet's identity is `cli-usage`.** The packet `SKILL.md` frontmatter is `name: cli-usage`,
  and the hub-level docs — this packet's `SKILL.md`, `README.md`, feature catalog, benchmark index
  and playbook — now name this hub rather than the old one.
- **The `transport-axis` extension moved with the packet.** `cli-usage` is the only transported mode
  the new hub declares, and the new hub is the one whose registry carries the axis.

## Not Changed

- The judgment contract: the eight hard rules and their implemented checks, the four references, the
  question-shaping card, the `JEV-` scenario ids and the recorded run verdicts are the same evidence
  at a new path.
- The dispatch shape's display name. The audit still reports a `jev` command as a `cli-jev` dispatch
  because `cli-jev` remains the hub id and a mode alias; only the packet path the guards read
  (`cli-jev/cli-usage/SKILL.md`) moved with the folder.
