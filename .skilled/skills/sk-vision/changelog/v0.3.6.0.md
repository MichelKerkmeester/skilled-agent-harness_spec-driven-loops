# v0.3.6.0, Bun Setup Stated Up Front

A fresh clone ships the vision runtime unbuilt. Both OpenCode plugin links and the Cursor CLI point at files that do not exist yet, so `/vision` fails with ENOENT, and nothing said the runtime needs Bun. The skill's opening now says so, with the one command that builds it.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/021-open-ends-remediation/002-onboarding-fixes` (Level 1)

&nbsp;

## What's New at a Glance

- **The Bun prerequisite is named.** A setup note sits under the skill's first paragraph, where a reader first meets sk-vision.
- **One command builds the runtime.** `bun install && bun run build` in `vision-runtime/` creates the files the plugin links and the CLI expect.

&nbsp;

## Upgrade

Install Bun 1.0 or newer, then run `bun install && bun run build` in `.skilled/skills/sk-vision/vision-runtime/` once.
