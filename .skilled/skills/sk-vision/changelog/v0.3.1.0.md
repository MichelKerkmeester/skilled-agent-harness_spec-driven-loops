# v0.3.1.0, Devin Hook Stdin Deadline

The Devin hook used to read stdin until the host closed it. A host that held the pipe open left the hook waiting until Devin's 60 second timeout killed it. The hook now reads through the shared hook reader, which settles at the end of the stream or after 3000 ms, and fails open with an empty object as before.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/012-post-merge-deep-review/001-hook-stdin-deadlines` (Level 1)

&nbsp;

## What's New at a Glance

- **The Devin hook has a deadline.** `hooks/devin/sk-vision.mjs` loads `readStdin` from `.skilled/hooks/shared/hook-adapter-shared.cjs`, the same way it already loads `hook-flags.cjs`.
- **A test holds the line.** `sk-vision-devin.test.mjs` spawns the hook with stdin left open and requires it to print `{}` and exit 0 in under 4.5 seconds.
