# v1.1.0.0, A Project Profile Slot and Reduced Motion

A project can now keep its own values beside the scales without the scales arguing with it, and motion now has a rule for users who asked the system to move less.

&nbsp;

## What's New at a Glance

- **An optional project profile.** A project may add `references/<project>-profile.md`. It loads only when a request names that project's UI, and an unknown project loads none. When sources disagree the order is the repository's mode, the tokens the app installs, the design scales, then the profile. The slot adds no routing phrase.
- **Reduced motion, web and native.** `motion-principles.md` closes its enforceable ruleset with the `prefers-reduced-motion: reduce` media query on the web and the platform setting on native. Movement becomes an instant change or a short fade, essential feedback stays, and nothing auto-plays. No animation library is named.
- **Two scenarios.** `SKD-013` checks that every value in a multi-value answer names its token or scale step. `SKD-040` checks that a project with no profile loads none.

&nbsp;

## Upgrade

No migration required. A project without a profile behaves as before.
