# v1.0.3.0, Long Prose Lines Are Short Sentences and Lists

`sk-design-fundamentals` reads in short sentences now. Four prose lines in `SKILL.md` had run past 400 characters, each one a paragraph or a rule written as a single unbroken block. They are split, and the enumerations inside them are bullets.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/010-prose-clarity-pass` (Level 2)

&nbsp;

## What's New at a Glance

- **The shadow pointer is two short paragraphs.** The two refined alternatives are a two-item list, and the tinting rule and the six-layer button anatomy follow it beside the link into the depth reference.
- **Hierarchy's four rules are bullets.** Size, text color count, emphasize by de-emphasizing and styling actions by hierarchy each hold one line, and the pointer into `references/hierarchy.md` Sections 2 through 7 follows them.
- **The six behavior references are a list.** Each reference and the sections it owns stand on one line, so a reader scans the intent instead of parsing a sentence.
- **The 4.5:1 rule splits text from non-text.** The large-text allowance and the 3:1 non-text rule are separate points, with the `24px regular or 18.66px bold` definition and WCAG 1.4.11 intact.
- **Nothing routes differently.** Every reference, section number, ratio and pixel value is the same one, and the build, improve and review split behaves as it did.

&nbsp;

## Upgrade

No action is needed. The scales, the references and the rule set are the ones the previous version carried.
