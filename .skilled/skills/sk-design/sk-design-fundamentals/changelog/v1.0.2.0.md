# v1.0.2.0, The Routing Prose Is Short and the Router Moved to the End

`sk-design-fundamentals` now reaches its value scales first. SMART ROUTING is eight lines of plain prose instead of the phase trees, resource tables and python that sat there, and all of that material is unchanged in a final `## 9. MACHINE ROUTER` section.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/007-sk-design-and-deep-loop-hubs` (Level 2)

&nbsp;

## What's New at a Glance

- **The routing section is prose.** Eight lines say what selects this mode, what it loads first and where the router is, so a reader meets the fixed scales without scrolling past a router.
- **The router is at the end.** The primary detection tree, the phase sequence, the resource domains, the loading-level table and the python router moved byte for byte into `## 9. MACHINE ROUTER`, the last H2 of the file.
- **Nothing routes differently.** The same intents, keywords and resource paths load as before, and the internal pointers that named Section 2 now name Section 9, in this file and in two playbook routing pages.
- **The body points instead of repeating.** Hierarchy's four rules and the always-true-core table are now one-line pointers into `references/hierarchy.md` Sections 2 to 7 and into the six references' own sections, and the palette build order is a pointer into `references/color-system.md` Section 3, taking `SKILL.md` from 4,975 to 4,880 words (95 fewer) with no fact lost.

&nbsp;

## Upgrade

No action is needed. The router reads the same paths, and the build, improve and review split behaves as it did.
