# v1.2.6.0, The Keyword Line Routes Only to This Mode

Four keyword triggers named more than this mode draws. `style reference` and `DESIGN.md` belong to the Style Reference mode, and `state machine` and `data model` are broad enough to catch debugging and schema work, so the line drops all four and every term left selects a diagram. A new check now keeps that line in agreement with the hub router.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/004-single-vocabulary-source` (Level 2)

&nbsp;

## What's New at a Glance

- **`style reference` and `DESIGN.md` are gone.** The hub routes both to the Style Reference mode, so a request that names either one no longer lands here.
- **`state machine` and `data model` are gone too.** A bare `state machine` or `data model` can name a debugging or schema task, so the line keeps only its diagram forms, such as `ER diagram`, `sequence diagram` and `architecture diagram`.
- **Every remaining term routes here.** That includes `/design:diagram`, `mermaid` and `venn`, which the hub now sends to this mode.
- **A check keeps the line honest.** `ci-hub-vocabulary-source.cjs` compares the line with `hub-router.json` and reports a term that one side carries and the other does not.

&nbsp;

## Upgrade

Nothing to do. The triggers decide which mode a request reaches. The diagrams this mode produces are unchanged.
