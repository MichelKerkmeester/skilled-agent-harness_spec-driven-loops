# v1.1.0.0, One Form Library, a Style Reference and Rules That Hold Themselves

This release brings diagram forms into one library, makes the visual language replaceable and adds checks for rules the packet stated but did not check. It also adds full-page captures, corrects corpus documentation and fixes defects.

## Why This Release

The corpus was split into templates and examples for no reason a reader could act on. One visual language had no way to be swapped. The packet had rules it stated and did not check.

---

## What's New at a Glance

- **`assets/templates/` and `assets/examples/` are now `assets/diagrams/`, holding 38 forms.** Each entry is a complete working diagram to copy and adjust rather than a strict template.
- **`assets/style-reference/harness-diagram/` holds the visual language as one bundle.** Another language is a sibling directory with the same four files.
- **`apply-design-md.cjs` themes chosen forms from any local Style Reference.** A reference may be measured by `sk-design-md-generator` or written by hand, and theming from the carried reference reproduces the stock palette exactly.
- **Two checker families bring the corpus check to twelve: `legend-fidelity` and `short-connector-labels`.** They compare legend swatches with what they key and check masks over short connectors.
- **A `text-on-mark` gate now exists at 4.5:1.** The text-gate analogy was right.
- **Starter hashes were deleted rather than refreshed.** Nothing read them.
- **The shared renderer adds opt-in `--full-page` captures.** It measures a page before capture.
- **The release fixes 52 defects across the corpus.** The repairs include a connector routed through the node it pointed at.
- **Four documents stopped stating values the corpus does not hold.** The dot pattern is documented as the default because 26 of 34 forms use it.

## Diagram Forms

#### One Library, Clear Roles

Prefixes are gone, and the four skin skeletons are named `starter-light`, `starter-dark`, `starter-terminal` and `starter-full`. The code stopped keying on the directory. Both applicators branch on whether a file carries a palette block, while the checker calls a file a starter or a form by its name. The catalog indexes what answers a question, which is why the starters are not in it. `--all` means all 38, and the examples flag is gone.

---

## Style Reference

#### A Visual Language You Can Replace

`DESIGN.md` states the language, `origin.md` says where it came from, `diagram-palette.json` carries the tokens and `icons.html` carries the glyphs.

Theming with `apply-design-md.cjs` is gated before anything is written. A reference naming our role tokens fills them verbatim, while anything it does not name falls back to selection rules over its colour table. Pure rules cannot reproduce this language: the lightest background row in a faithful reference is the near-white service fill, not the off-white ground.

## Corpus

#### Keep Legends and Connectors Clear

`legend-fidelity` refuses a legend swatch drawn unlike the thing it keys. `short-connector-labels` refuses a label mask painted across a connector under about 60px because the mask erases the stroke the reader was told to follow. It found a real instance on its first run that two reading passes had missed.

&nbsp;

#### Give Chip Labels Their Own Gate

A reader had been measuring chip labels against the text gate by analogy. The gate was missing.

&nbsp;

#### Drop Unused Starter Hashes

All four hashes were stale. Byte-identity already catches the drift they claimed to catch, while a hash would have flagged every legitimate geometry fix.

&nbsp;

#### Bring the Docs in Line

The structural role stopped carrying text in 50 places. The last form exempt from generation was tokenized, so the corpus now has no exemption at all.

&nbsp;

#### Fix Defects Across the Corpus

A full manual reading of every form found 34 defects, and a verification pass found 18 more. The 18 included two that never landed and nine fixes that had introduced something new, including a connector routed through the node it pointed at.
