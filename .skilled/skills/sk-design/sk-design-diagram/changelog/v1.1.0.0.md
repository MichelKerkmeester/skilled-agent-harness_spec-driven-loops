# v1.1.0.0 - One form library, a Style Reference, and rules that hold themselves

**Released:** 2026-09-11

The packet had rules it stated and did not check, a corpus split into templates and examples for no
reason a reader could act on, and one visual language with no way to swap it. This release closes all
three, and fixes the 52 defects two reading passes found along the way.

## One form library

`assets/templates/` and `assets/examples/` are now `assets/diagrams/`, holding 38 forms. Every one is
a complete working diagram to copy and adjust; none is a strict template. Prefixes are gone, and the
four skin skeletons are named `starter-light`, `starter-dark`, `starter-terminal` and `starter-full`.

The code stopped keying on the directory, because the directory was never the real distinction. Both
applicators branch on whether a file carries a palette block, and the checker calls a file a starter
or a form by its name. The catalog indexes what answers a question, which is why the starters are not
in it. `--all` means all 38, and the examples flag is gone with the split it described.

## A visual language you can replace

`assets/style-reference/harness-diagram/` holds the language as one bundle: `DESIGN.md` states it,
`origin.md` says where it came from, `diagram-palette.json` carries the tokens, `icons.html` carries
the glyphs. Another language is a sibling directory with the same four files.

`apply-design-md.cjs` themes chosen forms from any local Style Reference — one measured by
`sk-design-md-generator` or one written by hand — gated before anything is written. The mapping is
two-tier: a reference naming our role tokens fills them verbatim, and anything it does not name falls
back to selection rules over its colour table. Tier one exists because pure rules cannot reproduce
this language; the lightest background row in a faithful reference of it is the near-white service
fill, not the off-white ground. Theming from the carried reference reproduces the stock palette
exactly, which is the property that says the two have not drifted apart.

## Rules that hold themselves

Two more checker families, bringing the corpus check to twelve. `legend-fidelity` refuses a legend
swatch drawn unlike the thing it keys. `short-connector-labels` refuses a label mask painted across a
connector under about 60px, because the mask erases the stroke the reader was told to follow; it
found a real instance on its first run that two reading passes had missed.

A `text-on-mark` gate now exists at 4.5:1. A reader had been measuring chip labels against the text
gate by analogy — the analogy was right and the gate was missing, which is the worse problem, because
a rule applied by eye holds only while someone is looking.

The starter hashes were deleted rather than refreshed. Nothing read them, all four were stale, and
byte-identity already catches the drift they claimed to, while a hash would have flagged every
legitimate geometry fix.

## Captures that show the whole page

The shared renderer takes `--full-page` and measures a page before shooting it. Eleven of the 38
forms are taller than the old fixed viewport, and the crop is what hid two serious defects from a
reviewer reading the committed images. The flag is opt-in and short-circuits before measurement, so
the sibling chart packet's images are unchanged, verified by instrumenting every browser spawn.

## Fixed

52 defects across the corpus: 34 from a full manual reading of every form, then 18 more that a
verification pass found — two that never landed and nine fixes that had introduced something new,
including a connector routed through the node it pointed at.

Four documents stopped stating values the corpus does not hold. The structural role stopped carrying
text in 50 places. The dot pattern is documented as the default because 26 of 34 forms use it. The
last form exempt from generation was tokenized, so the corpus now has no exemption at all.
