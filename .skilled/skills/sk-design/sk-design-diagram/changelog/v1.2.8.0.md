# v1.2.8.0, Long Prose Lines Are Short Sentences and Lists

`sk-design-diagram` reads in short sentences now. Six prose lines in `SKILL.md` had run past 400 characters, each one a rule or a pointer written as a single unbroken block. They are split, and the enumerations inside them are lists.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/010-prose-clarity-pass` (Level 2)

&nbsp;

## What's New at a Glance

- **The typography bullet is a list.** Each role and its font, size and weight stand on one line, from the Instrument Serif title to the Geist Mono eyebrow and arrow label.
- **The four connector rules are lists.** The arrow-label gap, the shared stroke path, the fan of attach points and the routing behind a box each carry their conditions as sub-points, with every pixel and unit value intact.
- **The format resolution is two paragraphs.** `html-svg` as the default and `ascii-markdown` as the plain-text path read as separate statements, and the type reference stays the HTML/SVG one.
- **Nothing routes differently.** Every type, token, pattern path and section number the file names is the same one.

&nbsp;

## Upgrade

No action is needed. The design system, the drawing workflow and every diagram type behave as they did.
