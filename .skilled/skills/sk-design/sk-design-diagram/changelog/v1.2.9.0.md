# v1.2.9.0, Router Guidance Moves to ROUTER.md

The diagram skill keeps a short SMART ROUTING section in `SKILL.md` and its detailed machine router in `ROUTER.md`. The SMART ROUTING section ends with a line linking to the new file.

&nbsp;

## What's New at a Glance

- **The router has a clear entry point.** `ROUTER.md` opens with an overview and an intent model, and its MACHINE ROUTER section holds the format-resolution rule, the resource domains and the loading-level table. The intent map, resource map, default resource and the reference implementation sit in `references/foundations/router-pseudocode.md`, which that section points at.
- **Routing remains unchanged.** The parsed router is identical to the previous edition.
- **Related guidance opens the new file.** Testing playbooks, feature catalog entries and references that pointed to the router inside `SKILL.md` now point to `ROUTER.md`.
- **The packet points at the router it now carries.** An alignment pass added `ROUTER.md` rows to four indexes and a scenario anchor table, gave the extracted pseudocode an overview and a packet-root path, and corrected connector-rule citations that named a section with no numbered rules.
