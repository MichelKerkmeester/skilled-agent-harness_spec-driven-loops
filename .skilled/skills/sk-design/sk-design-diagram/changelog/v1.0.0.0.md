# create-diagram v1.0.0.0, Initial release

The initial release adds `create-diagram` as a nested `sk-doc` workflow mode, forked from the third-party `diagram-design` plugin (`cathrynlavery/diagram-design`). It rebuilds the diagram guidance to the `sk-create-skill` authoring contract and brings references, extraction tools and a hub command into the mode.

## Why This Release

The source content was restructured rather than copied verbatim to conform to the repository's frontmatter, section-order and root-metadata-class contracts.

## What's New at a Glance

- **The skill follows the required authoring order.** Its five mandatory connector rules are kept intact.
- **The diagram references cover 27 types.** Each type has a canonical example asset.
- **The mode provides a shared editorial design system.** It includes onboarding, an output specification and four primitives.
- **draw.io and Mermaid extraction are included.** Both extraction scripts require only the standard library.
- **The `sk-doc` hub exposes `/design:diagram`.** The command offers an auto/confirm workflow.

---

## Diagram Guidance

#### A Consistent Skill Structure

`SKILL.md` follows the required `WHEN TO USE / SMART ROUTING / HOW IT WORKS / RULES / SUCCESS CRITERIA / REFERENCES` order. All five mandatory connector rules are intact.

&nbsp;

#### Shared Editorial Foundations

The design system includes `references/foundations/style-guide.md`, agent-mediated `onboarding.md` and `output-spec.md`. Its four primitives are annotation callout, sketchy filter, terminal chrome and icon library.

&nbsp;

#### One Example Per Type

The 27 diagram-type references live under `references/types/type-*.md`, each with a canonical example asset. The multi-variant gallery of light, dark and full examples per type was trimmed to one canonical example per type plus a small set of special-pattern examples.

---

## Diagram Tools

#### Extraction for Two Formats

`scripts/drawio_extract.py` extracts draw.io diagrams and `scripts/mermaid_extract.py` extracts Mermaid diagrams. Redraw references and `references/import-export/export.md` accompany them.

---

## Hub Integration

#### A Registered Diagram Command

Hub registration includes `mode-registry.json` and `hub-router.json`. It also includes `command-metadata.json`. The command has a router and presentation as well as the auto/confirm workflow.

## Source Plugin Material

#### Source Tooling Was Left Out

The source plugin's own CI/lint tooling was not ported because it validates the source repository's release process, not this packet's runtime content. The full trim manifest and rationale are in `specs/sk-doc/028-sk-design-diagram/001-inventory-and-skill-contract/decision-record.md`.
