# create-diagram v1.0.0.0, Initial release

The initial release adds `create-diagram` as a nested `sk-doc` workflow mode.

- It is forked from the third-party `diagram-design` plugin (`cathrynlavery/diagram-design`).
- It rebuilds the diagram guidance to the `sk-create-skill` authoring contract.
- It also brings references, extraction tools and a hub command into the mode.

The diagram guidance and references were restructured.

- The skill follows the required authoring order.
- All five mandatory connector rules are intact.
- The diagram references cover 27 types. Each type has a canonical example asset.

The mode also adds a design system, extraction tools and a hub command.

- The design system includes onboarding, an output specification and four primitives.
- draw.io and Mermaid extraction are included.
- The `sk-doc` hub exposes `/design:diagram`, with an auto/confirm workflow.

&nbsp;

## Why This Release

The source content was restructured, not copied verbatim.

- The change conforms to the repository's contracts.
- Those cover frontmatter, section order and root metadata class.

## Diagram Guidance

The release rebuilds the diagram guidance to the `sk-create-skill` authoring contract. The references were restructured, not copied verbatim.

#### A Consistent Skill Structure <a id="c-a-consistent-skill-structure"></a>

- `SKILL.md` follows the required `WHEN TO USE / SMART ROUTING / HOW IT WORKS / RULES / SUCCESS CRITERIA / REFERENCES` order.
- All five mandatory connector rules are intact.

#### Shared Editorial Foundations <a id="c-shared-editorial-foundations"></a>

- The design system includes `references/foundations/style-guide.md`.
- It includes agent-mediated `onboarding.md` and `output-spec.md`.
- Its four primitives are annotation callout, sketchy filter, terminal chrome and icon library.

#### One Example Per Type <a id="c-one-example-per-type"></a>

- The 27 diagram-type references live under `references/types/type-*.md`.
- Each has a canonical example asset.
- The multi-variant gallery had light, dark and full examples per type.
- It was trimmed to one canonical example per type, plus a small set of special-pattern examples.

&nbsp;

## Diagram Tools

This area covers extraction for the two supported diagram formats.

#### Extraction for Two Formats <a id="c-extraction-for-two-formats"></a>

- `scripts/drawio_extract.py` extracts draw.io diagrams.
- `scripts/mermaid_extract.py` extracts Mermaid diagrams.
- Both extraction scripts require only the standard library.
- Redraw references and `references/import-export/export.md` accompany them.

&nbsp;

## Hub Integration

The `sk-doc` hub gains a registered diagram command.

#### A Registered Diagram Command <a id="c-a-registered-diagram-command"></a>

- Hub registration includes `mode-registry.json` and `hub-router.json`.
- It also includes `command-metadata.json`.
- The command has a router and presentation.
- It also has the auto/confirm workflow.
