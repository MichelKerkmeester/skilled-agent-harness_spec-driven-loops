# v1.2.0.0: The visible gap, focal balance and a label rule that sees the corpus

Version 1.2.0.0 corrects mismatches between diagram rules and the drawings they describe.

- Capture review failed the corpus on the visible-gap read. It was right.
- Three focal-balance findings survived two earlier passes.
- Rules had been measured in one place and assumed in another.

Labels, focal accents and legends all changed.

- Swimlane arrow labels now have clearance.
- The rule family is now `label-mask-clearance`.
- Focal accents now mark the intended shapes.
- Legend rules now span the drawings they sit under.

Theming, conventions and capture review changed too.

- The library converged on one legend typography.
- Themed blocks now declare the system that painted them.
- A delivery is judged as the form it came from.
- Capture review now reads whole pages.

## Diagram Labels

Label clearance and mask detection both changed.

#### Swimlane Labels Gain Clearance <a id="c-swimlane-labels-gain-clearance"></a>

- All three swimlane arrow labels sat on their own connector.
- The skill's own rule demands six pixels of clearance there.
- One of them erased a forty-unit leg outright.
- The clearance floor is four units.
- It was set by rendering the tightest form in the library, not by rounding up.
- A box overpainted the fourth label.
- Only the bottom sliver of its glyphs rendered.
- That label was removed rather than relocated, because the colour and the legend already said what it said.

#### More Masks Enter the Rule <a id="c-more-masks-enter-the-rule"></a>

- Recognition depended on a class marker carried by only two forms.
- So the rule missed most of the library.
- It now recognizes any ground-filled rectangle with its label immediately after.
- That took it from 168 assertions to 820.
- The rule family is now `label-mask-clearance`.
- The 1.1.0.0 entry called it `short-connector-labels`.
- That name is based on the first defect it caught, not on what it checks.
- The first full run found 46 violations.
- Thirteen were masks that moved.
- Thirty-three were sentences that described behaviour the corpus does not have.
- Those were corrected.

## Focal Balance

The integration topology, venn and full starter carry the corrected accents.

#### The Integration Topology Marks Boxes <a id="c-the-integration-topology-marks-boxes"></a>

- It spent its accent on nine connectors.
- It declared it twice under two meanings.
- It now marks two boxes.
- The legend says so once.

#### The Venn Gains a Focal Mark <a id="c-the-venn-gains-a-focal-mark"></a>

- The venn had no focal mark at all.
- It had only an unused declaration.
- It now carries the accent on its one focal intersection.
- The focal label measures 10.57:1 where it measured 2.18:1.

#### The Full Starter Uses One Accent <a id="c-the-full-starter-uses-one-accent"></a>

- The full starter taught six accents to everyone who copied it.
- The ceiling is two.
- It now carries one.

&nbsp;

## Legends

Legend rules and swatches now match their drawings.

#### Rules Span Their Drawings <a id="c-rules-span-their-drawings"></a>

- Two legend rules now span the drawing they sit under.
- Their scope was measured across the library.
- That was measured, not assumed.
- Sixteen forms shared the suspect value.
- Only two fell short of their content.

#### Legend Conventions Match <a id="c-legend-conventions-match"></a>

- The library converged on one legend typography.
- Three had coexisted.
- A reader learning the convention from one file met a different one in the next.
- Two swatches in the high-level map drew a bare line.
- Every connector they keyed carried an arrowhead.
- The swatches now show arrowheads.
- So the legend shows a direction where the drawing does.

#### Keyed Fills Have a Measured Comparison <a id="c-keyed-fills-have-a-measured-comparison"></a>

- A reviewer complained that three keyed fills read as one grey.
- The answer was a measurement, not a change.
- Flattened against the paper, they sit within four percent.
- The guide now says so.
- The next reviewer will measure the same fills and reach the same conclusion.

&nbsp;

## Theming

Themed blocks now name what painted them.

#### Theme Tokens Scope Equality <a id="c-theme-tokens-scope-equality"></a>

- A themed file is supposed to differ from the stock palette.
- So checking it against the stock palette checked it against the thing it was built not to match.
- A themed block now declares the system that painted it.
- A themed block must name the reference that painted it, and prove it with a hash.
- If it cannot, it fails by name.
- Without that token nothing changes.
- With it, equality is skipped for that block alone.
- With it, every other rule and all four gates still run.

#### Deliveries Follow Their Source Forms <a id="c-deliveries-follow-their-source-forms"></a>

- A delivery is judged as the form it came from.
- Copied starters and legacy files follow their source forms.
- A copied starter keeps the exemption its starter earns.
- A copied legacy file keeps the off-grid allowance its source recorded.

#### The Front Door Names the Applicator <a id="c-the-front-door-names-the-applicator"></a>

- The applicator now applies the mark-text gate at write time.
- The applicator and the checker cannot disagree about whether a delivery is clean.
- The checker already applied the mark-text gate to a themed block.
- The sibling packet's front door named the applicator.
- This one did not.
- This packet's front door now names the applicator.

#### Roles Carry Their Translucency <a id="c-roles-carry-their-translucency"></a>

- When a role moves, its translucent forms travel with it.
- That covers 75 places across 32 of the 38 forms.
- Starter figures name declared roles.
- Eighty literals across the four starters hid the roles those starters declare.
- One starter declared ten roles.
- It referenced none of them inside its figure.
- It now names its role in eighty places.
- Two custom properties stopped naming colours they are not.
- So repainting a palette block repaints the drawing, not the header alone.
