This release lets charts with an honest data baseline lead with a number before the plot. GLM-5.3-Flash built it through pi from two short briefs.

## What's New at a Glance

- **Every form declares whether it has a metric header.** Eight forms set `present: true`. They show a value, signed delta and period above the plot. That sits between the subtitle and the figure. Beside `READOUT`, `METRIC` carries `value`, `valueLabel`, `delta`, `deltaLabel`, `period`, `trend` and a `why` line.
- **Metric values use a published 26px size.** `typeScale.roles` in the palette source gains `metric: 26px`. So the value uses a published size rather than a template-local one.
- **`metric-block` checks required fields and usage.** Errors cover a missing block, `present: true` without its labels and a trend outside the set. They also cover a script that never reads the value. They also cover markup shipped with `present: false`.
- **`card-parts` accepts an optional metric.** The part may sit between the subtitle and the figure. It fits nowhere else.
- **Values and deltas are grounded in each form's data.** Every value and delta is computed from that form's own data block. Each matches a number in its table.
