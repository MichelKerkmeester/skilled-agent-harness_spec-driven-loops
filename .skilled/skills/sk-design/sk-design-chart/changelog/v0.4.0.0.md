The chart corpus now carries one measured visual register from card chrome through marks, readouts and legends across all twenty-six forms and their deliveries. This makes the browser-facing surface coherent while keeping the existing data, palette and geometry contracts. Palette values, palette JSON, geometry blocks and numeric gates are preserved.

## What's New at a Glance

- **Every form uses a five-part, shadcn-informed card register.** The parts come in order: headline, subtitle, figure, footer and source. Titles, descriptions, ticks, notes, hero values and ring totals use the measured type scale, while findings and sources share the footer with a consistent divider and gap.
- **Tooltip-bearing forms render positioned HTML cards.** Each padded, rounded card sits inside the figure with a per-series indicator, the `READOUT` label and the formatted value. Tooltip copy is no longer painted as SVG text.
- **Multi-series forms render keyed legends.** Each declared series gets one centered entry with an 8px keyed swatch, muted 12px label and 16px gap.
- **Gallery frames pass the requested scheme to templates.** They pass `?scheme=light` or `?scheme=dark` and apply the corresponding `data-scheme` attribute inside the frame, which templates can honour consistently.
- **Cartesian forms use measured axes and marks.** They use bare axes, muted tabular ticks, an 8px tick margin, horizontal dashed grids, 2px lines and the measured bar and area radii. Single-series cartesian marks use the first categorical token, while emphasis remains reserved for highlighted marks.
- **Area fills use a 0.8-to-0.1 vertical gradient.** Stacked areas use flat 0.4 opacity, while ordinary line points remain invisible unless the form's contract calls for a highlighted point.
- **The corpus checker adds `legend` and `tooltip-card` families.** It retunes `type-scale`, `radius` and `card-parts` to the measured register without lowering any prior assertion floor.
- **The render pass remains dependent on Chrome launching in the sandbox.** When Chrome cannot launch there, existing captures remain untouched for the conductor to regenerate.

## Upgrade

No migration required.
