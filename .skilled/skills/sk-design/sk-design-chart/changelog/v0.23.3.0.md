# v0.23.3.0, The Routing Prose Is Short and the Router Moved to the End

`sk-design-chart` now reaches its chart workflow first. SMART ROUTING is five lines of plain prose instead of 44 lines of python and resource tables, and that material sits unchanged in a final `## 9. MACHINE ROUTER` section.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/007-sk-design-and-deep-loop-hubs` (Level 2)

&nbsp;

## What's New at a Glance

- **The routing section is prose.** Five lines say what selects the mode, what it loads first and where the router is, so a reader meets the chart workflow without scrolling past a discovery script.
- **The router is at the end.** The resource domains table and the python discovery block moved byte for byte into `## 9. MACHINE ROUTER`, the last H2 of the file.
- **Nothing routes differently.** The same catalog row, template file and style reference load as before, and the packet still answers only the chart phrases the hub sends it.

&nbsp;

## Upgrade

No action is needed. The router reads the same paths, and every chart form and palette behaves as it did.
