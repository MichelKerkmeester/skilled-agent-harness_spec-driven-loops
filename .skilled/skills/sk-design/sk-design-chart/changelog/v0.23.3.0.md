# v0.23.3.0, The Routing Prose Is Short and the Router Moved to the End

`sk-design-chart` now reaches its chart workflow first. SMART ROUTING is five lines of plain prose, not 44 lines of python and resource tables. That material sits unchanged in a final `## 9. MACHINE ROUTER` section.

&nbsp;

## What's New at a Glance

- The routing section is prose.
  - Five lines say what selects the mode.
  - The five lines say what it loads first and where the router is.
  - So a reader meets the chart workflow without scrolling past a discovery script.
- The router is at the end.
  - The resource domains table and the python discovery block moved byte for byte into `## 9. MACHINE ROUTER`.
  - That is the last H2 of the file.
- Nothing routes differently.
  - The same catalog row, template file and style reference load as before.
  - The packet still answers only the chart phrases the hub sends it.

&nbsp;

## Upgrade

No action is needed. The router reads the same paths. Every chart form and palette behaves as it did.
