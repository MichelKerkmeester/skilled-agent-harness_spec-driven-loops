# sk-design-chart v0.23.0.0

The packet kept its colour in `assets/color/` and its Style References in
`assets/style-reference/`, as if those were two subjects. They were one: v0.18.0.0 derived the
stock palette from the evilcharts reference, so the same values lived in two places and only a
prose line said which was the source. This release puts the palette inside the reference it came
from, and makes that arrangement a rule rather than a convention.

---

## 1. CHANGED

- **`assets/color/` no longer exists.** `palettes.json` and the three palette proof sheets moved
  into `assets/style-reference/evilcharts/`, beside the `DESIGN.md` they were measured from. Their
  screenshots followed to `screenshots/style-reference/evilcharts/`, which the renderer mirrors
  from the assets tree without being told.
- **The palette source is resolved, not hardcoded.** `check-corpus.cjs` and `apply-design-md.cjs`
  each name a default reference and build the path from it, so the stock values are one
  reference's answer rather than a file that floats free of any reference.
- **A palette proof sheet is recognised by its filename.** Two rules, card anatomy and the type
  scale, exempt the sheets because they prove colour rather than draw a chart. Both matched the
  old directory, which would have meant editing them each time a reference was added. Both now
  match `palette-sheet-*.html` wherever a reference keeps it.

---

## 2. ADDED

- **Every Style Reference must carry its own `palettes.json`, and it must record a derivation.**
  The corpus check fails a reference directory that has neither. This is the rule the release
  exists for: adding a reference is now deciding its colour, not inheriting whichever palette
  happens to be the default. Verified by adding a reference with no palette and watching the gate
  fail, then with an empty palette and watching the derivation check fail.

---

## 3. NOT CHANGED

- **No colour value moved.** This is a relocation, not a re-colour. Every template still reads the
  same values and the corpus check passes with the same assertion counts.
- **The three systems still mean what they meant.** `neutral`, `ordered` and `categorical` remain
  answers to what colour encodes. Owning them per reference means a second reference brings its own
  three, not that the encodings changed.
