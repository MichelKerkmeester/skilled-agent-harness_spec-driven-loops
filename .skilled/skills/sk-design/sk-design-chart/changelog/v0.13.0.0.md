Everything the last four releases recorded as a gap is closed. Two of them were checks that could not fire. One was a paragraph describing a palette that no longer ships. The last was the derivation this packet rests on. It was documented rather than held.

&nbsp;

## What's New at a Glance

- The `metric-block` family now runs across the whole corpus.
  - Its repository-relative label could not match the resolved directory.
  - So its first assertion never ran on a shipped form.
  - A form without a metric header could therefore drop its declaration unnoticed.
  - The family now makes 122 assertions across the corpus.
  - It previously reached only deliveries.
- A colour paragraph that described a replaced palette is rewritten.
  - `references/color-system.md` illustrated the theme-boundary rule.
  - It used a categorical rotation into navy, gold and violet-blue.
  - The shipped categorical system rotates nothing.
  - All four hues clear the mark gate on both grounds.
  - Only the fourth value moves, back to its measured tone.
  - The paragraph is rewritten with the measured ratios.
- `palette-derivation` is a new check family.
  - The palette is a derivation of one Style Reference.
  - Nothing held it to that.
  - The four departures are now structure rather than a prose note.
  - Each names the gate it was made to clear.
  - Each names what it is measured against.
  - `palette-derivation` checks that the reference is still the file the palette came from.
  - It checks that every value is published by it or accounted for.
  - It checks that each departure is still both necessary and sufficient.
- `points` now applies in both directions.
  - A form promising marks must draw them.
  - A form declaring none may no longer paint a visible one.
  - A circle in a form the rule cannot parse is an error, not a pass.
- Four references are vendored for override-path coverage.
  - The suite borrows them.
  - So coverage for the override path does not fail when an unrelated library is pruned.
- Derivation checks now cover both carried references.
  - Three tests were added.
  - That is because the suite could not detect if either stopped deriving.
  - One assertion compared a value with itself on the first pass.
  - The constant it meant to check is now exported.
  - So the assertion is real.
