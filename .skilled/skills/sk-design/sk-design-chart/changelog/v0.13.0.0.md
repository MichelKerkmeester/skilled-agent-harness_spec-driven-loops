Everything the last four releases recorded as a gap is closed. Two of them were checks that could
not fire, one was a paragraph describing a palette that no longer ships, and one was the derivation
this packet rests on being documented rather than held.

## What's New at a Glance

- **The `metric-block` family now runs across the whole corpus.** Its repository-relative label could not match the resolved directory, so its first assertion never ran on a shipped form. A form without a metric header could therefore drop its declaration unnoticed. The family now makes 122 assertions across the corpus, where it previously reached only deliveries.
- **A colour paragraph that described a replaced palette is rewritten.** `references/color-system.md` illustrated the theme-boundary rule with a categorical rotation into navy, gold and violet-blue. The shipped categorical system rotates nothing: all four hues clear the mark gate on both grounds, and only the fourth value moves, back to its measured tone. The paragraph is rewritten with the measured ratios.
- **`palette-derivation` is a new check family.** The palette is a derivation of one Style Reference and nothing held it to that. The four departures are now structure rather than a prose note, each naming the gate it was made to clear and what it is measured against. `palette-derivation` checks that the reference is still the file the palette came from, that every value is published by it or accounted for, and that each departure is still both necessary and sufficient.
- **`points` now applies in both directions.** A form promising marks must draw them, and a form declaring none may no longer paint a visible one. A circle in a form the rule cannot parse is an error, not a pass.
- **Four references are vendored for override-path coverage.** The suite borrows them, so coverage for the override path does not fail when an unrelated library is pruned.
- **Derivation checks now cover both carried references.** Three tests were added because the suite could not detect if either stopped deriving. One assertion compared a value with itself on the first pass. The constant it meant to check is now exported, so the assertion is real.

## Upgrade

No migration required.
