The chart corpus can now use evilcharts through the override path as a second option beside the stock reference. Its stylesheet provides the source values for that style.

## What's New at a Glance

- **`assets/style-reference/evilcharts/` adds a v3 reference.** It contains eighteen colour tokens converted from the stylesheet's `oklch()` values, the three typefaces it binds and a radius ladder derived from `--radius: 0.525rem`. `origin.md` separates what was measured from what was authored.
- **A `tokens.json` file adds the dark theme setting.** It sits beside the reference, where the applicator reads `darkMode` from a file under exactly that name. evilcharts has a dark theme, so this makes the dark chart set resolve against `#090909` rather than the corpus stock dark chrome.
- **Both chart sets are in the colour table.** The reference ships both sets as tokens, and four of nine hues clear on both grounds at the 3:1 mark a chart mark needs: Flame 3.60/5.53, Teal 3.67/5.43, Violet 4.12/4.83 and Rose 3.75/5.30. Deep and Cobalt clear only on white, while Gold, Amber and Jade clear only on ink.
- **A light-only table was refused.** It was refused not for want of hues that clear on ink but because the applicator picks series greedily for hue separation as well as contrast, and the light set could not offer it four separated candidates on the dark ground.
- **The hue note was corrected in v0.13.0.0.** It had called the two sets complements and named the wrong hues on each side. The correction addressed errors about three of the nine hues and the reason.
- **Two of the five light chart colours cannot carry a thin stroke.** Against evilcharts' own white, Gold reaches 1.72:1 and Amber 2.13:1, both below the 3:1 a mark needs. The reference records this rather than correcting it because a Style Reference documents a source.
- **Applying the reference themes 25 of the 29 forms.** The four ordered ramps are refused by design, as with any reference.

No migration required.
