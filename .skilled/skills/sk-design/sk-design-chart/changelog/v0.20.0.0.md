Two of the three fixes in v0.19.0.0 shipped before the reader who checked them came back. Both were wrong. v0.20.0.0 corrects them. The same pattern has now occurred twice in a row. A fix read by its maker shipped. Then someone else found it had not worked.

## What's New at a Glance

- **The box plot median now contrasts with its box.** v0.19.0.0 thinned the stroke from three units to one and a half. It called the median repaired. But the width was never the reason it remained a hole. The page-coloured stroke read as the ground showing through, however thin it was drawn. So every box was still split into two stacked blocks. A filled box now takes the ink. The emphasised box is filled with the ink, so it takes the hue. It never takes the page colour. One rule covers both grounds.
- **The box plot's finding was checked and left alone.** It names three teams. The emphasis marks one. v0.19.0.0 repaired this shape in two other forms by rewriting the sentence. Those rewrites do not apply here. The cluster claim reads from median heights, which the first fix restores. Complex is emphasised because its 85-day span is the sentence's one hard number. Position carries the first half of the claim. Colour carries the second.
- **The white box was checked and left alone.** It is 44% of the plot's ink. A reader counting pixels measured it. That is under the line. It follows from Complex's genuinely widest quartile range, not from a colour decision.
- **The dumbbell axis now reads 0, 20, 40, 60.** v0.19.0.0 stopped thinning from dropping the last rung. That recovered 60 and fixed that symptom. But it left the axis at 0, 40, 60. Thinning exists to relieve crowding. This four-step ladder had nothing to relieve. So thinning spent half the rungs. It left nine of the ten rows inside one unbroken span. That span had no interior mark to read a distance against. Every rung inside the readings is now drawn.
