# v0.23.2.0, The chart packet stops advertising extraction phrases

The Keyword triggers line now names only the phrases the sk-design hub sends to this packet. The two extraction phrases it advertised belong to sk-design-md-generator, and two chart phrases take their place.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/004-single-vocabulary-source` (Level 2)

&nbsp;

## What's New at a Glance

- **The extraction phrases leave the line.** `style reference` and `DESIGN.md` now sit only in sk-design-md-generator, so a request for either no longer promises work this packet cannot do.
- **Two chart phrases join it.** `theme a chart` and `measured site's look` describe what this packet does, and the hub routes both here.
- **A new check holds the line to the router.** `.skilled/skills/sk-doc/sk-create-skill/scripts/ci-hub-vocabulary-source.cjs` compares the line against `hub-router.json` and reports any term the hub sends to another packet.
