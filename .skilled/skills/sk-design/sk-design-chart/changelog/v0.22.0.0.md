On request, the gallery is gone, along with the work that existed only to serve it.

## What's New at a Glance

- **`assets/gallery.html` and `scripts/build-gallery.cjs` are removed.** The packet's own contract already says a gallery is a workbench and never a deliverable.
- **Height-poster scripts are removed from every template.** Twenty-nine forms carried a script whose only reader was the gallery's frame sizer. The `?scheme=` reader beside it stays for the screenshot renderer.
- **The `gallery` and `frame-height` families are removed, with the renderer's gallery exclusion.** Nothing framed the corpus any more, so nothing had a frame to hold.
- **Screenshots are now the review surface.** There is one capture per form, replacing the gallery's two views, one for each colour scheme.
- **Every screenshot capture was re-rendered from the final sources.** The set was rebuilt from empty: 32 sources, 32 captures, none stale.

## Upgrade

No migration required.
