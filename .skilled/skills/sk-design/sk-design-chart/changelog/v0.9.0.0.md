The chart corpus could not answer three questions. Now those questions have forms. What has a number been doing lately? Did each period hold? Which of these is biggest when the names are long? `spark`, `tracker` and `bar-list` add those views.

## What's New at a Glance

- **`spark` adds a KPI-sized trend.** It has no axis, gridlines or tick labels. It marks the last reading. It carries the value in the metric header. Its three declared variants are line, area and bar. It holds twenty-four readings in a 176-unit frame.
- **`tracker` shows status across periods.** It uses one block per period, across sixty periods. Each block has a legend and a tooltip. Green means held. Amber means degraded. The alarm colour means failed. Status classes are named rather than indexed. So each status takes the colour its meaning asks for. The conductor moved `tracker` off the ordered ramp. That is because capture showed three adjacent steps a reader could not tell apart at block size.
- **`bar-list` is a ranked list where long names cost no horizontal room.** Labels sit inside bars. They slip outside when a bar is too short. Values are right-aligned in the mono stack. The largest row is emphasised.
- **The catalogue gives each new form a row.** Each row carries the reader question it answers. The corpus is 29 chart forms. All three pass every existing family without needing a new one. GLM-5.3-Flash built one form per brief through pi.
