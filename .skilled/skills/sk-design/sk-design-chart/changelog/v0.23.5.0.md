# v0.23.5.0, Separate Machine Router

This release separates the machine router from the skill's short routing guidance. The parsed router remains identical to the previous edition.

&nbsp;

## What's New at a Glance

- **The routing details have a dedicated home.** The intent map, resource map, default resource, loading levels and routing pseudocode live in `ROUTER.md` after a short overview and intent model.
- **`SKILL.md` keeps routing guidance short.** Its SMART ROUTING section ends with a link to `ROUTER.md`.
- **Related documents use the new path.** Testing playbooks, feature catalog entries and references point to `ROUTER.md`.
