# v0.23.5.0, Separate Machine Router

This release separates the machine router from the skill's short routing guidance. The parsed router remains identical to the previous edition.

&nbsp;

## What's New at a Glance

- **The routing details have a dedicated home.** `ROUTER.md` opens with an overview and a prose intent model, then a MACHINE ROUTER section holding the format-resolution rule, the resource domains and the discovery pseudocode. This packet keeps no machine resource map, default resource or loading-level table, so none moved.
- **`SKILL.md` keeps routing guidance short.** Its SMART ROUTING section ends with a link to `ROUTER.md`.
- **The routing scenario uses the new path.** `manual-testing-playbook/delivery-and-routing/form-choice-and-the-diagram-boundary.md` now points at `ROUTER.md`. The packet ships no feature catalog, and its references never named the router.
- **The packet names sk-design as its hub.** An alignment pass corrected the hub named in the description, the boundary list, the integration input, the playbook index and both README tables, and made the routing scenario expect `sk-design` at stage one.
