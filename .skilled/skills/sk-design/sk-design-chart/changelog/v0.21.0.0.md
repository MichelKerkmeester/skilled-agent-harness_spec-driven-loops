# sk-design-chart v0.21.0.0

sk-design-chart v0.21.0.0 aligns its palette guidance with the stock palette source.

- The packet now carries one Style Reference.
- It is evilcharts.

It removes worked deliveries.

- They came from `assets/examples/`.
- Their captures are removed too.

Table values become directly visible.

- `table-disclosure` now requires `open` on every form.
- Table values are visible without relying on a hover.

Gallery frames get the height their forms need.

- Gallery frames now fit each form.
- The finding and source were cut off on the majority of tiles.

> [!IMPORTANT]
> 3 changes can break an existing setup.
>
> 1. `assets/style-reference/cursor/` is removed. [One Source for the Palette](#c-one-source-for-the-palette)
> 2. The captures for `assets/examples/` are removed. [Templates Replace Deliveries](#c-templates-replace-deliveries)
> 3. Every data table starts open. [Values Visible Without Hovering](#c-values-visible-without-hovering)

&nbsp;

## Why This Release

The packet carried two Style References. One of them had stopped being true.

- Data tables were closed wherever a tooltip answered the pointer.
- That left the tooltip as the only visible source of the values on twenty forms.
- That meant one hover per number.
- Every gallery frame was 560px tall.
- Most forms ran past it.

## Style Reference

#### One Source for the Palette <a id="c-one-source-for-the-palette"></a>

> [!WARNING]
> `assets/style-reference/cursor/` is removed.

- The stock palette has been derived from evilcharts since v0.18.0.0.
- `--default` has themed from it since then.
- Three references still called cursor the stock.
- `SKILL.md`, `references/color-system.md` and `references/design-md-theming.md` now say what the palette source and applicator already did.
- The corner-ladder argument had still been made from the cursor reference's numbers.
- The passage now follows the ladder the applicator reproduces.
- That is 4.4px on the track, swatch and pill.
- It is 8.4px on the card and the corpus's own 2px mark corner.

&nbsp;

## Templates and Tables

#### Templates Replace Deliveries <a id="c-templates-replace-deliveries"></a>

> [!WARNING]
> The captures for `assets/examples/` are removed with the worked deliveries.

- The templates are now the corpus.
- Seven families scoped to templates-or-examples are now scoped to templates.
- The hand list that named a delivery no longer does.
- The mutation case that read a themed delivery from disk now builds one with the applicator instead.
- So the fixture is made by the code under test.

#### Values Visible Without Hovering <a id="c-values-visible-without-hovering"></a>

> [!WARNING]
> Every data table starts open.

- `table-disclosure` now requires `open` on every form.
- It says so.
- The disclosure used to follow the interaction register.
- It was open only on inert forms.
- The contract and the checker comment carry the reason.

&nbsp;

## Gallery

#### Frames Fit Their Forms <a id="c-frames-fit-their-forms"></a>

- The clipping was worse after the tables opened.
- Each file is its own origin.
- So a page cannot measure a frame on disk.
- Each form posts its own height to a parent on load and on every change.
- The gallery sizes the frame that sent it.
- `frame-height` holds the template side.
- `gallery` holds the listener.
