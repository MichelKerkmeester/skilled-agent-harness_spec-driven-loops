The corpus took a visual overhaul in seven phases. Every chart now carries one chrome. It moves once when it opens. It answers a pointer. It paints on either ground. It says so when it has nothing to draw. A twenty-first form landed for the question nothing in the index answered. `progress-single` now uses its declared color system. The corpus check grew from fifteen named checks to twenty-five. It grew from one browser-backed check to three. That is because a rule the tooling does not check is a wish. It is also because this release wrote eight rules before it enforced them.

## Why This Release

A chrome change is a twenty-file change. Finding out afterwards that the operator dislikes it costs twenty reverts.

## What's New at a Glance

- **Five corner rungs now share one 2px knob.** `assets/color/palettes.json` supplies them to every file. It uses the palette block already there.
- **Nine forms animate when opened.** Their form determines which motion they use.
- **Twelve forms gain a pointer.** Hover cards, in-figure keys and dimming support the interactions that suit each form.
- **Charts carry a dark palette that follows the system preference.** The chart file adds no theme switch.
- **A notice distinguishes unreadable data from an all-zero chart.** The message appears inside the frame.
- **`bar-line-composed` fills the index's twenty-first-form gap.** It places a count and rate on the same periods.
- **`progress-single` now makes fill follow value.** The color ramp runs across the whole track.
- **A published type scale sets the available text sizes.** The size of the next form's axis tick is now a choice out of six rungs rather than a guess.
- **Rule 13 now reads motion outside stylesheet regions.** The old blind spot was motion driven from drawing code.
- **Eleven more checks now enforce written rules.** They cover rendering, dark-palette contrast, empty notices and more.
- **The draggable range window is refused on density and contract grounds.** The ramp-key rename is the release's one deliberate carry-forward.
- **The catalog rows and the six family deliveries were audited.** No catalog row moved, and no delivery needed a word changed.

## Chart Presentation

#### Corners and Figure Clarity

Twenty-nine files typed `border-radius: 10px`. Another twenty-one corners were typed into drawing code as `rx` values. All fifty are gone. A `radius` check fails a corner typed anywhere else.

Every figure a reader compares is set in a system mono face with tabular figures. So an axis rung, a value label and a table cell line up digit under digit. Grids are dashed and drawn below full strength. That is because the rule token is also the card border. A grid at the same weight competes with the frame.

&nbsp;

#### Chrome Tested Before Expansion

The chrome was proved on two files before it reached twenty. Two forms carried the agreed rows. The one row nobody could settle by argument was rendered three ways. It was rendered on a sheet the operator read.

&nbsp;

#### Motion Follows the Form

Three time-series forms wipe in from the left over one second. Six bar forms grow each mark from the anchor it is measured against over half a second. Consecutive marks sit a twentieth of a second apart. The stagger is capped rather than accumulated. So a file settles inside one second, whatever a reader pastes into its data block. The other eleven forms do not move and carry no fallback. That is why the gate checks that the grep returns nine files rather than at least nine.

&nbsp;

#### Pointer Controls Stay Reachable

A hover card appears on the seven forms whose marks carry a value the picture cannot print. A key appears inside the figure on the four multi-series forms. A dim to a third appears on the five where holding one series against the rest is the reading. Every key entry is a button rather than a label. That is because the key is also the control for the dim. A control reachable by pointer has to be reachable from a keyboard.

&nbsp;

#### The System Sets the Ground

Every file carries a second palette block behind a `prefers-color-scheme` query. It has its own sentinel pair. The palette source gained a dark ground, dark text roles and dark series values for all three systems. They were chosen against near-black rather than derived from the light ones. Mixing a color toward the surface is what makes a mark disappear on a dark ground.

A delivered chart has no state to keep a preference in. So the reader's operating system is the only signal. A chart printed from a dark browser still goes onto paper the way it always did.

&nbsp;

#### Empty Data Gets a Notice

An empty frame and a chart whose values are all zero look identical. So a reader shown an empty box had no way to tell which one they were holding. All twenty-one forms now print one line in the middle of the frame. They draw nothing else when the data block holds nothing readable.

Readability, not length, determines whether there is anything to draw. A block whose entries all carry values that are not finite numbers has length. It still has nothing to draw. The first guard coerced with `Number()` before testing finiteness. `Number(null)` is zero. So null-only input passed straight through to a drawing with nothing to draw. The guard now uses the test already used in the three time forms that break a line at a gap. A fixture found this. That is the reason the phase wrote fixtures.

&nbsp;

#### Focus Preserves Copying

The interaction hygiene borrowed from the reference is one line rather than two. The focus half is adopted through `:focus-visible`. It drops the ring for a reader who clicked. It keeps the ring for a reader who tabbed. The text-selection half is refused outright. That is because the numbers in a delivered chart are meant to be copied out of it. `interaction-hygiene` now fails both a widening of the first half and any return of the second.

## Chart Forms

#### Counts and Rates Share Periods

The index had no row for this pairing. That is because `waterfall` covers signed steps against a running total. It is also because no other form put two measures with different units on one period axis. `bar-line-composed` puts count columns and a rate line over the same periods.

The second scale is a condition rather than a setting. The form divides the larger of the two peaks by the smaller. It draws a right-hand ladder at a factor of ten or more. Below that it uses one shared ladder. When an editor changes the values, the numbers determine which scale appears. A dual axis is the easiest way to lie with a chart. The arithmetic is what keeps this one honest.

&nbsp;

#### Progress Color Tracks Value

`progress-single` sits on `ordered`. Its whole content is that color encodes magnitude. Its fill was fixed and did not move. The fill now sweeps along the ramp with the value. The ramp is anchored to the whole track rather than the fill. So its shade says how far along the goal the bar has reached. It does not say only the end of the bar.

&nbsp;

#### Gap Notices Fit the Frame

A period with no rate on `bar-line-composed` prints one line under the plot. The line landed below the bottom edge of the drawing. There a reader saw its top half. The notice now grows the frame. That is what the ceiling notices elsewhere in the corpus already do.

## Corpus Rules

#### Motion Rules Cover Every Route

Rule 13 had never once fired on a real file. That is because it read stylesheet regions and nothing else. Motion driven from drawing code matched none of its patterns. So it could ship with no fallback while the check reported a pass. It now reads three routes. It checks each against the guard that route can honor. It rejects two things it never looked for. One is a fallback that shortens the motion instead of removing it. The other is an animation that repeats.

&nbsp;

#### Published Type Scale Guides Sizes

Six named roles and three named departures were recorded from what the corpus already did. They were not proposed. They live in the palette source beside the corner ladder. `type-scale` rejects a size on neither list.

&nbsp;

#### Eleven More Checks Enforce the Rules

Eleven more checks landed. Every one was written after the rule it enforces. `settled-render` compares two opens of every file as pictures rather than only as documents. That is because a stylesheet animation never touches the DOM. `dark-render` opens each file a third time with the scheme pinned dark. It requires a different picture. That is because a block pasted outside its media query matches the source in both directions. It changes nothing on screen. `palette-source-dark` runs every contrast gate against the dark surface as its own line. So one theme's pass cannot be read as covering both. Eight more landed in the closing phase. They are `empty-notice`, `geometry-block`, `catalog-system`, `type-scale`, `interaction-hygiene`, `interaction-state`, `number-format` and `gradient-sweep`. Every new assertion was watched failing before it was trusted. The recipes are written into `scripts/README.md` so the next reader can repeat them.

&nbsp;

#### Range Windows Stay Out

The draggable range window is refused, and for two reasons rather than one. It is allowed only where a form is genuinely dense, past thirty points on a continuous axis. No form in the corpus reaches that. `daily-line` has a documented ceiling of thirty readings. It ships twenty-eight. `stacked-area` ships twenty-four periods. `bar-line-composed` is documented at six to twelve.

The second reason survives a raised ceiling. A range window rescales an axis and moves every mark. Contract section 10 already forbids a handler from doing that. That clause would need amendment before density mattered at all.

&nbsp;

#### Ramp Names Carry Forward

Two gate keys still carry names written for one ground. `rampDarkestOnSurface` and `rampLightestOnSurface` read wrong on a dark ground. There the step this corpus calls the darkest is the brightest one. The check tests the end by its distance from the ground rather than by its position in the array. It says which end it tested. So the behavior is right and the names are not.

They land as `rampFarEndOnSurface` and `rampNearEndOnSurface`. The change spans `color-system.md`, `palettes.json` and `check-corpus.cjs`. It lands in one edit or not at all. That edit is the one thing this release deliberately carries forward.

## Catalog and Release Records

#### Catalog Assignments Hold

The phase was built around the research finding that `grouped-bars` sits on the wrong system. The reading does not support it. All twenty catalog rows were read against the color definitions one by one. No row moved. The two series of `grouped-bars` are ordered in time. `categorical` is defined for categories that are unordered. `neutral` is the documented default that wins a tie. The reading found instead that `progress-single` was correctly declared. It was behaving as though it were not. Every verdict is written down, including the seventeen that were never in doubt. A wrong claim survived that long because nobody had read both documents against each other.

&nbsp;

#### Scenario Headlines Need No Rewrite

Each family delivery carries a scenario filename and a headline. The headline states a conclusion rather than a label. The six were audited against the headline rule. None needed a word changed. The audit is the deliverable, not a rewrite. A rewrite invented to justify the task would have been the failure.

&nbsp;

#### Versions Name Their Own Scope

A changelog entry's version names the release it describes. It does not name the packet's current state. Each document carries its own version. The packet version sits in `SKILL.md` and `README.md`. The three files in this directory read three different numbers. All three are correct.
