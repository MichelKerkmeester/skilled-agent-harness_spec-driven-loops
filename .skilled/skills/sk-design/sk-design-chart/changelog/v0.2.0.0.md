The chart corpus makes its figures easier to trust. This holds across templates and screen sizes. Readers can tell missing measurements from real values. They can also understand what shaded values mean. They can understand what oversized inputs mean.

&nbsp;

## Why This Release

Ten recommendations from fidelity research were reviewed against the contract. Seven were applied. Three were refused in writing. That is because an item nobody decided is an item that comes back.

&nbsp;

## What's New at a Glance

- One formatter handles every printed value in each template.
  - Ticks, value labels, hover titles and table cells all use it.
  - So a number agrees across views with comma grouping.
  - That holds regardless of the host locale.
  - The formatter also rounds to six decimals (`0.6000000000000001` becomes `0.6`).
  - Fractional ladders use the same decimal count for every rung.
  - So the candlestick axis reads `87.5 · 100.0 · 112.5 · 125.0 · 137.5 · 150.0` as one column.
- Missing readings leave gaps instead of zero marks.
  - Before, `daily-line` treated `null` as zero.
  - That pulled its line to the baseline.
  - `daily-line` also made the low-point annotation print `null`.
  - Now `daily-line` splits into segments at gaps.
  - `daily-line` searches only readings that exist.
  - `daily-range` leaves a missing day undrawn.
  - `daily-range` keeps its axis slot.
  - `stacked-area` breaks the whole stack.
  - `stacked-area` does not substitute zero and drop every band above it.
  - Each form reports how many readings it left out.
  - That is because a hole and a short line look the same.
- `scatter` and `heat-matrix` show when data exceeds their limits.
  - The catalog stated a shape per row but did not enforce it.
  - So a delivery with three times the data drew anyway.
  - `scatter` past twenty points now grows its frame.
  - `heat-matrix` past a hundred cells does the same.
  - Each prints one line with the count and ceiling.
  - A console warning was rejected.
  - That is because the person the ceiling protects reads the chart, not a developer console.
- The heat matrix explains its shaded values.
  - Its five-swatch ramp runs from palest to darkest.
  - It spans the low to the peak.
  - It shows what each step is worth.
- Narrow screens pan under Rule 14.
  - Each corpus file gives its figure region horizontal scrolling.
  - Each corpus file gives its drawing a minimum width.
  - So a phone-width screen pans rather than shrinking labels together.
  - The skeleton an author copies carries Rule 14 too.
  - So does every delivered example.
  - The corpus check enforces it.
  - That includes the rule that the floor is never wider than the drawing's own `viewBox`.
  - Rule 14 is asserted from the stylesheet, not from a rendered page.
  - The contract says so.
  - A headless browser hands back the DOM.
  - The DOM does not say whether the page overflowed.
  - The numbers that would answer it live in layout.
  - The check proves the affordance is declared.
  - That is the part an author forgets.
  - Whether a chart is legible at its floor stays a review question.
- Figure descriptions map series to swatches.
  - Five forms resolve their colors only through a detached key.
  - On those, a screen-reader user could learn that a stacked column had three product lines.
  - A screen-reader user could not learn which band was which.
  - The descriptions follow key order and stacking order, not color names.
  - So a palette swap cannot make the sentence wrong.
- Numeric budget comments explain crowded labels.
  - Seven forms explain the arithmetic behind gutter widths, thinning divisors and axis spacing.
  - Seven forms say how many units a gutter holds.
  - Seven forms say how many characters fit at the label size.
  - Seven forms say what to change when it runs out.
  - The constants were correct but unexplained.
  - That is how a later author picks a different one.
- `progress-single` measures its headline text.
  - Its unit used to sit at `String(value).length * 34`.
  - That was a character-count estimate against a proportional font.
  - The estimate became wrong when the formatter inserted a group separator.
  - It now advances by measured text length.
  - It keeps the character count as the fallback before layout.
- Diverging colors were declined.
  - No catalog form consumes a midpoint.
  - So a diverging system would repeat the fourth-system mistake.
  - That mistake is documented in the color reference.
  - The condition for reopening that decision is written down.
- Pattern fills were declined.
  - Each form already carries a non-color cue.
  - Pattern fills would change every chart's visual register.
  - They would solve a problem no current form has.
- Continuous gradient legends were declined.
  - Both shaded forms use five discrete steps.
  - So a continuous legend requested for both would promise unsupported resolution.
  - The heat matrix uses a stepped ramp.
  - The calendar grid keeps the stepped ramp it had.
- Each template duplicates the formatter.
  - This follows the corpus idiom.
  - A template is one file a recipient edits by hand.
  - A shared helper would break the delivery unit.
