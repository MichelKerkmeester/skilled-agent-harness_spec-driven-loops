The chart corpus makes its figures easier to trust across templates and screen sizes. Readers can distinguish missing measurements from real values and understand what shaded values and oversized inputs mean.

## Why This Release

Ten recommendations from fidelity research were reviewed against the contract. Seven were applied and three were refused in writing because an item nobody decided is an item that comes back.

## What's New at a Glance

- **One formatter handles every printed value in each template.** Ticks, value labels, hover titles and table cells all use it, so a number agrees across views with comma grouping regardless of the host locale and six-decimal rounding (`0.6000000000000001` becomes `0.6`). Fractional ladders use the same decimal count for every rung, so the candlestick axis reads `87.5 · 100.0 · 112.5 · 125.0 · 137.5 · 150.0` as one column.
- **Missing readings leave gaps instead of zero marks.** Before, `daily-line` treated `null` as zero, pulling its line to the baseline and making the low-point annotation print `null`, but it now splits into segments at gaps and searches only readings that exist. `daily-range` leaves a missing day undrawn while keeping its axis slot and `stacked-area` breaks the whole stack instead of substituting zero and dropping every band above it, with each form reporting how many readings it left out because a hole and a short line look the same.
- **`scatter` and `heat-matrix` show when data exceeds their limits.** The catalog stated a shape per row but did not enforce it, so a delivery with three times the data drew anyway. `scatter` past twenty points and `heat-matrix` past a hundred cells now grow their frames and print one line with the count and ceiling. A console warning was rejected because the person the ceiling protects reads the chart, not a developer console.
- **The heat matrix explains its shaded values.** Its five-swatch ramp runs from palest to darkest between the low and the peak, showing what each step is worth.
- **Narrow screens pan under Rule 14.** Each corpus file gives its figure region horizontal scrolling and its drawing a minimum width, so a phone-width screen pans rather than shrinking labels together. The skeleton an author copies and every delivered example carry Rule 14 too. The corpus check enforces it, including that the floor is never wider than the drawing's own `viewBox`. Rule 14 is asserted from the stylesheet, not from a rendered page, and the contract says so. A headless browser hands back the DOM, and the DOM does not say whether the page overflowed. The numbers that would answer it live in layout. The check proves the affordance is declared, which is the part an author forgets. Whether a chart is legible at its floor stays a review question.
- **Figure descriptions map series to swatches.** On the five forms whose colors are only resolved through a detached key, a screen-reader user could learn that a stacked column had three product lines without learning which band was which. The descriptions follow key order and stacking order rather than color names, so a palette swap cannot make the sentence wrong.
- **Numeric budget comments explain crowded labels.** Seven forms explain the arithmetic behind gutter widths, thinning divisors and axis spacing, including how many units a gutter holds, how many characters fit at the label size and what to change when it runs out. The constants were correct but unexplained, which is how a later author picks a different one.
- **`progress-single` measures its headline text.** Its unit used to sit at `String(value).length * 34`, a character-count estimate against a proportional font that became wrong when the formatter inserted a group separator. It now advances by measured text length and keeps the character count as the fallback before layout.
- **Diverging colors were declined.** No catalog form consumes a midpoint, so a diverging system would repeat the fourth-system mistake documented in the color reference. The condition for reopening that decision is written down.
- **Pattern fills were declined.** Each form already carries a non-color cue. Pattern fills would change every chart's visual register to solve a problem no current form has.
- **Continuous gradient legends were declined.** Both shaded forms use five discrete steps, so a continuous legend requested for both would promise unsupported resolution. The heat matrix uses a stepped ramp and the calendar grid keeps the stepped ramp it had.
- **Each template duplicates the formatter.** This follows the corpus idiom: a template is one file a recipient edits by hand. A shared helper would break the delivery unit.

## Upgrade

No migration required.
