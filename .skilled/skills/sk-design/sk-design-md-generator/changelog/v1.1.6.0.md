# v1.1.6.0, A lighter install and a working output path

v1.1.6.0 removes `playwright-extra` and `puppeteer-extra-plugin-stealth`, two npm packages the extraction backend declared but never imported. A fresh install now pulls 42 fewer packages, including a copy of `deepmerge` that GitHub flags for prototype pollution with no patched version. The crawl is unchanged, but the output rule now accepts the `specs/` folder the README tells you to use.

> Spec folder: `specs/system-speckit/053-ci-workflow-efficiency/014-unused-dependency-removal` (Level 1)

&nbsp;

## What's New at a Glance

- **A fresh install carries no flagged `deepmerge`.** The only route to it ran through the stealth plugin, so `npm ls deepmerge` in `backend/` now prints an empty tree.
- **Crawls behave exactly as before.** No source file imported either package, so nothing about how pages are fetched or measured moves.
- **The documented output folder works.** The README says to pass `--output specs/<track>/<packet>/output`, but the output rule only allowed `.opencode/specs`, a folder this repository does not have, so the run stopped before it crawled. The rule now accepts `specs/` and still accepts `.opencode/specs`.
- **The help text points at real paths.** `--help` and the missing-output error now print the script's real location and the `specs/` folder, where they printed paths that no longer exist.
- **Copied commands run.** The extraction workflow, the guided-run reference and 11 playbook pages pointed at a skill folder that does not exist, so a pasted command failed. They now use the real path. They and the install guide show `specs/<track>/<packet>/output` as the output folder.
- **The guides tell the truth about the tools.** The install guide's package list drops both removed packages and names `ts-node` as the dev dependency it is. The troubleshooting page used to say the tool ships stealth. It now says the crawl runs on plain Playwright with no stealth measures, so some sites block it.

&nbsp;

## Upgrade

Run `npm install` in `backend/` to drop the two packages from an existing install. No other migration required.
