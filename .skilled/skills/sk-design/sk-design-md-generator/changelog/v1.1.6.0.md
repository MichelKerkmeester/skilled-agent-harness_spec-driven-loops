# v1.1.6.0, A lighter install and a working output path

v1.1.6.0 removes `playwright-extra` and `puppeteer-extra-plugin-stealth`. The extraction backend declared both npm packages but never imported them. A fresh install now pulls 42 fewer packages. That count includes a copy of `deepmerge`. GitHub flags that copy for prototype pollution, with no patched version. The crawl is unchanged. But the output rule now accepts the `specs/` folder the README tells you to use.

&nbsp;

## What's New at a Glance

- **A fresh install carries no flagged `deepmerge`.** The only route to it ran through the stealth plugin. So `npm ls deepmerge` in `backend/` now prints an empty tree.
- **Crawls behave exactly as before.** No source file imported either package. So nothing about how pages are fetched or measured moves.
- **The documented output folder works.** The README says to pass `--output specs/<track>/<packet>/output`. But the output rule only allowed `.opencode/specs`. This repository does not have that folder. So the run stopped before it crawled. The rule now accepts `specs/` and still accepts `.opencode/specs`.
- **The help text points at real paths.** `--help` and the missing-output error now print the script's real location and the `specs/` folder. Before, they printed paths that no longer exist.
- **Copied commands run.** The extraction workflow, the guided-run reference and 11 playbook pages pointed at a skill folder that does not exist. So a pasted command failed. They now use the real path. They and the install guide show `specs/<track>/<packet>/output` as the output folder.
- **The guides tell the truth about the tools.** The install guide's package list drops both removed packages. It names `ts-node` as the dev dependency it is. The troubleshooting page used to say the tool ships stealth. It now says the crawl runs on plain Playwright with no stealth measures. So some sites block it.

&nbsp;

## Upgrade

Run `npm install` in `backend/` to drop the two packages from an existing install. No other migration required.
