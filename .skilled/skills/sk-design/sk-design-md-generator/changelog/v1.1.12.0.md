# v1.1.12.0, Numeric Design Laws Point to the Frontend Surface

The numeric design laws still report measured values and never decide them. The paragraph that named the design values mode as the deciding side now names sk-code's frontend surface instead, with its reference files as the place where the authoring direction lives. No threshold, row or reading rule changed.

> Spec folder: `specs/sk-design/021-deprecate-fundamentals` (Level 2)

&nbsp;

## What's New at a Glance

- **Value decisions have a live owner again.** A reader who reaches the reconciliation note is sent to `sk-code-frontend` instead of a mode that no longer exists.
- **The reading and authoring split is unchanged.** This document still reports the values a captured surface uses. The authoring side still decides the values a new surface should use.
