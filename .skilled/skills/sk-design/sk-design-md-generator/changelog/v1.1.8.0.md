# v1.1.8.0, The Routing Prose Is Short and the Router Moved to the End

`sk-design-md-generator` now reaches its instructions first. SMART ROUTING is five lines of plain prose. It was 145 lines of phase trees, resource tables and python. That material sits unchanged in a final `## 9. MACHINE ROUTER` section.

&nbsp;

## What's New at a Glance

- The routing section is prose.
  - Five lines say what selects the mode, what it loads first and where the router is.
  - So a reader meets the extraction pipeline without scrolling past a router.
- The router is at the end.
  - The phase detection, the resource domains and the loading levels moved byte for byte.
  - So did the procedure-card rule and the python router.
  - The moved material sits in `## 9. MACHINE ROUTER`, the last H2 of the file.
- Nothing routes differently.
  - The same intents, keywords and resource paths load as before.
  - Every pointer that named Section 2 now names Section 9, in this file and in three playbook anchors.

&nbsp;

## Upgrade

No action is needed. The router reads the same paths. The phase detection behaves as it did.
