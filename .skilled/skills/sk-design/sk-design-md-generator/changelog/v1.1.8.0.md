# v1.1.8.0, The Routing Prose Is Short and the Router Moved to the End

`sk-design-md-generator` now reaches its instructions first. SMART ROUTING is five lines of plain prose instead of 145 lines of phase trees, resource tables and python, and that material sits unchanged in a final `## 9. MACHINE ROUTER` section.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/007-sk-design-and-deep-loop-hubs` (Level 2)

&nbsp;

## What's New at a Glance

- **The routing section is prose.** Five lines say what selects the mode, what it loads first and where the router is, so a reader meets the extraction pipeline without scrolling past a router.
- **The router is at the end.** The phase detection, the resource domains, the loading levels, the procedure-card rule and the python router moved byte for byte into `## 9. MACHINE ROUTER`, the last H2 of the file.
- **Nothing routes differently.** The same intents, keywords and resource paths load as before, and every pointer that named Section 2 now names Section 9, in this file and in three playbook anchors.

&nbsp;

## Upgrade

No action is needed. The router reads the same paths, and the phase detection behaves as it did.
