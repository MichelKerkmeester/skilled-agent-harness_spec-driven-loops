# v1.0.0.0 - First Stable Release

First stable release of the `md-generator` skill. It captures a live website's real, measured CSS in a publication-quality v3 Style Reference `DESIGN.md`, giving AI agents ground truth for colours, fonts, spacing and shadows instead of hallucinated values. It is the extraction-and-format-fidelity engine of the `sk-design-*` family, alongside `sk-design-interface` for new distinctive direction and the `mcp-figma` and `mcp-open-design` transports.

## What's New at a Glance

- **The embedded `backend/` provides a three-phase pipeline.** It includes 20 TypeScript pipeline modules and a vitest suite in `backend/tests/`.
- **`extract` captures CSS from five viewports for `write`.** A Playwright crawler samples the viewports and emits `tokens.json`. `write` composes the v3 Style Reference `DESIGN.md`, pre-rendering value-bearing sections deterministically and writing prose from a FACTS block.
- **`validate.ts` checks the `DESIGN.md`.** It checks hex accuracy, v3 section completeness and Quick-Start fidelity.
- **`write` copies numeric values verbatim from `tokens.json`.** Every hex, pixel, font-weight, shadow and radius must match. Estimating, rounding or inventing values breaks the document's hallucination-proof purpose. Validation runs before any completion claim.
- **`references/` contains eight knowledge docs and gold-standard examples.** Gold-standard sets for stripe, vercel, linear and supabase sit in `references/examples/`. Each set pairs a v3 Style Reference `DESIGN.md` with `tokens.json` and `writing-notes.md`.
- **`SKILL.md` routes the pipeline and its supporting paths.** Routing covers the `extract`, `write` and `validate` phases, plus a report and an example-study path. `SKILL.md` also encodes the cardinal verbatim-value rule, 6-digit lowercase hex and the L1-L4 stability gates.
- **Framework guidance covers extraction and troubleshooting.** `references/extraction-workflow.md` adds framework-specific operational guidance and `references/troubleshooting.md` adds failure-mode fixes. Deep design knowledge stays in `references/`.
- **`INSTALL-GUIDE.md` documents setup and a first extraction.** It gives the one-time command `cd backend && npm install && npx playwright install chromium`.
- **The regenerable example HTML reports were trimmed.** The reduction was about 2 MB, keeping the skill lean.
- **`graph-metadata.json` registers `md-generator` in the `sk-code` family.** It sets the `design` category and reciprocal sibling edges that link `md-generator` with `sk-design-interface` and with each of the `mcp-figma` and `mcp-open-design` transports. It also includes an `enhances` edge to `sk-code`, which builds against the `DESIGN.md` as its implementation contract.
