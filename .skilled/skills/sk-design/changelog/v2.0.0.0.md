`sk-design` was a single skill. It is now a parent hub of four modes.

Chart and diagram move in from `sk-doc`, the md generator returns as a mode, commands land on `/design:` and fundamentals stops being UI-only.

## Why This Release

`sk-design` projects one design identity and routes to the mode owning the decision being asked for.

## What's New at a Glance

- **Four modes are registered for `sk-design`.** `sk-design-fundamentals` is the default.
- **Design commands use the `/design:` surface.** It includes `/design:extract`, `/design:chart` and `/design:diagram`.
- **Canvas modes have rendered screenshots.** They cover every form the two canvas modes ship.
- **Fundamentals is no longer UI-only.** The WCAG review pass still applies only where the surface is a screen.
- **The root `SKILL.md` follows the `sk-code` and `sk-doc` shape.** Its routing rules are explicit.
- **`resourceContractVersion` is now a number.** Its value in `mode-registry.json` is `1`, matching every peer hub.
- **The mode table gains a command column.** It shows the same command declared in `mode-registry.json`.
- **Chart and diagram move from `sk-doc`.** They take this hub's name.

---

## Design Modes

#### Registered Modes Own Routing

`mode-registry.json` declares the modes. `hub-router.json` and the root `ROUTER.md` route them. `sk-design-md-generator` returns as a mode.

&nbsp;

#### Commands Follow Mode Rules

`sk-design-fundamentals` routes by alias and carries no command of its own. Mode tool surfaces did not change. `sk-design-md-generator` remains the only mutating mode.

&nbsp;

#### Screenshots Stay Out of Leaf Sets

The rendered screenshots sit beside each canvas mode rather than inside `assets/`. This means a human-facing picture never enters a mode's loadable leaf set.

## Design Guidance

#### Fundamentals Covers More Surfaces

First-class surfaces include:

- Slide decks
- Printed layouts
- Document surfaces
- Screen UI

---

## Hub Structure

#### Root Routing Names Its Parts

The root `SKILL.md` has these routing parts:

- A surface router
- A stated discriminator
- An explicit routing rule
- An unknown-input fallback

&nbsp;

#### A Numeric Contract Version

`resourceContractVersion` had been the string `"1.0.0"`, which reads as absent to a numeric check. That silently disabled the manifest byte-drift, target-collision and reachability checks.

---

## Chart and Diagram

#### Mode Names Join the Hub

Chart and diagram left `sk-doc` and took this hub's name: `sk-create-chart` became `sk-design-chart` and `sk-create-diagram` became `sk-design-diagram`. Both hubs were edited together so no phrase was claimed twice.

&nbsp;

#### Records Keep Their Old Names

The chart corpus contract and its checker moved unmodified. Authored spec-folder records, benchmark reports and run artifacts describe what was on disk when they were written and keep the old names.
