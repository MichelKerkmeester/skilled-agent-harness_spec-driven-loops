# v2.0.7.0, One Home for the Router Reason

The hub `SKILL.md` no longer restates why the leaf router stays in `ROUTER.md`. It links to `parent-skills-nested-packets.md`, which gives the reason once for every hub that carries a root router. Routing is unchanged.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/006-sk-doc-hub` (Level 2)

&nbsp;

## What's New at a Glance

- **The reason lives in one place.** `SKILL.md` points at the reference section rather than repeating why the machine block cannot move into `SKILL.md` or `hub-router.json`.
