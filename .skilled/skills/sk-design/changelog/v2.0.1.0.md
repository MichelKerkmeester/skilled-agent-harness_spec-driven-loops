# v2.0.1.0, Rules in ALWAYS, NEVER and ESCALATE IF Form

v2.0.1.0 brings the hub `SKILL.md` to the skill template's rule shape and ships the feature catalog fixes in sk-design-diagram and sk-design-md-generator.

> Spec folder: `specs/sk-doc/066-feature-catalog-template-anchor-deprecation` (Level 2)

&nbsp;

## What's New at a Glance

- **The rules say when to stop.** Section 5 lists what to always do, what never to do and two cases that escalate: a request with no registered mode, and a registry, router or manifest that disagree.
- **Section 4 is named References.** Its table is unchanged.
- **Mode catalogs are cleaner.** sk-design-diagram v1.2.1.0 to v1.2.2.0 and sk-design-md-generator v1.1.1.0 to v1.1.3.0 drop the template-name comment and repair the strict validator findings.
