# v2.0.10.0, Routing Rules Move to ROUTER.md

The routing rules for sk-design moved out of SKILL.md. They moved into a final MACHINE ROUTER section of ROUTER.md. SKILL.md stays short. The move leaves the hub's routes as they were.

&nbsp;

## What's New at a Glance

- SKILL.md keeps a single pointer.
  - SKILL.md no longer carries a MACHINE ROUTER section.
  - Its SMART ROUTING section ends with one line.
  - That line points to ROUTER.md.
- The compiler finds the checklist in either file.
  - When that section exists, it reads the fallback checklist from the final MACHINE ROUTER section of ROUTER.md.
  - It reads from SKILL.md when the section does not exist.
- The move changed no route.
  - The map from intent to files is byte for byte the same.
  - Every route the hub selects matches the run before the move.
  - The compiled admission check gives the same result.
  - The compiled manifest was regenerated from the new sources.
- The hub meets the routing-shape canon.
  - Its known-debt entry is removed.
  - So the hub no longer needs an exception in that check.
- ROUTER.md speaks from its own point of view.
  - The `SKILL_ROOT` line now reads from the router itself.
  - So does the separate-document line.
- The playbooks name the file that holds the router.
  - An alignment pass repointed four hub scenarios from `SKILL.md` to `ROUTER.md`.
  - The alignment pass replaced sk-doc's eighteen-intent list in a diagram scenario with the hub's five leaf intents.
  - The alignment pass corrected the hub named in the `/design:diagram` and `/design:chart` choreography.
- A chart or diagram that names a DESIGN.md reaches its theming branch.
  - "style reference" no longer scores `sk-design-md-generator` on its own.
  - "theme this chart" and "theme the chart" now score `sk-design-chart`.
  - A diagram repaint from a DESIGN.md routes to `sk-design-diagram` alone.
  - A chart theming request routes to the generator and then the chart.
  - A request to extract, generate or validate a DESIGN.md still routes to the generator.

No action is needed.
