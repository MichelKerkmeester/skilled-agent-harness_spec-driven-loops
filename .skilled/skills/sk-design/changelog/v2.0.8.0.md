# v2.0.8.0, Routing Prose Short, Detail in One Place

The routing section of the hub `SKILL.md` now opens with a short summary. The mode table moved up into When to Use, and the compiled-routing directive, the discriminator and the routing rule sit together in a final `## 6. MACHINE ROUTER` section. Routing is unchanged.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/007-sk-design-and-deep-loop-hubs` (Level 2)

&nbsp;

## What's New at a Glance

- **The routing summary fits the canon budget.** Twelve lines name the two stages, the compiled-router call, the vocabulary file and the no-signal default.
- **The detail has one home.** The compiled-routing directive, the leaf-router pointer and the routing rule now sit together at the end of the file.
- **The mode table opens the skill.** Which mode owns what, and the command for each, now reads in When to Use, before any routing detail.
- **The registry warning reads beside the layout.** The note that a registry row proves nothing moved to How It Works, where it explains the mechanism rather than the routing.

&nbsp;

## Upgrade

No action is needed. The compiled router, the mode names and the routing behaviour are unchanged.
