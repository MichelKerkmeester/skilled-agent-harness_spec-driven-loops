# v2.0.5.0, The Hub Drops an Author Line It Never Used

The sk-design hub metadata carried an `author: OpenCode` entry beside its `family` field. No part of the runtime read it. It also did not tell the truth about who wrote the hub. The line is gone for both reasons, while the `family` field stays and the rest of the frontmatter is untouched.

> Spec folder: `specs/sk-code/017-portable-code-modes/015-frontmatter-yaml-validity` (Level 2)

&nbsp;

## What's New at a Glance

- **The hub frontmatter says only what it means.** The `metadata` block keeps `family: sk-design`. The `author` key is gone with no replacement because no consumer existed.

No migration required.
