# v2.0.2.0, Typo-Proof Script Options

The corpus checkers, the screenshot renderer and the design.md generator scripts used to ignore a misspelled option. Each one now names the option and exits with an error before it does any work.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/021-open-ends-remediation/001-typo-proof-parsers` (Level 1)

&nbsp;

## What's New at a Glance

- **A mistyped option fails loudly.** `check-corpus.cjs`, `check-diagram-corpus.cjs`, `render-screenshots.cjs` and `guided-run.ts` refuse an option they do not know.
- **`build-write-prompt.ts` stops when the study context cannot be read.** It used to print a prompt without the study and exit 0. It now exits 1 with the read error.

&nbsp;

## Upgrade

Replace any misspelled option with the one the script's usage line lists.
