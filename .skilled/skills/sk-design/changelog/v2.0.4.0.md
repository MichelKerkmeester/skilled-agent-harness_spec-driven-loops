# v2.0.4.0, Paths That Run When Copied

The sk-design READMEs now give commands that work when you copy them. That is because each one names the folder where the file lives. A few of them also gained a shape you can scan. An overview comes first, then numbered sections.

&nbsp;

## What's New at a Glance

- Copied commands run unchanged.
  - The main sk-design-md-generator README prints the real hub path `.skilled/skills/sk-design/sk-design-md-generator/`.
  - So do the READMEs in its backend, styles and styles database folders.
  - All of them replace the old top-level one.
- The tokens file is copied from its own folder.
  - The sk-design-fundamentals README reads `tokens.css` out of `sk-design-fundamentals/assets/`.
  - That is where the file lives.
- Two styles READMEs point at what exists.
  - The tests README drops a pointer to a playbook that was removed.
  - The styles README names its `tests/` folder.
- Three READMEs read in the same order.
  - Each opens with an overview, then numbers its sections.
  - One is the sk-design-diagram style-reference README.
  - Another is the md-generator design-knowledge README.
  - The last is the md-generator examples README.
- The v2.0.2.0 hub entry says what its scenario does.
  - It describes the create-diagram command scenario in words.
  - It does not quote its identifier.
