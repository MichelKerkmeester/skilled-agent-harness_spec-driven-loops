# v2.0.4.0, Paths That Run When Copied

The sk-design READMEs now give commands that work when you copy them, because each one names the folder where the file lives. A few of them also gained a shape you can scan: an overview first, then numbered sections.

> Spec folder: `specs/sk-doc/070-repo-doc-debt` (Level 2)

&nbsp;

## What's New at a Glance

- **Copied commands run unchanged.** The main sk-design-md-generator README and the READMEs in its backend, styles and styles database folders print the real hub path `.skilled/skills/sk-design/sk-design-md-generator/` instead of the old top-level one.
- **The tokens file is copied from its own folder.** The sk-design-fundamentals README reads `tokens.css` out of `sk-design-fundamentals/assets/`, where the file lives.
- **Two styles READMEs point at what exists.** The tests README drops a pointer to a playbook that was removed. The styles README names its `tests/` folder.
- **Three READMEs read in the same order.** The sk-design-diagram style-reference README, the md-generator design-knowledge README and the md-generator examples README open with an overview, then number their sections.
- **The v2.0.2.0 hub entry says what its scenario does.** It describes the create-diagram command scenario in words rather than quoting its identifier.
