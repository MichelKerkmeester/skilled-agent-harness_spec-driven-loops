The packet's Smart Routing section now follows the sk-create-skill template, with Availability Check as its detection signal and a resource loading table in place of the request-to-file table.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/041-code-readmes-and-routing-alignment/` (Level 2)

## What's New at a Glance

- **Smart Routing follows the sk-create-skill template.** One Smart Router Pseudocode block replaces the request-to-file table the section used before.
- **The wire contract loads on every route.** `references/wire-contract.md` is the baseline resource. `references/model-pin.md` and `references/deem-ctl-lifecycle.md` load only when their intent fires.
- **The script folders gained code-folder READMEs.** `scripts/` and `scripts/tests/` now each hold one.

## Upgrade

No migration required.
