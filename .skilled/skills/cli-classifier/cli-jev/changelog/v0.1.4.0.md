The packet's Smart Routing section now follows the sk-create-skill template and states which resources load on every route.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/041-code-readmes-and-routing-alignment/` (Level 2)

## What's New at a Glance

- **Smart Routing follows the sk-create-skill template.** Section 2 now carries Prerequisite Detection, Phase Detection, Resource Domains, an ALWAYS / CONDITIONAL / ON_DEMAND loading table and one Smart Router Pseudocode block. The request-to-file table is gone.
- **Every route loads the same two resources.** `references/cli-reference.md` and `references/integration-patterns.md` load on every route. The provider, MCP and question-shaping resources load only when their intent fires.
- **Transport Guard and Transport Selection moved.** Both now sit in section 3 How It Works, unchanged in wording.
