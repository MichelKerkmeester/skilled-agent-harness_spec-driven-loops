The cli-classifier hub now registers one mode, and this packet's SKILL.md says so.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/046-deem-deprecation/004-references-sweep-and-verification` (Level 2)

## What's New at a Glance

- **Jev is the hub's only mode.** The Hub Integration section names `cli-jev` as the only mode `cli-classifier` registers today, where it used to name a sibling mode.
- **A future classifier has a stated path.** It joins the same parent hub as a new mode with its own packet.
- **The transport is unchanged.** Commands, gates, provider handling and the wire contract are as in v0.1.4.0.
