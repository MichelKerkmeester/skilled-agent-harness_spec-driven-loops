# v0.8.3.0, One Vocabulary Source for Mode Routing

The root `ROUTER.md` stage-two intents now carry every term `hub-router.json` routes to each mode, so a prompt stage one sends to a mode always finds that mode's leaves. Thirteen terms were added to close the gap.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/004-single-vocabulary-source` (Level 2)

&nbsp;

## What's New at a Glance

- **The added terms are the cli-jev invocation phrases.** Phrases such as `run jev` and `typed judgment cli` now name their mode at both routing stages.
- **The skill advisor reads the same words.** Their multi-word forms also sit in `graph-metadata.json` intent signals, the list the advisor scores.
- **A new check keeps the vocabulary from drifting.** `ci-hub-vocabulary-source.cjs` fails when the registry aliases, the root `ROUTER.md` intents or a packet `Keyword triggers:` line disagree with `hub-router.json`, which is now the one authored mode vocabulary.
