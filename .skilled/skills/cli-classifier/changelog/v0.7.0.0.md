The hub now registers `cli-jev` as its only mode. It remains a full parent hub so future classifier backends can join as separate modes with their own packets.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/046-deem-deprecation/003-cli-deem-mode-removal/` (Level 2)

## What's New at a Glance

- **The retired mode leaves the hub.** The `cli-deem` mode and packet were removed, leaving `cli-jev` as the only registered mode.
- **Future classifiers have a clear path in.** Add each backend as a new mode and packet under the existing parent hub.

## Upgrade

No migration required.
