# v0.8.6.0, Routing Rules Move to ROUTER.md

The cli-classifier routing rules moved out of SKILL.md. They moved into a final MACHINE ROUTER section of ROUTER.md. That keeps SKILL.md short. The way the hub routes stays the same.

&nbsp;

## What's New at a Glance

- SKILL.md keeps a single pointer.
  - SKILL.md no longer carries a MACHINE ROUTER section.
  - Its SMART ROUTING section ends with one line.
  - That line points to ROUTER.md.
- Routing is unchanged.
  - The map from intent to files is byte for byte the same.
  - Every route the hub selects matches the run before the move.
  - The compiled admission check gives the same result.
- The compiled activation manifest was regenerated.
  - Its sources changed.
  - So the manifest was rebuilt from the new files.
- The hub meets the routing-shape canon.
  - Its known-debt entry is removed.
  - So the hub no longer needs an exception in that check.
- A read-only alignment pass corrected the front page, the playbook anchors and one router sentence.
  - The changelog pointer and table now reach this release.
  - Both hub-routing scenarios name ROUTER.md as the source of the expected leaves.
  - The surface router says which source the replay reads.
