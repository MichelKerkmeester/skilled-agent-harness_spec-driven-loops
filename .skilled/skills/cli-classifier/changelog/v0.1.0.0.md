`cli-jev` leaves the `cli-external-orchestration` family. It becomes Jev's single public hub identity. It has one packet named `cli-usage`.

## What's New at a Glance

- **The hub and transport resolve apart.** The advisor resolves the hub. `hub-router.json` resolves the transport. `mode-registry.json` is the registry of record.
- **`cli-usage` is the hub's first mode and its only `packetKind: "transport"`.** Its `noul`, `choice`, `score` and `run` operations each return one typed value from a state. The mode writes nothing into the workspace.
- **The `transport-axis` extension registers `cli-usage`.** The hub declares `extensions["transport-axis"].transports: ["cli-usage"]`. The per-hub gate enforces the full contract. It covers `routingClass` `metadata`, `mutatesWorkspace: false`, the forbidden `Write`, `Edit` and `Task` tools and membership in the axis.
- **The hub ships its companion files.** It includes `SKILL.md`, `README.md`, `ROUTER.md` with `router_state: stage1-only`, `description.json`, `graph-metadata.json` and `leaf-manifest.json`. It ships a hub `changelog/`, a hub `manual-testing-playbook/` and a `benchmark/` baseline.
- **The hub carries an inactive compiled-routing directive.** `SKILL.md` has the `Compiled routing (default-on` marker, `compiled-route.cjs --hub cli-jev`, the `servingAuthority":"legacy` sentinel and the `SPECKIT_COMPILED_ROUTING=0` kill-switch. The directive stays inert until the hub is onboarded to the serving closure.
- **The `cli-usage` packet moved to its new home.** It moved from `.skilled/skills/cli-external-orchestration/cli-jev/` to `.skilled/skills/cli-jev/cli-usage/`. History is preserved by rename. Its references, assets, feature catalog, playbook, benchmark and changelog moved with it.
- **Existing `cli-jev` requests still reach the transport.** `cli-usage` is the mode identity. `cli-jev` remains a hub id, a mode alias and the hub's routing vocabulary.
- **The transport names its new hub.** Its prose names `cli-jev` instead of `cli-external-orchestration`. Its packet `SKILL.md` frontmatter is `name: cli-usage`.
- **The judgment evidence stays the same.** At the new path, the contract keeps the eight hard rules and four references. It also keeps the question-shaping card, JEV scenario ids and recorded run verdicts.

No migration required.
