# v0.8.2.0, Two Retired Jev Features Removed

v0.8.2.0 removes two features from the hub's Jev feature registry. They are the reviewer verdict fallback and the hallucination grader. Both existed only to back runs in the retired `/deep:model-benchmark` command. So `shared/scripts/jev-features.mjs` now lists the two features that are still live.

&nbsp;

## What's New at a Glance

- **The registry holds two features instead of four.** The citation drift advisory and the injection screen remain with their switches.
- **The transport itself is untouched.** Routing, exit codes and the two remaining switches behave as before.

&nbsp;

## Upgrade

Delete the `JEV_FEATURE_VERDICT_FALLBACK` line from your own `.env` or `.skilled/hooks/hook-flags.env`. Delete the `JEV_FEATURE_HALLUCINATION_GRADER` line too. Nothing reads them. No other migration is required.
