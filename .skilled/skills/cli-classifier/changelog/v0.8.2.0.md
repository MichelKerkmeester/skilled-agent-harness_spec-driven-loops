# v0.8.2.0, Two Retired Jev Features Removed

v0.8.2.0 removes the reviewer verdict fallback and the hallucination grader from the hub's Jev feature registry. Both existed only to back runs in the retired `/deep:model-benchmark` command, so `shared/scripts/jev-features.mjs` now lists the two features that are still live.

> Spec folder: `specs/system-deep-loop/039-deprecate-improvement-modes` (Level 2)

&nbsp;

## What's New at a Glance

- **The registry holds two features instead of four.** The citation drift advisory and the injection screen remain with their switches.
- **The two retired switches are inert.** `JEV_FEATURE_VERDICT_FALLBACK` and `JEV_FEATURE_HALLUCINATION_GRADER` have no effect wherever you set them.
- **The transport itself is untouched.** Routing, exit codes and the two remaining switches behave as before.

&nbsp;

## Upgrade

Delete the `JEV_FEATURE_VERDICT_FALLBACK` and `JEV_FEATURE_HALLUCINATION_GRADER` lines from your own `.env` or `.skilled/hooks/hook-flags.env`. Nothing reads them. No other migration is required.
