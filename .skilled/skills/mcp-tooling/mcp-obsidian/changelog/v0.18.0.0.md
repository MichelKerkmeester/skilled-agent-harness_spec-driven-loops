# v0.18.0.0, Registration Documentation Aligned

This documentation release aligns mcp-obsidian's guidance with registration that is already live. It also corrects the README version and the catalog link. No runtime, vault or config files were touched. No config, environment or vault data was written.

## Why This Release

The "later gated phase" wording was accurate when written. That is because registration wiring was genuinely deferred to a gated configuration phase. That phase has since run. `.utcp_config.json` carries the `obsidian` manual. `.env` and `.env.example` carry the three `obsidian_OBSIDIAN_*` keys. The prose was not reconciled to that change.

The README version and link casing pass `validate_document.py`. That is because frontmatter version is not cross-checked against `SKILL.md`. A case-insensitive filesystem also masks the link mismatch. So neither surfaced in prior conformance passes.

## What's New at a Glance

- **Registration guidance reflects the live `obsidian` wiring.** Nine passages across six files replace the pending "later gated phase" wording with present tense. They include the config note and the "Never auto-modify" invariant in `SKILL.md` §3 and §4. The invariant's prohibition on auto-modifying `.utcp_config.json`, `.env.example`, `opencode.json` and hub files is unchanged in intent. Its justification shifts from "a later phase applies it" to "already registered there."
- **The `README.md` and `SKILL.md` versions now match.** The `README.md` frontmatter version changes from `0.12.0.0` to `0.18.0.0`. It had drifted five releases behind the tracked `SKILL.md`. The `SKILL.md` version changes from `0.17.0.0` to `0.18.0.0`.
- **The `README.md` §9 link matches the catalog filename's case.** In §9, `feature-catalog/feature-catalog.md` changes to `feature-catalog/FEATURE-CATALOG.md`. The lowercase link resolved on case-insensitive macOS. It would 404 on a case-sensitive Linux/CI checkout. The `v0.10.0.0` and `v0.17.0.0` references in historical changelog entries are left untouched.
