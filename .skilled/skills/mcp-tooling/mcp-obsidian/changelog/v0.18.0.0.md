# mcp-obsidian v0.18.0.0

Documentation-vs-reality drift fix. The `obsidian` MCP manual is now live in `.utcp_config.json` and the `obsidian_OBSIDIAN_*` keys are in `.env.example`, but nine passages across six files still described that registration as pending a "later gated phase." This corrects the narration, fixes a stale README version, and repairs one case-mismatched link. No runtime, vault, or config files were touched.

---

## 1. CHANGED

- **Stale "later phase" registration narration → present tense (9 spots, 6 files).** The manual and env keys are already wired, so the docs now say so:
  - `SKILL.md` — §3 config note and the §4 "Never auto-modify" invariant. The agent prohibition is preserved verbatim in intent; only the "a later phase applies it" justification became "already registered there."
  - `README.md` — the install-script FAQ answer.
  - `INSTALL-GUIDE.md` — the §4 env-values note.
  - `references/troubleshooting.md` — the MCP-not-found fix step.
  - `references/mcp-tools.md` — the registration note callout.
  - `mcp-servers/obsidian-mcp/README.md` — the AT A GLANCE "Produces" row, the QUICK START Step 3, and the §4 VERIFICATION registration note.
- **`README.md` frontmatter version 0.12.0.0 → 0.18.0.0.** It had drifted 5 releases behind `SKILL.md` (the tracked version).
- **`README.md` §9 link casing.** `feature-catalog/feature-catalog.md` → `feature-catalog/FEATURE-CATALOG.md` to match the on-disk filename. The lowercase link resolved on case-insensitive macOS but would 404 on a case-sensitive Linux/CI checkout.
- `SKILL.md` version 0.17.0.0 → 0.18.0.0.

## 2. WHY IT WAS MISSED

- The "later phase" wording was accurate when written — the wiring was genuinely deferred to a gated configuration phase. That phase has since run (`.utcp_config.json` carries the `obsidian` manual; `.env` and `.env.example` carry the three keys), but the prose was never reconciled to the new reality.
- The README version and the link casing both pass `validate_document.py` (frontmatter version is not cross-checked against `SKILL.md`, and a case-insensitive filesystem masks the link mismatch), so neither surfaced in prior conformance passes.
