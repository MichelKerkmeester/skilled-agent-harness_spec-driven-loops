# v0.24.5.0, The Iconic Rulebook Reads as Vault Data

The plugin knowledge layer names `data.json` twice: once as the Iconic rulebook the mode treats as a file format, once in the plugin table as the file the 21 file rules and 11 folder rules merge into. The reference check read the name as a file in this repository, found none, and failed the README.

The name stays, because that is the file the live plugin writes and the mode edits. The README now declares it in its `readme-check` block with the reason that the vault holds the rulebook and this repository does not. The backup-before-write discipline is unchanged.
