# v0.24.5.0, The Iconic Rulebook Reads as Vault Data

The plugin knowledge layer names `data.json` twice. Once it is the Iconic rulebook. The mode treats that as a file format. Once it is in the plugin table. There the 21 file rules and 11 folder rules merge into it. The reference check read the name as a file in this repository. It found none, and it failed the README.

The name stays. That is because the live plugin writes it and the mode edits it. The README now declares it in its `readme-check` block. The reason is that the vault holds the rulebook. This repository does not. The backup-before-write discipline is unchanged.

&nbsp;

## What's New at a Glance

- **The README passes the reference check again.** One `allow-ref` entry covers both mentions. Its reason names the vault as the file's home.
- **The plugin knowledge layer is unchanged.** The Iconic rules still merge into the rulebook. A backup is taken before every write.
- **The README edition is raised.** The body changed. So its own edition moves with it.
