# v0.24.7.0, Docs Read in Order and Render as Written

The mode's `SKILL.md`, `ROUTER.md`, `README.md`, references and assets were read file by file. It covered readability, layout and structure. No tool, rule or source citation changed.

&nbsp;

## What's New at a Glance

- **The official CLI failures share one section.** Troubleshooting section 5 is now Official CLI Issues. It holds three subsections. The CLI is not registered. The app is not running. An error still exits zero. So sections 6 to 12 keep their numbers.
- **The agent invariants come first.** In the CLI commands reference they are section 4. They sit ahead of the commands they govern. So the command sections move to 5 to 11.
- **Overviews open with their purpose.** The plugin and theme references gain Purpose and When to Use subsections. The plugin development scope note is its Boundaries. The Health MD chart examples number their sections.
- **Packed paragraphs became lists.** The MCP tools header lines read one fact per line. So do the when-to-prefer rules for the official CLI. So do the other dense passages.

&nbsp;

The links to `references/troubleshooting.md#5b-official-cli-registered-but-the-app-is-not-running` and `#5c-official-cli-returns-an-error-but-exits-0` move to `#5-official-cli-issues`.
