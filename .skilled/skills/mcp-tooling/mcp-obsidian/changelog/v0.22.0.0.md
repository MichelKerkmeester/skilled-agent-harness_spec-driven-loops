# v0.22.0.0, Make.md Replaces Beancount Finance

This release replaces Beancount Finance with Make.md as a first-class documented file-layer plugin. The new documentation covers Make.md's Spaces and Contexts model, including the limitation on reproducing configured table views.

## Why This Release

The vault retired double-entry from its finance workflow. Beancount Finance's `isDesktopOnly` shell-out also made it mobile-incapable.

## What's New at a Glance

- **Beancount Finance is removed entirely.** Its four-file reference tree, feature-catalog entry, example, two assets and manual-testing tie-in are removed. `PLUGIN_FINANCE` is removed from `SKILL.md`. Beancount references are removed from `README.md`, `INSTALL-GUIDE.md`, `feature-catalog/FEATURE-CATALOG.md`, `installed-plugins.md`, `plugin-operation-logic.md`, `examples/README.md`, `assets/workflows.md` and the manual-testing playbook.
- **Make.md gains a four-file reference tree and feature-catalog entry.** `references/plugins/make-md/` and `feature-catalog/plugins/make-md.md` follow the Notion Bases documentation pattern and cover the `Make-md/makemd` plugin (id `make-md`, v1.3.5+).
- **Make.md's Spaces, Contexts and views are documented.** Spaces are folders that auto-register without a vault registry, and Contexts are databases. The documentation covers the full Notion-grade formula library, table, board, gallery, calendar, list, frames and charts views, plus the `number`, `text`, `boolean`, `date`, `option`, `option-multi`, `link`, `file`, `fileprop` and `aggregate` field types.
- **The `.space` on-disk format is documented.** It pairs `def.json` with `context.mdb` and `views.mdb`, which use SQLite over `m_schema` and `m_fields`.
- **A configured table view requires a UI-created Space to clone.** Its filter, sort, footer-summary predicate JSON and context schema id cannot be reproduced from scratch. Columns are hidden until added, so a raw folder does not auto-show all frontmatter columns.
- **The plugin roster adds Make.md and removes Beancount Finance.** `references/plugins/installed-plugins.md` keeps the file-layer-versus-UI split and its counts consistent. The net plugin-document count is unchanged, with one Beancount document removed and one Make.md document added.
- **Make.md's router intent is added to `SKILL.md`.** The additive `PLUGIN_MAKEMD` intent mirrors the per-plugin pattern. `SKILL.md` advances from `0.21.0.0` to `0.22.0.0`.
- **Make.md has file-layer support.** It is installed from the Obsidian Community store (v1.3.5) when the Notion-like Spaces UI is wanted.

## Upgrade

No migration required.
