# mcp-obsidian v0.22.0.0

Swaps Beancount out for Make.md in the skill's file-layer plugin coverage. Beancount Finance is removed entirely; Make.md is added as a first-class documented plugin using the same 4-file reference pattern as Notion Bases, covering its Notion-like Spaces/Contexts model, the `.space` SQLite on-disk format, and the honest limitation that a configured table view cannot be generated from scratch (a UI-created golden sample must be cloned).

---

## 1. REMOVED

- **Beancount Finance removed.** Deleted `references/plugins/beancount-finance/` (4 files), `feature-catalog/plugins/beancount-finance.md`, `examples/beancount-transaction.sh`, `assets/plugins/beancount-finance/` (2 files), and `manual-testing-playbook/plugin-tie-ins/beancount-transaction.md`. Stripped `PLUGIN_FINANCE` from `SKILL.md` (§2 loading map, `INTENT_SIGNALS`, `RESOURCE_MAP`, the `PLUGINS` aggregate, the `specific_plugin_intents` tuple, the headline plugin list, the keyword comment, the activation triggers, and the §8 reference inventory), and removed the Beancount references in `README.md`, `INSTALL-GUIDE.md`, `feature-catalog/FEATURE-CATALOG.md`, `installed-plugins.md`, `plugin-operation-logic.md`, `examples/README.md`, `assets/workflows.md`, and the manual-testing playbook. Rationale: the double-entry paradigm was retired from the vault's finance workflow; its `isDesktopOnly` shell-out also made it mobile-incapable.

---

## 2. ADDED

- **New `references/plugins/make-md/` 4-file tree** (index, data-model, workflows, troubleshooting) plus `feature-catalog/plugins/make-md.md`, mirroring the Notion Bases documentation pattern. Covers Make.md (`Make-md/makemd`, id `make-md`, v1.3.5+): the **Spaces** (folders auto-register, no vault registry) + **Contexts** (databases) model; the full Notion-grade formula library and view types (table/board/gallery/calendar/list/frames/charts); field types (`number`/`text`/`boolean`/`date`/`option`/`option-multi`/`link`/`file`/`fileprop`/`aggregate`); and the `.space` on-disk format (`def.json` + `context.mdb`/`views.mdb` SQLite over `m_schema`/`m_fields`).
- **Honest limitation documented:** a fully configured table view (filter/sort/footer-summary predicate JSON + the context schema id) is not reproducible from scratch — one UI-created Space must be cloned. Columns are hidden until added, so a raw folder does not auto-show all frontmatter columns.
- **`SKILL.md`: new `PLUGIN_MAKEMD` router intent**, additive, mirroring the per-plugin pattern — the §2 loading map, `INTENT_SIGNALS`, `RESOURCE_MAP`, the `PLUGINS` aggregate, the `specific_plugin_intents` tuple, the headline plugin list, the keyword comment, the activation triggers, and the §8 reference inventory. Net plugin-doc count is unchanged (−1 Beancount, +1 Make.md).

---

## 3. ROSTER SYNC

`references/plugins/installed-plugins.md` reconciled: the Beancount Finance row is removed and a Make.md file-layer row is added, keeping the file-layer-vs-UI split and its counts consistent. Make.md is documented as file-layer-supported; it is installed from the Obsidian Community store (v1.3.5) when the Notion-like Spaces UI is wanted.
