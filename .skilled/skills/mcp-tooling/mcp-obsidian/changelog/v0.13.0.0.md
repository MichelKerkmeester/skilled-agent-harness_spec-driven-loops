# mcp-obsidian v0.13.0.0, Consistent Plugin Coverage

A deep review by `cli-codex gpt-5.6-luna` in `max`/`fast` surfaced one structural gap and several enumeration inconsistencies. This release closes those issues across mcp-obsidian's router, shared contract and playbook.

## What's New at a Glance

- **The `SKILL.md` router now treats `health-md` as a first-class plugin intent.** `PLUGIN_HEALTH` is included in `INTENT_SIGNALS`, `RESOURCE_MAP` and the specific-plugin disambiguation tuple, so health queries load only health-md references. This brings the router from ten wired plugins to eleven.
- **Generic `PLUGINS` requests now sample all eleven plugin indexes.** The fallback expanded from four indexes (beancount, tables, BRAT and iconic) to eleven, so generic plugin requests no longer omit the seven newer artifacts.
- **The plugin overview now lists every per-plugin reference.** `references/plugins/plugin-operation-logic.md` lists eleven, up from five, matching the §3 data map, which already listed all eleven.
- **The playbook indexes all eleven plugin tie-in scenarios.** Section 12 of `manual-testing-playbook/manual-testing-playbook.md` now lists `OBS-011..OBS-021`, up from three. Its frontmatter description and opening prose say eleven instead of "three" and a five-plugin list.
- **The beancount scenario documents its isolation boundary and teardown.** `manual-testing-playbook/plugin-tie-ins/beancount-transaction.md` states the throwaway-scratch-ledger isolation boundary and teardown for `OBS-011`, matching sibling scenarios.
- **The Git data model names its credential fields.** `references/plugins/git/data-model.md` grounds `username`, `password`, `hostname`, `gitPath` and `git-show-password` in the installed `main.js`. The runtime key prefix stays `VERIFY`.
- **The release fixes wiring and enumeration rather than adding plugin materials.** No plugin reference set, asset or feature-catalog card was added or removed. The review confirmed all eleven plugins were already covered across references, assets, feature-catalog cards and playbook scenarios.
- **`VERIFY` markers preserve honest uncertainty.** Markers on app-only, per-vault and source-inspection details were intentionally retained, not resolved by fabrication.
- **CLI and MCP surface behavior did not change.** No vault, plugin or runtime data was touched.
- **`README.md` stays at version `0.12.0.0`.** It was untouched this cycle and already enumerated eleven plugins.
