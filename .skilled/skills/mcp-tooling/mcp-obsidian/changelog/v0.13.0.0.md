# mcp-obsidian v0.13.0.0

Remediation from a deep-review of plugin coverage (cli-codex gpt-5.6-luna, `max`/`fast`). The review confirmed all eleven plugins are covered across references, assets, feature-catalog cards, and playbook scenarios, and surfaced one structural gap plus several enumeration inconsistencies. This release closes them; every fix was re-verified against the real files.

## 1. CHANGED

- **`SKILL.md` router — health-md is now a first-class plugin intent.** Added `PLUGIN_HEALTH` to `INTENT_SIGNALS`, `RESOURCE_MAP`, and the specific-plugin disambiguation tuple, so a health query loads only the health-md reference set. The router now wires **eleven of eleven** plugins (was ten).
- **`SKILL.md` generic `PLUGINS` fallback now samples all eleven** plugin indexes (was four: beancount, tables, BRAT, iconic), so a generic plugin request no longer omits the seven newer artifacts.
- **`references/plugins/plugin-operation-logic.md`** — the overview enumeration lists all eleven per-plugin references (was five); the §3 data map already carried all eleven.
- **`manual-testing-playbook/manual-testing-playbook.md`** — §12 now indexes all eleven tie-in scenarios (`OBS-011..OBS-021`, was three); the frontmatter description and opening prose say eleven (were "three" / a five-plugin list).
- **`manual-testing-playbook/plugin-tie-ins/beancount-transaction.md`** — OBS-011 now states the throwaway-scratch-ledger isolation boundary and teardown, matching the sibling scenarios.
- **`references/plugins/git/data-model.md`** — grounded the credential field names (`username`, `password`, `hostname`, `gitPath`, `git-show-password`) from the installed `main.js`; the runtime key prefix stays `VERIFY`.

---

## 2. NOT CHANGED

- No plugin reference set, asset, or feature-catalog card was added or removed — all eleven were already present; this release fixes wiring and enumeration only.
- The `VERIFY` markers on app-only / per-vault / source-inspection details are intentionally retained as honest-uncertainty markers, not resolved by fabrication.
- No CLI or MCP surface behavior changed. `README.md` stays at `0.12.0.0` (untouched this cycle; it already enumerated eleven plugins).
- No vault, plugin, or runtime data was touched.
