This release resets the whole package onto a pre-1.0 `0.x` track. So the numbers tell the truth. That is because the mode is still maturing.

&nbsp;

## What's New at a Glance

- The package's historical releases move to the `0.x` track.
  - Every package `version` field and changelog filename moved from the old `1.x` track to `0.x`.
  - The releases moved in order, one flat step per release.
  - The first release became `v0.1.0.0`.
  - The last became `v0.11.0.0`.
  - The two off-track per-file versions moved with their base release.
  - The mode was authored on a `1.x` track.
  - But a `1.0` release is a readiness declaration that was never made.
- External tool versions were left untouched.
  - The untouched tools are the Local REST API, `obsidian-mcp-server`, `notesmd-cli`, Health.md and Minimal.
- `SKILL.md` and `README.md` agree on `0.12.0.0` again.
  - The two release heads had drifted apart.
  - `SKILL.md` was `0.10.0.0` and `README.md` was `0.11.0.0`.
  - Both move to `0.12.0.0`.
- The release changes numbering only.
  - No new CLI, MCP, plugin or theme surface was added.
  - Skill behavior is unchanged from the prior head.
- Reference sets, feature-catalog cards, playbook scenarios, assets and scripts changed only in version tokens.
  - No vault, plugin or runtime data was touched.
- Earlier changelog wording is retained.
  - Renumbered entries `v0.1.0.0` through `v0.11.0.0` keep their original wording.
  - Only the entries' own version tokens were rewritten to the new track.
