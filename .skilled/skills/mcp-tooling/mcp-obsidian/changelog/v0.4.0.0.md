This release extends the mcp-obsidian mode's plugin knowledge with Health.md Visualizations, using the existing per-plugin reference pattern of an index, data model, workflows and troubleshooting.

## What's New at a Glance

- **`references/plugins/health-md/` is the new Health.md Visualizations (`health-md`) reference set.** It covers Apple Health export data files (JSON/CSV/Markdown/Bases) in the vault data folder (default `Health/`), schema v0–v7, roll-ups under `Health/Rollups/`, `_healthmd_data_dictionary.json`, render-block placement and the hard rule to never fabricate health data. Health.md Visualizations was installed and enabled in all three vaults (packet Phase 11).
- **`SKILL.md` gains activation triggers for health requests.** It moves from version 0.3.0.0 to 0.4.0.0 in its frontmatter and keywords, adds the reference set to load-on-demand and extends the keyword comment. The data map in `plugin-operation-logic.md` grows from 3 to 4 rows.
- **The health-md catalog and playbook entries are added.** The feature card `feature-catalog/plugins/health-md.md` and scenario `OBS-014` (Health.md data-file round-trip) are added, and indexes are updated. The plugin category in `feature-catalog/FEATURE-CATALOG.md` changes from 3 to 4 plugins. `manual-testing-playbook/manual-testing-playbook.md` changes from 19 to 20 scenarios (`OBS-011`..`OBS-014`).
- **An example export file is included.** `assets/plugins/health-md/healthmd-export.example.json` is an example data file, and no plugin code is vendored.
- **The three existing plugin reference sets are unchanged.** The only exception is the shared data-map table.

## Upgrade

No migration required.
