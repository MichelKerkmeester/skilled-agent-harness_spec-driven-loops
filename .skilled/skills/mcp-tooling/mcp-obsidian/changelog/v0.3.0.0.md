# mcp-obsidian v0.3.0.0: Search and MCP Documentation

This documentation-only release corrects mcp-obsidian's title-search guidance and documents a second MCP server, so readers can use the reliable search surface and distinguish the tool namespaces.

## What's New at a Glance

- **Name lookups have a working alternative.** In v0.3.6, `notesmd-cli search` returns "Cannot find note in vault" even for on-disk notes. `SKILL.md` and `references/obsidian-cli-commands.md` now direct name lookups to `notesmd-cli list` plus filtering. For body searches, they point to `search-content`, the reliable body-search surface.
- **The Local REST API plugin has its own MCP server.** `obsidian-local-rest-api` v5.1.0+ ships a built-in MCP at `https://127.0.0.1:27124/mcp/` with 16 `vault_*` tools. It is distinct from the cyanheads `obsidian-mcp-server` `obsidian_*` surface this catalog documents. `SKILL.md` and `references/mcp-tools.md` now warn readers not to conflate the namespaces.
