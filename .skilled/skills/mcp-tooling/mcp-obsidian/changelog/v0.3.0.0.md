# mcp-obsidian v0.3.0.0: Search and MCP Documentation

This release only changes documentation. It corrects mcp-obsidian's title-search guidance. It also documents a second MCP server. So readers can use the reliable search surface and tell the tool namespaces apart.

## What's New at a Glance

- **Name lookups have a working alternative.** In v0.3.6, `notesmd-cli search` returns "Cannot find note in vault". It does this even for on-disk notes. `SKILL.md` and `references/obsidian-cli-commands.md` now send name lookups to `notesmd-cli list` plus filtering. For body searches, they point to `search-content`. That is the reliable body-search surface.
- **The Local REST API plugin has its own MCP server.** `obsidian-local-rest-api` v5.1.0+ ships a built-in MCP at `https://127.0.0.1:27124/mcp/`. It has 16 `vault_*` tools. It is distinct from the cyanheads `obsidian-mcp-server` `obsidian_*` surface. That surface is the one this catalog documents. `SKILL.md` and `references/mcp-tools.md` now warn readers not to conflate the namespaces.
