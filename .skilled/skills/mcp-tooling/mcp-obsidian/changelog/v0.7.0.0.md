Version 0.7.0.0 adds a template-conformant Markdown companion for the canonical Iconic rulebook payload, giving agents a routable usage guide. No rule, vault, phase or hub files were touched, and no Markdown outside the scoped set was modified.

## What's New at a Glance

- **`assets/plugins/iconic/iconic-rules.full.md` follows the sk-create-skill asset structure.** Its full five-field frontmatter contains a title, one-line description, six lowercase multi-word `trigger_phrases`, `importance_tier: normal`, `contextType: implementation` and `version: 0.7.0.0`. It includes a one-sentence intro, `OVERVIEW` with Purpose and Usage, a numbered payload section naming the sibling JSON as the exact source for all 21 `fileRules` and 11 `folderRules`, concise coverage tables matching 21 file rules by extension and 11 folder rules by name without duplicating rule objects, the five-step merge contract and a closing `RELATED RESOURCES` section linking the Iconic index, data model, workflows and the compact `iconic-rules.example.json` schema sample.
- **Iconic reference navigation adds the companion.** The rulebook-asset table gains a usage-companion row and clarifies the JSON's copy/merge role, and canonical-asset bullets add the `.md` while identifying the JSON as exact source.
- **The apply-rulebook recipe points to the companion.** The companion provides coverage and merge-contract details for the recipe, while the feature-card asset list adds it and the feature card and `SKILL.md` router state the `.md` as usage guide and the `.json` as exact copy/merge payload.
- **`SKILL.md`, the three Iconic references and the feature card move from `0.6.0.0` to `0.7.0.0`.** The `SKILL.md` frontmatter keyword comment adds `iconic-rules.full.md`.
- **The two JSON assets retain distinct roles.** `iconic-rules.full.json` was untouched, byte-valid and the only authoritative full rule content, with 21 file and 11 folder rules. `iconic-rules.example.json` was untouched as the compact schema sample.
