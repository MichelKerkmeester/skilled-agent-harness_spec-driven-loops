Version 0.7.0.0 adds a template-conformant Markdown companion for the canonical Iconic rulebook payload. It gives agents a routable usage guide. No rule, vault, phase or hub files were touched. No Markdown outside the scoped set was modified.

&nbsp;

## What's New at a Glance

- `assets/plugins/iconic/iconic-rules.full.md` follows the sk-create-skill asset structure.
  - Its full five-field frontmatter holds a title and a one-line description.
  - It also holds six lowercase multi-word `trigger_phrases`.
  - It also holds `importance_tier: normal`, `contextType: implementation` and `version: 0.7.0.0`.
  - The file opens with a one-sentence intro.
  - `OVERVIEW` covers Purpose and Usage.
  - A numbered payload section names the sibling JSON as the exact source.
  - That source holds all 21 `fileRules` and 11 `folderRules`.
  - Concise coverage tables match 21 file rules by extension and 11 folder rules by name.
  - They do not duplicate rule objects.
  - The five-step merge contract follows.
  - A closing `RELATED RESOURCES` section links the Iconic index, data model and workflows.
  - It also links the compact `iconic-rules.example.json` schema sample.
- Iconic reference navigation adds the companion.
  - The rulebook-asset table gains a usage-companion row.
  - It clarifies the JSON's copy/merge role.
  - Canonical-asset bullets add the `.md`.
  - They identify the JSON as exact source.
- The apply-rulebook recipe points to the companion.
  - The companion gives the recipe its coverage and merge-contract details.
  - The feature-card asset list adds it.
  - The feature card and `SKILL.md` router state the `.md` as usage guide.
  - They state the `.json` as exact copy/merge payload.
- `SKILL.md`, the three Iconic references and the feature card move from `0.6.0.0` to `0.7.0.0`.
  - The `SKILL.md` frontmatter keyword comment adds `iconic-rules.full.md`.
- The two JSON assets retain distinct roles.
  - `iconic-rules.full.json` was untouched and byte-valid.
  - It is the only authoritative full rule content, with 21 file and 11 folder rules.
  - `iconic-rules.example.json` was untouched as the compact schema sample.
