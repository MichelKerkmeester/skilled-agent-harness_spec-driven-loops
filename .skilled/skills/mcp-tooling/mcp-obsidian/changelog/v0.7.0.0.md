# mcp-obsidian — v0.7.0.0

Adds a template-conformant Markdown companion for the canonical Iconic rulebook payload. `assets/plugins/iconic/iconic-rules.full.md` now carries the sk-create-skill asset structure — full frontmatter, rule-class coverage, and the merge contract — so agents get a routable usage guide while `iconic-rules.full.json` remains the byte-valid, only authoritative full rule content. Every Iconic navigation surface (references, feature card, SKILL.md router) states the pairing explicitly: the `.md` is the usage guide, the `.json` is the exact copy/merge payload.

## 1. NEW

- **`assets/plugins/iconic/iconic-rules.full.md`** — template-conformant usage companion built from the sk-create-skill asset template: full 5-field frontmatter (title, one-line description, 6 lowercase multi-word `trigger_phrases`, `importance_tier: normal`, `contextType: implementation`, `version: 0.7.0.0`), a 1-sentence intro, `OVERVIEW` (Purpose/Usage), a numbered payload section naming the sibling JSON as exact source (all 21 `fileRules` + 11 `folderRules`), concise rule-class coverage tables (21 extension-matched file rules, 11 name-matched folder rules — no rule objects duplicated), the five-step merge contract, and a closing RELATED RESOURCES section linking the Iconic index/data model/workflows plus the compact `iconic-rules.example.json` schema sample.
