# mcp-obsidian v0.21.0.0

Consolidates the vault's plugin stack toward Notion parity on Notion Bases. Excalidraw and Project Manager are removed from the skill (both uninstalled from the vault); Meta Bind (+ JS Engine) gains a reference for the Notion-style start/stop task timer; Notion Bases gains a Calendar-view recipe for an inline, no-external-sync calendar built from notes/tasks; and the roster is reconciled to the 24-plugin vault.

---

## 1. REMOVED

- **Excalidraw deprecated and removed.** Deleted `references/plugins/excalidraw/` (4 files), `feature-catalog/plugins/excalidraw.md`, `assets/plugins/excalidraw/` (2 files), and `manual-testing-playbook/plugin-tie-ins/excalidraw-drawing-note.md`. Stripped `PLUGIN_EXCALIDRAW` from `SKILL.md` (§2 loading, `INTENT_SIGNALS`, `RESOURCE_MAP`, the `PLUGINS` aggregate, the `specific_plugin_intents` tuple, the headline plugin list, and the keyword comment), and removed the Excalidraw references in `README.md`, `feature-catalog/FEATURE-CATALOG.md`, `plugin-operation-logic.md`, and the manual-testing playbook (scenario `OBS-018`). The plugin was uninstalled from the vault the same day.
- **Project Manager deprecated and removed.** Deleted `references/plugins/project-manager/` (4 files) and `feature-catalog/plugins/project-manager.md`. Stripped `PLUGIN_PROJECT_MANAGER` from `SKILL.md` (all the same wiring points) and updated the roster's overlap note. Its task-tracking role is consolidated onto Notion Bases + Meta Bind, which made a dedicated PM plugin redundant.

---

## 2. ADDED

- **New `references/plugins/meta-bind/` 4-file tree** (index, data-model, workflows, troubleshooting) plus `feature-catalog/plugins/meta-bind.md`, documenting Meta Bind's `INPUT[]`/`VIEW[]`/`BUTTON[]` syntax and the `meta-bind-button` action catalog, centered on the **Notion-style task timer**: Start/End buttons that stamp frontmatter timestamps over a Notion Bases task database, totalled by a Bases formula column. The **JS Engine** companion (`js-engine`) is documented within this tree. The evaluated-expression grammar and the `js`-action signature are flagged `VERIFY` (grounded in the plugin docs fetched 2026-08-22, not invented).
- **`SKILL.md`: new `PLUGIN_META_BIND` router intent**, additive, mirroring the existing per-plugin pattern — §2 loading, `INTENT_SIGNALS`, `RESOURCE_MAP`, the `specific_plugin_intents` tuple, the `PLUGINS` aggregate, and §8 References. The `INTENT_SIGNALS` count comment updated `twenty-two` → `twenty-one` (−2 removals, +1 addition).
- **Notion Bases Calendar-view recipe** (`references/plugins/notion-bases/workflows.md` §6a): an inline, Notion-style month calendar built from the database's own notes/tasks via a date column, with **no external calendar sync**, plus a `calendar_view_valid` checkpoint.
