This release consolidates the vault's plugin stack toward Notion parity on Notion Bases. It removes Excalidraw and Project Manager from the skill and vault, adds a Meta Bind reference for a Notion-style start/stop task timer and adds a Notion Bases Calendar-view recipe.

## Why This Release

Project Manager's task-tracking role is consolidated onto Notion Bases + Meta Bind, making a dedicated PM plugin redundant.

---

## What's New at a Glance

- **Excalidraw is deprecated and removed.** The plugin was uninstalled from the vault the same day.
- **Project Manager is deprecated and removed.** The roster's overlap note is updated.
- **Meta Bind gains a task-timer reference.** It documents the Notion-style start/stop timer with the JS Engine companion.
- **`PLUGIN_META_BIND` is added to the router.** The `INTENT_SIGNALS` count comment changes from `twenty-two` to `twenty-one` after two removals and one addition.
- **Notion Bases gains a Calendar-view recipe.** In `references/plugins/notion-bases/workflows.md` §6a, the recipe builds an inline, Notion-style month calendar from the database's own notes and tasks via a date column, with no external calendar sync, plus a `calendar_view_valid` checkpoint.
- **The installed-plugin roster is reconciled to the 24-plugin vault.** It adds Meta Bind, JS Engine, Dragger, Bullet Depth Markers and Dynamic Outline, and removes the Excalidraw and Project Manager rows, both uninstalled.

---

## Skill Changes

#### Excalidraw Material Is Removed

The four-file `references/plugins/excalidraw/` tree, `feature-catalog/plugins/excalidraw.md`, the two-file `assets/plugins/excalidraw/` tree and `manual-testing-playbook/plugin-tie-ins/excalidraw-drawing-note.md` were deleted. `PLUGIN_EXCALIDRAW` was stripped from `SKILL.md`'s §2 loading, `INTENT_SIGNALS`, `RESOURCE_MAP`, `PLUGINS` aggregate, `specific_plugin_intents` tuple, headline plugin list and keyword comment. Excalidraw references were also removed from `README.md`, `feature-catalog/FEATURE-CATALOG.md`, `plugin-operation-logic.md` and the manual-testing playbook scenario `OBS-018`.

&nbsp;

#### Project Manager Material Is Removed

The four-file `references/plugins/project-manager/` tree and `feature-catalog/plugins/project-manager.md` were deleted. `PLUGIN_PROJECT_MANAGER` was stripped from `SKILL.md` at the same wiring points as Excalidraw.

&nbsp;

#### Meta Bind Joins the Router

The additive intent follows the existing per-plugin pattern. In `SKILL.md`, its wiring covers §2 loading, `INTENT_SIGNALS`, `RESOURCE_MAP`, the `specific_plugin_intents` tuple, the `PLUGINS` aggregate and §8 References. `SKILL.md` changes from version 0.20.0.0 to 0.21.0.0.

## Notion References

#### A Notion-Style Task Timer

The new four-file `references/plugins/meta-bind/` tree has an index, data-model, workflows and troubleshooting files, alongside `feature-catalog/plugins/meta-bind.md`. It documents `INPUT[]`/`VIEW[]`/`BUTTON[]` syntax and the `meta-bind-button` action catalog. Start/End buttons stamp frontmatter timestamps over a Notion Bases task database, totalled by a Bases formula column. The `js-engine` companion is documented within this tree. The evaluated-expression grammar and the `js`-action signature are flagged `VERIFY`, grounded in the plugin docs fetched 2026-08-22, not invented.

## Installed Plugin Roster

The roster held 21 entries before this reconciliation. Meta Bind and JS Engine are file-layer rows, with JS Engine sharing the `meta-bind/` tree. Until then, the live `community-plugins.json` shows 23 ids. `references/plugins/installed-plugins.md` changes from version 0.1.0.0 to 0.2.0.0.
