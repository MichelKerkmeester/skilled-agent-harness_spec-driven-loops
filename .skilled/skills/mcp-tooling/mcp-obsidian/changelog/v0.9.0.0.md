# v0.9.0.0, Effective AI Use Inside Obsidian

The release corrects the skill's stated purpose and rewrites the README in the repo-root narrative voice: the skill exists solely for effective AI use inside Obsidian through an agent that can read, write, search and extend the vault with proper plugin knowledge so community plugins are operated as data. The three execution surfaces are means to that purpose, not the skill's identity. A concurrent deep-loop containment sweep deleted the never-committed entry before its content was restored from the session record.
