# v0.10.0.0, Plugin and Theme Support

mcp-obsidian v0.10.0.0 adds skill support for five plugins and a theme.

- The plugins are Charts, Dataview, Excalidraw, Git and Outliner.
- Minimal is the theme added alongside them.
- The router resolves them to the right resources.

Each addition has reference material, copyable assets, a card and a scenario.

- Each addition has reference material and copyable assets.
- Each addition has a feature-catalog card.
- Each addition has a manual tie-in scenario.

The release adds plugin and theme knowledge only.

- No vault files were touched by the skill work.
- No CLI or MCP surface changed.

&nbsp;

## Why This Release

Charts, Dataview, Excalidraw, Git and Outliner were installed into every vault in the plugin-installation batch.

## Plugin and Theme Knowledge

#### Reference Sets Cover Each Addition <a id="c-reference-sets-cover-each-addition"></a>

- Directories are added under `references/plugins/`.
- They are `charts/`, `dataview/`, `excalidraw/`, `git/`, `outliner/` and `minimal/`.
- Each set has an index, a data-model, workflows and troubleshooting.
- All carry full frontmatter.
- Reference facts draw on installed bundles.
- These include manifest versions, `main.js` default settings and registered block languages.
- Details that could not be verified carry `VERIFY` markers.

#### Examples Cover Common Tasks <a id="c-examples-cover-common-tasks"></a>

- Copyable examples cover plugin and theme tasks.
- The copyable examples are under `assets/plugins/`.
- Charts has a render-block example.
- Dataview has query and metadata examples.
- Excalidraw has drawing-note and scene examples.
- Git has settings and command examples.
- Outliner has full and partial settings examples.
- Minimal has activation and CSS examples.

## Catalog and Manual Playbook

#### Cards Extend Catalog Coverage <a id="c-cards-extend-catalog-coverage"></a>

- Dataview metadata and query round-trip.
- Excalidraw drawing-note round-trip.
- Obsidian Git status round-trip.
- Outliner settings and defaults.
- Minimal theme activation.
- The tie-in range updates to `OBS-011..OBS-021`.

## Skill Guidance and Request Routing

#### Skill Maps Name the New Resources <a id="c-skill-maps-name-the-new-resources"></a>

- `SKILL.md` advances from 0.9.0.0 to 0.10.0.0.
- Its resource guidance expands with this release.
- `SKILL.md` updates its frontmatter description, keywords comment, H1 introduction and resource-map notes to name eleven artifacts instead of five.
- Its specific-plugin list grows from four to ten intents.
- `references/plugins/plugin-operation-logic.md` expands its data map from five to eleven rows.

#### Router Maps Resolve Plugin Requests <a id="c-router-maps-resolve-plugin-requests"></a>

- Six plugin-specific intents route requests to resources.
- Their identifiers distinguish requests for the added plugins and theme.
- The intents are `PLUGIN_CHARTS`, `PLUGIN_DATAVIEW`, `PLUGIN_EXCALIDRAW`, `PLUGIN_GIT`, `PLUGIN_OUTLINER` and `PLUGIN_MINIMAL`.
- They appear in `INTENT_SIGNALS`, `RESOURCE_MAP` and the specific-plugin disambiguation list.
- `mode-registry.json` and `hub-router.json` have mcp-obsidian aliases and vocabulary classes extended with the six artifacts for advisor discoverability.
