# mcp-obsidian v0.10.0.0: Plugin and Theme Support

mcp-obsidian v0.10.0.0 adds skill support for Charts, Dataview, Excalidraw, Git and Outliner alongside the Minimal theme. Each addition has reference material, copyable assets, a feature-catalog card and a manual tie-in scenario. The router resolves them to the right resources.

## Why This Release

Charts, Dataview, Excalidraw, Git and Outliner were installed into every vault in the plugin-installation batch.

## What's New at a Glance

- **Six reference sets add skill support.** They cover five community plugins and the Minimal theme.
- **Copyable examples cover plugin and theme tasks.** The examples cover blocks, queries, drawings, settings and theme activation.
- **The feature catalog gains six cards.** They group the additions in the plugin category.
- **The manual playbook gains six scenarios.** They run against throwaway vaults only.
- **`SKILL.md` advances from 0.9.0.0 to 0.10.0.0.** Its resource guidance expands with this release.
- **Six plugin-specific intents route requests to resources.** Their identifiers distinguish requests for the added plugins and theme.
- **The release adds plugin and theme knowledge only.** No vault files or CLI or MCP surfaces changed.

---

## Plugin and Theme Knowledge

#### Reference Sets Cover Each Addition

Directories are added under `references/plugins/`: `charts/`, `dataview/`, `excalidraw/`, `git/`, `outliner/` and `minimal/`. Each set has an index, a data-model, workflows and troubleshooting, all with full frontmatter.

The reference facts draw on installed bundles, including manifest versions, `main.js` default settings and registered block languages. Details that could not be verified carry `VERIFY` markers.

&nbsp;

#### Examples Cover Common Tasks

The copyable examples are under `assets/plugins/`. Charts has a render-block example. Dataview has query and metadata examples. Excalidraw has drawing-note and scene examples. Git has settings and command examples. Outliner has full and partial settings examples. Minimal has activation and CSS examples.

---

## Catalog and Manual Playbook

#### Cards Extend Catalog Coverage

The plugin cards cover Charts, Dataview, Excalidraw, Git, Outliner and Minimal under `feature-catalog/plugins/`. The plugin category prose and card sections changed in `feature-catalog/feature-catalog.md`. The root count moves from 25 to 31 entries. The Plugin Knowledge Layer table and FAQ in `README.md` now cover all eleven artifacts.

&nbsp;

#### Scenarios Tie Support to Practice

`manual-testing-playbook/manual-testing-playbook.md` adds these scenarios, which run against throwaway vaults only:

- **OBS-016:** Charts render-block round-trip.
- **OBS-017:** Dataview metadata and query round-trip.
- **OBS-018:** Excalidraw drawing-note round-trip.
- **OBS-019:** Obsidian Git status round-trip.
- **OBS-020:** Outliner settings and defaults.
- **OBS-021:** Minimal theme activation.

The tie-in range updates to `OBS-011..OBS-021`.

## Skill Guidance and Request Routing

#### Skill Maps Name the New Resources

`SKILL.md` updates its frontmatter description, keywords comment, H1 introduction and resource-map notes to name eleven artifacts instead of five. Its specific-plugin list grows from four to ten intents. `references/plugins/plugin-operation-logic.md` expands its data map from five to eleven rows.

&nbsp;

#### Router Maps Resolve Plugin Requests

The intents are `PLUGIN_CHARTS`, `PLUGIN_DATAVIEW`, `PLUGIN_EXCALIDRAW`, `PLUGIN_GIT`, `PLUGIN_OUTLINER` and `PLUGIN_MINIMAL`. They appear in `INTENT_SIGNALS`, `RESOURCE_MAP` and the specific-plugin disambiguation list. `mode-registry.json` and `hub-router.json` have mcp-obsidian aliases and vocabulary classes extended with the six artifacts for advisor discoverability.
