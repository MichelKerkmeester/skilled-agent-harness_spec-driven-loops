This release closes the deeper findings from the plugin-coverage deep-review. These go beyond structural coverage. It adds two safety fixes and a loopback-only TLS caveat. The human loading index is complete. The CLI and MCP surfaces are otherwise unchanged. No plugin reference set, asset, feature-catalog card or playbook scenario was added or removed. No vault, plugin or runtime data was touched. The intentional `VERIFY` markers stay as honest-uncertainty markers. They cover app-only, per-vault and source-inspection details.

## What's New at a Glance

- **The BRAT install rejects unsafe plugin IDs.** Two files now validate `PLUGIN_ID` against `^[A-Za-z0-9._-]+$`. They are `references/plugins/obsidian42-brat/workflows.md` and `manual-testing-playbook/plugin-tie-ins/brat-headless-install.md`. The check runs before the value goes into the vault plugin path. Earlier they checked only for a non-empty or not-`null` value. A hostile release manifest can no longer escape `.obsidian/plugins/`. That holds when `.id` supplies `../` or `/`. So it can no longer write elsewhere in the vault.
- **The round-trip example fails safe on non-404 errors.** `examples/mcp-roundtrip.sh` no longer treats every `obsidian_get_note` error as "note absent". Auth, transport or server errors re-throw. They no longer fall through to an empty-content write. So a transient read failure can no longer overwrite a real note. The exact error shape stays `VERIFY`. Confirm it with `tool_info()`.
- **Disabled certificate verification is safe only on loopback.** `references/mcp-tools.md` and `examples/mcp-roundtrip.sh` now state this. Disabling cert verification (`OBSIDIAN_VERIFY_SSL=false` / `curl -k`) is safe only because the endpoint is loopback (`127.0.0.1`). The bearer token must never go to a non-loopback host with verification off.
- **The human loading index lists all eleven plugin reference sets.** In `SKILL.md`, the version advances from `0.13.0.0` to `0.14.0.0`. `README.md` stays at `0.12.0.0`. The human-readable resource-loading display adds Charts, Dataview, Excalidraw, Obsidian Git, Outliner and Minimal. It matches the executable router, which already resolved all eleven.
