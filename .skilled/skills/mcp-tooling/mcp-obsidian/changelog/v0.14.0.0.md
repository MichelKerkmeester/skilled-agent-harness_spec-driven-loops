This release closes the deeper findings from the plugin-coverage deep-review beyond structural coverage, adding two safety fixes, a loopback-only TLS caveat and a completed human loading index. The CLI and MCP surfaces are otherwise unchanged, with no plugin reference set, asset, feature-catalog card or playbook scenario added or removed and no vault, plugin or runtime data touched. The intentional `VERIFY` markers on app-only, per-vault and source-inspection details stay as honest-uncertainty markers.

## What's New at a Glance

- **The BRAT install rejects unsafe plugin IDs.** `references/plugins/obsidian42-brat/workflows.md` and `manual-testing-playbook/plugin-tie-ins/brat-headless-install.md` now validate `PLUGIN_ID` against `^[A-Za-z0-9._-]+$` before it is interpolated into the vault plugin path, where previously they checked only for a non-empty or not-`null` value. A hostile release manifest supplying `../` or `/` in `.id` can no longer escape `.obsidian/plugins/` and write elsewhere in the vault.
- **The round-trip example fails safe on non-404 errors.** `examples/mcp-roundtrip.sh` no longer treats every `obsidian_get_note` error as "note absent": auth, transport or server errors re-throw instead of falling through to an empty-content write, so a transient read failure can no longer overwrite a real note. The exact error shape stays `VERIFY` (confirm with `tool_info()`).
- **Disabled certificate verification is safe only on loopback.** `references/mcp-tools.md` and `examples/mcp-roundtrip.sh` now state that disabling cert verification (`OBSIDIAN_VERIFY_SSL=false` / `curl -k`) is safe only because the endpoint is loopback (`127.0.0.1`). The bearer token must never be sent to a non-loopback host with verification off.
- **The human loading index lists all eleven plugin reference sets.** In `SKILL.md`, the version advances from `0.13.0.0` to `0.14.0.0`, while `README.md` stays at `0.12.0.0`. The human-readable resource-loading display adds Charts, Dataview, Excalidraw, Obsidian Git, Outliner and Minimal, matching the executable router that already resolved all eleven.
