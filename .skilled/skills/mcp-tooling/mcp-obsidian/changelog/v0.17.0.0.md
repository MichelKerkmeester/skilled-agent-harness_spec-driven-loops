# v0.17.0.0, Plugin Catalog Dividers

Eleven plugin feature-catalog leaves were the only catalog files in the skill missing dividers between numbered sections. Adding the dividers brings their layout in line with the sibling `cli/` and `mcp/` leaves and the repo-wide catalog convention. The release makes no content edits and changes no vault or runtime data, while the already-dividered `feature-catalog.md` index and already-conformant `cli/` and `mcp/` leaves were untouched.

## Why This Release

The gap was missed because `validate_document.py` classifies these leaves as the `feature_catalog` doc type, whose rules do not require section dividers (`requiredSections: []`, no divider rule). So the leaves validated with 0 issues despite the gap, and the earlier reference/asset conformance pass did not cover `feature-catalog/`.

## What's New at a Glance

- **Plugin catalog leaves now have numbered-section dividers.** Each of the 11 `feature-catalog/plugins/*.md` files gained three `---` dividers, 33 total, before every numbered H2 after `## 1.`. This matches the divider layout of the sibling `cli/` (14) and `mcp/` (6) leaves and the repo-wide catalog convention, with no divider after the intro or between `###` H3s.
- **The skill version advances.** `SKILL.md` moves from 0.16.0.0 to 0.17.0.0.

No migration required.
