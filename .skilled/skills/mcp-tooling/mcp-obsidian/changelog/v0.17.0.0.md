# mcp-obsidian v0.17.0.0

The eleven plugin feature-catalog leaves were the only catalog files in the skill without `---` dividers between their numbered sections. This adds them.

---

## 1. CHANGED

- **`feature-catalog/plugins/*.md` (11 files)** — inserted a `---` divider before every numbered H2 after `## 1.` (three per file, 33 total). The leaves now match the divider layout of the sibling `cli/` (14) and `mcp/` (6) catalog leaves and the repo-wide catalog convention: a rule between each numbered section, none after the intro, none between `###` H3s.
- `SKILL.md` version 0.16.0.0 → 0.17.0.0.

---

## 2. WHY IT WAS MISSED

- `validate_document.py` classifies these as the `feature_catalog` doc type, whose rules do not require section dividers (`requiredSections: []`, no divider rule). So the leaves validated with 0 issues despite the gap, and the earlier reference/asset conformance pass did not cover `feature-catalog/`.

---

## 3. VERIFICATION

- Deterministic, idempotent, code-fence-aware insertion; a re-run adds 0 dividers.
- Every touched leaf now has 3 body dividers (matching the `cli/`/`mcp/` siblings) and still passes `validate_document.py` (0 issues).
- The diff is exclusively `---` + blank-line insertions — no catalog content, table, or code was altered.

---

## 4. NOT CHANGED

- No content edits, no vault or runtime data. The `feature-catalog.md` index (already dividered) and the `cli/`/`mcp/` leaves (already conformant) were untouched.
