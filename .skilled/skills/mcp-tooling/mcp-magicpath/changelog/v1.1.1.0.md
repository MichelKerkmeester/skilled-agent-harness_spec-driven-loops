# v1.1.1.0, Template-Name Comment Removed from the Feature Catalog

v1.1.1.0 removes the `sk-doc-template` comment that sat under the heading of 20 feature catalog files. The comment named the template a file was scaffolded from, but no validator, router or script ever read it, and the catalog template no longer adds it.

## What's New at a Glance

- **Each catalog file now goes straight from its title to its overview.** The heading, sections and links are otherwise unchanged.
- **Catalog validation reports the same results as before.** Removing the comment changed no check outcome.
