# v1.2.22.0, A Lost Repeated Line Fails the Saved-Page Check

A page that lost one of two identical lines passed as saved. The check asked whether each sent line existed on the page, not how many times.

&nbsp;

## What's New at a Glance

- **Lines are counted.** The page writer and both gap-pass programs compare the saved page with the sent markdown line for line, with counts. A line sent twice must come back twice, or it shows in the import diff.
- **The browser boundary is stated.** Aside owns signed-in ClickUp work by default and the user's live Chrome is the fallback. Only the gap pass has a Chrome program.
- **The discovery exemption is written down.** The page programs call tools by the names the reference records, so they skip Code Mode's discovery step. A tool-not-found answer is the cue to run `tool_info()`.

&nbsp;

## Upgrade

No migration required. A page that passed before and holds a repeated line may now report an import diff, which is the defect the old check missed.
