To align the mcp-tooling hub's mode README set with the mcp-obsidian pilot standard, v1.1.0.0 rewrites the `mcp-click-up` README using the refined template from the skill-readme-refinement packet. Routing behavior, the command surface and the install path do not change. The rewrite carries forward every factual claim from the previous README and touches no `SKILL.md`, reference, script, feature catalog, manual testing playbook, template or vault file.

## What's New at a Glance

- **The README now uses a purpose-first layout.** It places a one-line pitch blockquote after the H1, puts the AT A GLANCE table first and opens the OVERVIEW with the reader's situation before any feature list. The ClickUp Operation Layer capability table covers task statuses, time tracking, documents/goals/OKRs and offline task reads.
- **The INSTALL-GUIDE links now point to the packet-root file.** RELATED DOCUMENTS and FAQ use `INSTALL-GUIDE.md`, which exists, instead of the unresolved `references/INSTALL-GUIDE.md` target.
- **RELATED DOCUMENTS adds two links.** `feature-catalog/FEATURE-CATALOG.md` and `manual-testing-playbook/manual-testing-playbook.md` both exist on disk.
- **The `README.md` frontmatter version is `1.1.0.0`.** It changed from `1.0.0.7`.
- **The README follows the Human Voice Rules.** The whole file, including table cells and code blocks, has no em dashes, semicolons, Oxford commas or banned words.
- **The `cupt` health verification command now uses `python3 -m json.tool`.** It replaces a semicolon-based Python one-liner.
