# v1.2.10.0, Doc Page Dividers Without the Extra Gap

The hosted ClickUp server creates or rewrites a page. That page shows an empty line under every divider. The mode now says why. It says how to see it and how to remove it. That comes from a 65-page split run on 2026-11-05.

&nbsp;

## What's New at a Glance

- The gap has a name and a check.
  - `references/mcp-tools.md` section 8 explains that every divider spelling gets the empty line.
  - That section also says only the `"text/plain"` read-back shows it.
- The fix runs in the editor.
  - The same section gives the Delete-key fix.
  - The same section also gives a four-step `mcp-chrome-devtools` pass.
  - That pass keeps each page's markdown byte-equal to its baseline.
- The contract warns first.
  - `SKILL.md` section 0 adds a doc page divider line.
  - `references/troubleshooting.md` adds the symptom with a pointer to the fix.
- The example IDs match the server.
  - The section 8 example reads `document_id` and `page_id` instead of `id`.
  - `document_id` and `page_id` are the fields the server returns.
- No delete tool.
  - Section 4 records that no tool deletes a document or a page.
