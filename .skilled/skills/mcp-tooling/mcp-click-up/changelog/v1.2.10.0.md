# v1.2.10.0, Doc Page Dividers Without the Extra Gap

A page the hosted ClickUp server creates or rewrites shows an empty line under every divider. The mode now says why, how to see it and how to remove it, from a 65-page split run on 2026-11-05.

> Spec folder: `specs/mcp-tooling/026-clickup-doc-divider-spacing`

&nbsp;

## What's New at a Glance

- **The gap has a name and a check.** `references/mcp-tools.md` section 8 explains that every divider spelling gets the empty line, and that only the `"text/plain"` read-back shows it.
- **The fix runs in the editor.** The same section gives the Delete-key fix and a four-step `mcp-chrome-devtools` pass that keeps each page's markdown byte-equal to its baseline.
- **The contract warns first.** `SKILL.md` section 0 adds a doc page divider line, and `references/troubleshooting.md` adds the symptom with a pointer to the fix.
- **The example IDs match the server.** The section 8 example reads `document_id` and `page_id`, the fields the server returns, instead of `id`.
- **No delete tool.** Section 4 records that no tool deletes a document or a page.
