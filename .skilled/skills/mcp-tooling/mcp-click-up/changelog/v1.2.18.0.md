# v1.2.18.0, Side-by-Side Screenshots in ClickUp Columns

Design feedback compares the built screen with its Figma frame. ClickUp shows that best in a columns block. No MCP call could write one.

> Spec folder: `AI Systems/Product Owner/specs/system/024-clickup-side-by-side-columns`

&nbsp;

## What's New at a Glance

- **Columns are built in the editor.** A page write leaves a `[[COLS-n]]` line. The new routine in `references/mcp-tools.md` section 8 pastes a columns row over it. The row survives a reload.
- **Local screenshots upload themselves.** A PNG pasted as a file lands in its column as a ClickUp attachment. A hosted URL works too.
- **The check reads the editor.** The markdown read-back flattens columns. So the routine reloads the page and counts each row's images.
- **A page with columns is never replaced.** A `replace` built from the read-back would delete the columns. `SKILL.md` section 1 says so.
