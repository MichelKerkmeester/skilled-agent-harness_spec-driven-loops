# v1.2.20.0, Safer Page Writer Uploads and Stricter Checks

A review of the browser-first page writer found gaps. Uploads could read any file. The check also missed a lost divider.

> Spec folder: `AI Systems/Product Owner/specs/system/029-review-remediation`

&nbsp;

## What's New at a Glance

- **Uploads read only image files.** A local image must be a bare png, jpg, gif or webp name. A path is refused and reported.
- **The upload type follows the file.** A jpg or webp is no longer sent as a png.
- **Script links stay plain text.** A link keeps its target only for http, https and mailto.
- **Every divider spelling works.** A `- - -` line now becomes a divider, not a bullet.
- **The check knows what to expect.** The report counts dividers, gray runs, checklist items and columns from the source. `mismatch` names any count the page misses.
- **One normalizer and one marker list.** All three programs compare read-backs the same way. Both gap passes compute `gapsLeft` the same way.
