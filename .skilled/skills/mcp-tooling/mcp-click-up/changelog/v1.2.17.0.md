# v1.2.17.0, The Gap Pass Finds the Page Body and Two Spellings Import as Written

A task pushed to a ClickUp doc on 2026-11-10 showed three defects. Every check had passed.

> Spec folder: `AI Systems/Product Owner/specs/system/023-clickup-doc-push-editor-and-numbering`

&nbsp;

## What's New at a Glance

- **The gap pass edits the page body.** A doc page now has two editors. The first one is the title. The pass found it and reported no gaps. The plain-text read-back still counted 60. Both programs now take the editor with the most blocks. That removed all 60 gaps. The text stayed the same.
- **An empty checkbox imports as a checklist item.** ClickUp turned `- []` into literal `\[\]` text. Send it as `- [ ]` instead.
- **A numbered bold title stays a plain number.** ClickUp read `2.  **Header**` as a numbered list. The divider after it ended that list. So every title read `1.` on the page. Send it as `2\. **Header**`. It reads back exactly as sent.

&nbsp;

## Upgrade

No migration required. Write an older page again in `replace` mode. Then run the gap pass.
