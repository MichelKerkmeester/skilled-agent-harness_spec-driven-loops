# v1.2.11.0, Every Doc Page Write Checks Its Import and Removes the Gaps

v1.2.10.0 explained the empty line ClickUp writes under every divider and left the fix as an offer. The fix is now part of every doc page write, and so is a check of how ClickUp imported the markdown.

> Spec folder: `specs/mcp-tooling/026-clickup-doc-divider-spacing` (Level 1)

&nbsp;

## What's New at a Glance

- **A required routine after every page write.** `references/mcp-tools.md` section 8 adds "Required after every page write": check the import, count the gaps, remove them, report per page.
- **The import is checked line by line.** The markdown read-back is compared with what was sent, so an escaped `\*\*`, a paragraph turned into a heading or a literal `\[\]` is caught before the push is reported.
- **One program does the work.** A Code Mode program runs the import check, the editor pass and the text-unchanged proof for a batch of pages, and stops with `login: true` when ClickUp asks for a login.
- **No second yes.** The approved push covers the routine, because it removes only empty lines and proves the text unchanged. `SKILL.md` section 0 and `references/troubleshooting.md` say so.
