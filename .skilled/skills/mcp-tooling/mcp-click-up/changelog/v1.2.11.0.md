# v1.2.11.0, Every Doc Page Write Checks Its Import and Removes the Gaps

v1.2.10.0 explained the empty line ClickUp writes under every divider. It left the fix as an offer. The fix is now part of every doc page write. So is a check of how ClickUp imported the markdown.

&nbsp;

## What's New at a Glance

- A required routine after every page write.
  - `references/mcp-tools.md` section 8 adds "Required after every page write".
  - Section 8 says to check the import, count the gaps and remove them.
  - Section 8 also says to report per page.
- The import is checked line by line.
  - The markdown read-back is compared with what was sent.
  - So an escaped `\*\*` is caught before the push is reported.
  - So is a paragraph turned into a heading or a literal `\[\]`.
- One program does the work.
  - A Code Mode program runs the import check for a batch of pages.
  - It runs the editor pass and the text-unchanged proof too.
  - It stops with `login: true` when ClickUp asks for a login.
- No second yes.
  - The approved push covers the routine.
  - That is because it removes only empty lines and proves the text unchanged.
  - `SKILL.md` section 0 and `references/troubleshooting.md` say so.
