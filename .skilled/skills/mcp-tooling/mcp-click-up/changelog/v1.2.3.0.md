# v1.2.3.0, Vendored copy review fixes

v1.2.3.0 fixes what a deep review of the copy Product Owner vendors found.

&nbsp;

## What's New at a Glance

- `scripts/doctor.sh` finds the nearest `.utcp_config.json` above the packet.
  - So the Code Mode check works wherever the packet sits.
- The docs now agree that `cupt add` creates a task.
  - It sends only the plain `description` field.
  - So a task with a markdown description goes through the MCP.
  - `references/cupt-commands.md` lists `cupt add`.
  - The `--json` command list has one owner.
- The install guide warns that a token typed on the command line lands in shell history.
  - The guide carries one version.
  - It runs its install command from the packet folder.
  - The README and SKILL.md install commands match it.
- The router no longer declares an `assets` folder the packet does not have.

&nbsp;

No migration required.
