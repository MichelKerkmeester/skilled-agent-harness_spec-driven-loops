# v1.2.19.0, Browser-First Doc Page Writes

A markdown page write left a gap under every divider. It kept no colour either. The team's pages use gray numbers and side-by-side screenshots.

> Spec folder: `AI Systems/Product Owner/specs/system/026-browser-first-doc-writer`

&nbsp;

## What's New at a Glance

- **The editor writes the body.** The MCP creates the page with `[[BODY]]`. The new page writer pastes the whole body over it in one change.
- **Dividers stay tight.** The paste leaves no empty line under a divider. The gap pass has nothing to remove.
- **Numbers and Mark-as-done turn gray.** A numbered title keeps its number gray and regular. The Mark-as-done line is gray italic.
- **Columns come from the markdown.** A `[[COLS]]` block becomes a side-by-side row in the same paste.
- **The editor selector is fixed.** On a short page the title and body editors tied. Every program now selects the body by its wrapper.
- **The markdown write is the fallback.** With no browser, the page is written as markdown. The gap pass and columns routine still run.
