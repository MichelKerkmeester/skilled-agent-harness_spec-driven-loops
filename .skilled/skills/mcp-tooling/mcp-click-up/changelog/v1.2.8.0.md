# v1.2.8.0, Router File Move

The full machine router now lives in `ROUTER.md` under the `MACHINE ROUTER` heading, after the overview and intent model. The parsed router is identical to the previous edition.

&nbsp;

## What's New at a Glance

- **Routing references point to one file.** `SKILL.md` keeps short `SMART ROUTING` prose ending in a link to `ROUTER.md`. Testing playbooks, feature catalog entries and references now point there too.
- **The router accepts a root install guide.** `ROUTER.md` lists `INSTALL-GUIDE.md` in `ROOT_RESOURCES`. The router contract now accepts a file at the skill's own root.
- **Every related-document table reaches the machine router.** The README, the install guide, the examples index and both server READMEs now list `ROUTER.md`.
