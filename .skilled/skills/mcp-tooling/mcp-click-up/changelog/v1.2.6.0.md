# v1.2.6.0, Routing Summary Up Front

The routing section of this packet opened with a loading-level block, a twenty-row operation-to-tool table and two hundred lines of pseudocode, so a reader looking for where a request lands had to walk all of it first. The section now says in a few sentences what selects this packet, which two reference files load first and where the routing detail lives. The loading levels, the operation-to-tool map and the pseudocode moved without a word changing.
