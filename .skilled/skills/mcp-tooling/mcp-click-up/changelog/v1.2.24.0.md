# v1.2.24.0, ClickUp names the browser hub

`SKILL.md`, `README.md` and `references/mcp-tools.md` named the browser packets as if they were standalone skills, so a reader could not tell they now live as modes of the `mcp-browser-use` hub.

&nbsp;

## What's New at a Glance

- The "Which browser" note in `references/mcp-tools.md` (1.1.21.0) says both browsers come from the `mcp-browser-use` hub, and the Aside and Chrome bullets name `mcp-browser-use/mcp-aside-devtools` and `mcp-browser-use/mcp-chrome-devtools`.
- The related-skills line in `SKILL.md` and the README (1.1.9.0) table name the `mcp-browser-use` hub, whose Chrome DevTools mode is the structural template and whose Aside and Chrome DevTools modes drive the signed-in doc page writes.

&nbsp;

## Upgrade

No action is needed. The browser programs and tool names are unchanged.
