# v1.2.5.0, Frontmatter That a Strict Parser Reads

Three frontmatter descriptions in this packet were written without quotes and held a colon or a bare double quote, which a strict YAML parser rejects. All three values are now quoted, and none of their words changed.

> Spec folder: `specs/sk-code/017-portable-code-modes/015-frontmatter-yaml-validity` (Level 2)

&nbsp;

## What's New at a Glance

- **The README description is quoted.** The colon in the value no longer breaks the block for a strict parser.
- **Two feature-catalog pages escape their inner quotes.** The `cupt note` and `cupt done --note` lines now escape the quotes around `<text>`, so the description parses and still shows the placeholder.
