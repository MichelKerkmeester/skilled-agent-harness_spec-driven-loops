# v1.2.5.0, Frontmatter That a Strict Parser Reads

Three frontmatter descriptions in this packet were written without quotes. Each held a colon or a bare double quote. A strict YAML parser rejects that. All three values are now quoted. None of their words changed.

&nbsp;

## What's New at a Glance

- The README description is quoted.
  - The colon in the value no longer breaks the block for a strict parser.
- Two feature-catalog pages escape their inner quotes.
  - The `cupt note` and `cupt done --note` lines now escape the quotes around `<text>`.
  - So the description parses.
  - The description still shows the placeholder.

No migration required.
