# v1.0.1.0, Top-Level Install Guide

mcp-click-up v1.0.1.0 makes its install guidance available from a top-level entry point.

## What's New at a Glance

- **A top-level `INSTALL-GUIDE.md` adds an install front door at the packet root.** It brings mcp-click-up to install-guide parity with the sibling packets (`mcp-chrome-devtools/INSTALL-GUIDE.md`, `mcp-figma/INSTALL-GUIDE.md`), which already carry a top-level guide. It promotes and reorganizes the content of `references/INSTALL-GUIDE.md`: AI-first install block, component overview and architecture, prerequisites + cupt install, authentication (token and OAuth), optional Code Mode MCP configuration, verification, troubleshooting and a resources table. No content was invented: every command and configuration block derives from `references/INSTALL-GUIDE.md`, `SKILL.md` and the mcp-servers READMEs.
- **The reference now ends with a short pointer note to the new front door.** It keeps its FULL content and remains the smart router's INSTALL-intent target (`SKILL.md §2 RESOURCE_MAP`). All existing inbound links from `SKILL.md`, `README.md`, `examples/README.md`, `mcp-servers/clickup-cli/README.md`, `mcp-servers/clickup-mcp/README.md`, `scripts/doctor.sh` and `references/mcp-tools.md` keep resolving to the same step-by-step guide they describe. The front door links back into the reference for the phase-by-phase validation ladder.

## Upgrade

No migration required. This is a documentation-only change. It does not change the install path, script or routing behavior.
