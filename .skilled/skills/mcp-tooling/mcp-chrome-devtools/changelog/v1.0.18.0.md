# v1.0.18.0, The Script Count Names Its Folder

Two README lines failed their checks for different reasons. The headless-mode line said "all three scripts" without naming the folder that holds them, so the count check had nothing to count against. The reference check read `performance-baselines/` as a repository folder and found none.

The count now reads "all three scripts under `examples/`", which is the same three scripts the bullets above it name and lets the check count the folder itself. `performance-baselines/` is declared in the `readme-check` block as the output folder `performance-baseline.sh` writes its timestamped metrics, HAR, screenshot and console logs into, which is what it always was.
