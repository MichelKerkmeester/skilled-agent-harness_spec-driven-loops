# v1.0.16.1, The Router Moves to Its Own Section

`SKILL.md` now states its routing in four plain sentences. The SMART ROUTING section is now a short prose summary. The sentences name the hub mode that selects this packet. They name the references it loads first. They name where the machine router lives.

The loading-level table moved unchanged. The router resilience bullets moved unchanged. The router pseudocode that followed them moved unchanged. All of it went into a final `## 9. MACHINE ROUTER` section. That section closes the file.

&nbsp;

## What's New at a Glance

- The routing section reads at a glance.
  - A reader sees the selection signal.
  - A reader sees the references loaded first.
  - A reader sees the pointer to the router.
  - No scrolling through pseudocode is needed.
- The router itself is unchanged.
  - The intent map moved byte for byte.
  - So the resource map, the fallback checklist and the helper code moved byte for byte.
  - The same requests reach the same references.
- The scenario pointers follow the blocks.
  - Every routing-recall scenario now points at the section.
  - That section holds the intent tables it checks.
- Nothing else moved.
  - Section numbers and order are as they were.
  - The new section is appended at the end.

&nbsp;

## Upgrade

No migration required. The routing behavior is identical.
