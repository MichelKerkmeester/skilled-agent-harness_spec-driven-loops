# v1.0.22.0, The Live Manual Has a Catalog Entry and Closes by Page ID

The live manual shipped in v1.0.21.0. It had a summary row. Its close rule could pick the user's own tab.

&nbsp;

## What's New at a Glance

- Close the page by its ID.
  - SKILL.md now says to close the page ID that appeared in `list_pages` after your `new_page`.
  - Never close a tab found by URL.
  - That is because the user may have the same page open.
- The live manual has its own entry.
  - `feature-catalog/mcp-parallel-instances/live-instance.md` covers setup, background pages and the own-tab rule.
  - The catalog counts 30 features.
- The manuals asset counts three.
  - Its overview, its isolation note and its trigger phrases now include `chrome_devtools_live`.
  - The dual-instance entry says the live manual is not part of that pattern.
- Routing knows the manual by name.
  - `chrome_devtools_live`, "remote debugging" and "my own chrome" now reach this mode.
- Changelog spec lines carry the path only.
  - Nine older entries dropped their level label.
