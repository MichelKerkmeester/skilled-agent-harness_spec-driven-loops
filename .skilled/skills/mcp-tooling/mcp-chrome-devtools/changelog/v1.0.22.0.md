# v1.0.22.0, The Live Manual Has a Catalog Entry and Closes by Page ID

The live manual shipped in v1.0.21.0 with a summary row and a close rule that could pick the user's own tab.

> Spec folder: `specs/mcp-tooling/026-clickup-doc-divider-spacing`

&nbsp;

## What's New at a Glance

- **Close by page ID.** SKILL.md now says to close the page ID that appeared in `list_pages` after your `new_page`, never a tab found by URL, since the user may have the same page open.
- **The live manual has its own entry.** `feature-catalog/mcp-parallel-instances/live-instance.md` covers setup, background pages and the own-tab rule, and the catalog counts 30 features.
- **The manuals asset counts three.** Its overview, its isolation note and its trigger phrases now include `chrome_devtools_live`, and the dual-instance entry says the live manual is not part of that pattern.
- **Routing knows the manual by name.** `chrome_devtools_live`, "remote debugging" and "my own chrome" now reach this mode.
- **Changelog spec lines carry the path only.** Nine older entries dropped their level label.
