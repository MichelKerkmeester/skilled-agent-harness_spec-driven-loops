#### Version alignment

- Need: The README frontmatter carried 1.0.0.22 while the packet release record headed at v1.0.10.0, so the document and the changelog disagreed.
- Change: The README version field moved to 1.0.11.0 and this entry records the release.
- Why it matters: The README and the changelog now move together per the versioning convention.
