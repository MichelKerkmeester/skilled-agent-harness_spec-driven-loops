# v1.1.4.1, The Router Moves to Its Own Section

`SKILL.md` now states its routing in four plain sentences. The sentences name the hub mode that selects this packet. They name the references it loads first. They name where the machine router lives.

The loading-level table moved unchanged into a final `## 9. MACHINE ROUTER` section. So did the router resilience bullets. So did the router pseudocode that followed them. That section closes the file.

&nbsp;

## What's New at a Glance

- The routing section reads at a glance.
  - A reader sees the selection signal.
  - A reader sees the references loaded first.
  - A reader sees the pointer to the router.
  - No scrolling through pseudocode is needed.
- The router itself is unchanged.
  - The intent map, resource map, fallback checklist and helper code moved byte for byte.
  - So the same requests reach the same references.
- The scenario pointers follow the blocks.
  - Every routing-recall scenario now points at one section.
  - That section holds the intent tables the scenario checks.
- Nothing else moved.
  - Section numbers and order are as they were.
  - The new section is appended at the end.

&nbsp;

## Upgrade

No migration required. The routing behavior is identical.
