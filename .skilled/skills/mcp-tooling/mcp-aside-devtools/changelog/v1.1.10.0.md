# v1.1.10.0, One Redaction Rule for Logs and Saved Captures

ALWAYS rule 6 said to redact secrets from default logs. The packet never defined that term. The cookies catalog entry already barred secrets from any saved evidence, so the skill body was weaker than its own leaf.

> Spec folder: `AI Systems/Product Owner/specs/system/030-system-review-and-vendor-sync`

&nbsp;

## What's New at a Glance

- **Rule 6 drops "default logs".** It now covers every log, transcript, saved capture, report and reply. A saved cookie file no longer sits outside its letter.
- **Names and keys, not values.** The rule says to record cookie and storage names and keys only, unless the operator explicitly needs a value.
- **Captures stay out of the repository.** Rule 6 now matches `mcp-chrome-devtools` ALWAYS rule 7. Captures go to a scratch folder or an ignored path and are never committed.
- **The restatements match.** `references/troubleshooting.md`, `references/session-management.md` and the cookies catalog entry use the same plain words.
- **Screenshot and PDF recipes leave the repository.** `feature-catalog/devtools-parity/screenshots-and-pdf.md` and scenario ASD-017 wrote to `./artifacts/`, inside the open repository. They now write to `/tmp/aside-artifacts/`, and ASD-017 deletes the files.
