# v1.1.8.0, The REPL Works Beside the User

An agent driving Aside needs to know whether it takes over the user's screen. It does not: `openTab` opens a background tab, and the user's active tab stays in view.

> Spec folder: `specs/mcp-tooling/026-clickup-doc-divider-spacing`

&nbsp;

## What's New at a Glance

- **Background tabs are measured.** `references/session-management.md` section 6 adds "Working beside the user": the user's active tabs were unchanged around a ClickUp editor pass, and the pass tab reported `active: false`.
- **Key presses still land.** The background tab reports itself visible and focused, so `page.keyboard.press` works there.
- **One rule follows.** Open your own tab with `openTab`, work only in it and close it. Never attach to the user's active tab for a mutating step.
