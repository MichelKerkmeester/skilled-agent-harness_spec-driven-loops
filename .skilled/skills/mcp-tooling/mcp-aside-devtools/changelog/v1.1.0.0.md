# mcp-aside-devtools v1.1.0.0

The README rewrite from the skill-readme refinement packet. The previous README used the older tabular reference-card style and its body failed the Human Voice Rules punctuation gate. This release rewrites it purpose-first on the refined template with a one-line pitch and a problem-first OVERVIEW. Every verified fact from the prior text survives the rewrite.

## 1. NEW

- `README.md` pitch and identity. A one-line blockquote under the H1 states the delivered outcome before any tool name. The frontmatter description mirrors the pitch so the identity survives both a skim and a deep read.
- `README.md` problem-first OVERVIEW. The reader's situation and the wrong-lane failure mode come before any feature list.
- `README.md` lane capability layer. A four-row table names what each lane operates: agent tasks, deterministic REPL steps, MCP composition and DevTools parity.

---

## 2. CHANGED

- `README.md` voice and punctuation. The body now passes the Human Voice Rules punctuation greps with zero em dashes and zero semicolons. Oxford-comma patterns are gone from every list.
- `README.md` version field `1.0.0.0` to `1.1.0.0`, aligned with this changelog head.

---

## 3. NOT CHANGED

- `SKILL.md` stays at `1.0.0.0`. No skill file, reference set, feature-catalog card or playbook scenario moved in this release.
- The released changelog entry `v1.0.0.0` stays byte-identical.
- No vault, plugin or runtime data was touched.
