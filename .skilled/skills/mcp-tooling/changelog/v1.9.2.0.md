# v1.9.2.0, The Hub Moves to the Routing Canon

The mcp-tooling hub was still in the older routing shape. Its SMART ROUTING section now holds short prose. That prose points at `ROUTER.md`. It also points at a final machine router section. The routing detail lives there. No routing behavior changed.

&nbsp;

## What's New at a Glance

- **SMART ROUTING is short.** It is eight lines of prose. They point at `ROUTER.md` and at `## 6. MACHINE ROUTER`.
- **The routing detail has one home.** The compiled-routing directive now sits in the final section. So do the Two-Axis Model and the routing rule. The outcomes (single, orderedBundle and defer) sit there too. So does the Surface Router note.
- **The sections are renumbered.** The separate Two-Axis Model section is gone. So HOW IT WORKS is now section 3. RULES is 4 and REFERENCES is 5.

&nbsp;

## Upgrade

No migration required.
