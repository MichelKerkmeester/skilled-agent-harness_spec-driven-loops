# v1.9.2.0, The Hub Moves to the Routing Canon

The mcp-tooling hub was still in the older routing shape. Its SMART ROUTING section now holds short prose that points at `ROUTER.md` and at a final machine router section, where the routing detail lives. No routing behavior changed.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/013-mcp-tooling-routing-canon` (Level 2)

&nbsp;

## What's New at a Glance

- **SMART ROUTING is short.** It is eight lines of prose that point at `ROUTER.md` and at `## 6. MACHINE ROUTER`.
- **The routing detail has one home.** The compiled-routing directive, the Two-Axis Model, the routing rule, the outcomes (single, orderedBundle and defer) and the Surface Router note now sit in the final section.
- **The sections are renumbered.** The separate Two-Axis Model section is gone, so HOW IT WORKS is now section 3, RULES is 4 and REFERENCES is 5.
