The `mcp-tooling` hub gains a third workflow mode: `mcp-aside-devtools` brings AI-browser automation via the Aside browser, using the agentic `aside` CLI, deterministic `aside repl` evidence capture and `aside mcp` via Code Mode fallback.

## Why This Release

The hub covered Chrome-family debugging (`mcp-chrome-devtools`), ClickUp task management (`mcp-click-up`) and the Figma Desktop transport (`mcp-figma`), but had no bridge for agentic AI-browser automation. Aside's developer surface combines natural-language CLI tasks, deterministic REPL and a built-in stdio MCP server, filling that gap with the same CLI-primary/MCP-fallback architecture the hub already routes.

## What's New at a Glance

- **The Aside mode has a nested workflow packet.** `mcp-aside-devtools/` is a 41-file packet authored from a converged 10-iteration deep-research fan-out with 3 lineages. It has `packetKind: "workflow"`, `backendKind: "cli-plus-mcp"` and `mutatesWorkspace: true`.
- **The registry and router carry the new workflow.** `mode-registry.json` adds a fourth `modes[]` entry on the workflow axis and updates count-coupled prose. `hub-router.json` adds a weight-4 `mcp-aside-devtools` signal (`aside-devtools-aliases` + `agentic-browser` + `hub-identity`), mirrored vocabulary classes and a tie-break slot after `mcp-click-up` and before the transport.
- **Hub references name the new mode.** `SKILL.md`, `description.json` and `graph-metadata.json` add the mode table row, keywords, trigger example, intent signals, domains, packet entity and key files. `SKILL.md` also updates the two-axis prose, layout and references. `manual-testing-playbook/hub-routing/aside-browser-automation.md` adds a routing scenario guarding the Aside-vs-Chrome vocabulary boundary.
- **The Aside MCP manual is registered.** `.utcp_config.json` registers the `aside` manual with stdio, `aside mcp` and credential-free `env: {}` under a single-manual posture. The dual-manual layout stays an open question gated on an isolation test.
- **The live-probed MCP inventory is documented as version-pinned.** It lists one `repl` tool at CLI 1.26.626.1517 and protocol 2024-11-05, and runtime rediscovery is mandated.
