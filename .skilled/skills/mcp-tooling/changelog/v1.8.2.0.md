# v1.8.2.0, Root Metadata Check Command

The feature catalog showed `ci-skill-root-metadata.cjs --skills-dir .skilled/skills --check`. The script never had a `--check` option and used to ignore it. It now refuses unknown options with exit 2, so the catalog line runs the check without it.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/021-open-ends-remediation/001-typo-proof-parsers` (Level 1)

&nbsp;

## What's New at a Glance

- **The documented check command runs again.** The catalog line is now `ci-skill-root-metadata.cjs --skills-dir .skilled/skills`, whose default run is the read-only check.

&nbsp;

## Upgrade

Drop `--check` from any copy of this command you keep elsewhere.
