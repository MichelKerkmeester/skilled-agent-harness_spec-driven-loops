`mcp-tooling` gains a second design transport with `mcp-refero`. It brings read-only real-app UI design-reference research through Refero MCP via Code Mode into the hub and pairs it with `sk-design` for judgment.

## Why This Release

The hub's only design-side bridge was the Figma Desktop transport. Refero's MCP surface, with 8 read-only tools over real-app screens, flows and styles, was already registered in the unchanged `.utcp_config.json` as the `refero` manual, but had no skill packet, routing vocabulary or transport contract. Design-reference research therefore had no advisor-reachable home.

## What's New at a Glance

- **`mcp-refero/` is a 29-file nested transport packet.** It was authored from a converged 10-iteration deep-research fan-out with 3 lineages, all first-attempt. It declares `packetKind: "transport"`, `backendKind: "code-mode-remote-mcp"` and `mutatesWorkspace: false`, and forbids Write, Edit and Task.
- **The doubled-prefix Code Mode callable is documented from live evidence.** A `tool_info` confirmation is mandatory after registration. Plan gating sets Pro at 8,000 calls/month and Free has no MCP, and the `OAuth-Inferred` posture is carried honestly.
- **`mode-registry.json` adds Refero as the fifth `modes[]` entry.** The `transport-axis` extension now declares two transports with `crossHubPairing` to `sk-design` for both. `mode-registry.json` also adds `backendKind: code-mode-remote-mcp`.
- **`hub-router.json` adds an `mcp-refero` signal with weight 4.** The signal uses `refero-aliases`, `design-reference-research` and `hub-identity`. The router mirrors that vocabulary and appends its tie-break after `mcp-figma`.
- **The hub's skill surfaces describe the new transport.** `SKILL.md` (v1.2.0.0), `description.json` and `graph-metadata.json` generalize transport prose so pairing rules cover all transports. They add a mode-table row, keywords, a trigger example, intent signals, domains and a packet entity.
- **The playbook covers the Refero-Figma vocabulary boundary.** `manual-testing-playbook/hub-routing/refero-design-reference.md` is the routing scenario that guards it.
