# v1.8.7.0, The Hub Drops an Author Line It Never Had

The hub SKILL.md declared `author: OpenCode` in its metadata block. No router, validator or installer read that field. It named a tool that did not write the file. So the line is gone.

&nbsp;

## What's New at a Glance

- The metadata block no longer names an author.
  - `family: mcp` stays.
  - The name, description, allowed-tools and version keys are untouched.
- Nothing consumed the field.
  - The hub router, the mode registry and the doctor checks never read `author`.
  - So routing and dispatch behave the same.

&nbsp;

## Upgrade

No migration required.
