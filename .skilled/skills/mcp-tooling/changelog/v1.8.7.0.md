# v1.8.7.0, The Hub Drops an Author Line It Never Had

The hub SKILL.md declared `author: OpenCode` in its metadata block. No router, validator or installer read that field, and it named a tool that did not write the file, so the line is gone.

> Spec folder: `specs/sk-code/017-portable-code-modes/015-frontmatter-yaml-validity` (Level 2)

&nbsp;

## What's New at a Glance

- **The metadata block no longer names an author.** `family: mcp` stays, and the name, description, allowed-tools and version keys are untouched.
- **Nothing consumed the field.** The hub router, the mode registry and the doctor checks never read `author`, so routing and dispatch behave the same.
