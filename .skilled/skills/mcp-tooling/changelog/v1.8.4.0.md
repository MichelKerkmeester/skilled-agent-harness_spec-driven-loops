# v1.8.4.0, Docs Say What They Mean

The hub's documents now say what each one is for. The README hands routing to SKILL.md, the mcp-mobbin examples README opens with an overview, and the released changelogs describe their scenarios in words rather than internal ids. No released fact changed.

## What's New at a Glance

- **The hub README points at SKILL.md for routing.** A reader who wants to know how a request reaches a packet is sent to the contract, not to a second description of the modes.
- **The mcp-mobbin examples README opens with an overview.** The template expects that section up front, so the file passes the check instead of failing on a missing opening.
- **Released changelogs speak in plain words.** The hub, mcp-figma and mcp-obsidian entries name the scenario and the decision a reader can picture, rather than an internal id. No released fact changed.
