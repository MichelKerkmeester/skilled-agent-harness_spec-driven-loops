# v1.9.8.0, The Hub Changelog Spec Lines Carry Paths Only

v1.9.7.0 shipped while eighteen older hub entries still failed the changelog shape check, the same defect the modes fixed in their own entries.

## What's New at a Glance

- **Every hub entry passes the shape check.** The spec lines of v1.5.0.0, v1.8.0.1 to v1.8.9.0 and v1.9.0.0 to v1.9.6.0 dropped their level label. The v1.9.3.0 entry names two folders, so it now reads `Spec folders:` with the two paths joined by "and".
- **The modes it routes to changed.** mcp-click-up v1.2.16.0 and mcp-chrome-devtools v1.0.23.0. Routing is unchanged.
