# v1.8.8.0, The Hub Router Learns Two Health Words

The stage-one hub router already sent the words health and health-md to the mcp-obsidian mode, but the stage-two OBSIDIAN intent in the hub ROUTER.md knew neither word, so a request that reached it had no leaf set to load. The intent now carries both words, so a Health.md request resolves to the mcp-obsidian leaves.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/002-baseline-and-routing-correctness` (Level 2)

&nbsp;

## What's New at a Glance

- **health and health-md now route in both stages.** A Health.md request that reaches the hub loads the mcp-obsidian leaves. Stage one and stage two now agree on both words.
- **Other stage-one terms still lack a stage-two home.** The remaining vocabulary gap is left for a later pass.

&nbsp;

## Upgrade

No action is needed. The intent only gained two words, so every route that matched before still matches.
