# mcp-tooling README moves to the purpose-first narrative voice

The mcp-tooling README adopts the mcp-obsidian pilot's purpose-first narrative voice. It replaces the tabular reference-card style.

&nbsp;

## What's New at a Glance

- The README moves to the refined standalone template shape.
  - The new shape replaces the older tabular reference-card style.
  - The new shape has a one-line pitch and a problem-first OVERVIEW.
  - An AT A GLANCE table comes first.
  - Numbered ALL-CAPS sections follow, with dividers.
- Every factual claim about the seven registered modes survives the rewrite. That includes the routing facts, the transport axis and the mcp-code-mode boundary.
- The frontmatter version is now 1.5.0.0.
  - The version was 1.0.0.0.
  - This brings the README into agreement with changelog history for the first time.
  - That history had already reached v1.4.2.0.
- Each of the seven mode rows links to its packet README. A reader can land on each mode's runtime surface in one step.
