# v1.9.5.0, The Compiled-Routing Directive Returns to the Machine Router

The v1.9.4.0 readability pass moved the compiled-routing directive from `ROUTER.md` section 5 into the overview. The skill-package validator reads that directive only from the `## MACHINE ROUTER` section, so the hub failed its compiled routing readiness check from then on. The directive is back in section 5, word for word, as in `sk-design` and `sk-code`.

- **No route changed.** The directive text is unchanged, and a ClickUp doc request still routes to `mcp-click-up`.
