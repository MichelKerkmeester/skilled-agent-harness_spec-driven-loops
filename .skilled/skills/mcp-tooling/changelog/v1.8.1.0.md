# v1.8.1.0, Template-Name Comment Removed from the Feature Catalog

v1.8.1.0 removes the `sk-doc-template` comment from 2 feature catalog files. The comment sat under each file's heading. It named the template a file was scaffolded from. No validator, router or script ever read it. The catalog template no longer adds it.

&nbsp;

## What's New at a Glance

- **Each catalog file now goes straight from its title to its overview.** The heading, sections and links are otherwise unchanged.
- **Catalog validation reports the same results as before.** Removing the comment changed no check outcome.
- **The rest of the catalog track ships here too.** Older changelog entries gain their `version` key. The catalog validator and skill package findings are fixed in the child packets. These are mcp-aside-devtools 1.1.2.0, mcp-chrome-devtools 1.0.14.0, mcp-click-up 1.2.2.0, mcp-figma, mcp-mobbin and mcp-refero 1.1.3.0.

&nbsp;

## Upgrade

No migration required.
