# v1.8.1.0, Template-Name Comment Removed from the Feature Catalog

v1.8.1.0 removes the `sk-doc-template` comment that sat under the heading of 2 feature catalog files. The comment named the template a file was scaffolded from, but no validator, router or script ever read it, and the catalog template no longer adds it.

> Spec folder: `specs/sk-doc/066-feature-catalog-template-anchor-deprecation` (Level 2)

&nbsp;

## What's New at a Glance

- **Each catalog file now goes straight from its title to its overview.** The heading, sections and links are otherwise unchanged.
- **Catalog validation reports the same results as before.** Removing the comment changed no check outcome.
- **The rest of the catalog track ships here too.** Older changelog entries gain their `version` key, and the catalog validator and skill package findings are fixed in the child packets: mcp-aside-devtools 1.1.2.0, mcp-chrome-devtools 1.0.14.0, mcp-click-up 1.2.2.0, and mcp-figma, mcp-magicpath, mcp-mobbin and mcp-refero 1.1.3.0.
