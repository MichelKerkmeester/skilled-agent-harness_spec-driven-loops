# v1.9.14.0, Browser Captures Stay Out of the Repository

Both browser packets now carry a rule for captures. A HAR file can hold live session cookies and bearer tokens. So can a cookie dump or a screenshot of a signed-in page. The recipes wrote them into the open folder.

> Spec folder: `AI Systems/Product Owner/specs/system/030-system-review-and-vendor-sync`

&nbsp;

## What's New at a Glance

- **The modes it routes to changed.** mcp-chrome-devtools v1.0.24.0 and mcp-aside-devtools v1.1.10.0 shipped. Routing is unchanged.
- **Captures go to a scratch folder.** The recipes and example scripts write outside the repository. The cookie recipes print names and domains, not values.

&nbsp;

## Upgrade

No migration required. The chrome example scripts now write under the temp folder. Look there for their results.
