`mcp-tooling` gains `mcp-mobbin` as its third design transport, bringing read-only app, screen and flow design research through Mobbin MCP via Code Mode into the hub. It completes the three-mode expansion program: `aside`, `refero` and `mobbin`.

## Why This Release

Mobbin's MCP server for real-app mobile UX patterns across screens, flows and elements had no bridge, registration or routing vocabulary. With `mcp-refero` covering design-reference search, `mcp-mobbin` completes the design-research transport pair. Both are read-only and paired with `sk-design` for judgment.

## What's New at a Glance

- **`mcp-mobbin/` is a 31-file nested packet.** It came from a converged 10-iteration deep-research fan-out with 3 lineages, all first-attempt. It sets `packetKind: "transport"`, `backendKind: "code-mode-remote-mcp"` and `mutatesWorkspace: false`. Write, Edit and Task are forbidden.
- **`mcp-mobbin` is the sixth `modes[]` entry in `mode-registry.json`.** `transport-axis` declares three transports, all with `crossHubPairing` to `sk-design`.
- **`hub-router.json` gives `mcp-mobbin` a weight-4 signal.** The signal uses `mobbin-aliases`, `app-design-research` and `hub-identity`. Its vocabulary is mirrored, and its tie-break is appended last.
- **The hub metadata carries the new transport details.** `SKILL.md` is v1.3.0.0, and `SKILL.md`, `description.json` and `graph-metadata.json` carry its mode table row, transport enumerations, keywords, trigger example, intent signals, domains and packet entity.
- **Mobbin's connection uses OAuth through `mcp-remote`.** OAuth/DCR/PKCE are documented as the mechanism. No API key environment variable exists, and the callable name is inferred pending live discovery. `.utcp_config.json` registers the `mobbin` manual with `npx -y mcp-remote https://api.mobbin.com/mcp` over stdio with an empty environment. OAuth uses `mcp-remote`'s browser round-trip on first use. The documentation carries 10 research open questions verbatim.
- **Routing covers the Mobbin-versus-Refero boundary.** `manual-testing-playbook/hub-routing/mobbin-app-research.md` guards this distinction, and generic phrasing may defer.
