`mcp-tooling` gains `mcp-mobbin` as its third design transport. It brings read-only app, screen and flow design research into the hub. The route is Mobbin MCP via Code Mode. It completes the three-mode expansion program: `aside`, `refero` and `mobbin`.

## Why This Release

Mobbin's MCP server covers real-app mobile UX patterns. It spans screens, flows and elements. It had no bridge, registration or routing vocabulary. `mcp-refero` covers design-reference search. So `mcp-mobbin` completes the design-research transport pair. Both are read-only. Both are paired with `sk-design` for judgment.

## What's New at a Glance

- **`mcp-mobbin/` is a 31-file nested packet.** It came from a converged 10-iteration deep-research fan-out. That fan-out had 3 lineages, all first-attempt. It sets `packetKind: "transport"`, `backendKind: "code-mode-remote-mcp"` and `mutatesWorkspace: false`. Write, Edit and Task are forbidden.
- **`mcp-mobbin` is the sixth `modes[]` entry in `mode-registry.json`.** `transport-axis` declares three transports. All three pair to `sk-design` through `crossHubPairing`.
- **`hub-router.json` gives `mcp-mobbin` a weight-4 signal.** The signal uses `mobbin-aliases`, `app-design-research` and `hub-identity`. Its vocabulary is mirrored. Its tie-break is appended last.
- **The hub metadata carries the new transport details.** `SKILL.md` is v1.3.0.0. `SKILL.md`, `description.json` and `graph-metadata.json` carry its mode table row, transport enumerations, keywords, trigger example, intent signals, domains and packet entity.
- **Mobbin's connection uses OAuth through `mcp-remote`.** OAuth/DCR/PKCE are documented as the mechanism. No API key environment variable exists. The callable name is inferred pending live discovery. `.utcp_config.json` registers the `mobbin` manual. The command is `npx -y mcp-remote https://api.mobbin.com/mcp`. It runs over stdio with an empty environment. OAuth uses `mcp-remote`'s browser round-trip on first use. The documentation carries 10 research open questions verbatim.
- **Routing covers the Mobbin-versus-Refero boundary.** `manual-testing-playbook/hub-routing/mobbin-app-research.md` guards this distinction. Generic phrasing may defer.
