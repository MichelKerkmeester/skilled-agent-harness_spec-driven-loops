# v1.10.0.0, The Browser Modes Leave for Their Own Hub

`mcp-chrome-devtools` and `mcp-aside-devtools` now live in the `mcp-browser-use` hub. The new Bladebro mode sits beside them. This hub keeps its six other modes unchanged. They are ClickUp, Obsidian, Notion, Figma, Refero and Mobbin.

&nbsp;

## What's New at a Glance

- The hub routes six modes.
  - The registry no longer carries either browser mode.
  - Neither do the hub router and the root `ROUTER.md`.
- The advisor stops sending browser requests here.
  - `graph-metadata.json` drops the browser vocabulary, domains and trigger phrases.
  - Its edge contexts and summary describe six modes.
  - The Chrome, DevTools, HAR, staging and browser-console boosts now name `mcp-browser-use`.
- The compiled router serves this hub again.
  - The two-mode removal had left the activation manifest stale.
  - So the hub had fallen back to legacy routing.
  - The manifest is re-minted to the six-mode policy hash.

&nbsp;

## Upgrade

Route browser work through `mcp-browser-use`. A request that names either browser mode reaches that hub.
