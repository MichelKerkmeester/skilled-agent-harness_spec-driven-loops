## Mobbin Research

The transport routes research intents and discovers its tools before the first call.

#### Route Research Intents <a id="c-route-research-intents"></a>

- `SKILL.md` defined Mobbin-specific activation signals.
- It defined a guarded intent router.
- It defined discovery-first execution.
- Research patterns covered apps, screens, flows, elements and website sections.
- Read-only safety rules applied.
- Apps and elements were query intents over the discovered read-only tools.
- They were not separate tool families.

#### Discover the Search Tools <a id="c-discover-the-search-tools"></a>

- The 2026-07-16 pre-auth discovery fixture recorded three registry names:
- `mobbin.mobbin.search_screens`, `mobbin.mobbin.search_flows` and `mobbin.mobbin.search_sections`.
- Confirmed TypeScript Code Mode calls were `mobbin.mobbin_search_screens(...)`, `mobbin.mobbin_search_flows(...)` and `mobbin.mobbin_search_sections(...)`.
- Each session still ran `list_tools` and `tool_info` before its first call.
- It failed closed on discovery drift.
- `search_flows` supplied ordered per-screen previews for research across a flow.
- `search_sections` supplied website-section research.
- Returned ordering was treated as fact.
- Interpolation, omitted states and cross-app generalization were labeled inference.

#### Shape Screen Searches <a id="c-shape-screen-searches"></a>

- `search_screens` exposed `mode: "deep" | "standard" | "fast"`.
- It exposed `exclude_screen_ids` and `image_format`.
- The `fast` mode was a deprecated alias for `standard`.
- Its declared output used `query` and screen records.
- Each record had `id`, `image_url`, `mobbin_url`, `app_name` and `platform`.
- Older undeclared fields were probe-required rather than asserted.

#### Keep Design Judgment Separate <a id="c-keep-design-judgment-separate"></a>

- Any design-affecting use loaded `sk-design` first.
- Mobbin supplied cited evidence.
- It never issued taste, accessibility or readiness verdicts.
- Design-affecting conclusions were routed to `sk-design`.

## Access and Limits

The manual bridges the hosted provider and records OAuth, plan and rate boundaries.

#### Bridge the Hosted Provider <a id="c-bridge-the-hosted-provider"></a>

- The registered `mobbin` Code Mode manual launched `npx -y mcp-remote https://api.mobbin.com/mcp` over stdio.
- That bridged the hosted Streamable HTTP provider.
- Its `env` was intentionally empty.
- That is because Mobbin MCP used browser OAuth.
- There was no `MOBBIN_API_KEY` or other auth environment variable.
- The manual was preserved as a byte-identical reference shape.
- Its presence was the healthy state.
- Its absence was a diagnostic error.
- The packet did not edit or re-add `.utcp_config.json`.

#### Document OAuth Boundaries <a id="c-document-oauth-boundaries"></a>

- The packet documented browser OAuth through DCR, PKCE S256 and `openid`.
- Operator-owned auth state was under `~/.mcp-auth` or `MCP_REMOTE_CONFIG_DIR`.
- No API key entered config or `.env`.
- Discovery and full schemas worked before authentication.
- OAuth completion, authenticated response shapes, inline-image fidelity and authenticated calls were marked Inferred or UNKNOWN.
- That held until an operator completed the browser round trip on a paid account.

#### Record Plan and Rate Limits <a id="c-record-plan-and-rate-limits"></a>

- Access was documented for Pro, Team or Enterprise plans.
- Provider evidence relayed Free-plan denial.
- Its exact status, payload and user experience were unverified.
- The published rate contract was 60 requests per 60 seconds per user.
- On HTTP 429 the workflow honored `Retry-After`.
- It applied exponential backoff with jitter.
- It did not force load tests.
- It did not define finer burst, concurrency, per-plan cap or Finance+ coverage contracts.

## Transport Boundaries

The package keeps one read-only backend and claims no undocumented results.

#### Keep Authority Read-Only <a id="c-keep-authority-readonly"></a>

- The package retained one registered backend.
- It retained one read-only transport contract with `packetKind: transport` and `mutatesWorkspace: false`.
- It had no packet-local design judgment or workspace mutation.
- Runtime authority allowed Read, Bash, Grep, Glob and Code Mode calls.
- Write, Edit and Task were forbidden.
- No hub files or live configuration belonged to this release.
- No undocumented tools, parameters, credentials, limits or authenticated results were claimed.
