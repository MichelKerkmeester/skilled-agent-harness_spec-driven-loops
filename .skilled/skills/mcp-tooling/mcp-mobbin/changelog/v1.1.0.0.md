# v1.1.0.0 - README Rewrite

The `mcp-mobbin` README replaces a tabular reference card with a purpose-first narrative, putting the skill's purpose before its tools. The rewrite follows the refined README template. No SKILL.md, no other skill README, no template and no vault file changed.

## What's New at a Glance

- **A delivered-outcome pitch sits below the H1.** Its one-line blockquote states the delivered outcome before any tool name.
- **The OVERVIEW names the reader's situation.** `Why This Skill Exists` puts that situation before any feature list.
- **The Three-Tool Search Surface is a capability section.** Its table has one row for each tool discovered live.
- **The README uses the mcp-obsidian pilot's section layout.** Numbered ALL-CAPS H2 sections use dividers, with `AT A GLANCE` first. The README body is written to the Human Voice Rules.
- **The README version changed.** It advances from 1.0.0.0 to 1.1.0.0.
- **The VERIFICATION check was updated.** The `SKILL.md` frontmatter check now states the actual version field of the live `SKILL.md`.
- **The three-tool surface and documented boundaries are unchanged.** Registered wiring state, browser-OAuth auth model and the `sk-design` judgment boundary stay exactly as documented.
