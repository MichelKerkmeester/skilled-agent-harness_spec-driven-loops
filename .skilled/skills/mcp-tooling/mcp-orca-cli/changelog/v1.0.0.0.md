# mcp-orca-cli v1.0.0.0

**Released:** 2026-09-19

The first packet adds an evidence-backed Orca CLI workflow to the mcp-tooling hub. It resolves one Orca executable, loads the version-matched `orca-cli` guide, and keeps worktree, terminal, browser, automation, publishing, and authentication actions behind explicit safety gates.

## What is included

- A CLI-first workflow contract for Orca-managed repositories, worktrees, terminals, handoffs, automations, artifacts, skill sharing, comments, and embedded browser state.
- References for the observed 1.4.205 command families, session receipts, archive-hook deletion protection, browser ownership, publishing permissions, and fail-closed recovery.
- A manual safety matrix that distinguishes read-only discovery from mutating and destructive actions.
- A CLI-only backend declaration. The inspected command registry exposed no native Orca MCP command, so no speculative Code Mode manual is registered.

## Known limitations

Command flags remain version-matched. The public discovery stub is not a frozen command reference. Authenticated calls, mutation probes, and publishing checks require an operator-authorized Orca environment and are not implied by package or routing validation.
