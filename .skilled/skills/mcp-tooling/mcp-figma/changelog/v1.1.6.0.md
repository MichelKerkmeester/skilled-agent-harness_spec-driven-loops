# v1.1.6.0, Hosted Server From CLI Children

v1.1.6.0 adds what a live FigJam run on 2026-10-26 showed about reaching Figma's hosted MCP server from headless Claude Code and Codex children. The Code Mode path is unchanged.

&nbsp;

## What's New at a Glance

- `references/mcp-wiring.md` Section 6 gains a subsection on reaching the hosted server natively from a CLI child.
- A Claude Code child reuses the operator's Figma login through a strict MCP config naming the same server, and `--bare` cannot.
- Codex reaches Figma through the ChatGPT account's Figma app, and `codex exec` runs `figma.use_figma` only once an `[apps._default]` block pre-approves app tools.
- A child given a file key can still create a new file in a team plan, so a harness that must stay on one file withholds `create_new_file`.
