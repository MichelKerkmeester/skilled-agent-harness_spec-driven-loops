# v1.2.0.0, Figma-to-Code Scenarios and a Design Hand-Off

A Figma read that feeds code now has somewhere to end and something to test it.

> Spec folders: `specs/sk-code/018-frontend-upstream-proposals/001-frontend-surface-mode`, `003-design-handoffs` and `004-playbook-scenarios` (Level 2)

&nbsp;

## What's New at a Glance

- **The check is named.** A Figma read that feeds code ends at the five-pass check in `.skilled/skills/sk-code/sk-code-frontend/references/figma-to-code.md`.
- **Open values have an owner.** When a request or a frame leaves a visual value open, or a value sits off every token and scale, `sk-design-fundamentals` decides it.
- **A figma-to-code category.** `F2C-001` turns a node into markup on installed tokens, `F2C-002` reports off-scale values as drift, and `F2C-003` checks a built screen in five passes, returning `INCOMPLETE` when a pass cannot run. The package holds 20 scenarios in 7 categories.

&nbsp;

## Upgrade

No migration required. Every new scenario reads Figma and writes nothing to it.
