# v1.1.9.0, The Plugin Manifest Reads as a Third-Party File

The connect steps tell you to import `plugin/manifest.json` once. The connect-modes section repeats it. Both name the manifest that ships inside the installed `figma-ds-cli` package. The reference check read the token as a path in this repository. It found none. It failed the README twice for one file.

The token stays. That is because it is the name Figma Desktop asks for. The README now declares it in its `readme-check` block. The reason is that the installed package carries the manifest. This repository does not. The safe-mode and yolo-mode descriptions are otherwise unchanged.

&nbsp;

## What's New at a Glance

- The README passes the reference check again.
  - One `allow-ref` entry covers both mentions.
  - Its reason names the installed package as the owner.
- The connect instructions are untouched. Importing the manifest once and keeping `Plugins > Development > FigCli` open is still the safe-mode step.
- The README edition is raised.
  - The body changed.
  - So its own edition moves with it.
