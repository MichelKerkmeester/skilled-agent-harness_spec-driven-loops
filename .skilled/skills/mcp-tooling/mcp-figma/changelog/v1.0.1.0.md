# v1.0.1.0 - Worked Example Walkthroughs

The mcp-figma skill now ships worked walkthroughs for its manual-testing-playbook scenarios.

## Why This Release

The new examples bring mcp-figma to parity with sibling packets `mcp-chrome-devtools/examples/` and `mcp-click-up/examples/`.

## What's New at a Glance

- **The examples directory has a clear safety boundary.** No destructive verb, yolo patch or `init-agent` appears anywhere in the directory.
- **`examples/README.md` explains prerequisites and safe use.** It covers the directory overview, safety properties including binary discipline, gating fidelity and command provenance, per-walkthrough usage and exit codes, troubleshooting and see-also links.
- **The daemon health walkthrough protects the token.** `examples/safe-connect-daemon-health.sh` detects binaries, refuses the naming trap and uses `connect --safe` (plugin bridge, no patch) with read-only `daemon status` and `daemon diagnose`. It never prints the daemon token and mirrors DETECT-001, CONNECT-001 and DAEMON-001.
- **The inspection walkthrough refuses overwrites.** `examples/inspect-export-readonly.sh` uses read-only `node tree` / `find` and `export screenshot -f svg -o <path>` to an explicit, non-existing output path. It refuses overwrites and mirrors INSPECT-001 and EXPORT-001.
- **Optional MCP context starts with discovery.** `examples/optional-mcp-context.md` covers the opt-in Framelink `figma` MCP via Code Mode. It puts `list_tools` / `tool_info` before any call, requires the prefixed `figma_FIGMA_API_KEY` and pulls context read-only. It mirrors MCP-001.
- **Commands follow the skill's documented sources.** Every command derives from the skill's own SKILL.md, references, feature catalog and playbook. Gated and destructive operations are marked gated exactly as those documents define. None run in the examples.

## Upgrade

No migration required. No action is required. The release adds documentation and examples only. CLI, daemon, gating and MCP wiring behavior did not change.
