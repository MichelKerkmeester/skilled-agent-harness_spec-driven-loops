# v1.1.5.0, Standards Alignment

v1.1.5.0 aligns the packet with the skill packet rules and the shell code standard. No flag or script name changed. The example scripts now write their failures to stderr, and the install hint they print works from a vendored copy.

&nbsp;

## What's New at a Glance

- `SKILL.md` puts SUCCESS CRITERIA before the references, folds the short references section into REFERENCES AND RELATED RESOURCES and lists keywords as phrases a user would type.
- Every shell file opens with a COMPONENT header, and the non-trivial scripts document their exit codes.
- `scripts/install.sh` no longer reruns a failed npm command in quiet mode when `--verbose` is set. Its other `&&`/`||` chains became plain `if` blocks with the same result.
- `scripts/_common.sh` names the minimum Node version once for the installer and the doctor, and every script points ShellCheck at `_common.sh` from any working directory.
- The install guide's common operations name the real `get`, `export node`, `create frame` and `render` forms, since the CLI has no `--out` flag.
- The scripts and examples READMEs state which scripts source `_common.sh`, what `install.sh --skip-verify` still does and which exit codes come from the CLI itself.

&nbsp;

## Fixed

- **Failures went to stdout.** Both example scripts printed their failure lines through the same helper as progress lines. A `fail` helper now sends them to stderr, so a caller that keeps stdout still sees why the run stopped.
- **An install hint that broke in a vendored copy.** `safe-connect-daemon-health.sh` named `.skilled/skills/mcp-tooling/mcp-figma/scripts/install.sh`, which does not exist outside this repository. It now prints the installer's path relative to its own folder, and the scripts and examples READMEs say to run from the packet root.

&nbsp;

## Upgrade

No migration required.
