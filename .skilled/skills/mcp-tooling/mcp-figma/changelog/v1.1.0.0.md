# v1.1.0.0 - Purpose-First README Rewrite

The mcp-figma README moves from a tabular reference card to the fleet narrative standard. That standard was proven by the mcp-obsidian pilot.

&nbsp;

## What's New at a Glance

- The README uses a purpose-first structure.
  - A one-line pitch sits after the title.
  - An AT A GLANCE table comes up front.
  - A problem-first OVERVIEW comes next.
  - Then comes a Figma document layer capability table.
  - It covers frames and components, tokens and variables, read-only exports and design context.
  - That context is pulled through the optional MCP.
  - The structure matches the refined README template from the `sk-doc` skill set.
  - It follows Human Voice Rules with zero em dashes, zero semicolons and zero Oxford commas.
- Every fact from the previous README survives.
  - These include the `figma-cli` naming trap.
  - They include safe and yolo connect modes and the daemon model.
  - They include the gating taxonomy.
  - It covers read-only, mutating or destructive actions and optional Framelink MCP wiring.
  - The frontmatter description and trigger phrases are preserved.
- The README version field is updated.
  - It moves from `1.0.0.2` to `1.1.0.0`.
  - The changelog entry sits at `changelog/v1.1.0.0.md`.
  - The version bump records the release.

&nbsp;

## Upgrade

No migration required. This is a documentation release only. CLI, daemon, gating, MCP wiring and skill behavior did not change.
