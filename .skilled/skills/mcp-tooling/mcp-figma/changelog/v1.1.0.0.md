# v1.1.0.0 - Purpose-First README Rewrite

**Released:** 2026-08-04

The skill README moves from a tabular reference card to the fleet narrative standard proven by the mcp-obsidian pilot: a one-line pitch after the title, an AT A GLANCE table up front, a problem-first OVERVIEW and a capability table for the Figma document layer. Every fact from the previous README survives the rewrite, from the `figma-cli` naming trap to the safe and yolo connect modes, the daemon model, the read-only and mutating and destructive gating taxonomy and the optional Framelink MCP wiring. The frontmatter description and trigger phrases are preserved. The version field bumps to `1.1.0.0` to record the release.

## What Changed

#### README rewrite

- **Purpose-first structure.** The README now opens with a one-line pitch and a problem-first OVERVIEW that states the reader's situation before any feature list, matching the refined README template from the `sk-doc` skill set.

- **Voice and validation.** The document is written in the Human Voice Rules with zero em dashes, zero semicolons and zero Oxford commas. It passes `validate_document.py --type readme` with zero issues.
