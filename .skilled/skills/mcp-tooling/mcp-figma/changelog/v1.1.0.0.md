# v1.1.0.0 - Purpose-First README Rewrite

The mcp-figma README moves from a tabular reference card to the fleet narrative standard proven by the mcp-obsidian pilot.

## What's New at a Glance

- **The README uses a purpose-first structure.** It puts a one-line pitch after the title and an AT A GLANCE table up front, then uses a problem-first OVERVIEW before a Figma document layer capability table for frames and components, tokens and variables, read-only exports and design context pulled through the optional MCP. This matches the refined README template from the `sk-doc` skill set and follows Human Voice Rules with zero em dashes, zero semicolons and zero Oxford commas.
- **Every fact from the previous README survives.** These include the `figma-cli` naming trap, safe and yolo connect modes, the daemon model, the gating taxonomy covering read-only, mutating or destructive actions and optional Framelink MCP wiring. The frontmatter description and trigger phrases are preserved.
- **The README version field is updated.** It moves from `1.0.0.2` to `1.1.0.0`, with the changelog entry at `changelog/v1.1.0.0.md`. The version bump records the release.

## Upgrade

No migration required. This is a documentation release only. CLI, daemon, gating, MCP wiring and skill behavior did not change.
