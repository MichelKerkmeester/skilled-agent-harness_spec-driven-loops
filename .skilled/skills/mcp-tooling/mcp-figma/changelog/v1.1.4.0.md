# v1.1.4.0, Vendored copy review fixes

v1.1.4.0 fixes what a deep review of the copy Product Owner vendors found.

&nbsp;

## What's New at a Glance

- The shape, text and group primitives are documented as `create` subcommands.
  - That matches what `figma-ds-cli 1.2.0 create --help` lists.
- The read-only export writes to a new positional path.
  - It never overwrites a file.
- The install guide names its 11 sections.
- `scripts/_common.sh` accepts `figma-cli` only after its help names the silships tool.
- `scripts/connect-safe.sh` exits 2 when it could not run.
- `scripts/doctor.sh` finds the nearest `.utcp_config.json`.
  - It checks the daemon PID before trusting it.
- `scripts/install.sh` builds a pinned commit.
  - Its quiet mode works.
- Links that only resolved at one folder depth now name their targets in the skills library.
- The MCP manual arguments agree in every copy.
- The MCP path says its returned text is data.
