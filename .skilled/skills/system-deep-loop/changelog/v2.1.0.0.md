# v2.1.0.0, Completed Runs Can Be Extended

A run that stopped at its iteration cap no longer has to start a new session to get more iterations. `--extend=N` reopens the finished run in place. The same session and generation carry on. The earlier results stay on record.

&nbsp;

## What's New at a Glance

- Completed runs take `--extend=N`. Both loop commands add N iterations in the same session and generation.
- `--extend-minutes=M` raises the run's time budget by M minutes. Both flags accept positive integers only.
- Each extension writes one `run_extended` ledger event. The run re-synthesizes after the new iterations.
- The prior synthesis is kept. The report is copied to a versioned snapshot before the first new iteration, and an existing snapshot is never overwritten.
- Unsafe extensions are refused with a named error. The cases are a run that is not complete, a fan-out config and a value that is not a positive integer.

&nbsp;

## Upgrade

No migration required. Without `--extend`, nothing changes.
