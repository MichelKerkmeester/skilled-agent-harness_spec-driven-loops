# v2.1.0.0, Completed Runs Can Be Extended

A run that stopped at its iteration cap no longer has to start a new session to get more iterations. `--extend=N` reopens the finished run in place. The same session and generation carry on. The earlier results stay on record.

&nbsp;

## What's New at a Glance

- **Completed runs take `--extend=N`.** `/deep:research --extend=N` and `/deep:review --extend=N` add N iterations to a completed run in the same session and generation.
- **`--extend-minutes=M` adds time.** The flag raises the run's time budget by M minutes. Both flags accept positive integers only.
- **Each extension is one ledger event.** The `run_extended` event records the extension, and the run re-synthesizes after the new iterations.
- **The prior synthesis is kept.** The synthesis or review report is copied to a versioned snapshot before the first new iteration. An existing snapshot is never overwritten.
- **Unsafe extensions are refused.** Three cases stop with a named error. They are a run that is not complete, a fan-out config and a value that is not a positive integer.

&nbsp;

## Upgrade

No migration required. Without `--extend`, nothing changes.
