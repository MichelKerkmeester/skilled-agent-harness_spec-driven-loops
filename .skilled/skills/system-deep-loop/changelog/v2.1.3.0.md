# v2.1.3.0, Free Text No Longer Steers Next Focus

Next Focus could follow a sentence that only reported progress. A run then spent a round on a settled question. Next Focus now follows open questions and the latest leaf's recommendation.

&nbsp;

## What's New at a Glance

- Research carries forward only open questions. Status sentences and answered questions no longer return.
- Research reads the latest leaf's `Recommended Next Focus`. It leads while a machine question is open, unless that focus is already answered or rejected.
- Review names the first uncovered dimension. Leaf free text that names no dimension is ignored.
- Imperative items, such as `Investigate the review twin`, no longer carry forward. The leaf's recommendation can still carry one into Next Focus.

&nbsp;

## How It Was Checked

Seven new cases failed before the change and pass after it. The three reducer and continuity suites pass, and every existing case is kept.

&nbsp;

## Upgrade

No migration required. Normal research and review runs use the new focus rules with no flag.
