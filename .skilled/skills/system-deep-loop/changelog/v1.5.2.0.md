# v1.5.2.0, An ARCHITECTURE Map for the Deep Loop

The deep-loop skill now has one document that explains how its parts fit together. `ARCHITECTURE.md` maps the five modes onto the shared runtime, names the allowed dependency directions and records the decisions behind them. The runtime itself was brought in line with the shared code standard in the same release.

> Spec folder: `specs/system-deep-loop/036-deep-loop-innovation/029-align-runtime-code-with-sk-code-opencode` (Level 2)

## What's New at a Glance

- **`ARCHITECTURE.md` maps the skill.** It follows the eight-section template and lists the three places where `lib/` reaches into `scripts/` on purpose.
- **The runtime follows the shared code standard.** Its changes are recorded in the runtime's own v1.9.1.0 entry.
