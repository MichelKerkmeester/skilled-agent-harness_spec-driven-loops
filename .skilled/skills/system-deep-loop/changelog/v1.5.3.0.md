The deep-loop scorers measured a Deem backend beside Jev. The Deem arm and the Deem docs are removed. So cli-jev is the only classifier the loop measures. Every default run and Jev arm is unchanged.

## What's New at a Glance

- **Every deep-loop scorer runs Jev alone.** The Deem arm is gone from `score-fanout-pairs.cjs` in the runtime. It is gone from `score-d4-agreement.cjs` and `score-verdict-fallback.cjs` in deep-improvement.
- **The docs describe what exists now.** The hub skill, the packet READMEs and skill docs name Jev only. The feature catalogs and the manual-testing playbooks name Jev only.

## Upgrade

Drop `--deem` from any command that still passes it. A run that keeps it stops at the unknown flag. The Jev arm prints what it printed before.
