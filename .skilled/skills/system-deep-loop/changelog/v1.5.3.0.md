The deep-loop scorers measured a Deem backend beside Jev. The Deem arm and the Deem docs are removed, so cli-jev is the only classifier the loop measures, and every default run and Jev arm is unchanged.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/046-deem-deprecation/004-references-sweep-and-verification` (Level 2)

## What's New at a Glance

- **Every deep-loop scorer runs Jev alone.** The Deem arm is gone from `score-fanout-pairs.cjs`, `score-stop-rater.cjs`, `score-stop-hint.cjs` and `score-severity-replay.cjs` in the runtime, from `score-d4-agreement.cjs` and `score-verdict-fallback.cjs` in deep-improvement, and from `score-residue-flagger.cjs` in deep-review.
- **The docs describe what exists now.** The hub skill, the packet READMEs and skill docs, the feature catalogs and the manual-testing playbooks name Jev only.

## Upgrade

Drop `--deem` from any command that still passes it. A run that keeps it stops at the unknown flag, and the Jev arm prints what it printed before.
