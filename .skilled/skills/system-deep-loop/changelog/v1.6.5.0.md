# v1.6.5.0, A Healthy Review Closes as Complete

The synthesis closeout check added up findings from every iteration record, but each record repeats the findings before it. A finding seen in five iterations counted five times, so the totals never matched and a healthy run closed as incomplete.

> Spec folder: `specs/sk-git/033-git-setup-customization/010-open-ends-cleanup` (Level 1)

&nbsp;

## What's New at a Glance

- **Each finding counts once.** The closeout check counts open and repeated findings by identity, so a deep-review run whose findings carry across iterations closes as complete.
