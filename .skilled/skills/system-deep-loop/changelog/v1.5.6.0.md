# v1.5.6.0, Review Reducer and Recompiled Contracts

v1.5.6.0 is the hub release for two closeout fixes. The review reducer now reads the older review folders that never wrote a config file, and the deep command contracts record current source digests again.

> Spec folders: `specs/sk-code/011-sk-code-poinytail-based-refinement/015-closeout/007-review-reducer-missing-config` and `009-open-items-ledger` (Level 1)

## What's New at a Glance

- **Every review folder reduces.** deep-loop-runtime v1.9.8.0 reduces a folder with a state log and no `deep-review-config.json` on default settings, so all 505 review folders under `specs/` reduce in lenient mode.
- **The README version matches the hub.** It carried 1.4.3.0 and now carries the release version like the other carriers.
- **The command contracts are recompiled.** The deep/ai-council, deep/review and deep/research contracts record the current source digests again.
