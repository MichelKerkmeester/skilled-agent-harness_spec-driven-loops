# v1.6.20.0, Routing Rules Move to ROUTER.md

The routing rules for system-deep-loop moved out of SKILL.md and into a final MACHINE ROUTER section of ROUTER.md. SKILL.md stays short, and the move leaves the hub's routes as they were.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/014-skill-router-files/004-hub-router-merge` (Level 1); `specs/sk-doc/072-skill-routing-and-clarity/015-routing-data-alignment` (Level 2)

&nbsp;

## What's New at a Glance

- **SKILL.md keeps a single pointer.** SKILL.md no longer carries a MACHINE ROUTER section. Its SMART ROUTING section ends with one line that points to ROUTER.md.
- **The README contributor checklist points at ROUTER.md.** It now names the MACHINE ROUTER section, so a contributor who changes routing knows where to edit.
- **The move changed no route.** The map from intent to files is byte for byte the same, and every route the hub selects matches the run before the move. The compiled admission check gives the same result, and the compiled manifest was regenerated from the new sources.
- **The hub meets the routing-shape canon.** Its known-debt entry is removed, so the hub no longer needs an exception in that check.
- **The compiled routing entry names ROUTER.md.** The feature catalog entry for compiled routing names ROUTER.md as the home of the directive.
- **ROUTER.md describes its own setup.** The `allowed-tools` note in ROUTER.md names the frontmatter of SKILL.md, and the separate-document line now reads from the router's own point of view.
- **The hub's own documents point at `ROUTER.md`.** The README layout table and contributor checklist give it a row and a step, the testing playbooks cite it for the override, discriminator and backend rules it holds, and the compiled-routing catalog entry counts seven default-on hubs.
- **The router's own mode phrases now pick their mode.** "audit the diff", "seat diversity", "investigate why" and eight other phrases that `ROUTER.md` already named now sit in `hub-router.json`, so a request built from them routes to its review, research or council mode instead of asking which loop is wanted.
