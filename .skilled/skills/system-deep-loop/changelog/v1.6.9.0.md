# v1.6.9.0, Readmes and Changelogs Speak in Words

A released entry used to name a scenario or a decision by an internal id, so a reader without the packet met a label they could not follow. The released entries for deep-ai-council, deep-research, deep-review and the runtime now name the scenario and the decision in words. Two READMEs also gained the folder names they were missing.

> Spec folder: `specs/sk-doc/070-repo-doc-debt` (Level 2)

&nbsp;

## What's New at a Glance

- **The deep-ai-council scripts README names its folders.** It lists `lib/` and `tests/`, each with a link and a line on what the folder holds.
- **The shared rollout README names its `tests/` folder.** A reader can find the suite from the README instead of guessing the path.
- **Released entries say which scenario and which decision they mean.** The deep-ai-council, deep-research, deep-review and runtime entries point at the scenario and the decision in words, so the story reads without a lookup.
- **No released fact changed.** Only the naming moved.
