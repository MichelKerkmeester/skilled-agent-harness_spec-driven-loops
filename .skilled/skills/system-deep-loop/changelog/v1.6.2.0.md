# v1.6.2.0, Typo-Proof Script Options

The runtime scripts parsed every `--key value` pair and ignored the keys they did not use, so `--modell` or `--sandbx` changed nothing and the run went ahead with defaults. Each script now checks its options against its own list and stops on the first unknown one.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/021-open-ends-remediation/001-typo-proof-parsers` (Level 1)

&nbsp;

## What's New at a Glance

- **Runtime scripts report unknown options as input errors.** `convergence`, `status`, `query`, `upsert`, `fanout-merge` and `loop-lock` print their usual JSON error with code `INPUT_VALIDATION` and exit 3, the code they already use for bad input.
- **`codex-dispatch.cjs` stops on a misspelled flag.** It used to drop `--modell` and run the default model. It now names the flag and exits before it spawns anything.
- **The council, snapshot and drift scripts follow suit.** `advise-council-completion.cjs`, `render-contract-snapshot.cjs`, `check-documentation-drift.cjs`, `check-projection-coverage.cjs`, `check-protocol-append-sites.cjs` and `append-state-record.cjs` refuse an unknown option.

&nbsp;

## Upgrade

Replace any misspelled option with the one the script's usage line lists.
