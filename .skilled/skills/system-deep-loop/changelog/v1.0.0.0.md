# v1.0.0.0 - Initial Release

The deep-loop family now follows the parent-skill pattern with one invokable hub and one advisor identity. The hub is routing-only, and the loop logic lives in nested mode packets.

> Spec folder: `.opencode/specs/skilled-agent-orchestration/155-parent-skill-native-invocability/002-deep-loop-alignment` (Level 3)

## What's New at a Glance

- **Four modes sit behind the hub.** The hub's `SKILL.md` now carries the smart-routing contract, so invoking `Skill(deep-loop-workflows)` loads the hub. Its router reads the request and loads a matching mode packet. The active modes are `deep-research`, `deep-review`, `deep-ai-council` and `deep-improvement`. Each is registered in `mode-registry.json` and holds its loop logic behind the hub's single `graph-metadata.json` identity.

## Upgrade

No migration required. The `/deep:*` commands and the deep agents keep working unchanged.
