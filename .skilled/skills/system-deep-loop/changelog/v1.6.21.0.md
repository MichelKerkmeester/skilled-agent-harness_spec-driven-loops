# v1.6.21.0, Hub Docs Read in Order

The hub's `SKILL.md`, `ROUTER.md`, `README.md` and its `shared/` behavior-benchmark and rollout docs were read file by file for readability, layout and structure. No mode, command, convergence threshold or routing decision changed.

> Spec folder: `specs/sk-doc/066-skill-readability-refinement/011-system-deep-loop` (Level 1)

&nbsp;

## What's New at a Glance

- **The router reads in the order it runs.** `ROUTER.md` lists the path guard, the fallback and the mode-hint rules as one indented block under the routing steps, and the note on the `allowed-tools` grant follows them instead of opening the section.
- **The behavior-benchmark framework numbers its sections.** Its eleven unnumbered headings carry integer numbers, Purpose became the Overview, Schema Versioning is a subsection of the scenario contract schema it governs, and Delegation Evidence Kinds moves ahead of the scoring rubric that scores it.
- **The rollout promotion rule has an overview.** It gains numbered Overview, Promotion Evidence, Evidence Mechanism and Validation sections, and its README's "Deferred TODOs" reads "Deferred Scope".
- **The README puts the how-to before the links.** Adding a Workflow Mode now comes before Related Documents.
- **Section names stay as cited.** Other files cite these sections by name, never by number, and every cited name still heads its section.
