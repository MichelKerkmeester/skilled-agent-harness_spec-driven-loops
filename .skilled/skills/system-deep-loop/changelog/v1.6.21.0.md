# v1.6.21.0, Hub Docs Read in Order

The hub's `SKILL.md`, `ROUTER.md` and `README.md` were read file by file. So were its `shared/` behavior-benchmark and rollout docs. The reading checked readability, layout and structure. No mode, command, convergence threshold or routing decision changed.

&nbsp;

## What's New at a Glance

- **The router reads in the order it runs.** `ROUTER.md` lists the path guard, the fallback and the mode-hint rules. They sit as one indented block under the routing steps. The note on the `allowed-tools` grant follows them. It does not open the section.
- **The behavior-benchmark framework numbers its sections.** Its eleven unnumbered headings carry integer numbers. Purpose became the Overview. Schema Versioning is a subsection of the scenario contract schema it governs. Delegation Evidence Kinds moves ahead of the scoring rubric that scores it.
- **The rollout promotion rule has an overview.** It gains numbered Overview, Promotion Evidence, Evidence Mechanism and Validation sections. Its README's "Deferred TODOs" reads "Deferred Scope".
- **The README puts the how-to before the links.** Adding a Workflow Mode now comes before Related Documents.
- **Section names stay as cited.** Other files cite these sections by name, never by number. Every cited name still heads its section.
