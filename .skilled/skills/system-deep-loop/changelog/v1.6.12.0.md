# v1.6.12.0, The Behavior Benchmark Cannot Hang on git status

The behavior benchmark runs `git status` before and after each run to prove the run left the repository alone. A stuck git fsmonitor daemon could leave that call waiting forever, and a call that failed outright counted as a clean repository. Both gaps are closed.

> Spec folder: `specs/sk-git/035-fsmonitor-daemon-and-worktree-relocation-regression` (Level 2)

&nbsp;

## What's New at a Glance

- **The status call has a 20-second ceiling.** It also runs with `core.fsmonitor=false`, so it reads the repository without asking the daemon at all.
- **A missing answer is no longer a pass.** When `git status` cannot answer, the run records an isolation violation that says the check could not be made, instead of reporting no changes.
