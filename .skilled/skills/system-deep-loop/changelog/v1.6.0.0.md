The `agent-improvement` and `model-benchmark` modes are removed, with the `deep-improvement` packet and agent, both `/deep` commands and the runtime lane libraries they ran on. The hub now routes three modes: `research`, `review` and `ai-council`. The agent mirror checker moved to `.skilled/bin/check-agent-mirror-sync.cjs`.

## What's New at a Glance

- **The improvement modes are gone.** `agent-improvement` and `model-benchmark` leave the mode registry, so `system-deep-loop` routes `research`, `review` and `ai-council`.
- **The packet, agent and commands are gone.** The `deep-improvement/` packet, the `deep-improvement` agent and the `/deep:agent-improvement` and `/deep:model-benchmark` commands no longer exist in any runtime.
- **The runtime lane libraries are gone.** The mode-specific ledger, reducer and sealed-artifact libraries and their tests were deleted, and the shared runtime serves the three remaining modes.
- **The agent mirror checker moved.** `check-agent-mirror-sync.cjs` now lives at `.skilled/bin/check-agent-mirror-sync.cjs`, outside the deleted packet.

## Upgrade

`/deep:agent-improvement` and `/deep:model-benchmark` no longer exist. Agent evaluation and model benchmarking have no in-repo replacement. Old spec packets that hold `improvement/` artifact folders are history and need no action.
