# v1.6.7.0, Fan-Out Reviews Skip the Root Resource Map

A deep review that fans out across several lineages ran the resource-map reducer at the root, where no state log exists until closeout writes it, so the step failed on a missing file. Both review workflows now skip that step at a fan-out root, and a single-lineage run still emits its map as before.

> Spec folder: `specs/system-speckit/054-weak-model-spec-authoring` (a phased packet)

&nbsp;

## What's New at a Glance

- **The report names the maps that exist.** A fan-out report points at `{artifact_dir}/lineages/*/resource-map.md`, the map each lineage already writes.
- **Auto and confirm runs behave the same.** The skip sits on the same step in both workflows and is keyed on the fan-out setting, which a lineage never carries.
- **Compiled contracts match their sources.** The deep-review, deep-research and deep-ai-council contracts were recompiled, so their source digests match the edited workflows.
