# v1.6.7.0, Fan-Out Reviews Skip the Root Resource Map

A deep review fans out across several lineages. It ran the resource-map reducer at the root. No state log exists there until closeout writes it. So the step failed on a missing file. Both review workflows now skip that step at a fan-out root. A single-lineage run still emits its map as before.

> Spec folder: `specs/system-speckit/054-weak-model-spec-authoring` (a phased packet)

&nbsp;

## What's New at a Glance

- **The report names the maps that exist.** A fan-out report points at `{artifact_dir}/lineages/*/resource-map.md`. That is the map each lineage already writes.
- **Auto and confirm runs behave the same.** The skip sits on the same step in both workflows. It is keyed on the fan-out setting. A lineage never carries that setting.
- **Compiled contracts match their sources.** The deep-review, deep-research and deep-ai-council contracts were recompiled. So their source digests match the edited workflows.
