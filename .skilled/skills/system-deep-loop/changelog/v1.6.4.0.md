# v1.6.4.0, The Deep Commands Bind Their Input First

The three deep commands put their input gate inside section 1, and `/deep:research` told the agent to load its workflow before the gate ran. Each command now binds its input before anything else, the position every other command uses.

> Spec folder: `specs/sk-git/033-git-setup-customization/009-second-review-remediation` (Level 2)

&nbsp;

## What's New at a Glance

- **The gate comes first.** `/deep:research`, `/deep:review` and `/deep:ai-council` bind their input after the title and purpose line, before section 1.
- **No early workflow load.** `/deep:research` no longer loads its workflow file before its setup inputs are bound.
