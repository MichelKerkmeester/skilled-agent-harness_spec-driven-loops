# v2.1.4.0, Divergent Pivots Get One Quorum Retry

A divergent pivot ended on its first quorum miss. One missed seat could end the pivot. A pivot now gets one retry before it stops.

&nbsp;

## What's New at a Glance

- `maxCouncilSeatOutputs` now means three per council attempt.
- A first-attempt quorum miss gets one retry.
- A second miss still ends the pivot. No third attempt opens.
- A later pivot is no longer refused because earlier pivots used seats.
- A run uses at most 18 seat outputs. That is three pivots with six seats each.
- Research and review pivots follow the same rule.

&nbsp;

## How It Was Checked

Eleven new cases cover the seat budget, the retry and the attempt identity. The divergent pivot suites pass. Attempt 1 keeps its existing paths and event ids.

&nbsp;

## Upgrade

No migration required. Pivots written before this change still load. A first-attempt quorum miss now runs one more council round.
