# v2.1.1.0, Source Diversity Reads Derived Source Classes

Source diversity could not score real classes, because no producer set `quality_class`. Research SOURCE nodes now get a class when they are stored. The diversity signal reads what the sources are.

&nbsp;

## What's New at a Glance

- **Research sources are classified when stored.** `upsert.cjs` sets `quality_class` on each research SOURCE node from its path first, then its label, then its id. A value the leaf supplies is overwritten.
- **Source diversity has real values on normal runs.** The signal counts the distinct classes a question's findings cite. It no longer moves only on fixtures that typed a class in.
- **A code-only question still blocks.** A question answered only from code files scores 1.0 and stops at `source_diversity_guard`, by design. Code plus its tests scores 2.0 and passes.
- **The threshold is unchanged.** The 1.5 threshold and the averaging rule did not change.

&nbsp;

## Upgrade

No migration required.
