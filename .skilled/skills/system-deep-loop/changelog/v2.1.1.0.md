# v2.1.1.0, Source Diversity Reads Derived Source Classes

Source diversity could not score real classes, because no producer set `quality_class`. Research SOURCE nodes now get a class when they are stored. The diversity signal reads what the sources are.

&nbsp;

## What's New at a Glance

- Research sources are classified when stored. `upsert.cjs` sets `quality_class` on each SOURCE node from its path, name, label or id, in that order. A value the leaf supplies is overwritten.
- Source diversity reads real classes on normal runs. The signal counts the distinct classes a question's findings cite, not only fixtures that type a class in.
- A code-only question still blocks. It scores 1.0 and stops at `source_diversity_guard`. Code plus its tests scores 2.0 and passes.
- The threshold stays at 1.5, with the same averaging rule.

&nbsp;

## Upgrade

No migration required.
