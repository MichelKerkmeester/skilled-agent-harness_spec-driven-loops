# v1.17.0.0, Repo-Wide Agent-Mirror-Sync Gate

Before this release, mirror sync ran only during a deep-improvement promotion, so edits to agents by other paths could leave runtime copies out of sync until production routing behaved differently across runtimes. This release folds the deep-improvement slice of the packet 146 ponytail-based refinement into the agent-mirror surface. This release moves the check to every commit and pull request, makes the normalizer accurate enough for that scope and clears the real drift it found.

> Spec folder: `.opencode/specs/skilled-agent-orchestration/142-sk-code-ponytail-based-refinement` (Level 2)

## What's New at a Glance

- **The mirror check now runs on every commit and pull request.** Every agent is authored once under `.opencode/agents/<name>.md` as the canonical body and mirrored to `.claude/agents/<name>.md` and `.codex/agents/<name>.toml`. A new `scripts/check-agent-mirror-sync.cjs` wraps the existing `verifyMirrorSync` library as a gate over the changed agent files, or over every agent with `--all`. It fails when an agent's mirrors drift from the canonical body, including a deleted mirror or a deleted canonical whose runtime copies still linger. `.opencode/hooks/git/pre-commit` runs it over added, modified and deleted agent paths, and a new `.github/workflows/agent-mirror-sync.yml` runs it on pull requests and fails closed if the checker is ever removed. The deep-improvement README surfaces the gate in its Integration Scan section.
- **Legitimate runtime-specific wording no longer triggers mirror drift.** The old normalizer counted each mirror's self-description clause as body drift and false-flagged healthy mirrors, while a blanket collapse of every bare `.md` and `.toml` extension token could mask a real format-extension mismatch. The normalizer now strips the self-description clause and normalizes only the runtime agent-file paths, so a mirror's reference to its own `.codex/agents/<name>.toml` no longer reads as drift, and the blanket collapse is gone. The fix removes only those known shapes, so real body drift, including a genuine format-extension mismatch, is still caught.
- **All twelve agents now report in sync.** The `context` Codex mirror's dropped Tool-Inventory row is restored to match the canonical body, and the `orchestrate` false positive clears with the normalizer change.

## Upgrade

No migration required. The gate is additive. It runs against changed agent files at commit time and against the full set in CI, and it only fails when a mirror genuinely diverges from its `.opencode` canonical. Run `node .opencode/skills/deep-loop-workflows/deep-improvement/scripts/check-agent-mirror-sync.cjs --all` to verify all mirrors locally.
