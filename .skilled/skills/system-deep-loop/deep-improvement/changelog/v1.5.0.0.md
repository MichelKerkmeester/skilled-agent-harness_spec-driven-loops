# v1.5.0.0, Agent Rename: `@improve-agent` to `@deep-improvement`

v1.5.0.0 aligns the skill and agent names within the deep-improvement family.

> Spec folder: `specs/skilled-agent-orchestration/087-improve-agent-to-deep-improvement-rename`

## Why This Release

On 2026-05-06, packet 079 at `specs/skilled-agent-orchestration/z_archive/079-sk-deep-improvement/` renamed the skill folder `sk-improve-agent` to `deep-improvement` but kept `@improve-agent` stable. It followed the `070-sk-deep-rename` precedent that agents already used modern non-`sk-` names. That left the skill and agent with different names, so this release completes the alignment. The direct precedent was the sister agent rename in `specs/skilled-agent-orchestration/085-sk-prompt-testing-playbook-and-agent-rename/001-prompt-improver-rename/`.

## What's New at a Glance

- **The agent name is now `@deep-improvement`.** It matches the `deep-improvement` skill.
- **The YAML asset names follow the new target identity.** The auto and confirm assets use updated paths.
- **The slash command stays `/deep:agent-improvement`.** It needs no migration.

---

## Agent Identity

#### The Agent Name Aligns

The skill is `deep-improvement` under `.opencode/skills/`. The agent name changes from `@improve-agent` to `@deep-improvement` across the `.opencode/`, `.claude/` and `.codex/` runtime files, with each agent file's frontmatter `name:` field updated.

&nbsp;

#### The Slash Command Stays Stable

`/deep:agent-improvement` is unchanged because `agent` is a generic sub-name, parallel to `/prompt`. There is no behavior change, dispatcher contract change or skill change.

---

## Reference Migration

#### Active References Use the New Name

**Breaking:** External scripts that hardcode `@improve-agent` need their agent dispatch references updated. The new agent identity is `@deep-improvement`. The rename modified ~30 active reference files (~54 references).

&nbsp;

#### YAML Assets Follow the Target

The YAML asset filename pattern is `improve_<TARGET>_<MODE>.yaml`. The auto and confirm YAML assets were renamed in both the `.opencode/commands/deep/assets/` and `.claude/commands/deep/assets/` trees to track the new target identity.

&nbsp;

#### Historical References Stay Verbatim

Historical changelog narrative for v1.0.0.0 through v1.4.0.0 stays verbatim, while `@improve-agent` mentions in active prose were migrated. Research artifacts in `specs/z_archive/` include ~189 historical references that stay verbatim under the historical-record policy, and `barter/coder/` handles propagation in its external repository.
