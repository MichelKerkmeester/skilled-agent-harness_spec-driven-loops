# v1.4.0.0, Skill Rename to deep-improvement

This release renames the skill from `sk-improve-agent` to `deep-improvement`.

## Why This Release

The rename brings the skill folder, identity, metadata and active documentation under the `deep-*` naming convention.

## What's New at a Glance

- **The skill name changes to `deep-improvement`.** Its references and install guidance use the renamed skill.
- **The command surfaces keep `/deep:agent-improvement`.** The command surfaces span three runtimes.
- **The agent skill matrices keep `@improve-agent`.** They point to `deep-improvement`, while the separate agent rename is documented in v1.5.0.0.

---

## Skill Identity

#### One Name Across the Skill

The skill folder moved from `.opencode/skill/sk-improve-agent/` in the then-current singular OpenCode layout to `.opencode/skill/deep-improvement/`. The later plural-layout migration moved it to `.opencode/skills/deep-loop-workflows/deep-improvement/`.

The skill frontmatter, trigger phrases, key files and derived entities now use `deep-improvement`. Skill advisor routing and scoring references target the new skill name. Top-level references describe the new skill name and path, and installation and packaging instructions install `deep-improvement`.

This rename follows the sister rename in `specs/skilled-agent-orchestration/070-sk-deep-rename/`, which moved `sk-deep-review` and `sk-deep-research` to `deep-review` and `deep-research`.

---

## Commands and Agents

#### Command Path Stays Put

OpenCode/Copilot, Claude and Codex command surfaces keep `/deep:agent-improvement`. Their routing references point to the new skill path.

&nbsp;

#### Agent Rename Comes Later

OpenCode/Copilot, Claude and Codex agent skill-matrix lines keep the then-current `@improve-agent` identity while pointing to `deep-improvement`. Git history around the rename shows the pre-v1.5 family still using `sk-improve-agent` in changelog/docs commits, and the later v1.5 packet completes the separate `@improve-agent` agent rename. Agent identity migration is documented separately in v1.5.0.0.

## Upgrade Notes

- **Breaking:** The old `sk-improve-agent` skill name no longer resolves. Use `.opencode/skills/deep-loop-workflows/deep-improvement/` for current skill files, references, assets, scripts, feature catalog entries and manual testing playbooks.
