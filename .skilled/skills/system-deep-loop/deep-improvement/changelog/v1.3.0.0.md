Before this release, the only way to understand what `deep-improvement` did was to read `SKILL.md` or the source files. This release adds a feature catalog so you can see what its evaluation stack does without reading source code.

> Spec folder: `.opencode/specs/system-spec-kit/026-graph-and-context-optimization/011-skill-advisor-graph/008-deep-skill-feature-catalogs/` (Level 3)

## What's New at a Glance

- **The catalog maps `deep-improvement`.** Its file at `.opencode/skills/deep-loop-workflows/deep-improvement/feature-catalog/feature-catalog.md` groups 13 features into 3 areas. Each feature has its own file with an overview, what the code does today and a pointer to its source.
- **The evaluation loop is mapped.** It covers setup, candidate generation, integration-aware evaluation, promotion gate and rollback path.
- **Integration scanning is mapped.** It covers cross-surface dependency discovery, contract scan and runtime-signal capture.
- **The scoring system is mapped.** It covers a 5-dimension rubric, score aggregation, margin computation, threshold gates and deterministic replay.
- **The skill README points to the catalog.** It is the first place to look when you want to understand the evaluation stack.

## Upgrade

No migration required. The catalog is documentation only, and runtime behavior is unchanged.
