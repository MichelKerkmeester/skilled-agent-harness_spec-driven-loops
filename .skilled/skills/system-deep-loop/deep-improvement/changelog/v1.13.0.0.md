The `model-benchmark` change places benchmark evidence with the model registry it measures.

> Spec folder: `.opencode/specs/skilled-agent-orchestration/131-registry-benchmark-consolidation/`

## What's New at a Glance

- **`model-benchmark` outputs now go to the hub.** Benchmark run data, results and synthesis go to `sk-prompt-models/benchmarks/{run_label}` under the skills root, with no spec-local fallback or override. Agent-improvement, skill-benchmark and all other deep-improvement modes keep their spec-local output paths.

## Upgrade

No migration required. Previously written spec-local benchmark outputs remain where they are. The routing change applies only to new `model-benchmark` invocations going forward. The `{run_label}` value comes from the benchmark profile or command argument, unchanged.
