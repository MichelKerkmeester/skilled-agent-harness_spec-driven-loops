Across Phases 009–011, the `deep-improvement` workflow received changes to its command path, reducer behavior, agent definition, skill advisor routing and README guidance.

> Spec folder: `.opencode/specs/skilled-agent-orchestration/041-sk-recursive-agent-loop`

## Why This Release

The goal is to make the workflow easier to follow and easier to trust.

## What's New at a Glance

- **`agent-improver.md` now uses `/deep:agent-improvement`.** This replaces the path to a command that did not exist.
- **Phase 010 fixed four reducer issues.** The dashboard now shows profile families and counts accepted recommendations.
- **The plateau window is now configurable.** Short runs can use a window of 2.
- **Six candidate improvements were promoted.** They cover missing inputs, checklists, validation, anti-patterns and reporting.
- **Skill advisor routing now covers 5D scoring and integration scanning.** It also covers dynamic profiling and all `/deep:` and `/create:` slash commands.
- **README guidance was updated across skill and command surfaces.** The updates cover agent names and command references.

---

## Deep Improvement Workflow

#### Command Paths Resolve

Phase 010 changed the stale `/deep:agent-improvement-improver` path in the canonical `agent-improver.md`. It now resolves to `.opencode/commands/deep/agent-improvement.md`. The corrected path was synced to all 3 mirrors.

&nbsp;

#### Dashboard Counts Match Profiles

The dashboard no longer labels every profile `session-handover`. `agent-improver` appears under its own name. It also counts `candidate-acceptable` and `candidate-better` recommendations as accepted, where the count previously showed 0.

&nbsp;

#### Short Runs Choose a Window

The detector reads `stopRules.plateauWindow` from configuration. Before the setting was introduced, the window was hardcoded to 3.

&nbsp;

#### Promoted Agent Improvements

Phase 010 promoted these changes to the agent definition:

- A halt condition for missing inputs.
- Merged checklists.
- Checkbox self-validation.
- A fourth anti-pattern.
- A scan report provenance note.
- An updated summary box label.

---

## Routing and Documentation

#### Advisor Covers More Workflows

Phase 011 updated skill advisor routing for 5D scoring, integration scanning and dynamic profiling. It also added routing for every `/deep:` and `/create:` slash command. The update added 7 `INTENT_BOOSTERS`, 13 `PHRASE_INTENT_BOOSTERS` and 8 `COMMAND_BRIDGES`.

&nbsp;

#### READMEs Reflect the Changes

The skill README was bumped to v1.0.0.0. The root README added Context-Prime and Agent-Improver to the Agent Network and rewrote the Improve Agent command description.

Five command `README.txt` files were fixed. They added the improve group and changelog, fixed command counts, added the deep-review command and moved the prompt from create to improve.

## Upgrade Notes

No upgrade needed. Existing runtime configs without `plateauWindow` continue working identically because the default is 3, the same as the previous hardcoded value.
