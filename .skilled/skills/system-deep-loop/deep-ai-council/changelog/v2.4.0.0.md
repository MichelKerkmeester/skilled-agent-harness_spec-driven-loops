# v2.4.0.0, Mode Packet Renamed to deep-ai-council

The `ai-council` mode packet folder is renamed to `deep-ai-council` to match the `SKILL.md` name and the convention followed by the rest of the deep-loop family. That match is the invariant `package_skill.py --check` enforces. The rename is structural only and preserves the workflow mode, command, agent and artifact root.

> Spec folder: `.opencode/specs/skilled-agent-orchestration/155-parent-skill-native-invocability/002-deep-loop-alignment` (Level 3)

## What's New at a Glance

- **The packet folder moves to `deep-loop-workflows/deep-ai-council/`.** The former path was `deep-loop-workflows/ai-council/`. The `workflowMode` key, `/deep:ai-council` command, `@ai-council` agent and `<packet>/ai-council/` artifact root are unchanged. Only the skill packet path changed, so no command, agent or stored-artifact path breaks.

No migration required.
