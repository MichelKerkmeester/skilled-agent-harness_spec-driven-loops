This release aligns the council's OpenCode examples with supported model routes and restores coverage for the current Pi runner behavior.

> Spec folder: `specs/cli-external-orchestration/077-gpt-6-luna-sol-cutover` (Level 2)

## What's New at a Glance

- **MiMo examples use its available route.** The skill and seat-diversity patterns use `llmgateway/mimo-v2.6-pro` because cli-opencode reaches MiMo through LLM Gateway and no longer carries the `xiaomi/` route.
- **The OpenCode bench names the supported provider mix.** It now lists direct DeepSeek and OpenAI models plus MiMo through LLM Gateway.
- **Pi runs use the current roster default.** The session CLI runner test dispatches Pi with `llmgateway/deepseek-v4.1-flash`, replacing retired `deepseek-v4-flash`.
- **stdin checks follow builder output.** The runner writes whatever the shared builder returns, and cli-pi returns an empty string that closes stdin. The old assertion expected no stdin write for every seat except Hermes. It now follows the builder, and the suite passes 21 of 21.
