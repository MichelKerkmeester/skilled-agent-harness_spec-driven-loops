v2.0.0.0 adds deep mode, iterative multi-topic council deliberation through `/deep:ai-council`.

## Why This Release

This release supersedes v1.3.0.0, which renamed the skill. It follows v1.0 through v1.2, the single-round council era.

## What's New at a Glance

- **`/deep:ai-council` has two modes.** The command is wired with `:auto` and `:confirm`.
- **The runtime-agent contract is mirrored across the agent surfaces.** It covers OpenCode, Claude and Codex.
- **Single-round `ai-council` behavior is preserved as deep mode is added.** The new `/deep:ai-council` path does not replace existing `ai-council` usage.

---

## Deep AI Council

#### Bounded Topic Rounds

Deep mode uses the packet 129 state hierarchy: a session, then topics, then rounds. Each topic runs bounded council rounds and stops on adjudicator-verdict stability, max rounds or failure conditions. The session reducer writes `deep-ai-council-findings-registry.json`, and later topics receive compact cross-topic priors by registry fingerprint.

&nbsp;

#### Default Cost Guards

Default cost guards remain conservative:

- `max_rounds_per_topic = 3`
- `max_topics_per_session = 5`
- `saturation_threshold = 0.20`
- `seats_per_round = 3`
