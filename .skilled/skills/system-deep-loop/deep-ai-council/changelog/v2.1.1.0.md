# v2.1.1.0: Deep-Mode Docs + Script Tests

After the v2.1.0.0 release cleanup, this follow-on closes the five follow-ons deferred by the 004 phase-5 deep-research loop. Documentation and tests are the only changes, so deep-mode runtime and script logic did not change and there are no backward-incompatible changes.

> Spec folder: `116-deep-skill-evolution/000-release-cleanup/004-deep-ai-council/001-deep-mode-docs-and-tests`

## What's New at a Glance

- **The deep-mode session hierarchy now has a guide.** `references/deep-mode.md` describes the session-to-topic-to-round hierarchy, the `session-state.jsonl` and `round-state.jsonl` state files, cost guards and the `deep-loop-runtime/lib/council/` dependency.
- **The findings registry now has a guide.** `references/findings-registry.md` documents the cross-topic schema, fingerprint-based deduplication, cross-topic priors and filesystem locking.
- **The new guides are wired into the skill.** `SKILL.md` moves from version `2.1.0.0` to `2.1.1.0` and adds both references to RESOURCE_MAP and REFERENCES. `README.md` links them from RELATED DOCUMENTS, and the router pseudocode did not change.
- **Recovery guidance now links graph replay.** `references/graph-support.md` connects `replay-graph-from-artifacts.cjs` with its derivation in the recovery path and cross-references.
- **The DAC-001 rename note now matches the names.** Agent files use `ai-council.*` under the `@ai-council` identity after the `deep-` prefix dropped in v1.2.0.0. The skill keeps the `deep-ai-council` name.
- **Five previously untested scripts now have coverage.** The full `vitest run` is deferred to the project's standard test invocation because the skill's `scripts/` has no local vitest config. The existing `.vitest.ts` tests share this setup.
