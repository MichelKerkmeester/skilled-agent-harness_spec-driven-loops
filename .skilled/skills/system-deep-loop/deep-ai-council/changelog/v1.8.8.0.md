# v1.8.8.0, The Council Artifact Folders Read as Runtime Output

The persist steps and the audit-trail answer name two folders that exist only after a council run: the per-seat proposals under `seats/round-NNN/`, and the archive a failed round moves into under `failed/`. The reference check read both as paths in this skill folder, found none, and failed the README.

Both names stay, because they are the layout a reader will see inside their packet's `ai-council/` tree. The README now declares each one in its `readme-check` block with the reason that the persist helper and the round rollback create them under a packet, never in this repository. Nothing is deleted and nothing is rewritten, exactly as before.
