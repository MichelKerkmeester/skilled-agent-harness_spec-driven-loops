# v1.8.7.0, Long Prose Lines Become Short Sentences and Lists

The two opening paragraphs of the operational-modes section were each written as one very long line. The first sorted out what an in-CLI round is, which models the active runtime can seat and why no external dispatch is needed. The second sorted out when external dispatch helps, which executors the resolver accepts and where that dispatch is invoked from.

Both are now short sentences. The model bench, which was a bracket of three runtimes in one sentence, is now a short list with one runtime per line. Instructions address you directly, and the instruction comes before the background.

The content did not change. Every runtime name, model name, executor name and alias in the old lines is still there, and the rewrite adds nothing new. What selects this skill, what it loads first and how a request routes are all exactly as they were.

## What's New at a Glance

- **The in-CLI case reads as four lines.** What the council is, what it seats when invoked inside a runtime, why the common case needs no external dispatch and what supplies seat diversity.
- **The model bench is a list.** Claude Code, OpenCode and LLM Gateway each get their own line instead of one bracketed sentence.
- **The external-CLI case reads as three lines.** When it helps, which executors the resolver accepts and rejects, and where that dispatch is invoked from.
- **Every fact is the same.** No executor name, model name, alias or routing signal changed, so a request routes where it always did.
