# v1.3.0.0, Council Skill Returns to the deep-* Family

v1.3.0.0 renames the council skill package so it can rejoin the `deep-*` family.

## Why This Release

The council skill rejoins `deep-review`, `deep-research`, `deep-agent-improvement` and `deep-loop-runtime` following the 130 research verdict and user intent. This is a point-release in the v1.x single-round-council era because the skill package is renamed without changing the runtime model.

## What's New at a Glance

- **The skill folder moved into the `deep-*` family.** Its new path is `.opencode/skills/deep-loop-workflows/deep-ai-council/`, replacing `.opencode/skills/sk-ai-council/`. v1.2.x shipped under `sk-ai-council`, following the original `deep-ai-council` single-round council lineage in v1.0..v1.1 before the 114/115 rename wave.
- **Internal references and package metadata were updated.** The frontmatter now sets `name: deep-ai-council` and `version: 1.3.0.0`, and internal skill references across the package were updated.
- **The runtime agent slug remains `ai-council`.** This packet is skill-folder-only, and agent identity is already decoupled from the skill folder slug.

## Upgrade

No migration required.
