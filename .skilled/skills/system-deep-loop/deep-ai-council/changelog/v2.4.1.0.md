# v2.4.1.0 - README rewritten purpose-first

The deep-ai-council README now meets the refined skill README standard. It opens with a one-line pitch and a problem-first overview, then carries every council fact in the narrative voice: the round flow, the six strategy lenses, the three critique roles, the two-of-three convergence rule, the artifact tree and the command surface. The rewrite clears the measured HVR drift (two semicolons and nine Oxford comma patterns in the old text) and adds a capability table for the six lenses so a reader sees what each lens applies before reading the workflow details.

## What Changed

#### README voice and structure

The old README passed the validator floor but carried reference-card residue: two semicolons, nine comma-plus-and or comma-plus-or patterns and a tabular tone in the long FAQ, troubleshooting and integration sections. The rewrite keeps every real fact and presents it purpose-first on the refined template, with the mcp-obsidian pilot as the exemplar. The six lenses move into a capability table inside HOW IT WORKS. The task-type lens mapping becomes a two-row table. The critique roles become a bullet list. All commands, expected outputs and reference links carry over unchanged.

#### Version and changelog

The `version:` field bumps from 2.4.0.0 to 2.4.1.0 and this entry records the release per the folder convention. The SKILL.md version stays put because no runtime behavior changed.
