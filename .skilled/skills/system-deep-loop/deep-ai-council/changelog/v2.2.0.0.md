Version 2.2.0.0 aligns `deep-ai-council` with the shared deep-skill resource model while preserving its planning-only domain. It adds a council-specific quick reference, loop protocol and runtime asset family. No runtime script or workflow behavior changed.

## Why This Release

Operators can use the same resource shape as `deep-research` and `deep-review` without copy-pasting their loop vocabulary.

---

## What's New at a Glance

- **Council guidance now covers first-touch use and the full workflow.** A quick reference and loop protocol serve those two stages.
- **The runtime asset family now includes council templates.** The set covers configuration, strategy, status, seat prompts and runtime parity.
- **The skill and README reflect the new resource family.** The skill's resource-loading guidance includes the references and assets, while the README's structure and navigation were updated.

---

## Council Guidance

#### First-Touch and Workflow Guidance

`references/quick-reference.md` adds a sk-doc-shaped guide to commands, the artifact map, stop conditions, validation and sibling-skill routing boundaries. `references/loop-protocol.md` covers packet resolution, seat setup, critique, convergence, persistence, handoff and recovery.

---

## Runtime Assets

#### Configuration and Convergence

`assets/deep-ai-council-config.json` is the run-config template. Its convergence signal now uses `two-of-three-agree`, the canonical value used by runtime persistence and reference docs.

&nbsp;

#### Strategy and Dashboard

`assets/deep-ai-council-strategy.md` is the round strategy template. `assets/deep-ai-council-dashboard.md` is the status dashboard template.

&nbsp;

#### Seat Prompts and Parity Matrix

`assets/prompt_pack_round.md.tmpl` is the council-seat prompt-pack template. `assets/runtime-capabilities.json` is the runtime parity and validation matrix.

## Skill Documentation

#### Guarded Resource Discovery

The `SKILL.md` resource domains now discover markdown references and markdown assets through the same guarded router pattern used by sibling deep skills. `SKILL.md` is version `2.2.0.0`, with the reference and asset family wired into its resource-loading guidance.
