# v1.12.0.0, Custom Review Dimensions Are Supported

A review can now name its own dimensions, such as performance. Before this, a custom name was never marked covered. So the review could never reach its clean stop. Setup now accepts custom names. The loop tracks and covers them, and the review prompt lists them. Runs with only the four canonical dimensions are unchanged.

&nbsp;

## What's New at a Glance

- Custom dimensions such as performance now reach the clean stop.
- Setup accepts custom names after the four canonical ones.
- Custom dimensions keep their configured order after the canonical four.
- A finding can name a custom dimension.
- Canonical-only runs keep the same registry, dashboard and verdict.

&nbsp;

## Upgrade

No migration required. To review a custom dimension, add its name to `review_dimensions`, such as `correctness,performance`. A custom dimension applies to a single-executor run only, because a fan-out run binds `review_dimensions: all` in every lineage.
