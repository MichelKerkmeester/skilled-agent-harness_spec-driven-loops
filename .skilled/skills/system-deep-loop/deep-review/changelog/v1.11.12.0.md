# v1.11.12.0, Long Prose Lines Become Short Sentences and Lists

Several paragraphs in the deep-review skill were written as one very long line each. A reader had to untangle four or five rules out of a single sentence, and the same held for the reference list, the completion conditions and the quality gates.

Those lines are now short sentences, and a line that listed several rules or steps is now a short list. The instruction comes before the background, and instructions address you directly.

The content did not change. Every file path, resource name, command, field and number in the old lines is still there, and the rewrite adds nothing new. What selects this skill, what it loads first and how a request routes are all exactly as they were.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/010-prose-clarity-pass` (Level 2)

&nbsp;

## What's New at a Glance

- **The resource map gate reads as steps.** The four things deep review does with a resource map, and the one flag that turns it off, are now a list.
- **The context snapshot reads as what it holds.** Target pointers, claimed behavior, convention pointers and risk areas each get their own line.
- **The severity and reach rules are split.** The three-tier scale, the out-of-scale conversion and the trust-boundary case no longer share one sentence.
- **The completion conditions are a checklist.** The composite stop score, dimension coverage, state files, report sections and the continuity save each stand alone.
- **The nine quality gates are numbered.** The security-sensitive override follows them as its own short paragraph.
- **Every fact is the same.** No routing signal, resource path, loading level or command changed, so a request routes where it always did.

## Upgrade

No migration required. Nothing that pointed at a section or a resource of this skill needs to change.
