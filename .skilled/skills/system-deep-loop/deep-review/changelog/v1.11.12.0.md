# v1.11.12.0, Long Prose Lines Become Short Sentences and Lists

Several paragraphs in the deep-review skill were one very long line each. A reader had to untangle four or five rules from a single sentence. The same held for the reference list. So did the completion conditions. So did the quality gates.

Those lines are now short sentences. A line that listed several rules or steps is now a short list. The instruction comes before the background. Instructions address you directly.

The content did not change. Every file path, resource name, command, field and number is still there. The rewrite adds nothing new. What selects this skill is exactly as it was. So is what it loads first. So is how a request routes.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/010-prose-clarity-pass` (Level 2)

&nbsp;

## What's New at a Glance

- **The resource map gate reads as steps.** Deep review does four things with a resource map. One flag turns it off. Those four things and that flag are now a list.
- **The context snapshot reads as what it holds.** The snapshot holds target pointers and claimed behavior. It also holds convention pointers and risk areas. Each gets its own line.
- **The severity and reach rules are split.** The three-tier scale and the out-of-scale conversion no longer share one sentence. Neither does the trust-boundary case.
- **The completion conditions are a checklist.** The composite stop score and dimension coverage each stand alone. So do state files and report sections. So does the continuity save.
- **The nine quality gates are numbered.** The security-sensitive override follows them as its own short paragraph.
- **Every fact is the same.** No routing signal, resource path, loading level or command changed. So a request routes where it always did.

No migration required. Nothing that pointed at a section or a resource of this skill needs to change.
