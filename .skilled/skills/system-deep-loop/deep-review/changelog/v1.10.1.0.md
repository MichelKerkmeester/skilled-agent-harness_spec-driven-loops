# v1.10.1.0: Reference And Asset Alignment

This release aligns `deep-review` with the shared deep-skill reference model through focused convergence and state-output references while moving the version from `1.10.0.0` to `1.10.1.0`. Loop behavior is unchanged: `/deep:review` still owns state, dispatch, reducer updates, convergence checks and synthesis. No runtime YAML, reducer, script, command or agent behavior changed.

> Spec folder: `.opencode/specs/skilled-agent-orchestration/116-deep-skill-evolution/000-release-cleanup/001-deep-loop-runtime/003-reference-asset-alignment/` (Level 3)

## What's New at a Glance

- **The focused references follow the deep-skill shape.** They do not import research or council vocabulary. `references/convergence.md` and `references/state-format.md` remain hubs, with narrower files for operator navigation.
- **Reference topics now have dedicated pages.** `references/convergence-signals.md` covers severity-weighted STOP signals, P0 override, legal stop and sibling threshold contrast. `references/state-outputs.md` covers packet outputs, iteration markdown, dashboard, final report and resource-map behavior. `references/state-reducer-registry.md` covers reducer ownership, registry semantics, fail-closed behavior and reconstruction.
- **The focused references are loaded for named review flows.** `SKILL.md` routing loads them for setup, iteration, convergence, synthesis, stuck and on-demand flows. README structure and related documents list the focused references.
- **No new review assets were required.** Existing config, strategy, dashboard, prompt-pack, review contract and runtime capability assets remain canonical.
