# v1.11.0.37: Residue Flagger Measurement

deep-review gains `score-residue-flagger.cjs`, an offline residue-flagger measurement census over the finding tables in committed review documents. Version `1.11.0.36` becomes `1.11.0.37` with a default run that spawns no backend call and writes no file, and with `--jev` and `--deem` to run one backend each behind its own gate.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/033-validator-residue-flagger` (Level 1)

## What's New at a Glance

- **The default run is a census and nothing else.** `score-residue-flagger.cjs` counts the finding rows in the review documents committed at HEAD under `specs/` and prints `census:`, `severity`, `dimension`, `header` and `resolvable` lines. It spawns no backend call and writes no file.
- **`--jev` and `--deem` each run one arm behind its own gate.** Both need `--out <dir>` so every call is recorded, and without it the run exits 2 before any call. A gate that fails prints its skip line, like `jev arm skipped: no credential` or `deem arm skipped: stub backend`, and every other line is unchanged.
- **The arms wait for 100 labeled rows.** `--draw --seed <n>` writes 100 rows into `residue-flagger-labels.jsonl` for the operator to label, and `--labels <file>` names another file. The draw needs 25 resolvable rows per category and exits 2 naming any shortfall. Until 100 rows carry a label the run prints `stop: fewer than 100 labeled rows` and starts no arm.
