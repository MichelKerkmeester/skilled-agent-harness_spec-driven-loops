# v1.11.15.0, a 24-Call Iteration Budget Rendered from the Run Config

A review iteration needs 16 tool calls. The agent capped it at 13. Its three profiles all ended below 16. The run config said 12. An agent that obeyed any of them skipped a step. The config now sets 24, and the prompt renders it.

&nbsp;

## What's New at a Glance

- **The prompt states the budget.** The template renders `Max {max_tool_calls_per_iteration} tool calls total.` Both workflows pass the config value. A missing value fails the render by name.
- **One budget, no profiles.** The agent drops `scan`, `verify` and `adjudicate`. It names its 16-call floor.
- **The docs name the config key.** `SKILL.md` and the loop protocol point at `config.maxToolCallsPerIteration`.
- **The checklist ships unticked.** Its boxes start empty.

&nbsp;

## Upgrade

No migration required. A run that sets its own value keeps it.
