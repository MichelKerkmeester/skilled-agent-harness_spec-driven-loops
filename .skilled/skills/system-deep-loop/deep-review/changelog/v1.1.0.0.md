- OpenCode, Claude and Codex mirrors point to one packet model.

## Review Contract

This section defines the review packet's expected behavior. It freezes artifacts and makes lifecycle and reducers explicit.

#### Canonical Artifacts Are Frozen <a id="c-canonical-artifacts-are-frozen"></a>

- The canonical review artifacts are now frozen.
- `deep-review-config.json` and `deep-review-state.jsonl` are canonical.
- `deep-review-findings-registry.json` and `.deep-review-pause` are canonical.
- `deep-review-dashboard.md` is canonical.
- They are frozen across the skill, references, workflow assets and runtime mirrors.

#### Review Naming Is Consistent <a id="c-review-naming-is-consistent"></a>

- `deep-review-*` is the main naming across all surfaces.
- Legacy `deep-research-*` names are limited to scratch migration.
- That path is intentional, not a live review surface.

#### Lifecycle and Reducer Expectations <a id="c-lifecycle-and-reducer-expectations"></a>

- Lifecycle branches are explicit and consistent across the review packet.
- The branches are `resume`, `restart`, `fork` and `completed-continue`.
- Release-readiness states are first-class expected behavior terms, not scattered prose.
- Expected behavior surfaces document reducer inputs, outputs and metrics directly, along with machine-owned boundaries.

&nbsp;

## Runtime and Workflows

This section covers the runtime mirrors and workflow assets. They now match the review model.

#### Mirrors and Workflows Align <a id="c-mirrors-and-workflows-align"></a>

- OpenCode, Claude and Codex runtime mirrors all point to one review packet model.
- The auto and confirm workflow assets encode migration logic.
- They encode reducer refresh behavior and synthesis boundaries.
- They encode release-readiness propagation.

&nbsp;

## Review Guidance

This section covers the review references and operator guidance. They now follow one lifecycle and state model.

#### References and Operator Guidance <a id="c-references-and-operator-guidance"></a>

- The review references describe one main lifecycle and one main state model.
- The manual testing playbook no longer teaches stale `deep-research-*` review-mode names.
- The config asset now exposes the reducer metrics expected by the expected behavior tests.
- That makes future drift easier to catch.
