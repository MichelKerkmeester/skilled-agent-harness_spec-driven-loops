# v1.11.18.0, A Review Run Holds Below Its Minimum Iterations

The minimum-iteration floor applied to research runs only. A review that reached a stop candidate before its configured floor could stop early, so the floor now applies to review runs too.

&nbsp;

## What's New at a Glance

- **A review below its floor continues.** A stop candidate below `minIterations` returns `CONTINUE` with reason `minIterationsNotReached`, and the run releases once the floor is reached.
- **The floor is checked before the legal-stop gates.** The review workflow's stop order names it as item `4a`, and the deep-review README says what it does.
- **The shipped floor is unchanged.** The shipped floor of 2 and its stop-path replay are the same, with fixtures untouched.

&nbsp;

## Upgrade

No migration required. A review that sets `minIterations` above its previous stop now runs until the floor is reached.
