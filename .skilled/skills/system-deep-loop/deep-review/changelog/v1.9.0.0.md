# deep-review v1.9.0.0

This release aligns `deep-review` documentation with current templates.

- The docs also align with the Human Voice Rules.
- The README, runtime guide, references, assets, feature catalog and playbook are updated.
- No behavioral code ships.
- The reducer (`scripts/reduce-state.cjs`) was bug-scan only, under the surgical-edit policy.

Work ran in three phases inside packet `131/000/003-deep-review`.

- A Level-3 spec packet was authored end-to-end.
- A surgical audit produced 23 schema-validated findings.
- The README rewrite then closed the release.

The audit ended with no open work.

- Every actionable finding was resolved or formally closed with rationale.
- Zero deferrals shipped.

## Skill Documentation

The documentation was updated to match current templates and voice rules.

#### A Familiar README <a id="c-a-familiar-readme"></a>

- The previous README ran in a mixed technical voice.
- That voice predated the shift toward marketing-leaning HVR copy.
- The README follows the nine-section `system-spec-kit/README.md` pattern.
- Readers can navigate `deep-review` through a familiar structure.
- The rewrite covers every unique feature in the catalog.
- The catalog holds 21 entries.
- They span loop lifecycle, state management, review dimensions and severity.
- Cross-system links name explicit target paths.
- The voice was calibrated to roughly 70 percent of the root `Public/README.md` voice.

#### Runtime Guide Moves <a id="c-runtime-guide-moves"></a>

- The `Executor Selection Contract` and `Code-Graph Readiness TrustState` moved from section 1 to section 3.
- That is because they describe how the skill works, not when to invoke it.
- The two REFERENCES sections merged into one.
- A packet-citation parenthetical left a section heading.
- A deprecated planning placeholder was removed.
- The frontmatter changed from 1.4.0.0 to 1.9.0.0.
- That matches the changelog stream after entries had reached 1.8.0.0.
- The Smart Router section was preserved exactly as shipped.
- Convergence math, severity model, verdict logic, state schemas and JSONL events did not change.
- So the runtime contract needs no migration.
- Any consumer reading `SKILL.md`, the four `references/`, the asset templates, or the JSONL contract continues to work without code changes.

#### Reference Guide Navigation <a id="c-reference-guide-navigation"></a>

- The four files are `convergence.md`, `loop_protocol.md`, `state_format.md` and `quick_reference.md`.
- Each one places `### When to Use` inside `## 1. OVERVIEW`.
- All four reference files gain a `When to Use` subsection.
- The convergence threshold guidance has a dedicated reference home.
- The convergence threshold semantics block moved from the `SKILL.md` preamble to `references/convergence.md`.
- The references' meta-commentary line was removed.
- So were 33 em dash marks.
- The wording changed from `seamlessly` to `cleanly`.

#### Asset Template Boundaries <a id="c-asset-template-boundaries"></a>

- Two markdown assets and one prompt template had 19 em dash marks removed between them.
- The asset dashboard intro went from three sentences to two.
- `prompt_pack_iteration.md.tmpl` stayed structurally unchanged.
- That is because `prompt-pack.ts` consumes it as a raw template through `readFileSync`.
- Adding YAML frontmatter would inject metadata text into the rendered agent prompt.
- So would condensing the intro or inserting horizontal rules.
- So the template-conformance rules in `skill_asset_template.md` do not apply to that file.

#### Audit Findings Closed <a id="c-audit-findings-closed"></a>

- The surgical audit produced 23 schema-validated findings.
- The surgical audit closed all 23 findings.
- The closeout included 2 P0, 8 P1 and 13 P2 findings.
- Zero were deferred and zero stayed open.
- Every actionable finding was resolved or formally closed with rationale.
- Five findings were closed as resolved-with-rationale rather than edited away.
- Three concerned the raw-template exception for `prompt_pack_iteration.md.tmpl`.
- One corrected the audit's claim that historical changelogs failed the current template convention.
- Later `####` category subheaders had been counted as leading H1s.
- One confirmed that the playbook root frontmatter already carried a description field.
