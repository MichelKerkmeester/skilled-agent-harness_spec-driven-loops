This first release makes `deep-review` a standalone skill that owns all iterative code review and quality auditing functionality. It extracts all review-mode functionality from the unified `deep-research` skill v1.2.2.0 and gives the skill its own command, YAML workflows, reference documentation and manual testing playbook.

## Why This Release

The goal is to make the review workflow easier to follow and easier to trust.

## What's New at a Glance

- **`deep-review` has its own command and workflow set.** Its dedicated command gives review work a separate entry point.
- **Four references document review work.** They cover the loop, convergence, state formats and quick lookup.
- **The skill includes a manual testing playbook.** Its review scenarios follow the `deep-research` structure.
- **Review routing was updated alongside the skill split.** The skill advisor and the Barter advisor both handle review keywords.
- **Runtime definitions point to the standalone skill.** The runtime agent definitions and command wrapper were updated for `deep-review`.
- **Documentation and catalogs include `deep-review`.** Agent guidance and skill catalogs gained entries for the new skill.

---

## Review Workflow

#### The New Command and Workflows

The new command `/speckit:deep-review` offers `:auto` and `:confirm` modes. Its YAML workflows are `spec_kit_deep-review_auto.yaml` and `spec_kit_deep-review_confirm.yaml`, renamed from `spec_kit_deep-research_review_*.yaml`. **Breaking:** the old `/speckit:deep-research:review` command is no longer supported.

&nbsp;

#### Review Assets Move with the Skill

The review-specific assets moved into the `deep-review` package:

- `deep_review_strategy.md`
- `deep_review_dashboard.md`
- `review_mode_expected behavior.yaml`
- `deep_review_config.json`

## Review Documentation

#### References Cover Each Stage

- **`references/loop-protocol.md`.** Describes the review loop lifecycle of init, iterate, synthesize and save, including scope discovery, dimension ordering, cross-reference protocols and claim adjudication.
- **`references/convergence.md`.** Documents the severity-weighted ratio, P0 override, dimension coverage signal, quality guards and provisional verdict logic.
- **`references/state-format.md`.** Describes state file schemas for config, JSONL, strategy, iteration files, the review report, dashboard, claim adjudication and finding registry.
- **`references/quick-reference.md`.** Provides a review-only cheat sheet with numbered H2 sections aligned to `skill_reference_template.md`.

## Manual Testing

#### Review Stages Guide Scenarios

The playbook's review-specific scenarios mirror the `deep-research` structure and cover:

- Entry points and modes
- Initialization and state setup
- Iteration execution and state discipline
- Convergence and recovery
- Pause, resume and fault tolerance
- Synthesis, save and guardrails

## Skill Routing

#### Review Keywords Follow the Split

The skill advisor routes review keywords to `deep-review` instead of `deep-research`. The Barter repo's `skill_advisor.py` received matching review-keyword routing.

&nbsp;

#### Runtimes Receive the New Entry

Agent definitions across `.claude`, `.opencode`, `.agents` and `.codex` were updated to reference `/speckit:deep-review` and `deep-review`. The `.agents` runtime received a new wrapper at `.agents/commands/speckit/deep-review.toml`. Agent guidance and the root and `.opencode` catalogs gained `deep-review` entries.
