# v1.11.9.0, The Agent Finds Its Skills Where They Are Installed

The deep-review agent pointed at fixed `.skilled/` paths for its review doctrine, its event gateway, its reducer and its retrieval helpers, so a repository that installed the skills in another folder sent it to files that do not exist. The agent now names each file by its place inside the installed skill, the way the code agent already does.

> Spec folder: `specs/sk-code/017-portable-code-modes/006-review-agent-and-dispatch` (Level 2)

&nbsp;

## What's New at a Glance

- **Review doctrine from the installed review mode.** The severity reference is read from the sk-code skill wherever it is installed.
- **Loop scripts from the installed deep-loop skill.** The event gateway, the reducer and the loop protocol are named inside the system-deep-loop skill, with this repository's path given as the example.
