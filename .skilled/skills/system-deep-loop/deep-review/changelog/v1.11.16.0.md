# v1.11.16.0, One Workflow File and a Stop a Script Computes

A review run now stops for a reason a script computed from files. Auto mode and confirm mode run the same steps from one workflow file. The docs in this packet named workflow files and a reducer path that do not exist. They now match the code.

&nbsp;

## What's New at a Glance

- One workflow file serves both modes.
  - `/deep:review` runs from `deep-review.yaml`.
  - The files `deep-review-auto.yaml` and `deep-review-confirm.yaml` are gone.
  - Confirm mode adds approval gates and nothing else.
- A script computes the stop decision.
  - `runtime/scripts/convergence.cjs` runs the nine legal-stop gates and decides once per pass.
  - `maxDurationReached` joins the stop reasons.
- A resumed run counts the same.
  - The stuck count and the failure count are rebuilt from the state log on every pass.
- Three failed iterations in a row stop the loop.
  - The stop reason is `error`.
  - Confirm mode first asks Retry, Skip or Cancel.
  - Auto mode asks nothing.
- `--restart`, `--lineage-mode` and `--dry-run` work in both modes.
  - A dry run halts before any dispatch or state write.
- The docs name the real reducer.
  - `SKILL.md` and the state references said `scripts/reduce-state.cjs`.
  - The review reducer is `runtime/scripts/reduce-state.cjs`.
- The docs state no tool-call number.
  - `SKILL.md` and `references/protocol/loop-protocol.md` point at the `- Target` line of `assets/prompt-pack-iteration.md.tmpl`.
- The contract snapshot names its source.
  - `scripts/render-contract-snapshot.cjs` said `review_mode_contract.yaml`.
  - The file is `review-mode-contract.yaml`, and `assets/review-mode-contract-snapshot.md` was regenerated.
- The docs name files that exist.
  - `SKILL.md`, seven files under `references/` and the files under `feature-catalog/` and `manual-testing-playbook/` were corrected.
  - The native fan-out scenario now describes `fanout-run.cjs`.

&nbsp;

## Upgrade

Replace `deep-review-auto.yaml` or `deep-review-confirm.yaml` in your own scripts with `deep-review.yaml`. Nothing else is required.
