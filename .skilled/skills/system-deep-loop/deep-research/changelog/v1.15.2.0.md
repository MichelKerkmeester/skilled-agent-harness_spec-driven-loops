Research writers now learn, in every iteration's prompt, that their `[SOURCE: path:line]` tags are checked. The check runs in the next spec-kit validation and warns on a gone file, a moved file or a line past the end.

> Spec folder: `specs/system-speckit/050-open-knowledge-format-adoption/005-source-resolver` (Level 2)

## What's New at a Glance

- **Writers cite the current path.** The iteration prompt asks for the path as it is now, because a moved file draws a warning.
- **A resolved tag is not proof.** The prompt says a resolved tag shows only that the path and line exist, so the cited lines must still say what the finding claims.
