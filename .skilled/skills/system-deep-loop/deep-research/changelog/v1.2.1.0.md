Deep-research review mode now writes its packets under `review/` rather than `scratch/`, and review uses a simplified taxonomy.

## What's New at a Glance

- **Review packets move to `review/`.** The review-mode contract moves the canonical review output paths from `scratch/` to `review/`. The automatic review workflow gains `review/` packet creation, migration and a resume flow, and the confirm workflow matches that contract.
- **The review taxonomy is simplified.** The automatic review workflow and the `deep-review` agent use the simplified taxonomy, and the agent follows the `review/` packet contract in every runtime mirror.
- **Review-mode routing is updated.** `SKILL.md` updates the review-mode intent signals, phase detection and review packet contract, and the `deep-research` command updates its review-mode routing and canonical review packet guidance. The `.agents` command wrapper's metadata is aligned to the review-mode entrypoints.
- **Docs and scenarios follow the new location.** The README covers the review folder's behavior and recovery for users, and the review-mode playbook scenarios expect the new packet location.

## Upgrade

No manual migration is required. Pull latest to use the simplified 7-dimension review taxonomy and new `review/` packet contract. Legacy `scratch/`-based review sessions are migrated automatically on resume.
