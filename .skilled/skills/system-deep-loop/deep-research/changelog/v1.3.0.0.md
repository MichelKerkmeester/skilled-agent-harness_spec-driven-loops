# v1.3.0.0, Review Splits Into Its Own Skill

v1.3.0.0 splits review mode out of `deep-research` into the new standalone `deep-review` skill.

- `deep-research` is now research-only.
- Its review keywords, commands and references were removed or redirected.
- `deep-review` owns the review-specific files and scenarios.

Review commands, references and keywords now point to `deep-review`.

- `/deep:research` now uses `:auto` and `:confirm`.
- Review examples and the review path now lead to `/deep:review`.
- The quick reference's review section points to the `deep-review` reference.
- Review keywords now route to `deep-review`. Research keywords were unchanged.

Review scenarios now have a dedicated playbook under `deep-review`.

- The root manual testing playbook now has 30 scenarios.
- The `07--review-mode/` playbook moved to `deep-review`.

> [!IMPORTANT]
> 1 change can break an existing setup. Read it before you update.
>
> 1. The `:review` suffix is no longer recognized by the `deep-research` command. [Replace the review command](#c-review-uses-its-own-command)

&nbsp;

## Why This Release

The split is intended to make the workflow easier to follow and easier to trust.

## Deep Research Skill

Review content moved out of the `deep-research` skill.

#### Review Has a Separate Home <a id="c-review-has-a-separate-home"></a>

- Review triggers, `REVIEW_*` intent signals and architecture diagrams were removed from `SKILL.md`.
- Rules, success criteria and references were removed from `SKILL.md`.
- `deep_review_strategy.md`, `deep_review_dashboard.md` and `review_mode_expected behavior.yaml` moved to `deep-review`.
- Sections 1 and 8 now use the cross-reference `For code review, see deep-review`.

&nbsp;

## Research Command

Review handling left the `/deep:research` command.

#### Review Uses Its Own Command <a id="c-review-uses-its-own-command"></a>

> [!WARNING]
> The `:review` suffix is no longer recognized by the `deep-research` command. Replace `/deep:research:review` with `/deep:review`.

- `/deep:research` no longer handles `:review` suffixes.
- It no longer asks review-specific setup questions.
- Its only mode suffixes are `:auto` and `:confirm`.
- The removed suffixes are `:review`, `:review:auto` and `:review:confirm`.
- Review examples now point to `/deep:review`.
- The command chain's review path now points to `/deep:review`.

&nbsp;

## Reference Documentation

Reference docs now redirect review readers to `deep-review`.

#### Review Guidance Has a Redirect <a id="c-review-guidance-has-a-redirect"></a>

- The 80-line Review Mode section in `references/quick-reference.md` was replaced by a redirect to `deep-review/references/quick-reference.md`.
- Its H2 sections were numbered according to `skill_reference_template.md`.

#### Shared Protocols Keep Review Sections <a id="c-shared-protocols-keep-review-sections"></a>

- Review-specific sections in `references/loop-protocol.md`, `convergence.md` and `state_format.md` were retained as shared protocol documentation.
- `deep-review` cross-references them.

&nbsp;

## Skill Advisor Routing

The skill advisor now sends review keywords to `deep-review`.

#### Review Routes to Deep Review <a id="c-review-routes-to-deep-review"></a>

- Review keywords including `deep review`, `review mode`, `iterative review`, `code audit` and `:review` now route to `deep-review`.
- They route from `deep-research` in both Public and Barter repos.
- The `autoresearch`, `deep research` and `research loop` keywords were unchanged.

&nbsp;

## Manual Testing Playbooks

Review scenarios moved into a dedicated `deep-review` playbook.

#### Review Scenarios Move to Deep Review <a id="c-review-scenarios-move-to-deep-review"></a>

- The `07--review-mode/` playbook moved to `deep-review`.
- It was restructured from 11 scenarios into 28 across 6 categories.
- The manual testing playbook was reduced from 41 scenarios to 30 across 6 categories after review scenarios moved.
- The root playbook document removed Section 13 (Review Mode) and renumbered the remaining sections.

&nbsp;

## Upgrade Notes

The review command changed for existing setups.

#### Before You Start <a id="c-before-you-start"></a>

1. Replace `/deep:research:review` with `/deep:review`. The `:review` suffix is no longer recognized by the `deep-research` command.
