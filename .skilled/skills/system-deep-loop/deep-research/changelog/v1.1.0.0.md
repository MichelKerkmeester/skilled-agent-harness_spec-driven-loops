This release updates the deep-research workflow around validation coverage, adding quality guards, a generated dashboard, new iteration state fields and research-charter validation. The command documentation updates its workflow overview, the agents on five runtimes gain the same v1.1.0 features and the manual testing playbook adds scenarios.

## What's New at a Glance

- **Quality guards gate convergence.** `references/convergence.md` gains a Quality Guard Protocol, and `loop-protocol.md` adds a quality guard check at Step 2c. The auto workflow applies the guard in its convergence check, the confirm workflow adds a quality guard, the state format records `guard_violation` events, and `quick-reference.md` adds a quality guards note.
- **A dashboard is generated after each iteration.** The new `assets/deep-research-dashboard.md` template has 8 numbered sections, retrieval anchors and an Overview with Purpose and Usage. `loop-protocol.md` adds dashboard generation at Step 4a, `state-format.md` adds the dashboard schema, both workflow YAMLs gain a `step_generate_dashboard` step, and the config adds the dashboard to `fileProtection`.
- **Iteration state records more.** `state-format.md` adds the `ruledOut`, `noveltyJustification`, `focusTrack` and `sourceStrength` fields, an extended status enum and an auto-generated protection level. `quick-reference.md` adds an iteration status legend, and `loop-protocol.md` adds track labels.
- **Negative knowledge reaches the synthesis.** `loop-protocol.md` adds synthesis rules for negative knowledge.
- **Research charters are validated.** `loop-protocol.md` adds charter validation at Step 5a.
- **Each iteration has a budget.** `loop-protocol.md` adds a per-iteration budget, and `deep-research-config.json` adds `maxToolCallsPerIteration` and `maxMinutesPerIteration`.
- **Recovery starts from a diagnosis.** `convergence.md` adds diagnosis-led recovery, a reference-only dead-end coverage signal and a source-hygiene note, and `loop-protocol.md` adds recovery classification.
- **The strategy template follows the sk-doc template.** `assets/deep-research-strategy.md` now has 13 numbered sections, retrieval anchors, an Overview, Non-Goals, Stop Conditions and Ruled Out Directions.
- **The skill and command docs describe the new features.** `SKILL.md` bumps the skill version from 1.0.0 to 1.1.0 and gains 3 new ALWAYS rules, a quality gates row, the iteration status enum and a dashboard reference, and the README adds the v1.1.0 features, a version history section and the dashboard in its structure tree. The `deep-research` command doc updates its workflow overview for the charter, guards and dashboard and expands its Key Differences. The confirm workflow gains a resume decision gate, and both workflow YAMLs gain a version comment.
- **The agent gains the new features on five runtimes.** The `deep-research` agent for Claude, OpenCode, ChatGPT, Codex and Agents gains the new statuses, ruled-out directions, novelty justification, source diversity, the dashboard and focus tracks.
- **The playbook grows from 19 to 30 scenarios.** The new scenarios, DR-020 to DR-030, cover the source-diversity, focus-alignment and single-weak-source guards, a guard failure overriding passed convergence, dashboard generation after an iteration, novelty justification in JSONL, ruled-out directions in synthesis, charter validation, focus track labels in the dashboard, the insight status preventing a false stuck signal and thought-status convergence handling. The playbook's date is updated to 2026-03-24.
