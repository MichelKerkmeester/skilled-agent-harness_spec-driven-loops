This release updates deep-research with clearer support for request routing, making the release easier to understand and use.

## What's New at a Glance

- **Deep-research now supports review mode.** The mode audits code rather than doing open-ended research.
- **A `:review` suffix selects review mode.** The `.opencode/commands/speckit/deep-research.md` command detects the suffix, asks review setup questions and routes to the review workflows.
- **Review runs in an autonomous or an interactive workflow.** The autonomous workflow runs four phases with review convergence and `review-report.md` synthesis, and the interactive workflow adds five approval gates.
- **`@deep-review` is a new leaf agent.** It ships for the OpenCode, ChatGPT, Claude, Codex and Agents runtimes.
- **Review mode has its own templates and documentation.** A review strategy template with seven dimensions and a review dashboard template are added. The config, references, `SKILL.md`, README and manual testing playbook gain review-mode content, including 11 playbook scenarios.
- **`AGENTS.md` files register the new agent.** The Public and Barter `AGENTS.md` files and `AGENTS_example_fs_enterprises.md` add `@deep-review` and an `@speckit` exception, and the Public file also adds the review workflow.

## Upgrade

No migration required. Use the new review mode entrypoint.
