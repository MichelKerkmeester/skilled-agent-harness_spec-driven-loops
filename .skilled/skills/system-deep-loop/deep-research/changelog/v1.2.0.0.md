This release updates deep-research with clearer support for request routing. That clearer support makes the release easier to understand and use.

&nbsp;

## What's New at a Glance

- Deep-research now supports review mode.
  - The mode audits code.
  - The mode does not do open-ended research.
- A `:review` suffix selects review mode.
  - The `.opencode/commands/speckit/deep-research.md` command detects the suffix.
  - The command asks review setup questions and routes to the review workflows.
- Review runs in an autonomous or an interactive workflow.
  - The autonomous workflow runs four phases.
  - The autonomous workflow has review convergence and `review-report.md` synthesis.
  - The interactive workflow adds five approval gates.
- `@deep-review` is a new leaf agent.
  - The agent ships for the OpenCode, ChatGPT, Claude, Codex and Agents runtimes.
- Review mode has its own templates and documentation.
  - A review strategy template with seven dimensions is added.
  - So is a review dashboard template.
  - The config, references, `SKILL.md`, README and manual testing playbook gain review-mode content.
  - That includes 11 playbook scenarios.
- `AGENTS.md` files register the new agent.
  - The Public and Barter `AGENTS.md` files add `@deep-review` and an `@speckit` exception.
  - So does `AGENTS_example_fs_enterprises.md`.
  - The Public file also adds the review workflow.

&nbsp;

## Upgrade

No migration required. Use the new review mode entrypoint.
