This release adds a feature catalog for `deep-research` so readers can see what the loop does without reading source code. Before this release, the only way to see what the research loop did was to read `SKILL.md` or the source files. No map, no per-feature breakdown, no pointer from behavior back to code.

> Spec folder: `.opencode/specs/system-spec-kit/026-graph-and-context-optimization/011-skill-advisor-graph/008-deep-skill-feature-catalogs/` (Level 3)

## What's New at a Glance

- **The `deep-research` catalog maps 14 features into four areas.** At `.opencode/skills/deep-loop-workflows/deep-research/feature-catalog/feature-catalog.md`, it groups them as loop lifecycle (init, iteration dispatch, convergence check, synthesis and memory save), state management (JSONL log, strategy tracking and config), convergence (three-signal model, stuck detection, quality guards and graph convergence) and research output (progressive synthesis and negative knowledge).
- **Each feature has its own file.** Each file provides an overview, describes what the code actually does today and points to the source. The skill README points to the catalog as the first place to look when you want to understand the loop.

## Upgrade

No migration required. The catalog is documentation only, and runtime behavior is unchanged.
