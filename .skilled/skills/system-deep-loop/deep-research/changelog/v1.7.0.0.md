This release adds a feature catalog for `deep-research`. So readers can see what the loop does without reading source code. Before this release, there was only one way to see what the research loop did. You had to read `SKILL.md` or the source files. There was no map and no per-feature breakdown. There was no pointer from behavior back to code.

## What's New at a Glance

- **The `deep-research` catalog maps 14 features into four areas.** It sits at `.opencode/skills/deep-loop-workflows/deep-research/feature-catalog/feature-catalog.md`. The first area is loop lifecycle. It covers init, iteration dispatch, convergence check, synthesis and memory save. The second is state management. It covers the JSONL log, strategy tracking and config. The third is convergence. It covers the three-signal model, stuck detection, quality guards and graph convergence. The fourth is research output. It covers progressive synthesis and negative knowledge.
- **Each feature has its own file.** Each file gives an overview. It describes what the code actually does today. It points to the source. The skill README points to the catalog as the first place to look when you want to understand the loop.

## Upgrade

No migration required. The catalog is documentation only. Runtime behavior is unchanged.
