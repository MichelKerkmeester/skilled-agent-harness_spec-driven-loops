# v1.15.13.0, One Workflow File and a Stop a Script Computes

A research run now stops for a reason a script computed from files. Auto mode and confirm mode run the same steps from one workflow file. The docs in this packet named two workflow files and described a stop the workflow decided in prose. They now match the code.

> Spec folder: `specs/system-deep-loop/loop-architecture/004-workflow-logic-hardening`

&nbsp;

## What's New at a Glance

- **One workflow file serves both modes.** `/deep:research` runs from `deep-research.yaml`. The files `deep-research-auto.yaml` and `deep-research-confirm.yaml` are gone. Confirm mode adds approval gates and nothing else.
- **A script computes the stop decision.** `runtime/scripts/convergence.cjs` decides once per loop pass. The frozen stop reason list holds `converged`, `maxIterationsReached`, `blockedStop`, `manualStop`, `error`, `stuckRecovery`, `userPaused` and `maxDurationReached`.
- **A missing graph decision blocks a stop.** A stop candidate with no graph decision continues with the reason detail `graphDecisionMissing`.
- **A resumed run counts the same.** The stuck count and the failure count are rebuilt from the state log on every pass. Failed iterations stay out of the ratio signals.
- **Three failed iterations in a row stop the loop.** The stop reason is `error`. Confirm mode first asks Retry, Skip or Cancel. Auto mode asks nothing.
- **A run has a wall-clock limit.** Each pass compares `maxDurationMinutes` with the config `createdAt`. At the limit the loop goes to synthesis with `maxDurationReached`.
- **`--restart`, `--lineage-mode` and `--dry-run` work in both modes.** A dry run halts before any dispatch or state write.
- **The docs state no executor count and no tool-call number.** `SKILL.md` names the `EXECUTOR_KINDS` array and `maxToolCallsPerIteration` in the config.
- **The docs name files that exist.** `SKILL.md`, `README.md`, seven files under `references/` and 66 files under `feature-catalog/` and `manual-testing-playbook/` were corrected. Playbook search commands now print a line when run.

&nbsp;

## Upgrade

Replace `deep-research-auto.yaml` or `deep-research-confirm.yaml` in your own scripts with `deep-research.yaml`. Nothing else is required.
