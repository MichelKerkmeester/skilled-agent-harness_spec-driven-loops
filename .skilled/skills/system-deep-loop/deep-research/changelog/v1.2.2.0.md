Deep-research's research and review modes move to a new canonical packet layout. The runtime agents follow it. So does spec-kit's packet tooling. The wrappers align to `/speckit:deep-research`.

## What's New at a Glance

- **Deep-research advances to version `1.2.2.0`.** `SKILL.md` aligns to the canonical packet contract. The `deep-research` command updates its research and review workflow contract. That contract moves to the new packet layout.
- **Workflows use the new paths.** The `speckit_deep-research_*.yaml` workflows update their research and review paths. Those paths cover init, iteration and synthesis.
- **Docs and scenarios follow the new layout.** The loop, state, convergence and quick-reference docs align to the new packet paths. The README shows users the packet layout for research and review modes. The playbook expectations follow the canonical layout.
- **Agents get runtime parity updates.** The OpenCode and Claude agents carry runtime parity updates. These cover deep-research, deep-review, orchestrate and speckit guidance. The Codex agents synchronize their deep-research and deep-review packet guidance.
- **Wrapper naming aligns to `/speckit:deep-research`.** The `.agents` command wrappers now use that name. So does the `spec_kit_research.md` workflow.
- **Spec-kit follows the new contract.** `system-spec-kit` updates packet discovery, parsing, migration and indexing for it.

## Upgrade

No manual migration is required for the tracked repo corpus. The in-repo migration utility has already moved first-party packets to the new layout. If you maintain older custom research folders outside the tracked repo, move them first. Move them to the new research-folder and review-iterations structure. Do this before relying on this contract.
