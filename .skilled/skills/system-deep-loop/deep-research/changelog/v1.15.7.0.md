# v1.15.7.0, Fan-Out Lineages Reduce Their Own State

v1.15.7.0 points each fan-out lineage's reducer at the lineage's own folder. The reducer used to refresh the base research folder, so the lineage's registry, dashboard and strategy sat at their starting state and the merge read stale data.

> Spec folder: `specs/system-deep-loop/038-review-and-cli-lineage/006-research-lineage-reducer-path` (Level 1)

&nbsp;

## What's New at a Glance

- **A lineage's reducer now writes into the lineage folder.** `reduce-state.cjs` takes `--artifact-dir`. Both research workflows pass the lineage folder on every per-iteration call, so the lineage's registry, dashboard and strategy stay current.
- **Single-executor runs keep their behavior.** The workflows pass the flag only when a fan-out lineage directory is present, so a run without one resolves its artifact root as before.
- **A missing path stops the reducer.** `--artifact-dir` with no value exits with a message. The value it takes is never read as the spec folder.
