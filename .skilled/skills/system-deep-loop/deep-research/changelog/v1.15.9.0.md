# v1.15.9.0, A Short Summary Opens the Skill and the Router Keeps Its Own Section

The deep-research skill opened with one long routing section that held both a summary and the router itself. A reader had to work through the tables and the discovery code to find out what the skill does with a request. The section is now a short prose summary: what selects this skill, what it loads first and where the rest lives.

The router blocks did not change. The resource domains, the loading levels, the phase signals and the discovery pseudocode moved as they were to a final machine router section at the end of the file. Every intent, every resource path and every loading level is the same, so a request routes exactly where it did before.
