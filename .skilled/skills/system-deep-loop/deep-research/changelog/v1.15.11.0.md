# v1.15.11.0, Machine Routing Moves to ROUTER.md

The deep-research router now has a dedicated file. So routing guidance is easier to locate. The parsed router stays identical to the previous edition. So requests route the same way.

&nbsp;

## What's New at a Glance

- The router has its own file.
  - `ROUTER.md` holds the intent map and the resource map.
  - `ROUTER.md` also holds the default resource, loading levels and routing pseudocode.
  - These items come after a short overview and intent model.
- The skill page keeps routing prose short.
  - `SKILL.md` keeps SMART ROUTING as brief prose.
  - That prose ends with a line linking to `ROUTER.md`.
- Skill documents point to the router file.
  - Testing playbooks, feature catalog entries and references now point to `ROUTER.md`.
- One scenario reads the router by heading.
  - The intra-routing resource-map scenario now prints from the `MACHINE ROUTER` heading.
  - It uses that heading instead of a fixed line range.
  - So an inserted keyword line cannot change what it shows.
