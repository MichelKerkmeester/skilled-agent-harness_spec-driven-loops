# v1.15.16.0, The Prompt Pack Names research.md and the Next-Focus Heading

The research prompt pack now agrees with the research agent definition on two points. A fan-out lineage can write its own synthesis. The reducer reads the next focus the pack asks for.

&nbsp;

## What's New at a Glance

- **The pack allows `research/research.md`.** ALLOWED WRITE PATHS lists `research.md` beside the iterations folder. It does so only when `progressiveSynthesis` is `true`.
- **The narrative heading is `Recommended Next Focus`.** The heading list ends in the heading the research reducer parses. The next focus is read from the pack's own wording.
- **A lockstep test guards both points.** It fails when the pack and the agent definition drift apart on either one.

&nbsp;

## Upgrade

No migration required. The agent definition and the runtime mirrors are unchanged.
