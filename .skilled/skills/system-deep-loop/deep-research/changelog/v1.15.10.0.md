# v1.15.10.0, Long Prose Lines Become Short Sentences and Lists

Several paragraphs in the deep-research skill were one very long line each. A reader had to untangle the executor rules from a single sentence. The same went for the event-record contract and the state packet layout.

Those lines are now short sentences. A line that listed several rules or steps is now a short list. The instruction comes before the background. Instructions address you directly.

The content did not change. Every file path, resource name, command, field, executor name and number in the old lines is still there. The rewrite adds nothing new. What selects this skill is exactly as it was. So is what it loads first and how a request routes.

## What's New at a Glance

- **The executor contract reads as steps.** What the workflow owns now stands alone. So does what is discouraged. So does the file that owns the executor kinds. So does the YAML branch for each executor.
- **The event record rule reads as four lines.** The required fields are one point. The single-object rule is another. So are the reducer-owned delta file and the ledger refresh.
- **The state packet location is split by target kind.** Root-spec targets get their own sentence. So do child-phase targets. So does the flat-first subfolder rule.
- **The late-init anchoring steps are numbered.** The lock, the folder state, the bounded context seed and the findings fence replacement each stand alone. They read in run order.
- **Every fact is the same.** No routing signal changed. No resource path, loading level or command changed either. Every fenced line is byte-identical.
