The deep-research README now leads with the outcome the skill delivers. That replaces a reference-card inventory. New operators get a one-line pitch, a problem-first overview and the research state layer. These come in the same order used by the pilot skills. The rewrite follows the refined skill README template. It carries every fact from the previous README forward. That includes dispatch rules, state files, convergence contract and all 23 reference links.

## What's New at a Glance

- **The README follows the refined skill template.** It opens with a one-line pitch blockquote and a problem-first OVERVIEW. Then come AT A GLANCE, QUICK START, HOW IT WORKS, INTEGRATION & NAVIGATION, TROUBLESHOOTING, FAQ, VERIFICATION and RELATED DOCUMENTS. They follow in template order.
- **The Research State Layer covers six packet files.** Its capability table names what the skill reads and writes in each file. It is modeled on the pilot's plugin knowledge layer.
- **The README version changes.** Its frontmatter moves from 1.14.0.46 to 1.15.0.0. This changelog entry records the revision.
