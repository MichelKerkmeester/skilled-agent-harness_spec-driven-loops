# v1.9.11.0, Both Skills Install the Same zod

The runtime pinned zod 4.4.3 while `system-spec-kit` installed 4.5.4, so the two skills shipped different versions of the same schema library. The runtime's pin now names the version `system-spec-kit` installs.

> Spec folder: `specs/sk-code/015-quality-agnostic-gate/010-alignment-audit` (Level 2)

&nbsp;

## What's New at a Glance

- **The pin stays exact.** The runtime names 4.6.7 with no range, so a fresh install cannot land on a release other than the one `system-spec-kit` resolves.
- **The pin test tracks the new version.** It compares the versions the runtime installed with the ones it mirrors from `system-spec-kit`, so a pin raised in one tree alone fails the runtime suite instead of splitting the two quietly.
- **The test tooling's advisories are closed.** vitest moves to 4.1.12 and the packages beneath it move with the audit fix, so the runtime's dev install no longer carries the reported alerts.

&nbsp;

## Upgrade

No migration required. A fresh `npm install` in the runtime folder picks up the new pins.
