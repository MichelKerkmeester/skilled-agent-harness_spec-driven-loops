The four offline replay scorers measured a Deem backend beside Jev. The Deem arm and the Deem docs are removed, so cli-jev is the only classifier the replays measure, and every default run and Jev arm is unchanged.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/046-deem-deprecation/004-references-sweep-and-verification` (Level 2)

## What's New at a Glance

- **The replays run Jev alone.** `score-stop-rater.cjs`, `score-stop-hint.cjs`, `score-severity-replay.cjs` and `score-fanout-pairs.cjs` each keep one Jev arm and reject the removed switch as an unknown flag.
- **The runtime docs name Jev only.** The runtime README, the feature catalog and the manual-testing playbook describe the Jev arm alone.

## Upgrade

Drop `--deem` from any replay command that still passes it. Every default run prints what it printed before.
