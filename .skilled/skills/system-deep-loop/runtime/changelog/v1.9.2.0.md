The offline replay scorers measured a Deem backend beside Jev. The Deem arm and the Deem docs are removed. So cli-jev is the only classifier the replays measure. Every default run and Jev arm is unchanged.

&nbsp;

## What's New at a Glance

- The replays run Jev alone.
  - `score-fanout-pairs.cjs` keeps one Jev arm.
  - `score-fanout-pairs.cjs` rejects the removed switch as an unknown flag.
- The runtime docs name Jev only.
  - The runtime README, the feature catalog and the manual-testing playbook describe the Jev arm alone.

&nbsp;

## Upgrade

Drop `--deem` from any replay command that still passes it. Every default run prints what it printed before.
