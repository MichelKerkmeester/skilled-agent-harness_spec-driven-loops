# v1.9.12.0, The Pi Fan-Out Accepts GPT-6.1 Terra

Pi reaches GPT-6.1 Terra through its `openai` provider, but the fan-out refused the id because its closed cli-pi allowlist did not name it. The allowlist now does, so a deep-loop lineage can pin the model.

> Spec folder: `specs/cli-external-orchestration/083-gpt-6-1-terra-roster` (Level 1)

&nbsp;

## What's New at a Glance

- **A lineage that pins `gpt-6.1-terra` runs.** The fan-out dispatches it as `openai/gpt-6.1-terra`, beside GPT-6 Sol and GPT-6 Luna on the same provider.
- **The executor config and the fan-out script agree.** Both copies of the allowlist carry the new id, so a config that validates also dispatches.
