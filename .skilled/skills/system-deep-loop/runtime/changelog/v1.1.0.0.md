This first release-cleanup pass is documentation-only and corrects four P1 documentation deviations in `deep-loop-runtime`. It makes three surgical edits to `SKILL.md` and no others beyond the separate frontmatter version bump. Smart Router section 2, runtime lib code, script entry points, tests and SQLite storage are unchanged as they shipped in v1.0.0, and the release ships from the `001-deep-loop-runtime` packet under `000-release-cleanup`, the first of five sibling cleanup packets that follow the same template.

> Spec folder: `.opencode/specs/skilled-agent-orchestration/116-deep-skill-evolution/000-release-cleanup/001-deep-loop-runtime/`

## Why This Release

The deep-loop-runtime v1.0.0 baseline shipped the arc-118 FULL_ISOLATE_NO_MCP consolidation, but the documentation had not been audited end to end against current sk-doc templates or HVR voice standards. The README had six of the nine sections prescribed by the system-spec-kit README structural anchor.

## What's New at a Glance

- **The README was fully rewritten to the nine-section structure.** It grew from 174 to 470 lines, and its sections are OVERVIEW, QUICK START, FEATURES with seven sub-domains, STRUCTURE, CONFIGURATION, USAGE EXAMPLES, TROUBLESHOOTING, FAQ and RELATED DOCUMENTS. Its voice is anchored at ~70% of `Public/README.md` intensity.
- **The README maps seven runtime domains to their consuming skills.** The domains are executor and prompt (4 modules), state safety (4 modules), scoring and routing (2 modules), coverage graph (3 modules), council primitives (5 modules per packet 131/001/008 ADR-001), script entry points (4 .cjs entry points plus cli-guards lib) and storage. Each row identifies a consuming skill (`deep-review`, `deep-research` or `deep-ai-council`). Storage is runtime-owned SQLite at `storage/deep-loop-graph.sqlite`.
- **The skill description is now within its character limit.** It changed from 240 to 124 characters against the 130-character skill limit.
- **Council Primitives is now a subsection under section 3.** `## Council Primitives` became `### Council Primitives` to follow the numbered-H2-ALL-CAPS rule.
- **Both changelog references now use the full version filename.** `SKILL.md` and `README.md` point to `changelog/v1.0.0.0.md` rather than `changelog/v1.0.0.md`.
- **The frontmatter version was bumped.** It changed from `version: 1.0.0` to `version: 1.1.0`.

## Upgrade

No migration required. The script-interface contract (argv shape, stdout JSON shape and exit codes) is unchanged. TS import paths into `lib/` are unchanged. The SQLite schema is unchanged at version 2. `system-spec-kit/mcp-server/vitest.config.ts` still picks up tests at `../deep-loop-runtime/tests/`.

Consumers that hold a path reference to `changelog/v1.0.0.md` should update it to `changelog/v1.0.0.0.md`. External consumers should grep their docs.
