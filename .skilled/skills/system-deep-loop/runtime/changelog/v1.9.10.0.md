# v1.9.10.0, The Docs Name the Files the Repository Holds

The runtime README listed its configuration files. It did not list its package manifest. So a reader had to open the folder. That was the only way to find where the dependencies and the commands come from. Two module READMEs also named compiled files. The repository does not carry those files. So an import line led nowhere.

&nbsp;

## What's New at a Glance

- The runtime README lists the package manifest.
  - The row says what the file is.
  - The row also says the file holds the runtime's dependencies and its two commands.
- Two module READMEs name the tracked source files.
  - An import line named a compiled file.
  - The repository does not carry that file.
  - The line now names the source file you can open.

&nbsp;

## Upgrade

No action is needed. This is a documentation change. So the runtime runs exactly as it did.
