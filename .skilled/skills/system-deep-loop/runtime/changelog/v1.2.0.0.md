# v1.2.0.0, Phase 5 Audit Remediation

This release closes all 36 findings from the Phase 5 deep-research audit.

- The work ran in four remediation batches.
- It corrects three README-related errors.
- It corrects three drifted feature descriptions.

It brings the council surface into catalog and playbook coverage.

- It also adds targeted test coverage.
- Council test coverage also expanded.

&nbsp;

## Why This Release

The v1.1.0.0 release-cleanup pass is documented in `changelog/v1.1.0.0.md`. It rewrote the README and fixed four focused `SKILL.md` issues.

- Its audit-and-validate phases missed findings.
- Those findings surfaced later in the Phase 5 deep-research audit.
- The README rewrite also introduced or propagated errors.
- That shows structural validation checks template conformance, not content accuracy.
- The deep-research loop is the fact-checker.
- The Phase 5 audit synthesis at `.../001-deep-loop-runtime/research/research.md` identified seven transverse patterns.

## Documentation Accuracy

Documentation claims now match their sources.

#### Documentation Claims Corrected <a id="c-documentation-claims-corrected"></a>

- Three high-impact errors came from the README rewrite, or were propagated by it.
- The fabricated `code-surface` node kind was replaced.
- The 10-kind source-of-truth allow-list took its place.
- Cross-arc citations changed from `129/001` to `131/001/008 ADR-001` at six sites.
- The changelog was one of them.
- The Vitest count changed from 22 to 27.
- Batch A's consolidated cleanup addressed 22 findings.

#### Feature Descriptions Match Their Sources <a id="c-feature-descriptions-match-their-sources"></a>

- All 17 `feature_catalog` descriptions were compared with their source-module exports.
- Three were corrected, with matching playbook `OVERVIEW` lines.
