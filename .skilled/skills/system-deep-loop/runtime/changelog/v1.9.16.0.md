# v1.9.16.0, Fan-out lineages know their directory

Each fan-out lineage now runs with `PWD` set to its own directory. Node's `spawn()` passed the parent's `PWD` on unchanged, and OpenCode tells the model its working directory from `PWD`, so a lineage could read and write the parent's checkout.

> Spec folder: `specs/cli-external-orchestration/087-opencode-worktree-confinement`

&nbsp;

## What's New at a Glance

- **A lineage reports its own directory.** `runLineageProcess` sets `PWD` to the resolved `cwd`, whether the parent passed a `PWD` or none.
