# v1.9.9.0, Hand-Written Dashboards Refused

v1.9.9.0 stops a research lineage that skipped the reducer from merging. A lineage whose dashboard lacks the reducer's stamp is refused, so a hand-written dashboard can no longer pass as reduced output.

> Spec folder: `specs/system-deep-loop/038-review-and-cli-lineage/007-lineage-reducer-compliance` (Level 1)

&nbsp;

## What's New at a Glance

- **A hand-written dashboard no longer merges as reduced output.** A research lineage whose `deep-research-dashboard.md` lacks the reducer's stamp is refused, so its registry stays out of the merged result and the run lists it under `refused_reducer_provenance`. Only research lineages with an on-disk registry are checked, so review merges are unchanged.
- **The attribution table marks refused lineages.** Their verdict cell reads REFUSED, so the table cannot present a lineage as merged while the payload reports it refused.
- **A lineage with no dashboard still merges, with a warning.** Its provenance is unconfirmed rather than failed. The run lists it under `reducer_provenance_warnings`.
- **One bad dashboard refuses only its own lineage.** A dashboard that is a link or resolves outside the artifact root no longer aborts the merge. The other lineages merge as usual.
