# v1.9.8.0, Review Folders Without a Config

v1.9.8.0 lets the review reducer read the 43 older and per-lineage review folders that keep a state log but no `deep-review-config.json`.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/015-closeout/007-review-reducer-missing-config` (Level 1)

&nbsp;

## What's New at a Glance

- **A missing config is a warning, not a crash.** `reduceReviewState` reduces on default settings and records the missing file the way it records a corrupt state-log line.
- **Strict reduction still fails loudly.** Without `--lenient` the reducer throws `STATE_CORRUPTION` and names `deep-review-config.json`, instead of a bare `ENOENT`.

No migration required.
