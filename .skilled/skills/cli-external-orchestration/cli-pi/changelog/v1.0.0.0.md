This first release makes Pi the sixth workflow mode. The mode sits in the external command-line interface (CLI) orchestration hub.

&nbsp;

## What's New at a Glance

- Pi's route refuses self-invocation.
  - A guarded check confirms the `pi` program is available.
  - The packet adds no second advisor identity.
  - The packet adds no packet-local execution adapter.
- Routing guidance covers print, JSON and RPC.
  - The local Pi contract pin confirmed the headless (without an interactive interface) entry point.
  - The local Pi contract pin confirmed a JSON (structured data format) event stream.
  - The local Pi contract pin confirmed a persistent RPC (remote procedure call) surface.
- The local contract pin confirms Pi's installed version and failure behavior.
  - The pin records the failure when a provider is missing.
  - The pin records inconsistent failure exit codes (numbers returned when a command fails).
  - The pin also confirms extension validation.
  - The pin confirms the trusted install verb for `pi-subagents`.
- Native Pi resources are distinct from community packages.
  - Pi's native skills and prompt-template discovery remain documented but unconfirmed.
  - `pi-subagents` and `pi-mcp-extension` are community packages.
  - `pi-subagents` and `pi-mcp-extension` are not first-party Pi features.
