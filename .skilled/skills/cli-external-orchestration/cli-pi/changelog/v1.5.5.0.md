- The provider reference names Xiaomi's v2.6 models.
  - `references/providers-and-models.md` mechanically updates the two roster rows.
  - The two roster rows become `mimo-v2.6-pro` and `mimo-v2.6-pro-ultraspeed`, with case preserved.
  - The low-latency tier note stays with the `-ultraspeed` row.
  - That is because it describes the tier structure being renamed.
- The `cli-pi` version identifies the reference generation.
  - Version `1.5.5.0` lets the reference's audience tell which generation it documents.
- Earlier evidence and release history stay as recorded.
