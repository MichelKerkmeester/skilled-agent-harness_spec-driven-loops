- **The provider reference names Xiaomi's v2.6 models.** `references/providers-and-models.md` mechanically updates the two roster rows to `mimo-v2.6-pro` and `mimo-v2.6-pro-ultraspeed`, preserving case. The low-latency tier note stays with the `-ultraspeed` row because it describes the tier structure being renamed.
- **The `cli-pi` version identifies the reference generation.** Version `1.5.5.0` lets the reference's audience tell which generation it documents.
- **Earlier evidence and release history stay as recorded.** The dated evidence cell in the allowlist-smoke playbook preserves its capture against that moment's enforcement source. Changelog history keeps the IDs each release shipped.
