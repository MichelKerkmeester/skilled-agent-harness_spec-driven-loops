# v1.5.19.0, long prose lines become short ones

Nine single lines in SKILL.md ran 400 to 930 characters, so the provider roster, the execution ownership paragraph and rules 10 to 12 each asked a reader to separate several facts from one line. Each is now short sentences, and the pi-blackhole warning carries its five conditions as five lines. Every command, path, environment variable, model id and number is the one that was already there.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/010-prose-clarity-pass` (Level 2)

&nbsp;

## What's New at a Glance

- **The provider facts read in one pass.** The closed roster, the four reachable providers and the `google` default each sit in two or three lines, with the instruction first and the reason after it.
- **A warning with five conditions reads as five lines.** The pi-blackhole compaction notice states the trigger, the effect, the `PI_BLACKHOLE_PASSIVE=true` escape and the filter that passes it through, one per line.
- **The rules state the instruction first.** Rules 10 to 12 lead with what to do and follow with the evidence, so a reader can act on the first line.
- **Nothing was dropped.** Every command, flag, path, environment variable, model id and observed value appears exactly as it did before.
- **Nothing routes differently.** No intent dictionary, resource map, loading level, guard or default changed, and the machine blocks are byte for byte what they were.

Nothing to do. The prose is the only change.
