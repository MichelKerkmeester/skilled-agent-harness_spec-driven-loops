# cli-pi v1.4.1.0

## Changed

- **Roster retirement** (spec `specs/cli-external-orchestration/056-roster-drop-deepseek-api-pro-terra/`): the direct DeepSeek API provider, DeepSeek V4 Pro in every form, and GPT-5.6 Terra were removed from `references/providers-and-models.md`. The closed roster now carries six providers: `openai-codex` (sol/luna), `minimax`, `xiaomi`, `opencode-go` (DeepSeek V4 Flash, Qwen 3.8 Max, GLM-5.3-Flash), `openrouter` (three-model allowlist unchanged), and `cline-pass` (flash + GLM-5.3-Flash).
- The bare `deepseek-v4-flash` literal is documented as opencode-go-fronted; the direct `--provider deepseek` dispatch shape no longer exists in any example.
- `references/providers-and-models.md` §3/§5 dispatch examples now use `--provider opencode-go --model deepseek-v4-flash --thinking max`, matching the deep-loop fan-out default (`PI_DEFAULT_MODEL` in `executor-config.ts` moved from `deepseek-v4-pro` to `deepseek-v4-flash`; the enforcement allowlists dropped `deepseek-v4-pro` and `gpt-5.6-terra`).
- Frontmatter version moved from 1.0.0.0 to 1.1.0.0.

## Not Changed

- The OpenRouter three-model allowlist, the cline-pass flash/GLM routes, the `--thinking` lever semantics, and the flash max-tier pin policy.
