# v1.2.0.0, Model Guidance Finds a Home

Pi's model-selection guidance now has a home in `cli-reference.md` §13.

- The standalone `model-dispatch-gpt-5.6.md` file is retired.
- The reference covers `--provider`, `--model` and standalone `--thinking`.
- The authenticated provider roster is live-verified.
- It lists `openai-codex`, `deepseek`, `minimax` and `xiaomi`.

The release also corrects extension lifecycle evidence and retargets model-roster references to that section.

- The native extension record now reports 33 events.
- Model-roster pointers now lead to `cli-reference.md` §13.
- The manual-testing playbook now has 20 scenarios, up from 19.
- New `PI-020` adds a session-lifecycle trace.

&nbsp;

## Why This Release

Sibling references for `cli-cursor`, `cli-devin` and `cli-opencode` place model-selection guidance in their `cli-reference.md` sections and delegation docs.

- Pi's standalone guide differed from that convention.

## Pi Model Selection

Pi's model-selection guidance and its verified controls now sit in `cli-reference.md` §13.

#### One Home for Model Guidance <a id="c-one-home-for-model-guidance"></a>

- Before: `model-dispatch-gpt-5.6.md` contained the model-selection guide.
- Now: `cli-reference.md` §13 contains MODEL SELECTION.

#### Verified Controls and Roster <a id="c-verified-controls-and-roster"></a>

- The confirmed selection surface includes `--provider` and `--model`.
- The accepted `--model` forms are `provider/id` and `:<thinking>`.
- The standalone `--thinking` flag sets effort on `off|minimal|low|medium|high|xhigh|max`.
- The old guide marked the effort control and its ceiling `UNCONFIRMED`.
- Pi's scale ends at `max`, with no Pi-side value matching Codex's `ultra` ceiling for `gpt-5.6-sol`.
- A real `deepseek-v4-flash` dispatch confirmed the `deepseek` entry.
- The installed catalog no longer lists `gpt-5.6-terra`, so Pi's roster drops it.
