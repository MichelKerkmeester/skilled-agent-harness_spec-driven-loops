## Pi Model Selection

#### One Home for Model Guidance

- **Before:** `model-dispatch-gpt-5.6.md` contained the model-selection guide.
- **Now:** `cli-reference.md` §13 contains MODEL SELECTION.

&nbsp;

#### Verified Controls and Roster

The confirmed selection surface includes `--provider` and `--model`. The accepted `--model` forms are `provider/id` and `:<thinking>`. The standalone `--thinking` flag sets effort on `off|minimal|low|medium|high|xhigh|max`.

The old guide marked the effort control and its ceiling `UNCONFIRMED`. Pi's scale ends at `max`, with no Pi-side value matching Codex's `ultra` ceiling for `gpt-5.6-sol`.

A real `deepseek-v4-flash` dispatch confirmed the `deepseek` entry. The installed catalog no longer lists `gpt-5.6-terra`, so Pi's roster drops it.
