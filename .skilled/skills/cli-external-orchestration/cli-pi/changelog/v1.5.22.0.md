# v1.5.22.0, The Mistral provider

Pi now reaches the operator's Mistral subscription. Five providers are reachable.

&nbsp;

## What's New at a Glance

- **Mistral is a fifth provider.** Pi's builtin `mistral` provider needs no `.pi/models.json` block, and `.pi/settings.json` enables `mistral/deepseek-v4-1-flash-1017` and `mistral/zai-glm-5-3-flash`.
- **Both ids are dispatch-verified.** Each replied `OK` under `pi -p` on 2026-11-14.
- **Mistral is for direct dispatch only.** Neither id is in `PI_SUPPORTED_MODELS`, so the deep-loop fan-out refuses them.
- **The dotted ids keep DevPass.** The bare `deepseek-v4.1-flash-1017` and `glm-5.3-flash` literals still route through LLM Gateway.

&nbsp;

## Upgrade

No action needed. A Mistral dispatch needs the operator's Mistral key, saved once with `pi auth login mistral --api-key`.
