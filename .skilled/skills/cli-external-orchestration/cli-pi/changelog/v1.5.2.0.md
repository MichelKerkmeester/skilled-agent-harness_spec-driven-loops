# cli-pi v1.5.2.0

Fan-outs that took the DevPass DeepSeek default reached a dead model after the gateway deactivated its ID.

- v1.5.2.0 replaces that bare default with the DeepSeek V4.1 Flash line.
- The gateway now answers 410 for the former bare ID, `deepseek-v4-flash-vision-exp`.
- The message reads "has been deactivated and is no longer available".

It also updates the roster with the route's documented effort ladder, returned ID responses and published rates.

- The fan-out default is now `deepseek-v4.1-flash`.
- Fan-outs that omit a model use the new bare ID.
- The roster carries the documented effort ladder.
- Its default effort is `high`.

The replacement accepts images the same way as before.

- It carries the same 1.05M context.
- It raises the output ceiling to 384K.
- The OpenRouter and opencode-go literals are unchanged.

> [!IMPORTANT]
> 1 change can break an existing setup. Read these before you update.
>
> 1. The default's bare ID changed. [Replace the Deactivated Default](#c-replace-the-deactivated-default)

## DevPass DeepSeek

#### Replace the Deactivated Default <a id="c-replace-the-deactivated-default"></a>

> [!WARNING]
> The default's bare ID changed. Replace `deepseek-v4-flash-vision-exp` with `deepseek-v4.1-flash` anywhere the old bare ID is named.

- The previous literal was cli-pi's fan-out default.
- A fan-out that omitted a model and took that default reached a dead route after the gateway deactivated it.
- The replacement accepts images the same way as before.
- It carries the same 1.05M context.
- It raises the output ceiling to 384K.
- The OpenRouter and opencode-go literals are unchanged.
- They name different routes.
- Both still resolve.

#### Use the Documented Effort Ladder <a id="c-use-the-documented-effort-ladder"></a>

- Three levels plus off are supported.
- `none` disables thinking.
- `minimal` and `low` reach low.
- `medium`, `high` and `xhigh` reach high.
- `max` reaches max.
- The effort pin forces `max`.
- That is a real top level here.
- The route rejects `ultra`, although DeepSeek's own mapping table lists it.
- It also rejects the integer 1-100 form documented on the model card.
- The names above are the route's whole effort surface.

#### Distinguish the ID Forms <a id="c-distinguish-the-id-forms"></a>

- The bare form of `deepseek-v4.1-flash` returns `200`.
- The prefixed form returns `400 "Provider llmgateway does not support model deepseek-v4.1-flash"`.

#### See Rates Per Million Tokens <a id="c-see-rates-per-million-tokens"></a>

- The listed rates are per million tokens, including cached reads.
- Input: $0.15
- Output: $0.60
- Cached reads: $0.003
