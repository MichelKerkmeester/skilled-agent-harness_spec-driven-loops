Fan-outs that took the DevPass DeepSeek default reached a dead model after the gateway deactivated its ID. v1.5.2.0 replaces that bare default with the DeepSeek V4.1 Flash line and updates the roster with the route's documented effort ladder, returned ID responses and published rates.

## Why This Release

The gateway now answers 410 "has been deactivated and is no longer available" for the former bare ID, `deepseek-v4-flash-vision-exp`.

## What's New at a Glance

- **The fan-out default is now `deepseek-v4.1-flash`.** Fan-outs that omit a model use the new bare ID.
- **The roster carries the documented effort ladder.** Its default effort is `high`.
- **The ID examples distinguish bare and prefixed forms by their responses.** The upstream rewrite reports `deepseek/deepseek-v4.1-flash` instead of `gonka24/`.
- **The roster carries published rates instead of a comparison.** They come from the gateway's own model listing.

## DevPass DeepSeek

#### Replace the Deactivated Default

The previous literal was cli-pi's fan-out default. A fan-out that omitted a model and took that default reached a dead route after the gateway deactivated it.

The replacement accepts images the same way as before and carries the same 1.05M context. It raises the output ceiling to 384K. The OpenRouter and opencode-go literals are unchanged. They name different routes and both still resolve.

**Breaking:** The default's bare ID changed.

&nbsp;

#### Use the Documented Effort Ladder

Three levels plus off are supported. `none` disables thinking. `minimal` and `low` reach low. `medium`, `high` and `xhigh` reach high. `max` reaches max. The effort pin forces `max`, which is a real top level here.

The route rejects `ultra`, although DeepSeek's own mapping table lists it. It also rejects the integer 1-100 form documented on the model card. The names above are the route's whole effort surface.

&nbsp;

#### Distinguish the ID Forms

The bare form of `deepseek-v4.1-flash` returns `200`. The prefixed form returns `400 "Provider llmgateway does not support model deepseek-v4.1-flash"`.

&nbsp;

#### See Rates Per Million Tokens

The listed rates are per million tokens, including cached reads:

- Input: $0.15
- Output: $0.60
- Cached reads: $0.003
