The cli-pi v1.4.0.0 release rewrites the skill README purpose-first on the refined template. It also adds details about its outputs and verification material.

&nbsp;

## What's New at a Glance

- The skill README now follows the refined template.
  - It opens with a one-line pitch and a problem-first OVERVIEW.
  - It documents the conductor model, the conservative self-invocation guard and prompt-quality delegation.
  - It closes with troubleshooting, FAQ, verification and related documents.
- The README frontmatter version moves from `1.2.0.0` to `1.4.0.0`.
  - This re-aligns the README with the changelog head.
- An Output Contract Layer capability table covers Print, JSON and RPC.
  - Each entry states what the skill returns.
  - Each entry states when its contract earns its place.
  - The table matches the pilot's Plugin Knowledge Layer pattern.
- VERIFICATION and RELATED DOCUMENTS now include the manual-testing playbook.
  - This lets readers find the scenario suite behind the checks.
- Dispatch behavior remains unchanged.
  - The `command -v pi` probe is preserved from the prior README.
  - So is the self-invocation guard, with its ancestry and `.pi` heuristic.
  - So are three headless surfaces and shared deep-loop delegation.
- All seven `references/*.md` files, both `assets/*.md` files and the pinned contract pointer keep their paths and purposes.
  - No `SKILL.md` content moved.
  - No template asset, other skill README, vault file or runtime data moved.
