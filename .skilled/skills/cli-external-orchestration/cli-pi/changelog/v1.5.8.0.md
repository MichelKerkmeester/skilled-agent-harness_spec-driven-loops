This release brings three Pi records in line with the config and runtime they describe. The xiaomi section explains the picker change, the DevPass `gpt-6-luna` row states one verification status instead of two, and the PI-017 allowlist scenario expects the current ten ids and default.

> Spec folder: `specs/cli-external-orchestration/077-gpt-6-luna-sol-cutover` (Level 2)

---

## What Changed

#### Model Roster

- **Ultraspeed is out of the picker, not off the roster** -- `.pi/settings.json` now lists only `mimo-v2.6-pro` in `enabledModels`. That setting scopes startup selection and model cycling, not `--model`, so `mimo-v2.6-pro-ultraspeed` stays on the roster and dispatches with an explicit `--model xiaomi/mimo-v2.6-pro-ultraspeed`.
- **One status for DevPass Luna** -- the `.pi/custom-providers.md` row called `llmgateway/gpt-6-luna` both dispatch-verified and not yet dispatch-verified. It now reads catalog-listed and dispatch-verified on 2026-09-23.

#### Manual Testing Playbook

- **PI-017 expects the current allowlist** -- the scenario still expected `deepseek-v4-flash-vision-exp` as the default and carried an eleven-id capture from an older roster. It now expects `deepseek-v4.1-flash` and the ten current ids, with source output re-captured on 2026-09-23. Its live smoke step was not re-run.
