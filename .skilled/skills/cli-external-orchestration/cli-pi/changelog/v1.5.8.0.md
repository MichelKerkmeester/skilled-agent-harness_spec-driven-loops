This release brings three Pi records in line with the config and runtime they describe. The xiaomi section explains the picker change, the DevPass `gpt-6-luna` row states one verification status, and the PI-017 allowlist scenario expects the current ten ids and default.

> Spec folder: `specs/cli-external-orchestration/077-gpt-6-luna-sol-cutover` (Level 2)

## What's New at a Glance

- **Ultraspeed left the picker, not the roster.** `.pi/settings.json` lists only `mimo-v2.6-pro` in `enabledModels`, which scopes startup selection and model cycling, not `--model`, so `mimo-v2.6-pro-ultraspeed` still dispatches with an explicit `--model xiaomi/mimo-v2.6-pro-ultraspeed`.
- **DevPass Luna has one status.** The `.pi/custom-providers.md` row called `llmgateway/gpt-6-luna` both dispatch-verified and not yet dispatch-verified; it now reads catalog-listed and dispatch-verified on 2026-09-23.
- **PI-017 expects the current allowlist.** It expected `deepseek-v4-flash-vision-exp` as the default and carried an eleven-id capture from an older roster. It now expects `deepseek-v4.1-flash` and ten ids, with source output re-captured on 2026-09-23 and the live step not re-run.

## Upgrade

No migration required. Select `mimo-v2.6-pro-ultraspeed` with `--model` rather than the picker.
