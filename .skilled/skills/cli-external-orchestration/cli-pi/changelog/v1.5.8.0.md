This release brings two Pi records in line with the config and runtime they describe. The xiaomi section explains the picker change, and the supported-model allowlist smoke scenario expects the current ten ids and default.

> Spec folder: `specs/cli-external-orchestration/077-gpt-6-luna-sol-cutover` (Level 2)

## What's New at a Glance

- **Ultraspeed left the picker, not the roster.** `.pi/settings.json` lists only `mimo-v2.6-pro` in `enabledModels`, which scopes startup selection and model cycling, not `--model`, so `mimo-v2.6-pro-ultraspeed` still dispatches with an explicit `--model xiaomi/mimo-v2.6-pro-ultraspeed`.
- **The supported-model allowlist smoke expects the current allowlist.** It expected `deepseek-v4-flash-vision-exp` as the default and carried an eleven-id capture from an older roster. It now expects `deepseek-v4.1-flash` and ten ids, with source output re-captured on 2026-09-23 and the live step not re-run.

## Upgrade

No migration required. Select `mimo-v2.6-pro-ultraspeed` with `--model` rather than the picker.
