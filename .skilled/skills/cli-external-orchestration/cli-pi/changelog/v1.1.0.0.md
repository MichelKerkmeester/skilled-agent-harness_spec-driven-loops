This release brings `cli-pi`'s references, assets and general setup closer to the `cli-devin` and `cli-cursor` mode skills. It adds a reference for Pi capabilities with no sibling analog. It updates confidence framing with later evidence. It brings reference and prompt-template structures closer to sibling patterns.

## What's New at a Glance

- **Pi has a new capabilities reference.** `pi-tools.md` follows the `devin-tools.md` and `cursor-tools.md` structural pattern. It keeps this packet's confidence-labeling discipline. It catalogs persistent bidirectional RPC with `--mode rpc`. It also catalogs first-party native extensions and prompt templates. It covers the minimal built-in tool surface and reasoning-effort control.
- **Two references now cite live-verified evidence.** Since this packet's initial release, three phases live-verified claims. They are 007 (`007-pi-mcp-host-integration`), 012 (`012-pi-runtime-compatibility`) and 013 (`013-pi-manual-testing-playbook-authoring`). Those claims sat in `native-skills-and-extensions.md` and `mcp-and-third-party-packages.md`. Both files still framed them as `Per Pi docs, unconfirmed`. Phase 007 verified `pi-mcp-extension`'s stdio transport. Phase 012 verified `pi-subagents`' agent-mirroring. It also verified native prompt-template and extension discovery. That discovery is at the project-local surfaces this repository populates.
- **Five references gained a leading `OVERVIEW` section.** The files are `agent-delegation.md`, `model-dispatch-gpt-5.6.md`, `native-skills-and-extensions.md`, `mcp-and-third-party-packages.md` and `integration-patterns.md`. Each gained a section with `Core Principle`, `Purpose` and `When to Use`. That matches the section `cli-reference.md` already had. It also matches every `cli-devin` and `cli-cursor` reference file. Of pi's six references, only one previously lacked it. That was the one built first.
- **Integration patterns now cover cross-validation and anti-patterns.** `integration-patterns.md` gained `CROSS-VALIDATION WITH OTHER CLI EXECUTORS` and `ANTI-PATTERNS`. That matches every sibling packet's own `integration-patterns.md`.
- **Prompt templates gained an overview and more examples.** `prompt-templates.md` gained an `OVERVIEW` section with a flag-reference table. It gained a concrete `Example` under every existing template. It also gained a new `SPEC-FOLDER PRE-APPROVAL (GATE 3 BYPASS)` template.
- **Heading lint was corrected in `mcp-and-third-party-packages.md`.** Two pre-existing `h2_not_uppercase` issues were fixed. The section renumbering came with them.
