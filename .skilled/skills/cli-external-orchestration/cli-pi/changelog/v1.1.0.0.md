## What's New at a Glance

- **Pi has a new capabilities reference.** `pi-tools.md` follows the `devin-tools.md` and `cursor-tools.md` structural pattern while preserving this packet's confidence-labeling discipline. It catalogs persistent bidirectional RPC with `--mode rpc`, first-party native extensions and prompt templates, the minimal built-in tool surface and reasoning-effort control.
- **Two references now cite live-verified evidence.** Since this packet's initial release, phases 007 (`007-pi-mcp-host-integration`), 012 (`012-pi-runtime-compatibility`) and 013 (`013-pi-manual-testing-playbook-authoring`) live-verified claims that `native-skills-and-extensions.md` and `mcp-and-third-party-packages.md` still framed as `Per Pi docs, unconfirmed`. Phase 007 verified `pi-mcp-extension`'s stdio transport, while phase 012 verified `pi-subagents`' agent-mirroring and native prompt-template and extension discovery at the project-local surfaces this repository populates.
- **Five references gained a leading `OVERVIEW` section.** `agent-delegation.md`, `model-dispatch-gpt-5.6.md`, `native-skills-and-extensions.md`, `mcp-and-third-party-packages.md` and `integration-patterns.md` gained sections with `Core Principle`, `Purpose` and `When to Use`, matching the section `cli-reference.md` and every `cli-devin` and `cli-cursor` reference file already had. Of pi's six references, the only one that previously lacked it was the one built first.
- **Integration patterns now cover cross-validation and anti-patterns.** `integration-patterns.md` gained `CROSS-VALIDATION WITH OTHER CLI EXECUTORS` and `ANTI-PATTERNS`, matching every sibling packet's own `integration-patterns.md`.
- **Prompt templates gained an overview and more examples.** `prompt-templates.md` gained an `OVERVIEW` section with a flag-reference table, a concrete `Example` under every existing template and a new `SPEC-FOLDER PRE-APPROVAL (GATE 3 BYPASS)` template.
- **Heading lint was corrected in `mcp-and-third-party-packages.md`.** Two pre-existing `h2_not_uppercase` issues were fixed alongside the section renumbering.
