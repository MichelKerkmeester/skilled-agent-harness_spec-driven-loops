This release aligns cli-pi's references, assets, and general setup closer to the cli-devin and cli-cursor mode skills, and updates two references' confidence framing to reflect what phases 007/012/013 actually confirmed since this packet's initial release.

A new `pi-tools.md` reference catalogs Pi capabilities with no sibling analog — persistent bidirectional RPC (`--mode rpc`), first-party native extensions and prompt templates, the minimal built-in tool surface, and reasoning-effort control — matching the `devin-tools.md`/`cursor-tools.md` structural pattern while preserving this packet's own confidence-labeling discipline.

`native-skills-and-extensions.md` and `mcp-and-third-party-packages.md` both had sections still framed as "Per Pi docs, unconfirmed" for things phases 007/012/013 already live-verified: pi-mcp-extension's stdio transport (phase 007), pi-subagents' agent-mirroring (phase 012), and native prompt-template/extension discovery at the project-local surfaces this repo actually populates (phase 012). Those sections now cite the real evidence instead of carrying stale hedges forward.

`integration-patterns.md` gained a CROSS-VALIDATION WITH OTHER CLI EXECUTORS section and an ANTI-PATTERNS section, matching every sibling packet's own integration-patterns.md. `prompt-templates.md` gained an OVERVIEW section with a flag-reference table, a concrete "Example" under every existing template, and a new SPEC-FOLDER PRE-APPROVAL (GATE 3 BYPASS) template.

Five reference files (`agent-delegation.md`, `model-dispatch-gpt-5.6.md`, `native-skills-and-extensions.md`, `mcp-and-third-party-packages.md`, `integration-patterns.md`) gained a leading OVERVIEW section (Core Principle / Purpose / When to Use), matching the section this packet's own `cli-reference.md` and every devin/cursor reference file already had — the only one of pi's 6 references that previously lacked it was the one built first. Two pre-existing `h2_not_uppercase` lint issues in `mcp-and-third-party-packages.md` (predating this release) were fixed alongside the renumbering.
