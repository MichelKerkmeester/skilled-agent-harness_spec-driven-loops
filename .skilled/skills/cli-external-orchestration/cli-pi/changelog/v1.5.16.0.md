# v1.5.16.0, GPT-6.1 Terra on the openai provider

Pi can now dispatch GPT-6.1 Terra through the ChatGPT sign-in. A dispatch on `openai/gpt-6.1-terra` replied as expected, and the deep-loop fan-out accepts the model and routes it to the `openai` provider.

> Spec folder: `specs/cli-external-orchestration/083-gpt-6-1-terra-roster` (Level 1)

&nbsp;

## What's New at a Glance

- **GPT-6.1 Terra is a third openai model.** It sits beside GPT-6 Sol and GPT-6 Luna, and its effort ceiling is `ultra`, which Pi's `--thinking` scale reaches only up to `max`.
- **The fan-out allowlist accepts it.** A lineage that pins `gpt-6.1-terra` dispatches as `openai/gpt-6.1-terra` instead of being refused.
- **The model picker lists it.** `.pi/settings.json` adds `openai/gpt-6.1-terra` to the enabled models. The same change enables the `pi-claude-code-ui` package and sets `terminalTheme` to `false`, so that package leaves Pi on the repository's `dark` theme instead of switching it to the terminal's palette.

&nbsp;

## Upgrade

Run `pi update --models` once so Pi's own catalog carries the model. Without it a dispatch still answers, after a warning that Pi is using a custom model id.
