Pi reaches GPT-6 Luna two ways now. The `openai-codex` subscription route moves to `gpt-6-luna` and `gpt-6-sol`, and LLM Gateway gains `llmgateway/gpt-6-luna`, the Luna route this skill was missing.

> Spec folder: `specs/cli-external-orchestration/077-gpt-6-luna-sol-cutover` (Level 2)

## What's New at a Glance

- **GPT-6 on `openai-codex`** -- the ids come from Pi's own model catalog once `pi update --models` refreshes it; `.pi/models.json` keeps only the custom `llmgateway` and `cline-pass` providers, and `pi --list-models gpt-6` shows both ids.
- **GPT-6 Luna is the default** -- `.pi/settings.json` defaults to `llmgateway/gpt-6-luna` at the global `xhigh`, and the pi-blackhole compaction model is `openai-codex/gpt-6-luna` at `medium`.
- **Xiaomi from Pi's catalog** -- `mimo-v2.6-pro` and `mimo-v2.6-pro-ultraspeed` are native Pi models, so `.pi/models.json` drops its redundant `xiaomi` block and Pi uses its catalog values.
- **Luna through LLM Gateway** -- `llmgateway/gpt-6-luna` joins the DevPass roster at 1.05M context and $0.10 in, $0.50 out per million tokens. It is a direct-dispatch route; the fan-out's bare `gpt-6-luna` literal still maps to `openai-codex`.

## Upgrade

No migration required. The new gateway route uses the existing `${LLMGATEWAY_API_KEY}`, and a one-turn smoke on 2026-09-23 proved the credential.
