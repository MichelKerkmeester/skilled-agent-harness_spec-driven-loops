Pi reaches GPT-6 Luna on the subscription route now. The `openai-codex` subscription route moves to `gpt-6-luna` and `gpt-6-sol`.

> Spec folder: `specs/cli-external-orchestration/077-gpt-6-luna-sol-cutover` (Level 2)

## What's New at a Glance

- **GPT-6 runs on `openai-codex`.** The ids come from Pi's own model catalog once `pi update --models` refreshes it, so `.pi/models.json` keeps only the custom `llmgateway` and `cline-pass` providers, and `pi --list-models gpt-6` shows both ids.
- **pi-blackhole compacts with Luna.** The pi-blackhole compaction model is `openai-codex/gpt-6-luna` at `medium`.
- **Xiaomi comes from Pi's catalog.** `mimo-v2.6-pro` and `mimo-v2.6-pro-ultraspeed` are native Pi models, so `.pi/models.json` drops its redundant `xiaomi` block and Pi uses its catalog values.
