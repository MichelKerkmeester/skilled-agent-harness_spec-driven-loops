MiMo V2.6 Pro can now be selected through the existing DevPass LLM Gateway route as well as the official Xiaomi route. The two provider-qualified selectors remain separate so direct use can choose the route without changing deep-loop fan-out behavior.

## What Changed

- Added `llmgateway/mimo-v2.6-pro` to the Pi configuration and picker.
- Documented the gateway catalog facts, including its `none`/`low`/`medium`/`high` effort ladder, 1M context, 131K output, image input, and published cost shape.
- Kept the bare `mimo-v2.6-pro` fan-out literal mapped to `xiaomi`.
- Preserved the existing LLM Gateway credential reference and session-affinity setting.

## Not Changed

Historical cutover entries remain unchanged. MiMo V2.6 Pro UltraSpeed remains on the official Xiaomi route because the gateway catalog entry requested here is Pro only. A real Pi round-trip is still required to confirm the configured credential and upstream availability.
