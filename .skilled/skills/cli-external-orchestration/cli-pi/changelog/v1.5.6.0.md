Pi now lets you select MiMo V2.6 Pro through the existing DevPass LLM Gateway route. That route sits alongside the official Xiaomi route.

&nbsp;

## What's New at a Glance

- Choose the Gateway route in Pi.
  - The `llmgateway/mimo-v2.6-pro` selector is in the Pi configuration and picker.
- Read the gateway catalog facts.
  - Its documentation lists the `none`/`low`/`medium`/`high` effort ladder.
  - The documentation lists 1M context, 131K output, image input and published cost shape.
- Keep direct selection separate from fan-out.
  - The bare `mimo-v2.6-pro` fan-out literal remains mapped to `xiaomi`.
  - Provider-qualified selectors remain separate for direct use.
  - Historical cutover entries are unchanged.
  - MiMo V2.6 Pro UltraSpeed remains on the official Xiaomi route.
  - That is because the gateway catalog entry requested here is Pro only.
- Keep the existing gateway settings.
  - Pi retains the existing LLM Gateway credential reference and session-affinity setting.
  - A real Pi round-trip is still required to confirm the configured credential and upstream availability.

&nbsp;

## Upgrade

No migration required.
