MiMo now goes through LLM Gateway only. The `xiaomi` provider leaves Pi's roster. The deep-loop fan-out sends the bare `mimo-v2.6-pro` literal to `llmgateway`. The gateway does not serve `mimo-v2.6-pro-ultraspeed`. So `mimo-v2.6-pro-ultraspeed` leaves the roster with it.

> Spec folder: `specs/cli-external-orchestration/077-gpt-6-luna-sol-cutover` (Level 2)

## What's New at a Glance

- **Fan-out MiMo lineages use the gateway.** The bare `mimo-v2.6-pro` literal now builds `llmgateway/mimo-v2.6-pro`. A one-turn smoke through that command replied `OK` on 2026-09-23.
- **Ultraspeed is no longer allowed.** The gateway has no ultraspeed tier. So the fan-out refuses `mimo-v2.6-pro-ultraspeed`. The roster is nine ids. The supported-model allowlist smoke expects nine.
- **The picker drops Xiaomi.** `.pi/settings.json` no longer lists `xiaomi/mimo-v2.6-pro`. The provider reference drops its `xiaomi` section.

## Upgrade

Use `llmgateway/mimo-v2.6-pro` wherever a direct dispatch named `xiaomi/mimo-v2.6-pro`. A lineage that names `mimo-v2.6-pro-ultraspeed` now fails at the allowlist. So switch it to `mimo-v2.6-pro`. Pi's stored Xiaomi credential is left in place.
