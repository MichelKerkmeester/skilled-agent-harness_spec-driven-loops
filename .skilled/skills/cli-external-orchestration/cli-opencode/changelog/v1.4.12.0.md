The provider auth pre-flight now detects configured providers by ID. So it no longer reports the configured default as missing. The README documents the same check.

&nbsp;

## What's New at a Glance

- Auth checks now match provider IDs.
  - The pre-flight runs `opencode models <provider-id>`.
  - That command exits 0 when a provider is configured.
  - The command exits 1 when it is not.
  - The old `opencode providers list` check searched display names such as `OpenCode Go`.
  - So `opencode-go` appeared missing despite being the configured default.
  - On the maintainer's machine, the block reports `default=1 minimax_token=0 minimax_direct=1 llmgateway=1`.
