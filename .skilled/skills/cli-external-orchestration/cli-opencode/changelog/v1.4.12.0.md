The provider auth pre-flight now detects configured providers by ID, so it no longer reports the configured default as missing. The README documents the same check.

> Spec folder: `specs/cli-external-orchestration/077-gpt-6-luna-sol-cutover` (Level 2)

## What's New at a Glance

- **Auth checks now match provider IDs.** The pre-flight runs `opencode models <provider-id>`, which exits 0 when a provider is configured and 1 when it is not. The old `opencode providers list` check searched display names such as `OpenCode Go`, so `opencode-go` appeared missing despite being the configured default. On the maintainer's machine, the block reports `default=1 minimax_token=0 minimax_direct=1 llmgateway=1`.
