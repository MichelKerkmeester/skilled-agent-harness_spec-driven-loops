# v1.5.2.0, GPT-6.1 Terra returns to the GPT grid

Terra is back on the `openai` provider as GPT-6.1 Terra. A refreshed OpenCode 1 catalog lists `openai/gpt-6.1-terra` and `openai/gpt-6.1-terra-fast`, and a one-turn run on the base slug replied as expected.

> Spec folder: `specs/cli-external-orchestration/083-gpt-6-1-terra-roster` (Level 1)

&nbsp;

## What's New at a Glance

- **The GPT grid has three personas.** Sol, Luna and Terra each carry a base and a `-fast` slug, six slugs in all. The older `gpt-5.6-terra` slugs stay off the roster.
- **Terra's effort range is not yet measured here.** OpenCode does not report variant ranges, so the effort map names the Codex catalog's `low` to `ultra` range and says it is unmeasured on OpenCode.

&nbsp;

## Upgrade

Run `opencode models openai --refresh` on the OpenCode 1 fallback if the Terra slugs do not appear. OpenCode 2 lists no `openai` provider.
