The mode default moves to the newer DeepSeek Flash id, and the Cline DeepSeek row moves with it —
but the second route is listed rather than proven, and this entry says which is which.

## What Changed

#### Breaking

- **The mode default is `opencode-go/deepseek-v4.1-flash`.** It was
  `opencode-go/deepseek-v4-flash-vision-exp`. Same route, same catalog price ($0.15 in and $0.60 out
  per million tokens, cached reads $0.003), same 1M context and 384K output ceiling, and it still
  takes images, so the swap trades no capability and no price for a newer model. The `--variant max`
  policy pin is unchanged and still lands on a tier this route carries.
- **The Cline DeepSeek row is `cline-pass/cline-pass/deepseek-v4.1-flash`.** It is **listing-only**.
  Cline's own API lists `deepseek/deepseek-v4.1-flash`, but opencode resolves provider models from
  models.dev, which carries no cline-pass V4.1 entry, so this id fails at resolution with
  `Unexpected server error` before any request leaves the machine — the same signature the
  GLM-5.3-Flash note in the same section already documents. The superseded
  `cline-pass/cline-pass/deepseek-v4-flash` remains available upstream and is named in the row as the
  fallback until a live turn passes.

#### Fixes

- **A price claim the catalog contradicts.** The superseded row said the opencode-go flash route
  billed $0.22 in and $0.66 out per million. The catalog reports $0.15 and $0.60 for every flash id on
  that route, so the replacement carries the measured figures instead of the inherited comparison.
- **The default model was named in eight places and all eight moved.** `SKILL.md`'s default-invocation
  note, quick-invocation command, model-selection line and operating-rule list, plus the roster's
  provider intro, default row, defaults table, dispatch envelope and effort table.
- **The deep-loop pin assertion follows the live route.** The private copy of the effort-pin test in
  `executor-config.vitest.ts` asserted the opencode-go literal that is no longer the default; it now
  asserts the one that is. The pin pattern itself already covered the new id, so no runtime change was
  needed.

## Verification

- Live dispatch on the new default: `opencode run --model opencode-go/deepseek-v4.1-flash
  --variant max` returned its token for $0.0012.
- Catalog read on 2026-09-11: 1M context, 384K output, `images: yes`, variants `low`/`high`/`max`,
  $0.15 in and $0.60 out per million.
- The Cline route is **not** reported as working. A catalog gap and a quota block are both recorded,
  and every attempt that day returned `429 monthly Clinepass limit`, including the previously working
  V4-Flash id.
- `fanout-run.vitest.ts` and `executor-config.vitest.ts` together: 213 tests, 213 pass, 0 fail.
