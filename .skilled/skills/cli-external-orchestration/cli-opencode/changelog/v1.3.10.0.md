To keep cli-opencode's docs consistent with the rest of the skill set as spec phases change, this release aligns the prompt-quality card and three reference docs with the sk-doc templates and removes ephemeral spec, packet and phase pointers from them. Dispatch behavior is unchanged.

> Spec folder: `.opencode/specs/skilled-agent-orchestration/130-prompt-knowledge-layering/012-cli-doc-alignment/` (Level 1)

## What's New at a Glance

- **The prompt-quality card follows the sk-doc asset template.** `assets/prompt-quality-card.md` now opens with `## 1. OVERVIEW` for Purpose and Usage, uses ALL-CAPS numbered sections and ends with `## N. RELATED RESOURCES`. The framework and CLEAR tables remain in the canonical card instead of being inlined.
- **Three reference docs follow the sk-doc reference template.** `references/permissions-matrix.md`, `references/destructive-scope-violations.md` and `references/context-budget.md` now open with `## 1. OVERVIEW` covering Purpose, When to Use and Core Principle. They use ALL-CAPS numbered sections and rewrite ephemeral spec, packet and phase pointers, including ADR IDs, `Phase 003` and spec-folder paths, in durable wording.

No migration required.
