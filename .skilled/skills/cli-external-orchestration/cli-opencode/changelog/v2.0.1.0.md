# v2.0.1.0, The Battery Server Listens on Loopback Only

The doctor battery's OpenCode 2 check starts a private server. It listens on loopback only, because it inherits your environment, which can include credentials.

&nbsp;

## What's New at a Glance

- Before, the server took OpenCode's default network address.
- The server now starts with `--hostname 127.0.0.1`, the loopback address.

&nbsp;

## Upgrade

No migration required.
