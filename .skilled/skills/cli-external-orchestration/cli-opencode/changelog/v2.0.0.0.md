# v2.0.0.0, OpenCode 2 Is the Only Supported Major

Only OpenCode 2 stays in the skill now. Every OpenCode 1 branch is gone.

- The setup helper and the doctor battery target OpenCode 2.3.2.
- Version resolution reports an OpenCode 1 binary as unsupported.

An old OpenCode 1 install can now be removed in one step.

- The `remove-v1` mode removes the old package and its launcher.
- It leaves other installs and your data files in place.

Some removals change what reaches your scripts, loops and session history.

- Native lineages no longer run.
- Scripts that pass the v1 argv must switch to the v2 form.
- Session readers no longer see sessions written before 2026-10-22.

> [!IMPORTANT]
> Four changes can break an existing setup. Read these before you update.
>
> 1. Scripts that call the `opencode1` launcher stop working once it is removed. [Only the OpenCode Launcher Remains](#c-only-the-opencode-launcher-remains)
> 2. Native lineages no longer run. [Native Lineages Are Dropped](#c-native-lineages-are-dropped)
> 3. Scripts that pass the v1 argv must switch to the v2 form. [The Wrapper Accepts Only the v2 Form](#c-the-wrapper-accepts-only-the-v2-form)
> 4. Session readers no longer see sessions written before 2026-10-22. [Session Readers Use Only v2 Tables](#c-session-readers-use-only-v2-tables)

&nbsp;

## Why This Release

The skill ran OpenCode 1 and OpenCode 2 side by side. Each layer kept a v1 branch. The install guide also told you to install a second major.

- The v1 branches never ran on the supported version.
- Each branch added setup modes, CI legs or tests to keep working.
- OpenCode 2.3.2 is now the one version in use.

## Setup and Launchers

The setup helper now handles OpenCode 2 only. Its side-by-side modes are gone. A new mode removes an old install.

#### Remove an Old OpenCode 1 Install <a id="c-remove-an-old-opencode-1-install"></a>

- Run `opencode-setup.sh remove-v1` once to clean up an old install.
- It removes the OpenCode 1 package and the `opencode1` launcher.
- It refuses any launcher path outside its own bin directory.
- A link that belongs to another install is kept.
- After it runs, `opencode --version` prints `opencode v2.3.2`.

#### Only the OpenCode Launcher Remains <a id="c-only-the-opencode-launcher-remains"></a>

> [!WARNING]
> Scripts that call `opencode1` stop working once `remove-v1` runs. Point them at `opencode` instead.

- The setup helper accepts three modes: `v2`, `remove-v1` and `check`.
- It no longer writes an `opencode1` launcher.

&nbsp;

## Dispatch and Deep Loops

Dispatch and deep loops now take only the OpenCode 2 command form.

#### Two Dispatch Rules Are Retired <a id="c-two-dispatch-rules-are-retired"></a>

- The `no-bare-agent-general` rule applied only to OpenCode 1.
- The `command-flag-for-slash-prompt` rule applied only to OpenCode 1.
- Both rules and their checks are removed from the dispatch hook.

#### Native Lineages Are Dropped <a id="c-native-lineages-are-dropped"></a>

> [!WARNING]
> Native lineages no longer run. The OpenCode 1 `run --command deep/<loop>` path has no replacement, so a loop that used it needs another executor.

- The native-lineage path in the fan-out runner is deleted.
- This was a deliberate removal, and nothing replaces it.

#### The Wrapper Accepts Only the v2 Form <a id="c-the-wrapper-accepts-only-the-v2-form"></a>

> [!WARNING]
> Scripts that pass the v1 argv must switch to the v2 form before they run.

- The loop wrapper no longer has a v1 `-m` branch.
- It no longer reads the help text to guess the OpenCode version.
- The fan-out runner uses the v2 argv only.

#### Deep Loops Drop the Pure Flag <a id="c-deep-loops-drop-the-pure-flag"></a>

- The deep-review and deep-research protocol docs no longer name `--pure`.
- The two deep-loop presentation files no longer name it either.
- The compiled deep contracts were regenerated from their sources.

&nbsp;

## Plugins and Session History

Plugins listen only for events OpenCode 2 defines. The session readers open only the v2 tables.

#### Plugin Events Match OpenCode 2 <a id="c-plugin-events-match-opencode-2"></a>

- The `server.instance.disposed` and `app.disposed` branches are removed.
- The 2.3.2 binary has no literal for either event.
- The `session.resumed`, `session.compact` and three `question.*` branches go for the same reason.
- The `global.disposed` branch stays, because the 2.3.2 binary defines that event.

#### Session Readers Use Only v2 Tables <a id="c-session-readers-use-only-v2-tables"></a>

> [!WARNING]
> Session readers no longer see sessions written before 2026-10-22. The older rows stay in the database, but the readers skip the legacy tables.

- The readers read `session_v2` and `session_message` only.
- The legacy `part` table reads are gone as well.
- The decision-capture sweep reads the same v2 tables.

#### The Plugin Bridge Gains a Hidden Factory <a id="c-the-plugin-bridge-gains-a-hidden-factory"></a>

- The bridge drops its v1-facing `server` key.
- Each plugin exports an `id` and a `setup` function.
- A hidden `factory` property holds the hook builder. Tests and helpers can call it directly.

## Doctor and Checks

The doctor battery now checks the OpenCode 2 family only.

#### The Doctor Battery Checks OpenCode 2 Only <a id="c-the-doctor-battery-checks-opencode-2-only"></a>

- The battery drops its OpenCode 1 legs.
- Those legs covered plugin discovery, plugin load and the v1 command listing.
- On OpenCode 2.3.2 all four remaining legs pass.

&nbsp;

## How It Was Checked

The OpenCode suites ran before and after the change. The plugin event names were read from the 2.3.2 binary. A live battery and a live dispatch also ran on OpenCode 2.3.2.

#### Before and After <a id="c-before-and-after"></a>

| Check | Before | After |
|---|---|---|
| `node --test` over the OpenCode suites | 843 pass, 1 fail, 1 skip of 845 | 831 pass, 1 fail, 1 skip of 833 |
| Dispatch audit, vitest | 133 of 133 pass | 133 of 133 pass |
| Deep-loop runtime OpenCode suites | 418 pass, 9 skip | 411 pass, 9 skip, 0 fail |

The after counts are lower. The v1-only tests were removed with the v1 code. One node test still fails: `Claude source clamps prompts, keeps fallback parity, and flushes fail-open output`. It also fails on the main branch.

## Upgrade Notes

Move every install to OpenCode 2.3.2 before you update. Then check the steps that match your setup.

#### Before You Start <a id="c-before-you-start"></a>

1. Run `bash .skilled/skills/cli-external-orchestration/cli-opencode/scripts/opencode-setup.sh v2` to install OpenCode 2.3.2.
2. Run `opencode --version`. It prints `opencode v2.3.2`.
3. Run `bash .skilled/skills/cli-external-orchestration/cli-opencode/scripts/opencode-setup.sh remove-v1` to remove an old OpenCode 1 install.

<details>
<summary><b>Setup and Launchers</b></summary>

- Replace any call to the `opencode1` launcher with `opencode`.
- Use only the `v2`, `remove-v1` and `check` setup modes.

</details>

<details>
<summary><b>Dispatch and Deep Loops</b></summary>

- Switch any script that passes the v1 argv to the v2 form.
- Stop relying on native lineages, which no longer run.
- Remove `--pure` from any custom protocol text you keep.

</details>

<details>
<summary><b>Plugins and Session History</b></summary>

- Expect sessions written before 2026-10-22 to be missing from the session readers.
- Build test hooks through the plugin's `factory` property, not the removed `server` key.

</details>

<details>
<summary><b>Doctor and Checks</b></summary>

- Run `node .skilled/commands/doctor/scripts/opencode-version-battery.cjs --family=v2` to confirm the OpenCode 2 legs pass.

</details>
