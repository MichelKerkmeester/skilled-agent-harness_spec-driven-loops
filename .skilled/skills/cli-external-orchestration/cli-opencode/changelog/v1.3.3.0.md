# cli-opencode v1.3.3.0: Cross-CLI prompt guidance

This documentation-only release brings cross-model prompt-quality findings into `assets/prompt-quality-card.md` for `cli-opencode`, following the `sk-prompt` master card v1.3.1.0 propagation. It updates §3 with three composition-guidance notes and advances `SKILL.md` frontmatter from 1.3.2.0 to 1.3.3.0 without changing its body.

> Spec folder: `specs/skilled-agent-orchestration/113-cli-devin-prompt-quality/003-eval-loop/` and `specs/skilled-agent-orchestration/113-cli-devin-prompt-quality/007-cross-model-validation/`

## Why This Release

Packet 113/007 measured council-seeded variants against `deepseek-v4-pro` via `cli-opencode`, the validation packet's primary dispatch surface originally planned per ADR-001, plus the DeepSeek direct API. `kimi-k2.6` ran through the `cli-devin` preset after the `opencode-go` account ran out of credits mid-packet, the split-surface decision recorded by ADR-003. The `003-eval-loop` folder is the SWE-1.6 empirical source. `007-cross-model-validation` is the evidence base where both findings held across models.

## What's New at a Glance

- **The existing pre-planning density note is softened.** It changes "without yield" to "without clear yield": frontier models tie medium with dense, while smaller coding-specialized models lose on dense.
- **A new Bundle-gate strictness note favors standard over strict.** The `Bundle-gate-aversion` finding measured +0.0525 for `deepseek-v4-pro` and +0.0305 for `kimi-k2.6`.
- **A new Anti-hallucination as secondary lever note ranks framework wording higher.** The measured differences were +0.0732 for `deepseek-v4-pro` and +0.0756 for `kimi-k2.6`.
