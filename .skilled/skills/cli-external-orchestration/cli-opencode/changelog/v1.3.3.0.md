# cli-opencode v1.3.3.0: Cross-CLI prompt guidance

This is a documentation-only release. It brings cross-model prompt-quality findings into `assets/prompt-quality-card.md` for `cli-opencode`. It follows the `sk-prompt` master card v1.3.1.0 propagation. It updates §3 with three composition-guidance notes. It advances `SKILL.md` frontmatter from 1.3.2.0 to 1.3.3.0. The body does not change.

## Why This Release

Packet 113/007 measured council-seeded variants against `deepseek-v4-pro` via `cli-opencode`. It also measured them against the DeepSeek direct API. `cli-opencode` is the validation packet's primary dispatch surface. Its decision record originally planned that. `kimi-k2.6` ran through the `cli-devin` preset. That came after the `opencode-go` account ran out of credits mid-packet. The packet's decision record captures that split-surface decision. The `003-eval-loop` folder is the SWE-1.6 empirical source. `007-cross-model-validation` is the evidence base. Both findings held across models there.

## What's New at a Glance

- **The existing pre-planning density note is softened.** It changes "without yield" to "without clear yield". Frontier models tie medium with dense. Smaller coding-specialized models lose on dense.
- **A new Bundle-gate strictness note favors standard over strict.** The `Bundle-gate-aversion` finding measured +0.0525 for `deepseek-v4-pro`. It measured +0.0305 for `kimi-k2.6`.
- **A new Anti-hallucination as secondary lever note ranks framework wording higher.** The measured differences were +0.0732 for `deepseek-v4-pro`. They were +0.0756 for `kimi-k2.6`.
