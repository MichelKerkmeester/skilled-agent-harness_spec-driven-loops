# v1.3, Credential Check Before Dispatch

v1.3 adds a credential check before dispatch.

- So the AI asks the user before choosing another model.
- It does not silently substitute one they have not approved.

The release restores the default and removes a provider.

- The release restores `opencode-go/deepseek-v4-pro` with `--variant high` as the `cli-opencode` default.
- It removes `github-copilot` from the skill's provider set.

The release also updates docs and metadata.

- The release updates default-position invocations, provider-auth guidance and the multi-provider playbook.
- It also refreshes the skill's provider metadata.

> [!IMPORTANT]
> 2 changes can break an existing setup. Read these before you update.
>
> 1. `github-copilot/<id>` users should migrate or log in. [Remove the GitHub Copilot Provider](#c-remove-the-github-copilot-provider)
> 2. External scripts must drop those references. [Remove Copilot-Only Tests](#c-remove-copilot-only-tests)

&nbsp;

## Why This Release

Provider Auth Pre-Flight (Smart Fallback) is the reason for this release.

- It makes the ASK-not-substitute decision explicit.
- It does so in the three credential states.

## Provider Defaults

The release restores the OpenCode Go default and removes the Copilot provider. It keeps direct DeepSeek access and distinct caller names.

#### Restore the OpenCode Go Default <a id="c-restore-the-opencode-go-default"></a>

- Default-position examples now use the restored command.
- The documented v1.2 default was `github-copilot/gpt-5.4`.
- The OpenCode Go gateway routes DeepSeek and other open models.
- DeepSeek's reasoning model gives deeper reasoning at low cost.
- It does so without per-provider OAuth friction.

<details>
<summary><b>Detailed file changes</b></summary>

- They appear in `SKILL.md`, `README.md`, all four `references/*.md` files and `assets/prompt-templates.md`.
- Within `SKILL.md`, this also updates the §3 Default Invocation block.
- It updates the override and Model Selection tables, Agent Delegation patterns and ALWAYS rule 3.
- Seven Essential Commands examples in `SKILL.md` were included in the update.

</details>

#### Keep Direct DeepSeek Access <a id="c-keep-direct-deepseek-access"></a>

- `cli-opencode` documents `opencode-go` and `deepseek` as its two providers.
- `deepseek` remains the direct API option outside the gateway.
- The `deepseek` provider calls DeepSeek's API directly.
- It bypasses the OpenCode Go gateway.
- The direct DeepSeek API surface stays unchanged.

#### Keep Caller Names Distinct <a id="c-keep-caller-names-distinct"></a>

- The `cli-copilot` sibling skill remains.
- `Copilot` mentions in cross-AI handback prose also remain because they identify external-runtime callers, not the removed provider.

#### Remove the GitHub Copilot Provider <a id="c-remove-the-github-copilot-provider"></a>

> [!WARNING]
> Operators who used `github-copilot/<id>` should migrate to an equivalent `opencode-go/<id>`.
> They should do this when the upstream model is available through the gateway.
> Or they should log in to `opencode-go` or `deepseek` before their first dispatch.

- `github-copilot/` is fully removed as a `cli-opencode` provider.

## Provider Authentication

The release adds a pre-dispatch credential check. It also defines the retry path after an authentication error.

#### Choose Before Dispatch <a id="c-choose-before-dispatch"></a>

- `SKILL.md` adds the pre-dispatch auth check in a new §3 subsection.
- ALWAYS rule 11 requires a one-shot `bash` check at session start.
- It runs before the first dispatch.
- The check runs `opencode providers list`.
- It captures the `OPENCODE_GO_OK` and `DEEPSEEK_OK` flags.
- The decision table routes `default-available` to the default.
- It prompts the user in the other two states.

<details>
<summary><b>The prompt choices</b></summary>

- In `default-missing-fallback-ready`, the prompt offers three choices.
- A is to use the configured fallback.
- B is to log in to the default.
- C is to name a different model.
- In `both-missing`, the user prompt presents a login-command menu.

</details>

#### Retry After Authentication Errors <a id="c-retry-after-authentication-errors"></a>

- An authentication error during dispatch clears the saved credential result.
- Then the pre-flight runs again before retry.
- The Error Handling table sends `provider/model not found` and `401 Unauthorized` back to the same pre-flight.

## Upgrade Notes

Adopt the new command. Migrate provider IDs and drop deleted test references where they apply.

#### Before You Start <a id="c-before-you-start"></a>

1. Replace the documented v1.2 invocation with the v1.3 command.

```bash
# Old (v1.2):
opencode run --model github-copilot/gpt-5.4 --variant high --agent general --format json --dir <repo>

# New (v1.3):
opencode run --model opencode-go/deepseek-v4-pro --variant high --agent general --format json --dir <repo>
```
