v1.3 adds a credential check before dispatch. So the AI asks the user before choosing another model. It does not silently substitute one they have not approved. The release restores `opencode-go/deepseek-v4-pro` with `--variant high` as the `cli-opencode` default. It removes `github-copilot` from the skill's provider set.

The release updates default-position invocations, provider-auth guidance and the multi-provider playbook. It also refreshes the skill's provider metadata.

## Why This Release

Provider Auth Pre-Flight (Smart Fallback) makes the ASK-not-substitute decision explicit. It does so in the three credential states.

## What's New at a Glance

- **`opencode-go/deepseek-v4-pro` with `--variant high` is the default again.** The documented v1.2 default was `github-copilot/gpt-5.4`.
- **`cli-opencode` documents `opencode-go` and `deepseek` as its two providers.** `deepseek` remains the direct API option outside the gateway.
- **Provider Auth Pre-Flight (Smart Fallback) adds a credential check before dispatch.** Its three states route to the default or a user prompt.
- **Two Copilot-only entries leave `03--multi-provider/`.** The remaining cases keep their IDs and the section range narrows.
- **Twenty-eight other playbook entries replace Copilot model examples.** The changes cover eight playbook sections.
- **`graph-metadata.json` and `SKILL.md` provider metadata are refreshed.** The causal summary names the gateway default and direct API.

## Provider Defaults

#### Restore the OpenCode Go Default

Default-position examples now use the restored command. They appear in `SKILL.md`, `README.md`, all four `references/*.md` files and `assets/prompt-templates.md`. Within `SKILL.md`, this also updates the §3 Default Invocation block. It updates the override and Model Selection tables, Agent Delegation patterns and ALWAYS rule 3. Seven Essential Commands examples in `SKILL.md` were included in the update. The OpenCode Go gateway routes DeepSeek and other open models. DeepSeek's reasoning model gives deeper reasoning at low cost. It does so without per-provider OAuth friction.

&nbsp;

#### Keep Direct DeepSeek Access

The `deepseek` provider calls DeepSeek's API directly. It bypasses the OpenCode Go gateway. The direct DeepSeek API surface stays unchanged.

&nbsp;

#### Keep Caller Names Distinct

The `cli-copilot` sibling skill remains. `Copilot` mentions in cross-AI handback prose also remain. That is because they identify external-runtime callers, not the removed provider.

&nbsp;

#### Remove the GitHub Copilot Provider

`github-copilot/` is fully removed as a `cli-opencode` provider. **Breaking:** Operators who used `github-copilot/<id>` should migrate to an equivalent `opencode-go/<id>`. They should do this when the upstream model is available through the gateway. Or they should log in to `opencode-go` or `deepseek` before their first dispatch.

## Provider Authentication

#### Choose Before Dispatch

`SKILL.md` adds the pre-dispatch auth check in a new §3 subsection. ALWAYS rule 11 requires a one-shot `bash` check at session start. It runs before the first dispatch. The check runs `opencode providers list`. It captures the `OPENCODE_GO_OK` and `DEEPSEEK_OK` flags. The decision table routes `default-available` to the default. It prompts the user in the other two states. In `default-missing-fallback-ready`, the prompt offers three choices. A is to use the configured fallback. B is to log in to the default. C is to name a different model. In `both-missing`, the user prompt presents a login-command menu.

&nbsp;

#### Retry After Authentication Errors

An authentication error during dispatch clears the saved credential result. Then the pre-flight runs again before retry. The Error Handling table sends `provider/model not found` and `401 Unauthorized` back to the same pre-flight.

## Upgrade Notes

- **Adopt.** Replace the documented v1.2 invocation with the v1.3 command.

```bash
# Old (v1.2):
opencode run --model github-copilot/gpt-5.4 --variant high --agent general --format json --dir <repo>

# New (v1.3):
opencode run --model opencode-go/deepseek-v4-pro --variant high --agent general --format json --dir <repo>
```

- **Repoint.** Operators previously relying on `github-copilot/<id>` should migrate to an equivalent `opencode-go/<id>`. They should do this when the upstream model is available through the gateway. Or they should log in before the first dispatch. Gateway model ID examples are `opencode-go/glm-5.1` and `opencode-go/kimi-k2.6`. The login commands are `opencode providers login opencode-go` and `opencode providers login deepseek`. Operators expecting a silent fallback should explicitly approve option A in the prompt.
- **Drop.** Remove external-script references to `001-copilot-default-gpt-5-4.md` and `002-copilot-claude-sonnet-4-6.md`.
