# v1.5.12.0, The auth and agent-listing commands on OpenCode 2.3.0

OpenCode 2.3.0 dropped two subcommands the docs still named. The docs now use the commands 2.3.0 accepts.

&nbsp;

## What's New at a Glance

- **Credentials are under `opencode auth`.** `opencode providers` is read as a directory argument on 2.3.0 and fails, so the docs say `opencode auth list` and `opencode auth login <provider>` and keep the OpenCode 1 form beside them.
- **Agents are listed by `opencode debug agents`.** 2.3.0 has no `agent` subcommand and no `debug skill`.

&nbsp;

## Upgrade

No action needed.
