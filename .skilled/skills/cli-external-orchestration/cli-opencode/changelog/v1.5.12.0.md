# v1.5.12.0, The setup helper installs OpenCode 2.3.0

`scripts/opencode-setup.sh` now installs `@opencode/cli@2.3.0`, the version the skill was verified on in 1.5.11.0.

> Spec folder: `specs/system-deep-loop/loop-architecture/004-workflow-logic-hardening/007-open-findings-follow-up`

&nbsp;

## What's New at a Glance

- **The pin is 2.3.0.** It is the `latest` tag of `@opencode/cli` on 2026-11-15.
- **The expected version is 2.3.0.** The install recipes, the pinned-targets table and the version checks name it. The notes about what was seen on 2.1.4 stay as history.
- **The link target is unchanged.** The 2.3.0 package keeps the `bin/opencode.exe` path 2.1.4 used.

&nbsp;

## Upgrade

A machine on 2.1.4 keeps working. Rerun the setup helper to move it to 2.3.0, and run `npm install -g @opencode/cli@2.1.4` to go back.
