# v1.5.3.0, Benchmark Report READMEs Follow the README Template

A benchmark report README written in the older layout had no overview section, so the README validator rejected it. Each such README under this skill now opens with a numbered overview, with its run and file sections numbered after it, the way a report rendered today reads. Only the headings moved.

> Spec folder: `specs/sk-doc/070-repo-doc-debt/004-benchmark-report-readmes` (Level 2)

&nbsp;

## What's New at a Glance

- **The validator accepts these reports.** Each one opens with `## 1. OVERVIEW`, followed by `## 2. RUN` and `## 3. FILES`.
- **No report says anything new.** The overview is the paragraph that used to close the report, moved to the top, and every other line is unchanged.

Nothing to do. This is a documentation-only fix.
