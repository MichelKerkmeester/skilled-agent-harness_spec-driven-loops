# cli-opencode v1.4.1.0: purpose-first README rewrite on the refined skill README template

**Released**: 2026-08-04
**Status**: Documentation release. Rewrites `README.md` purpose-first against the refined skill README template and the mcp-obsidian pilot shape: one-line pitch, problem-first OVERVIEW, capability surface, HVR-clean prose and a reconciled version field. No runtime, router or dispatch behavior changes.

---

## Summary

The README carried the older tabular reference-card style: an aspect table and feature-list sections with no human entry point. It also drifted from its own release history. The `version:` field read `1.3.0.29` while `SKILL.md` and the changelog had moved to `v1.4.0.0` in the providers-and-models release, and the roster prose still named providers the v1.4.0.0 catalog had retired (`kimi-for-coding`, the Token-Plan providers, `zai-coding-plan`). This release rewrites the README to the outcome-first voice the skill READMEs now use and lands the version field on top of the release it actually documents.

The rewrite opens with a one-line pitch in a blockquote, then an AT A GLANCE table, then a problem-first OVERVIEW that names the reader's situation (an external session that cannot load the project runtime) before any feature list. A new capability section, The Dispatch Surface, states what the skill can operate at the dispatch level: the full project runtime, parallel detached sessions, cross-AI handback, the provider catalog and agent delegation. Every dispatch fact from the old README survived the narrative pass: the default invocation shape, the `</dev/null` rule, the top-level `--agent` caveats, the three-layer self-invocation guard and the `--share` confirmation gate.

The provider prose now matches the v1.4.0.0 catalog: four documented providers (`deepseek` default, `minimax`, `xiaomi`, `openai`) with `references/providers-and-models.md` as the single source for model ids and `--variant` effort. The FAQ model-pick answer was corrected to the curated roster and the RELATED DOCUMENTS table gained the two references the body now points to.
