# v1.3.5.0, Xiaomi Token Plan Adds MiMo-V2.5-Pro

This documentation and registry addendum adds a new `cli-opencode` target. The target is Xiaomi Token Plan (Europe) and MiMo-V2.5-Pro. The skill gains another explicitly selectable model. Its default does not change. A live probe on OpenCode 1.15.13 found provider `xiaomi-token-plan-ams` configured and responsive.

## What's New at a Glance

- **MiMo-V2.5-Pro is an explicit target.** Its lowercase model id is `xiaomi-token-plan-ams/mimo-v2.5-pro`. This follows the existing MiniMax (`minimax-coding-plan`) setup. The skill default remains `opencode-go/deepseek-v4-pro`.
- **The provider has a named route and quota pool.** Its provider id is `xiaomi-token-plan-ams`. Its credential display is `Xiaomi Token Plan (Europe)`. Its quota pool is `xiaomi-token-plan`. The endpoint is provider-managed. No base URL is published.
- **Other live MiMo ids remain available.** The text and coding siblings are `xiaomi-token-plan-ams/mimo-v2.5`, `xiaomi-token-plan-ams/mimo-v2-pro` and `xiaomi-token-plan-ams/mimo-v2-omni`.
- **Omit `--agent` and put roles in the prompt body.** A one-shot dispatch to `xiaomi-token-plan-ams/mimo-v2.5-pro` returned cleanly on OpenCode 1.15.13 without the flag. On that version, `--agent general` warns that `general` is a subagent. It is not a primary agent. It then falls back to the default. This matches MiniMax's `--agent` contract.
- **Omit `--variant` by default.** Its behavior remains unverified pending `126/003`. Keep `context_length` as a `null` placeholder. That is because its value is unknown, also pending `126/003`.
- **No prompt framework is claimed for MiMo.** Template 15 documents the dispatch shape only. The best framework remains unknown pending the benchmark in `126/004`. MiMo has not been benchmarked. So no TIDD-EC, RCAF or other framework is claimed as a winner. MiniMax's TIDD-EC and dense pre-plan contract should not be assumed to transfer.
- **The free route uses the opencode-go gateway.** `opencode/mimo-v2.5-free` supports cheap iteration and probes. It shares the opencode-go credit pool. It is the v2.5 tier, not the Pro tier.
- **Xiaomi and MiMo terms were added to discovery metadata.** `derived.trigger_phrases` and `derived.key_topics` gain terms such as `xiaomi`, `mimo`, `mimo-v2.5-pro` and `xiaomi-token-plan-ams`.

## Upgrade

- **Authenticate.** Run `opencode auth login`. Select `Xiaomi Token Plan (Europe)`.
- **Confirm live ids.** Before dispatch, run `opencode models xiaomi-token-plan-ams`.
