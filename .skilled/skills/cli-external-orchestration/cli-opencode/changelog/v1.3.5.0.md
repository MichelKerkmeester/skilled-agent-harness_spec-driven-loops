# v1.3.5.0, Xiaomi Token Plan Adds MiMo-V2.5-Pro

This documentation and registry addendum adds Xiaomi Token Plan (Europe) and MiMo-V2.5-Pro as a new `cli-opencode` target, giving the skill another explicitly selectable model without changing its default. A live probe on OpenCode 1.15.13 found provider `xiaomi-token-plan-ams` configured and responsive.

## What's New at a Glance

- **MiMo-V2.5-Pro is an explicit target.** Its lowercase model id is `xiaomi-token-plan-ams/mimo-v2.5-pro`, following the existing MiniMax (`minimax-coding-plan`) setup. The skill default remains `opencode-go/deepseek-v4-pro`.
- **The provider has a named route and quota pool.** Its provider id is `xiaomi-token-plan-ams`, its credential display is `Xiaomi Token Plan (Europe)` and its quota pool is `xiaomi-token-plan`. The endpoint is provider-managed, and no base URL is published.
- **Other live MiMo ids remain available.** The text and coding siblings are `xiaomi-token-plan-ams/mimo-v2.5`, `xiaomi-token-plan-ams/mimo-v2-pro` and `xiaomi-token-plan-ams/mimo-v2-omni`.
- **Omit `--agent` and put roles in the prompt body.** A one-shot dispatch to `xiaomi-token-plan-ams/mimo-v2.5-pro` returned cleanly on OpenCode 1.15.13 without the flag. On that version, `--agent general` warns that `general` is a subagent rather than a primary agent, then falls back to the default, matching MiniMax's `--agent` contract.
- **Omit `--variant` by default.** Its behavior remains unverified pending `126/003`. Keep `context_length` as a `null` placeholder because its value is unknown, also pending `126/003`.
- **No prompt framework is claimed for MiMo.** Template 15 documents the dispatch shape only, while the best framework remains unknown pending the benchmark in `126/004`. MiMo has not been benchmarked, so no TIDD-EC, RCAF or other framework is claimed as a winner and MiniMax's TIDD-EC and dense pre-plan contract should not be assumed to transfer.
- **The free route uses the opencode-go gateway.** `opencode/mimo-v2.5-free` supports cheap iteration and probes, shares the opencode-go credit pool and is the v2.5 tier, not the Pro tier.
- **Xiaomi and MiMo terms were added to discovery metadata.** `derived.trigger_phrases` and `derived.key_topics` gain terms such as `xiaomi`, `mimo`, `mimo-v2.5-pro` and `xiaomi-token-plan-ams`.

## Upgrade

- **Authenticate.** Run `opencode auth login` and select `Xiaomi Token Plan (Europe)`.
- **Confirm live ids.** Before dispatch, run `opencode models xiaomi-token-plan-ams`.
