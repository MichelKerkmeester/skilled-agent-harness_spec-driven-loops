# v1.5.11.0, OpenCode 2.3.0 and the Mistral provider

The skill is verified against OpenCode 2.3.0, and the provider roster gains Mistral.

> Spec folder: `specs/cli-external-orchestration/runtime-lifecycle/004-cli-mistral-vibe-creation/002-mistral-provider-roster`

&nbsp;

## What's New at a Glance

- **OpenCode 2.3.0 is the verified OpenCode 2.** The setup script and the dual-version CI workflow pin `@opencode/cli@2.3.0`. OpenCode 1.19.4 stays the fallback.
- **The version battery knows the v2 `goal` command.** OpenCode 2.3.0 lists `goal` with no command folder entry, so the battery counts it as built in.
- **Mistral joins the roster.** OpenCode's built-in `mistral` provider reaches the operator's Mistral subscription at `https://api.mistral.ai/v1`.
- **Mistral ids use dashes.** The DeepSeek id is `deepseek-v4-1-flash-1017` and the GLM id is `zai-glm-5-3-flash`. The dotted DevPass forms do not resolve there.

&nbsp;

## Upgrade

Install OpenCode 2.3.0 with the setup script to match the verified version. Save a Mistral key through OpenCode before a Mistral dispatch.
