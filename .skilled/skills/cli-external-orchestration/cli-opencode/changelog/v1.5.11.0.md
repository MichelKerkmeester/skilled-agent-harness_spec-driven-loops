# v1.5.11.0, OpenCode 2.3.0 and the Mistral provider

The skill is verified against OpenCode 2.3.0. The provider roster gains Mistral.

&nbsp;

## What's New at a Glance

- OpenCode 2.3.0 is the verified OpenCode 2.
  - The setup script and the dual-version CI workflow pin `@opencode/cli@2.3.0`.
  - OpenCode 1.19.4 stays the fallback.
- The version battery knows the v2 `goal` command.
  - OpenCode 2.3.0 lists `goal` with no command folder entry, so the battery counts it as built in.
- Mistral joins the roster.
  - OpenCode's built-in `mistral` provider reaches the operator's Mistral subscription at `https://api.mistral.ai/v1`.
- Two Mistral ids are allowed.
  - `mistral/deepseek-v4-1-flash-1017` and `mistral/zai-glm-5-3-flash` each replied `OK` at `#max` on OpenCode 2 on 2026-11-14.
  - Every other `mistral` id stays forbidden.
- Mistral ids use dashes.
  - The DeepSeek id is `deepseek-v4-1-flash-1017` and the GLM id is `zai-glm-5-3-flash`.
  - The dotted DevPass forms do not resolve there.
- Billing is unconfirmed.
  - OpenCode prices a turn at Mistral's list rate.
  - Whether a turn draws on the subscription pool is UNKNOWN until the console counter is read.

&nbsp;

## Upgrade

Install OpenCode 2.3.0 with the setup script to match the verified version. Save a Mistral key through OpenCode before a Mistral dispatch.
