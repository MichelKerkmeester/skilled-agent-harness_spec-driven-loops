This release restores the missing sk-doc section dividers in cli-opencode's numbered reference docs so they scan cleanly and match the rest of the skill set. Only blank lines and `---` lines changed. Dispatch behavior did not change.

> Spec folder: `.opencode/specs/skilled-agent-orchestration/130-prompt-knowledge-layering/014-doc-divider-sweep-and-sk-prompt-cleanup/` (Level 1)

## What's New at a Glance

- **Numbered H2 sections now have dividers.** The `sk-doc` templates require a standalone `---` before each numbered H2. The release adds the separator before every non-first numbered H2 in `references/agent-delegation.md`, `references/integration-patterns.md`, `references/opencode-tools.md`, `references/permissions-matrix.md` and `references/context-budget.md`.
- **Sections 4 and 9 now have immediate dividers.** In `agent_delegation.md`, each section's only nearby `---` sat in the previous section's body rather than before its H2. A divider now sits immediately before each H2.
- **Section 1 now has a leading divider in two references.** `references/permissions-matrix.md` and `references/context-budget.md` now have a leading `---` before section 1.
- **The CLI reference divider fix was deferred.** At sweep time, `references/cli-reference.md` carried a new, unrelated uncommitted model-id row. The fix was held back to avoid bundling that change.
