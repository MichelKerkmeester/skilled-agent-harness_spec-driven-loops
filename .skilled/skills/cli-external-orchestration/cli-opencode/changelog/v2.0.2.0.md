# v2.0.2.0, No OpenCode 1 Code or Guide Remains

OpenCode 2 was already the only supported major. This release removes the rest of OpenCode 1. The removal helper, its refusal and its docs are gone.

> [!IMPORTANT]
> `opencode-setup.sh` no longer has a `remove-v1` mode. It takes only `v2` or `check`. Skilled no longer removes OpenCode 1 for you.

&nbsp;

## What's New at a Glance

- The version resolvers read major 2 as `v2`. Any other major, 1 included, is `unknown`.
- The `unsupported` family is gone.
- A deep-loop lineage still refuses an `unknown` binary.
- The skilled-loop wrapper no longer probes `--version` to refuse an OpenCode 1 binary.
- The setup helper's `check` mode no longer lists an `opencode1` launcher.
- The install guide drops its section on removing an old OpenCode 1 install.
- The model catalog drops ladders, runs and limits measured only on OpenCode 1. No OpenCode 2 result replaces them.
- The catalog drops `opencode models <provider> --verbose`. OpenCode 2.3.2 does not take it. Confirm a level with a one-turn run.

&nbsp;

## Upgrade

- Replace any `opencode-setup.sh remove-v1` call. Remove an old OpenCode 1 install by hand.
- Code that matched the `unsupported` family should match `unknown`.
