# v1.3.7.0, Prompt Guidance and Composition Order

v1.3.7.0 removes duplicated framework and model override material so dispatchers can follow the source for each kind of prompt guidance. It also sets an explicit order for prompt composition. This documentation-only update does not change dispatch behavior.

## What's New at a Glance

- **The framework table is replaced with a canonical reference.** The duplicated table is removed from `assets/prompt-quality-card.md`, and dispatchers should read framework guidance from the canonical `sk-prompt` card.
- **The MiniMax and MiMo overrides now point to their profiles.** No information was lost when a two-row table mapped each model slug and framework to its `sk-prompt-models` profile, the maintained source of truth.
- **The quality card description reflects its new scope.** It now describes a quality checklist and per-model pointer table rather than a framework reference.
- **`SKILL.md` sets the prompt-composition order.** Per-model profiles in `sk-prompt-models` take precedence over `sk-prompt` framework guidance, which takes precedence over local quality-card defaults. A link to the `sk-prompt-models` hub is included.

## Upgrade

No migration required.
