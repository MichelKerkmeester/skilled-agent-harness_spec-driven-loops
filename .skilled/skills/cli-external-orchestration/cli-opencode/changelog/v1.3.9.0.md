# cli-opencode v1.3.9.0: Tier-3 Guidance, Model Links and Discovery Triggers

This refinement closes prompt-guidance and discovery drift. The 130 deep research found that drift. Dispatch behavior is unchanged.

## What's New at a Glance

- **Tier-3 guidance points to the canonical prompt card.** `SKILL.md` now points its deep-path escalation bullet to `sk-prompt/assets/cli-prompt-quality-card.md`. It does this under its Tier 3 deep-path guidance. It does not repeat the trigger list. That list had drifted from canonical.
- **The prompt card links to each model profile.** `assets/prompt-quality-card.md` replaces its directory-only pointer with per-model profile links. The links cover `deepseek`, `kimi`, `qwen` and `glm`. Its introduction now names the `opencode-go` cluster it dispatches.
- **Discovery recognizes the model names.** `graph-metadata.json` adds `deepseek`, `kimi`, `qwen` and `glm` to `trigger_phrases` and `key_topics`. It also refreshes `last_updated_at`. These models are dispatched here. `qwen3.6` is now reachable by name.
