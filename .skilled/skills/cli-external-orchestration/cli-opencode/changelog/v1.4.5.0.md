This release updates the DevPass DeepSeek row, records its effort settings, corrects the gateway model count and moves examples off a deactivated ID.

## Why This Release

The DevPass roster carried a DeepSeek ID the gateway had switched off. The other two claims in that section were checked against the live API rather than carried forward.

## What's New at a Glance

- **The DevPass DeepSeek row now uses `llmgateway/deepseek-v4.1-flash`.** The gateway returns `410` for the retired ID.
- **The effort table now lists the route's accepted ladder.** It distinguishes accepted settings from rejected values.
- **The gateway model count is corrected to 262.** The previous count was 183.
- **The bare-ID example and upstream-rewrite note now use a live ID.** The bare and prefixed request forms receive different responses.

## DevPass DeepSeek

#### Replace the Retired ID

The gateway now returns `410` for `llmgateway/deepseek-v4-flash-vision-exp`. **Breaking:** Replace it with `llmgateway/deepseek-v4.1-flash` in the DevPass DeepSeek row. The replacement is image-capable like the retired ID and keeps the retired ID's 1.05M context and 384K output. It costs $0.15 in and $0.60 out per million tokens, with cached reads at $0.003. That is below the gateway's Premium threshold, so the no-weekly-cap note still holds. This row is the DevPass route only. The `opencode-go` and `cline-pass` DeepSeek rows are different routes and remain untouched.

&nbsp;

#### Show the Accepted Ladder

The previous table omitted `minimal`, `medium` and `xhigh`, though the route accepts them. `minimal` reaches low, `medium` and `xhigh` reach high, `max` reaches max, `none` disables thinking and `high` is the default. The ladder comes from DeepSeek's thinking-mode guide rather than status-code inference. The route rejects `ultra` and the integer form.
