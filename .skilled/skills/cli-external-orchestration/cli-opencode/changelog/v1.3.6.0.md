# cli-opencode v1.3.6.0: MiMo Profile and Prompt Guidance

cli-opencode v1.3.6.0 adds a researched MiMo-V2.5-Pro profile and prompt guidance.
- It ships as a documentation and registry addendum.
- The skill default remains `opencode-go/deepseek-v4-pro`.

The profile records MiMo's context, model and endpoint details.
- MiMo's `context_length` is 1,000,000 tokens. This replaces the former `null` value.
- MiMo was released on 2026-04-22 with about 1.02T total and 42B active parameters.
- An OpenAI-compatible endpoint sits at `https://token-plan-ams.xiaomimimo.com/v1`.

Prompt guidance names a recommended framework and one to avoid.
- COSTAR (Context, Objective, Style, Tone, Audience and Response) is MiMo's recommended framework.
- Set Style="no preamble" and Audience="automated consumer".
- MiMo is already frontier-correct.
- Avoid CIDI for MiMo. Its failure appeared in about 22% of observed dispatches.

&nbsp;

## Why This Release

v1.3.5.0 registered MiMo-V2.5-Pro while leaving `context_length` and the best prompt framework pending. This release resolves both items.

## MiMo Profile

MiMo's profile covers its context, model and endpoint details.

#### A Million-Token Context <a id="c-a-million-token-context"></a>

- MiMo's `context_length` is 1,000,000 tokens.
- This replaces the former `null` value.
- MiMo's native context was 32K before RoPE (rotary position embeddings) extended it.
- Usable long-context retention reaches past 512k, though quality degrades beyond about 512k.

#### Model and Task Capabilities <a id="c-model-and-task-capabilities"></a>

- MiMo-V2.5-Pro was released on 2026-04-22. It has about 1.02T total and 42B active parameters.
- MiMo sustains 1000+ sequential tool calls. It used 40–60% fewer tokens per trajectory than frontier models.
- MiMo is multimodal (handles more than one input type). It uses a mixture-of-experts design.
- It scored 57.2 on SWE-bench Pro, a software-engineering benchmark.
- MiMo's reasoning effort is controlled by `--variant`. In OpenCode settings, `--variant` maps to MiMo's low, medium or high reasoning effort.
- OpenCode 1.15.13 accepted the high setting.

#### Endpoint and Billing <a id="c-endpoint-and-billing"></a>

- MiMo has an OpenAI-compatible endpoint. It is at `https://token-plan-ams.xiaomimimo.com/v1`.
- The endpoint uses `@ai-sdk/openai-compatible`.
- OpenCode reports a `0/0` cost, which reflects Token-Plan subscription billing.
- Token-Plan request-window semantics remain unverified.

## Prompt Guidance

Prompt guidance covers framework choice and reasoning settings for MiMo.

#### COSTAR's Close Result <a id="c-costars-close-result"></a>

- COSTAR (Context, Objective, Style, Tone, Audience and Response) is MiMo's recommended framework.
- Set Style="no preamble" and Audience="automated consumer".
- MiMo is already frontier-correct.
- All five frameworks scored 100% correctness, so frame for format and brevity rather than guardrails.
- RACE is the fallback.

#### Format Beats Guardrails <a id="c-format-beats-guardrails"></a>

- TIDD-EC, the guardrail-heavy framework that won for MiniMax in `120/003`, ranked last for MiMo.
- So avoid TIDD-EC and dense prompts.
- On harder tasks, lean output and audience-framed prompts suppressed explanatory preambles from CIDI, RCAF and TIDD-EC.
- TIDD-EC produced about 2.4 times the output.
- CIDI's process framing intermittently made MiMo write code to a file via a tool call instead of returning it inline.
- Avoid CIDI for MiMo. Its failure appeared in about 22% of observed dispatches.

#### High Reasoning Narrows the Gap <a id="c-high-reasoning-narrows-the-gap"></a>

- The high-reasoning comparison reran MiMo and MiniMax across default and high settings.
- It used a two-by-two model and reasoning comparison.
- TIDD-EC's verbosity penalty on the hard fixture largely disappeared.
- Format-adherent frameworks rose, so framework choice mattered less.
- Lean COSTAR or RACE remained the safe default.
- COSTAR remains a co-winner for MiMo at high reasoning.
- COSTAR and `--variant high` are independent, composable choices.

#### MiniMax Keeps Its Guidance <a id="c-minimax-keeps-its-guidance"></a>

- The comparison favored RACE for MiniMax.
- This result does not replace the seven-fixture TIDD-EC recommendation in `120/003`.
- The high-reasoning MiniMax result used two fixtures.
- Correctness saturated on those two tractable fixtures.

## How It Was Checked

MiMo and MiniMax were compared through a deterministic benchmark on real dispatches.

#### Before and After <a id="c-before-and-after"></a>

| Check | Before | After |
|---|---|---|
| TIDD-EC output on the hard fixture | 151 words | 66 |
| Format-adherent frameworks | 2/5 | 4/5 |

<summary><b>Tests and scenarios</b></summary>

- With lean-to-medium pre-planning, COSTAR scored a composite 1.0000 on default reasoning.
- RACE scored 0.9934, a statistical tie within single-sample noise.
- The benchmark used 10/10 real `xiaomi-token-plan-ams/mimo-v2.5-pro` dispatches.
- It spanned five frameworks and two deterministic fixtures, one sample per framework and fixture.
- Scoring was fully deterministic and used no large language model judge.
- The rig remains ready to run: `node eval/run-mimo-bench.cjs --model xiaomi-token-plan-ams/mimo-v2.5-pro --timeout 120`.
