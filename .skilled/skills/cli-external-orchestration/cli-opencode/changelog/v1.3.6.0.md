# cli-opencode v1.3.6.0: MiMo Profile and Prompt Guidance

cli-opencode v1.3.6.0 adds a researched MiMo-V2.5-Pro profile and prompt guidance as a documentation and registry addendum. The skill default remains `opencode-go/deepseek-v4-pro`.

> Spec folder: `.opencode/specs/skilled-agent-orchestration/126-cli-opencode-mimo-pro-optimization/003-mimo-efficiency-deep-research` and `.opencode/specs/skilled-agent-orchestration/126-cli-opencode-mimo-pro-optimization/004-mimo-prompt-framework-benchmark`

## Why This Release

v1.3.5.0 registered MiMo-V2.5-Pro while leaving `context_length` and the best prompt framework pending. This release resolves both items.

## What's New at a Glance

- **MiMo's `context_length` is 1,000,000 tokens.** This replaces the former `null` value.
- **MiMo-V2.5-Pro was released on 2026-04-22.** It has about 1.02T total and 42B active parameters.
- **MiMo sustains 1000+ sequential tool calls.** It used 40–60% fewer tokens per trajectory than frontier models.
- **MiMo has an OpenAI-compatible endpoint.** It is at `https://token-plan-ams.xiaomimimo.com/v1`.
- **MiMo's reasoning effort is controlled by `--variant`.** OpenCode 1.15.13 accepted the high setting.
- **COSTAR (Context, Objective, Style, Tone, Audience and Response) is MiMo's recommended framework.** Set Style="no preamble" and Audience="automated consumer".
- **MiMo is already frontier-correct.** All five frameworks scored 100% correctness, so frame for format and brevity rather than guardrails.
- **Avoid CIDI for MiMo.** Its failure appeared in about 22% of observed dispatches.
- **COSTAR remains a co-winner for MiMo at high reasoning.** COSTAR and `--variant high` are independent, composable choices.
- **The high-reasoning MiniMax result used two fixtures.** Correctness saturated on those two tractable fixtures.

## MiMo Profile

#### A Million-Token Context

MiMo's native context was 32K before RoPE (rotary position embeddings) extended it. Usable long-context retention reaches past 512k, though quality degrades beyond about 512k.

&nbsp;

#### Model and Task Capabilities

MiMo is multimodal (handles more than one input type) and uses a mixture-of-experts design. It scored 57.2 on SWE-bench Pro, a software-engineering benchmark. In OpenCode settings, `--variant` maps to MiMo's low, medium or high reasoning effort.

&nbsp;

#### Endpoint and Billing

The endpoint uses `@ai-sdk/openai-compatible`. OpenCode reports a `0/0` cost, which reflects Token-Plan subscription billing. Token-Plan request-window semantics remain unverified.

## Prompt Guidance

#### COSTAR's Close Result

With lean-to-medium pre-planning, COSTAR scored a composite 1.0000 on default reasoning. RACE scored 0.9934, a statistical tie within single-sample noise. The benchmark used 10/10 real `xiaomi-token-plan-ams/mimo-v2.5-pro` dispatches across five frameworks and two deterministic fixtures, with one sample per framework and fixture. Scoring was fully deterministic and used no large language model judge. The rig remains ready to run: `node eval/run-mimo-bench.cjs --model xiaomi-token-plan-ams/mimo-v2.5-pro --timeout 120`. RACE is the fallback.

&nbsp;

#### Format Beats Guardrails

TIDD-EC, the guardrail-heavy framework that won for MiniMax in `120/003`, ranked last for MiMo, so avoid TIDD-EC and dense prompts. On harder tasks, lean output and audience-framed prompts suppressed explanatory preambles from CIDI, RCAF and TIDD-EC. TIDD-EC produced about 2.4 times the output. CIDI's process framing intermittently made MiMo write code to a file via a tool call instead of returning it inline.

&nbsp;

#### High Reasoning Narrows the Gap

The high-reasoning comparison reran MiMo and MiniMax across default and high settings in a two-by-two model and reasoning comparison. TIDD-EC's verbosity penalty on the hard fixture largely disappeared, with output falling from 151 words to 66. Format-adherent frameworks rose from 2/5 to 4/5, so framework choice mattered less. Lean COSTAR or RACE remained the safe default.

&nbsp;

#### MiniMax Keeps Its Guidance

The comparison favored RACE for MiniMax. This result does not replace the seven-fixture TIDD-EC recommendation in `120/003`.
