MiMo now goes through LLM Gateway only. The Xiaomi Direct API and Xiaomi Token Plan routes leave the roster, and every MiMo instruction, template and example names `llmgateway/mimo-v2.6-pro`.

> Spec folder: `specs/cli-external-orchestration/077-gpt-6-luna-sol-cutover` (Level 2)

## What's New at a Glance

- **Two Xiaomi routes are gone.** `xiaomi/mimo-v2.6-pro`, `xiaomi/mimo-v2.6-pro-ultraspeed` and `xiaomi-token-plan-ams/mimo-v2.6-pro` are off the roster, and the provider count drops to five. The gateway serves no ultraspeed tier, so the low-latency MiMo option goes with them.
- **MiMo has one route.** The auth pre-flight checks for LLM Gateway instead of Xiaomi, and the MiMo routing table, the fallback prompts and the MiMo prompt template all use `llmgateway/mimo-v2.6-pro --variant high`.

## Upgrade

Replace any `xiaomi/` or `xiaomi-token-plan-ams/` MiMo slug with `llmgateway/mimo-v2.6-pro`, and authenticate LLM Gateway with `opencode auth login` if it is not set up yet. There is no ultraspeed replacement.
