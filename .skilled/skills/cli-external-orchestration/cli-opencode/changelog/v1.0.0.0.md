The first release adds `cli-opencode` as the fourth sibling in the CLI skill family. It lets external AI assistants and detached OpenCode sessions invoke `opencode run`. That call dispatches work through OpenCode's plugin, skill and MCP runtime.

&nbsp;

## What's New at a Glance

- The missing CLI skill is now a fourth sibling.
  - `cli-opencode` sits under `.opencode/skills/cli-*/`.
  - The skill follows the canonical 9-file blueprint: 3 root files, 2 assets and 4 references.
- External runtimes can dispatch through OpenCode in one call.
  - Claude Code, Codex, Copilot and raw shell can invoke `opencode run`.
  - That one-shot call starts a fresh OpenCode session.
  - The session loads every project plugin, skill, MCP tool and the Spec Kit Memory database.
- Three use cases have their own instructions.
  - Each has a copy-paste prompt template and an `opencode run` invocation shape.
  - They cover external-runtime dispatch into OpenCode.
  - They also cover parallel detached OpenCode sessions for ablation and worker farms.
  - They also cover cross-AI handback, so Codex or Copilot can reach the project's spec-kit workflows.
- A layered guard blocks circular self-dispatch.
  - The guard checks three signals: any `OPENCODE_*` environment variable, an `opencode` parent process and a lock file at `~/.opencode/state/<id>/lock`.
  - The smart router's documented refusal message names three remediation options.
- The advisor graph recognizes all four CLI siblings.
  - The graph links `cli-opencode` symmetrically with `cli-claude-code`, `cli-codex` and `cli-copilot`.
  - The link uses weight `0.5` and context `CLI orchestrator peer`.
  - So the advisor can surface it as their sibling.
- The README totals include the new skill.
  - `.opencode/skills/README.md` and `.opencode/README.md` now show 21 skills and four CLI skills.
  - Before, they showed 20 and three.
  - Their counts, tables, tree diagrams and feature rows are refreshed.
  - The skill README received 8 line-anchored patches.
  - The root README received 2.

&nbsp;

## Upgrade

No migration is required. The sibling-edge additions are additive. Advisor scoring tables keep their baseline thresholds. Existing `cli-*` dispatches are unchanged.

To pick up the new skill, restart the MCP server. That reloads `skill-graph.sqlite`. Then run `python3 .opencode/skills/system-skill-advisor/mcp-server/scripts/skill_advisor.py --health`. Confirm `skill_graph_skill_count=22` and `inventory_parity.in_sync=true`.
