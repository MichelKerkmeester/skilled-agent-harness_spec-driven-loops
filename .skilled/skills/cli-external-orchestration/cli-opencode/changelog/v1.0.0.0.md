The first release adds `cli-opencode` as the fourth sibling in the CLI skill family. It lets external AI assistants and detached OpenCode sessions invoke `opencode run` to dispatch work through OpenCode's plugin, skill and MCP runtime.

> Spec folder: `.opencode/specs/skilled-agent-orchestration/047-cli-opencode-creation/` (Level 3)

## What's New at a Glance

- **The missing CLI skill is now a fourth sibling.** `cli-opencode` sits under `.opencode/skills/cli-*/` and follows the canonical 9-file blueprint: 3 root files, 2 assets and 4 references.
- **External runtimes can dispatch through OpenCode in one call.** Claude Code, Codex, Copilot and raw shell can invoke `opencode run` as a one-shot call to start a fresh OpenCode session that loads every project plugin, skill, MCP tool and the Spec Kit Memory database.
- **Three use cases have their own instructions.** Each has a copy-paste prompt template and an `opencode run` invocation shape. They cover external-runtime dispatch into OpenCode, parallel detached OpenCode sessions for ablation and worker farms and cross-AI handback for Codex or Copilot to reach the project's spec-kit workflows.
- **A layered guard blocks circular self-dispatch.** It checks three signals: any `OPENCODE_*` environment variable, an `opencode` parent process and a lock file at `~/.opencode/state/<id>/lock`. The smart router's documented refusal message names three remediation options.
- **The advisor graph recognizes all four CLI siblings.** It links `cli-opencode` symmetrically with `cli-claude-code`, `cli-codex` and `cli-copilot` at weight `0.5` and context `CLI orchestrator peer`, so the advisor can surface it as their sibling.
- **The README totals include the new skill.** `.opencode/skills/README.md` and `.opencode/README.md` now show 21 skills and four CLI skills instead of 20 and three, with their counts, tables, tree diagrams and feature rows refreshed. The skill README received 8 line-anchored patches and the root README received 2.

## Upgrade

No migration is required. The sibling-edge additions are additive, advisor scoring tables keep their baseline thresholds and existing `cli-*` dispatches are unchanged.

To pick up the new skill, restart the MCP server so it reloads `skill-graph.sqlite`. Then run `python3 .opencode/skills/system-skill-advisor/mcp-server/scripts/skill_advisor.py --health` and confirm `skill_graph_skill_count=22` and `inventory_parity.in_sync=true`.
