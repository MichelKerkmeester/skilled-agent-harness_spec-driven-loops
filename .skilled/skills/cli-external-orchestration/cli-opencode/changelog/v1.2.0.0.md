# v1.2.0.0, Copilot Supplies the Documented Default

cli-opencode v1.2.0.0 reshapes its documented provider choices.

- It centers them on the providers registered for the operator.
- It sets a Copilot default.
- It narrows the named Copilot and direct DeepSeek models.
- It updates the multi-provider playbook.

Three changes can break an existing setup.

- Callers using the prior invocation must replace its model value.
- Operators using removed prefixes should override per invocation or migrate.
- Scripts referencing renamed scenario files must use new names.

> [!IMPORTANT]
> 3 changes can break an existing setup. Read these before you update.
>
> 1. Callers using the prior invocation must replace its model value. [Copilot Takes the Default](#c-copilot-takes-the-default)
> 2. Operators using removed prefixes should override or migrate. [Documented Providers Match Access](#c-documented-providers-match-access)
> 3. Scripts referencing renamed scenario files must use new names. [Repoint](#c-repoint)

&nbsp;

## Why This Release

The previous guidance named provider prefixes outside the operator's authentication set. It also used a default that depended on separate provider login.

- The prefixes did not match the operator's authentication set.
- The default required a separate provider login.

## Provider Defaults

The default invocation and the documented provider prefixes both changed.

#### Copilot Takes the Default <a id="c-copilot-takes-the-default"></a>

> [!WARNING]
> Callers using the prior invocation must replace its model value with the Copilot default.

- The default invocation changed from `opencode-go/deepseek-v4-pro` to `github-copilot/gpt-5.4 --variant high`.
- For active subscribers, Copilot is pre-authenticated.
- It exposes the broadest model surface under one OAuth token.
- That surface includes Claude and GPT variants.
- This removes the per-provider login friction that came with the previous default.
- `gpt-5.4` accepts `minimal / low / medium / high / xhigh`.
- So the existing `--variant high` setting carries over without behavioral change.
- During the release, the default moved from `gpt-5.5` to `gpt-5.4`.
- That matches the `cli-copilot` default and operator preference.

#### Documented Providers Match Access <a id="c-documented-providers-match-access"></a>

> [!WARNING]
> Operators using those prefixes should override per invocation when separately authenticated or migrate to the equivalent `github-copilot/<id>` model.

- The operator's registered providers were OpenAI, GitHub Copilot, DeepSeek and OpenCode Go.
- `anthropic/` and `google/` were not reachable through that authentication setup.
- The documented prefixes are now `github-copilot`, `opencode-go` and `deepseek`.
- They replace the previous Anthropic, OpenAI, Google, `opencode-go` and DeepSeek mix.
- Within `cli-opencode`, `--model anthropic/...`, `--model openai/...` and `--model google/...` were removed.
- They were removed from invocation strings, override tables, model-selection tables, FAQ entries and the variant matrix.

## Model Choices

The skill narrows its named Copilot and direct DeepSeek models.

#### Copilot Models Stay Focused <a id="c-copilot-models-stay-focused"></a>

- The skill names `gpt-5.4` as the default.
- It names `claude-sonnet-4.6` as the Anthropic alternative for code review and balanced reasoning.
- The full Copilot lineup remains available through `--model github-copilot/<id>` overrides.
- That lineup includes Opus, Haiku, additional GPT models and Grok variants.
- It is not listed in the skill's tables.

#### Direct DeepSeek Stays Separate <a id="c-direct-deepseek-stays-separate"></a>

- The direct DeepSeek API bypasses `opencode-go`.
- `deepseek/` and `opencode-go/` remain independent surfaces rather than aliases.
- The direct API keeps `deepseek-v4-pro` for reasoning effort.
- It keeps `deepseek-v4-flash` as its non-reasoning latency sibling.
- The model-selection tables and override examples drop `deepseek/deepseek-reasoner` and `deepseek/deepseek-chat`.

- It uses a TypeScript helper code-generation prompt and `tsc` validation.

- It lists `opencode-go/deepseek-v4-pro` as provider-specific.

## Upgrade Notes

The steps below cover the new default and the renamed scenario files.

#### Before You Start <a id="c-before-you-start"></a>

1. The new default is reachable in environments where `opencode providers list` reports `github-copilot` as authenticated.
2. So verify that before the first dispatch.

<details>
<summary><b>Adopt</b></summary>

- Old (v1.1): `opencode run --model opencode-go/deepseek-v4-pro --variant high --agent general --format json --dir <repo>`.
- New (v1.2): `opencode run --model github-copilot/gpt-5.4 --variant high --agent general --format json --dir <repo>`.
- With an active Copilot subscription, use `github-copilot/claude-sonnet-4.6` for Anthropic.
- Or use `github-copilot/gpt-5.4` for OpenAI.

</details>

#### Repoint <a id="c-repoint"></a>

> [!WARNING]
> External scripts that reference `001-opencode-go-default-deepseek.md` must use `001-copilot-default-gpt-5-4.md`.
>
> References to `002-openai-gpt-5-5.md` must use `002-copilot-claude-sonnet-4-6.md`.
>
> Scripts referencing the multi-provider scenarios must use `003-deepseek-direct-api.md` for the new direct API scenario.

<details>
<summary><b>Drop</b></summary>

- To keep using `anthropic/`, `openai/` or `google/` with a direct provider, run `opencode providers login <provider>`.
- Then continue using the original prefix per invocation.

</details>
