# v1.7.6.0, The Hub Frontmatter Parses Under Strict YAML

The hub README description held a colon and a space, which an unquoted YAML scalar cannot carry, so a strict parser rejected the block while every reader of the rendered page saw normal text. The description is quoted now and no word changed. The `author: OpenCode` line is gone from the hub metadata, because nothing read it and it was not true.

> Spec folder: `specs/sk-code/017-portable-code-modes/015-frontmatter-yaml-validity` (Level 2)

&nbsp;

## What's New at a Glance

- **The hub README description is valid YAML.** A linter, an index builder or any other strict parser now reads the description instead of a parse error.
- **The metadata author line is gone.** No code path read `author`. The claim it made about who wrote the hub was not true either.
