# v1.7.6.0, The Hub Frontmatter Parses Under Strict YAML

The hub README description held a colon and a space. An unquoted YAML scalar cannot carry that. So a strict parser rejected the block. Every reader of the rendered page saw normal text. The description is quoted now. No word changed. The `author: OpenCode` line is gone from the hub metadata. That is because nothing read it, and it was not true.

## What's New at a Glance

- **The hub README description is valid YAML.** A linter, an index builder or any other strict parser now reads the description. None of them hit a parse error.
- **The metadata author line is gone.** No code path read `author`. The claim it made about who wrote the hub was not true either.
