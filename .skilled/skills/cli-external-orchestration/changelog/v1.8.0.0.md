Version 1.8 registers DeepSeek Harness (`dsh`) as the eighth CLI mode. So a request that names the tool reaches a packet. That packet composes and checks the dispatch. The mode is experimental. The LLM Gateway route answered a keyed run on 2026-11-06. The OpenCode Go route answered a keyed run on 2026-11-07.

&nbsp;

## What's New at a Glance

- **`cli-deepseek-harness` is the eighth CLI mode.** It sends one task to `dsh --profile headless`. The prompt goes on stdin. It runs from a scratch cwd with a disposable `DSH_HOME`. A run counts as complete only on exit 0 plus a `completed` final event.
- **Tool words route to it, model words do not.** `dsh`, `dsh headless`, `deepseek harness` and `delegate to dsh` select the mode. "Use cli-opencode with deepseek-v4.1-flash" still goes to `cli-opencode`.
- **The roster is closed at two routes.** LLM Gateway and OpenCode Go both serve DeepSeek V4.1 Flash. A checked-in route patch chooses it. LLM Gateway `deepseek-v4.1-flash-1017` is the default. OpenCode Go was proved by a keyed run on 2026-11-07. A run uses it only when the request names it.
- **The dispatch audit recognizes dsh commands and checks thirteen rules.** A headless dsh command is judged before it spawns. The audit checks the route, lineage and guards patches. It checks the closed roster and the opt-in MCP patch. It checks the isolated home and the version pin. It checks an installed `dsh` on PATH. It checks the approval policy and the repository-root `.env`.
- **A route name beats a word inside it.** "opencode go route" selects `cli-deepseek-harness`. A one-word alias of another mode no longer counts. That holds when its word appears only inside a phrase another mode matched. So such a prompt routes instead of tying.
- **Roster surfaces name eight modes.** The hub tables and the mode roster include the new mode. So do the feature catalog, the prompt-improver eligibility table and the persona-attach table. The seven existing modes keep their contracts and routing.
- **DSH sessions reach hook parity.** The `cli-deepseek-harness` guards reference and playbook describe the 20-adapter bundle. They describe its interactive and fan-out compositions. They describe the adapter links in the hook library.
- **Mode docs match the tree.** `cli-cursor` and `cli-devin` count the 11 mirrored agents. The `cli-pi` tools reference says the Cursor and Devin hook files are rendered from the shared hook registry.
