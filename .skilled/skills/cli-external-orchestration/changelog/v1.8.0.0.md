Version 1.8 registers DeepSeek Harness (`dsh`) as the eighth CLI mode, so a request that names the harness reaches a packet that composes and checks the dispatch. The mode is experimental. The LLM Gateway route answered a keyed run on 2026-11-06, and the OpenCode Go route answered a keyed run on 2026-11-07.

> Spec folder: `specs/cli-external-orchestration/085-cli-deepseek-harness-creation/`

&nbsp;

## What's New at a Glance

- **`cli-deepseek-harness` is the eighth CLI mode.** It dispatches one task to `dsh --profile headless` with the prompt on stdin, from a scratch cwd with a disposable `DSH_HOME`. A run counts as complete only on exit 0 plus a `completed` final event.
- **Harness words route to it, model words do not.** `dsh`, `dsh headless`, `deepseek harness` and `delegate to dsh` select the mode. "Use cli-opencode with deepseek-v4.1-flash" still goes to `cli-opencode`.
- **The roster is closed at two routes.** LLM Gateway and OpenCode Go both serve DeepSeek V4.1 Flash, chosen by a checked-in route patch. LLM Gateway `deepseek-v4.1-flash-1017` is the default. OpenCode Go was proved by a keyed run on 2026-11-07, and a run uses it only when the request names it.
- **The dispatch audit recognizes dsh commands and checks thirteen rules.** A headless dsh command is judged before it spawns for the route, lineage and guards patches, the closed roster, the opt-in MCP patch, the isolated home, the version pin, an installed `dsh` on PATH, the approval policy and the repository-root `.env`.
- **A route name beats a word inside it.** "opencode go route" selects `cli-deepseek-harness`. A one-word alias of another mode no longer counts when its word appears only inside a phrase another mode matched, so such a prompt routes instead of tying.
- **Roster surfaces name eight modes.** The hub tables, the mode roster, the feature catalog, the prompt-improver eligibility table and the persona-attach table include the new mode. The seven existing modes keep their contracts and routing.
- **DSH sessions reach hook parity.** The `cli-deepseek-harness` guards reference and playbook describe the 20-adapter bundle, its interactive and fan-out compositions and the adapter links in the hook library.
- **Mode docs match the tree.** `cli-cursor` and `cli-devin` count the 11 mirrored agents. The `cli-pi` tools reference says the Cursor and Devin hook files are rendered from the shared hook registry.
