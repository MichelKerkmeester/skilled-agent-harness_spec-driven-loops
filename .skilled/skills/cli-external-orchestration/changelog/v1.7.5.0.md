# v1.7.5.0, Released Notes in Plain Words

The released changelog entries in cli-codex, cli-opencode and cli-pi used to point at a playbook scenario or a decision by its internal id. Each one now names the scenario or the decision in words, so a reader can follow what a release changed without leaving the page.

> Spec folder: `specs/sk-doc/070-repo-doc-debt` (Level 2)

&nbsp;

## What's New at a Glance

- **Released changelogs read in plain words.** The cli-codex, cli-opencode and cli-pi entries state the playbook scenario or decision they mean instead of quoting an internal id.
- **The published history was corrected too.** The entries already on disk in those three packets were rewritten, so the changelogs read correctly today rather than only from here on.
- **No released fact changed.** Every claim, expected result and decision those entries carried still says the same thing.

&nbsp;

## Upgrade

No action is needed. The wording changed and the facts did not.
