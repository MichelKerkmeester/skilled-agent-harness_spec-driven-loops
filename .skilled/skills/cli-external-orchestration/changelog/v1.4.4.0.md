# cli-external-orchestration v1.4.4.0

## Changed

- **Retired Ox Alpha and routed Z.AI GLM-5.3-Flash in its place**, across cli-opencode and cli-pi. The OpenRouter stealth route (`stealth/ox-alpha`) and the Cline route (`x-ai/ox-alpha`) are both gone; every surface now carries GLM-5.3-Flash instead. All model facts were live-verified via `opencode models openrouter|opencode-go|cline-pass` before any edit — no Ox Alpha live-dispatch evidence was carried onto the new entries.
- **The CLI OpenRouter allowlist now holds exactly three models** (both CLIs): `deepseek/deepseek-v4-flash-latest`, `z-ai/glm-5.3-flash`, and `google/gemini-3.7-flash`.
  - **GLM-5.3-Flash** (`openrouter/z-ai/glm-5.3-flash`) — reasoning model, variants `low`/`high`/`max`, pinned to its top tier (`--variant max` on cli-opencode, `--thinking max` on cli-pi). 1.31M context / 131K output.
  - **Gemini 3.7 Flash** (`openrouter/google/gemini-3.7-flash`) — reasoning model, variants `low`/`medium`/`high`, dispatched at its top tier (`--variant high` / `--thinking high`). It has no `max` tier and is intentionally **not** caught by the flash max-pin.
- **GLM-5.3-Flash also registered on opencode-go** (`opencode-go/glm-5.3-flash`) and the **Cline provider** (`cline-pass/z-ai/glm-5.3-flash`, id `z-ai/glm-5.3-flash` with the `z-ai/` vendor prefix, `xhigh` ceiling — Cline has no `max`). The Cline id was confirmed from the operator's own Cline runtime logs, since `opencode models cline-pass` does not list it (list-invisible, dispatch-works).
- **`.pi` config**: `.pi/models.json` `cline-pass` block swapped Ox Alpha for `z-ai/glm-5.3-flash`; `.pi/settings.json` repointed `defaultModel` to `z-ai/glm-5.3-flash` and swapped the `enabledModels` ids (dropped both Ox Alpha ids; added the OpenRouter GLM/Gemini ids, `opencode-go/glm-5.3-flash`, and `cline-pass/z-ai/glm-5.3-flash`).
- **Deep-loop cli-pi fan-out roster** (`executor-config.ts` + its byte-mirror `fanout-run.cjs`): `PI_SUPPORTED_MODELS` / `PI_ALLOWED_MODELS` dropped the two Ox Alpha literals and gained `z-ai/glm-5.3-flash` (→ openrouter), `google/gemini-3.7-flash` (→ openrouter), and the bare `glm-5.3-flash` (→ opencode-go). `isFlashMaxPinnedModel` now also matches GLM-5.3-Flash. Guard tests re-pinned; `npx vitest run` = 203 passed / 0 failed.
- **Fixed a stale doc claim**: cli-opencode `SKILL.md` said "OpenRouter routes DeepSeek V4 Flash only"; it now names the three-model allowlist.

## Not Changed

- **DeepSeek V4 Flash** stays the first OpenRouter model and its `max` pin is unchanged.
- **The OpenRouter↔Cline collision is by design**: both use the id `z-ai/glm-5.3-flash`, and one `modelId→provider` map holds one provider per id, so the fan-out routes the shared literal via OpenRouter and the Cline GLM stays a direct-dispatch route.
- **cli-cursor / cli-devin** — never carried Ox Alpha; untouched.
- Every other model and effort mapping (DeepSeek Pro, GLM-5.2, GPT-5.6, Grok, SWE, MiniMax, MiMo, Qwen) is unchanged.
