# v1.7.14.0, READMEs Open with OVERVIEW and Intros Say When to Read

The hub and its modes now pass every render check. The packager enforces those checks once the staged checks retire. No dispatch rule, flag or citation changed.

&nbsp;

## What's New at a Glance

- **READMEs open with OVERVIEW.** The hub README moves its scan table into OVERVIEW as `### At a Glance`. The cli-claude-code, cli-codex, cli-cursor, cli-devin, cli-opencode and cli-pi READMEs do the same. The sections after it are numbered one lower.
- **Intros say when to open the file.** Ten reference and asset intros repeated their frontmatter description. They now tell a reader when the file is worth opening. Facts only the old intro carried stay in the new one.
- **Prompt-quality cards gain Usage.** The cli-cursor card adds a Usage list drawn from its Purpose. The cli-hermes card renames its When to Use to Usage. That is the asset name for that subsection.
