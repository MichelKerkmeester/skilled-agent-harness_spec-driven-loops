The external CLI hub now uses `cli-external-orchestration` for its directory and public advisor identity, replacing `cli-external`.

## What's New at a Glance

- **Supporting references use the renamed identity.** Hub metadata, advisor integration, hooks, commands and live documentation were repointed to `cli-external-orchestration`.
- **Nested CLI packets keep their names and behavior.** `cli-opencode` and `cli-claude-code` are unchanged.

## Upgrade

No migration required.
