# v1.7.2.0, Template-Name Comment Removed from the Feature Catalog

v1.7.2.0 removes the `sk-doc-template` comment from 4 feature catalog files. The comment sat under the heading of each file. It named the template a file was scaffolded from. No validator, router or script ever read it. The catalog template no longer adds it.

- **Each catalog file now goes from its title straight to its overview.** The heading, sections and links are otherwise unchanged.
- **Catalog validation reports the same results as before.** Removing the comment changed no check outcome.
