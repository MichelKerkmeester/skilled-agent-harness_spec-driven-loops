v1.4.0.0 adds two GPT-5.6 IDs to `cli-cursor`. It adds four model IDs to `cli-devin`. It documents `opencode-go/glm-5.3` in `cli-opencode`'s gateway roster. It updates `cli-devin` routing guidance. It also corrects stale model counts. All model additions were confirmed in live CLI listings on 2026-08-14.

## What's New at a Glance

- **`cli-cursor` adds `gpt-5.6-luna-max` and `gpt-5.6-luna-max-fast`.** They bring its first GPT-5.6 persona. They expand its allowlist from 18 to 20 IDs. The allowlist is the set of permitted models. See `cli-cursor/changelog/v1.4.0.0.md`.
- **`cli-devin` adds four model IDs.** It adds `deepseek-v4-pro-max`, `deepseek-v4-flash-max`, `gpt-5-6-luna-max` and `gpt-5-6-luna-max-priority`. It grows from four model families to five, with GPT-5.6 included. Grok 4.6 support was already complete (packet 036). It remains unchanged. `cli-cursor` keeps all eight `cursor-grok-4.6-*` IDs. `cli-devin` keeps all four `grok-4-6-*` UIDs. See `cli-devin/changelog/v1.4.0.0.md`.
- **`cli-opencode` documents `opencode-go/glm-5.3`.** Its opencode-go gateway roster lists the model as documentation only. That is because `cli-opencode` has no code-enforced allowlist. See `cli-opencode/changelog/v1.4.2.0.md`.
- **`cli-devin` routing guidance now names GPT-5.6 Luna Max.** `shared/references/smart-routing.md` lists it alongside the existing families. The hub still reads `hub-router.json` and `mode-registry.json`. It keeps the same `tieBreak` order. `cli-opencode` stays the default mode.
- **Roster counts now match the documented model sets.** The sweep changes `cli-cursor` from "18-id" to "20-id". It changes `cli-devin` from "four families" to "five". It also corrects two stale "10"-count claims. Those claims predate packet 036's growth of the Cursor roster to 18.
