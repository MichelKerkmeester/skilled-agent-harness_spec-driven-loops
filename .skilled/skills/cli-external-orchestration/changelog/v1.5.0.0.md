Version 1.5 brings Hermes Agent into CLI orchestration and deep-loop work. Hermes can receive direct dispatches and join AI-council seats and model-benchmark runs. The generated `.hermes/` runtime includes the `repo-guards` plugin, which bridges the repository hooks Hermes can reach.

> Spec folder: `specs/cli-external-orchestration/071-cli-hermes-creation/` (Level 3)

## What's New at a Glance

- **`cli-hermes` is the seventh CLI mode.** Hermes Agent from Nous Research uses the `hermes` binary for a quiet one-shot chat and reads its prompt from stdin (standard input) with `hermes chat -Q --oneshot --query-file - --provider llmgateway --model <roster id> --ignore-rules --source tool -t <explicit toolsets> [--yolo]`. `hub-router.json` now includes Hermes signals, vocabulary classes and tie-break order.
- **Hermes is the eighth deep-loop executor kind.** Its closed roster allows `deepseek-v4.1-flash` and `glm-5.3-flash`. It pins reasoning to `max` and sets `--run-budget` one margin under the lineage timeout. `liveTools.mcpServers` names the MCP servers a Hermes leaf may reach. Only this executor kind accepts a non-empty list and refuses `delegation`, `memory` and `clarify`.
- **The dispatch audit recognizes Hermes commands and checks seven operating rules.** The rules cover availability, `--yolo` for write toolsets, `--ignore-rules`, explicit `-t` toolsets, no `--worktree` and MCP and hooks at operator level.
- **AI-council seats and the model-benchmark dispatcher accept `cli-hermes`.** Council seats send the prompt on stdin.
- **`.hermes/` provides a generated Hermes runtime.** It contains Markdown-only copies of all 56 skills and 12 agent personas, an `agents/` link, generated prompt stubs, the `repo-guards` project plugin and `SYNC.md`. The plugin bridges every repository hook Hermes can reach: the advisor and gate at prompt time, dispatch and MCP guards, post-edit quality, goal core, session-start advisories, cleanup and vision.
- **Roster and prompt-improver references include Hermes.** Every roster surface that named six modes now names seven. The prompt-improver eligibility table and canonical prompt card include a `cli-hermes` row. The prompt-card sync guard covers the seventh packet.
- **Existing modes and hub routing keep their contracts.** The six existing modes' contracts, rosters and hard rules remain unchanged. The hub's advisor identity remains unchanged. Routing is still hub then mode.
