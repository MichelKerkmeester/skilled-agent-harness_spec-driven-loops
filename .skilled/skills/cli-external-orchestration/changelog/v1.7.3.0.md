# v1.7.3.0, Dispatch Authorization Names Shell Wrappers

v1.7.3.0 brings the hub's dispatch authorization docs in line with the Pi dispatch guard. The feature catalog entry and the preflight playbook scenario now say that a shell `-c` wrapper is classified by the command it runs and that a variable counts as an executor only in command position.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/013-root-cause-and-ux-research/009-pi-guard-classification` (Level 1)

&nbsp;

## What's New at a Glance

- **A shell wrapper is read through.** `bash -c 'devin -p task'` is a direct cli-devin dispatch, not an unknown wrapper.
- **A variable is an executor only in command position.** `mkdir -p "$DIR"` and `node -p "$EXPR"` classify as no dispatch.
