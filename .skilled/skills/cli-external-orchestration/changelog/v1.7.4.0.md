# v1.7.4.0, The Fanout Scenarios Share One Layout

The fanout-stress scenarios each laid out their commands, evidence and verdict in their own way, so the package validator could not read them. All fourteen now use the five numbered sections every playbook scenario uses, with the commands, evidence, verdict and triage kept under the test-execution section. The playbook also says that a scenario is not complete until its outcome and evidence paths are recorded under the benchmark reports folder.

> Spec folder: `specs/sk-code/015-quality-agnostic-gate` (Level 2)

&nbsp;

## What's New at a Glance

- **The package validator reads every scenario.** The fourteen fanout-stress files pass the strict package check.
- **A finished scenario leaves a record.** The playbook names the reports folder where each pass, fail or skip is written with its reason and evidence.
- **The compiled-routing scenario matches its siblings.** The cli-transport ordered bundle uses the same section shape as the other hubs.

&nbsp;

## Upgrade

No migration required. Scenario ids, commands and expected results are unchanged.
