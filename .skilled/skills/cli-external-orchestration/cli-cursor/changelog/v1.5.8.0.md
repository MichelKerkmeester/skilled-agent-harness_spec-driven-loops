# v1.5.8.0, The Child Preamble Rule Applies to Every Dispatch

An earlier prose pass folded the per-session worktree wrapper into the instruction that copies the child-dispatch preamble into a prompt. The trailing clause read as a condition, so a dispatch that skips the wrapper would have left the preamble out. A child given only `AI_SESSION_CHILD=1` still stops to ask the documentation-scope question and writes nothing.

The instruction is now one sentence on its own. Copy the preamble to the top of every non-interactive prompt. The wrapper is the next line, naming the same path and keeping the note that a dispatched `cursor-agent -p` shares the parent's worktree rather than taking its own. The rest of the rule, including the distinction from Cursor's native `-w` flag, is as it was.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/012-alignment-remediation` (Level 2)

&nbsp;

## What's New at a Glance

- **The preamble rule is unconditional.** It applies to every non-interactive dispatch, whether or not the wrapper launched the session.
- **The wrapper gets its own line.** The path `.skilled/bin/worktree-session.sh` and the shared-worktree behavior are unchanged.
- **Nothing routes differently.** No intent dictionary, resource map, loading level, guard or default changed.
