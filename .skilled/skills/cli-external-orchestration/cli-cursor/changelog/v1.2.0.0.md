#### Purpose-first rewrite

The old README opened with a tabular feature card and its OVERVIEW named the tooling before the outcome. The rewrite opens with a one-line pitch and a problem-first OVERVIEW on the refined template from the skill-readme-refinement packet, with the mcp-obsidian README as the exemplar. A new capability section names the dispatch guard rails: the smart router, the enforced model allowlist, the auth pre-flight, the self-invocation guard and the memory handback.

#### Version alignment

The README version field had drifted from the release trail: it read 1.0.0.0 while the changelog folder already held v1.1.0.0 and `SKILL.md` carried 1.1.0.0. This release bumps the field to 1.2.0.0 and adds this entry, so the README field matches the changelog head again.

#### Not changed

`SKILL.md` stays at 1.1.0.0 in this release. The rewrite is README-only. Skill behavior and routing are untouched.
