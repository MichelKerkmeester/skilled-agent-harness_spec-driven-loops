Cursor users can now choose Google's Gemini 3.7 Flash High from this skill's allowlist. The included tier and supported scope are clear in the skill's guidance.

## What's New at a Glance

- **Google's Gemini 3.7 Flash High joins the allowlist.** The first Gemini id takes the roster from 20 to 21. It sorts after `cursor-grok-4.6-xhigh-fast` and before `glm-5.2-high`. Only High is included. The Low and Medium ids remain out of scope. Composer, GLM 5.2 and GPT-5.6 Luna Max remain unchanged. Grok 4.5 and 4.6 remain unchanged.
- **The display name leaves High in the id.** Cursor displays `gemini-3.7-flash-high` as "Gemini 3.7 Flash", with High only in the id suffix. `references/providers-and-models.md` and code comments explain the suffix. This is so readers do not conclude that the tiered ids are absent.
- **The live listing and dispatch confirmed the new id.** On 2026-08-15, `cursor-agent --list-models` listed `gemini-3.7-flash-high` verbatim. The Luna Max addition was list-verified only. Unlike it, the live `cursor-agent -p --model gemini-3.7-flash-high` probe returned a live model response that day. The run exited 0, echoed the marker and left stderr empty.
- **The skill's guidance now matches the 21-id allowlist.** `SKILL.md`, `README.md`, Cursor references and prompt templates now show 21 ids. The manual testing playbook shows 21 ids too. They include Gemini 3.7 Flash High wherever they list the allowlist's model families. The old wording said "every Claude / Gemini / Kimi id is out of scope". It now reads "every Claude / other Gemini / Kimi id". `references/providers-and-models.md` carries the fullest account and dated verification note.
