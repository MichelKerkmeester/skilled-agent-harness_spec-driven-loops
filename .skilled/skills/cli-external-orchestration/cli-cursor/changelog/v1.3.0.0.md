Cursor and Devin now support Grok 4.6 alongside Grok 4.5, so users can add the newer family without losing the earlier one. Cursor's live roster listed both families on 2026-08-12.

> Spec folder: `specs/cli-external-orchestration/036-grok-4.6-support/`

## What's New at a Glance

- **Grok 4.6 joins Grok 4.5 in Cursor's curated model allowlist.** Eight new `cursor-grok-4.6-*` model IDs (identifiers) bring the total from 10 to 18 alongside the six existing `cursor-grok-4.5-*` IDs. Composer and GLM 5.2 remain unchanged, and `cursor-grok-4.5-high` still dispatches.
- **Devin adds Grok 4.6 model support and routing.** `DEVIN_SUPPORTED_MODELS` now includes Grok 4.6 IDs alongside Grok 4.5 IDs, and Devin routing keywords cover both Grok versions.
- **Grok 4.6 adds a fourth thinking tier.** Its `xhigh` tier was not available in Grok 4.5. Every `cursor-grok-4.6-*` ID was dispatch-tested end to end before release, and `cursor-grok-4.6[effort=high]` is rejected outright, matching 4.5's behavior.
- **The Grok documentation now covers both versions.** `SKILL.md`, `README.md`, `references/{cli-reference,integration-patterns,providers-and-models,agent-delegation}.md`, `assets/{prompt-templates,prompt-quality-card}.md` and `manual-testing-playbook/manual-testing-playbook.md` now include both Grok families in their tables and raise the allowlist count from 10 to 18. Their rosters and enumerated model lists are sorted alphabetically by ID or by family name then ID instead of release order, and the single-source catalog `references/providers-and-models.md` gives the fullest account while noting Cursor still lists Grok 4.5 upstream.
