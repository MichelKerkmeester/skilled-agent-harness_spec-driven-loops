Cursor users can now dispatch Grok 4.7 at its highest tier through this skill.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/001-deep-research` (Level 1)

## What's New at a Glance

- **Grok 4.7 xhigh fast joins the allowlist.** `grok-4.7-xhigh-fast` takes the roster from 21 to 22 and sorts last. It is the only Grok 4.7 id in scope. The other seven 4.7 tiers stay out, and Composer, Gemini, GLM 5.2, GPT-5.6 Luna Max and Grok 4.5 and 4.6 are unchanged.
- **The 4.7 ids drop the `cursor-` prefix.** Cursor lists them as `grok-4.7-{low,medium,high,xhigh}[-fast]` with no Max tier, so a request for "Grok 4.7 Max" maps to the extra-high fast id.
- **The live listing and a dispatch confirmed the id.** On 2026-09-26 `cursor-agent --list-models` printed `grok-4.7-xhigh-fast`, and a `cursor-agent -p --model grok-4.7-xhigh-fast` probe replied `OK` with exit 0.
- **The guidance now matches the 22-id allowlist.** `SKILL.md`, `README.md`, the Cursor references, the prompt templates and the manual testing playbook show 22 ids and list the new id wherever they list the Grok tiers.
