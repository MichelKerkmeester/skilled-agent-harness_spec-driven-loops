#### A single-source provider and model catalog

Readers had no one place to answer the provider/model/effort/dispatch question for this mode. The release adds `references/providers-and-models.md`, a dedicated catalog of cli-cursor's one backing provider (Cursor via `cursor-agent`), the enforced 10-id model allowlist, the default model, the suffix-baked effort model (there is no `--effort` flag — the tier lives in the id), and the dispatch shape. The full 10-id allowlist is mirrored inline because that list is a safety contract, with a link to the `CURSOR_SUPPORTED_MODELS` enforcement source in `executor-config.ts` — if code and doc ever diverge, the code wins.

#### Trimming the scattered duplicates to a pointer

The same model facts were duplicated in `cli-reference.md` §5 and the `SKILL.md` roster, inviting drift. Both were trimmed to a compact residue that points at the new catalog as the single source.
