This first release gives other AI assistants a clearer, safer way to delegate focused work to Cursor's command-line tool, grounded in a live-verified Cursor CLI contract.

## What's New at a Glance

- **`cli-cursor` routes work by task.** It covers generation, review, Composer-model dispatch, read-only plan/ask exploration and agent-based delegation. Assistants can hand work to Cursor intentionally instead of treating it as a generic fallback.
- **Execution safeguards cover Cursor-specific risks.** The package maps approval choices to sandbox behavior and documents Cursor's always-zero exit code and shared editor-config surface. Its self-invocation guard uses live-confirmed `CURSOR_AGENT` and `CURSOR_CONVERSATION_ID` signals plus process ancestry to prevent a session already running inside Cursor CLI from dispatching itself.
- **Reusable guidance supports consistent handoffs.** The release includes a main guide, references for Cursor's worktree, cloud-worker and plugin surfaces, shared editor config and prompt templates. People can reuse the prompts instead of rebuilding them, making Cursor easier to adopt and use consistently.
