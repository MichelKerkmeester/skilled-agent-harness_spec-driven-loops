This release condenses `SKILL.md`. Claude Code dispatch behavior, routing, rules, models and contracts stay unchanged. Reference-table duplication moves to pointers. Compact dispatch guidance stays in `SKILL.md`.

&nbsp;

## What's New at a Glance

- Repeated reference tables move to pointers.
  - The flag glossary, unique-capabilities table, essential-command examples and troubleshooting table left `SKILL.md`.
  - That is because they duplicate `references/cli-reference.md`.
- Compact dispatch guidance stays in `SKILL.md`.
  - The guidance has a compact Model Selection roster and a compact Agent Delegation table.
  - The guidance also has a Dispatch-Critical Gotchas subsection.
  - That subsection covers the print-mode default and `--permission-mode plan` vs `bypassPermissions`.
  - The subsection also covers no `--search` flag and the `$CLAUDECODE` nesting check.
- Model Selection and Agent Delegation point to details.
  - Model Selection drops redundant use-case prose.
  - Model Selection points to `cli_reference.md` §6 for current-generation IDs.
  - Agent Delegation drops the per-row invocation-pattern column.
  - Agent Delegation points to `agent_delegation.md`.
- Dispatch safeguards remain verbatim.
  - All 13 ALWAYS rules, 4 NEVER rules, 4 ESCALATE conditions and the Memory Handback protocol remain unchanged.
  - So do the smart-router `INTENT_SIGNALS` / `RESOURCE_MAP` / `LOADING_LEVELS` dictionaries.
  - So do the self-invocation guard and the OAuth auth pre-flight (`claude auth login` / `setup-token`).
  - So does the default-invocation override table.

&nbsp;

## Upgrade

No migration required. The full flag, capability, session and troubleshooting reference now lives solely in `references/cli-reference.md`. That file loads on every invocation.
