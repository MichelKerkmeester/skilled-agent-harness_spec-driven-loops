This release condenses `SKILL.md` while keeping Claude Code dispatch behavior, routing, rules, models and contracts unchanged. It moves reference-table duplication to pointers and leaves compact dispatch guidance in `SKILL.md`.

## What's New at a Glance

- **Repeated reference tables move to pointers.** The flag glossary, unique-capabilities table, essential-command examples and troubleshooting table were removed from `SKILL.md` because they duplicate `references/cli-reference.md`.
- **Compact dispatch guidance stays in `SKILL.md`.** It has a compact Model Selection roster, a compact Agent Delegation table and a Dispatch-Critical Gotchas subsection covering the print-mode default, `--permission-mode plan` vs `bypassPermissions`, no `--search` flag and the `$CLAUDECODE` nesting check.
- **Model Selection and Agent Delegation point to details.** Model Selection drops redundant use-case prose and points to `cli_reference.md` §6 for current-generation IDs. Agent Delegation drops the per-row invocation-pattern column and points to `agent_delegation.md`.
- **Dispatch safeguards remain verbatim.** All 13 ALWAYS rules, 4 NEVER rules, 4 ESCALATE conditions and the Memory Handback protocol remain unchanged. So do the smart-router `INTENT_SIGNALS` / `RESOURCE_MAP` / `LOADING_LEVELS` dictionaries, the self-invocation guard, the OAuth auth pre-flight (`claude auth login` / `setup-token`) and the default-invocation override table.

## Upgrade

No migration required. The full flag, capability, session and troubleshooting reference now lives solely in `references/cli-reference.md`, which loads on every invocation.
