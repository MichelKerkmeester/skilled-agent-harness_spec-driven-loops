The model roster was scattered: the full Anthropic id list, the default pin, the `--effort` lever, and the dispatch shape were duplicated across `SKILL.md` §3 and `references/cli-reference.md` §6, so any model change meant editing two places and risked drift. This release gives cli-claude-code a single source of truth for "which model, which effort, how to dispatch" — a dedicated, routable catalog leaf — and trims the two former homes down to a compact residue plus a pointer. cli-claude-code is single-provider (Anthropic only) and never curated a roster, so this is a catalog-and-trim restructure: no model ids, defaults, or dispatch behavior changed.

---

## What Changed

#### New Catalog Leaf

- **`references/providers-and-models.md` added** -- a dedicated single-source catalog of cli-claude-code's Anthropic model ids, the `claude-sonnet-4-6` default pin, the `--effort` reasoning-effort lever, and the non-interactive dispatch shapes (default envelope + spec-gate-neutralized child envelope). Registered as a routable reference leaf so the router and readers reach one authoritative file.
- **Section 2 structured per provider** -- the catalog's `## 2. PROVIDERS & MODELS` uses a `### Anthropic` heading plus a model table (id / default / tier-and-use-case notes), the shape that scales cleanly if a provider is ever added even though this mode stays single-provider today.

#### Roster Trimmed to Residue + Pointer

- **`references/cli-reference.md` §6 MODELS trimmed** -- the section keeps a compact `### Available Models` table and leads with a bold pointer to `providers-and-models.md` for the full catalog, tiers, defaults, and `--effort` mapping. The exhaustive model prose no longer lives here.
- **`SKILL.md` Model Selection compacted** -- the roster residue is a two-sentence Model Selection paragraph (default pin, when to reach for Opus / Haiku, current-generation ids selectable by name) that ends in a pointer to `references/providers-and-models.md`. The small 6-id roster stays inline for self-sufficiency; the deep detail is single-sourced in the catalog.

#### Unchanged

- The skill default pin (`claude-sonnet-4-6`), the full model roster (`claude-opus-4-8` / `claude-sonnet-5` / `claude-fable-5` / `claude-opus-4-6` / `claude-sonnet-4-6` / `claude-haiku-4-5-20251001`), routing, permission modes, and every dispatch rule are untouched.
- No roster curation occurred -- cli-claude-code is single-provider; this is a catalog + trim + restructure only.
