Claude Code sessions could delegate back through the `cli-claude-code` skill, adding no value and creating confusion. This release makes the workflow simpler by avoiding unnecessary loops. This is a rule-only documentation update.

## What's New at a Glance

- **The `cli-claude-code` guide now warns against self-invocation.** Claude Code sessions should use the built-in features they already have instead of calling themselves through the wrapper.

No migration required.
