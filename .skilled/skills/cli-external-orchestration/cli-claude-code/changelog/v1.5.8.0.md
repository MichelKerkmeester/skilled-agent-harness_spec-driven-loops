# v1.5.8.0, The Machine Router Moves to ROUTER.md

`SKILL.md` now keeps `SMART ROUTING` as short prose and ends with a one-line link to `ROUTER.md`. The parsed router is identical to the previous edition, so routing is unchanged.

&nbsp;

## What's New at a Glance

- **The router details have a dedicated file.** `ROUTER.md` holds the intent map, resource map, default resource, loading levels and routing pseudocode under `MACHINE ROUTER`, after a short overview and intent model.
- **Supporting documents point to the new location.** Testing playbooks, feature catalog entries and references now point to `ROUTER.md`.
- **`DESIGN` is a no-load signal.** `ROUTER.md` declares `DESIGN` in `NO_LOAD_INTENTS`, so the signal loads no resource of the skill.
- **An alignment pass finished the pointer sweep.** The routing-recall playbooks read ROUTER.md in their resource-map step and in failure triage, the provider catalog lists ROUTER.md, and three implementation anchors cite a section instead of a line number.
