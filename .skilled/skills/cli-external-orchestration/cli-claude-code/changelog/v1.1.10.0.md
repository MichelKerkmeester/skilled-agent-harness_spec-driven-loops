This release aligns the `cli-claude-code` prompt-quality card with the sk-doc asset template. That template is used across the other CLI skills. Dispatch behavior is unchanged.

## What's New at a Glance

- **The prompt-quality card gains the template's opening and closing sections.** `assets/prompt-quality-card.md` opens with `## 1. OVERVIEW` for Purpose and Usage. It ends with `## N. RELATED RESOURCES`. Shared Layer, Model Overrides, Delegation / Precedence and Failure Patterns are recased and renumbered as ALL-CAPS sections. The framework and CLEAR tables stay in the canonical card. They are not inlined. The pointer to that card remains unchanged.

## Upgrade

No migration required.
