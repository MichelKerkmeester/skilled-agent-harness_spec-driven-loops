This documentation trim and cross-link makes the Claude prompt card a lean supplement to sk-prompt. It points readers to its canonical source for shared guidance. It removes duplicated content that created drift risk. That same content doubled the maintenance surface.

&nbsp;

## What's New at a Glance

- The `prompt_quality_card.md` card (`assets/prompt-quality-card.md`) is now a Claude-specific supplement to sk-prompt.
  - It removes the duplicated framework table and CLEAR scoring rubric.
  - It retains Claude model defaults and permission-mode notes.
  - It points readers to the canonical source for everything else.
- `SKILL.md` gains one prose block for the three-tier precedence rule and sk-prompt hub cross-link.
  - The tiers put the sk-prompt canonical card first.
  - That card holds the framework table, CLEAR rubric and cross-model guidance.
  - The cli-claude-code supplement comes second.
  - The supplement holds Claude model defaults, permission modes and self-invocation guard.
  - Caller-supplied in-prompt instructions override both.
  - The CLEAR rule points to the canonical card.
