This first release gives outside AI assistants a clearer way to delegate focused work to Claude Code. Model guidance and reusable handoff materials help teams use Claude Code deliberately instead of as an ad hoc fallback.

## What's New at a Glance

- **Other assistants can better match Claude Code to suitable work.** Routing patterns cover deep reasoning, code editing, review, structured output and agent-based delegation. Routing signals also help other assistants suggest Claude Code when it fits.
- **Model guidance shows where Claude Code is useful.** It covers model tiers, deeper thinking mode, structured output, budget controls and the edit workflow, helping users choose it for jobs where it adds value.
- **Reusable materials support consistent use.** The main guide, references, comparisons and prompt templates give teams material to reuse instead of building prompts from scratch.
