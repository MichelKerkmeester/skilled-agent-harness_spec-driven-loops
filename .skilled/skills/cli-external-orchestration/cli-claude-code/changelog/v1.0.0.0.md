This first release gives outside AI assistants a clearer way to delegate focused work to Claude Code. Model guidance and reusable handoff materials help teams use Claude Code deliberately. That is instead of using it as an ad hoc fallback.

## What's New at a Glance

- **Other assistants can better match Claude Code to suitable work.** Routing patterns cover deep reasoning and code editing. They also cover review and structured output. They also cover agent-based delegation. Routing signals help other assistants suggest Claude Code when it fits.
- **Model guidance shows where Claude Code is useful.** It covers model tiers and deeper thinking mode. It also covers structured output, budget controls and the edit workflow. This helps users choose it for jobs where it adds value.
- **Reusable materials support consistent use.** The main guide, references, comparisons and prompt templates give teams material to reuse. That is instead of building prompts from scratch.
