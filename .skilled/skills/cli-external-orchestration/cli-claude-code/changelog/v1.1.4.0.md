This release shortens `cli-claude-code`'s guide. It keeps the `cli-*` family consistent. Sibling `cli-*` skills received the same treatment in coordinated commits.

## What's New at a Glance

- **Shared guidance moved to two new references.** The helper bodies were byte-for-byte identical across all five `cli-*` sibling skills. So was the seven-step Memory Handback Protocol. They now live in `shared_smart_router.md` and `memory_handback.md`. Both sit under `system-spec-kit/references/cli/`.
- **Claude Code's routing data stays in `SKILL.md`.** `INTENT_SIGNALS`, `RESOURCE_MAP`, `LOADING_LEVELS` and `UNKNOWN_FALLBACK_CHECKLIST` remain inline. Beside them sits a six-line stub. It names the helper-call sequence and a one-line cross-reference.
- **The compression is limited to wrapper boilerplate.** The verbose `ALWAYS`, `NEVER` and `ESCALATE` prose was compressed. Section 8 collapsed to a five-line stub. That stub points back to Section 5.
- **The self-invocation guard remains intact.** `SKILL.md` keeps the top-of-file `CRITICAL` admonition. It keeps Section 1's first bullet, "You ARE Claude Code already." Its three-layer `detect_self_invocation` check remains visible. It uses the environment, process ancestry and state lockfile. Then it calls `refuse(...)`.
- **The external interface stays unchanged.** The frontmatter, `Keywords` HTML comment and advisor-consumed metadata remain the same. No script changes are required. Agents that read the body of `SKILL.md` see compressed but equivalent guidance. Full helper-body or Memory Handback caveat detail is available on demand through the new shared references.
- **The root playbook now uses lowercase.** It was renamed from `MANUAL_TESTING_PLAYBOOK.md` to `manual_testing_playbook.md`. All scenario references were updated.

## Upgrade

No migration required.
