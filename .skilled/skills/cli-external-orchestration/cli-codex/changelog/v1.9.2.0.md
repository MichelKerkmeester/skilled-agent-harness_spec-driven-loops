This release corrects two things the GPT-6 cutover left wrong. The playbook's default-model scenarios agree with the skill again, and every effort-ceiling statement gives `gpt-5.6-terra` the `ultra` ceiling that Codex's model cache reports.

> Spec folder: `specs/cli-external-orchestration/077-gpt-6-luna-sol-cutover` (Level 2)

## What's New at a Glance

- **Terra reaches `ultra`.** v1.9.1.0 gave `gpt-5.6-terra` a `max` ceiling, but Codex's model cache lists `low` through `ultra` for it, so Sol is no longer called the only model that reaches `ultra`.
- **`gpt-6-astra` stays off the roster.** v1.9.1.0 said Terra has no GPT-6 counterpart; more exactly, Codex's catalog names no successor to Terra but does list `gpt-6-astra`, described as frontier intelligence with a `low` to `ultra` ladder. The roster stays `gpt-5.5`, `gpt-6-luna`, `gpt-5.6-terra` and `gpt-6-sol`.
- **CX-001 and CX-002 test the real default.** A playbook sweep had both scenarios call `gpt-6-luna` the default, and CX-002's roster loop listed Luna twice and left Sol out. Both assert `gpt-5.5` at `medium` again, and CX-002 runs Luna, Terra and Sol once each and reads all three outputs.
