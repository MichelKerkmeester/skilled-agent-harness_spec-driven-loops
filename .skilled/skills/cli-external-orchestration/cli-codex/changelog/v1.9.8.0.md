# v1.9.8.0, GPT-6.1 Terra joins the roster

Codex can now be asked for GPT-6.1 Terra by name. The Codex model catalog lists `gpt-6.1-terra` with efforts from `low` to `ultra`, and a one-turn dispatch on it replied as expected.

> Spec folder: `specs/cli-external-orchestration/083-gpt-6-1-terra-roster` (Level 1)

&nbsp;

## What's New at a Glance

- **GPT-6.1 Terra is a fifth model.** Pass `--model gpt-6.1-terra` with any effort up to `ultra`. It has no dedicated config profile, so it is called directly like GPT-5.6 Terra.
- **The roster test checks it.** The roster smoke scenario now dispatches all five models, so a Terra model the CLI stops accepting shows up as a failure.

&nbsp;

## Upgrade

No migration required. `gpt-5.5` stays the default, and `gpt-5.6-terra` stays on the roster.
