The first release of `cli-codex` gives other AI assistants a way to delegate focused work to OpenAI's Codex command-line tool. Its guidance helps teams follow the handoff workflow more deliberately and trust it.

## Why This Release

Other assistants needed a clear way to decide when Codex was the right helper. Delegated work also needed file-access guardrails, clearer specialist roles and reusable prompts.

## What's New at a Glance

- **Route requests by work type.** `cli-codex` covers generation, review, research, architecture work and delegation to agents, so Codex is less likely to be treated as a generic fallback. The added Skill Advisor routing signals suggest Codex when it fits.
- **Choose a balance of safety and capability.** The skill documents sandbox levels as file-access guardrails and lists the specialist agents Codex can use. Teams can choose a balance that fits each job.
- **Reuse support material.** The release includes a main guide, a user-facing overview with quick-start information, references, comparisons and prompt templates. These make Codex easier to adopt and use consistently without rebuilding delegation prompts from scratch.
