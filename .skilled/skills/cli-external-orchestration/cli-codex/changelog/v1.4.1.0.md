Seven playbook-authoring bugs surfaced when the cli-codex manual playbook ran against Codex 0.125.0. This release restores the affected scenarios to the working pattern. The remaining authoring-related failures traced to playbook drift rather than Codex runtime issues. They are expected to pass on the next re-run.

&nbsp;

## What's New at a Glance

- Five prompts now include the pre-approved Gate 3 preamble.
  - The explicit approval-policy, native hook integration, cross-AI generate-review-fix cycle, prompt-template inventory and CLEAR-scoring prompts now add `Spec folder: <path> (pre-approved, skip Gate 3)`.
  - SKILL.md ALWAYS rule 8 requires the preamble.
  - Codex previously inherited the project's `CLAUDE.md` and `AGENTS.md` gate rules.
  - Codex paused in non-interactive `exec` mode for a spec-folder choice no human would answer.
  - The preamble lets the dispatched task run.
- The `@debug` profile scenario keeps the intended off-by-one bug.
  - The `printf` block was meant to create a deliberately broken JavaScript file.
  - But `let i = 0.` and `I <= arr.length. I++` stopped Codex from parsing the file.
  - Codex now writes `for (let i = 0; i <= arr.length; i++)`.
  - That leaves the off-by-one as the only flaw.
  - `codex exec` also redirects stdin with `< /dev/null`, as ALWAYS rule 5 requires.
- The session resume/fork scenario resumes from the actual session UUID.
  - The prompt asked the model to end with `SESSION_ID: <id>`.
  - But the model treated the marker literally and emitted `cx017`.
  - So resume calls used an invalid id.
  - The scenario now extracts the UUID from Codex's verbose header.
  - The scenario uses `session id: [a-f0-9-]+`, with `ls -t ~/.codex/state/` as a fallback.
  - The scenario removes `--sandbox` from `codex exec resume`.
  - That is because the subcommand rejects it as an invalid flag.
  - The scenario also redirects stdin from `/dev/null` for every call.
- The playbook uses a lowercase filename.
  - `MANUAL_TESTING_PLAYBOOK.md` is now `manual_testing_playbook.md`.
  - Scenario references use the new name.
  - The sk-doc template now defaults `/create:testing-playbook` to the lowercase convention for future runs.
- The `--search` diagnosis is corrected.
  - Codex 0.125.0 accepts the flag.
  - So flag positioning did not explain the web-search and exec-mode live-browsing scenarios.
  - Neither of those was patched.
  - The web-search and exec-mode live-browsing failures may relate to entitlement or rate limits.

&nbsp;

## Upgrade

- Re-pull and re-run.
- Operators using the cli-codex manual playbook should do this to get the corrected scenarios.
- Keep existing dispatch defaults.
- Scripts using the documented `gpt-5.5 + medium + fast` defaults are unaffected.
- The release makes no skill-surface changes.
