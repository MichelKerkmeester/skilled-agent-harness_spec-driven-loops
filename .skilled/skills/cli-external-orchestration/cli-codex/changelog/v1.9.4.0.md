The fan-out rule now says which dispatches it covers. The dispatch gotchas record a sandbox limit. That limit made a child report a passing check as failed.

&nbsp;

## What's New at a Glance

- The fan-out rule covers research and review lineages only.
  - ALWAYS rule 2 and Execution Ownership sent every orchestrated dispatch through `fanout-run.cjs`.
  - That script accepts only the `research` and `review` loop types.
  - A single build or doc dispatch now uses the child dispatch envelope in `references/providers-and-models.md` §5.
- A sandboxed child cannot run checks that start `tsx`.
  - Under `--sandbox workspace-write`, spec-kit's `npm --prefix runtime/cli run check` fails with `listen EPERM`.
  - The check passes outside the sandbox.
  - The new fifth gotcha tells the orchestrator to run such checks itself.

&nbsp;

No migration required.
