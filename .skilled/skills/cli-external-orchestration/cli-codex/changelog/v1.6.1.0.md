`SKILL.md` gets more concise. Repeated reference material moves into pointers to `references/cli-reference.md`. The file drops from 4630 to 3976 words. Models and contracts remain unchanged.

&nbsp;

## What's New at a Glance

- `SKILL.md` points to the always-loaded CLI reference.
  - The flag glossary, unique-capabilities table, essential-command examples and troubleshooting table now live in `references/cli-reference.md`.
  - That file is ALWAYS loaded on every invocation.
  - `SKILL.md` keeps only three dispatch-critical gotchas and a pointer.
  - The read-only sandbox default silently does nothing.
  - `service_tier="fast"` must be explicit.
  - There is no `--reasoning-effort` flag.
- Repeated guidance appears once.
  - The duplicate install/auth block was consolidated into one authoritative statement.
  - So was the repeated per-model ceiling clause.
  - So were the duplicated sandbox and fast-mode warnings.
  - Section 8 points to Section 5's reference index instead of restating it.
- Existing rules and routing references are preserved verbatim.
  - The 16 ALWAYS rules, 5 NEVER rules, 4 ESCALATE conditions and Memory Handback protocol remain as written.
  - The four-model GPT-5.5 / GPT-5.6 roster stays verbatim.
  - So do the per-model reasoning-effort ceilings and the user-override resolution table.
  - The `INTENT_SIGNALS` / `RESOURCE_MAP` / `LOADING_LEVELS` router dictionaries stay too.
  - So do the self-invocation guard and the auth pre-flight decision tree.

&nbsp;

## Upgrade

No migration required. Dispatch behavior, routing and every rule are unchanged. The full flag, sandbox, session and troubleshooting reference now lives only in `references/cli-reference.md`. That file is ALWAYS loaded on every invocation.
