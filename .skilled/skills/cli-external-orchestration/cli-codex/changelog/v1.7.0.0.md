# v1.7.0.0, Codex Dispatch Requires ChatGPT OAuth

Codex dispatch now stops before it starts when no OAuth session is active.

- The pre-flight now checks only for an OAuth session.
- When Codex is not logged in, `cli-codex` asks you to run `codex login`.
- It waits instead of dispatching.

Codex sign-in now follows one ChatGPT OAuth route.

- `codex login` starts a browser sign-in with a ChatGPT account.
- It requires a ChatGPT Plus, Pro, Business, Edu or Enterprise account.

The API-key route for Codex is removed.

- `OPENAI_API_KEY` is no longer offered for Codex authentication.
- `cli_reference.md` sections 3, 13 and 14 remove the API-key method.

> [!IMPORTANT]
> One change can break an existing setup.
>
> 1. `OPENAI_API_KEY` is no longer offered for Codex authentication. [Use ChatGPT OAuth](#c-use-chatgpt-oauth)

&nbsp;

## Why This Release

Before this release, the pre-flight decision used both `OPENAI_KEY_OK` and `CODEX_OAUTH_OK`.

- The pre-flight decision used both checks before this release.

## Codex Authentication

Codex authentication now uses a single ChatGPT OAuth session. The pre-flight waits when no OAuth session is active.

#### Use ChatGPT OAuth <a id="c-use-chatgpt-oauth"></a>

> [!WARNING]
> `OPENAI_API_KEY` is no longer offered for Codex authentication.

- `codex login` starts a browser sign-in with a ChatGPT account.
- It requires a ChatGPT Plus, Pro, Business, Edu or Enterprise account.

#### Wait for Sign-In <a id="c-wait-for-sign-in"></a>

- The pre-flight now checks only for an OAuth session.
- When Codex is not logged in, `cli-codex` asks you to run `codex login`.
- It waits instead of dispatching.
- The model roster, routing, sandbox modes and every dispatch rule remain unchanged.

#### Remove API-Key Setup <a id="c-remove-api-key-setup"></a>

- `cli_reference.md` sections 3 (Authentication), 13 (Troubleshooting) and 14 (Environment Variables) remove the API-key method.
- They also remove `OPENAI_API_KEY` and the `platform.openai.com` key-management link.
- The generic NEVER rule against sending API keys or passwords in prompts remains.
- That is because it covers secret handling, not authentication.

&nbsp;

## Upgrade Notes

One sign-in step applies to machines that used the API-key method.

#### Before You Start <a id="c-before-you-start"></a>

1. If a machine relied on `OPENAI_API_KEY` for Codex, run `codex login` once. That establishes a ChatGPT OAuth session. Dispatch flags are otherwise unchanged.
