## What's New at a Glance

- **The roster now names `gpt-5.5`, `gpt-5.6-luna`, `gpt-5.6-terra` and `gpt-5.6-sol`.** `gpt-5.5` remains the default model, with `gpt-5.5 medium` as the skill default.
- **The documented `none…xhigh` reasoning-effort scale now also includes `max` and `ultra`.** `gpt-5.5` caps at `xhigh`, `gpt-5.6-luna` and `gpt-5.6-terra` at `max`, and `gpt-5.6-sol` at `ultra`.
- **Model guidance matches effort levels to tasks.** It recommends `gpt-5.6-luna max` for deep implementation and `gpt-5.6-sol xhigh`/`ultra` for verification and review.
- **The CX-002 playbook no longer treats `gpt-5.5` as the only supported model.** Its `gpt-5.5 model lock` scenario now verifies the default pin and callable GPT-5.6 roster.

## Upgrade

The default dispatch is unchanged: `--model gpt-5.5 -c model_reasoning_effort="medium" -c service_tier="fast"`. To use deeper reasoning, name a GPT-5.6 model per dispatch within its effort ceiling. For example, use `--model gpt-5.6-sol -c model_reasoning_effort="ultra"`.
