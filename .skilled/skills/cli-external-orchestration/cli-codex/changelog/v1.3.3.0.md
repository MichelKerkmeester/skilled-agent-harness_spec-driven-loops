This release updates Codex delegation rules to pass along an approved spec folder when one exists. That makes non-interactive delegation more likely to keep moving instead of pausing for missing project context. The goal is to make the workflow easier to follow and trust, and this is a rule-only change.

## What's New at a Glance

- **Pass the active spec folder in Codex handoffs.** When a spec folder has already been approved, the calling AI must include it in the handoff.

## Upgrade

No migration required.
