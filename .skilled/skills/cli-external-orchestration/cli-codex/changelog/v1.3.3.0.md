This release updates Codex delegation rules. The rules pass along an approved spec folder when one exists. That makes non-interactive delegation more likely to keep moving. It is less likely to pause for missing project context. The goal is to make the workflow easier to follow and trust. This is a rule-only change.

&nbsp;

## What's New at Glance

- Pass the active spec folder in Codex handoffs.
  - When a spec folder has already been approved, the calling AI must include it in the handoff.
