The Codex skill gives every delegation one predictable default and lets callers tune reasoning depth for tasks that need more or less analysis.

## What's New at a Glance

- **Every task uses one default dispatch.** Scripts previously chose between `gpt-5.4` and `gpt-5.3-codex` before dispatch. Callers were asked to pick even for ordinary work. Now every task uses `--model gpt-5.5 -c model_reasoning_effort="medium" -c service_tier="fast"`. Calls with no input use this path and stay reproducible across runs.
- **Callers can adjust reasoning effort.** For deeper analysis in architecture or security audits, callers can use `Use gpt 5.5 high fast`. For trivial lookups, they can use `Use gpt 5.5 low`. These phrases resolve to matching `model_reasoning_effort` values while the model and service tier stay fixed.
- **The guide and templates now tell one model story.** The guide still referred to two models in tables, comparisons and per-task examples. Across `SKILL.md`, `README.md` and the four reference files, every model table, selection strategy, agent definition and bash snippet now uses `gpt-5.5` as the only model and reasoning effort for task tuning. All templates were rewritten to match.

## Upgrade

No migration is required. Existing scripts passing `--model gpt-5.4` or `--model gpt-5.3-codex` should be updated to `--model gpt-5.5` and, if desired, given an explicit `-c model_reasoning_effort="..."` value. Scripts that relied on the old default will automatically pick up `gpt-5.5` with `medium` reasoning through `fast` when they regenerate their command lines from the skill.
