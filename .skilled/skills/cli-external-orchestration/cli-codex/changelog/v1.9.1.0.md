The Luna and Sol alternates move to OpenAI's GPT-6 generation. `gpt-6-luna` and `gpt-6-sol` replace `gpt-5.6-luna` and `gpt-5.6-sol`. That holds wherever this skill recommends, dispatches or tests them. The deep-loop fan-out's unpinned Codex lineage now runs `gpt-6-luna`.

> Spec folder: `specs/cli-external-orchestration/077-gpt-6-luna-sol-cutover` (Level 2)

## What's New at a Glance

- **Luna and Sol run on GPT-6.** The roster names `gpt-6-luna` (ceiling `max`) and `gpt-6-sol` (ceiling `ultra`). So do the effort-ceiling table, the phrasing examples and every playbook scenario. These are the same ladders Codex's model cache reports for the 5.6 pair.
- **Terra and the default stay put.** `gpt-5.5` remains the skill default. `gpt-5.6-terra` keeps its 5.6 id. That is because Terra has no GPT-6 counterpart in Codex's catalog.

## Upgrade

No migration required. If an operator's `~/.codex/config.toml` still sets `model = "gpt-5.6-luna"`, that default stays until they change it.
