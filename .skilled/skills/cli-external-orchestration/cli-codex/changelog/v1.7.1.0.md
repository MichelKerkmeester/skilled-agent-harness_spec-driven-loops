v1.7.1.0 makes a small, safe follow-up condensation to the Codex Agent Delegation guidance in `SKILL.md`.

## Why This Release

`SKILL.md` had already been condensed in v1.6.1.0 from 4630 to 3976 words. The remaining content was largely load-bearing. ALWAYS rules 10 to 16 were preserved verbatim as functional dispatch contracts because a small word saving was not worth risking a dropped directive.

## What's New at a Glance

- **The Codex Agent Delegation table drops the `Invocation Pattern` column and its seven full `codex exec -p ...` examples because they duplicate `agent_delegation.md`.** The table now lists Task and Profile, includes a one-line note for the built-in `codex exec review` subcommand and points to `references/agent-delegation.md` for the full roster and invocation patterns.
- **The dispatch rules and Memory Handback protocol stay verbatim.** `SKILL.md` keeps all 16 ALWAYS rules, 5 NEVER rules and 4 ESCALATE conditions.
- **The four-model GPT-5.5 / GPT-5.6 roster and router dictionaries stay verbatim.** The dictionary names are `INTENT_SIGNALS` / `RESOURCE_MAP` / `LOADING_LEVELS`.
- **The Codex safeguards stay verbatim in `SKILL.md`.** They are the self-invocation guard and ChatGPT OAuth auth pre-flight.

## Upgrade

No migration required. Dispatch behavior, routing, rules, models and contracts are unchanged.
