## What's New at a Glance

- **Model facts now have one authoritative catalog.** `references/providers-and-models.md` covers model families, uids (model identifiers), aliases, the default, permission-mode lever and dispatch shapes. The catalog is registered as a routable leaf, while the `references/cli-reference.md` §5 model section and `SKILL.md` roster retain compact residues pointing to it.
- **Cognition variants are grouped by family.** Section 2 of the catalog uses a per-family table under the `### Cognition` provider heading. Each row gives the model uid, context window and tier notes.
- **The roster now covers four families.** The ids were read from a live `devin models list`. GLM-5.2 has six variants: `glm-5-2`, `glm-5-2-max`, `glm-5-2-1m`, `glm-5-2-max-1m`, `glm-5-2-none` and `glm-5-2-none-1m`. SWE-1.7 has `swe-1-7`, `swe-1-7-medium` and `swe-1-7-lightning`. Grok 4.5 has `grok-4-5-low`, `grok-4-5-medium` and `grok-4-5-high`. DeepSeek V4 Pro uses `deepseek-v4-pro` with uid `deepseek-v4`.
- **The default changes from `adaptive` to `swe`.** The `swe` alias resolves to `swe-1-7-lightning`. The curated roster drops `adaptive`, `opus`, `sonnet`, `claude`, `haiku`, `gpt`, `codex`, `gemini`, `kimi` and the SWE-1.6 ids. The `adaptive` router remains available through `devin models list` but is outside the curated catalog's scope.
