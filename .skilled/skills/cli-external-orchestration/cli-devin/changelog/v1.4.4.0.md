GPT-6 Luna can now be dispatched through Devin. Devin had listed the GPT-6 Luna family for a while, but the fan-out runner only accepts ids on this skill's curated roster, so a request for GPT-6 Luna was refused before it reached Devin. This release adds the family's Max pair to the roster beside the GPT-5.6 Luna pair, which stays.

> Spec folder: `specs/agents/013-prompting-guide-alignment` (Level 2)

## What's New at a Glance

- **`gpt-6-luna-max` and `gpt-6-luna-max-priority` join the allowlist.** Both appear verbatim in the live `devin models list` on devin 3000.11.1. The `-priority` suffix is Devin's Fast tier, so `gpt-6-luna-max-priority` is GPT-6 Luna at Max thinking, Fast.
- **The GPT-5.6 Luna pair stays.** Devin lists GPT-6 Luna and GPT-5.6 Luna as separate families at different prices, so this is an addition. Nothing was swapped out.
- **One id is dispatch-tested, one is not.** A direct `devin -p --model gpt-6-luna-max-priority` call returned a live reply at exit 0 on 2026-09-24. `gpt-6-luna-max` was confirmed on the live list only, and the docs say so.
- **Both copies of the roster moved together.** `DEVIN_SUPPORTED_MODELS` in the deep-loop executor config and its hand-copied mirror in the fan-out runner carry the new ids, and the roster test fixture lists them, so the parity check between the two copies still holds.

## Upgrade

No migration required. Pass `--model gpt-6-luna-max-priority` (or `gpt-6-luna-max`) to reach the new family. The default model is unchanged.
