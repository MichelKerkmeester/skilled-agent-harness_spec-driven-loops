Devin's model choices now include Grok 4.6 alongside Grok 4.5, so adding the newer family does not remove existing options.

> Spec folder: `specs/cli-external-orchestration/036-grok-4.6-support/`

## What's New at a Glance

- **Devin's live roster adds Grok 4.6 beside Grok 4.5.** `devin models list` showed `grok-4.6` alongside still-present `grok-4.5` on 2026-08-12, confirming Cognition has not dropped 4.5.
- **The supported choices add four Grok 4.6 model IDs.** `grok-4-6-{low,medium,high,xhigh}` joins the three existing `grok-4-5-{low,medium,high}` IDs, an addition rather than a swap. GLM-5.2, SWE-1.7 and DeepSeek are unchanged.
- **Grok 4.6 adds an `xhigh` effort tier.** Grok 4.5 never had that tier. Every `grok-4-6-*` ID was dispatch-tested end to end. `grok-4-5-high` was independently re-dispatch-tested and still works.
- **Devin's documentation now covers both Grok versions.** `SKILL.md`, `README.md` and `references/{cli-reference,providers-and-models}.md` describe both versions. The single-source `references/providers-and-models.md` catalog carries the fullest account, including Devin's upstream 4.5 listing.
- **Model rosters and tables now sort alphabetically by family and model ID.** Families sort by name, then IDs sort within each family instead of following release order. The Cognition family order is DeepSeek, GLM-5.2, Grok 4.5, Grok 4.6 and SWE-1.7.
