This first release lets other AI assistants delegate focused work to Cognition's Devin command-line tool. It packages safe execution rules, delegation patterns, and reference docs grounded in a live-verified Devin CLI contract, so teams can use Devin more deliberately. The goal is to make the workflow easier to follow and easier to trust.

---

#### Structured delegation into Devin

Other assistants needed a clear way to decide when Devin was the right helper for a task. The skill introduced routing patterns for generation, review, research, architecture work, subagent delegation, and cloud handoff. Requests can be handed off more intentionally instead of treating Devin as a generic fallback.

---

#### Safety and self-invocation guarding

Delegated work needed guardrails around the 4-tier permission model, OS-level sandboxing, and a self-invocation guard built from the `DEVIN_PROJECT_DIR` env signal plus process ancestry, so a session already running inside Devin CLI never dispatches itself.

---

#### Multi-model and subagent support material

People needed guides and templates they could reuse instead of rebuilding delegation prompts from scratch. The release shipped a main guide, references covering Devin's unique subagent system, cloud handoff mechanics, multi-model selection, and the built-in tool surface, plus prompt templates. Devin becomes easier to adopt and easier to use consistently.
