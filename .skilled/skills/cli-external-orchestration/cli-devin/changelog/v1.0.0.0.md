This first release lets other AI assistants delegate focused work to Cognition's Devin command-line tool. It packages guidance for deliberate delegation and safe execution. That guidance rests on reference material. The material is grounded in a live-verified Devin command-line contract. The workflow is easier to follow and trust.

## What's New at a Glance

- **Choose when to delegate to Devin.** Patterns guide generation, review, research, architecture work, subagent delegation and cloud handoff. So assistants can choose Devin for these requests. They can pick it instead of treating it as a generic fallback. References explain the `run_subagent` tool and custom `AGENT.md` profiles. They also cover `/handoff`, cloud session mechanics and multi-model selection. They describe Devin's built-in tool surface. Prompt templates give teams examples to reuse.
- **Stop Devin from dispatching itself.** The skill uses the 4-tier permission model and OS-level sandboxing. Its self-invocation guard checks the `DEVIN_PROJECT_DIR` environment signal and process ancestry. So a session already running inside Devin CLI never dispatches itself.
