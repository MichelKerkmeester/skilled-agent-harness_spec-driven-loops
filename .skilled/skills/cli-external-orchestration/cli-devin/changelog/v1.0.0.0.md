This first release lets other AI assistants delegate focused work to Cognition's Devin command-line tool. It packages deliberate delegation and safe execution guidance, backed by reference material grounded in a live-verified Devin command-line contract. The workflow is easier to follow and trust.

## What's New at a Glance

- **Choose when to delegate to Devin.** Patterns guide generation, review, research, architecture work, subagent delegation and cloud handoff, so assistants can choose Devin for these requests instead of treating it as a generic fallback. References explain the `run_subagent` tool, custom `AGENT.md` profiles, `/handoff`, cloud session mechanics, multi-model selection and Devin's built-in tool surface, while prompt templates give teams examples to reuse.
- **Stop Devin from dispatching itself.** The skill uses the 4-tier permission model and OS-level sandboxing. Its self-invocation guard checks the `DEVIN_PROJECT_DIR` environment signal and process ancestry so a session already running inside Devin CLI never dispatches itself.
