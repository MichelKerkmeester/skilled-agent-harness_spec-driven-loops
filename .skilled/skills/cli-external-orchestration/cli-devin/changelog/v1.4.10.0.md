# v1.4.10.0, Long Prose Lines Become Short Sentences and Lists

Seventeen passages in the cli-devin skill were written as one very long line each: the prerequisite note, execution ownership, the whole model roster, the subagent profiles, the gotchas, seven of the ALWAYS rules, the design manifest and the memory handback. Some ran past a thousand characters, so a reader had to untangle four or five rules out of a single sentence.

Those lines are now short sentences, and a line that carried several rules or steps is now a short list. The instruction comes before the background it needs, and instructions address you directly.

The content did not change. Every model id, flag, path, command, exit code and number in the old lines is still there, and the rewrite adds nothing new. What selects this packet, what loads first and how a request routes are exactly as they were.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/010-prose-clarity-pass` (Level 2)

## What's New at a Glance

- **The model roster is a list of families.** DeepSeek, Gemini, GLM-5.2, GLM-5.3, GPT-5.6 Luna Max, GPT-6 Luna Max, SWE-2 and SWE-1.7 each hold their own bullet, and every id, price note and context size stays.
- **The gotchas read as rules.** The permission-mode default, the four-values-in-help trap and the `--sandbox` note are short lines, and the `--yolo` and project-skill observations are unchanged facts.
- **The numbered rules keep their numbers.** Seven ALWAYS rules that carried a paragraph each are now a lead line with indented detail, so the number you cite still points at the same rule.
- **The design manifest is one sentence.** The block's five fields read as a list inside a sentence, and the rule to ask before launching a child without a manifest keeps its own paragraph.
- **Every fact is the same.** No intent signal, reference path, model id or command changed, so a request routes where it always did.
