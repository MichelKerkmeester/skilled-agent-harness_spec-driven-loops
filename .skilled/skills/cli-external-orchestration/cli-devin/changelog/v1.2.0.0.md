Version 1.2.0.0 rewrites the cli-devin README on the shared skill README template. So the skill's purpose and delegation surface come before its reference details. It replaces retired model examples with current catalog facts. It brings the README version field into line with release history. The release updates documentation only.

## What's New at a Glance

- **The README starts with the skill's purpose.** The old aspect table buried the skill's outcome. The shared skill README template gives it a one-line pitch and at-a-glance table. A problem-first overview follows. It covers when a second AI perspective pays off. Its capability section names multi-model dispatch, subagent delegation, cloud handoff, session management and MCP integration.
- **The README's model examples now match the curated catalog.** It replaces retired `adaptive`, `opus`, `gpt` and SWE-1.6 examples. The four curated families take their place: GLM-5.2, SWE-1.7, Grok 4.5 and DeepSeek V4 Pro. It states the `swe` default and permission-mode lever. It points to `references/providers-and-models.md` as the single source for current model facts.
- **The README version field matches release history.** It moves to 1.2.0.0 from one release behind. The rewrite keeps the self-invocation guard, cloud handoff mechanics, subagent profiles, permission-mode table and troubleshooting rows that still apply.
