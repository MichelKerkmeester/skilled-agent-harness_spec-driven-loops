# v1.0.1.0, A third route through Mistral

DeepSeek Harness gains a third roster route: DeepSeek V4.1 Flash served by the operator's Mistral subscription. The route composes on dsh 0.2.2-rc.3, but no keyed dsh run has proved it yet.

> Spec folder: `specs/cli-external-orchestration/runtime-lifecycle/004-cli-mistral-vibe-creation/003-dsh-mistral-route`

&nbsp;

## What's New at a Glance

- **The roster has three routes.** Mistral `deepseek-v4-1-flash-1017` joins the LLM Gateway and OpenCode Go routes. Anything else is still refused before launch.
- **The route has its own patch.** `.dsh/patches/route-mistral-deepseek.patch.yml` carries no DeepSeek thinking format, its one difference from the other two.
- **The guard knows the new patch.** The `closed-roster` and `route-patch-required` rule messages and the dispatch preflight's patch list all name it.

&nbsp;

## Upgrade

Export `MISTRAL_API_KEY` before dispatching on the Mistral route.
