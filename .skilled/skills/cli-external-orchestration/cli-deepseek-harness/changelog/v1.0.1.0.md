# v1.0.1.0, A third route through Mistral

The closed roster now holds three routes. The new one runs DeepSeek V4.1 Flash on the operator's Mistral subscription.

&nbsp;

## What's New at a Glance

- A Mistral route patch.
  - `.dsh/patches/route-mistral-deepseek.patch.yml` pins `deepseek-v4-1-flash-1017` at `https://api.mistral.ai/v1` with `MISTRAL_API_KEY`.
- No DeepSeek thinking format on this route.
  - Mistral answers 422 to the DeepSeek `thinking` field.
  - Mistral accepts `reasoning_effort`.
  - So the patch leaves the thinking format out.
- The preflight admits the third patch.
  - The `route-patch-required` and `closed-roster` rules name it.
  - Any other patch is still refused.
- Not yet proven by a keyed run.
  - The route composes on dsh 0.2.2-rc.3.
  - No dsh run with a Mistral key has been recorded.

&nbsp;

## Upgrade

Set `MISTRAL_API_KEY` before dispatching on the Mistral route. The other two routes are unchanged.
