This release updates HerMeS's MiMo roster entry and the documentation describing it.

## Why This Release

The skill's contract says a roster ID change must update its documentation and `HERMES_SUPPORTED_MODELS` together, never one without the other.

## What's New at a Glance

- **The seven-ID roster now uses `mimo-v2.6-pro`.** This is the v2.6 spelling of the one MiMo ID HerMeS serves. The spelling now appears in `SKILL.md`, the fan-out dispatch feature catalog, the provider reference and the testing playbook, while `HERMES_SUPPORTED_MODELS` moved to the new spelling in the same pass as the documentation.
- **The `-ultraspeed` exclusion remains.** Hermes's roster remains Pi's roster minus that ID. The gateway answered HTTP 400 "not supported" for that ID on this route under the previous spelling. The pairing test checks the roster relationship structurally, and a live probe of the v2.6 spelling belongs to the testing playbook's next run.
- **The skill version identifies the roster generation.** Its own version changed so readers can tell which generation the roster describes.

## Upgrade

No migration required.
