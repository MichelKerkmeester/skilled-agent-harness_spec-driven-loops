# v1.0.7.0, The Repo-Guards Plugin Manifest Drops Its Author Line

The Hermes repo-guards plugin manifest is hand written and carried an `author: "OpenCode"` entry. No part of the Hermes plugin loader read that field. The claim was not true either. Both reasons point the same way, so the line is gone and every other field is untouched.

> Spec folder: `specs/sk-code/017-portable-code-modes/015-frontmatter-yaml-validity` (Level 2)

&nbsp;

## What's New at a Glance

- **The repo-guards manifest says only what it means.** Its `author` entry is removed. The name, version, kind, hook list and the rest of the plugin contract are unchanged.
