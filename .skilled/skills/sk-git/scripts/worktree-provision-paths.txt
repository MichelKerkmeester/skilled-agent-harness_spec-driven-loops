# Dependency trees a worktree needs before it can build, test, or pass its own
# commit gates. Every one of these is gitignored, so a fresh worktree has none
# of them and fails in ways that read as broken code rather than missing deps.
#
# One path per line, relative to the repository root, naming a directory that
# holds a package.json. A line may add a second whitespace-separated field: a
# file relative to the package directory that `npm run build` writes. Provision
# builds the package when that file is missing. Blank lines and # comments are ignored.
#
# Order is install order: a package whose build another package consumes comes
# first.

# The repo root. A check that runs from a temporary directory resolves shared
# packages by walking up from there; without this it finds nothing.
.

# built policy plan directly.

# The sk-communication projection OpenCode plugin imports this build output.
.skilled/skills/sk-communication/cli-communication-projection  dist/index.js

# The deep-loop runtime, which the fan-out runner needs.
.skilled/skills/system-deep-loop/runtime

# sk-doc. A conformance check copies a real skill hub into a temporary

# it, and without them the check fails on a hub that is correct.
