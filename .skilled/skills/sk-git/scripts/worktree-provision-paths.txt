# Dependency trees a worktree needs before it can build, test, or pass its own
# commit gates. Every one of these is gitignored, so a fresh worktree has none
# of them and fails in ways that read as broken code rather than missing deps.
#
# One path per line, relative to the repository root, naming a directory that
# holds a package.json. A line may add a second whitespace-separated field: a
# file relative to the package directory that the package's build writes. Provision
# builds the package when that file is missing. A package with a bun.lock and no
# package-lock.json is installed and built with bun. Blank lines and # comments are ignored.
#
# Order is install order: a package whose build another package consumes comes
# first.

# The repo root. A check that runs from a temporary directory resolves shared
# packages by walking up from there; without this it finds nothing.
.

# The shared source tree. Hook and script tests resolve vitest from here.
.skilled

# The OpenCode plugins, which live where the OpenCode runtime loads them and
# resolve the plugin SDK and zod from this tree. Without it the plugin tests
# that import a plugin fail on import.
.opencode

# sk-vision's runtime. The OpenCode plugin folder links its bundle, which bun
# builds, so without it the sk-vision plugin test cannot import the plugin.
.skilled/skills/sk-vision/vision-runtime  dist/plugin.js

# Spec-kit, its shared library, and the two builds that the validation
# orchestrator and the spec CLI are compiled into. Each build pulls in the
# shared library through its project references. Without the runtime output,
# the metadata re-derive behind repair-derived cannot import @spec-kit/runtime;
# without the CLI output, the continuity writer is missing.
.skilled/skills/system-spec-kit
.skilled/skills/system-spec-kit/shared
.skilled/skills/system-spec-kit/runtime  dist/api/index.js
.skilled/skills/system-spec-kit/runtime/cli  dist/continuity/generate-context.js

# The advisor daemon and CLI front door. The spec-gate hook core imports its
# built policy plan directly.
.skilled/skills/system-skill-advisor/runtime  dist/runtime/lib/policy-plan.js

# The deep-loop skill root, whose only dependency links the spec-kit shared
# package for the mode packets' scripts outside runtime/. The agent-mirror commit
# gate imports its frontmatter parser through that link.
.skilled/skills/system-deep-loop

# The deep-loop runtime, which the fan-out runner needs.
.skilled/skills/system-deep-loop/runtime

# sk-doc. A conformance check copies a real skill hub into a temporary
# directory; in a provisioned checkout the copy carries these dependencies with
# it, and without them the check fails on a hub that is correct.
.skilled/skills/sk-doc
