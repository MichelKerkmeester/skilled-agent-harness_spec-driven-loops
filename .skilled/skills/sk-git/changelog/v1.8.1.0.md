Both sk-git agent hooks used to read stdin until the host closed it. A host that held the pipe open left the hook waiting until the host's own timeout killed it, which reads as a stalled session rather than a decision. Each hook now reads through the shared hook reader, which settles at the end of the stream or after 3000 ms, whichever comes first.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/012-post-merge-deep-review/001-hook-stdin-deadlines` (Level 1)

&nbsp;

## What's New at a Glance

- **The message gate has a deadline.** `scripts/hooks/git-message-gate.mjs` reads stdin through `readStdin` from `.skilled/hooks/shared/hook-adapter-shared.cjs`.
- **The preflight advisory has a deadline.** `scripts/hooks/git-preflight-advisory.mjs` uses the same shared reader.
- **A test holds the line.** Both hooks join the shared suite `.skilled/hooks/shared/hook-stdin-deadline.test.mjs`, which strips every kill-switch, spawns each hook with stdin left open and requires it to exit 0 on its own no sooner than 2.9 seconds and before 8.
