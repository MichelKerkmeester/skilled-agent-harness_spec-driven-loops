This release stops live-sync from silently dropping a just-made commit when a stale or foreign rebase is present. A blanket `git rebase --abort` could reset the branch to that rebase's orig-head, after which the fast-forward-only follower advanced the now-behind branch and left the commit only on the remote. Both live-sync reconcilers now refuse rebases they did not start and restore the pre-rebase commit if an abort moves HEAD.

## What's New at a Glance

- **Pre-existing rebases are refused.** Before rebasing onto the live tip, `git-primary-reconcile.sh` and `git-sync.sh` check for an existing `rebase-merge` or `rebase-apply` state directory. If one exists, the script records a block and stops without touching it, so it cannot abort a rebase it did not start. This removes the path where a killed or stale leftover made the script's own `git rebase` fail instantly and triggered the blanket `git rebase --abort` fallback.
- **An abort can no longer leave HEAD rewound.** After its own abort, each script compares HEAD with the commit checked out before the rebase and uses `git reset --hard` to restore it if needed. Previously, `git-primary-reconcile.sh` detected drift but only warned and exited. `git-sync.sh` captured no pre-rebase SHA and recorded the rewind as `aborted cleanly`. Both now restore HEAD before reporting.
- **Existing branch and publish rules are unchanged.** Branch grammar, allocator, gates and commit rules are unchanged. This includes owner-first naming and the remote-push permission model. Every pre-push/commit gate is unchanged. `git-live-follow.sh` is unchanged and fast-forward-only. It advanced the branch after the rewind but was not the destructive actor. The genuine-conflict and clean-publish paths are unchanged. An own-rebase conflict still aborts cleanly with local commits preserved, and clean divergence still rebases and publishes.

## Upgrade

No migration required. The guards take effect at the next SessionStart reconcile and the next post-commit sync. The disable flags are unchanged. `SYSTEM_LIVE_SYNC_DISABLED=1` disables the whole loop. `SYSTEM_PRIMARY_RECONCILE_DISABLED=1` disables the SessionStart reconcile leg. `SPECKIT_AUTOSYNC=0` is for a single publish. If a stale rebase directory is present, `git-primary-reconcile.log` and `git-sync.log` record `pre-existing rebase in progress; refused` instead of a rewind. The full model and safety contract live in `references/continuous-integration.md`.
