# v1.11.6.0, The Machine Router Has Its Own File

This edition keeps skill guidance brief. It also moves the machine router into its own file.

&nbsp;

## What's New at a Glance

- **The former router section has its own home.** The old final MACHINE ROUTER section from SKILL.md now lives in sibling ROUTER.md. It sits under the heading 3. MACHINE ROUTER. A short overview and intent model come before it. It keeps the intent map, resource map and default resource. It also keeps the loading levels and routing pseudocode.
- **SMART ROUTING stays concise.** SKILL.md ends the short prose with a link to ROUTER.md. The parsed router is identical to the previous edition. So the move changed no route.
- **No supporting document needed repointing.** No sk-git reference, playbook, feature catalog entry or asset cited the old router section inside SKILL.md. So this packet left every supporting document where it was. It changed only the five router files.
- **Alignment pass: router-adjacent claims now match the files they describe.** The preflight advisory scenario copies `hard-rules.json` beside `SKILL.md`. That lets the documented sequence fire. The resource-discovery sentence names where those resources actually live. Both GitHub MCP tool pointers name where those tools actually live. The README records the current hook test counts. ROUTER.md names the always-loaded quick reference baseline. The leaf-manifest note separates the roots the intent router reaches from those the generated manifest reaches.
- **Switching GitHub accounts now includes the way back.** The wrong-account recovery in `finish-workflows.md` pushes. Then it switches back to the account that was active before. That is because a switch applies to every session on the machine.
- **Benchmark reports name the skill by its repository path.** Two benchmark reports gave the skill root as an absolute path on one machine. They now use `.opencode/skills/sk-git`.
- **"gitlens start review" reaches sk-git.** The two GitLens actions that `ROUTER.md` names now sit in the advisor's intent signals. So the bare action name routes to sk-git instead of sk-code.
