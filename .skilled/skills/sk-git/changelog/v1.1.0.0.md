Publishing a release through git-finish now has a guided alternative that creates the changelog, manages tags and publishes the release in one flow.

## What's New at a Glance

- **Step 6 now points to `/create:changelog --release :auto`.** Before, Step 6 (Create Release) was the only documented way to publish a release and required manual changelog composition, tag creation and `gh release create` invocation.
- **The decision matrix recommends the guided workflow.** A new "Release with changelog" row recommends `/create:changelog --release :auto`.

## Upgrade

No migration required. Existing git-finish workflows are unchanged.
