# v1.9.4.0, A Named Default Export Counts

`/doctor:git setup` read only an inline default export, so an adapter that ended with `export default plugin;` read as unregistered even when `plugin` wired the advisory correctly. The check now follows the name to its declaration.

> Spec folder: `specs/sk-git/033-git-setup-customization/011-remaining-limits` (Level 1)

&nbsp;

## What's New at a Glance

- **`export default plugin;` counts.** The check finds `plugin` at the top level of the file, as a function, arrow or object, and applies the same OpenCode and Pi rules to it.
- **A name that registers nothing still fails.** A declaration nested inside a function, an imported name or a function that never binds the handler reads as unregistered.

&nbsp;

## Upgrade

No migration required. Rerun `/doctor:git setup`.
