# v1.11.10.0, The Git Advisory Names the dsh Run Surface

`SKILL.md` and the README now count the DeepSeek Harness run surface among the places the git preflight advisory runs. No rule changed. The DSH adapters for the message gate and the preflight advisory moved into this skill.

> Spec folder: `specs/cli-external-orchestration/085-cli-deepseek-harness-creation`

&nbsp;

## What's New at a Glance

- **The runtime count names dsh.** Both files said seven runtimes share the advisory. They now name the seven repository runtimes and the dsh run surface.
- **The DSH Git adapters live here.** Both sit in `scripts/hooks/dsh/`, and the DSH bundle reaches them through links.
- **`/doctor:git setup` checks DSH.** It accepts `--tool dsh` and fails with a reason when the DSH git-preflight advisory link is dangling or the bundle never registers it.
