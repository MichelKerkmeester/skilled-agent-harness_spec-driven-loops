sk-git hardens its git safety layer so no gate can silently strand a push. It adds a SessionStart reconcile for the shared primary checkout and a helper that restores machine-local spec pointers after a destructive clean.

## What's New at a Glance

- **Every pre-push and commit gate emits a stable `[gate:<name>]` marker when it blocks.** The naming, remote-permission, mass-deletion, skill-root-metadata and test-suite gates name themselves and the exact fix command instead of failing with a generic message. A broken optional validator no longer exits past independent gates that run after it.
- **Blocked autosync pushes leave a durable gate record.** `git-sync.sh` captures and replays the hook output, identifies the rejecting gate and prints `AUTOSYNC BLOCKED`. It appends `blocked gate=<name> fix=<command>` to the common-dir log, so a gate rejection cannot be mistaken for a silent push race.
- **The primary checkout catches up at session start.** `git-primary-reconcile.sh` runs only in the main checkout, on the resolved live branch and with tracked files clean. It fast-forwards when behind and rebase-publishes local commits when ahead, so a session that commits directly in the primary does not leave the checkout ahead of and behind origin.
- **Reconcile never touches uncommitted work.** A dirty tracked tree, linked worktree, non-live branch, rebase conflict or pre-push gate rejection stops it safely and loudly. It ignores untracked build output, asserts that a rebase abort restores the original clean state and treats every internal failure as non-fatal so session start continues.
- **SessionStart runs the reconcile in every runtime.** It starts in the background in Claude, Codex, OpenCode and Pi, so startup is never delayed. This replaces the follower daemon that was never auto-started with a reliably wired step.
- **Machine-local spec pointers can be restored after `git clean -fdx`.** `relink-local-specs.sh` recreates the gitignored symlinks for machine-local spec folders whose real content lives outside the working tree. It is idempotent and refuses to create a link when the target is missing, so `git clean -fdx` can delete only a re-creatable pointer, never the data behind it.
- **Branch grammar, the allocator and commit rules are unchanged.** Owner-first naming and the remote-push permission model stay untouched.
- **Real mass-deletion and remote-permission violations still block.** The change only guarantees that every block is loud and logged.

## Upgrade

The reconcile and autosync loop is on by default in the main checkout. Disable the whole loop with `SYSTEM_LIVE_SYNC_DISABLED=1`, the reconcile leg alone with `SYSTEM_PRIMARY_RECONCILE_DISABLED=1` or the publish leg with `SPECKIT_AUTOSYNC=0`. The full gate map and reconcile behavior live in `references/continuous-integration.md`.
