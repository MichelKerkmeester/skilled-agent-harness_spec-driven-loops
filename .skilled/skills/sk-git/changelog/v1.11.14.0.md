# v1.11.14.0, Only Provision Is Idempotent

The sk-git skill said `worktree-naming.sh create` and `worktree-naming.sh provision` are both idempotent. Only `provision` is. Each `create` allocates the next worktree number and runs `git worktree add`, so running it twice makes two worktrees.

&nbsp;

## What's New at a Glance

- The provisioning rule names the one idempotent command.
  - `provision` skips what is already installed and built.
  - `create` makes a new numbered worktree every time.

&nbsp;

No migration required.
