# v1.8.6.0, A Commit-Id in Every Repository

The git hooks now stamp a Commit-Id in every repository that uses sk-git. The commit and push checks refuse a commit without one. An untrusted clone can no longer run its own code through the hooks.

&nbsp;

## What's New at a Glance

- **One setting decides coverage.** `git config --local skilled.commitId true|false` decides first. Without it, a repository is covered if it ships the sk-git allocator. It is also covered if it ships the spec-kit sentinel. Recent commits that already carry a Commit-Id also cover it. Only local config counts. So the setting never travels with a clone.
- **Stamping follows coverage, not the trust gate.** `prepare-commit-msg` mints through the allocator beside the hooks. That happens when the repository's own allocator is hidden or missing. So an untrusted clone is stamped like any other covered repository. A continued revert and a squash commit are stamped as well. Only a real merge is left alone.
- **A missing Commit-Id now blocks.** `commit-msg` refuses a covered message without an id. `pre-push` refuses every added non-merge commit without one. That catches a commit made with `--no-verify`. The reserved id 0000000 counts as missing at both.
- **An untrusted clone cannot plant code the hooks run.** The fallback source root now sits under `/dev/null`. So a guard library or Commit-Id allocator planted in the clone never runs.
- **Hook trust covers the repository, not a branch.** A branch checked out in a trusted checkout runs its own scripts. The same holds in one of its worktrees. So review an untrusted branch in a separate clone.

&nbsp;

## Upgrade

Update every machine that has the hooks installed. Re-run `bash .skilled/scripts/install-git-hooks.sh`. Then expect the Commit-Id check. A covered repository blocks a commit without a Commit-Id. It also blocks a push whose commits lack one. The push message prints the rebase that stamps them. A repository that should not carry ids can opt out with `git config --local skilled.commitId false`.
