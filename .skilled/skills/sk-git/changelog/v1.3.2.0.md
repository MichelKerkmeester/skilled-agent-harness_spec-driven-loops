## Documentation and Paths

This release refreshes the sk-git documentation and its resource paths.

#### Resource Paths Use Hyphen-Case <a id="c-resource-paths-use-hyphen-case"></a>

- `references/`, `assets/`, `feature-catalog/` and `manual-testing-playbook/` replaced their snake_case names with hyphen-case names.
- The move covered 66 files and 13 directories.
- Every path reference was repointed.
- This included the Smart Router's `RESOURCE_MAP`, `LOADING_LEVELS` and `DEFAULT_RESOURCE`.
- Relative cross-links, link labels and per-feature metadata also use the new names.
- Findings from `package_skill.py --check` for snake_case in `references/` and `assets/` are advisory-only.
- They are advisory-only until the repo-wide naming program flips the checker.

#### The README Explains the Work <a id="c-the-readme-explains-the-work"></a>

- `README.md` was rewritten to the create-readme canon.
- Its HOW IT WORKS section shows the skill's unique surface.
- That covers the owner-first worktree grammar, clone-wide number allocator and its lock.
- It also covers the ask-first workspace rule, launch-wrapper autosync and reaper contract.
- Deterministic commits and safety refusals appear there too.

#### Executable Surfaces Gain READMEs <a id="c-executable-surfaces-gain-readmes"></a>

- Four code READMEs were added for `.opencode/skills/sk-git/scripts/`.
- They also cover `.opencode/skills/sk-git/scripts/tests/`.
- They cover repository-root `.github/workflows/` and repository-root `.github/hooks/scripts/`.
- Each accurately documents its files, including the Copilot hook wrappers' file-writing fallback.

#### Catalogs Match Their Templates <a id="c-catalogs-match-their-templates"></a>

- Documentation for `feature-catalog` and `manual-testing-playbook` was verified.
- The check used `sk-doc`'s `create-feature-catalog` and `create-manual-testing-playbook` templates.
- Verification also used `template_rules.json`.
- The optional Root-vs-Feature rule was added for fuller scaffold alignment.

#### Review Corrects Stale Claims <a id="c-review-corrects-stale-claims"></a>

- A fresh independent review surfaced documentation claims.
- Every one was reconciled.
- Several were stale documentation claims.
- The README's worktree-lane framing marks `wt/{NNNN}-{slug}` as legacy and non-conformant, with owner-first as current.
