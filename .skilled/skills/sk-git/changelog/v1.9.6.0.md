# v1.9.6.0, The Wrapper-Session Gap Has a Troubleshooting Entry

A session started through a launch wrapper edits its own files but reads the main checkout's first-party code, so a generator run inside it can exit 0 without writing. `SKILL.md` carried that as a long known-gap paragraph. It now keeps one sentence and a link, and the worktree workflows reference gives the symptom, the cause and the action.

> Spec folder: `specs/sk-code/015-quality-agnostic-gate` (Level 2)

## What's New at a Glance

- **The symptom is searchable.** A reader who sees a generator exit cleanly without writing finds the entry by that description.
- **The action is stated.** Strict validation and metadata regeneration run on `main` after the merge.
