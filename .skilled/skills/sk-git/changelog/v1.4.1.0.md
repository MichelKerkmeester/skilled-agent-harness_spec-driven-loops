## [**1.4.1.0**] - 2026-08-04

Documentation-surface rewrite of the sk-git README against the refined standalone skill README template: purpose-first identity with a one-line pitch, an AT A GLANCE table up front, a problem-first OVERVIEW and the Human Voice Rules enforced across the body. No script behavior, branch grammar or command surface changed.

---

## What Changed

#### README rewrite

- **The README now reads as the front door of the skill.** It opens with a one-line blockquote pitch stating the delivered outcome before any tool name, then an AT A GLANCE table and a problem-first OVERVIEW, followed by the template section order through RELATED DOCUMENTS. The legacy FEATURES and STRUCTURE sections folded into the template model. The REQUIREMENTS table moved to QUICK START. The capability table became the Git Workspace Safety Layer inside OVERVIEW.
- **The Human Voice Rules now hold across the body.** The em dash in the preflight advisory row at line 102 and every other HVR violation were removed. The body carries zero em dashes and zero semicolons, with no Oxford commas either.
- **The version field moved from `1.4.0.0` to `1.4.1.0`.** The changelog folder previously topped out at `v1.3.2.0.md`, so the frontmatter version had no matching entry. This entry closes that gap.
- **The readme validator reports zero issues.** `validate_document.py --type readme` passes on the rewritten file. Every relative link resolves against the skill root.

## Not Changed

- No `SKILL.md` content changed. The runtime instruction surface stays untouched, along with the smart router and the rule set.
- No script, allocator, validator or hook behavior changed.
- No branch grammar, commit rule or workspace rule changed.

None. Documentation-only release. The README text, version field and changelog folder are the only surfaces touched.
