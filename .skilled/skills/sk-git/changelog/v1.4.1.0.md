The sk-git README now gives the skill a purpose-first identity. It does this through the refined standalone skill README template. This release is documentation only. It touched only the README text, the version field and the changelog folder.

## What's New at a Glance

- **The README now follows the standalone skill template as the skill's front door.** Its one-line blockquote pitch states the outcome before any tool name. An AT A GLANCE table follows. So does a problem-first OVERVIEW. The template section order continues through RELATED DOCUMENTS. FEATURES and STRUCTURE are folded into it. The REQUIREMENTS table moved to QUICK START. The capability table became the Git Workspace Safety Layer inside OVERVIEW.
- **Human Voice Rules now hold across the README body.** The em dash in the preflight advisory row was removed. So was every other HVR violation. The body has no em dashes, semicolons or Oxford commas.
- **The version field now matches its changelog entry.** The frontmatter version moved from `1.4.0.0` to `1.4.1.0`. That closes the gap. The changelog folder had topped out at `v1.3.2.0.md`.
- **The runtime instruction surface stayed untouched.** No `SKILL.md` content changed. The smart router and rule set also stayed untouched. Script, allocator, validator and hook behavior did not change. Neither did branch grammar, commit rule, workspace rule or command surface.

## Upgrade

No migration required.
