# v1.11.11.0, A new worktree can commit again

A worktree you make with `worktree-naming.sh create` or fix with `provision` can commit again. Provisioning used to turn every private `local-*` command into an absolute link, and the mirror gate then blocked every commit there.

> Spec folder: `specs/sk-git/038-provision-private-command-links`

&nbsp;

## What's New at a Glance

- **Private commands keep their form.** A command file is copied, a relative mirror link keeps its link text and a private folder stays one shared link, the same way the primary checkout holds them.
- **An edit to a copied file stays in its worktree.** Only a shared folder still reaches every worktree at once.

&nbsp;

## Upgrade

A worktree provisioned before this release still holds absolute links. Remove its private `local-*` entries and run `worktree-naming.sh provision` again.
