# sk-git v1.6.0.0

Every commit gets a trailer paragraph.

- A contiguous trailer paragraph is attached to every commit.
- That makes commit history easier to cite and search.

Commits carry packet and identifier references.

- Packet work carries a `Spec:` reference.
- Every commit carries a `Commit-Id:` with a stable repository-wide ordinal.

&nbsp;

## Why This Release

Before this release, a commit was reachable only by a hash nobody remembers.

- You could also read `git log`.
- Finding the commits behind a packet meant searching by eye.
- A single commit could not be cited by a short ordinal.

## Commit Trailers

Trailers carry the packet and commit references on every commit.

#### Packet and Commit References <a id="c-packet-and-commit-references"></a>

- Each commit gets a contiguous trailer paragraph.
- Packet work carries `Spec: <track>/<packet>[/<phase>...]`.
- Every commit carries `Commit-Id: NNNNNNN`.
- That is a seven-digit repository-wide ordinal, minted once under a lock.
- `Refs:` is for external links only.
- So packet references now live in `Spec:` instead.

#### Hooks Handle Commit Cases <a id="c-hooks-handle-commit-cases"></a>

- `prepare-commit-msg` writes a blank line and the trailer paragraph when a commit has a body.
- It keeps the id on amend.
- That is because the amended commit already owns it.
- It re-mints on cherry-pick.
- That is because the picked commit keeps its own.
- In a repository without the allocator, the stamper exits silently.
- `commit-msg` whitelists `Spec:` and `Commit-Id:`.
- It refuses an id that is not exactly seven digits.
- It refuses an id that already belongs to another commit.
- Its duplicate scan excludes `HEAD`.
- So an amend never collides with itself.

&nbsp;

## Commit Discovery

Commit discovery tools find commits by their trailers and ordinals.

#### Ordinals Support Branch Work <a id="c-ordinals-support-branch-work"></a>

- `scripts/commit-id-naming.sh` allocates the next value under a lock.
- It uses a history-derived high-water mark.
- It exposes `allocate`, `next`, `scan-max`, `validate` and `rebuild-highwater`.
- `scripts/stamp-branch.sh` takes a branch and a base.
- It stamps an ordinal onto each unique commit.
- So a rebase does not leave the branch's commits unidentified.

#### Trailer Queries Find Commits <a id="c-trailer-queries-find-commits"></a>

- `git log -E --grep='^Spec: sk-git/028'` lists a packet's commits.
- `git log --fixed-strings --grep='Commit-Id: 0009113'` finds the commit that owns an ordinal.
- `git log --format='%(trailers:key=Commit-Id,valueonly)'` lists every stamped id.

#### Documentation Covers Commit Identity <a id="c-documentation-covers-commit-identity"></a>

- The feature catalog carries a "Commit Identity And Search" subsection.
- The manual testing playbook carries a scenario that finds commits by packet and identifier.

## Git Conventions

The existing commit rules stay untouched.

#### Existing Rules Are Untouched <a id="c-existing-rules-are-untouched"></a>

- The Conventional Commit subject and body grammar are untouched.
- So are the type and scope priority orders and the artifact-filtering rules.
- The numbered-worktree grammar and the per-namespace allocator are untouched.
- So is every pre-push and pre-commit gate.

&nbsp;

## Upgrade Notes

New commits pick up the trailer paragraph automatically once the hooks are installed.

#### Before You Start <a id="c-before-you-start"></a>

1. Install the updated hooks.
