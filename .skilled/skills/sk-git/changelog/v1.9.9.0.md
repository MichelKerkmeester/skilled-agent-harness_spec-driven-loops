# v1.9.9.0, Hook Paths You Can Follow From the Repository Root

The hooks README named the plugin target and the shared rule-check module with paths that only made sense from one folder. Both now read as repository paths, so you can follow either one from wherever you are working.

> Spec folder: `specs/sk-doc/070-repo-doc-debt/005-reference-and-coverage-fixes` (Level 2)

&nbsp;

## What's New at a Glance

- **The plugin target reads as a repository path.** The tree diagram writes the symlink target as it appears from the repository root, in place of a stack of parent folders.
- **The rule-check import names its base.** The shared module is given by its repository path, with a note that the specifier is relative to the plugins folder.

&nbsp;

## Upgrade

No action is needed. These are documentation changes, so nothing about how the skill runs is different.
