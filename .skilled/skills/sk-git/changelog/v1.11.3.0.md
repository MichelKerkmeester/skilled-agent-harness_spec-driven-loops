# v1.11.3.0, fsmonitor Daemon Requests Reach the Git Skill

The fsmonitor daemon reaper belongs to sk-git, but sk-git's routing metadata never named the daemons. A request such as "fsmonitor daemon reaper" or "end idle fsmonitor daemons" got no recommendation, and only prompts that also said "git" or "push" found the skill.

> Spec folder: `specs/sk-git/035-fsmonitor-daemon-and-worktree-relocation-regression` (Level 2)

&nbsp;

## What's New at a Glance

- **fsmonitor daemon requests reach sk-git.** The skill now declares `fsmonitor daemon`, `fsmonitor daemons` and `fsmonitor daemon reaper`. "fsmonitor daemon reaper" routes at 0.92, and "end idle fsmonitor daemons" and "stop the fsmonitor daemons piling up" at 0.82.
