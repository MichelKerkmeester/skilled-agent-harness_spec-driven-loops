# v1.9.3.0, The Adapter Check Reads the Real Binding

`/doctor:git setup` matched the OpenCode and Pi adapters as text, so a handler that was defined but never registered still passed. The check now reads what the adapter's default export actually registers.

> Spec folder: `specs/sk-git/033-git-setup-customization/010-open-ends-cleanup` (Level 1)

&nbsp;

## What's New at a Glance

- **OpenCode counts only a returned hook.** The adapter passes only when `tool.execute.before` sits in the object its default export returns.
- **Pi counts only a registered handler.** The extension passes only when its default export calls `.on('tool_call', handler)` on the API it receives.
- **Strings and comments no longer count.** The check skips strings, comments and regular expressions when it reads the source, and it still never runs the adapter.

&nbsp;

## Upgrade

No migration required. Rerun `/doctor:git setup`. An adapter that exports its plugin as a separate `export default plugin;` line reads as unregistered, so return the hooks from the default export directly.
