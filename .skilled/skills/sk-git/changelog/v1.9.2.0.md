# v1.9.2.0, The Setup Check Holds Outside This Checkout

A second review ran `/doctor:git setup` against repositories other than the one it ships in and found verdicts that were wrong there. Each check now reports what is true for the repository it inspects.

> Spec folder: `specs/sk-git/033-git-setup-customization/009-second-review-remediation` (Level 2)

&nbsp;

## What's New at a Glance

- **Clones get the right trust verdict.** A clone whose hooks link into its own tree passes the trust row instead of being told its scripts do not run.
- **The rules check reads the right file.** It validates the repository's own `hard-rules.json`, which the advisory reads, and shows DEGRADED when that file is missing.
- **A registration must be able to run.** An AI tool hook counts only when the script or import it names exists, and Claude's `"*"` matcher counts as match-all.
- **Repairs work in any folder.** Every repair path is quoted, so a folder name with a space no longer breaks the command.
- **Hermes is the seventh runtime.** `--tool=hermes` is accepted and checks the Hermes adapter, so a healthy Hermes install reaches OK.

&nbsp;

## Upgrade

No migration required. Rerun `/doctor:git setup`, and in Hermes pass `--tool=hermes`.
