# v1.11.5.0, Long Prose Lines Are Now Short Sentences and Lists

Eleven ALWAYS rules each carried a whole procedure in one sentence. Each now opens with the rule. Then it lists the steps you take. Two paragraphs in `HOW IT WORKS` also read a sentence at a time. So do the owned-keyword list and the manual testing note.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/010-prose-clarity-pass` (Level 2)

&nbsp;

## What's New at a Glance

- **Each long ALWAYS rule is a lead sentence plus bullets.** These rules cover the numbered-worktree grammar and the `Spec:` trailer. They also cover worktree provisioning and the autostash warning. Then come the detached-HEAD reconcile and autosync. The reaper, the GitKraken rules and the release rules are there too. Each states the rule once. Then it lists what you do.
- **The owned-keyword list wraps.** Every phrase is still there. The list now runs over three lines. It used to be one unbroken line.
- **Two HOW IT WORKS paragraphs read a sentence at a time.** The launch-wrapper comparison split into separate sentences. So did the live-branch autosync note. Both keep their links and their switches.
- **The manual testing note split in two.** The playbook layout is one paragraph now. The validate command is another.

&nbsp;

## Upgrade

No action is needed. Every command, path, flag, hook name and threshold is the same. The skill routes and behaves exactly as it did.
