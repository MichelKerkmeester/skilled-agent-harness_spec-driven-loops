# v1.11.5.0, Long Prose Lines Are Now Short Sentences and Lists

Eleven ALWAYS rules each carried a whole procedure in one sentence. Each now opens with the rule, then lists the steps you take. Two paragraphs in `HOW IT WORKS`, the owned-keyword list and the manual testing note also read a sentence at a time.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/010-prose-clarity-pass` (Level 2)

&nbsp;

## What's New at a Glance

- **Each long ALWAYS rule is a lead sentence plus bullets.** The numbered-worktree grammar, the `Spec:` trailer, worktree provisioning, the autostash warning, the detached-HEAD reconcile, autosync, the reaper and the GitKraken and release rules each state the rule once and then list what you do.
- **The owned-keyword list wraps.** Every phrase is still there and the list now runs over three lines instead of one unbroken line.
- **Two HOW IT WORKS paragraphs read a sentence at a time.** The launch-wrapper comparison and the live-branch autosync note split into separate sentences, and both keep their links and their switches.
- **The manual testing note split in two.** The playbook layout and the validate command are separate paragraphs now.

&nbsp;

## Upgrade

No action is needed. Every command, path, flag, hook name and threshold is the same, and the skill routes and behaves exactly as it did.
