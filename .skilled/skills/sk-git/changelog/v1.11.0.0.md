# v1.11.0.0, Finished Numbered Worktrees Clean Themselves Up

Numbered worktrees stayed on disk after their branch was merged. They stayed until someone removed them by hand. Each one kept an fsmonitor daemon alive. This release lets the worktree reaper remove a numbered worktree. It does so once nothing in it is worth keeping. The sweep runs at session start. The release also tightens the fsmonitor reaper. It puts a time limit on every git call in the commit and push hooks that reads the index.

&nbsp;

## What's New at a Glance

- **The worktree reaper removes finished numbered worktrees.** `worktree-reaper.sh --numbered` removes a numbered worktree only when its branch is merged into the live branch. It also needs no uncommitted, untracked or unrecoverable ignored files. It needs no process working in it. It needs no activity for 48 hours. Anything else is kept with a one-line reason. `--dry-run` shows the verdicts without touching anything.
- **Each session start runs that sweep in the background.** The worktree guard starts a detached `--numbered` sweep. It does this at most once every 6 hours. `SPECKIT_WORKTREE_AUTOREAP=0` stops only the sweep. Disabling the guard stops both.
- **The doctor counts numbered worktrees.** `/doctor:git setup` reports how many numbered worktrees exist. It also reports how many the sweep could remove. That information never changes the verdict.
- **The fsmonitor reaper checks before it ends a daemon.** It rechecks a daemon's start time right before ending it. It stops only a daemon that watches one worktree. It rereads the worktree list on every run. `--orphans` reports and ends daemons whose worktree folder is gone.
- **Hook git calls can no longer hang.** Every git call in the commit and push hooks that reads the index now runs through a shared helper. That helper has a 20 second limit (`SPECKIT_GIT_TIMEOUT`). A call that runs out blocks with `BLOCKED [gate:git-timeout]`. It does not wait forever. Creating a worktree from the launcher gets 60 seconds (`SPECKIT_WORKTREE_ADD_TIMEOUT`).

&nbsp;

## Upgrade

No migration required. Run `bash .skilled/bin/worktree-reaper.sh --numbered --dry-run` to see what the sweep would remove. A squash-merged branch never counts as merged. So its worktree is kept. Any worktree holding ignored files outside the regenerable list is kept too.
