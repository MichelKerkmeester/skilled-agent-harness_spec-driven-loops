# v1.1.5.0, A Vendored Tree Can Refuse Unowned Writes

An edit made straight in a vendored Skilled tree was lost at the next re-pin. Nothing stopped the edit when it was made. A project can now ask the overlay engine to refuse it. The setting is off by default, and Skilled's own repository keeps it off.

> Spec folder: `specs/system-skilled-doctor/001-skill-and-overlay-build/008-overlay-first-write-checks`

&nbsp;

## What's New at a Glance

- **The guard can refuse a write no overlay owns.** A manifest sets `"strictWrites": true`. A new file or an unowned upstream file under a vendored root then prints `refuse:` and exits 1. The line names the overlay path to create or the adopt command to run.
- **`/doctor:overlay apply --adopt <path>` makes a path an overlay.** It copies the file or folder into the overlay folder and adds one manifest entry. Every earlier byte of the manifest stays as it was. It cannot be combined with `--capture`.
- **Adopt refuses what it should not own.** A generated path exits 2. So does a token-named file. So does an overlap with an existing overlay. A copy that leaves the overlay folder through a link is refused too. Nothing is written.
- **Generated paths stay writable.** A `generated` list of globs in the manifest names paths any write may touch. `*` matches inside one segment and `**` across segments.
- **A commit check catches what the guard did not see.** `overlay-engine.cjs pre-commit` exits 1 on a staged change under a vendored root that no overlay owns. A commit that moves the pin passes.
- **A re-pin names changed root files.** Files listed in `repin.rootFiles` get one `root-file` line each when upstream changed them. The line says whether an overlay owns the file.
- **The skill converter copies its source on Node 26.** A strict copy into the folder it had just made threw `ERR_FS_CP_EEXIST`. Eight tests failed. It now copies each entry, and all 69 pass.

&nbsp;

## Upgrade

No migration required. To turn the checks on in a vendoring project, add `"strictWrites": true` to its overlay manifest.
