# v1.3.0.0, Edits Go to the Overlay

An agent can no longer lose its work by editing a vendored file an overlay owns. The `overlay-guard` hook refuses that edit before it is written and names the overlay file to change instead.

> Spec folder: `specs/system-skilled-doctor/001-skill-and-overlay-build/004-guard-hook`

## What's New at a Glance

- **Owned files are guarded.** An edit to a file an overlay owns is refused, with the overlay file to edit named. <!-- section: Guard Hook -->
- **Other repositories notice nothing.** Without an overlay folder the hook allows every edit after two file checks. <!-- section: Guard Hook -->
- **Five runtimes carry it.** Claude, Codex, Cursor, Devin and Pi each register the same hook. <!-- section: Guard Hook -->

## Guard Hook

#### Refuse, Never Apply

The hook only asks the engine whether a path is owned. It never applies or captures an overlay, so a refused edit leaves the tree exactly as it was. An engine error or timeout allows the edit with a one-line note.

---

## Upgrade

1. **Guard Hook:** nothing to do in a repository without overlays. To switch the hook off, set `SYSTEM_OVERLAY_GUARD_DISABLED=1`.

The hook itself has no separate changelog. Its README is `.skilled/hooks/overlay-guard/README.md`.
