# v1.1.7.0, Hook Checks Read the Command That Runs

The hook check used to pass any hook file that named the advisor script. A hook that only echoed the path still passed. It now passes only a command that starts node on that script. An AGENTS.md embed whose write fails now puts the tree back by itself. `/doctor:setup` also shows hook health without a debug flag.

&nbsp;

## What's New at a Glance

- The hook-wiring check reads the command a shell would run.
  - `echo node <script>` now prints `hook-missing claude .claude/settings.json`.
  - A launch through `env` or `bash -c` still reads as wired.
  - So does one after `nohup`, `time` or `exec`.
- `/doctor:symlink check` runs the hook-wiring check too.
  - A missing hook makes the route end `STATUS=WARN`.
- An embed whose write fails restores the backup and exits 3.
  - It prints the `backup:` and `undo:` lines.
  - It prints them even when the restore fails.
  - A backup copy with the wrong hash is never restored.
- The embed refuses a linked `REPO RULES.md` or Cursor mirror.
  - A write through the link would change a file this repository does not own.
  - A stray line outside the block now fails the proof.
- The Codex approval check names the repair for an absent entry.
  - It says to copy the advisor entry into `.codex/hooks.json`.
  - Then you approve it in `/hooks`.
  - A flag left where a value belongs is refused.
- The `/doctor:setup` advisor leg shows hook health on every machine.
  - It adds the degraded share and the newest record time.
  - With no record it says no prompt hook has written one.
  - It no longer names the debug variable.
- The AGENTS.md check counts only copies it really checked.
  - A10 lists report-only copies and a missing pointer apart.
  - A link where no file belongs is a finding.
  - A11 names a router row of the wrong width.
- The embedder route leaves a remote Ollama server alone.
  - It starts and pulls only on `127.0.0.1`, `localhost` or `::1`.
  - It passes that address to `ollama`.
- Four doctor routes answer more plain requests.
  - Each gained intent phrases.
  - They are `/doctor:speckit`, `/doctor:setup`, `/doctor:install` and `/doctor:update`.

&nbsp;

## Upgrade

No migration required. A hook entry that only names the advisor script now reads as missing. Run `/doctor:runtime-mirrors` in a Skilled checkout. Run `/doctor:symlink check` in a linked project.
