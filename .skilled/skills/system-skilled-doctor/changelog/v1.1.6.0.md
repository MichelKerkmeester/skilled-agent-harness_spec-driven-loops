# v1.1.6.0, The Overlay Engine Cleans Up After Itself

A project turned strict writes on and re-pinned. It reported three bugs and three gaps. Each one left work the operator had to finish by hand. This release closes all six.

> Spec folder: `specs/system-skilled-doctor/001-skill-and-overlay-build/009-overlay-write-checks-follow-up`

&nbsp;

## What's New at a Glance

- **A dead run's lock is taken over.** The lock line carries `pid` and `host`. `apply` takes over when the owner has ended on this host. It prints `note: took over the overlay lock of a run that has ended`. A live owner, another host or a lock with no `pid` still refuses.
- **The engine retargets its own layout links.** `sync-state.json` records the target of each link it made under `links`. A manifest that moves that target now updates its own link in place. A link the state does not record is refused and named.
- **A dropped appended item is removed.** `sync-state.json` records each added item under `items`. An item the overlay drops goes, while it still equals what the engine wrote. An item edited since is refused. The apply names it.
- **`status` prints a `LAYOUT` line for a source off its layout path.** The line names the overlay, the source and the path it belongs at. `/doctor:overlay apply --relayout` moves each one there. It backs up every path it moves first, under relayout-runs in the overlay folder.
- **A changed root file fails `status`.** Upstream changed a file named in `repin.rootFiles` after the overlay was pinned. `status` prints a `STALE    root-file` line and then fails.
- **`status --audit` reports what a re-pin would refuse.** It prints one `AUDIT` line per unowned vendored path. It reports a path that differs, one that is missing or one upstream never tracked. Any finding fails the status.
- **OpenCode gets the seventh guard adapter.** `.skilled/hooks/overlay-guard/opencode/overlay-guard.js` is a link back to the plugin OpenCode loads. It refuses an unowned write in `tool.execute.before` and throws the engine's `refuse:` line.
- **Three strict-write edges are corrected.** `**/` in a `generated` glob matches whole segments only. A path under a `repin.exclude` folder is not judged. The commit check reads CRLF as LF.
- **A deep review found three P1 defects in the relayout.** One left a link dangling after a move. One copied a protected file into the backup. One left a folder half moved when it failed. Each fix carries a test.

&nbsp;

## Upgrade

No migration required. The first `apply` after this release records `links` and `items`. A `generated` glob that relied on the old `**/` matching part of a name stops matching.
