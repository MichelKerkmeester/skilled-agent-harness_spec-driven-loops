# v1.0.0.0, Skilled in Your Project, Kept Current

The first `system-skilled-doctor` release gives the doctor commands about putting Skilled into a project one owner. It also adds `/doctor:overlay`, so a project that vendors Skilled keeps its own changes when it moves to a newer upstream commit.

> Spec folder: `specs/system-skilled-doctor/001-skill-and-overlay-build`

## What's New at a Glance

- **One skill owns eleven doctor commands.** Install, symlink, update, agents-md, runtime-mirrors, env, setup, helper, speckit, mcp and overlay credit `system-skilled-doctor`, and every command name works as before. <!-- section: Doctor Commands -->
- **Vendored copies keep their own changes.** `/doctor:overlay status` reports each overlay that is out of sync and its fix, and `apply` puts the overlays back. <!-- section: Overlays -->
- **Re-pins come with a rollback.** `/doctor:overlay repin` shows a staged result first, backs up every path it will touch and can undo a failed run byte for byte. <!-- section: Overlays -->
- **Edits go to the overlay.** The `overlay-guard` hook refuses an agent's edit to a file an overlay owns and names the overlay file to change instead. <!-- section: Guard Hook -->
- **Each request reaches the right place.** A request that names one doctor job reaches that command, and a request about Skilled in a project or a vendored copy reaches this skill. <!-- section: Routing -->

## Doctor Commands

#### One Owner for Skilled Integration

Ten existing commands each changed one line, their `skill_agent` tag. Nine came from `system-spec-kit` and `/doctor:agents-md` came from `sk-doc`. The scripts they call, such as the trigger-index lookup and `ENV-REFERENCE.md`, stay in `system-spec-kit`.

&nbsp;

#### Domain Commands Stay Put

`/doctor:sk-code`, `/doctor:ci`, `/doctor:git`, `/doctor:sk-skill`, `/doctor:skill-advisor` and `/doctor:deep-loop` stay with the skill whose own checks they run.

---

## Overlays

#### One Engine for Status, Apply and Re-Pin

Status and apply read the same record of what was last applied, so a changed overlay applies over its earlier copy without a restore script. The engine owns its lock, and the operations in one JSON overlay apply in order. A project names its overlay folder in `.skilled-overlays.json`, and `skilled-overlays/` is the default.

&nbsp;

#### Re-Pin to a Newer Commit

`repin --upstream <checkout> --to <commit>` copies the `.skilled` paths upstream changed and each runtime folder whole, removes what upstream deleted, sets the pin and applies the overlays twice. A run refuses before any write when a file no overlay owns differs from the pinned commit, and names that file. Each run keeps its backup in `<overlayDir>/repin-runs/<run-id>/`, and `--rollback` restores it.

&nbsp;

#### Secret Files Stay Unread

A `.env` file is never read, and a re-pin refuses when upstream ships one. A file whose name contains `token` is read only where the manifest names its exact path, through `protectedPaths` for an entry that walks a folder.

---

## Guard Hook

#### Refuse, Never Apply

Claude, Codex, Cursor, Devin and Pi register the same `overlay-guard` hook. It only asks the engine whether a path is owned, so a refused edit leaves the tree as it was. In a repository without an overlay folder it allows every edit, and an engine error or timeout allows the edit with a one-line note.

---

## Routing

#### Commands Win Their Own Requests

The regenerated command bridges credit each command to this skill, and each route carries the phrasings people use. The skill's own routing words describe Skilled in a project and vendored copies, so they never outrank a command on its own request. The word "doctor" on its own reaches this skill.

---

## Upgrade

1. **Doctor Commands:** nothing to do. A project that pins advisor results for the moved commands should expect `system-skilled-doctor` where it saw `system-spec-kit` or `sk-doc`.
2. **Overlays:** a project with overlays adds `.skilled-overlays.json` unless its folder is `skilled-overlays/`. A directory entry that walks a token-named file it needs lists that file in `protectedPaths`. Before a re-pin, list any folder upstream ships as a link in `repin.exclude`.
3. **Guard Hook:** nothing to do in a repository without overlays. Set `SYSTEM_OVERLAY_GUARD_DISABLED=1` to switch the hook off.

`/doctor:overlay` and the `overlay-guard` hook have no separate changelogs. The hook's README is `.skilled/hooks/overlay-guard/README.md`.
