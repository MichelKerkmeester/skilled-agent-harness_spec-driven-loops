# v1.1.0.0, Vendored Copies Keep Their Own Changes

A project that vendors Skilled can now keep its own changes across a new copy without private scripts. `/doctor:overlay status` reports every overlay that is out of sync and its fix, and `/doctor:overlay apply` puts the overlays back.

> Spec folder: `specs/system-skilled-doctor/001-skill-and-overlay-build/002-overlay-engine`

## What's New at a Glance

- **One engine checks and applies overlays.** Both read the same record of what was last applied, so a changed overlay applies without a restore script. <!-- section: Overlay Engine -->
- **Your project names its overlay folder.** `.skilled-overlays.json` at the tree root sets it, and `skilled-overlays/` is the default. <!-- section: Overlay Engine -->
- **The engine owns its lock.** A second apply refuses and names the run that holds the lock. <!-- section: Overlay Engine -->
- **Secret files stay unread.** A token-named file is read only where the manifest names its exact path. <!-- section: Safety -->
- **The skill explains each state.** A new reference says what each sync state means and what resolves it. <!-- section: Skill -->

## Overlay Engine

#### Apply and Check Agree

Apply and check now read the same hashes, so an overlay whose source changed applies over the copy it applied last time. A file listed both as replaced and as retained by a skill-root overlay is now checked and guarded like any other output.

&nbsp;

#### Ordered JSON Edits

The operations in one json-entry overlay apply in order, so a key set on an item another operation adds in the same set now succeeds.

---

## Safety

#### Exact Paths for Secret Files

A `.env` file is never read. A file whose name contains `token` is read only when a `file` entry names it, or when a directory entry lists its exact path in `protectedPaths`.

---

## Skill

#### The Overlay Reference

`references/overlays.md` holds the sync states, the overlay folder setting and what the engine refuses. The router loads it for any request about a vendored copy's overlays.

---

## Upgrade

1. **Overlay Engine:** a project with overlays adds `.skilled-overlays.json` naming its folder, unless the folder is `skilled-overlays/`.
2. **Safety:** a directory entry that walks a token-named file it needs lists that file in `protectedPaths`.

`/doctor:overlay` itself has no separate changelog. Its router and workflows ship with this release.
