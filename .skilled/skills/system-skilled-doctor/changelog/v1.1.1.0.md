# v1.1.1.0, One Guide and One Link Run

Setting Skilled up in your own project now has one guide, `SETUP.md`, and linking a new project takes one run. Every step in the guide was run before it was written.

> Spec folder: `specs/system-skilled-doctor/001-skill-and-overlay-build/006-setup-guide`
> Spec folder: `specs/system-skilled-doctor/002-symlink-first-link`

&nbsp;

## What's New at a Glance

- **One setup guide.** `SETUP.md` helps you choose between linking and copying, then walks through either one, from the first command to undo, with a health table and a troubleshooting table.
- **Copying starts from nothing.** The guide shows the first copy, the manifest, a first `file` and `directory` overlay, a live edit, a re-pin and a rollback.
- **One link run is enough.** The first `/doctor:symlink link` on a new project used to leave `.claude` and `.opencode` half linked until a second run. It now links every entry at once.
- **Git status stays clean.** The relative links inside a runtime folder now get an ignore line like every other link.

&nbsp;

## Upgrade

A project linked before this release may list relative links such as `.claude/skills` in `git status`. Add each listed path to `.git/info/exclude`, or undo that link run with `/doctor:symlink unlink` and link again.
