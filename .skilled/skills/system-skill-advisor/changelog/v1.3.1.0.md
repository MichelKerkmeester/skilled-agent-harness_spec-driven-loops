# v1.3.1.0, Named MCPs and Browser Tests Keep Their Owners

Two scorer rules sent prompts to the wrong skill. Both now hand the prompt to the skill that owns it.

&nbsp;

## What's New at a Glance

- A prompt that names an MCP goes to that MCP's owner.
  - "aside mcp through Code Mode" used to rank `mcp-code-mode` first.
  - The Code Mode bonus now skips a prompt that names another server as `<name> mcp`.
  - So that prompt goes to `mcp-browser-use`.
- A browser automation test goes to `sk-code`.
  - "fix the flaky browser automation test" used to go to the browser hub.
  - A new `automation test` anchor hands test code back to the code skill.
- Browser automation requests still route to `mcp-browser-use`.
- The eval baseline moved by two prompts on the full corpus, 159 to 161. Nothing else moved.

&nbsp;

## Upgrade

No migration required.
