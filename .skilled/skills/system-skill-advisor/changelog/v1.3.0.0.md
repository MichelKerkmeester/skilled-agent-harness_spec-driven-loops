# v1.3.0.0, background vector refresh

The daemon now keeps the skill and command vectors current without putting prompt embedding on the default recommendation path.

&nbsp;

## What's New at a Glance

- After startup IPC is ready and after each watcher reindex, the daemon starts one shared background refresh. It checks coverage locally and returns when the coverage check is complete. When coverage is incomplete, it probes Ollama once for 500 ms and embeds only missing or stale vectors. Coverage requires at least one embeddable skill, so a command-only index can still reach the probe when all its command vectors are current. A failed embed keeps the old vector. Set `SYSTEM_SKILL_ADVISOR_EMBED_REFRESH=off` to disable refreshes.
- Embeddable skills have a non-empty `SKILL.md` description. Embeddable command rows come from generated command bridges, have non-empty `embeddingText` and use an enabled TypeScript runtime id.
- At the default semantic lane weight of `0`, recommendation prompts are not embedded. If the lane is enabled, it scores only with current vectors for every embeddable skill and command. Incomplete coverage reports `incomplete_skill_vectors`. A failed prompt embed marks the lane degraded and removes it from that call's live confidence total.
- `advisor_status --include-semantic-health` reports skill and command `vectorCoverage` counts for current, total, stale and missing rows, along with `coverageComplete`. This optional health check probes Ollama even when the semantic lane weight is `0`.
- The launcher forwards `OLLAMA_BASE_URL` and `OLLAMA_REQUEST_TIMEOUT_MS` along with `SYSTEM_SKILL_ADVISOR_EMBED_REFRESH`. It always sets `SYSTEM_SKILL_ADVISOR_DB_DIR` for the daemon child. The daemon starts its heartbeat near the top of server startup. A server with no heartbeat five minutes after spawn is stale.
- Doctor setup and embedder checks pass when coverage is complete. They report `DEGRADED` when Ollama is unavailable. Lane weight `0` passes the checks. Update apply, overlay apply, overlay repin and symlink link report vector coverage. `/create:command` regenerates the generated command bridges.

&nbsp;

## How It Was Checked

The real-embedding ablation used the 196-row corpus and seeded skill and command vectors as production does. Two runs gave identical results. The lane at `0.05` scored 156 correct. The lane disabled scored 161. The runs had 7 flips and no new fire for a gold `none` row. The default stays at `0`. The opt-in ablation test asserts that the registry default follows this pass bar.

&nbsp;

## Upgrade Notes

The semantic lane remains off by default. Background indexing refreshes run regardless of its live weight. If Ollama is unavailable, a refresh leaves old vectors in place when an embed fails. Stale vectors are excluded from the current count for semantic scoring.
