# v2.0.1.0, settings that work as documented

Two fresh reviews of the v2.0.0.0 work found settings that did nothing. Some were never read. Others were read but never reached the process that scores. This release forwards the ones that matter and deletes the rest. The Python fallback now skips excluded skills the way the native scorer does. Default routing does not change.

&nbsp;

## What's New at a Glance

- `SPECKIT_ADVISOR_FEEDBACK_CALIBRATION_PATH` and `SPECKIT_ADVISOR_ROUTE_EXCLUSIONS_DIR` now reach the daemon. The launcher forwards both. So does the Python bridge to the native scorer.
- The Python fallback drops every skill on the route-exclusion list. It reads the same folder and files as the native loader. It drops a skill that delegation would add back as well.
- The graph compiler now honors `SPECKIT_ADVISOR_ROUTE_EXCLUSIONS_DIR` too. It shares one loader with the fallback.
- `SPECKIT_ADVISOR_CALIBRATION_OVERRIDE_JSON` is gone. Nothing ever passed it to the daemon.
- Query-class routing and the BM25 query-length switch are gone. Their flags were never forwarded, so neither code path could run.
- The four hook alert thresholds are gone. Only a test read `SPECKIT_ADVISOR_HOOK_CACHE_HIT_P95_WARN_MS`, its page twin or the two fail-open rates.
- The Python fallback no longer boosts the retired memory database words. One prompt about them now routes to `mcp-code-mode`.
- `score-outcome-rerank.mjs` is deleted. It imported a module removed in v2.0.0.0.
- The doctor contract test now runs the lane cleanup commands exactly as `/doctor:update apply` writes them. It covers no answer, `delete` and `keep`. Each run must change nothing in a clean fixture.

&nbsp;

## How It Was Checked

The advisor suite passed 2,449 with 4 skipped. That is one fewer than before because the threshold test went with its code. The Python suite passed 125 of 125. Each new test failed when its fix was undone. The ratchets held with no baseline recapture.

&nbsp;

## Upgrade

Remove any of the deleted settings from your env file. They changed nothing, so routing stays the same.
