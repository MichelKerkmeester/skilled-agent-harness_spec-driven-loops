# v0.7.0.0, Skill Advisor CLI Front Door

This release lands the system-skill-advisor portion of the 028 MCP-to-CLI dual-stack program.

- The `system_skill_advisor` daemon gains a daemon-backed CLI front door.
- The daemon now has a CLI front door for all nine tools.
- The command is `node .opencode/bin/skill-advisor.cjs`.
- It exposes all nine tools over the same daemon the MCP registration uses.

The advisor surface includes mutations.

- So CLI calls default to untrusted.
- Mutation tools require an explicit grant.

Hooks and runtimes gain alternate CLI routes.

- Warm-only CLI fallbacks give the Claude Code and Codex advisor hooks another route.
- The OpenCode plugin also gains a CLI fallback route.
- Runtime permission allowlists let runtimes invoke the CLI without prompting.

&nbsp;

## Why This Release

The advisor surface includes mutations. So CLI calls default to untrusted. Mutation tools require an explicit grant.

- The program-wide phases sit under the same parent.

## CLI Access

The CLI front door exposes all nine tools over the same daemon and IPC socket.

#### Nine Tools on the Daemon <a id="c-nine-tools-on-the-daemon"></a>

- `node .opencode/bin/skill-advisor.cjs` exposes the four `advisor_*` tools as CLI commands.
- It also exposes four `skill_graph_*` tools and the internal propagation tool.
- They run over the same daemon and IPC socket used by the MCP registration.
- The registration is unchanged.
- `list-tools --format text` enumerates them offline.
- Every other command validates its arguments against the existing schemas.
- It speaks JSON-RPC to the daemon.

#### Shared CLI Results <a id="c-shared-cli-results"></a>

- The CLI shares its exit taxonomy with the sibling `spec-memory` and `code-index` CLIs.
- `0` means success.
- `1` means runtime error.
- `64` means usage or schema error.
- `69` means protocol or `dist` mismatch.
- `75` means retryable daemon error.
- Natural exit waits for output writes to drain.
- That avoids the 64KB pipe-truncation hazard shared across the three CLIs.

#### Warm-Only CLI Calls <a id="c-warm-only-cli-calls"></a>

- `--warm-only` uses `SYSTEM_SKILL_ADVISOR_CLI_WARM_ONLY` and `SYSTEM_SKILL_ADVISOR_CLI_PROMPT_TIME` as environment defaults.
- It probes the advisor socket first.
- It exits `75` instead of cold-starting the daemon from a hook.
- The dist-freshness guard refuses stale builds with exit `69`.
- `SYSTEM_SKILL_ADVISOR_CLI_DEV_ALLOW_STALE=1` is the development override.

## Trust

CLI calls default to untrusted. Mutation tools require an explicit grant.

#### CLI Mutations Need a Grant <a id="c-cli-mutations-need-a-grant"></a>

- CLI calls are untrusted by default.
- The mutation tools `advisor_rebuild`, `skill_graph_scan` and apply-mode `skill_graph_propagate_enhances` require `--trusted` or `SYSTEM_SKILL_ADVISOR_CLI_TRUSTED=1`, the maintainer path.
- An untrusted mutation attempt is refused with exit `64`.

#### Native MCP Trust Has One Path <a id="c-native-mcp-trust-has-one-path"></a>

- The daemon fails closed when transport `_meta` carries no trust context.
- Native MCP registrations grant trust only through `SYSTEM_SKILL_ADVISOR_TRUST_DEFAULT=trusted` in their env block.
- That is a deployment-time declaration.
- Callers cannot forge it at request time.

&nbsp;

## Runtime Integrations

Warm-only fallbacks give the advisor hooks another route to the CLI.

#### Warm-Only Hook Fallbacks <a id="c-warm-only-hook-fallbacks"></a>

- The shared `hooks/lib/skill-advisor-cli-fallback.ts` helper gives the Claude and Codex `user-prompt-submit` advisor hooks a warm-only CLI path.
- The hooks probe the socket first.
- They call the CLI only when the daemon is warm.
- They fail open in about a millisecond when it is not.
- Gate 2 routing keeps working while the MCP transport is down.

#### OpenCode's CLI Route <a id="c-opencodes-cli-route"></a>

- The `.opencode/plugins/system-skill-advisor.js` plugin gains a CLI fallback route.
- The route goes through `mcp-server/plugin-bridges/system-skill-advisor-bridge.mjs`.
- Its primary bridge path is unchanged.

#### Runtime Calls Without Prompts <a id="c-runtime-calls-without-prompts"></a>

- `.codex/settings.json` allowlists CLI invocations for Codex.
- The Claude allowlist lives in local-only settings by decision.
- So the runtimes invoke the CLI without prompting.
