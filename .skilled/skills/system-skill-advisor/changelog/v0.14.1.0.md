# v0.14.1.0, A Flatter, Documented Runtime

The advisor runtime is now easier to read and has fewer one-file folders. Every file carries a module header, long files are split into numbered sections and every code folder has a README. Routing behavior is unchanged.

> Spec folder: `specs/system-skill-advisor/031-align-runtime-code-with-sk-code-opencode` (Level 2)

## What's New at a Glance

- **Three single-file folders folded into `lib/`.** `caller-context.ts`, `df-idf.ts` and `route-exclusions.ts` now sit directly in `lib/`. The route denylist still finds its config from both the source tree and the compiled build.
- **Test code moved under `tests/`.** The cosine scorer test, the shared fixtures and the environment snapshot helper all live there now. The helper no longer ships in the production build.
- **Dead stress-test code is gone.** `stress-test/search-quality/` had broken imports and nothing ran it.

## Upgrade

Repoint any out-of-tree import of `lib/context/`, `lib/corpus/` or `lib/routing/` to the same file name directly under `lib/`.
