# A Twenty-Fourth Doctor Bridge and a Wider Route Vocabulary

The doctor route manifest gained one route and nine trigger phrases, and both reach the advisor through the same generator as every other doctor bridge.

&nbsp;

## What's New at a Glance

- **The inventory grows by one.** `command-doctor-helper` is derived into the generated bridge file, the TypeScript projection, the Python projections and the rendered command list: twenty-four doctor routes and fifty-one bridges in total.
- **It ships inactive, and the reason is recorded.** Activating a doctor bridge needs a routing-slice row and a scorer rebaseline beside it, and neither belongs to the release that adds the route. The bridge is therefore derived and reachable through `/doctor:helper`, and the advisor routes no prompt to it yet.
- **Nine route phrases widen what the doctor vocabulary carries.** A branch-name pattern, a skill's frontmatter shape, a description that is too long, a Hermes prompt copy, a quality `json` that is missing, a UTCP config that is broken, an overview of the doctor family, a loop that never converges and a runtime copy that drifted from its source. Each one is an operator's wording that the manifest did not carry, and the reach probe confirms every one of them still reaches its own bridge.
- **No fusion rule moved.** A skill still keeps first place over a doctor bridge, and a doctor bridge still changes no skill's score.
