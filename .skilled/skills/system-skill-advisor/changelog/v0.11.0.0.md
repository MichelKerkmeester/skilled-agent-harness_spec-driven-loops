# v0.11.0.0, A Purpose-First Skill Advisor README

The README moves from a tabular reference card to the fleet's purpose-first narrative voice, so new readers understand what the advisor delivers before encountering the scoring details. No skill behavior changed. The runtime instruction surface and changelog history stay in place.

## What's New at a Glance

- **The README opens with a one-line pitch.** A blockquote after the H1 states the delivered outcome before any tool name, following the refined skill README template and the `mcp-obsidian` exemplar.
- **The overview puts the problem first.** `Why This Skill Exists` opens with misrouting and prompt-leak problems before any feature list.
- **The Five-Lane Scorer has a table.** Each lane gets one row with its live weight and evidence, modeled on the pilot's Plugin Knowledge Layer pattern.
- **Quick Start covers the caller paths.** It includes the MCP path, the legacy Python facade and the daemon-backed CLI, with the exit taxonomy and trusted-mutation guardrails.
- **Verification guidance has one close.** The README validator, TypeScript build, playbook and validation battery appear together in one section.
- **The README uses a numbered ALL-CAPS structure.** AT A GLANCE comes first and OVERVIEW is required, replacing the old reference-card style.
- **The README version is updated.** Its frontmatter changes from `0.8.0.34` to `0.11.0.0`.
- **Durable facts are preserved.** The five lane weights, nine tools, trust states, CLI exit taxonomy, env ownership and every reference link survive the README changes.

## Upgrade

No migration required. No `SKILL.md` content changed, and no scorer, daemon, MCP server, plugin bridge, hook, registry or vault file changed.
