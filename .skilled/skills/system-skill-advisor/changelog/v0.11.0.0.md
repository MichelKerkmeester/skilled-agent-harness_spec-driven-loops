# system-skill-advisor v0.11.0.0

The README moves from a tabular reference card to the purpose-first narrative voice the fleet now uses. It leads with a one-line pitch and a problem-first overview, so a new reader understands what the advisor delivers before they meet the scoring machinery. No skill behavior changed.

## 1. NEW

- **One-line pitch:** a blockquote right after the H1 states the delivered outcome before any tool name, following the refined skill README template and the mcp-obsidian exemplar.
- **The Five-Lane Scorer table:** one row per lane with the live weight and the evidence the lane operates on, modeled on the pilot's Plugin Knowledge Layer pattern.
- **Quick Start caller guidance:** the MCP path, the legacy Python facade and the daemon-backed CLI, with the exit taxonomy and the trusted-mutation guardrails.
- **Verification close:** the README validator, the TypeScript build, the playbook and the validation battery in one section.

---

## 2. CHANGED

- **README voice and structure:** the old reference-card style becomes the numbered ALL-CAPS section model with AT A GLANCE first and OVERVIEW as the required section.
- **Problem-first overview:** Why This Skill Exists opens with the misrouting and prompt-leak problems before any feature list.
- **Version field:** 0.8.0.34 to 0.11.0.0 in the README frontmatter.
- **Durable facts preserved:** the five lane weights, the nine tools, the trust states, the CLI exit taxonomy, the env ownership and every reference link survive the rewrite.

---

## 3. NOT CHANGED

- No SKILL.md content changed. The runtime instruction surface stays untouched.
- No scorer, daemon, MCP server, plugin bridge, hook, registry or vault file changed.
- The changelog history stays in place.
