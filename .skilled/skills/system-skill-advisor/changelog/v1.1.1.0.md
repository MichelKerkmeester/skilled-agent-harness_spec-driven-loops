# v1.1.1.0, Pasted Replies Keep the Task

The advisor routes from the task after an attributed reply. Short follow-ups stay with the delivered route when a confidence floor alone suggests a switch.

&nbsp;

## What's New at a Glance

- The hook and Python scoring paths strip an attributed reply before routing the task that follows.
- The hook gate and 10,000-character cut read that task.
- A floor-only weak follow-up that changes routes prints `Advisor: prompt skipped.`
- Route receipts change only after a brief is delivered, and the lifecycle clock expires stale ones.
- A hook crash prints `Advisor: outage (...)` with a manual route.
- `advisor_recommend` marks confidence-floor recommendations, and Python preserves `confidenceFloored: true`.
- The daemon receives `SPECKIT_ADVISOR_CONFIDENCE_THRESHOLD` and `SPECKIT_ADVISOR_UNCERTAINTY_THRESHOLD`.
- Requests naming route receipts, pasted replies, outage lines, lifecycle clocks or confidence floors now reach this skill.

&nbsp;

## How It Was Checked

Each code fix landed with a test that failed before it. The full advisor runtime suite passed 2532 tests with 8 skipped, one more than before. The Python harness passed 121 with no failures, the DSH extension tests 16, and the launcher tests 79. The routing-accuracy corpus gate passed its floors on the recaptured pin.
