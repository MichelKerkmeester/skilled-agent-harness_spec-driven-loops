# v0.18.1.0, Questions About Captured Decisions Reach Spec-Kit

The advisor holds a read-only question below its confidence floor unless the question names something a skill owns. "Show the decision capture queue for this project" named spec-kit's queue, but the advisor did not count it as spec-kit's, so the question routed nowhere.

> Spec folder: `specs/system-speckit/043-decision-capture/010-decision-routing-vocabulary` (Level 2)

&nbsp;

## What's New at a Glance

- **Decision-capture questions route.** A show, list or explain question that names the decision-capture queue, a chat candidate, an operator decision or the decision record is lifted to spec-kit, which owns the save step that reads them. "Show the evidence behind this chat candidate before I confirm it" and "Sweep this session and list the answers waiting to be recorded as decisions" now reach spec-kit.
- **Other requests about decisions are left alone.** The lift applies only to a read-only question. "Research how other tools handle decision capture" and "Dispatch this decision capture work to the Claude Code CLI" are scored as before.

&nbsp;

## Upgrade

No migration required. Rebuild the advisor with `npm run build` in `.skilled/skills/system-skill-advisor/runtime`.
