# v0.15.2.0, Surface Hint Only Inside the Hub

v0.15.1.0 sent `OPENCODE` for any workspace whose path held a `.skilled` folder, so a folder such as `/tmp/x/.skilled/demo`, outside this repository, got the hint. The stack-detection rule allows it only inside the hub's own `.skilled/` folder.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/016-residual-closeout/008-surface-hint-hub-root` (Level 1)

&nbsp;

## What's New at a Glance

- **The OPENCODE check is rooted at the hub.** The plugin resolves its own hub's `.skilled` folder once and sends `OPENCODE` only for a workspace at or below it. The OBSIDIAN and WEBFLOW markers are unchanged.
- **The plugin test uses the real hub.** The OPENCODE case now runs from this repository's `.skilled/skills`, and a new case pins that a `.skilled` folder outside the hub sends no hint.
