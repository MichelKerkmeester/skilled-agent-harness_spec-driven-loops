# v0.17.4.0, A Typed Doctor Target Routes to Its Own Bridge

A doctor command with several targets runs as `<command> <target>`, yet its bare form also matched the route's default target. A typed prompt such as `/doctor:git hooks` therefore pulled in the setup bridge next to the one it named. A typed target now names its own bridge. A bare `/doctor:git` typed alone still reaches its default target, setup.

> Spec folder: `specs/sk-code/015-quality-agnostic-gate/010-alignment-audit` (Level 2)

&nbsp;

## What's New at a Glance

- **The hooks prompt lists its own bridge.** `/doctor:git hooks` returns the hooks bridge first and sk-git second. The setup bridge drops out of the list.
- **The gate prompt leads with hooks.** Asking to disable the comment hygiene gate puts the hooks bridge ahead of sk-code.

No migration required. Callers need no change.
