# v0.17.13.0, Router Reach Reports Private Surfaces as Notes

`/doctor:skill-advisor router-reach` failed on an operator's machine when a private surface linked there tied a shipped hub, and the operator had no tracked way to fix it. The reach check now judges the shipped fleet, and the doctor workflow and its playbook scenario say how to read the new note it prints.

> Spec folder: `specs/sk-code/017-portable-code-modes/013-router-reach-local-ties` (Level 2)

&nbsp;

## What's New at a Glance

- **The doctor workflow names the new row.** It lists `operator-local` beside the other row kinds, prints those notes apart from the failures and never counts one as a failure.
- **The playbook scenario checks it.** It now fails a run where an operator-local note fails the run or names the private surface.
