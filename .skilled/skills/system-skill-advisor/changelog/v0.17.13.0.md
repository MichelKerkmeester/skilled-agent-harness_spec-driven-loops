# v0.17.13.0, Router Reach Reports Private Surfaces as Notes

On an operator's machine, `/doctor:skill-advisor router-reach` failed when a private surface linked there tied a shipped hub. The operator had no tracked way to fix it. The reach check now judges the shipped fleet. The doctor workflow and its playbook scenario say how to read the new note it prints.

&nbsp;

## What's New at a Glance

- **The doctor workflow names the new row.** It lists `operator-local` beside the other row kinds. It prints those notes apart from the failures. It never counts one as a failure.
- **The playbook scenario checks it.** It now fails a run where an operator-local note fails the run. It also fails a run where that note names the private surface.

&nbsp;

## Upgrade

No action is needed.
