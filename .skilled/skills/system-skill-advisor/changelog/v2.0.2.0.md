# v2.0.2.0, a floor only for a skill the prompt names

A prompt with task intent lifted any skill with a small lexical match to the 0.82 confidence floor. Out-of-domain prompts such as "set that aside and fix the failing unit test" or "my emails got flagged as a bot" passed for the browser hub on one shared word. The floor now needs the prompt to name the skill, and three browser anchors that matched unrelated work are narrowed.

&nbsp;

## What's New at a Glance

- The task-intent floor applies only when the prompt names the skill. That means an explicit-lane hit, a declared lexical hint, a lexical score of 0.45 or more, or the noun the skill id ends in, such as "doctor". A skill reached through one or two shared words keeps the confidence it earned.
- A strong direct score, 0.65 or more, still lifts a skill to the floor.
- A bare `har` is no longer a browser token boost or lexical hint. "export a HAR of" and "as a HAR file" still route through the hub's own phrases.
- The browser read-only lift needs "chrome performance trace" or "browser performance trace". A bare "performance trace" also names SQL and server traces.
- One corpus prompt that was already wrong now abstains, so the ratchet's `unknown_count` baseline moves from 13 to 14. No correct corpus answer changed.
- Three prompts that should route nowhere now route nowhere, so the command routing baseline gains one plain holdout hit. "update skilled to the latest release" now ranks the doctor update command first, where sk-code had matched only the word "release". Three local-native divergence rows now agree and left the ledger.

&nbsp;

## How It Was Checked

Every accuracy ratchet metric held except that one abstain: full corpus 161 of 196, holdout 49 of 63, ambiguity 21 of 24, review 25, memory save 27 and delegation 22, with five false fires before and after. The browser hub's 18 out-of-domain replay prompts all score below 0.8, and its real requests stay above it.

&nbsp;

## Upgrade

No migration required. A request that relied on one shared word to pass may now abstain, so name the skill or its domain phrase.
