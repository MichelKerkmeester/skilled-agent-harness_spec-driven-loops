## What's New at a Glance

- **The RRF core graduates with the conflict-rerank seam.** In benchmark phase 007 (`advisor-rrf-fusion`), RRF top-1 on a widened 42-prompt set went from 37/42 to 38/42, with zero regressions, 0.976 agreement and deterministic output. The seam repairs a regression plain RRF introduces and corrects 1 of 5 conflict cases.
- **The separate self-recommendation guard is cut.** The guard changed top-1 in 0 of 4 cases. Together, the generic explainer floor and the unflagged audit penalty had already done that work.
- **The implicit penalty is documented at -0.25.** After the guard was cut, `auditRecsAdvisorPenalty` was the only defense on audit and explainer prompts. It lacked a written rationale, so a future refactor could silently remove it. Follow-up work documented the penalty in a durable WHY comment and locked its role. Its value is unchanged.
- **The `skill-advisor` alias is demoted with the canonical id.** An opus deep review found that exact-id matching left the alias at the top in the default guard-off config. The predicate now uses the canonical self-recommendation id set, so both `system-skill-advisor` and `skill-advisor` are demoted by the same penalty.
- **Default-off behavior did not change existing routing.** It was byte-identical across the 42-prompt set, and phase 007 itself did not flip a production default.
