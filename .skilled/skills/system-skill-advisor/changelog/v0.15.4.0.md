# v0.15.4.0, Typo-Proof Script Options

The routing accuracy scripts, the command bridge generator and the soak and card sync checks used to ignore a misspelled option and run their default mode. Each one now names the option and exits 2.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/021-open-ends-remediation/001-typo-proof-parsers` (Level 1)

&nbsp;

## What's New at a Glance

- **Routing accuracy scripts refuse unknown options.** `build-holdout.mjs`, `capture-scorer-eval-baseline.mjs`, `derive-ambiguity-slice.mjs` and `capture-local-native-divergence-ledger.mjs` check their options before they read any data.
- **`init-skill-graph.sh` takes no arguments.** Any argument now exits 2 instead of starting a graph rebuild.
- **The bridge generator and the shell checks follow suit.** `derive-command-bridges.cjs`, `verify-zombie-soak.sh` and `check-prompt-quality-card-sync.sh` refuse an unknown option.

&nbsp;

## Upgrade

Replace any misspelled option with the one the script's usage line lists.
