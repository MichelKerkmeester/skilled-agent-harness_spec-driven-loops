This release hardens the advisor's persistence and routing in response to deep-review P1 findings from the 028 playbook-findings remediation. A routing change the dispatch attempted was reverted as incomplete before release.

> Spec folder: `.opencode/specs/system-spec-kit/028-memory-search-intelligence/006-review-remediation`

## What's New at a Glance

- **The highest-weight routing match-terms are now sanitized.** `derived.trigger_phrases`, `derived.key_topics` and `derived.entities` were unsanitized highest-weight routing match-terms, so instruction-shaped values from skill graph metadata reached the scorer unfiltered, unlike `source_docs` and `key_files`. Instruction-shaped, control-character and over-length values in those fields are now removed before projection, though the separate `skill_docs` upsert path still writes and reads `title`, `description` and `trigger_phrases` raw.
- **Concurrent metrics writes no longer lose records.** Previously, concurrent advisor invocations in one workspace could overwrite each other's records because writes read and rewrote the full file without a lock. Writes now append atomically and are serialized per path through an in-process queue, and bounding is retained under the same queue, with trimming delayed until the file exceeds 1.5 times the cap so the common path stays a cheap append.
- **Hook diagnostics cannot surface unhandled rejections.** Two unhandled-rejection paths arose because asynchronous diagnostic writes were not awaited inside synchronous try blocks in Claude and Codex `user-prompt-submit` hooks and the Codex `prompt-wrapper` hook. The writes now catch and swallow failures so diagnostics do not affect hook behavior.
- **Rollback removes only the derived block.** Previously, it also erased `lifecycle_status` and `redirect_to`, silently un-deprecating skills and dropping supersession redirects. Those two fields are now preserved.

## Upgrade

No migration required. Adopt via a fresh session so the daemon respawns with the new dist. The sanitizer affects only skills whose derived metadata carries instruction-shaped or over-length values, so a clean corpus is byte-identical. Verify by indexing a skill with an instruction-shaped `trigger_phrases` value and confirming it does not appear in the projection's `derivedTriggers`.
