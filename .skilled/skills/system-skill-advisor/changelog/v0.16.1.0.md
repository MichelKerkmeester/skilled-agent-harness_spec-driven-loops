# v0.16.1.0, The Doctor Hint Fires Only When It Fits

The doctor routing from v0.16.0.0 fired on two kinds of prompt it should leave alone. Both are narrowed, and no prompt that routed correctly before changed its answer.

> Spec folder: `specs/system-skill-advisor/035-doctor-command-routing` (Level 2)

&nbsp;

## What's New at a Glance

- **"Check" alone no longer triggers the setup hint.** It needs an environment, hook or tooling word after it, so "check my essay" gets no hint while "check my git hooks" still does. Claude, Pi and OpenCode match the same way.
- **A quoted command stays a quote.** A `/doctor:` command counts as typed only when the prompt starts with it, so "fix the hook that /doctor:git hooks lists" keeps the matching skill first. The Python fallback follows the same rule.

&nbsp;

## Upgrade

No migration required. Rebuild the advisor runtime (`npm --prefix .skilled/skills/system-skill-advisor/runtime run build`) so the hooks load the new rules.
