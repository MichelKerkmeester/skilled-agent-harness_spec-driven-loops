# v0.11.1.0, Command Alignment and Honest No-Match Diagnostics

The advisor now aligns its command bridge with the `/speckit:save` rename and distinguishes a successful no-match from an unavailable advisor. The release also refreshes the command census and scorer evaluation baseline without changing the release floors.

## What's New at a Glance

- **The command bridge now reflects `/speckit:save`.** The rename from `/memory:save` had reached only the bridge list the scorer consults. The gap failed both the drift guard, which compares the two descriptions, and the resolution guard, which found the leftover slash id with no command file behind it. The inventory projection now uses the renamed slash id and description, while scorer keys `memory:save` and `command-memory-save` stay unchanged.
- **A live no-match now has a distinct diagnostic.** The hook routes, fails open or skips. Previously, a live advisor with no recommendation and an unreachable advisor both reported `errorCode: NON_ZERO_EXIT` and `errorMessage: CLI_ADVISOR_UNAVAILABLE`, even when the call exited zero. A live or stale advisor with no match now reports `reason: no_recommendation` and `errorMessage: CLI_ADVISOR_NO_MATCH` without an error code or class, while an unreachable advisor keeps its previous wording.
- **The command census now counts 20 commands.** It was 21 before `/deep:skill-benchmark` was retired.
- **The scorer evaluation baseline is 152 correct of 195.** It was re-captured after roughly ninety routing inputs changed, down from 154. Two prompts joined the accepted parity regression list because they route correctly with a live skill graph and lose only in the pinned no-database regime.
