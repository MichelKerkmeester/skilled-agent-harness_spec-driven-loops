# v0.17.20.0, Discovery Roots and the Hooks Leaf Corrected

Two defects in the advisor skill's own resource router are fixed. Discovery now reaches the feature catalog and the manual testing playbook. The HOOK route resolves to a real typed leaf inside the manifest the router promises to stay in.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/002-baseline-and-routing-correctness` (Level 2)

&nbsp;

## What's New at a Glance

- **Discovery finds the catalog and the playbook.** The roots named `feature_catalog` and `manual_testing_playbook` with underscores, while the folders use hyphens, so neither doc set was found and `hooks` was left out entirely. The roots now match the folders and include `hooks`.
- **The HOOK route lands on a real leaf.** The HOOK intent points at `hooks/skill-advisor-hook.md`, but `hooks` was not a leaf root, so that doc sat outside the manifest. The manifest and its aliases now carry the leaf.
