# v0.18.7.0, The Baseline Can List Its Failing Prompts

The scorer baseline recorded how many prompts fail in each set and never which ones.

&nbsp;

## What's New at a Glance

- **`--misses` lists the failing prompts.** `capture-scorer-eval-baseline.mjs --misses` prints one JSON line per failing prompt with its set, its gold skill and what the scorer picked. A rerun on the current scorer reproduces the stored metrics, so the baseline file is unchanged.
- **The `hub_skills` section matches the query.** The cookbook described a combined in and out degree ranking with a `topN` input. The query counts inbound edges against `minInbound`, and the section now shows that input and the real output shape.
- **Two doctor phrases are bridged.** The derived command bridges carry "mcp tools are missing" and "advisor daemon is stale".
