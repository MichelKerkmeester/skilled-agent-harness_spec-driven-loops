# v0.14.2.0, Jev as the Only Classifier

The offline routing evals now support Jev alone. The tie-break and suggested-order scorers drop their Deem arms and Deem docs, and `cli-jev` is the only classifier.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/046-deem-deprecation` (Level 2)

## What's New at a Glance

- **The tie-break eval is Jev only.** `score-jev-tiebreak.mjs` drops its `--deem` switch and arm. Its zero-call census and `--jev` arm print as before.
- **The suggested-order eval is Jev only.** `score-suggested-order.mjs` drops its `--deem` arm, and its planned-calls line now counts Jev calls alone.
- **The reference docs name Jev alone.** The feature catalog, manual testing playbook and READMEs no longer describe a second backend.

## Upgrade

No migration required. Both scripts keep their zero-call default, and their `--jev` arms behave as before.
