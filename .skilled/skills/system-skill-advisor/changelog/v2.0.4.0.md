# v2.0.4.0, a skill counts as named only on a word few skills share

Version 2.0.3.0 left the shared lexical anchor alone. A trace of each 0.82 lift found three paths. Some lifts came from words many skills list, such as "run" and "check". Some came from the strong-score lift. It never asked whether the prompt named the skill. One came from the id-noun rule. It took "patch", a synonym of "fix", as the second word.

&nbsp;

## What's New at a Glance

- A lexical score of 0.45 names a skill only on a distinctive word. The prompt must hold a skill word that at most a quarter of skills list.
- Command entries are left out of that count. Each one repeats its owner's words.
- "run the doctor update check" now lifts system-skilled-doctor alone. cli-classifier and sk-doc no longer rise beside it.
- The strong-score lift at 0.65 needs a named anchor too.
- "rewrite this prompt so it is shorter" no longer lifts sk-code. "fix the code in the parser" no longer lifts local-webflow.
- The id noun's second word must be in the prompt. It is read from the skill's own text, not the capped evidence list.
- A typed command names the skill that owns it. `/create:skill-parent deploy-hub with three modes` keeps sk-doc on top.

&nbsp;

## How It Was Checked

Every accuracy ratchet held. Full corpus 161, unknown 14, holdout 49, ambiguity 21. Review 25, memory save 27, delegation 22, five false fires. The full suite passes except the known `system-skilled-bots` empty-description test. No pinned command, doctor or golden row moved. Three stricter candidate rules each moved pinned rows. They were dropped. The mcp-browser-use replay holds at 55 of 56. The new test `tests/scorer/lexical-anchor-naming.vitest.ts` fails without the change.

&nbsp;

## Known Limitation

Three of five probe prompts still lift a second skill:

- "fix the container orchestration config" lifts mcp-code-mode and the browser hub.
- "rewrite this prompt so it is shorter" lifts sk-doc.
- "update the plan for the mode rollout" lifts cli-external-orchestration.

Each shares a rare word with the prompt. A stricter rule is needed. The ones tried moved pinned rows.

No migration required.
