# v0.16.0.0, The Advisor Points to the Doctor Commands

The advisor knew every skill. It knew none of the doctor commands. So a prompt like "help me set up skilled" got no suggestion at all. The same went for "check my environment variables". It now names the doctor command to run. The line is one you can paste. It does not take first place from a skill that fits.

&nbsp;

## What's New at a Glance

- **Setup and health prompts name a doctor command.** "Help me set up skilled" suggests `/doctor:setup`. "Check my environment variables" suggests `/doctor:env list`. Each is a runnable line, not an internal id.
- **A matching skill keeps first place.** "Check my git hooks setup" still routes to sk-git. The brief adds `Also: /doctor:git setup` as a second line. No prompt that routed correctly before changed its answer.
- **The doctor routes come from the doctor route list.** The routes are generated from the doctor commands' own route file. A new target still needs its activation entry in `scoring-compatibility.json`. Only then does the advisor suggest it.
- **The Python fallback answers typed commands only.** It routes a typed `/doctor:git setup`. Plain wording is left to the main scorer. That keeps the fallback from over-firing.
- **A setup prompt with no match gets a hint.** Nothing matches, and the prompt says set up, install, check or configure. Then the line adds "For setup or health checks, run /doctor:setup." An unrelated prompt gets no hint.
- **The hint holds when the advisor is down.** The outage line carries the same hint. It sits ahead of its route-by-hand command. That is because `/doctor:setup` also checks the advisor. The command stays last, so it can still be copied.
- **Claude, Pi and OpenCode show the same text.** Pi passes the setup check on its deadline path. The OpenCode plugin renders the hint from its own copy of the check. That copy is kept equal to the hook's.
- **The skill-advisor doctor steps run again.** `/doctor:skill-advisor` and its rebuild workflow called `advisor_status`. They left out the workspace root it requires. That exited 64. They now pass it.

&nbsp;

## Upgrade

No migration required. Rebuild the advisor runtime (`npm --prefix .skilled/skills/system-skill-advisor/runtime run build`). That way the hooks load the new renderer.
