# v0.15.3.0, Writing Code Beats Deep-Review Wording

Some prompts ask for a test. One is "Write a Vitest covering the resume deep review phrase." The advisor read the phrase. It sent the prompt to the deep-review loop. "Add a packet-local helper that formats confusion-matrix rows" went to spec-kit for the same reason. Both now reach sk-code. The advisor's two entry points agree on the order.

&nbsp;

## What's New at a Glance

- **Writing a test or helper is code work.** A prompt asks to add, build, create, implement or write a test. It may ask for a Vitest or a helper. It routes to sk-code. That holds even when it names a deep-review phrase. It also holds for a study artifact. One example is the confusion matrix.
- **Real deep-review and study requests keep their routes.** "Resume the deep-review iteration from the last save point" still goes to the deep loop. Editing a study prompt template still goes to spec-kit.
- **The Python advisor keeps the same order.** With the native scorer, it no longer pushes the deep loop back above sk-code. That is true on these prompts.
