# v0.15.3.0, Writing Code Beats Deep-Review Wording

A prompt such as "Write a Vitest covering the resume deep review phrase" asks for a test, but the advisor read the phrase and sent it to the deep-review loop. "Add a packet-local helper that formats confusion-matrix rows" went to spec-kit for the same reason. Both now reach sk-code, and the advisor's two entry points agree on the order.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/019-routing-miss-fixes` (Level 1)

&nbsp;

## What's New at a Glance

- **Writing a test or helper is code work.** A prompt that asks to add, build, create, implement or write a test, Vitest or helper routes to sk-code, even when it names a deep-review phrase or a study artifact such as the confusion matrix.
- **Real deep-review and study requests keep their routes.** "Resume the deep-review iteration from the last save point" still goes to the deep loop, and editing a study prompt template still goes to spec-kit.
- **The Python advisor keeps the same order.** With the native scorer, it no longer pushes the deep loop back above sk-code on these prompts.
