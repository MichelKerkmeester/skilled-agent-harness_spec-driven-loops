# v0.17.6.0, The Adapter README Names Its Source File

The embedder adapters README showed an import for a compiled file. A reader would not find that file in the repository. It now names the source that is tracked. The tests README accounts for one more file in its folder.

&nbsp;

## What's New at a Glance

- The adapter README points at the source it means.
  - The README names `ollama.ts` as the file the embedder imports.
  - The README keeps the note that the specifier carries the `.js` extension.
  - The module setting requires that extension.
- The tests README lists the test type check.
  - `tsconfig.tests.json` now appears in the folder tree and in the table.
  - There it says what the file does.
  - A reader does not have to open it.

No action is needed. These are documentation changes. So nothing about how the skill runs is different.
