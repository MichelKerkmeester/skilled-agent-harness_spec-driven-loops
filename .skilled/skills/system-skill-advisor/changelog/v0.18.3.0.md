# v0.18.3.0, Negated Writes Stop Pulling Toward sk-doc

An instruction not to write used to read like an instruction to write. The scorer saw a write verb and a document word in the same prompt and added its document-writing boost, even when the words asked to leave the file alone. A negated write now reads as what it is, so a review that asks for no edits stays with the skill that reviews.

> Spec folder: `specs/sk-design/021-deprecate-fundamentals` (Level 2)

&nbsp;

## What's New at a Glance

- **A negated write no longer counts as a write.** A write phrase that follows "don't", "do not", "never" or "without" is blanked before the document-surface tests run, so "don't write anything back yet" stops earning the `sk-doc` boost.
- **Routing accuracy rose.** The full labeled corpus now scores 157, the holdout 50 and the ambiguity slice 20, and a review that asks for no write now ranks `sk-code` first.
