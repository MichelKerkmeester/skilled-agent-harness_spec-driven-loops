# v0.17.14.0, Runtime READMEs stop naming removed files

Several runtime READMEs still named the code-graph bench files, a parse-latency bench, a runtime-parity test and a `.skilled/.gitignore`, none of which exist. They now describe the files on disk.

> Spec folder: `specs/sk-doc/070-repo-doc-debt/007-alignment-fixes` (Level 2)

&nbsp;

## What's New at a Glance

- **The bench README lists the bench that remains.** The code-graph bench rows are gone and the baseline stays.
- **The runtime and legacy test READMEs drop removed files.** The parse-latency bench line and the runtime-parity test line are gone.
- **The data README names the real ignore file.** It points at the repository root `.gitignore`.
- **The stress-test README resolves.** Its test and library paths read `../../tests/` and `../../lib/`, relative to the README.
