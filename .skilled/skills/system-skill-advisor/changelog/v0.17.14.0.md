# v0.17.14.0, Runtime READMEs stop naming removed files

Several runtime READMEs still named files that do not exist. They named the code-graph bench files, a parse-latency bench, a runtime-parity test and a `.skilled/.gitignore`. They now describe the files on disk.

&nbsp;

## What's New at a Glance

- The bench README lists the bench that remains.
  - The code-graph bench rows are gone.
  - The baseline stays.
- The runtime and legacy test READMEs drop removed files.
  - The parse-latency bench line is gone.
  - The runtime-parity test line is gone.
- The data README names the real ignore file.
  - The README points at the repository root `.gitignore`.
- The stress-test README resolves.
  - The test and library paths read `../../tests/` and `../../lib/`, relative to the README.

&nbsp;

## Upgrade

No migration required.
