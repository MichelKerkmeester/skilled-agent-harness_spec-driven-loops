# v0.2.0, Production Isolation (Preview Track)

The `system-skill-advisor` non-embeddings code is fully isolated from `system-spec-kit`, while its embeddings dependency is visible through a symlink. As a pre-1.0 preview, v0.2.0 reflects the substantive isolation work and leaves runtime API ids stable from v0.1.0. Production `.ts` cross-skill imports go from 6 to 0.

## What's New at a Glance

- **Non-embeddings helpers are local.** Four of the six production `.ts` files imported shared-payload types, and two of those also imported `canonicalFold`. Local copies in `mcp-server/lib/shared/shared-payload.ts` and `mcp-server/lib/shared/unicode-normalization.ts` carry 7 types plus transitive helpers, and `canonicalFold` with `CANONICAL_FOLD_VERSION`, `HIDDEN_CHAR_PATTERN`, `COMBINING_MARK_PATTERN` and `CONFUSABLE_REPLACEMENTS`. These copies replace the helper imports in those four files, with comments pointing contributors to `system-spec-kit` for upstream changes.
- **The embeddings dependency is visible in the file tree.** The stack was too heavy to duplicate and too critical to drop, so `mcp-server/lib/shared/embeddings` points to `../../../../system-spec-kit/shared/embeddings`. The other two files, `semantic-shadow` and `skill-graph-db`, load `createEmbeddingsProvider` through the `@spec-kit/shared/embeddings/factory.js` alias resolved by `tsconfig` paths. Embeddings-backed features require the target, and removing `system-spec-kit` leaves a dangling symlink as the failure signal.
- **`@spec-kit/shared` is no longer a package dependency.** Its declaration was removed from `mcp-server/package.json` and `package-lock.json` was regenerated. The alias now resolves only through `tsconfig` paths for type checking, while runtime imports resolve through the file system and the symlink.
- **The advisor test suite has no cross-skill imports.** `tests/handlers/advisor-recommend.vitest.ts` uses a local fixture for errors instead of importing them from `system-spec-kit`.
- **CI blocks cross-skill import regressions.** Two new audits check reverse-direction relative-path imports and `@spec-kit/*` workspace-alias imports. The first excludes `lib/shared/embeddings/**` and `tests/stress-test`, and the second excludes `@spec-kit/shared/embeddings/*` as the documented exception. A regression fails CI with a precise error message.
- **The TypeScript configuration accommodates the embeddings alias.** `mcp-server/tsconfig.json` adds `ignoreDeprecations: "6.0"` to silence the pre-existing TS5101 `baseUrl` deprecation warning and removes `rootDir: "."` because the alias lies outside the previous root. The config extends `system-spec-kit/mcp-server/tsconfig.json`, so deleting `system-spec-kit` breaks `tsc --build`. TypeScript emits informational TS6307 notes for files reached through the embeddings alias. These are not errors and describe the cross-skill program structure.

## Upgrade

No migration required. The runtime API surface is unchanged from v0.1.0: `advisor_recommend`, `advisor_rebuild`, `advisor_status` and `advisor_validate` keep the same signatures and behavior. `skill_graph_scan`, `skill_graph_query`, `skill_graph_status` and `skill_graph_validate` are unchanged.

If you maintain a fork, rerun `npm --prefix .opencode/skills/system-skill-advisor/mcp-server install` to refresh `package-lock.json` without `@spec-kit/shared`. Git tracks the `lib/shared/embeddings` symlink and recreates it on checkout.
