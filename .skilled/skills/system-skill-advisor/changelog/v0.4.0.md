`check-prompt-quality-card-sync.sh` now protects the canonical prompt-quality tables by checking per-CLI cards for copies. It replaces hash comparison across three mirrors, which required synchronized copies and could flag deliberate updates before they reached every mirror.

## What's New at a Glance

- **The guard checks four `cli-*` cards for copied tables.** It scans `cli-claude-code`, `cli-codex`, `cli-devin` and `cli-opencode` for the canonical framework comparison table and CLEAR scoring table, which stay in one authoritative location and are referenced rather than copied. Exit 0 means neither table appears in any card. A non-zero exit means at least one card contains content that belongs only in the canonical card, so CI should reject it.
- **Table-header matching replaces hash comparisons.** Targeted substring matches use header text unique to each canonical block. They stay stable across minor wording changes and do not require an updated hash baseline after every canonical-card edit.
- **The existing script path and pass result are preserved.** CI steps can keep invoking `.opencode/skills/system-skill-advisor/mcp-server/scripts/check-prompt-quality-card-sync.sh`, and exit 0 still means pass. A non-zero result now means duplication rather than a hash mismatch, but the operational response remains to review and fix the flagged card.

## Upgrade

No migration required. The script is self-contained. Remove any stored hash baselines that the old sync-check relied on. The script no longer reads them.
