# v0.17.0.0, Private Skills and CI Doctor Routes

Operator-private skills now route through the advisor without their names reaching tracked output. The advisor also suggests the `/doctor:ci` commands for CI workflow prompts. Plain web words no longer pull prompts toward sk-code.

> Spec folders: `specs/sk-code/013-private-surface-skills` (Level 2) and `specs/system-speckit/053-ci-workflow-efficiency` (Level 2)

&nbsp;

## What's New at a Glance

- **Private skills route only through trusted links.** A top-level `local-*` link is followed only when its real path sits inside the skills root or a root named in `SPECKIT_PRIVATE_SKILL_ROOTS`. Every other link is skipped.
- **Private skill names stay out of tracked output.** The fallback graph, the Hermes mirror, the CI gates and the doctor findings all skip them by name.
- **CI doctor commands show up as runnable lines.** A `/doctor:ci` route that matches a prompt shows as a runnable line next to the matching skill. `/doctor:ci report` ranks first when the prompt uses one of its lead phrases.
- **Read-only doctor routes can pass the floor.** A request such as "show which ci workflow switches are off" can now surface `/doctor:ci report` when the prompt uses that route's own phrase. Commands that change files stay gated.
- **Plain web words stop boosting sk-code.** Single words such as CSS, HTML, mobile, viewport, CDN and Lighthouse no longer add to sk-code's score on their own.
- **Loop words need a review in reach.** In a prompt that mentions review, a verb such as resume or continue counts toward the deep review loop only when it governs the review within three words. Convergence and iteration words still count anywhere, as does the word loop.
- **Embedding outages stop early and spare current vectors.** After a run of backend failures the refresh stops and warns. Rows that already have current vectors keep them.

&nbsp;

## Upgrade

Rebuild the advisor runtime (`npm --prefix .skilled/skills/system-skill-advisor/runtime run build`). If a private skill link points into another folder, set `SPECKIT_PRIVATE_SKILL_ROOTS` to that folder's absolute path. Join several paths with `:` on macOS and Linux. Without the variable, that link is skipped.
