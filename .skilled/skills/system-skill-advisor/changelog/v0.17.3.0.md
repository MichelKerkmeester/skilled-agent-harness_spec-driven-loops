# v0.17.3.0, A Bare Doctor Command Reaches Its Bridge

A doctor command with several targets runs as `<command> <target>`, yet its router binds one target when none is typed. The advisor only matched the full form, so a bare `/doctor:ci` found no bridge. A route marked `default_target` in the doctor routes file now also answers the bare command, in both the TypeScript scorer and the Python advisor.

> Spec folder: `specs/sk-code/015-quality-agnostic-gate` (Level 2)

&nbsp;

## What's New at a Glance

- **The bare command routes.** `/doctor:ci` returns the CI report bridge, `/doctor:sk-code` returns sk-code first and then its setup bridge, and `/doctor:git` returns the git setup bridge.
- **The deriver checks the flag.** A non-boolean value or a flag on a single-target command stops the build with a clear message.
- **The setup playbook counts nineteen targets.** The doctor setup scenario now lists the sk-code quality route in its table.

&nbsp;

## Upgrade

Regenerate the command bridges after pulling. No other migration is required.
