- **One source of values.** `check-skill-doc-frontmatter.mjs` reads sk-create-frontmatter's `frontmatter-values.json`, so skill docs and spec docs agree on what is legal.
- **Ranking is unchanged.** Tier weights are untouched, so no recommendation moves.
