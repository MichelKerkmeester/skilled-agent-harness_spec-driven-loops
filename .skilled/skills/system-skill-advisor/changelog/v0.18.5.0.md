# v0.18.5.0, Deep-review and deep-research reach the deep-loop hub

A request that names the `deep-review` or `deep-research` workflow, written with its hyphen, now reaches `system-deep-loop` even when it also mentions docs. The advisor tests also cover the new DeepSeek Harness mode.

> Spec folders: `specs/system-skilled-doctor/001-skill-and-overlay-build/001-skill-and-tag-move` and `specs/cli-external-orchestration/085-cli-deepseek-harness-creation`

&nbsp;

## What's New at a Glance

- **Hyphenated workflow names count.** The lexical lane matched `deep review` and `deep research` with a space, so the usual written form scored no hint.
- **A docs audit stays a deep review.** "Use the deep-review workflow for the docs audit" ranked `sk-doc` first. It now ranks `system-deep-loop` first, its gold.
- **Accuracy moved up.** The full-corpus top-1 count went from 157 to 158, and the baseline was re-captured.
- **Parity holds.** The native scorer again keeps 110 of the 114 Python-correct corpus answers, and `rr-iter3-166` left the accepted-regression list.
- **"dsh headless" is a tested route.** The executor-delegation cases add "run this task through dsh headless", which must reach `cli-deepseek-harness`.
- **Interactive DSH sessions get the brief.** The DSH prompt-advisor adapter lives in `hooks/dsh/` and runs only in an interactive session. A fan-out leaf gets no brief.
- **The CLI card check covers dsh.** `check-prompt-quality-card-sync.sh` now checks the DeepSeek Harness prompt card and `SKILL.md` with the other seven CLI modes.
