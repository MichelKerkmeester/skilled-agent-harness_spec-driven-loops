The advisor moved with the rest of the source tree from `.opencode` to `.skilled`. This release records the move and the fixes that followed it: the prompt hook delivers a skill suggestion again, and the OpenCode plugin started from a subfolder keeps its cached answers in step with skill changes. The scorer also lets a two-character executor name such as `pi` count toward a route.

## What's New at a Glance

- **The skill lives under `.skilled`.** Its files moved from `.opencode/skills/system-skill-advisor/` to `.skilled/skills/system-skill-advisor/`, and its paths and documents name the new root. In a checkout that uses either name, the advisor still finds its repository root, its launcher and its skill graph.
- **The hooks find their flags under either root name.** The advisor hooks looked for the hook flags under `.opencode` by name. They now look under their own source root, so they find the flags in a checkout that carries `.skilled` and in one that carries only `.opencode`.
- **The skill brief is back.** After the move, the hook's fast path looked for its tools under the old root name, so every prompt in every runtime that runs the hook gave up in about two milliseconds with no suggestion. It now tries `.skilled` first and `.opencode` second, and takes its shim, bridge and database folder from the root it found.
- **A changed suggestion reaches Pi again.** Pi held back a delivery as a repeat whenever its directives matched the last one, even when the suggested skill had changed. It now compares the whole delivery.
- **The OpenCode plugin's cache follows skill changes below the checkout root.** Started from a subfolder, the plugin hashed a skill folder that was not there, so its cached answers never noticed a skill change. It now finds the repository root first and hashes the real skills.
- **The OpenCode status tool reports compiled routing again.** Without `.opencode/bin` the tool showed compiled routing as unavailable. It now also looks for the routing status under `.skilled/bin`.
- **Two-character executor names reach the scorer.** The scorer dropped every word of two characters or fewer, so `pi` never counted and a prompt such as "delegate this to pi" got no suggestion at all. That prompt now gets `cli-external-orchestration` with a compiled route to `cli-pi`.
- **`cli-jev` and `sk-design` recommendations carry a compiled route.** When the advisor recommends either hub it now attaches the hub's `compiledRoute` by default, as it already did for five other hubs.

## Upgrade

Anything that names `.opencode/skills/system-skill-advisor/` should now name `.skilled/skills/system-skill-advisor/`.
