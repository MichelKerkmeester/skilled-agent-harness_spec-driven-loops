The advisor moved with the rest of the source tree. It went from `.opencode` to `.skilled`. This release records the move and the fixes that followed. The prompt hook delivers a skill suggestion again. The OpenCode plugin started from a subfolder. It keeps its cached answers in step with skill changes. The scorer also lets a two-character executor name such as `pi` count toward a route.

## What's New at a Glance

- **The skill lives under `.skilled`.** Its files moved from `.opencode/skills/system-skill-advisor/` to `.skilled/skills/system-skill-advisor/`. Its paths and documents name the new root. In a checkout that uses either name, the advisor still finds its repository root. It still finds its launcher and its skill graph.
- **The hooks find their flags under either root name.** The advisor hooks looked for the hook flags under `.opencode` by name. They now look under their own source root. So they find the flags in a checkout that carries `.skilled`. They also find them in one that carries only `.opencode`.
- **The skill brief is back.** After the move, the hook's fast path looked for its tools. It looked under the old root name. So every prompt gave up in about two milliseconds. That held in every runtime that runs the hook. It gave up with no suggestion. It now tries `.skilled` first and `.opencode` second. It takes its shim, bridge and database folder from the root it found.
- **A changed suggestion reaches Pi again.** Pi held back a delivery as a repeat whenever its directives matched the last one. That held even when the suggested skill had changed. It now compares the whole delivery.
- **The OpenCode plugin's cache follows skill changes below the checkout root.** Started from a subfolder, the plugin hashed a skill folder that was not there. So its cached answers never noticed a skill change. It now finds the repository root first. It hashes the real skills.
- **The OpenCode status tool reports compiled routing again.** Without `.opencode/bin` the tool showed compiled routing as unavailable. It now also looks for the routing status under `.skilled/bin`.
- **Two-character executor names reach the scorer.** The scorer dropped every word of two characters or fewer. So `pi` never counted. A prompt such as "delegate this to pi" got no suggestion at all. That prompt now gets `cli-external-orchestration` with a compiled route to `cli-pi`.
- **`cli-jev` and `sk-design` recommendations carry a compiled route.** When the advisor recommends either hub, it now attaches the hub's `compiledRoute` by default. It already did this for five other hubs.

## Upgrade

Anything that names `.opencode/skills/system-skill-advisor/` should now name `.skilled/skills/system-skill-advisor/`.
