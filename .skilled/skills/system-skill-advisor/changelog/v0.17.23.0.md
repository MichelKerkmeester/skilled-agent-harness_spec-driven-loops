# A Cli Tool's Name Lifts the Read-Only Floor

A prompt can open with a read-only verb such as `list` or `show`. It sits on the explainer floor, at confidence 0.25. That is unless it names the skill it wants. Only the skill's id counted as naming it. So "List my Orca worktrees and open a terminal in the new one" abstained. That was even though cli-orca led sk-git by 0.19. For a cli skill, the tool's own name now counts too. That is `orca` for cli-orca and `classifier` for cli-classifier. Both Orca prompts the alignment probe uses now return cli-orca as top-1. Routing accuracy holds at 155/195, 49/66 and 19/24.

The leaf-inventory note listed three leaf roots. `leaf-manifest.config.json` declares five. A reader compared the note with `leaf-manifest.json`. They could not account for the `hooks/` leaves. They could not account for an `assets/` root that contributes none.

The note now names all five. It says how `hooks/` stays Markdown-only. The `/doctor:skill-advisor skill-budget` audit now counts each command's description once.

&nbsp;

## What's New at a Glance

- A cli skill's tool name names the skill.
  - A read-only prompt that says `orca` reaches cli-orca at 0.84.
  - That read-only prompt no longer abstains at 0.25.
  - Prefixes other families use, such as `sk-` and `mcp-`, still need the full id.
  - That is because their bare suffixes (`git`, `code`, `tooling`) are ordinary words.
- All five declared leaf roots are named: `references/`, `assets/`, `feature-catalog/`, `manual-testing-playbook/` and `hooks/`.
- `hooks/` is Markdown-only through `leaf-scopes.json`.
  - The scope names its five hook docs.
  - So the nine runtime `.ts`, `.py` and `.json` files beside them are never leaves.
- `assets/` is accounted for.
  - It is declared.
  - It has no docs to contribute.
- The `/doctor:skill-advisor skill-budget` audit now counts each command once.
  - A native file that repeated a canonical command was counted a second time.
  - The audit now keeps the canonical copy.
  - It reads that copy first.
  - It skips the repeat.

## Upgrade

No action is needed. Rebuild the advisor (`npm --prefix .skilled/skills/system-skill-advisor/runtime run build`). Then restart its daemon to pick up the scorer change.
