# v0.17.19.0, the Python Fallback Keeps the Workflow First and Compound Words Stop Matching

Two gaps that v0.17.18.0 left open are closed. When the daemon cannot answer, the Python fallback now gives the same order as the native scorer on a prompt that names a workflow and an executor. The lexical lane's partial word credit stopped reading a compound as an extension of a short word, which lets sk-git declare its sweep switch without pulling "auto review this PR" off sk-code.

> Spec folder: `specs/system-skill-advisor/039-executor-workflow-owner-guard` (Level 2)

&nbsp;

## What's New at a Glance

- **The Python fallback keeps the workflow owner first.** "run a deep research loop with the cli-pi executor" and "create a spec folder for this feature and use cli-codex to write the code" used to list the CLI hub first in a degraded answer. The fallback now keeps `system-deep-loop` or `system-spec-kit` first and puts the hub directly below it, 0.001 lower, as the native scorer does. A plain delegation such as "delegate this refactor to codex" still lists the hub first. This corrects v0.17.18.0, which said the fallback had no such guard.
- **An iteratively phrased review with an executor ranks the same on both scorers.** The fallback reads a loop word beside "research" or "review" as a request for the deep-loop workflow, as the native explicit lane does, so "Review this change iteratively using cli-opencode as the executor." returns `system-deep-loop` at 0.82 with the hub at 0.819 on both.
- **A compound word no longer counts as a longer form of a short one.** The lexical lane gave partial credit whenever a skill word began with a prompt word, so "auto" matched `autoreap`, "open" matched `opencode` and "launch" matched `launchpad`. Credit now needs the extra letters to read as a suffix: `plan` to `planning`, `converge` to `convergence` and `deploy` to `deployment` still match, and a second word added on does not. A compound whose second word starts with a vowel, such as `openai`, still matches.
- **Naming the sweep switch reaches sk-git.** sk-git now declares `speckit_worktree_autoreap` and `worktree autoreap`, so "how do I set SPECKIT_WORKTREE_AUTOREAP=0" routes to sk-git instead of returning nothing, and "auto review this PR" stays on sk-code. In the Python fallback that prompt ranks sk-git first at 0.71, below the 0.8 threshold, so a strict degraded answer still returns nothing.

&nbsp;

## Upgrade

No action is needed. Rebuild `dist/` so the daemon serves the new partial-credit rule; it reindexes sk-git's metadata on its own.
