# v0.17.19.0, the Python Fallback Keeps the Workflow First and Compound Words Stop Matching

Two gaps that v0.17.18.0 left open are closed. When the daemon cannot answer, the Python fallback now matches the native scorer's order. That holds on a prompt that names a workflow and an executor. The lexical lane gave partial word credit. It stopped reading a compound as an extension of a short word. So sk-git can declare its sweep switch. That does not pull "auto review this PR" off sk-code.

&nbsp;

## What's New at a Glance

- The Python fallback keeps the workflow owner first.
  - Two prompts used to list the CLI hub first.
  - That was in a degraded answer.
  - One is "run a deep research loop with the cli-pi executor".
  - The other is "create a spec folder for this feature and use cli-codex to write the code".
  - The fallback now keeps `system-deep-loop` or `system-spec-kit` first.
  - It puts the hub directly below it, 0.001 lower.
  - The native scorer does the same.
  - A plain delegation still lists the hub first.
  - One example is "delegate this refactor to codex".
  - This corrects v0.17.18.0.
  - That release said the fallback had no such guard.
- An iteratively phrased review with an executor ranks the same on both scorers.
  - The fallback reads a loop word beside "research" or "review".
  - It reads that as a request for the deep-loop workflow.
  - The native explicit lane does the same.
  - So "Review this change iteratively using cli-opencode as the executor." returns `system-deep-loop` at 0.82.
  - The hub sits at 0.819 on both.
- A compound word no longer counts as a longer form of a short one.
  - The lexical lane gave partial credit.
  - It did so whenever a skill word began with a prompt word.
  - So "auto" matched `autoreap`, "open" matched `opencode` and "launch" matched `launchpad`.
  - Credit now needs the extra letters to read as a suffix.
  - `plan` to `planning`, `converge` to `convergence` and `deploy` to `deployment` still match.
  - A second word added on does not.
  - A compound whose second word starts with a vowel still matches.
  - One example is `openai`.
- Naming the sweep switch reaches sk-git.
  - sk-git now declares `speckit_worktree_autoreap` and `worktree autoreap`.
  - So "how do I set SPECKIT_WORKTREE_AUTOREAP=0" routes to sk-git.
  - It routes there instead of returning nothing.
  - "auto review this PR" stays on sk-code.
  - In the Python fallback that prompt ranks sk-git first at 0.71.
  - That is below the 0.8 threshold.
  - So a strict degraded answer still returns nothing.

&nbsp;

## Upgrade

No action is needed. Rebuild `dist/` so the daemon serves the new partial-credit rule. It reindexes sk-git's metadata on its own.
