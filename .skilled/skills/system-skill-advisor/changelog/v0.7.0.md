This release lands the system-skill-advisor portion of the 028 MCP-to-CLI dual-stack program. The `system_skill_advisor` daemon gains a daemon-backed CLI front door, `node .opencode/bin/skill-advisor.cjs`, exposing all nine tools over the same daemon the MCP registration uses, with the registration unchanged. The program-wide phases sit under the same parent. Warm-only CLI fallbacks give the Claude Code and Codex advisor hooks another route, while the OpenCode plugin gains a CLI fallback and runtime permission allowlists let runtimes invoke the CLI without prompting.

> Spec folder: `.opencode/specs/system-spec-kit/028-mcp-to-cli-tool-transition/003-skill-advisor-cli/`

## Why This Release

The advisor surface includes mutations, so CLI calls default to untrusted and mutation tools require an explicit grant.

---

## What's New at a Glance

- **The daemon now has a CLI front door for all nine tools.** The new command reaches the same daemon used by the MCP registration.
- **CLI mutations require an explicit trust grant.** Native MCP callers receive trust only through an environment-block declaration.
- **Claude Code and Codex hooks gain warm-only CLI fallbacks.** The OpenCode plugin also gains a CLI fallback route.
- **Runtime permission allowlists cover CLI invocations.** They let runtimes invoke the CLI without prompting.

---

## CLI Access

#### Nine Tools on the Daemon

`node .opencode/bin/skill-advisor.cjs` exposes the four `advisor_*` tools, four `skill_graph_*` tools and the internal propagation tool as CLI commands over the same daemon and IPC socket used by the MCP registration. `list-tools --format text` enumerates them offline. Every other command validates its arguments against the existing schemas and speaks JSON-RPC to the daemon.

&nbsp;

#### Shared CLI Results

The CLI shares its exit taxonomy with the sibling `spec-memory` and `code-index` CLIs: `0` for success, `1` for runtime error, `64` for usage or schema error, `69` for protocol or `dist` mismatch and `75` for retryable daemon error. Natural exit waits for output writes to drain, avoiding the 64KB pipe-truncation hazard shared across the three CLIs.

&nbsp;

#### Warm-Only CLI Calls

`--warm-only` uses `SYSTEM_SKILL_ADVISOR_CLI_WARM_ONLY` and `SYSTEM_SKILL_ADVISOR_CLI_PROMPT_TIME` as environment defaults. It probes the advisor socket first and exits `75` instead of cold-starting the daemon from a hook. The dist-freshness guard refuses stale builds with exit `69` and `SYSTEM_SKILL_ADVISOR_CLI_DEV_ALLOW_STALE=1` is the development override.

---

## Trust

#### CLI Mutations Need a Grant

CLI calls are untrusted by default. The mutation tools `advisor_rebuild`, `skill_graph_scan` and apply-mode `skill_graph_propagate_enhances` require `--trusted` or `SYSTEM_SKILL_ADVISOR_CLI_TRUSTED=1`, the maintainer path. An untrusted mutation attempt is refused with exit `64`.

&nbsp;

#### Native MCP Trust Has One Path

The daemon fails closed when transport `_meta` carries no trust context. Native MCP registrations grant trust only through `SYSTEM_SKILL_ADVISOR_TRUST_DEFAULT=trusted` in their env block, a deployment-time declaration callers cannot forge at request time. A dedicated trust-gate fuzz scenario joined the manual-testing playbook.

---

## Runtime Integrations

#### Warm-Only Hook Fallbacks

The shared `hooks/lib/skill-advisor-cli-fallback.ts` helper gives the Claude and Codex `user-prompt-submit` advisor hooks a warm-only CLI path. The hooks probe the socket first, call the CLI only when the daemon is warm and fail open in about a millisecond when it is not. Gate 2 routing keeps working while the MCP transport is down.

&nbsp;

#### OpenCode's CLI Route

The `.opencode/plugins/system-skill-advisor.js` plugin gains a CLI fallback route through `mcp-server/plugin-bridges/system-skill-advisor-bridge.mjs`. Its primary bridge path is unchanged.

&nbsp;

#### Runtime Calls Without Prompts

`.codex/settings.json` allowlists CLI invocations for Codex. The Claude allowlist lives in local-only settings by decision, letting the runtimes invoke the CLI without prompting.

---

## Upgrade Notes

- No migration is required. The MCP registration and Python facade (`skill_advisor.py`) keep working unchanged.
- Run `node .opencode/bin/skill-advisor.cjs list-tools --format text` to enumerate the tools offline. Mutations need `--trusted`.
- If native mutations are rejected as untrusted, verify `SYSTEM_SKILL_ADVISOR_TRUST_DEFAULT=trusted` is present in the MCP registration env block.
- The new environment flags are documented in system-spec-kit's `mcp-server/ENV-REFERENCE.md`.
