# v1.2.0.0, the embedding lane off the prompt path

The advisor routes prompts without a running local model server by default.

&nbsp;

## What's New at a Glance

- The embedding lane's default weight is `0`. Prompts no longer wait for the local model server. To turn it back on, set its weight to `0.05` in `SPECKIT_ADVISOR_LANE_WEIGHTS_JSON` (removed in system-skill-advisor v2.0.0.0).
- `advisor_status` reports `lane_weight_zero` without a per-prompt warning.
- The embedding provider pointer resolves at daemon start. It resolves to the one registered model. It skips backend probing. The legacy embedding path is gone.
- The hf model server stays off unless `SPECKIT_SKILL_ADVISOR_MODEL_SERVER_ENABLED=1`. That switch was removed in system-skill-advisor v2.0.0.0.
- The server exits when its launcher dies. The launcher stops a server whose heartbeat file is over three minutes old.

&nbsp;

## How It Was Checked

The recorded ablation scored 149 of 193 prompts with the lane and 150 without.

&nbsp;

## Upgrade Notes

Live confidences rise about 5% because the lane no longer counts in the weight total. The labeled corpus had 196 prompts and no embeddings. That matches how the lane ran with the local model server down. The change altered no route and added no fire for a prompt whose answer is none.
