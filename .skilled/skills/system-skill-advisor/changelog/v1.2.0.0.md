# v1.2.0.0, Ollama off the prompt path

The advisor routes prompts without a running Ollama server by default.

&nbsp;

## What's New at a Glance

- The semantic lane's default weight is `0`. Prompts no longer wait for Ollama. Set `SPECKIT_ADVISOR_LANE_WEIGHTS_JSON` to `'{"semantic_shadow":0.05}'` to turn it back on.
- `advisor_status` reports `lane_weight_zero` without a per-prompt warning.
- The embedder pointer resolves to the one registered model at daemon start. The pointer skips backend probing. The legacy embedding path is gone.
- The hf model server stays off unless `SPECKIT_SKILL_ADVISOR_MODEL_SERVER_ENABLED=1`.
- The server exits when its launcher dies. The launcher stops a server whose heartbeat file is over three minutes old.

&nbsp;

## How It Was Checked

The recorded ablation scored 149 of 193 prompts with the lane and 150 without.

&nbsp;

## Upgrade Notes

Live confidences rise about 5% because the lane no longer counts in the weight total. The labeled corpus had 196 prompts and no embeddings, matching how the lane ran when Ollama was not running. The change altered no route and added no fire for a prompt whose answer is none.
