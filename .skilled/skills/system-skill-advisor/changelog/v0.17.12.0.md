# v0.17.12.0, A Packet Changelog Request Reaches sk-doc

A request such as "write a changelog for this packet" ranked system-spec-kit first, because "spec folder" lifts the spec workflow and the corpus-study rule read "packet-local" as research vocabulary. The advisor now treats the named folder as the source of the change history and ranks sk-doc's changelog mode first.

> Spec folder: `specs/system-speckit/054-weak-model-spec-authoring/027-alignment-preexisting-gaps` (Level 2)

&nbsp;

## What's New at a Glance

- **The verb has to govern the changelog.** The rule fires when create, write, add or draft is followed by a changelog noun phrase, with only articles or words such as nested, packet or release between them. "Add a nested phase to the packet for the changelog work" stays spec-folder work.
- **Other skills keep their routes.** The rule adjusts only sk-doc and system-spec-kit, so later bonuses still apply to every other skill. "Save context for this packet, then write a changelog" still reaches `memory:save`, and a `/speckit:plan` prompt still reaches the spec-kit command.
- **15 golden prompts lock the behavior.** Five sk-doc changelog cases sit beside ten controls that must keep their current route.

&nbsp;

## Upgrade

Rebuild the advisor runtime with `npm --prefix .skilled/skills/system-skill-advisor/runtime run build` so the scorer change takes effect.
