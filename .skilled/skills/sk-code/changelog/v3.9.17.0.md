# The Intent Table Matches Routing

The hub's intent table now matches the twelve intents. The deterministic router uses those intents. Readers can see what actually routes.

&nbsp;

## What's New at a Glance

- The table names the routed intents.
  - The table replaces TESTING and LANGUAGE_STANDARDS with JAVASCRIPT, TYPESCRIPT, PYTHON, SHELL and RUST.
  - The machine block does not contain TESTING or LANGUAGE_STANDARDS.
  - The five language rows use the machine block's keywords.
- Routing behavior stays the same. The machine-readable router block did not change.

No action is needed.
