# The Intent Table Matches Routing

The hub's intent table now matches the twelve intents that the deterministic router uses, so readers can see what actually routes.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/002-baseline-and-routing-correctness` (Level 2)

&nbsp;

## What's New at a Glance

- **The table names the routed intents.** It replaces TESTING and LANGUAGE_STANDARDS, which the machine block does not contain, with JAVASCRIPT, TYPESCRIPT, PYTHON, SHELL and RUST. The five language rows use the machine block's keywords.
- **Routing behavior stays the same.** The machine-readable router block did not change.
