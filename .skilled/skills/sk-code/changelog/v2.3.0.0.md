# v2.3.0.0, A Setup Battery for the Hub

The README battery for adapting sk-code was six commands copied by hand. Its route probe could pass a hub that routes nothing. `/doctor:sk-code setup` runs the adaptation checks as one read-only pass. It names the repair command for each failing leg. The adaptation guide was rewritten around that check. OpenCode is the native surface. Webflow and Obsidian are optional examples. You can remove or keep them.

&nbsp;

## What's New at a Glance

- **The hub has a doctor setup check.** `/doctor:sk-code setup` runs eight legs from the repository root. The hub `SKILL.md` and README point to it after you add or remove a surface.
- **OpenCode is the native surface.** The surface list now names it native. Webflow and Obsidian are optional examples. The adaptation guide covers keeping, removing or adding a surface.
- **A pasted probe line reruns the same prompt.** The setup report shell-quotes the probe prompt. So quotes or special characters in your prompt no longer change what a pasted line runs.
