# v3.9.8.0, CI Routing Reads Cost Requests and Leaves Git Releases Alone

A request to cut CI cost went to the documentation skill. A plain git release request went to the GitHub Actions surface. The CI surface's vocabulary now fits both cases. The hub's feature catalog lists the features its modes ship.

&nbsp;

## What's New at a Glance

- **CI cost requests reach the CI surface.** These requests now route to `sk-code-ci`. They are "Cut our CI costs", "reduce CI spend on this repo" and "make the CI pipeline cheaper". So do "halve our GitHub Actions minutes" and "our GitHub Actions bill is too high". The new phrases name CI, Actions or runner minutes. Examples are `ci cost`, `ci spend`, `ci bill`, `reduce ci costs`, `cut ci minutes`, `ci pipeline cheaper`, `ci runs cheaper`, `make ci cheaper`, `runner minutes`, `github actions minutes`, `github actions bill` and `github actions cost`. A pipeline, a run or minutes count only next to a cost word. So a request for meeting minutes stays out. So does a flowchart of the CI pipeline stages. So does a heatmap of CI minutes. So does a blog post about CI costs.
- **A failing CI pipeline reaches the CI surface.** "Fix the failing CI pipeline" and "debug the CI pipeline" route to `sk-code-ci`. They route through `failing ci`, `ci failure`, `ci is failing`, `broken ci` and `debug the ci`.
- **A git release stays with git.** The aliases `release workflow` and `deploy workflow` became `github actions release workflow`, `github actions deploy workflow`, `release workflow yaml` and `deploy workflow yaml`. So "tag the version and follow the release workflow" no longer routes to the CI surface.
- **The feature catalog covers the mode features.** New entries describe the quality gate and the repository quality config. They describe `/doctor:sk-code` and `/doctor:ci` with its switches. They describe the review reach rule.

&nbsp;

## Upgrade

No action is needed. A release request that relied on the bare `release workflow` phrase should name GitHub Actions. That applies when the request needs to reach the CI surface.
