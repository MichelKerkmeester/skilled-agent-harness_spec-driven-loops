# v3.12.7.0, The Rust Route Docs Match What the Router Loads

Two alignment runs on the Rust work found the docs ahead of the router in three places. The bracketed Rust keywords never parsed, so `#[napi]` routed nowhere. Several docs and scenarios said a task loads the language-shared folder because it touches more than one language, but the router adds that folder only for an intent that maps it. LS-007 named `src/main.rs`, so it could pass with the new app-crate words removed. This release brings the docs and scenarios in line with the route and fixes the parser.

&nbsp;

## What's New at a Glance

- The RUST keyword list parses whole.
  - Moving `#[napi]` and `#[wasm_bindgen]` to the end of the list in v3.12.6.0 did not help, because the parser still stopped at their `]` and dropped them. `sk-code-skilled` v2.3.1.0 fixes the parser.
- The shared folder loads by intent, never by language count.
  - `shared/references/stack-detection.md` section 3 and `ROUTER.md` sections 3 and 4 say `sk-code-skilled/references/shared/` joins only for IMPLEMENTATION, VERIFICATION or HOOKS.
  - The never-overrides paragraph no longer says a parity task loads the shared guidance.
- The RUST row names every marker the detector takes.
  - It adds `napi_rs`, `#[napi]`, `wasm_bindgen`, `#[wasm_bindgen]`, `wasi` and `cdylib`, and says any one marker is enough.
- The playbook expects what the route loads.
  - SD-002, LS-001 to LS-006 and the LS-005 and LS-006 scenario files drop `sk-code-skilled/references/shared/` from their expected refs, since none of their prompts scores an intent that maps it.
  - The LS-006 and LS-007 triage steps say one Rust marker is enough.
  - LS-007 moves its sandbox to the gitignored `.skilled/skills/.state/skc-LS007-sandbox/`, drops `src/main.rs` from the prompt and adds a prompt-only replay step. A `/tmp` sandbox left the surface `UNKNOWN` once the prompt named no `.rs` file.
- The hub names Rust.
  - The `SKILL.md` description, the `sk-code-skilled` row and `description.json` list Rust beside TypeScript, Python and shell.
  - The two-axis routing catalog entry gains a SKILLED language sub-detection section.

&nbsp;

## Upgrade

No migration required. A scenario run that checked for `sk-code-skilled/references/shared/` on a one-intent review prompt now expects it absent.
