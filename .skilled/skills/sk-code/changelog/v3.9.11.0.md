# v3.9.11.0, Review Reads Detection from the Quality Runner

The review mode no longer carries a copy of surface detection. It asks the quality runner which surfaces and checklists apply to each file, so the shared detection contract now names one reader fewer and points review at the runner.

> Spec folder: `specs/sk-code/017-portable-code-modes/005-review-floor-lens-overrides` (Level 2)

&nbsp;

## What's New at a Glance

- **One reader fewer in the detection table.** `stack-detection.md` lists review's resolver step, which reads the runner's `--explain` output instead of matching markers itself.
- **Review ids are checked against the contract.** A new shared suite fails when a review lens id is one the contract fixes, when a review floor id is one it leaves open, or when the review TODO rule stops naming the hygiene ids a repository can switch off.
