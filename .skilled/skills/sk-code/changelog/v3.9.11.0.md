# v3.9.11.0, Review Reads Detection from the Quality Runner

Review mode no longer carries a copy of surface detection. It asks the quality runner which surfaces and checklists apply to each file. So the shared detection contract now names one reader fewer. It points review at the runner.

&nbsp;

## What's New at a Glance

- One reader fewer in the detection table.
  - `stack-detection.md` lists review's resolver step.
  - That step reads the runner's `--explain` output instead of matching markers itself.
- Review ids are checked against the contract.
  - A new shared suite fails when a review lens id is one the contract fixes.
  - The suite fails when a review floor id is one it leaves open.
  - The suite fails when the review TODO rule stops naming the hygiene ids a repository can switch off.
