# v3.11.5.0, The Router-Sync Guard Fails on a Missing Registry

The router-sync guard read the surface inventory from the mode registry, and with the file missing it read an empty list and passed.

&nbsp;

## What's New at a Glance

- **A missing registry is a failure.** Check 2 of `verify-router-sync.cjs` reports a missing `mode-registry.json`. The other checks do not read the inventory and are unchanged.
- **The surface is named for what it holds.** `sk-code-skilled` and its router are titled the Skilled surface, not the opencode surface.
