# v3.6.0.0, The Quality Gate Proves What It Claims

This release follows 3.5.0.0. It carries sk-code-quality 1.10.0.0 to the hub. The code family's author gate stops lending authority it cannot prove. A layer that names a checker is green only when that checker can run. A declared build output is checked with no file written anywhere. A fifty-file run finishes under a second. A framework checklist no longer reaches a repository the runner cannot read.

&nbsp;

## What's New at a Glance

- **The quality gate proves the checker a hook names.** A `present` pre-commit layer now means one thing. The named checker resolves to an executable file. A hook names a deleted checker. It reads `broken` with the path to install. The layer state decides whether a finding on an untouched line blocks the run. So that authority now rests on a checker that will actually scan.
- **A declared build output is checked with nothing written.** The runner declares the dist entries this repository ships. It sends each one to the freshness checker on its read-only path. So the verdict holds. No cache record appears beside the output. The contract states what the guard hashes and what stays outside it.
- **A fifty-file run finishes under a second.** One bounded workspace listing replaces three whole-tree walks. A named-file scope reads none of it. The recorded command reads 0.72 s to 0.98 s. Before the change it read 1.97 s to 2.32 s. That is the budget the measurement phase gates on.
- **The spec-folder checklist stays in this repository.** A base-layer row may carry a repository condition. So a foreign repository holding a `specs/` folder no longer receives the framework's spec-folder standard. The shared doctrine, the surface declarations and the route are unchanged.
- **A review round tightened four edges.** A declared build output is checked against the package that builds it. It is not reported unmatched. A `--files` run bounds its guard snapshots. It covers only the folders its named files sit in. A repository-configured check skips a declared build output. A hook that quotes its checker variable resolves to the checker. It does not read `broken`.

&nbsp;

## Upgrade

No migration required. A repository that wants its own build outputs checked declares them in the `generated` rows of its quality config. A consumer that reads the layer states gains one sharper meaning for `broken`. That meaning now names an installed layer whose checker cannot run.
