# v3.9.6.0, The Surface Step Gives a Path a Reader Can Follow

The step that adds a surface to the hub pointed at the shared workflow docs with a link that had nothing to resolve against, so a reader had to work the target out alone. The step now gives the folder by its repository path and spells out the link to write.

> Spec folder: `specs/sk-doc/070-repo-doc-debt/005-reference-and-coverage-fixes` (Level 2)

&nbsp;

## What's New at a Glance

- **The step gives the shared workflow docs folder by its repository path.** You can open `.skilled/skills/sk-code/shared/references/` straight away instead of inferring it from a relative link.
- **The link target to write is spelled out.** The step shows `../../shared/references/<file>`, so a set of links copied into a new packet resolves to the real files.

&nbsp;

## Upgrade

No action is needed. This is a documentation change, so the hub routes and loads exactly as it did.
