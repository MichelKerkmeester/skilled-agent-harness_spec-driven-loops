# v4.2.3.0, Mobile-CLI Leaves the sk-code Hub

The retired `sk-code-mobile-cli` surface for Pi Remote Mobile-CLI work is removed from the `sk-code` hub's advertised, detected, routed and bundled surfaces, preventing mis-routed requests and an unreachable mode. The packet directory is retired separately.

## What's New at a Glance

- **The `sk-code` hub has five modes.** Two are workflow modes and three are surface modes.
- **The surface's routing and detection entries are removed.** `ROUTER.md` loses the `MOBILE_CLI` intent key, and `shared/references/stack-detection.md` loses the `PI_REMOTE` detection block and its markers (`app-mobile/`, `app-relay/`, `packages/pi-*`).
- **Pi Remote Mobile-CLI requests resolve to no mobile surface.** This includes requests shaped around `app-mobile/`, Svelte design-system, token or editability topics.
- **The `v4.2.2.0` notes are marked superseded, not rewritten.** Those notes record what the releases did.

## Upgrade

No migration required.
