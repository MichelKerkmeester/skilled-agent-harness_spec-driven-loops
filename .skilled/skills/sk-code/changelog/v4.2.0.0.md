# v4.2.0.0 purpose-first README rewrite

The sk-code README now reads as a purpose-first narrative instead of a reference card. It opens with a one-line pitch and a problem-first OVERVIEW, keeps the AT A GLANCE table first and adds a code work contract grid, a FAQ and a verification section. The rewrite changes no hub behavior: every mode, surface, routing and related-document fact from the previous README survives while the routing contract is untouched.

## What Changed

#### Documentation

- **README rewritten purpose-first** -- the README previously opened with a feature grid. It now leads with the problem code work creates and the outcome the hub delivers, then carries the same mode and surface facts in the new section model. The version field moves from 4.1.0.0 to 4.2.0.0.
- **Changelog entry added** -- this entry records the rewrite and points at the two files involved.
