This follow-on alignment release brings `sk-code`'s smart router and bundled assets up to the `sk-doc` skill-authoring standard after the ponytail-based refinement. It tightens conformance and consistency without changing surface detection, routing precedence or the Iron Law. Routing behavior, the `STACK_FOLDERS` surface map and either Iron Law line are also unchanged.

> Spec folder: `.opencode/specs/skilled-agent-orchestration/142-sk-code-ponytail-based-refinement/007-sk-code-asset-router-alignment` (Level 2)

## What's New at a Glance

- **`SKILL.md §2 SMART ROUTING` now shows both canonical router elements.** The section adds a Resource Loading Levels table for ALWAYS, CONDITIONAL and ON_DEMAND plus an UNKNOWN_FALLBACK disambiguation checklist, the two elements the canonical `sk-doc/assets/skill/skill-smart-router.md` standard makes visible inline. Both mirror `references/smart-routing.md`, which keeps the heavy `INTENT_SIGNALS` / `RESOURCE_MAP` pseudocode factored out, so the surface-first two-axis design and the deferral are preserved. Only the canonical surface is now readable in `SKILL.md`.
- **The authoring checklists now follow the asset template.** The five files in `assets/opencode/checklists/*_authoring.md` failed `validate_document.py --type asset` because they began with `## 1. PURPOSE` instead of the required `## 1. OVERVIEW`. Each now opens with `## 1. OVERVIEW` carrying a `### Purpose` and a `### Usage` subsection (the old WHEN TO USE content), with `---` dividers and renumbered sections. The checklist content is preserved verbatim.
- **The always-loaded router references now use accurate, unique links.** `stack_detection.md` and `phase_detection.md` are part of the always-loaded `DEFAULT_RESOURCE` preamble, where accuracy matters on every route, so their stale labels (`code_surface_detection.md` / `intent_classification.md` / `resource_loading.md`) and duplicate links were removed. The labels now match the real filenames (`stack_detection.md` and `smart_routing.md`), while `smart_routing.md` itself was left unchanged to avoid risking its guard for no gain.

## Upgrade

No migration required. The router additions are read-time prose, the checklist edits are structural and the reference fixes change link text only. Run `python3 .opencode/skills/sk-doc/scripts/validate_document.py .opencode/skills/sk-code/SKILL.md --type skill` and `verify_stack_folders.py` to confirm the router and surface map still resolve.
