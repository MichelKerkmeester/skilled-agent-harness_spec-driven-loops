# v2.0.0.0, Nested Parent Hub

sk-code is now a nested parent hub with five mode packets over a shared surface-detection router.

- The flat two-axis skill gives way to the nested parent hub.
- The hub has five mode packets.
- They are `implement`, `quality`, `debug`, `verify` and `review`, over a shared surface-detection router.

Review joins the hub.

- The review doctrine is folded in as the `code-review` mode.
- At this scaffold phase, the packets are skeletons and content relocation follows.
