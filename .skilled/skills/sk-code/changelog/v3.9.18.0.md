# v3.9.18.0, The CI Fixture and Quality Config Match the Repository

This release lets the foreign-repository profile load its fixture and gives the quality gate repository-owned settings.

> Spec folder: `specs/sk-code/017-portable-code-modes/012-verification-and-release` (Level 2)

&nbsp;

## What's New at a Glance

- **The foreign-repository fixture has its identity helper.** It copies `repository-identity.cjs`, so the copied `ci-profile.cjs` loads and step 1 runs.
- **The quality gate reads this repository's config.** It adds optional `actionlint` for workflow files, disables no hygiene rule and passes the quality doctor with 0 errors.
- **The review playbooks install the hub.** The three foreign-repository scenarios copy `sk-code` into the reviewing runtime's skills folder, so a rerun reaches the review contract instead of a prose-only answer.
