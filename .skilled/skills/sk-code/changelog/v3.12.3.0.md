# v3.12.3.0, Browser Inspection and Page-Speed Claims Go Through the Browser-Use Hub

`SKILL.md` sent pure browser inspection to "the relevant MCP skill" without naming one, and a page-speed claim needed no measured number.

&nbsp;

## What's New at a Glance

- `SKILL.md` sends pure browser inspection to the `mcp-browser-use` hub, which routes to its Chrome DevTools, Aside or Bladebro mode.
- `sk-code-frontend/references/web-performance-and-loading.md` (1.0.6.0) asks a claimed LCP, CLS or INP improvement for a baseline and a current number from the same page under the same conditions, measured through any browser mode the user has installed. Without both numbers the claim says NOT MEASURED and gives the reason.

&nbsp;

## Upgrade

No action is needed. A page-speed claim now carries its two numbers or says why it has none.
