# v4.2.2.0, PI_REMOTE Detection and sk-code-mobile-cli References

v4.2.2.0 makes `PI_REMOTE` detection match the current SvelteKit app and folds the `sk-code-mobile-cli` surface's thirteen new routable references and checklists into the machine `RESOURCE_MAP` union. The Webflow, OpenCode and Motion.dev surfaces were not touched. v4.2.3.0 removes the `sk-code-mobile-cli` surface and its `PI_REMOTE` detection from the hub, so v4.2.2.0's mode set is not the hub's current one.

## What's New at a Glance

- **`PI_REMOTE` detection no longer targets the pre-migration React app.** It was keyed to `apps/pi-remote-web` and "React 19 / Vite / Tailwind 4 / style.css", which failed to match the current `app-mobile/` SvelteKit tree. Its markers, keywords and aliases now target Svelte and `app-mobile`.
- **`ROUTER.md` §11 `RESOURCE_MAP` extends the `sk-code-mobile-cli/` union.** It adds the surface's nine new source-grammar/verification references and four checklists, kept exactly equal to the child §2b map.

## Upgrade

No migration required.
