# v3.9.12.0, One Rule Id Grammar for Every Reader

The review report checker now validates the rule ids on a report's `Rule sources:` line. It reads the id pattern from the shared rule-overrides linter rather than keeping its own, so a change to the grammar reaches both at once.

> Spec folder: `specs/sk-code/017-portable-code-modes/006-review-agent-and-dispatch` (Level 2)

&nbsp;

## What's New at a Glance

- **The linter exports `RULE_ID`.** Any reader that checks a rule id outside a `## Rule overrides` section uses the linter's own pattern.
- **The contract reference says so.** `rule-overrides.md` names the export beside `lintOverrides` and `loadContract`.
