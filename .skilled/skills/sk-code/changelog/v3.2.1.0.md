This phase-child release declares sk-code's side of the cross-skill authoring-time load contract for `.opencode/` targets. It pairs with the `system-spec-kit/SKILL.md` §16-17 update and the `cross_skill_authoring_load` block in the `/speckit:complete:auto` and `:confirm` YAMLs (packet 078/002). It closes 077 findings F-009-001, F-009-002, F-008-004 and F-006-004.

> Spec folder: `specs/skilled-agent-orchestration/078-opencode-authoring-recipe/002-spec-kit-load` (Level 1)

## What's New at a Glance

- **The `Cross-Skill Consumption` block maps authoring guidance to `.opencode/` targets.** In `sk-code/SKILL.md`, it identifies the authoring checklist and `spec_folder_write` recipe for each target type, surfaced before writes rather than only at review-time. The pull-side contract is documented in `system-spec-kit/SKILL.md`.
- **`/speckit:complete` loads `sk-code` at two points.** Step 10 loads it for authoring on `.opencode/` targets and surfaces invariants for the writer to honor. Step 11 keeps the review-time load as before, which catches drift.

## Upgrade

No migration required. This is a doc-only declaration of an existing-but-undocumented contract. Orchestrators that already loaded `sk-code` at review-time gain a recommended authoring-time pre-load for `.opencode/` targets.
