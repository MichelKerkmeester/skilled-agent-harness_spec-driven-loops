# v3.11.6.0, The Pre-Claim Gate Rereads the Request

The Pre-Claim Gate checked the evidence for the work that was planned. It never asked whether the plan covered the whole request. A new row asks that before any status claim.

> Spec folder: `specs/other/006-repo-wide-unlazy-tail/002-request-reread-at-close`

&nbsp;

## What's New at a Glance

- **A Reread row joins the gate.** It sits between Record and Claim in `workflow-verify.md`. Each outcome in the request needs recorded evidence or a note that it is not done.
- **The mode it routes to changed.** sk-code-quality v1.13.19.0 shipped. Routing is unchanged.
