# v2.2.4.0, Tests Live Under tests/

The shared style guide now says where test code goes and how folders are named, on every surface. Before, each surface guide said something slightly different, and several runtimes kept tests beside their source or in folders such as `__tests__`.

> Spec folder: `specs/system-deep-loop/036-deep-loop-innovation/029-align-runtime-code-with-sk-code-opencode` (Level 2)

## What's New at a Glance

- **No folder name starts and ends with two underscores.** Name a folder for what it holds, such as `fixtures/` or `helpers/`. When a tool picks such a name by default, configure the tool instead, as vitest's `resolveSnapshotPath` does for snapshots.
- **Test code lives under the package's `tests/` folder.** Tests, fixtures and helpers all go there, and a test never sits beside the file it covers.
- **A `tests/` folder may stay flat.** Group tests by area only when a group holds several files, so the tree does not grow folders that each hold one test.

## Upgrade

No migration required. The sk-code-opencode checker's new `--check-folders` flag finds folders that break the naming rule.
