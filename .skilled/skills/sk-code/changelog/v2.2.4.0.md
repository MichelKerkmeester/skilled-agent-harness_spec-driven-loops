# v2.2.4.0, Tests Live Under tests/

The shared style guide now says, on every surface, where test code goes and how folders are named. Before, each surface guide said something slightly different. Several runtimes kept tests beside their source or in folders such as `__tests__`.

## What's New at a Glance

- **No folder name starts and ends with two underscores.** Name a folder for what it holds, such as `fixtures/` or `helpers/`. A tool may pick such a name by default. Then configure the tool instead. Vitest's `resolveSnapshotPath` does this for snapshots.
- **Test code lives under the package's `tests/` folder.** Tests, fixtures and helpers all go there. A test never sits beside the file it covers.
- **A `tests/` folder may stay flat.** Group tests by area only when a group holds several files. Then the tree does not grow folders that each hold one test.

## Upgrade

No migration required. The sk-code-skilled checker has a new `--check-folders` flag. It finds folders that break the naming rule.
