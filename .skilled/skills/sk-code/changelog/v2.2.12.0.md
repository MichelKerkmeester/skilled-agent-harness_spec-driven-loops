# v2.2.12.0, Typo-Proof Script Options

The review, quality, Webflow and OpenCode helper scripts used to ignore a misspelled option and run as if it were not there. Each one now names the option it does not know and exits 2 before it does any work.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/021-open-ends-remediation/001-typo-proof-parsers` (Level 1)

&nbsp;

## What's New at a Glance

- **A mistyped option fails loudly.** `check-dist-staleness.sh`, `check-comment-hygiene.sh`, `minify-webflow.mjs`, `verify-router-sync.cjs` and the three review checkers print the unknown option and exit 2.
- **An unreadable file no longer counts as clean.** `check-comment-hygiene.sh` exits 3 when an input file cannot be read. Exit 2 still means a staged file was skipped, so the commit hook keeps treating 2 as a pass and now blocks on 3.
- **`check-rule-copies.js --root` needs a value.** A bare `--root` used to fall back to the current folder. It is now an error.

&nbsp;

## Upgrade

Replace any misspelled option with the one the script's usage line lists.
