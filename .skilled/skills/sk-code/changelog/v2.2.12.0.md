# v2.2.12.0, Typo-Proof Script Options

The review, quality, Webflow and OpenCode helper scripts used to ignore a misspelled option. They ran as if it were not there. Each one now names the option it does not know. It exits 2 before it does any work.

&nbsp;

## What's New at a Glance

- A mistyped option fails loudly.
  - `check-dist-staleness.sh`, `check-comment-hygiene.sh`, `minify-webflow.mjs` and `verify-router-sync.cjs` print the unknown option and exit 2. The three review checkers print the unknown option and exit 2.
- An unreadable file no longer counts as clean.
  - `check-comment-hygiene.sh` exits 3 when an input file cannot be read.
  - Exit 2 still means a staged file was skipped.
  - So the commit hook keeps treating 2 as a pass.
  - The commit hook now blocks on 3.
- `check-rule-copies.js --root` needs a value.
  - A bare `--root` used to fall back to the current folder.
  - A bare `--root` is now an error.

&nbsp;

## Upgrade

Replace any misspelled option with the one the script's usage line lists.
