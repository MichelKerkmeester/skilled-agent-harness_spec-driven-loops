# v3.9.19.0, One Authored Mode Vocabulary

The mode vocabulary now has one authored home in `hub-router.json`. A check fails when another file drifts from it. The quality mode also routes the two checklist terms. Its trigger line already advertised them.

&nbsp;

## What's New at a Glance

- **`hub-router.json` is the one authored mode vocabulary.** A new check fails when another file disagrees with it. The check is `.skilled/skills/sk-doc/sk-create-skill/scripts/ci-hub-vocabulary-source.cjs`. It checks the registry aliases and the root `ROUTER.md` intents. It also checks each packet `Keyword triggers:` line.
- **The quality mode routes its checklist terms.** `sk-code-quality` gains `authoring checklist` and `skilled checklist`. Its Keyword triggers line advertised both terms. No mode routed them.
- **The check leaves this hub's router alone.** Its stage-two leg does not apply to `sk-code`. That is because `ROUTER.md` is a surface and phase router. Every route there loads `DEFAULT_RESOURCE`. `verify-router-sync.cjs` owns the mode-to-leaf agreement.

&nbsp;

No action is needed.
