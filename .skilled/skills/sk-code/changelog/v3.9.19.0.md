# v3.9.19.0, One Authored Mode Vocabulary

The mode vocabulary now has a single authored home in `hub-router.json`. A check fails when another file drifts from it. The quality mode also routes the two checklist terms its trigger line already advertised.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/004-single-vocabulary-source` (Level 2)

&nbsp;

## What's New at a Glance

- **`hub-router.json` is the one authored mode vocabulary.** A new check, `.skilled/skills/sk-doc/sk-create-skill/scripts/ci-hub-vocabulary-source.cjs`, fails when the registry aliases, the root `ROUTER.md` intents or a packet `Keyword triggers:` line disagree with it.
- **The quality mode routes its checklist terms.** `sk-code-quality` gains `authoring checklist` and `skilled checklist`, the two terms its Keyword triggers line advertised that no mode routed.
- **The check leaves this hub's router alone.** Its stage-two leg does not apply to `sk-code`, because `ROUTER.md` is a surface and phase router whose every route loads `DEFAULT_RESOURCE`. `verify-router-sync.cjs` owns the mode-to-leaf agreement.
