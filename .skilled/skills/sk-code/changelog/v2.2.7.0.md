# v2.2.7.0, The Session's Surface Breaks Surface Ties

A prompt that matches two code surfaces equally now lists the surface your session is working in first. Before this release, generic words such as `typescript`, `vitest` or `json` decided the lead surface, so a Webflow animation test plan opened with the OpenCode packet.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/011-round-four-remediation/008-session-aware-tie-break` (Level 1)

&nbsp;

## What's New at a Glance

- **The hub passes the session's surface to the router.** `SKILL.md` now tells the agent to run the existing surface detection on the working directory and the files it is editing, then call the front door with `--surface-hint`, for example `--surface-hint WEBFLOW`.
- **A hint only reorders, never changes what loads.** The hinted surface moves ahead of the other matched surfaces. Quality and review keep first place, and the packets and bundle kind stay the same.
- **No hint keeps the old order.** With no hint, `UNKNOWN` or a surface the prompt did not match, bundles follow the tie-break order OpenCode, Obsidian, Webflow as before. Other hubs ignore the flag.
