# v3.9.2.0, A Workflow Path Review Keeps the Review Mode

A review request could name only a workflow file. One under `.github/workflows/` is an example. That request routed to the CI surface alone. It dropped the review mode. That is because the CI vocabulary counted the workflows path twice. The path now counts once.

&nbsp;

## What's New at a Glance

- **A path-only workflow review bundles review and CI.** The review mode leads. The CI surface rides as evidence. That matches a request that says GitHub Actions workflow.
- **A quality request on a workflow file stays with the quality mode.** It routes to the quality mode alone. That is what its scenario expects. The quality gate still attaches the CI checklist. It does so through its path-based selection.
- **The review mode moves to v1.9.2.0.** See its changelog for the report, cache and benchmark changes.

&nbsp;

## Upgrade

No migration is required.
