# v3.9.2.0, A Workflow Path Review Keeps the Review Mode

A review request that named only a workflow file, such as one under `.github/workflows/`, routed to the CI surface alone and dropped the review mode, because the CI vocabulary counted the workflows path twice. The path now counts once.

> Spec folder: `specs/sk-code/016-review-mode-followups` (Level 2)

&nbsp;

## What's New at a Glance

- **A path-only workflow review bundles review and CI.** The review mode leads and the CI surface rides as evidence, the same as for a request that says GitHub Actions workflow.
- **A quality request on a workflow file stays with the quality mode.** It routes to the quality mode alone, as its scenario expects, and the quality gate still attaches the CI checklist through its path-based selection.
- **The review mode moves to v1.9.2.0.** See its changelog for the report, cache and benchmark changes.

&nbsp;

## Upgrade

No migration is required.
