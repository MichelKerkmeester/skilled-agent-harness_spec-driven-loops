# v3.12.2.0, Frontend Verification Names the Browser-Use Hub

The `sk-code-frontend` row in the router's verification table asked for "the page rendered in a browser" and named no tool, so nothing pointed an agent at the browser tooling the repository ships.

&nbsp;

## What's New at a Glance

- The row now asks for the changed page opened through the `mcp-browser-use` hub, in whichever browser mode the user has installed: Chrome DevTools, Aside or Bladebro. Users differ in which one they run, so no single mode is required.
- The evidence is a screenshot at the affected viewport and the console showing no new errors, or NOT RUN with the reason, such as no browser mode installed.
- The agent uses a browser session it owns and opens the user's signed-in browser only when the user asks.

&nbsp;

## Upgrade

No action is needed. A frontend completion claim now cites rendered-page evidence from any browser-use mode, or says why it could not be gathered.
