# v3.9.9.0, Every Floor Rule Has an Id

The universal floor said a surface could only add rules. It also carried this repository's own preferences. It assumed every codebase shared them. Each floor rule now has an id. A repository can name that id in a `## Rule overrides` section. Each rule also has a mark that says whether it may. The rules that stay fixed are the hard floor of the shared override contract.

&nbsp;

## What's New at a Glance

- Every floor rule has an id and a mark.
  - Parse faults, conflict markers, credential signatures, hardcoded secrets and input validation are FIXED.
  - So are silent failures, initialization safety, resource cleanup and accessibility.
  - Commented-out code, comment pointers, tests, error messages, typing, naming and documentation are overridable.
- Precedence replaces add-only.
  - The floor now points at the override contract's order.
  - That order is the hard floor, then the repository checklist, then a specific surface, then the SKILLED fallback.
- House rules left the floor.
  - Required docstrings on public APIs now live in the SKILLED checklists.
  - So do strict TypeScript without `any`, Python hints and the camelCase and snake_case examples.
  - The floor keeps a universal form of each.
  - Type checks pass.
  - Names follow the declared convention.
  - Complex code explains why.
- Wiring is labelled as this repository's.
  - The write-time, pre-commit and CI hygiene layers move to the quality mode's own description of this repository's wiring.
  - The floor says only one thing.
  - The verdict's `layers` field reports what a repository has.
- An unknown surface gets no house style.
  - The surface gets the floor and the runner's built-in checks.
  - The surface also gets what its own quality config names.
  - Each comes with its overrides applied.
- A test keeps the marks honest.
  - The linter suite fails when a FIXED mark and the contract's floor list disagree.
  - The suite also fails when a floor rule has no id.

&nbsp;

## Upgrade

No action is needed. A repository that wants a floor rule changed names its id. The id goes in a `## Rule overrides` section of a checklist its config already lists.
