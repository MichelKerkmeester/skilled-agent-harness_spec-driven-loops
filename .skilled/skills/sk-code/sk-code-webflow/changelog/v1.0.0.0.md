# v1.0.0.0, The Webflow Surface Is Established

This is the first release of the `webflow` surface packet. The Webflow frontend evidence that previously lived scattered across the workflow modes (`code-implement/references/webflow/` + `assets/webflow/`, `code-debug/references/webflow-debugging/`, `code-verify/references/webflow-verification/`, `shared/references/webflow-shared/`) is now consolidated under one read-only surface packet on the sk-code hub's surface axis.

## What's New at a Glance

- **`SKILL.md` defines when the hub bundles this surface.** It provides a full reference map and sets non-negotiable frontend standards for CDN runtime reality, interaction-gated loading, Core Web Vitals as a gate and focus/forms accessibility. The surface contract also describes the on-demand asset tier.
- **`README.md` gives the packet at-a-glance and layout.** `references/` covers CSS, HTML and JavaScript standards, implementation and performance patterns, CDN deployment and cross-language shared guidance. It also includes browser debugging and verification.
- **Assets are available on demand.** `assets/` includes integrations, patterns, templates, scripts and surface checklists.
- **The packet is reached only by the hub bundling it alongside a workflow mode.** It is read-only and invisible to the advisor. It never routes as a primary and mutates nothing.

## Upgrade

No migration required.
