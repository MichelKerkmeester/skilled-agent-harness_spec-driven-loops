# v1.1.0.0 - webflow README rewritten

Second release of the `webflow` surface packet. The README moves from the older tabular reference-card style to the purpose-first narrative standard the mcp-obsidian pilot set and the refined skill README template codified. A human reader now gets a one-line pitch, a problem-first OVERVIEW, a numbered section model and a verification close, with every fact from the prior README preserved.

## New

- Purpose-first README: a one-line pitch blockquote after the H1, a problem-first OVERVIEW and the numbered ALL-CAPS H2 section model with `---` dividers.
- A frontend evidence layer table that maps every reference domain (language standards, implementation, performance, deployment, debugging, verification, shared) to its folder.
- QUICK START, HOW IT WORKS, FAQ and VERIFICATION sections that explain detection, bundling, the read-only surface axis and the non-negotiable gates.

## Changed

- README version field bumped from 1.0.0.0 to 1.1.0.0.
- The LAYOUT section is gone, its content folded into the evidence layer table, HOW IT WORKS and RELATED DOCUMENTS.
- Two Oxford comma violations from the old prose were removed so the README passes the Human Voice Rules punctuation checks.

## Not Changed

- The frontmatter identity (`title: webflow` with its trigger phrases) and the surface contract facts (`packetKind: surface`, read-only, advisor-invisible, never a primary).
- SKILL.md, the references, the assets and the playbook stay untouched. This release is README-only.
