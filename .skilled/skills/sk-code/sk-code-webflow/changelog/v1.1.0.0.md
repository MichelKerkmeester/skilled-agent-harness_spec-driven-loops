# v1.1.0.0, Webflow README Rewritten

This second, README-only release of the `webflow` surface packet replaces its tabular reference-card style with a purpose-first narrative README. The `mcp-obsidian` pilot set this standard and the refined skill README template codified it. Readers now get a one-line pitch, a problem-first OVERVIEW, a numbered section model and a closing VERIFICATION section, while every fact from the prior README is preserved.

## What's New at a Glance

- **The README moves to a purpose-first structure.** A one-line pitch blockquote follows the H1, then a problem-first OVERVIEW and numbered ALL-CAPS H2 sections separated by `---`.
- **The frontend evidence layer connects reference domains to folders.** Its table covers language standards, implementation, performance, deployment, debugging, verification and shared.
- **Four sections explain the surface.** QUICK START, HOW IT WORKS, FAQ and VERIFICATION cover detection, bundling, the read-only surface axis and the non-negotiable gates. VERIFICATION closes the README.
- **The LAYOUT section is removed.** Its content moves into the evidence layer table, HOW IT WORKS and RELATED DOCUMENTS.
- **The README version field changes.** It advances from 1.0.0.0 to 1.1.0.0.
- **Punctuation is corrected.** Two Oxford comma violations from the old prose are removed.
- **The README identity and surface contract are unchanged.** Its frontmatter identity is `title: webflow` with its trigger phrases, and its surface contract facts are `packetKind: surface`, read-only, advisor-invisible and never a primary.
