# v1.1.3.0, Skipped Callbacks Are Reported

The minified runtime test runs timer, animation frame and `Webflow.push` callbacks in place, and it stops at a depth of 20 so a polling loop cannot overflow the stack. Until now it stopped without a word, so an error inside a callback past the cap could never show and the file still read PASS. The test now prints how many callbacks it did not run, under that file's PASS line.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/012-post-merge-deep-review/002-webflow-runtime-and-references` (Level 1)

&nbsp;

## What's New at a Glance

- **The depth cap is visible.** `test-minified-runtime.mjs` counts the callbacks it skips at the cap and prints `⚠ N callback(s) past depth 20 were not run, so errors inside them were not checked` for that file. Pass and fail stay as they were, because a polling loop reaches the cap by design.
- **No dead evidence pointers.** The scroll interceptor reference no longer lists two spec files that exist nowhere in this repository.
