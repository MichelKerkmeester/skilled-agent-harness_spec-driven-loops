# v1.9.4.0, A Reworded Verdict Line Is Still Checked

A review report could state one verdict in its summary and a different one on its status line and still pass, as long as the summary line was written as a list item or with a capital A. The checker now reads those forms too, and the suite that proves it runs on every change to the code skill.

> Spec folder: `specs/sk-code/016-review-mode-followups` (Level 2)

&nbsp;

## What's New at a Glance

- **Bulleted and title-case summaries are compared.** `- **Overall assessment**: ...` and `**Overall Assessment**: ...` are now held to the final `Review status:` line, so a contradiction in either form fails the check.
- **The review mode's tests run in CI.** The sk-code script tests workflow now runs the review mode's own suite, and it also starts when `AGENTS.md` changes, because the suite reads that file.

&nbsp;

## Upgrade

A report that disagreed with itself in one of these forms used to pass and now fails. Make the summary verdict match the status line. Nothing else is required.
