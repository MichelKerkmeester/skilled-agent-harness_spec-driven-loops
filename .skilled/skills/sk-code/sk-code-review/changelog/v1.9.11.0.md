# v1.9.11.0, The Routing Prose Comes First and the Resolver Algorithm Moves into the Doctrine

Section 2 is now eight lines of prose that name what selects the packet, the resource it loads first, the shared detection contract and where the machine router sits. The intent maps and the scoring code moved without a reword into a final `## 10. MACHINE ROUTER` appendix, and the entry point keeps the same selection and loading order. `## 3. The pseudocode block held two jobs. The router scores intents and loads resources, and it stays in the appendix. That algorithm now lives, byte for byte, in `review-core.md` section 9, beside the precedence and outcome tables it implements. One line in the router marks where it went.
