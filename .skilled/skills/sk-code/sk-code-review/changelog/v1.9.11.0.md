# v1.9.11.0, The Routing Prose Comes First and the Resolver Algorithm Moves into the Doctrine

The review packet opened with 312 lines of routing material. That was six prose subsections and a phase diagram. It also held two tables and a 282-line pseudocode block. The first check sat at line 415. Section 2 is now eight lines of prose. They name what selects the packet and the resource it loads first. They also name the shared detection contract and where the machine router sits. The intent maps and the scoring code moved without a reword. They now sit in a final `## 10. MACHINE ROUTER` appendix. The entry point keeps the same selection and loading order. `## 3. HOW IT WORKS` starts at line 63.

The pseudocode block held two jobs. The router scores intents and loads resources. It stays in the appendix. The rule-override algorithm read the quality runner's explain output. It seated each checklist and picked the winning row per file. It also formatted the `Rule sources:` line. That algorithm now lives, byte for byte, in `review-core.md` section 9. It sits beside the precedence and outcome tables it implements. One line in the router marks where it went.
