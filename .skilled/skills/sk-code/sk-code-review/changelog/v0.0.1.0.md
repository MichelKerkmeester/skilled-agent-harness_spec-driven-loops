# v0.0.1.0, The Metadata Block Drops an Unused Author Line

The review surface SKILL.md carried an author line inside its metadata block. Nothing read it, it was not true, and the fields beside it are the ones the router and a review run act on. It is gone, and a review reads a change exactly as it did before.

> Spec folder: `specs/sk-code/017-portable-code-modes/015-frontmatter-yaml-validity` (Level 2)

&nbsp;

## What's New at a Glance

- **One field fewer to trust.** The metadata block now holds only the family the router reads, so nothing in the header asks a reader to believe a claim no code checks.
