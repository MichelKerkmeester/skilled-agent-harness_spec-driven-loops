# v1.9.10.0, The Foreign-Repository Playbooks Install a Copy of the Hub

The three foreign-repository scenarios ended at a live review of a fixture outside this repository. Their fixture build wrote the repository's own files and nothing else, so the reviewing runtime found no `sk-code` skill and answered in prose with no `Rule sources:` line. The build now copies the hub into the runtime's skills folder, and a rerun reaches the review contract.

> Spec folder: `specs/sk-code/017-portable-code-modes/012-verification-and-release` (Level 2)

&nbsp;

## What's New at a Glance

- **A rerun as written reaches the review contract.** Each fixture build copies `.skilled/skills/sk-code` into `$SCRATCH/.devin/skills`, so the review reads the same floor, lens and `Rule sources:` line the scenario expects.
- **The copy is a copy, not a link.** A reviewer with write permission works inside the scratch folder and cannot change a tracked file.
