# v1.8.0.0, Every Matching Surface Is Named

Reviews now name every surface the code matches, rather than a single one. The minimum review rules that no repository, surface or added mode may lower now sit in one section, and the rule check fails when someone rewords one of them.

&nbsp;

## What's New at a Glance

- **Surface evidence lists every match.** The "Surface evidence used" line shows each matching surface in detection order. Specific surfaces come first and SKILLED comes last, so a specific match leads and SKILLED stays as second evidence.
- **The removed surfaces no longer appear.** Surface detection no longer carries the markers of the two surfaces the hub removed, so a review never reports them.
- **Six floors are written down.** The Extension Floors section lists the review minimums. A repository, a surface packet or an added mode may add checks beside them, but none may lower, skip or reword one.
- **The rule check pins each floor.** `check-rule-copies.js` fails when a floor line is reworded, and its tests cover that case.
- **Workflow files load the CI rules.** A review that names only a `.github/workflows/` path now loads the CI rules as well.

&nbsp;

## Upgrade

No migration required. Anything that reads the surface evidence line should expect several labels, in order, where it used to expect one.
