# v1.9.0.0, The Author Quality Gate Belongs to the Quality Mode

Review and the quality mode both claimed the phrase quality gate, so a request that used it could land in either. Review keeps review work and hands the author-side gate to `sk-code-quality`.

> Spec folder: `specs/sk-code/015-quality-agnostic-gate/005-consumers-and-routing` (Level 2)

&nbsp;

## What's New at a Glance

- **The review triggers drop the phrase.** The activation list and the keyword list no longer carry quality gate, so a request that asks for that gate reaches `sk-code-quality` alone.
- **A run verdict is input evidence.** A review reads a verdict when one exists and keeps its own `P0`, `P1` and `P2` ids, so no gate count renumbers or replaces a finding.

&nbsp;

## Upgrade

No migration required. A request that used the words quality gate to reach review now reaches `sk-code-quality`, which owns that gate.
