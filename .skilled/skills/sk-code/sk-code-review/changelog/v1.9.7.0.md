# v1.9.7.0, The Review Docs Describe the Floor, the Lens and the Verdict

The review README still described a single baseline plus surface and had no word for the `Rule sources:` line or the severity verdict. It now describes the shipped behavior, and the playbook gained scenarios for repositories that do not share the default style.

> Spec folder: `specs/sk-code/017-portable-code-modes/010-docs-and-doctor-alignment` (Level 2)

&nbsp;

## What's New at a Glance

- **The README says floor and lens.** "Baseline Plus Surface" became "Floor, Default Lens And Surface", with the fixed floor, the default lens, the precedence and the `Rule sources:` line in the summary template.
- **The agent's verdict is documented.** A paragraph states that the `@review` agent keeps no checklist, that any P0 or open P1 means `REQUESTED_CHANGES`, and that its 100-point score is advisory. The single-pass reference retires the older verdict words.
- **Three foreign-repository scenarios were added.** One is a repository that wants almost no inline comments and gets no documentation finding. One wants a comment on every function and gets a finding when it is missing. One is a floor override refused at every layer. Each was run with a live review, and the report checkers passed.
- **The playbook index is extended.** A new section and a wave row cover the three scenarios, the later sections moved down by one, and the existing scenario ids are unchanged.
- **The summary template matches the output contract.** The README's example uses the contract's `X files, Y lines changed` placeholders, which also clears a count claim the README checker could not derive.
- **The scripts README matches the folder.** A broken relative path to the shared linter is fixed, which also clears the setup battery's drift guard, and the fixture list names all sixteen fixtures.
