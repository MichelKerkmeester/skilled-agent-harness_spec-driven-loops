# v1.7.0.0 — natural source comments replace the retired inline marker grammar

The Mobile-CLI surface now teaches the comment convention piloted by the app: existing MODULE and
numbered box-drawing banners stay, while module headers, markup labels, per-part purpose lines, and
greppable frozen-seam notes use plain human language.

## Changed

- Rewrote `references/comment-grammar.md` as the single source for banners, module and markup labels,
  purpose comments, four edit classes, seam reading, and the `Do not edit — <why>` convention.
- Folded the useful editability model into `references/editability-guardrails.md`, including the
  scanner's guardrail-fence counter re-anchored to `Do not edit —`.
- Removed `references/ds-grammar.md`; rewired the leaf RESOURCE_MAP, hub RESOURCE_MAP, README, routing
  scenarios, and related references to `comment-grammar.md`.
- Replaced live authoring instructions that used the retired inline syntax with durable-WHY prose.

## Why

The app's presentation seams remain enumerable and safe to audit, but authors now write comments that
read naturally at the edit site instead of learning a special prefix vocabulary.
