# v1.2.7.0, Spec Scratch Is Left Alone

The alignment drift guard reported 278 warnings, and 244 of them came from throwaway scripts in spec `scratch/` folders and archived packets. A real warning in shipped code was easy to miss among them.

> Spec folder: `specs/sk-git/033-git-setup-customization/011-remaining-limits` (Level 1)

&nbsp;

## What's New at a Glance

- **Spec scratch and archives are skipped.** The guard no longer scans `scratch/` and `z_archive/` folders under `specs/`. The same folders elsewhere are still scanned, and spec code outside them still is too.
- **The warnings left are worth reading.** The shipped files it flagged were fixed at their source, so the count falls from 278 to 8, all of them in spec research records.

&nbsp;

## Upgrade

No migration required.
