The docs for `run-all-drift-guards.sh` promised three drift guards, while the wrapper runs two: the alignment-drift verifier and the stack-folder verifier. They now say two. The third, the router-sync suite, is retired, and a note after the guard calls records what it checked.

> Part of [Skilled v4.0.0.2](../../../../changelog/skilled/v4.0.0.2.md).
>
> Spec folder: `specs/system-skill-advisor/030-pi-skill-orchestrator-based-research-refinement` (Level 2)

## What's New at a Glance

- **The docs count the guards the wrapper runs.** Every page that describes the drift gate now says two guards, and so does the wrapper's own header.
- **The docs say nothing checks router equality now.** The alignment reference named a guard that compared the routing map with its files. It now says that guard was deleted and nothing replaced it.
