# v0.1.1.0, Tests Everywhere Under tests/

The Obsidian plugin guidance now points every test at the plugin's `tests/` folder. It used to allow tests beside their source in some places, which disagreed with the shared rule every other surface follows.

> Spec folder: `specs/system-deep-loop/036-deep-loop-innovation/029-align-runtime-code-with-sk-code-opencode` (Level 2)

## What's New at a Glance

- **Every test belongs under `tests/`.** The skill and its verification checklist both say so, and neither suggests a test beside its source.
- **No folder uses a double-underscore name.** Use `fixtures/` or `helpers/` instead of names such as `__tests__`.

## Upgrade

Move any test that sits beside its source into `tests/` the next time that area changes.
