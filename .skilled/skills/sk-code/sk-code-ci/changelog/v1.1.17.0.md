# v1.1.17.0, The README Names the Keyword Guard

The CI keyword rows have been checked against the hub's JSON since v1.1.16.0, but the README did not say so. A reader editing one copy could not tell from it which check would catch a mismatch. The README now names that check. No rule, reference, router or profile changed.

> Spec folder: `specs/sk-code/hub-architecture/007-ci-vocabulary-single-source`

&nbsp;

## What's New at a Glance

- **A Keyword copies row in the verification table.** It runs check 2 of `verify-router-sync.cjs`.
- **The row says what the check compares.** The `CI_WORKFLOW` rows in the hub and packet routers against the `code-ci-aliases` and `code-ci-runtime` classes of `hub-router.json`.
- **The row says why this packet is compared.** The hub lists it under `vocabularyMirrors`.
