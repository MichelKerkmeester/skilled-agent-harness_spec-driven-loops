# v1.13.14.0, The Prose Lines Are Short Sentences and Lists

Twelve prose lines in the packet ran from 418 to 1,170 characters. Most were a whole resource note or workflow step written as one line. Each one now reads as short sentences with one idea each. So a reader meets one rule at a time.

&nbsp;

## What's New at a Glance

- **The resource notes are scannable.** The runner, the ceiling report and the repository-config paragraph each keep every clause. Each now breaks one claim per line. So a reader can stop at the sentence they need.
- **The workflow step is readable.** Step 3 keeps its default, `--base <ref>` and `--files <path>...` forms. It then gives `BLOCKED`, `UNVERIFIED`, `NOTHING_CHECKED` and `ERROR` their own line.
- **Nothing was dropped.** Every path, code span and section number is still here. That includes `.skilled/skills/sk-code/sk-code-quality/repository/quality.json` and `references/quality-config.md` section 3.
- **No rule changed.** The ALWAYS, NEVER and ESCALATE IF lists are untouched. The machine router and its projections are byte-identical.

&nbsp;

No action is needed. The runner reads the same paths. `--explain` still decides the checklists.
