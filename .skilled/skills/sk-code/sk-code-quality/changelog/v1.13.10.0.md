# v1.13.10.0, The Quality Frontmatter Parses Under a Strict YAML Parser

The quality SKILL.md said the gate runs after implementation, before verification. That sentence needs a colon. The colon sat in an unquoted value. A strict YAML parser read it as the start of a nested mapping. So the parser refused the block. The gate itself ran on either way. The value is quoted now. Its wording is unchanged. The metadata block also loses the `author: OpenCode` line. Nothing read that field, and it was not true.

&nbsp;

## What's New at a Glance

- **The description is quoted.** A strict YAML parser reads the quality frontmatter. The sentence that says when the gate runs reads exactly as before.
- **The unused author line is gone.** The metadata block no longer claims OpenCode as its author. So the header states only the family the router reads.
