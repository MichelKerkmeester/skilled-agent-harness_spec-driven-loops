# v1.13.13.0, The Routing Prose Is Short and the Router Moved to the End

`sk-code-quality` now reaches its instructions first. SMART ROUTING is eight lines of plain prose instead of 102 lines of diagrams and tables, and the route map, the prompt-intent projection and the call sequence sit unchanged in a final `## 9. MACHINE ROUTER` section.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/005-sk-code-hub` (Level 2)

&nbsp;

## What's New at a Glance

- **The routing section is prose.** Eight lines say what selects the mode, what it loads first and where the router is, so a reader meets the quality gate without scrolling past a router.
- **The router is at the end.** The QUALITY TASK tree, the phase tree, the python intent map and the call sequence moved byte for byte into `## 9. MACHINE ROUTER`, the last H2 of the file.
- **The resource reference stays.** Resource domains, loading levels, the target-path checklist map and the comment-hygiene gates keep their content under `## 3. RESOURCES`.

&nbsp;

## Upgrade

No action is needed. The router reads the same paths, and `--explain` still decides the checklists.
