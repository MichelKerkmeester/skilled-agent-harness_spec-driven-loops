# v1.13.13.0, The Routing Prose Is Short and the Router Moved to the End

`sk-code-quality` now reaches its instructions first. SMART ROUTING is eight lines of plain prose instead of 102 lines of diagrams and tables. The route map, the prompt-intent projection and the call sequence sit unchanged. They sit in a final `## 9. MACHINE ROUTER` section.

&nbsp;

## What's New at a Glance

- The routing section is prose.
  - Eight lines say what selects the mode.
  - The eight lines say what it loads first and where the router is.
  - So a reader meets the quality gate without scrolling past a router.
- The router is at the end.
  - The QUALITY TASK tree and the phase tree moved byte for byte.
  - So did the python intent map and the call sequence.
  - All of them sit in `## 9. MACHINE ROUTER`, the last H2 of the file.
- The resource reference stays.
  - Resource domains, loading levels, the target-path checklist map and the comment-hygiene gates keep their content.
  - That content stays under `## 3. RESOURCES`.

&nbsp;

## Upgrade

No action is needed. The router reads the same paths. `--explain` still decides the checklists.
