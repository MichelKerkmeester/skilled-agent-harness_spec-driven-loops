# v1.11.0.0, A Sibling Skill's Checklists Join the Run

This release follows the runner-limit release. A skill outside the hub could declare its own quality rows and the runner never read them, so its files met the hub's rows alone. It now reads those rows, refuses any row that leaves the skill that shipped it, and reports a row it cannot follow by name.

> Spec folder: `specs/sk-code/015-quality-agnostic-gate/005-consumers-and-routing` (Level 2)

&nbsp;

## What's New at a Glance

- **A sibling skill's rows reach the run.** The runner reads the `quality` block of every `graph-metadata.json` that names the hub's family, through the same surface discovery the labels come from, so a skill's checklist loads for a file it detected itself.
- **A row cannot leave the skill that declares it.** An absolute path, a `..` segment, a path that resolves outside the skill folder and a link that leads out are refused with `CHECKLIST_OUTSIDE_SKILL`, and the file is never read. Containment is decided on the deepest part of the path that exists, so a link above a name that is not there is refused before anything tests it. Both ends are compared in their on-disk spelling, so a link to the skill's own file written in another case stays inside.
- **A malformed block or row is reported, not skipped.** An unknown key, an empty list, a row with no selector, a non-dotted extension and a value that is not a JSON object all read `CHECKLIST_ROW_INVALID`, so a declaration nobody could follow never looks like no declaration.
- **A row belongs to the skill that detected the file.** Two skills may share a label or a skill id, and each one's rows now apply only to the files it detected, resolved against its own folder.
- **A private folder name is matched in any case.** A folder called `Local-Folder` used to slip past the private-name match and reach the envelope, which no tracked file may name. It prints as its label now, in either spelling.
- **A row that names a folder is missing.** Only a regular file satisfies a row, so a folder spelled like a checklist reads `CHECKLIST_MISSING`.
- **One bad row stops the verdict.** The gate reads `ERROR` and exits 3, ahead of any `BLOCKED` another check found.

&nbsp;

## Upgrade

No migration required. A skill that declares checklists in its `graph-metadata.json` now has them loaded, and one whose rows leave its own folder is refused until the path points inside it.
