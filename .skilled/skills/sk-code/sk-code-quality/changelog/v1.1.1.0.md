# v1.1.1.0, The Quality Mode Names the Hooks That Run

The quality mode told readers that two legacy files were its gates. Those files were the pre-commit gate and the write-time gate. Neither file is installed. This release names the hooks that do run. So the gate an operator is told will block a commit is the gate that blocks it.

&nbsp;

## What's New at a Glance

- **The live hooks are named.** The pre-commit block is `.skilled/scripts/git-hooks/pre-commit`. It is installed through `core.hooksPath`. The write-time warning is `.skilled/hooks/post-edit-quality/claude/claude-posttooluse.cjs`. It is wired in `.claude/settings.json`. The older `.skilled/hooks/git/pre-commit` and `scripts/hooks/claude-posttooluse.sh` are marked as helpers. They are kept for direct tests.
- **Current names throughout.** `SKILL.md` still used the names from before the rename. It now says `sk-code-webflow`, `sk-code-skilled`, `sk-code-review` and `sk-code-quality`.
- **Spec folders route to system-spec-kit.** The README no longer sends spec folders to the OpenCode checklist folder. That folder has no spec-folder checklist.
- **The checker commands run.** The README runs `check-comment-hygiene.sh` and `check-dist-staleness.sh` directly. Both are Python programs. So the old `bash` form failed.

&nbsp;

No migration required.
