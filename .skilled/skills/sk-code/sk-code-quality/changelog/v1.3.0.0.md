# v1.3.0.0, The Quality Floor Splits Into a Baseline and a Web Overlay

The always-loaded checklist was a web house style. Its P0 items, such as the 67-character header and IIFE wrapping, bound every `.js` or `.css` file, including ESM modules where IIFE wrapping conflicts with the skilled JavaScript checklist. The operator chose to split the floor. Every pass now loads the surface-neutral baseline, and the house-style checklists load only for `.js` or `.css` targets.

&nbsp;

## What's New at a Glance

- **A surface-neutral baseline.** The ALWAYS row, `DEFAULT_RESOURCE` and the workflow, rules and success steps now name `../sk-code-skilled/assets/checklists/universal-checklist.md`.
- **A conditional web overlay.** A new CONDITIONAL row loads `overview-header-and-comments.md` and `naming-init-formatting-and-css.md` for a `.js` or `.css` target.
- **The P0 rule is unchanged.** A P0 item still blocks completion. Fewer P0 items bind a file by default.
- **CQ-001 tracks the new set.** The quality-gate playbook scenario lists the resources `DEFAULT_RESOURCE` now names.

&nbsp;

## Upgrade

No migration required. `RESOURCE_MAP["QUALITY"]` is unchanged.
