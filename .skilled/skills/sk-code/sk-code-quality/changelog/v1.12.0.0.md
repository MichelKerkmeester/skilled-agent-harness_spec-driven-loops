# v1.12.0.0, The Gate Is Measured for What It Catches and What It Costs

This release answers the two questions the mode could not answer before. Nobody knew what the gate catches on a change with a known defect, and nobody knew what a run costs. A live measurement now records both, a rendered report states each result against its target, and seven playbook scenarios let a reader replay every verdict for themselves.

> Spec folder: `specs/sk-code/015-quality-agnostic-gate/006-measurement` (Level 2)

&nbsp;

## What's New at a Glance

- **The catch rate is measured.** A seeded change across six language families carries seven forbidden comment labels, and the gate blocked on all seven in a repository that declares no code surface at all.
- **The false-positive set stays clean.** Measurement ratios, encoding names, hash and RFC names, a status code and a CWE id produced no finding.
- **A full run fits the target.** The 50-file set finished in 1661 ms at the slowest of five full runs with both built-in checks running, against a 2 second target.
- **Every quality prompt reached the mode.** Four prompts, among them an agent edit, a CI workflow edit and a rails request, each resolved a single route to this mode.
- **Seven scenarios replay each verdict.** They cover a foreign polyglot change, a language with no comment family, a CI target, a private surface, an absent required tool, an envelope round trip and a restraint prompt.
- **The mode's own router knows the restraint and envelope words.** `envelope`, `restraint` and `yagni` now select the quality intent, so a request to read a gate envelope or to apply yagni no longer falls back to the default resources.
- **The report sits with the mode's other runs.** `benchmark/reports/` holds the curated folder, rendered from the measurement record, with the four measures and their targets in one table.

&nbsp;

## Upgrade

No migration required. The numbers describe the gate this release ships, so a later change to a sensor, a label pattern or a checklist moves them and earns a new run rather than an edit to this report.
