# v1.0.0.2: purpose-first README release

The quality mode README moves from a tabular reference card to a purpose-first narrative on the refined skill README template. A reader now meets the delivered outcome in the opening pitch, sees the checklist router as a named capability and finds every fact the old card carried, with clean command expectations and verified links.

## New

- `README.md` is rewritten purpose-first with a one-line pitch, a problem-first OVERVIEW and a Checklist Router capability table.

## Changed

- The frontmatter version field moves from `1.0.0.1` to `1.0.0.2` and every section follows the refined template's numbered ALL-CAPS H2 model with `---` dividers.

## Not Changed

- The mode contract stays intact. The mode still sits between implementation and verification, applies P0/P1/P2 author checks, runs comment hygiene per modified file and hands clean evidence to the surface verification workflow.
- `SKILL.md`, the checklists and the scripts keep their behavior. No behavior change ships with this release.
