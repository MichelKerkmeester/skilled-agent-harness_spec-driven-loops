# v1.4.1.0, The Quality Gate Follows the Hub's Current Surfaces

Two changes from the surface removal reached the quality gate without an entry. The gate's routing for the removed surface is gone, and the universal style guide now lives in this mode. The 1.2.0.0 entry still describes that routing as live, so this release corrects the record.

&nbsp;

## What's New at a Glance

- **The envelope names the detected surface.** The advisory envelope's `resolved_surface` field now lists the declared surface labels in detection order. It reads `unknown` when no surface matches. Before, it accepted only `skilled` or `unknown`.
- **No checklist loads for a removed surface.** The routing rows that pointed at the removed surface's checklists are gone, so the gate no longer names files that were deleted.
- **The style guide lives in this mode.** The universal code style guide moved here, and the comment hygiene check prints the new path.

&nbsp;

## Upgrade

Repoint any link that names the old shared path of the universal code style guide to `references/code-style-guide.md` in this mode. Anything that parses `resolved_surface` should accept declared surface labels in order, as well as `unknown`. No other migration is required.
