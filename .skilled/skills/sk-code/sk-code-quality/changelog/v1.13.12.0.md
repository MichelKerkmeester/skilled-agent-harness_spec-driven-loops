# v1.13.12.0, The Trigger Line Matches the Hub Router

The Keyword triggers line in `sk-code-quality` now advertises only the terms the `sk-code` hub routes to this mode, so a word another mode owns no longer sends work here. A new check keeps the line in agreement with `hub-router.json`.

> Spec folder: `specs/sk-doc/072-skill-routing-and-clarity/004-single-vocabulary-source` (Level 2)

&nbsp;

## What's New at a Glance

- **The line drops the words another mode owns.** `P0`, `P1` and `P2` are severity words review also uses. `skill authoring`, `agent authoring`, `command authoring` and `MCP server authoring` go to `sk-code-skilled`. `spec folder authoring` leaves the line as well.
- **Drift now fails a check.** `.skilled/skills/sk-doc/sk-create-skill/scripts/ci-hub-vocabulary-source.cjs` compares the line with `hub-router.json` and fails when they disagree.
