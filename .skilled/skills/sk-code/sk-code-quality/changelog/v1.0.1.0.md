# v1.0.1.0, A Dist Check That Reads Its Switch Like the Hooks

The dist freshness checker (the hook that warns when a compiled build is older than its source) has its own reader of `.skilled/hooks/hook-flags.env`, and that reader disagreed with the hooks on two kinds of line. Both now read the same, so `SYSTEM_DIST_FRESHNESS_DISABLED=1` turns the check off however the line is saved.

> Part of [Skilled v4.0.0.2](../../../../changelog/skilled/v4.0.0.2.md).
>
> Spec folder: `specs/sk-doc/062-doc-validation-off-switches` (Level 2)

## What's New at a Glance

- **A comment after the value no longer hides the switch.** `SYSTEM_DIST_FRESHNESS_DISABLED=1  # note`, the way the example file writes its lines, used to read as `1  # note` and leave the check on. A `#` after a space or tab now ends the value.
- **A byte order mark no longer hides the first line.** An editor that saves UTF-8 with a signature puts an invisible mark before the first line, and the checker read it as part of the first switch name. It now drops the mark, as the Node and Python readers do.

## Upgrade

- **Saved lines with a comment.** A line in `hook-flags.env` with a comment after its value now takes effect. If you saved one you did not mean to apply, comment the whole line out.
