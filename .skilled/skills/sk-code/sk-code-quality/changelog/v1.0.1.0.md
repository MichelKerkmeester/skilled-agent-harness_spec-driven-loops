# v1.0.1.0, A Dist Check That Reads Its Switch Like the Hooks

The dist freshness checker is a hook. It warns when a compiled build is older than its source. It has its own reader of `.skilled/hooks/hook-flags.env`. That reader disagreed with the hooks on two kinds of line. Both now read the same. So `SYSTEM_DIST_FRESHNESS_DISABLED=1` turns the check off however the line is saved. Part of [Skilled v4.0.0.2](../../../../changelog/skilled/v4.0.0.2.md).

&nbsp;

## What's New at a Glance

- A comment after the value no longer hides the switch.
  - The example file writes its lines as `SYSTEM_DIST_FRESHNESS_DISABLED=1  # note`.
  - That used to read as `1  # note` and leave the check on.
  - A `#` after a space or tab now ends the value.
- A byte order mark no longer hides the first line.
  - An editor that saves UTF-8 with a signature puts an invisible mark before the first line.
  - The checker read it as part of the first switch name.
  - The checker now drops the mark.
  - The Node and Python readers do the same.

&nbsp;

## Upgrade

- A line in `hook-flags.env` now takes effect when a comment follows its value.
- If you saved one you did not mean to apply, comment the whole line out.
