# v1.13.1.0, The Trust Gate Has Scenarios

The trust gate and the parallel syntax check shipped in the previous release without an operator scenario to prove them. The playbook now has one for each, plus one for malformed checklist rows in a skill outside sk-code. The shell tests that sat beside the scripts moved into `scripts/tests/`, and the skill, the READMEs and the playbook cite the new paths.

> Spec folder: `specs/sk-code/015-quality-agnostic-gate` (Level 2)

&nbsp;

## What's New at a Glance

- **The untrusted skip can be proven by hand.** The scenario shows a configured check reading as skipped, the repair line that grants trust and the check running after the grant.
- **The parallel pool has its own scenario.** It checks that a bounded pool returns the same findings as a serial run.
- **Malformed rows are covered.** A broken checklist row errors the run only where its skill applies and is listed as a warning elsewhere.
- **Tests live in one folder.** The comment-hygiene and ceiling-report tests sit under `scripts/tests/` with the Node tests.
- **The doctor README names the trust state.** It lists the new helper scripts and the three states the check reports.

&nbsp;

## Upgrade

A script or workflow that ran `scripts/check-comment-hygiene.test.sh` or `scripts/ceiling-report.test.sh` should call the file under `scripts/tests/` instead.
