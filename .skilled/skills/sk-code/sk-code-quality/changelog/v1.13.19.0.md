# v1.13.19.0, The Mode Names an Outcome No Check Covers

A task could reach verification with a requested outcome that no check covered. Every check then passed, and the outcome was never tested. The mode now rereads the request first.

> Spec folder: `specs/other/006-repo-wide-unlazy-tail/002-request-reread-at-close`

&nbsp;

## What's New at a Glance

- **The mode rereads the request.** ALWAYS item 9 in `SKILL.md` says to reread the request before the handoff to verification. It names any outcome the request asks for that no check covers.
- **The mode still claims nothing.** It may not claim completion, so the item is a note for the verifier. The idea comes from the unlazy skill repo.
