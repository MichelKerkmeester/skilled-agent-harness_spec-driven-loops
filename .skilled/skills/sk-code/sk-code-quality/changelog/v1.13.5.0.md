# v1.13.5.0, The Style Guide Keeps Only Universal Rules

Every quality run loaded a style guide written for this repository and, for any `.js` or `.css` file, three checklists of web house style. A repository with its own conventions got both and could not turn them off. The guide now holds only rules that hold anywhere, and the house style lives with the SKILLED surface that chose it.

> Spec folder: `specs/sk-code/017-portable-code-modes/003-quality-floor-and-style-split` (Level 2)

&nbsp;

## What's New at a Glance

- **A universal style guide.** It keeps few comments, WHY not WHAT, no commented-out code, no ephemeral pointers and surface-owned comment density. It adds the rule that a comment describes the code as it is now, never its history.
- **House style moved out.** The identifier and file-order tables, the 500-line split point, the line length, formatter picks, the `MODULE:` header, the `__tests__` ban and the top-level `tests/` rule now sit in the SKILLED references.
- **The `ceiling:` marker is opt-in.** The guide says a surface may define a marker for a deliberate shortcut, and the SKILLED surface defines `ceiling:`.
- **No default JavaScript or CSS checklist.** A `.js` or `.css` file in another repository gets only the universal floor. SKILLED files keep the same checks through the SKILLED surface.
- **Plugins behind the hub link count as hub code.** A file reached through the hub's `.skilled/plugins` link, which points outside `.skilled/`, now resolves to SKILLED, so the OpenCode plugins keep the SKILLED checklists instead of falling back to the floor alone.
- **Ask the runner, not a table.** The checklist map leaves this mode. `quality-gate.cjs --explain <path>` names a file's checklists and why, and the SKILLED surface renders this repository's map.
- **This repository's wiring is labelled.** The hygiene layer table now says it describes this repository, and the post-edit router, bypass and CI details join it.

&nbsp;

## Upgrade

No action is needed in this repository. A surface that relied on the JavaScript and CSS default rows declares its own checklist rows.
