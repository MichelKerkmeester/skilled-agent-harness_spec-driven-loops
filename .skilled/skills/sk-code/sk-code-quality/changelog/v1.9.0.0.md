# v1.9.0.0, Comment Text Comes From One Reader

The checker read text inside template literals as comments. It read heredoc bodies as comments too. Its bare string rule depended on where the string stood. The ceiling report also kept a second copy of the comment rules. Both tools now read one set of rules. The whole-tree run went from 63 findings in 41 files at f69e5cd2e8 to 0.

&nbsp;

## What's New at a Glance

- **A template literal is a string, even across lines.** A backtick opens a string that spans lines. A backslash before the closing backtick keeps it open. A Go raw string keeps no escapes.
- **A regex literal is skipped whole.** In the c family, a slash after an operator or a keyword opens a regex literal. Its body is read as code. So a backtick inside one opens no string. A slash after a block comment is decided on the token in front of that comment. So a comment leaves an expression standing, and a statement start opens a literal. Only a `*/` that closes a block comment counts. So a regex literal that ends in a star stays a literal. The slash after it divides. A slash after the `)` that closes a same-line `if`, `while` or `for` header opens a literal too. A name, a number, a closer, a word after a `.` and a postfix `++` or `--` divide. A call whose word is a keyword, such as `q.for(a)`, names a method rather than a header.
- **An interpolation reads as code.** `${...}` ends the template text at an unescaped opener. It runs to the brace that closes it. A template literal inside an interpolation is tracked on a stack. So a comment inside `${...}` is checked. The text around it is not.
- **A continued line ends with its statement.** A backslash continuation that ends in a string closes its logical line. So an attribute docstring after a continued statement is checked again.
- **A heredoc body is text.** The body ends at the line that holds only the opener's word. `<<-` matches that word after leading tabs. A here-string, an arithmetic shift and an arithmetic command such as `(( n << shift ))` open no body. An arithmetic expansion closes at the `))` that matches its opener. So a pair nested inside one does not end it early. One that runs past the line end carries its depth into the next line. So a shift on a continuation line opens no body either.
- **A bare string statement is comment text.** A Python string literal that opens a logical line at bracket depth 0 counts wherever it stands. That is because nothing reads its value. A prefix that holds `f` keeps it data.
- **Both tools read one table.** The ceiling report loads the checker from beside its own real path. It takes the family table from it. It takes each line's comment text from it too. The report's own rule copy is gone. A marker after an optional comment prefix still counts.
- **A table with no fallback family is refused.** The comment family table may hold no `hash` family for a file of unknown language. Then the report exits 2 with one line instead of raising `KeyError`. It refuses before it reads the first file.
- **The debt was paid where it stood.** 17 live comments in 12 files were rewritten to their durable reason. 43 frozen lines in 26 files took the `hygiene-ok` escape rather than an edit.
- **Three readings stay short of what bash and JavaScript do.** An `if`, `while` or `for` header split across lines keeps the division reading for a slash after its `)`. A `{} / 2` reads as a regex literal. That is because `}` usually ends a block. A `((cd x; cat <<EOF) | wc)` and a `$((cat <<EOF) )` are read as arithmetic. So a comment inside that real heredoc body is reported.

The extraction removed 3 findings. One sat inside a template literal. Two sat inside a heredoc body. The f-string count stayed at 0.

Measured 2026-10-26 against a TypeScript scanner over every tracked JavaScript and TypeScript file. That scanner finds 119,929 comment lines. The checker misses 7 of them. All of them are scanner artifacts that the base checker shares. That is against 8 before. It reports 1,220 lines the scanner does not. That is against 1,907 before. No tracked file ends inside an open string or heredoc. The whole-tree run still prints no finding.

&nbsp;

## Upgrade

No migration required for a normal run. A caller that copies `ceiling-report.sh` somewhere without `check-comment-hygiene.sh` beside it now gets exit 2 and one line naming the missing file. That is because the report no longer falls back to a rule copy of its own.
