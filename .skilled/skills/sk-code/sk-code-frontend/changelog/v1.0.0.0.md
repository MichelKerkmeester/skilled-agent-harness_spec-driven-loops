# v1.0.0.0, The Frontend Surface Is Established

The first `sk-code-frontend` release gives web work one written standard. The packet is a read-only surface on the `sk-code` hub's surface axis. It is bundled beside a workflow mode. It is never routed as a primary.

> Spec folders: `specs/sk-code/018-frontend-upstream-proposals/001-frontend-surface-mode` and `007-web-only-frontend` (Level 2)

&nbsp;

## Why This Release

Frontend practice lived in the head of whoever last shipped a screen. It was spread across the framework. Which element carries a behavior was review memory, not a reference. So was where a focus ring belongs. So was how a long list keeps its rows readable. So was what a Figma comparison must cover. A frontend change reviewed as an unknown surface loaded none of it.

&nbsp;

## What's New at a Glance

- **A core page and a web layer.** `references/frontend-practice.md` holds the practice the web layer implements. Then `references/web-markup-and-css.md` adds the DOM and CSS mechanics for the app in front of you.
- **Six web topic references, loaded by condition.** The files cover elements and attributes. They cover cascade and selectors. They cover layout and sizing. They cover accessibility patterns. They cover performance and loading. They cover internationalization.
- **A five-pass Figma check.** `references/figma-to-code.md` compares a built screen with its Figma frame in five passes. A pass that cannot run is marked `NOT RUN` with its reason. The overall verdict is `INCOMPLETE`.
- **An overrides contract.** A project records each change to a core or web-layer statement. It puts the change under a `Frontend overrides` heading in its own `SKILL.md`. It names the section, the kind of change and the reason.
- **Shared workflow doctrine through symlinks.** Implement, debug and verify arrive from `shared/references/`. They do not come from a forked copy.
- **Nothing is written.** The packet supplies evidence. The paired workflow mode applies it.

&nbsp;

## Upgrade

No migration required. The packet is additive. It edits no project file.
