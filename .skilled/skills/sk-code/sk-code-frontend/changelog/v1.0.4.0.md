# v1.0.4.0, Docs Read in Order and Render as Written

The mode's `SKILL.md`, `ROUTER.md`, `README.md` and its topic references were read file by file. They were read for readability, layout and structure. No rule, browser support line or Baseline date changed.

&nbsp;

## What's New at a Glance

- **Packed lines are lists.** The stacking-context triggers read one fact per line. So do the per-feature support lines for `field-sizing`, `interpolate-size` and `calc-size()`.
- **Two headings name what they hold.** The cascade reference's section 4 adds its state-selector contract. The layout reference's section 3 adds container sizing. Both keep their numbers.

## Upgrade

Anchor links to the cascade reference's section 4 take the new heading slug. Anchor links to the layout reference's section 3 do the same. References by number are unchanged.
