# v2.1.18.0, Docs Read in Order and Render as Written

The surface's `SKILL.md` and `README.md` were read file by file. So were its language references, shared references, checklists and asset READMEs. The reading looked at readability, layout and structure. No language rule, checklist item, drift guard or citation changed.

&nbsp;

## What's New at a Glance

- Smart Routing comes first.
  - `SKILL.md` section 2 is Smart Routing.
  - Section 3 is the Reference Map.
  - So a reader learns how the surface is reached before what it loads.
- Packed passages are lists.
  - The two-step language detection reads one fact per line.
  - So do the five non-negotiables and the checklist notes.
  - The README's count now matches its five rules.
- Duplicate comment rules are merged.
  - The Python, shell and TypeScript style guides each state their WHY-not-WHAT rule once.
- Pointers name real sections.
  - The Rust P1 checklist points at the P2 checklist's validation commands.
  - The TypeScript checklist's commenting note points at the code style guide's commenting section.

## Upgrade

A reference to `sk-code-skilled/SKILL.md` section 2 as the Reference Map moves to section 3. Smart Routing moves from 3 to 2.
