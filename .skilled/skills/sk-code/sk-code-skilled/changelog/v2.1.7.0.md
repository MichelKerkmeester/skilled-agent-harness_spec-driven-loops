# v2.1.7.0, The House Style Lives Here

The universal quality floor and style guide now hold only rules that hold in any codebase, so the preferences this repository chose for its own code needed a home. They live with the SKILLED surface, which loads only for this repository's code, and every SKILLED file gets the same rules it got before.

> Spec folder: `specs/sk-code/017-portable-code-modes/003-quality-floor-and-style-split` (Level 2)

&nbsp;

## What's New at a Glance

- **Naming, layout and formatting rules.** The identifier scheme, the `MODULE:` header note and the `ceiling:` marker join the naming and commenting reference. The top-of-file order, the 500-line split point, formatter picks and line length join the file organization reference. The double-underscore and `tests/` tree rules join the test conventions.
- **Docs and typing on the house checklist.** Doc comments on public APIs, strict TypeScript without `any`, Python hints without `Any` and internal helper docs are SKILLED checklist items.
- **JavaScript and CSS house checks.** The header, section, trailing-comma, data-attribute and animation checks now sit under `assets/checklists/js-css-style/` and load for SKILLED `.js` and `.css` files.
- **This repository's checklist map.** The skill renders the map from the quality defaults and the surface declarations, and a test fails when they differ.
