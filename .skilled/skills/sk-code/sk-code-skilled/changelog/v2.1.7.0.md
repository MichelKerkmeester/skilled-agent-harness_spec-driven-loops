# v2.1.7.0, The House Style Lives Here

The universal quality floor and style guide now hold only rules that hold in any codebase. So the preferences this repository chose for its own code needed a home. They live with the SKILLED surface. It loads only for this repository's code. Every SKILLED file gets the same rules it got before.

&nbsp;

## What's New at a Glance

- **Naming, layout and formatting rules.** The identifier scheme joins the naming and commenting reference. So do the `MODULE:` header note and the `ceiling:` marker. The top-of-file order and the 500-line split point join the file organization reference. So do formatter picks and line length. The double-underscore and `tests/` tree rules join the test conventions.
- **Docs and typing on the house checklist.** Doc comments on public APIs are SKILLED checklist items. So is strict TypeScript without `any`. So are Python hints without `Any` and internal helper docs.
- **JavaScript and CSS house checks.** The header, section and trailing-comma checks now sit under `assets/checklists/js-css-style/`. So do the data-attribute and animation checks. They load for SKILLED `.js` and `.css` files.
- **This repository's checklist map.** The skill renders the map from the quality defaults and the surface declarations. A test fails when they differ.

No action is needed.
