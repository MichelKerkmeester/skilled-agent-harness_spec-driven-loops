# v2.1.4.0, The Router Checker Cannot Hang on a Stuck git Daemon

The router-sync verifier asks `git check-ignore` which docs are local cache files before it looks for unrouted docs. That call waited with no limit, so a git fsmonitor daemon that stopped answering held the whole check open. It now has a ceiling.

> Spec folder: `specs/sk-git/035-fsmonitor-daemon-and-worktree-relocation-regression` (Level 2)

&nbsp;

## What's New at a Glance

- **The call skips the daemon.** It runs with `core.fsmonitor=false`, so a stuck daemon is never asked in the first place.
- **The call stops after 20 seconds.** If git still has not answered, the check finishes without the ignore filter. A git-ignored cache doc under the hub can then show up as an orphan, which is a visible failure rather than a hang.
