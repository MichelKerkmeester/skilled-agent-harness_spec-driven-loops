# v2.3.1.0, Bracketed Rust Keywords Route and the Rust Citations Name Their Source

The RUST keyword list holds `#[napi]` and `#[wasm_bindgen]`. The replay parser read a list only up to its first `]`, so both attributes were dropped, and the language detector did not know `#[napi]` at all. A prompt that named a `#[napi]` export beside a TypeScript client lost the Rust set. This release fixes both, adds a test that fails on the old code, and names the upstream commit behind every `rust-anything` citation.

&nbsp;

## What's New at a Glance

- **The keyword list parses whole.** `parseIntentSignals` in `assets/scripts/router-replay-lib.cjs` reads the list as whole quoted strings, so a `]` inside a keyword no longer ends it. Only the two RUST rows carry such a keyword today.
- **The detector takes `#[napi]`.** `detectSkilledLanguages` adds `#[napi]`. `#[wasm_bindgen]` already matched through `wasm_bindgen`.
- **A test pins the Rust words.** `scripts/tests/rust-language-vocabulary.test.cjs` checks that the RUST list parses past its attributes, that `clap cli`, `clap::`, `ratatui`, `crossterm`, `#[napi]` and `#[wasm_bindgen]` each keep the Rust set beside `client.ts`, that a path-less clap CLI loads the Rust set alone and that the bare word `clap` does not.
- **The Rust citations name their source.** `references/rust/quality-standards/overview-and-data-ownership.md` gives the rust-anything repository URL and the commit, `beed6fa45fc9` of 2026-11-26, that every `(rust-anything, <file>:<line>)` anchor refers to. The Rust checklist points at it.
- **The vocabulary prose matches the detector.** The RUST line in `ROUTER.md`, the Rust row in `README.md` and the detection note in `SKILL.md` name the clap, ratatui and crossterm words, the binding words and their attributes.
- **The shared tier loads by intent.** `SKILL.md`, `README.md` and the `ROUTER.md` overview say the hub adds a shared doc only for IMPLEMENTATION, VERIFICATION or HOOKS, and that this packet's own `DEFAULT_RESOURCE` opens the shared tier first for a reader who routes inside it.
- **Two scenarios stop promising SKILLED.** OC-007 and OC-009 replay this packet's router. Their prompts name no `.skilled/` path, so the hub on its own leaves the surface `UNKNOWN`, and each scenario now says so.
