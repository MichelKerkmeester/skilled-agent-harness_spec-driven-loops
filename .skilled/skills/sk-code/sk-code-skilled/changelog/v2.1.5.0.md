# v2.1.5.0, The Replay Library Trusts Only a Verified Private Link

`router-replay-lib.cjs` reads surface declarations from the other sk-code family skills in the skills root, and the quality gate takes checklist rows from them. It followed any link, so a `local-*` link into an undeclared folder could add a surface that outranks SKILLED. It now asks the advisor's trusted-root rule first.

> Spec folder: `specs/sk-code/013-private-surface-skills/009-alignment-fixes` (Level 2)

&nbsp;

## What's New at a Glance

- **A private link counts only when its target is trusted.** The reader keeps real skill folders and a `local-*` link whose real target lies inside a trusted root, loading the rule from the advisor's plain CommonJS `private-skill-target.cjs`, so it works on Node 20 too. When that module cannot load, every such link is skipped and one stderr line says so.
- **The parity test covers the untrusted link.** `declared-surfaces-parity.test.cjs` checks that the replay library and the plugin both drop it and both keep a link into a declared trusted root.

&nbsp;

## Upgrade

No migration required. A private surface that lives outside the skills root needs its folder in `SPECKIT_PRIVATE_SKILL_ROOTS`.
