# v2.0.0.0, The Framework Surface Gets Its Own Name

The surface that holds the standards for this framework's own code was called `sk-code-opencode`. It covers skills, agents, commands, hooks and runtime scripts for every runtime, not only OpenCode, and the name collided with the OpenCode runtime's own `.opencode/` folder and `cli-opencode` executor. A search for one kept turning up the other.

It is now `sk-code-skilled`. The routing alias is `code-skilled` and the surface id the router reports is `SKILLED`. Nothing about what the surface does has changed, only what it is called.

> Spec folder: `specs/sk-code/012-sk-code-skilled-rename` (Level 2)

&nbsp;

## Why This Release

A name that means two things makes routing, search and review harder than they need to be. Giving the framework surface a name of its own lets a reader tell at a glance whether a reference is about the framework or about the OpenCode runtime.

&nbsp;

## What's New at a Glance

- **The packet folder is `sk-code/sk-code-skilled/`.** Every path, mirror and changelog link now uses it.
- **Routing answers to the new name.** The advisor and the sk-code hub both send framework code requests to `sk-code-skilled`.
- **The surface id is `SKILLED`.** Surface detection, playbook scenarios and the review checklist report the new id.
- **The OpenCode runtime keeps its names.** `.opencode/`, `cli-opencode` and the `opencode` binary are unchanged.

&nbsp;

## Routing

#### Both Routing Stages Use the New Name

The skill advisor rebuilt its index from the renamed hub, and the hub's compiled route was re-minted. A request about framework code now resolves to `workflowMode: sk-code-skilled` at both stages.

#### The Surface Reports SKILLED

**Breaking:** anything that matched the surface id `OPENCODE` from sk-code surface detection must now match `SKILLED`. The advisor plugin's post-edit surface detection reports `SKILLED` too.

&nbsp;

## History

#### Old Records Read With the New Name

Spec docs, changelogs and archived packets were renamed as well, including the spec folders whose own names carried the old one. Machine logs and recorded benchmark JSON keep the name they were written with.

&nbsp;

## Upgrade Notes

- **Adopt.** Use `sk-code-skilled`, `code-skilled` and `SKILLED` wherever you named the surface.
- **Repoint.** Paths under `.skilled/skills/sk-code/sk-code-opencode/` now live under `.skilled/skills/sk-code/sk-code-skilled/`, and the changelog link is `.skilled/changelog/sk-code/code-skilled`.
- **Drop.** The `sk-code-opencode` and `code-opencode` names no longer resolve. Old commit `Spec:` trailers still name the old spec folders, so search history with the old name.
