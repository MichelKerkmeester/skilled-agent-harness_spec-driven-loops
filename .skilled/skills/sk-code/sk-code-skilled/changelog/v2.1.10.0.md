# v2.1.10.0, The Drift Guard Waits for the Quality Config

The quality config now lives inside the skill folder. The doc-claims guard resolves every path a doc names. A checkout that has not run `/doctor:sk-code quality` yet holds no `repository/quality.json`. So a doc naming the new location failed the guard. The path was right.

&nbsp;

## What's New at a Glance

- **The on-demand config path is exempt.** The guard accepts `.skilled/skills/sk-code/sk-code-quality/repository/quality.json` when the file is absent. That is because the doctor command writes it. Any other missing path under that folder still fails.
- **One test pins both cases.** One doc names the quality config and a sibling file. It passes on the first and fails on the second. Both happen in the same run.

&nbsp;

## Upgrade

No migration required.
