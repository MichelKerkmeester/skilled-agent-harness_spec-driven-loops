# v2.1.10.0, The Drift Guard Waits for the Quality Config

The quality config now lives inside the skill folder, and the doc-claims guard resolves every path a doc names. A checkout that has not run `/doctor:sk-code quality` yet holds no `repository/quality.json`, so a doc naming the new location failed the guard while the path was right.

> Spec folder: `specs/sk-code/017-portable-code-modes/016-repository-config-in-skill` (Level 2)

&nbsp;

## What's New at a Glance

- **The on-demand config path is exempt.** The guard accepts `.skilled/skills/sk-code/sk-code-quality/repository/quality.json` when the file is absent, because the doctor command writes it. Any other missing path under that folder still fails.
- **One test pins both cases.** A doc that names the quality config and a sibling file passes on the first and fails on the second, in the same run.
