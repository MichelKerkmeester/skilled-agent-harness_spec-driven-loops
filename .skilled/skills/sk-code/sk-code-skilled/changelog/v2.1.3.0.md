# v2.1.3.0, The Router Checker Survives a Renumbered Router

The router-sync verifier looked for the heading `## 7. VERIFICATION COMMANDS` by its number, so renumbering a router would have broken it without any content change. It now matches the heading by name. The replay library gains the module header the code standard asks for, and the playbook opens with the overview, preconditions, evidence and review sections every playbook carries.

> Spec folder: `specs/sk-code/015-quality-agnostic-gate` (Level 2)

&nbsp;

## What's New at a Glance

- **The verifier ignores section numbers.** It reads the verification-commands section wherever it sits.
- **The replay library has a header.** `router-replay-lib.cjs` opens with its module banner above `'use strict'`.
- **The playbook has a standard shape.** Sections 1 to 6 cover overview, global preconditions, evidence, command notation, review protocol and sub-agent planning.
