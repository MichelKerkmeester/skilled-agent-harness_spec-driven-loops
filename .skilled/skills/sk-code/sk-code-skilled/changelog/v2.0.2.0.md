# v2.0.2.0, The Surface Reader Keeps Each Marker Kind

`declaredSurfaces` merged every marker of a surface into one list. That suits request text, where any kind can appear. A reader of real files needs each kind apart. A path marker reads the path. A file marker reads the name. A content marker reads the text. The quality runner is that reader.

&nbsp;

## What's New at a Glance

- **Each marker kind has its own list.** Every surface entry carries `pathMarkers`, `fileMarkers` and `contentMarkers`. They are lowercased like the merged `markers` list. That list stays as it was.
- **Nothing a caller imports moved.** The library exports the same five names. `detectSurfaces` still matches request text against the merged list.
