# v2.0.2.0, The Surface Reader Keeps Each Marker Kind

`declaredSurfaces` merged every marker of a surface into one list, which suits request text, where any kind can appear. A reader of real files needs each kind apart, because a path marker reads the path, a file marker the name and a content marker the text. The quality runner is that reader.

> Spec folder: `specs/sk-code/015-quality-agnostic-gate/002-builtin-runner` (Level 2)

&nbsp;

## What's New at a Glance

- **Each marker kind has its own list.** Every surface entry carries `pathMarkers`, `fileMarkers` and `contentMarkers`, lowercased like the merged `markers` list, which stays as it was.
- **Nothing a caller imports moved.** The library exports the same five names, and `detectSurfaces` still matches request text against the merged list.
