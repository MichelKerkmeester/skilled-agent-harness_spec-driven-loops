# v1.2.2.0, The Drift Umbrella Counts Warnings

`run-all-drift-guards.sh` printed a bare PASS over the alignment guard's 272 warnings and ended on "all 4 guards PASSED", so the warnings were easy to miss. Each guard's PASS line now carries its warning count, and the summary line adds the total.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/012-post-merge-deep-review/003-drift-guard-warning-count` (Level 1)

&nbsp;

## What's New at a Glance

- **Each PASS line shows its warnings.** A guard that printed `[WARN]` lines ends on `PASS: <name> (<N> warnings)`.
- **The summary shows the total.** The last line reads `run-all-drift-guards: all 4 guards PASSED, <N> non-blocking warning(s)` when any guard warned, and is unchanged when none did.
- **Warnings still never fail the gate.** Exit codes and pass or fail decisions are unchanged.

&nbsp;

## Upgrade

No migration required. A script that matches the exact summary line should match its `all 4 guards PASSED` prefix.
