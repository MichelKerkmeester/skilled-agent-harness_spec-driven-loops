# 1.4.1.0, Jev as the Only Classifier

The reply judge agreement measurement now supports Jev alone. The Deem arm and the Deem references in its docs were removed, `cli-jev` is the only classifier, and the default run and `--jev` path are unchanged.

> Spec folder: `specs/cli-jev/003-cli-jev-workflow-integration/046-deem-deprecation` (Level 2)

## What's New at a Glance

- **One judge backend remains.** `judge-agreement.mjs` drops its `--deem` switch, its Deem column and its Deem-only tests. Its zero-call census, label gate and `--jev` arm print as before.
- **The reference docs name Jev alone.** The README, SKILL references, feature catalog and manual testing playbook no longer describe a second judge.

## Upgrade

No migration required. Every default run and `--jev` run behaves as before.
