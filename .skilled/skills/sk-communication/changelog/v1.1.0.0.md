Version 1.1.0.0 adds a second lane to the skill. The existing lane adapts an explanation on one axis only, register, saying the same thing in plainer words. The new lane adapts modality and depth, so a request that words cannot carry becomes a picture instead.

## What's New at a Glance

- **`/rewrite:explain-visually` adds visual explanations.** It explains a named topic, or the previous reply when no topic is given, as the smallest visual that answers the question. The no-topic case re-renders the prior reply in a different medium, the same act as `/rewrite:response`, so it belongs to the rewrite family.
- **The modality dial matches form to content.** Logic uses pseudocode, control flow a call tree and structure a component or file tree. Mermaid covers flow and sequence, a diff covers change and code blocks cover cases where syntax matters. HTML covers dense comparison.
- **The depth dial sets assumed prior knowledge.** `expert`, `plain` and `novice` decide how much prior knowledge an explanation may assume. Simplification changes words, never facts, so a `novice` answer may be incomplete but not wrong.
- **Visual artifacts are opt-in.** Explanations are display-only by default. `--artifact` creates one new self-contained HTML file and never edits an existing one.
- **`SKILL.md` distinguishes the two lanes.** It identifies which lane handles a request and why gating differs. Lane A rewrites a byte stream and may reach a model. Lane B synthesizes in-context and carries neither risk, so the enablement flag and egress rules do not apply to it.
- **The on-disk rule distinguishes edits from new artifacts.** The bar on rewriting durable files applies to editing an existing file. Creating a new explanatory artifact on explicit request is Lane B behavior.
- **The smart router selects a lane before resources.** An explanation request loads the visual rubrics instead of the package map.
- **The projection lane is untouched.** Its package, adapters, enablement flags and evaluation setup do not change.
- **Both lanes remain hand-invoked.** The skill remains on the advisor route-exclusions denylist. Both lanes are invoked by command, never by recommendation.
