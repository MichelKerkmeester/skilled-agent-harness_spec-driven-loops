# v1.0.0.0, First Release

The `system-skilled-bots` hub registers the `run` mode, and this release gives it a packet to resolve.

&nbsp;

## What's New at a Glance

- `SKILL.md` carries the run workflow and its rules.
- `ROUTER.md` maps run requests to the packet's reference leaf.
- `references/run-queue-and-answer.md` names the verbs this mode runs.
- `/bots:run` is the mode's command, with Bash granted for the `bots.cjs` verbs.
