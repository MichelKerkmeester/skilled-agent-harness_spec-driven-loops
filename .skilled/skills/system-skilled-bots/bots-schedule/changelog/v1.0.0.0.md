# v1.0.0.0, First Release

The `system-skilled-bots` hub registers the `schedule` mode, and this release gives it a packet to resolve.

&nbsp;

## What's New at a Glance

- `SKILL.md` carries the schedule workflow and its rules.
- `ROUTER.md` maps schedule requests to the packet's reference leaf.
- `references/schedule-lifecycle.md` names the verbs this mode runs.
- `/bots:schedule` is the mode's command, with Bash granted for the `bots.cjs` verbs.
