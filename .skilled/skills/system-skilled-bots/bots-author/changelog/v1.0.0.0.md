# v1.0.0.0, First Release

The `system-skilled-bots` hub registers the `author` mode, and this release gives it a packet to resolve.

&nbsp;

## What's New at a Glance

- `SKILL.md` carries the author workflow and its rules.
- `ROUTER.md` maps author requests to the packet's reference leaf.
- `references/bot-definition.md` names the verbs this mode runs.
- `/bots:author` is the mode's command, with a read, write and edit tool grant and no Bash.
