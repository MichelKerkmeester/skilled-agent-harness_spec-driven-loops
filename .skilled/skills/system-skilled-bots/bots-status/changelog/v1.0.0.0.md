# v1.0.0.0, First Release

The `system-skilled-bots` hub registers the `status` mode, and this release gives it a packet to resolve.

&nbsp;

## What's New at a Glance

- `SKILL.md` carries the status workflow and its rules.
- `ROUTER.md` maps status requests to the packet's reference leaf.
- `references/status-and-inbox.md` names the verbs this mode runs.
- `/bots:status` is the mode's command, with no write tool and a Bash allowlist of the two read verbs.

&nbsp;
