# /create:diagram Presentation Contract

This file is the single source of truth for user-facing presentation in `/create:diagram`: startup questions, output-format resolution, setup/status dashboards, and result display. The command router owns asset routing only. The workflow YAML owns execution behavior.

Run this automatic self-check before setup. This is not a user question.


## 2. Auto Setup Resolution

For `:auto`, resolve setup using the system auto-mode contract, resolve `output_format` before selecting a type or pattern, then load `create-diagram-auto.yaml` only when every required field is available.

Resolution tiers:

| Tier | Use When | Output |
| --- | --- | --- |
| Tier 1 | `$ARGUMENTS`, flags, pre-bound answers, and defaults resolve all required fields | Persist config and load auto workflow |
| Tier 2 | One or two required fields remain genuinely ambiguous | Ask one narrow question per missing field |
| Tier 3 | Required fields remain unresolved | Emit missing-inputs error and do not load YAML |

Pre-bound setup schema:

```yaml
PRE-BOUND SETUP ANSWERS:
  output_format: html-svg
  request_shape: generate
  target_diagram_path: docs/diagrams/example-architecture.html
  source_content: Describe the system, process, or data model to diagram.
  diagram_type: architecture
  ascii_pattern: ""
  import_source_path: ""
  export_format: ""
  execution_mode: AUTONOMOUS
```

Default resolution table:

| Field | Required | Resolves Via | Default | Tier-2 Candidate |
| --- | --- | --- | --- | --- |
| `output_format` | Yes | `--output-format`, marker `output_format`, `.md` target, or ASCII/markdown flowchart signals; otherwise `html-svg` | `html-svg` | Yes, when ambiguous |
| `request_shape` | Yes | marker `request_shape`, a `--import` flag or `.drawio`/`.mmd`/`.mermaid` source (implies `import`), an `export`/`png`/`svg`/`rasterize` keyword against an existing diagram (implies `export`), otherwise `generate` | derive when confidence >=80% | Yes, when ambiguous |
| `target_diagram_path` | Conditional | Positional `.html` path for `html-svg`, `.md` path for `ascii-markdown`, or marker `target_diagram_path` | none | Yes, when missing |
| `source_content` | Conditional | Remaining positional text, prompt-body source, or marker `source_content` (required for `html-svg` generate or `ascii-markdown`) | none | Yes, when missing |
| `diagram_type` | Conditional | `--type` flag, marker `diagram_type`, or derived from `source_content` against the 27-type selection guide (required for `html-svg` generate) | derive when confidence >=80% | Yes, when ambiguous |
| `ascii_pattern` | Conditional | marker `ascii_pattern` or derived from `source_content` against the ASCII pattern-selection table (required for `ascii-markdown`) | derive when confidence >=80% | Yes, when ambiguous |
| `import_source_path` | Conditional | `--import` flag or marker `import_source_path` (required for `html-svg` import) | none | Yes, when missing |
| `export_format` | Conditional | `--format` flag or marker `export_format` (required for `html-svg` export; `png`, `svg`, or `html+png`) | none | Yes, when missing |
| `execution_mode` | Yes | `:auto`, `:confirm`, or marker `execution_mode` | `AUTONOMOUS` under `:auto` | No |

## 3. Consolidated Startup Prompt

Ask one prompt containing only applicable questions. Do not split these questions across turns.

```text
Before proceeding, please answer:

Q0. Output Format (if not clear)
A) HTML/SVG diagram (`html-svg`, default)
B) ASCII/markdown flowchart (`ascii-markdown`)

Q1. Request Shape (if not clear, html-svg only)
A) Generate a new artifact from a description
B) Import and redraw an existing .drawio or Mermaid source
C) Export an already-generated diagram to PNG/SVG

Q2. Target Artifact Path (if not provided)
Where should the artifact be created?
Format: workspace-relative `.html` path for html-svg or `.md` path for ascii-markdown.

Q3. Source Content or Import Path (if not provided)
For html-svg generate or ascii-markdown: what should the artifact show?
For html-svg import: the workspace-relative path to the `.drawio`, `.drawio.png`, `.drawio.svg`, `.mmd`, `.mermaid`, or Markdown-with-fenced-Mermaid source.

Q4. Diagram Type or ASCII Pattern (if not clear)
For html-svg, choose one of the 27 diagram types: architecture, IT current-state, flowchart, sequence, state machine, ER/data model, timeline, swimlane, quadrant, radar, loop, nested, tree, org chart, layer stack, venn, pyramid/funnel, bar, line, Gantt, scatter, high-level, process, medallion, data flow, DP integration, DP security matrix.
For ascii-markdown, choose: linear, decision, parallel, approval, swimlane, or journey.

Q5. Execution Mode (if no :auto/:confirm suffix)
A) Interactive - confirm at each step
B) Autonomous - execute without prompts

Reply with answers, for example: html-svg, A, docs/diagrams/architecture.html, "frontend, backend, database, Redis cache", architecture, B
```

Hard stops:

- Do not proceed until all applicable questions are answered.
- Resolve output format before selecting a diagram type or ASCII pattern.
- Do not guess between `html-svg` and `ascii-markdown`; use `UNKNOWN_FALLBACK` when ambiguous.
- Do not generate an artifact without an explicit target path and source content.
- Do not redraw an import source without an explicit source path.
- Do not auto-select execution mode without suffix or explicit choice.
- Do not infer diagram content from context, screenshots, or conversation history.

| Field | Required | Value | Source |
| --- | --- | --- | --- |

Proceed only when every required field (and every conditional field the resolved shape makes required) has a value.
