## Differences between MCP and Agents

Same engine. Two directions. One goes out. The other works in.

### MCP

Magnific goes to you

MCP brings Magnific to your workspace. Use it in Claude, Cursor, VS Code, or any tool that supports the protocol.

*   You're writing in Claude and need three hero variants in the chat
*   Your IDE is where the work happens—Cursor, VS Code, whichever
*   Your team's LLM should call Magnific without anyone leaving it
*   You want to wire Magnific into a script, a webhook, a slash command

### Agents

You work inside Magnific

Agents automate creative work inside Magnific. Build workflows that run autonomously and scale your output.

*   The same creative flow runs every week
*   A brief should return 50 variants, not one
*   A sketch comes back as a full campaign
*   A reference becomes a complete character sheet across shots

Build your Agents here.Call them from anywhere.[Learn more about Agents](https://www.magnific.com/agents)
