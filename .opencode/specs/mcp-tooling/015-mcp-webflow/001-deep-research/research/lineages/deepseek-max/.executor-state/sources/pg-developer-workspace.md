# Developer workspace plan

> Discover the features of Webflow's Developer Workspace plan, designed to let developers explore premium features used by large teams and enterprises

This plan does not allow for publishing sites to production or exporting code. If you are looking to host sites in production or need official support for any of the capabilities in this plan, see official Webflow plan offerings at
<a href="https://webflow.com/pricing">[https://webflow.com/pricing](https://webflow.com/pricing)</a>.

The **Developer workspace plan** gives App developers access to advanced Webflow features often used by larger teams and enterprises for the purposes of testing during Webflow App development.

This plan allows you to explore premium capabilities and see how they can elevate your Apps, offering a dedicated environment for building, testing, and integrating with Webflow’s powerful premium features.

## What's included

As Webflow continues to expand its offerings, you may see additional premium capabilities added to the App Developer Workspace Plan.

| Feature                                                                         | Details                                     |
| ------------------------------------------------------------------------------- | ------------------------------------------- |
| **Workspace Users**                                                             | Up to 3 users for collaboration and testing |
| **API Rate Limit**                                                              | 120 requests per minute (RPM)               |
| **Unhosted Sites**                                                              | Unlimited                                   |
| [**Custom Code**](https://developers.webflow.com/data/docs/custom-code)         | Enabled                                     |
| **Site Activity Log**                                                           | Enabled                                     |
| [**Page Branching**](https://help.webflow.com/hc/en-us/articles/33961355506195) | Enabled                                     |

## Limitations

This workspace allows App Developers an environment to test and build their Apps, but has some key restrictions in place.

| Feature                      | Details                       |
| ---------------------------- | ----------------------------- |
| **Publishing to Production** | Disabled                      |
| **Exporting Code**           | Disabled                      |
| **Site Transfer**            | Disabled                      |
| **Monthly Site Visitors**    | 1,000 site visitors per month |

## Accessing the developer workspace plan

There are two ways to get a Developer workspace:

* **Create a new developer workspace** yourself from your dashboard.
* **Convert an existing workspace** into a developer workspace by contacting Webflow support.

### Creating a developer workspace

You can create a Developer workspace directly from your dashboard. Select **Create a developer workspace** below to open the creation flow.

<a href="https://webflow.com/dashboard/workspaces?createDevWs=true">
  <button class="cc-primary">
    Create a developer workspace
  </button>
</a>

<br />

<br />

In the creation modal:

1. Enter a **Name** for your workspace.
2. Add a short **Reason** describing what you plan to build. Your reason must be at least 20 characters.
3. Confirm that you understand developer workspaces are only for building and testing Webflow Apps and integrations.
4. Select **Create developer workspace**.

Your developer workspace is created and ready to use right away.

You can only own **one** developer workspace. If you already own one, you won't be able to create another.

### Converting an existing workspace

To convert an existing workspace into a developer workspace, contact [Webflow support](https://support.webflow.com) and our team will help you make the switch.

## Managing your developer workspace plan

#### Is There a Cost for This Plan?

<p>
  The App Developer Workspace Plan is free of charge. However, any site plans purchased within this workspace will be billed at standard rates without discounts.
</p>

#### Switching Plans

<p>
  If you choose to move to a different Workspace plan, you will lose access to features unique to the App Developer Workspace Plan, such as the Site Activity Log and Page Branching. Contact us if you need assistance with transitioning to another plan.
</p>
