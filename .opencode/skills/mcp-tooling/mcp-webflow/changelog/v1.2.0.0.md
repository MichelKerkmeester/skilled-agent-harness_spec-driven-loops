# v1.2.0.0 - Template Alignment + Full Remote Surface

**Released:** 2026-08-03

## Template Alignment (sk-create-skill standards)

- SKILL.md restructured to the template's 8-section contract: WHEN TO USE, SMART ROUTING,
  HOW IT WORKS, RULES, SUCCESS CRITERIA, INTEGRATION POINTS, QUICK REFERENCE, REFERENCES AND
  RELATED RESOURCES — passes `validate_skill_package.py` / `package_skill.py --check`.
- README.md gained the required frontmatter (title/description/trigger_phrases/version).
- Description trimmed to the soft target (<= 130 chars).
- Playbook scenarios follow the hub's scenario conventions.

## Full Remote Surface (online research, official docs 2026-08-03)

- **New: `references/action-reference.md`** — the complete official remote surface:
  **31 tools / 216 actions** with required parameters, read/write flags, and frozen risk
  classes, sourced from developers.webflow.com/mcp/tools/* (data, designer, utility).
- Feature catalog now lists the full surface at a glance (22 capability groups) plus new
  cards: `agent-instructions.md`, `analyze.md`, `localization-fonts-forms.md`,
  `sitemap-scripts-assets-whtml.md`.
- New capability areas beyond the 18-module OSS baseline: Agent Instructions (6 actions),
  Analyze add-on (7), Assets incl. compression (12), component builder/props/variants (16),
  element tool/settings/builder (21), Fonts (7), Forms (7), Localization (7), Pages incl.
  schema markup (11), Scripts (20), Sitemap (8), Style (10), Variables (18), WHMTL builder,
  Designer canvas tool (15), utility surface (ask_webflow_ai, guide, get_more_tools).
- Playbook expanded 12 → 16 scenarios: REMOTE-SURFACE-001 (surface reconciliation),
  ANALYZE-001, INSTRUCTIONS-001, BULKGATE-001.
- New asset: `assets/example-payloads.md` (payload shapes for agent instructions, CMS items,
  variables, sitemap bulk, staging publish).

## Contract Changes

None — classification rules, gates, pairing, and credential discipline are unchanged; the
expansion documents the full remote surface under the same frozen safety contract.
Live discovery (`list_tools`) of the pinned version remains the authoritative inventory; the
remote docs surface and the local OSS baseline are both labeled as such and reconciled per
session (REMOTE-SURFACE-001).
