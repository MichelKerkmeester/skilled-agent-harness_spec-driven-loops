# v1.3.0.0 - Independent Review Remediation

**Released:** 2026-08-03

Four fresh-context GPT-5.6 SOL FAST reviewers audited completeness and sk-create-skill /
sk-create-feature-catalog / playbook alignment (findings in the review logs). This release
implements their fixes.

## Completeness (review 1)

- **UNKNOWN class added (P0)**: any tool/action outside the researched inventory is PROHIBITED
  until classified from the live schema — never inferred as DW.
- Action reference **regenerated to the complete official surface: 31 tools / 220 actions** with
  full required parameters (the four `*_301_*` Enterprise actions were missing; extraction now
  exact), global `siteId`/`pageId` notes for page-building tools, corrected classifications
  (`unregister_component` DS, `check_if_inside_component_view` RO, publish-status flips PB).
- **Surface separation**: remote (220 actions) vs local OSS (18 modules) labeled everywhere;
  `run_workflow` correctly scoped to the local surface; CMS draft semantics documented per
  surface (remote create/update = drafts; publish/unpublish = live, PB).
- Cards corrected: CMS (`delete_collection_field`, `unpublish_collection_items`), comments
  (`create_reply`), forms (`delete_form_submission`), localization (content-only), scripts
  (`set_page_scripts`/`set_site_scripts`), sitemap (individual actions), pages (`delete_branch`),
  WHTML typo fixed; **new component-variants card**.

## sk-create-skill alignment (review 2)

- SMART ROUTING: full resilient router pseudocode (RESOURCE_BASES, recursive discovery,
  `_guard_in_skill`, `load_if_available`, intent scoring, UNKNOWN_FALLBACK_CHECKLIST).
- `doctor.sh`/`install.sh`: Node check now requires **22.3.0+** (minor/patch-aware).
- README rebuilt per the skill-readme-template (frontmatter, pitch, AT A GLANCE, OVERVIEW,
  QUICK START, troubleshooting, verification, related docs).
- `validate_skill_package.py` PASS; `package_skill.py --check` PASS; strict leaves only the
  hub-wide `INSTALL-GUIDE.md` naming convention (identical to mcp-obsidian).

## Feature-catalog alignment (review 3)

- Root rebuilt to the canonical format: numbered ALL-CAPS sections, H3 entries per card with
  Description/Current Reality/Source Files + resolving links, 21 groups / 220 actions, labeled
  local-OSS baseline section, `last_updated` 2026-08-03.
- All 9 cards restructured to the canonical leaf contract (## 1. OVERVIEW / ## 2. HOW IT WORKS /
  ## 3. SOURCE FILES / ## 4. SOURCE METADATA).

## Playbook alignment (review 4)

- Root rebuilt with the canonical sections: global preconditions, execution policy and evidence,
  deterministic notation, review/readiness protocol, wave planning, full scenario index (16,
  with links), automated-test and feature-catalog cross-references.
- All 16 scenarios upgraded to the canonical 5-section contract with binary PASS/FAIL/SKIP,
  exact prompts, expected signals, evidence, and ordered triage.
- Safety fixes: REFUSE-001 (production publish **unconditionally refused**), PUBGATE-001
  (publishToWebflowSubdomain + pageId), DEPLOYGATE-001 (named environment + rollback),
  RATELIMIT-001 (no mocks; `X-RateLimit-Remaining` spelling), NONWEBFLOW-001 (`stage: negative`).

## Contract Changes

None — classification rules, gates, pairing, and credential discipline are unchanged; UNKNOWN
was added as the fail-closed class the contract already implied.
