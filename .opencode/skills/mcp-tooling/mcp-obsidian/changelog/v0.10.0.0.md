# mcp-obsidian — v0.10.0.0

Adds full skill support for the five community plugins installed into every vault in the plugin-installation batch (Charts, Dataview, Excalidraw, Git, Outliner) plus the Minimal theme. Each artifact now has a reference set, copyable assets, a feature-catalog card and a manual tie-in scenario, and the router resolves them to the right resources.

## 1. NEW

- **Six reference sets** under `references/plugins/` — `charts/`, `dataview/`, `excalidraw/`, `git/`, `outliner/`, `minimal/`. Each set has an index, a data-model, workflows and troubleshooting, all with full frontmatter. Facts were grounded in the installed bundles (manifest versions, `main.js` default settings, registered block languages); unverifiable details carry `VERIFY` markers.
- **Assets** under `assets/plugins/` — `charts-block.example.md`, `dataview-query.example.md`, `dataview-metadata.example.md`, `drawing-note.example.excalidraw.md`, `drawing-scene.example.json`, `git-settings.example.json`, `git-commands.example.md`, `outliner-settings.example.json`, `outliner-settings.partial.example.json`, `minimal-activation.example.json`, `minimal-snippet.example.css`.
- **Six feature-catalog cards** — `feature-catalog/plugins/{charts,dataview,excalidraw,git,outliner,minimal}.md`. Root catalog count updated from 25 to 31 entries.
- **Six playbook scenarios** — `OBS-016` Charts render-block round-trip, `OBS-017` Dataview metadata and query round-trip, `OBS-018` Excalidraw drawing-note round-trip, `OBS-019` Obsidian Git status round-trip, `OBS-020` Outliner settings and defaults, `OBS-021` Minimal theme activation. All run against throwaway vaults only.
- **Router intents** — `PLUGIN_CHARTS`, `PLUGIN_DATAVIEW`, `PLUGIN_EXCALIDRAW`, `PLUGIN_GIT`, `PLUGIN_OUTLINER`, `PLUGIN_MINIMAL` in `INTENT_SIGNALS`, `RESOURCE_MAP` and the specific-plugin disambiguation list. Hub aliases and vocabulary classes extended for advisor discoverability.

## 2. CHANGED

- `SKILL.md` version 0.9.0.0 → 0.10.0.0. Frontmatter description, keywords comment, H1 intro and the resource map notes now name eleven artifacts instead of five; the specific-plugin list grew from four to ten intents.
- `references/plugins/plugin-operation-logic.md` — data map extended from five to eleven rows.
- `feature-catalog/feature-catalog.md` — plugin category prose and the six new card sections; counts updated to 31 entries.
- `manual-testing-playbook/manual-testing-playbook.md` — scenario rows and the tie-in range updated to `OBS-011..OBS-021`.
- `README.md` — Plugin Knowledge Layer table and FAQ now cover all eleven artifacts.
- `mode-registry.json` and `hub-router.json` — mcp-obsidian aliases and vocabulary classes extended with the six artifacts.

## 3. NOT CHANGED

- No vault files were touched by the skill work. Installed plugin binaries and the Minimal theme stay exactly as the install batch placed them.
- The existing five reference sets (Beancount, Tables, BRAT, Health.md, Iconic) are untouched.
- No CLI or MCP surface changed. This release is plugin and theme knowledge only.
