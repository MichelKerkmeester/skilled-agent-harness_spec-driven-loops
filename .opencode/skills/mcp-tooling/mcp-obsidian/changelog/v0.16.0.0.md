# mcp-obsidian v0.16.0.0

Closes the two testing follow-ups recorded in v0.15.0.0: OBS-013 no longer needs network to run, and the harness that exercises all eleven plugin scenarios now lives in the skill.

---

## 1. NEW

- **`assets/plugins/obsidian42-brat/release.example.json`** — a captured GitHub release response (tag, asset list) that BRAT's headless install scenario can stage from without network access.
- **`assets/plugins/obsidian42-brat/sample-beta-plugin/{main.js,manifest.json}`** — a non-functional fixture beta plugin (valid manifest `id`/`version`, parseable `main.js`) staged into the throwaway vault as the release assets. It is never loaded by a real Obsidian instance; the scenario verifies the file-layer stage/register/activate contract, not runtime behaviour.
- **`scripts/run-scenarios.sh`** — the headless regression harness for the eleven plugin playbook scenarios (`OBS-011`..`OBS-021`). It runs each scenario in its own disposable throwaway-vault workspace (`cli-codex`, `workspace-write`, `TMPDIR` redirected), prints a per-scenario `RESULT: PASS/FAIL/SKIP` summary, and exits non-zero if any scenario FAILs. Self-locating (no hard-coded paths); requires the `codex` CLI.

## 2. CHANGED

- **`manual-testing-playbook/plugin-tie-ins/brat-headless-install.md`** — added a **Fixture mode (no network)** stage variant that copies from the shipped fixture instead of `curl`, updated the OVERVIEW and orchestration note to say OBS-013 runs fully offline, and linked the two fixture files under source anchors.
- **`manual-testing-playbook/manual-testing-playbook.md`** — the OBS-013 prerequisite line now offers the offline fixture as the default staging path (network optional).
- **`scripts/README.md`** — documents `run-scenarios.sh` in CONTENTS and VALIDATION.
- `SKILL.md` version 0.15.0.0 → 0.16.0.0.

## 3. VERIFICATION

- OBS-013 fixture mode was run end-to-end offline against a throwaway vault (deterministic `bash`+`jq`, no LLM, no network): stage, register, and activate all verify independently — assets staged non-empty, repo + frozen tag present in BRAT `data.json`, manifest id present in `community-plugins.json`.
- All edited docs pass `validate_document.py` (0 issues); the JSON fixtures parse; `main.js` passes `node --check`; `run-scenarios.sh` passes `bash -n`.

## 4. NOT CHANGED

- No vault, plugin, or runtime data was touched. `README.md` stays at `0.12.0.0`.
- The fixture plugin is intentionally inert — it exists only to give the file-layer scenario real, parseable assets to move, not to demonstrate plugin behaviour.
