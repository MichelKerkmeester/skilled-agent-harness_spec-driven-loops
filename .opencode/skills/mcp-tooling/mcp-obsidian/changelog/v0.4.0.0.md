# mcp-obsidian — v0.4.0.0

Extends the mode's plugin knowledge with Health.md Visualizations, mirroring the existing per-plugin reference pattern (index + data-model + workflows + troubleshooting).

## 1. NEW

- **Health.md Visualizations (`health-md`) reference set** — `references/plugins/health-md/`: Apple Health export data files (JSON/CSV/Markdown/Bases) in the vault data folder (default `Health/`), schema v0–v7, roll-ups under `Health/Rollups/`, `_healthmd_data_dictionary.json`, render-block placement, and the hard rule to never fabricate health data. Installed + enabled in all three vaults (packet Phase 11).
- **Router + docs** — `SKILL.md` v0.4.0.0: activation triggers for health requests, the reference set added to load-on-demand, keyword comment extended. `plugin-operation-logic.md` data map grows from 3 to 4 rows.
- **Catalog + playbook** — feature card `feature-catalog/plugins/health-md.md`; scenario `OBS-014` (Health.md data-file round-trip); indexes updated.
- **Assets** — `assets/plugins/health-md/healthmd-export.example.json`.

## 2. CHANGED

- `SKILL.md` version 0.3.0.0 → 0.4.0.0 (frontmatter + keywords).
- `feature-catalog/FEATURE-CATALOG.md` plugin category: 3 → 4 plugins.
- `manual-testing-playbook/manual-testing-playbook.md`: 19 → 20 scenarios (OBS-011..OBS-014).

## 3. NOT CHANGED

- No vendored plugin code; the asset is an example data file only.
- Existing three plugin reference sets untouched (except the shared data-map table).
