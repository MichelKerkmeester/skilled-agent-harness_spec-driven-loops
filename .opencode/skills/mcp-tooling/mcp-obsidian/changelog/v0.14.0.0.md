# mcp-obsidian v0.14.0.0

Closes the deeper findings from the plugin-coverage deep-review — the ones beyond structural coverage. Two are genuine safety fixes; one is a security caveat; one completes a display index. Behavior of the CLI and MCP surfaces is otherwise unchanged.

## 1. CHANGED

- **BRAT install: reject an unsafe plugin id (path-traversal guard).** `references/plugins/obsidian42-brat/workflows.md` and `manual-testing-playbook/plugin-tie-ins/brat-headless-install.md` now validate `PLUGIN_ID` against `^[A-Za-z0-9._-]+$` before it is interpolated into the vault plugin path. A hostile release manifest supplying `../` or `/` in `.id` can no longer escape `.obsidian/plugins/` and write elsewhere in the vault. Previously only non-empty / not-`null` was checked.
- **Code Mode round-trip: fail safe on non-404 errors.** `examples/mcp-roundtrip.sh` no longer treats every `obsidian_get_note` error as "note absent." An auth, transport, or server error now re-throws instead of falling through to an empty-content write, so a transient read failure can no longer overwrite a real note. The exact error shape stays `VERIFY` (confirm with `tool_info()`).
- **TLS caveat scoped to loopback.** `references/mcp-tools.md` and `examples/mcp-roundtrip.sh` now state that disabling cert verification (`OBSIDIAN_VERIFY_SSL=false` / `curl -k`) is safe only because the endpoint is loopback (`127.0.0.1`); the bearer token must never be sent to a non-loopback host with verification off.
- **Human loading index completed to eleven.** `SKILL.md` version 0.13.0.0 → 0.14.0.0; the human-readable resource-loading display now lists all eleven plugin reference sets (added Charts, Dataview, Excalidraw, Obsidian Git, Outliner, Minimal), matching the executable router which already resolved all eleven.

## 2. NOT CHANGED

- No plugin reference set, asset, feature-catalog card, or playbook scenario was added or removed.
- The intentional `VERIFY` markers on app-only / per-vault / source-inspection details stay as honest-uncertainty markers.
- No vault, plugin, or runtime data was touched. `README.md` stays at `0.12.0.0`.
