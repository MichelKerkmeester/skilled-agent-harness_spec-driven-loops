# mcp-tooling drops the removed mcp-webflow transport

The `mcp-webflow` packet was deleted by the operator. This release removes every remaining hub surface that advertised or routed to it, so the hub no longer offers Webflow as a routable mode.

---

## Why

The Webflow MCP skill packet no longer exists in this repo. The hub still declared `mcp-webflow` as an eighth mode in its registry, router, advisor description, leaf manifest, and shared routing reference, which would send agents to a nonexistent packet and break the mode-inventory contract. Removing the mode keeps the hub truthful and keeps routing failures from surfacing to users.

## What Changed

#### Hub routing surfaces

- `hub-router.json` (v1.1.2.0): `mcp-webflow` removed from `routerPolicy.tieBreak`, the `mcp-webflow` `routerSignals` entry deleted, and the `webflow-aliases` and `webflow-operations` vocabulary classes deleted.
- `mode-registry.json` (v1.0.2.0): `mcp-webflow` removed from `extensions.transport-axis.transports` and `crossHubPairing`; the mode entry (backendKind `code-mode-stdio-mcp`, Webflow token wiring, conditional `sk-design` pairing) deleted from `modes[]`; the transport-axis description no longer documents a local-stdio Webflow backend.

#### Advisor and docs

- `description.json` (v1.4.2.0): description and keywords no longer advertise Webflow operations.
- `SKILL.md` (v1.3.2.0): Webflow row removed from the mode table; the transport-axis sentence now names only `mcp-figma`, `mcp-refero`, and `mcp-mobbin` with a mandatory `sk-design` pairing.
- `shared/references/smart-routing.md`: `WEBFLOW` intent signals and resource-map entries removed; the surface router now covers the remaining seven modes.
- `README.md`: the four committed merge-conflict blocks were resolved (local side kept); neither side advertised Webflow.
- `leaf-manifest.json`: regenerated, dropping the `mcp-webflow` mode block.

#### Cleanup

- Deleted the `benchmark/reports/2026-08-02--webflow-registration--routing-replay/` report, which referenced the removed packet.
