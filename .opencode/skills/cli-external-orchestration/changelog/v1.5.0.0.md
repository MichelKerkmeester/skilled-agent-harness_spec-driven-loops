# cli-external-orchestration v1.5.0.0

## Added

- **`cli-hermes`, the seventh mode.** Hermes Agent (Nous Research, binary `hermes`) dispatches as a quiet oneshot chat with the prompt on stdin (`hermes chat -Q --oneshot --query-file - --provider llmgateway --model <roster id> --ignore-rules --source tool -t <explicit toolsets> [--yolo]`). Registered in `mode-registry.json`, `hub-router.json` (signals, vocabulary classes, tie-break order), `ROUTER.md`, `description.json`, `graph-metadata.json` and the regenerated `leaf-manifest.json`; the compiled-routing harness enumerates its `SKILL.md` and carries a `hermes-single` canary.
- **The eighth deep-loop executor kind.** `buildHermesLineageCommand` in the shared runtime, a closed two-id roster (`deepseek-v4.1-flash`, `glm-5.3-flash`) enforced in `executor-config.ts` and byte-mirrored in `fanout-run.cjs`, the `max` reasoning pin, a `--run-budget` one margin under the lineage timeout, and `liveTools.mcpServers` for naming the MCP servers a Hermes leaf may reach (only this kind accepts a non-empty list; `delegation`, `memory` and `clarify` are refused).
- **Dispatch guards.** A `hermes` shape in the dispatch audit and seven rule checks behind the packet's hard rules (availability, `--yolo` for write toolsets, `--ignore-rules`, explicit `-t`, no `--worktree`, MCP and hooks are operator-level).
- **AI-council seats and the model-benchmark dispatcher** accept `cli-hermes`; council seats feed the prompt on stdin.
- **A stress-matrix subject** (`cli-hermes.vitest.ts`, `hermes-shim.cjs`) with the fourteen hermetic cells implemented.
- **Repo runtime folder `.hermes/`** with generated markdown-only copies of all 56 skills and 12 agent personas, an `agents/` link, generated prompt stubs, the `repo-guards` project plugin and `SYNC.md`.

## Changed

- Every roster surface that named six modes names seven: the hub README, root README, orchestrate agent copies, the rewrite command, the deep-research and deep-review presentations and compiled contracts, and the sibling packet READMEs.
- The prompt-improver eligibility table and the canonical prompt card carry a `cli-hermes` row; the prompt-card sync guard covers the seventh packet.

## Not Changed

- The six existing modes' contracts, rosters and hard rules.
- The hub's advisor identity; routing is still hub then mode.
