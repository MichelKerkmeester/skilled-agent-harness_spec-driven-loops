# cli-external-orchestration v1.4.5.0

## Changed

- **Closed the cli-pi and cli-opencode model rosters.** Both skills now state explicitly that models not in the roster are **forbidden** to dispatch. A `CLOSED ROSTER — non-roster models are FORBIDDEN` callout was added to §2 of each `references/providers-and-models.md`, plus a one-line rule at each `SKILL.md` front door.
  - **cli-pi** — enforced: the deep-loop external-CLI fan-out hard-rejects any off-roster id (`isPiModelAllowed` over `PI_SUPPORTED_MODELS` in `executor-config.ts`, byte-mirrored in `fanout-run.cjs`). The `pi` binary itself is a passthrough with no allowlist, so for direct (non-fan-out) invocations the rule is a hard discipline rule. The prior "roster is machine state, not a contract" framing was updated to "closed roster."
  - **cli-opencode** — discipline only: it has **no** code-enforced allowlist (`--model provider/id` is free-form and the fan-out does not gate opencode ids), so the closed-catalog rule is stated as a hard discipline rule rather than a runtime gate. A live id that is not in the catalog is still forbidden.
- **Documented that GLM-5.3-Flash is NOT reachable via cli-opencode's Cline route.** opencode's `cline-pass` adapter returns `Unexpected server error` for every id form (`cline-pass/z-ai/glm-5.3-flash`, `cline-pass/cline-pass/glm-5.3-flash`), and `opencode models cline-pass` lists only `glm-5.3` (no `-flash`). Verified 2026-08-27. The cli-opencode cline-pass section now says so and points to `openrouter/z-ai/glm-5.3-flash` / `opencode-go/glm-5.3-flash` instead. (cli-pi's Cline route works because pi passes the raw Cline id straight through — unchanged.)

## Not Changed

- The roster contents themselves — no models added or removed here; this change is roster **policy** (closed) plus one documented provider limitation.
- The fan-out enforcement code (`isPiModelAllowed` / `PI_SUPPORTED_MODELS`) — already enforced cli-pi; this change documents it, it does not alter it.
- cli-cursor / cli-devin — already carry hard-enforced `CURSOR_SUPPORTED_MODELS` / `DEVIN_SUPPORTED_MODELS`; untouched.
- The cli-pi Cline GLM-5.3-Flash route (`cline-pass/z-ai/glm-5.3-flash`) — still present and working.
