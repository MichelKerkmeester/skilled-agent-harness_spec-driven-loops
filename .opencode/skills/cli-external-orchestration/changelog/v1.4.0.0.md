# cli-external-orchestration v1.4.0.0

## Changed

- Expanded the enforced model rosters of three modes with live-verified additions (packet 043, all confirmed present in the live CLI listings on 2026-08-14):
  - **cli-cursor** adds `gpt-5.6-luna-max` and `gpt-5.6-luna-max-fast` — the first GPT-5.6 persona in its curated allowlist (18 → 20 ids). See `cli-cursor/changelog/v1.4.0.0.md`.
  - **cli-devin** adds `deepseek-v4-pro-max`, `deepseek-v4-flash-max`, `gpt-5-6-luna-max`, and `gpt-5-6-luna-max-priority` — the curated scope grows from four families to five (GPT-5.6 added). See `cli-devin/changelog/v1.4.0.0.md`.
  - **cli-opencode** documents `opencode-go/glm-5.3` in the opencode-go gateway roster (doc-only; cli-opencode has no code-enforced allowlist). See `cli-opencode/changelog/v1.4.2.0.md`.
- Updated `shared/references/smart-routing.md` so the cli-devin routing description names GPT-5.6 Luna Max alongside the existing families.
- Ran a roster-count honesty sweep across the touched mode docs (cli-cursor "18-id" → "20-id"; cli-devin "four families" → "five"), including correcting two pre-existing stale "10"-count claims left over from before packet 036 grew the Cursor roster to 18.

## Not Changed

- Routing behavior. The hub still reads `hub-router.json` and `mode-registry.json` with the same `tieBreak` order and `cli-opencode` as the default mode.
- Grok 4.6 support, which was already complete (packet 036): cli-cursor carries all 8 `cursor-grok-4.6-*` ids and cli-devin all 4 `grok-4-6-*` uids, unchanged here.
- The enforcement mechanism. New ids were added to both the `executor-config.ts` source-of-truth arrays and their `fanout-run.cjs` mirrors together, kept in sync by the existing guard tests.
