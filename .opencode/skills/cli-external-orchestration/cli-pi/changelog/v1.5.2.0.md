The DevPass DeepSeek route was pointing at an id the gateway had switched off. It answers `410`
now, which means every fan-out that took the default reached a dead model. The route is the
DeepSeek V4.1 Flash line instead, and the roster says what was measured rather than what was
assumed.

## What Changed

#### Breaking

- **The bare DevPass DeepSeek literal is `deepseek-v4.1-flash`.** It was
  `deepseek-v4-flash-vision-exp`, which the gateway now answers `410 "has been deactivated and is
  no longer available"` for. That literal is the fan-out's cli-pi default, so an omitted model
  reached a dead route. The replacement accepts images the same way, carries the same 1.05M
  context, and raises the output ceiling to 384K. Anything that names the old bare id must be
  repointed. The OpenRouter and opencode-go literals are untouched: they name different routes
  and both still resolve.

#### Fixes

- **The roster carries the documented effort ladder.** Three levels plus off: `none` disables
  thinking, `minimal` and `low` reach low, `medium`, `high` and `xhigh` reach high, and `max`
  reaches max. The default is `high`. This route rejects `ultra`, which DeepSeek's own mapping
  table lists, and rejects the integer 1-100 form the model card documents, so the names above
  are the whole surface. The effort pin forces `max`, which is a real top level here.
- **The id-shape example is re-verified rather than inherited.** Bare returns `200`, prefixed
  returns `400 "Provider llmgateway does not support model deepseek-v4.1-flash"`, and the
  upstream rewrite reports `deepseek/deepseek-v4.1-flash` rather than the old `gonka24/` name.
- **The published rate is carried instead of a comparison.** $0.15 in and $0.60 out per million
  tokens with cached reads at $0.003, all read from the gateway's own model listing.

## Verification

- Live gateway probe: the new id returns `200`, the old one `410`, the prefixed form `400`,
  and `ultra` plus every integer are refused with `Invalid request parameters`.
- Effort ladder taken from DeepSeek's thinking-mode guide, not inferred from status codes.
- `fanout-run.vitest.ts` — 121 tests, 0 failures.
- `executor-config.vitest.ts` — 92 tests, 0 failures.
