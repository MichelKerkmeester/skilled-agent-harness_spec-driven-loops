This first release adds Pi as the sixth workflow mode in the external CLI orchestration hub. It packages a guarded binary probe, self-invocation refusal, print/JSON/RPC routing guidance, and a clear boundary between Pi's documented native resources and community packages.

The CLI reference is grounded in the local Pi contract pin. That pin confirmed the headless entry point, the JSON event stream, the persistent RPC surface, the installed version, the missing-provider failure, the inconsistent failure exit codes, extension validation, and the trusted install verb for pi-subagents.

Pi's native skills and prompt-template discovery remain labeled documented but unconfirmed. pi-subagents and pi-mcp-extension are called out as community packages, not first-party Pi features. The packet does not add a second advisor identity or a packet-local execution adapter.
