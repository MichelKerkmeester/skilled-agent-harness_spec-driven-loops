Devin's live roster added a `grok-4.6` family (confirmed via `devin models list`, 2026-08-12) alongside the still-present `grok-4.5` family — Cognition has not dropped 4.5. This skill's curated Grok family adds all 4 4.6 uids alongside the existing 3 4.5 uids, an addition rather than a swap. The 4.6 family carries a fourth effort tier, `xhigh`, that 4.5 never had. Every `grok-4-6-*` uid was dispatch-tested end to end before landing here. Model rosters and tables across the touched docs are now sorted alphabetically by family, then by uid, rather than grouped by release order.

---

#### Grok 4.6 joins Grok 4.5

`DEVIN_SUPPORTED_MODELS` in `executor-config.ts` and its hand-duplicated mirror `DEVIN_ALLOWED_MODELS` in `fanout-run.cjs` both add `grok-4-6-{low,medium,high,xhigh}` alongside the existing `grok-4-5-{low,medium,high}`. GLM-5.2, SWE-1.7 and DeepSeek are unchanged. Both allowlist arrays and their unit-test coverage were updated together and resorted alphabetically; the full `runtime` suite (188 tests) and `tsc --noEmit` pass clean.

#### Live verification, not a documentation-only addition

Before any file changed, `devin models list` confirmed the `grok-4.6` family and its 4 uids exist alongside the still-present `grok-4.5` family, and `devin -p --model grok-4-6-high -- "..."` / `...-xhigh` both returned a live model response from a trusted scratch workspace. `grok-4-5-high` was independently re-dispatch-tested too, confirming it still works.

#### Docs updated to match, now sorted alphabetically

`SKILL.md`, `README.md` and `references/{cli-reference,providers-and-models}.md` all move their Grok family description and tables to cover both versions. `references/providers-and-models.md` — the single-source catalog — carries the fullest account, including the fact that Devin still lists 4.5 upstream, and its Cognition table is now sorted alphabetically by family (DeepSeek, GLM-5.2, Grok 4.5, Grok 4.6, SWE-1.7) then by uid within each family.
