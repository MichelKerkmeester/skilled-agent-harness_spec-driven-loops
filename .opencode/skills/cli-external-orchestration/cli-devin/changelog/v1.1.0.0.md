cli-devin's model facts lived in two places that had drifted apart — a §5 block in the CLI reference and an inline roster in the main guide — and both still named model families that a live `devin models list` no longer returns. This release pulls those facts into one authoritative catalog, curates the roster to the families the mode actually dispatches, and leaves the old spots as a compact residue that points at the single source. The goal is one honest answer to "which model, which uid, which permission mode, how to dispatch" instead of two stale ones.

---

#### A single-source model catalog

The model, alias, default, and dispatch-shape facts had no home of their own, so they were duplicated and went stale. This release adds `references/providers-and-models.md` as a dedicated single-source catalog of cli-devin's model families, uids, default, permission-mode lever, and dispatch shapes, registered as a routable leaf. The `references/cli-reference.md` §5 model section and the `SKILL.md` roster were trimmed to a compact residue plus a pointer to the catalog, so the facts are maintained in exactly one place.

---

#### A per-family table under the Cognition provider

A flat list made it hard to compare variants at a glance. The catalog's section 2 was restructured into a per-family table under a `### Cognition` provider heading, with model uid, context window, and tier notes on each row.

---

#### Roster curated to what Devin actually returns

The roster carried families that no longer resolve, which made model selection guesswork. It was curated down to four families, with ids read from a live `devin models list`:

- **GLM-5.2** — six variants: `glm-5-2`, `glm-5-2-max`, `glm-5-2-1m`, `glm-5-2-max-1m`, `glm-5-2-none`, `glm-5-2-none-1m`.
- **SWE-1.7** — `swe-1-7`, `swe-1-7-medium`, `swe-1-7-lightning`.
- **Grok 4.5** — `grok-4-5-low`, `grok-4-5-medium`, `grok-4-5-high`.
- **DeepSeek V4 Pro** — `deepseek-v4-pro` (uid `deepseek-v4`).

The stale `adaptive`, `opus`, `sonnet`, `claude`, `haiku`, `gpt`, `codex`, `gemini`, `kimi`, and the SWE-1.6 ids were removed. The catalog default moved from `adaptive` to `swe` (the `swe` alias resolves to `swe-1-7-lightning`); the `adaptive` router stays available via `devin models list` but is out of the curated catalog's scope.
