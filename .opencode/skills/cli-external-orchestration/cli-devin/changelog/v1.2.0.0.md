The cli-devin README read like a reference card: an aspect table where the overview should be, plus stale model examples and a version field that lagged the changelog by a full release. This release rewrites the README purpose-first on the shared skill README template, with a one-line pitch, a problem-first overview, a capability section for the delegation surface and current model facts that point to the single-source catalog. The version field moves to 1.2.0.0 to match the release history.

---

#### A purpose-first front door

The old README opened with a tabular aspect table and buried the outcome the skill delivers. It now opens with a one-line pitch and an at-a-glance table, then a problem-first overview that names when a second AI perspective pays off. A capability section covers the delegation surface: multi-model dispatch, subagent delegation, cloud handoff, session management and MCP integration.

---

#### Current facts only

The old README carried model examples that the curated catalog retired: `adaptive`, `opus`, `gpt` and the SWE-1.6 ids. The rewrite documents the four curated families (GLM-5.2, SWE-1.7, Grok 4.5 and DeepSeek V4 Pro), the `swe` default and the permission-mode lever, with `references/providers-and-models.md` as the single source. Every fact that still applies was kept: the self-invocation guard, the cloud handoff mechanics, the subagent profiles, the permission-mode table and the troubleshooting rows.
