# v2.3.1.0 - README rewrite

**Released:** 2026-08-04

The sk-prompt-improve README now reads purpose-first like the rest of the pilot README family: a one-line pitch, a problem-first overview and narrative sections that name the outcome before the tooling. The old reference-card layout led with tables before the why, pointed the verification command at the legacy `prompt:improve` folder name and carried a version field with no matching changelog entry. Every fact survives the rewrite, the version moves to `2.3.1.0` and this entry keeps the README and the changelog in sync.

## What Changed

- Rewrote the README purpose-first on the refined README template: one-line pitch, problem-first OVERVIEW, numbered ALL-CAPS sections with dividers and a framework capability layer.
- Kept every fact the old README carried: the seven frameworks, the DEPTH phases, the CLEAR rubric, the operating modes, the agent escalation path, the quick start commands, the troubleshooting rows, the FAQ answers and all related document links.
- Corrected the verification path from the legacy `prompt:improve` folder name to `sk-prompt-improve`.
- Bumped the frontmatter `version` field from `2.3.0.21` to `2.3.1.0` so the field and the changelog top agree.
- Added this changelog entry at `changelog/v2.3.1.0.md`.

## Not Changed

- `SKILL.md` content and frontmatter stay untouched. The runtime contract still owns routing and workflow rules.
- Templates, scripts, references, assets and the manual testing playbook stay untouched. The README documents current state only.
- No behavior change. The rewrite is documentation-only and requires no migration.
