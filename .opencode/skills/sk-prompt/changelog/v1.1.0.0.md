## What Changed

#### Documentation

- **Purpose-first README** -- The old README read as a tabular reference card: feature lists and a structure tree, with no human entry point and a stale command name. The new README leads with the outcome: a one-line pitch and an AT A GLANCE table up front, a problem-first OVERVIEW and then the hub's two workflow packets. It gains a Model Profile Layer table that states what each of the six maintained profiles covers and an expected-output line for every command shown.
- **Command name corrected** -- The README told readers to invoke `/prompt-improve`. The command and the mode registry actually use `/prompt:improve`. The new README names the real command so the quick start works on the first try.
- **Version and release trail** -- The README version moves from 1.0.0.0 to 1.1.0.0 with this entry at `changelog/v1.1.0.0.md`. Every release now records itself in the skill changelog.

#### Not Changed

- **Stable facts** -- The seven-framework engine with its DEPTH thinking pass and CLEAR scoring, the per-model profiles, the single `graph-metadata.json` advisor identity and `prompt-models` having no slash command all ship unchanged.
