# create-feature-catalog v1.0.1.2

## Changed

- Rewrote the skill README purpose-first on the refined skill README template. The README now opens with a one-line pitch and a problem-first OVERVIEW, adds a capability table for the catalog package (root catalog, per-feature files, category folders), documents the authoring order and the root-versus-leaf boundary, and closes with troubleshooting, FAQ, verification and related documents. The frontmatter version moved from 1.0.0.0 to 1.0.1.2, re-aligning the README with the changelog top.
- Cleaned the README voice to the Human Voice Rules. Three Oxford-comma constructions and two forced three-item enumerations were rewritten, leaving the body free of em dashes, semicolons and Oxford commas.

- The skill contract. The `/create:feature-catalog` invocation, the `feature-catalog/feature-catalog.md` root path, the per-feature file shape with source and validation anchors, the kebab-case category folder rule, the playbook boundary and the validation workflow are preserved from the prior README.

- No `SKILL.md` content, template asset, reference file, vault file or runtime data moved.
