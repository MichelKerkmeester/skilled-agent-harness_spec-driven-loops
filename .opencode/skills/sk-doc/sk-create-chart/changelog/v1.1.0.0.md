The corpus now formats its own numbers, tells the truth about missing readings, says what a shaded step is worth, and pans instead of squashing on a phone. Ten recommendations from the fidelity research were reviewed against the contract. Seven are applied here and three are refused in writing, because an item nobody decided is an item that comes back.

---

## What Changed

#### New Features

- **One number formatter per template, and every printed figure goes through it.** A tick, a value label, a hover title and a table cell can no longer disagree about the same number. Grouping is fixed to a comma rather than read from the host locale, because a delivered file has to look on the machine that opens it exactly as it looked on the machine that made it. Rounding at six decimals strips the dust binary arithmetic leaves on an axis step: a ladder rung that read `0.6000000000000001` now reads `0.6`. Where a ladder has fractional steps, every rung prints to the same decimal count, so the candlestick axis reads `87.5 · 100.0 · 112.5 · 125.0 · 137.5 · 150.0` as one column instead of a ragged mix.
- **A missing reading breaks the mark instead of being drawn as zero.** This was the worst defect in the corpus and it was silent. A `null` in a daily line reached the geometry as zero, so the line dived to the baseline on a day nobody had measured, and the low-point annotation printed the word `null` beside it. `daily-line` now breaks into segments at the gap, `daily-range` leaves the day undrawn while keeping its slot on the axis, and `stacked-area` breaks the whole stack rather than substituting a zero that would drop every band above it. Each of the three prints how many readings were left out, because a line with a hole in it and a line that is simply short look the same.
- **A visible notice when a form is given more data than it can hold honestly.** The catalog has always stated a shape per row and nothing enforced it, so a delivery with three times the data drew anyway. `scatter` past twenty points and `heat-matrix` past a hundred cells now grow the frame and print one line naming the count and the ceiling. A console warning was the alternative and was rejected: the person a ceiling protects is reading a chart, not a developer console.
- **A ramp legend on the heat matrix.** The grid was shaded by value and said nowhere what a step was worth. A reader could see that one cell was darker than another and had no way to price the difference. Five swatches now run from the palest step to the darkest between the low and the peak.
- **Rule 14: narrow screens pan, they do not squash.** Every file in the corpus gives its figure region a horizontal scroll and its drawing a minimum width, so a phone-width screen moves the chart sideways instead of shrinking it until the axis labels sit on each other. The corpus check enforces it, including that the floor is never wider than the drawing's own `viewBox`.
- **Series-to-swatch mapping in the figure description,** on the five forms whose colours are only resolvable through a detached key. A screen-reader user was told a stacked column had three product lines and never which band was which. The mapping is written against the key order and the stacking order rather than against colour names, so a palette swap cannot make the sentence wrong.
- **Numeric budget comments where labels collide.** Seven forms now carry the arithmetic behind a gutter width, a thinning divisor or an axis spacing: how many units the gutter holds, how many characters that is at the label size, and what to change when it runs out. The constants were correct and unexplained, which is how a later author picks a different one.

#### Fixes

- **`progress-single` measured its headline number by character count.** The unit sat at `String(value).length * 34`, which was already an estimate against a proportional font and became wrong outright once the formatter could insert a group separator. It now advances by the measured text length, with the count kept as the fallback before layout.
- **`daily-line` could mark a gap as the low point.** A missing value compares as smaller than every real one, so an unfiltered search for the minimum picked the hole. The search now runs over the readings that exist.

#### Notes

- **Three recommendations are refused, in writing.** A diverging colour system has no catalog form that consumes a midpoint, and adding it now would repeat the fourth-system mistake the colour reference already documents, and the condition that would reopen it is written down. Pattern fills would change the visual register of every chart to solve a problem no current form has, since each already carries a non-colour cue. A gradient legend was asked for on both shaded forms and neither got one: both put values into five discrete steps, and a continuous bar would promise a resolution the encoding does not have, so the heat matrix received a stepped ramp and the calendar grid kept the stepped ramp it had.
- **Rule 14 is asserted from the stylesheet, not from a rendered page,** and the contract says so. A headless browser hands back the DOM, and the DOM does not say whether the page overflowed. The numbers that would answer it live in layout. The check proves the affordance is declared, which is the part an author forgets. Whether a chart is legible at its floor stays a review question.
- **The formatter is duplicated in every template rather than shared,** which is the corpus idiom and not an oversight. A template is one file that a recipient edits by hand, so there is nowhere for a shared helper to live that does not break the delivery unit.
- **Every change was proven against a fixture, not against the shipped demo data.** The shipped data has no gaps and exceeds no ceiling, so a run over it proves only that nothing broke. Copies with nulls injected, with a series past its ceiling, and with an axis step that lands on a value binary floats cannot hold were rendered before and after each fix.
