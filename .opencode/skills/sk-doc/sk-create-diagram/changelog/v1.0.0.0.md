# v1.0.0.0 - Initial release

**Released:** 2026-08-12

Initial release of `create-diagram` as a nested `sk-doc` workflow mode, forked from the third-party `diagram-design` plugin (cathrynlavery/diagram-design) and rebuilt to the `sk-create-skill` authoring contract.

## What's Included

- `SKILL.md` restructured to the required `WHEN TO USE / SMART ROUTING / HOW IT WORKS / RULES / SUCCESS CRITERIA / REFERENCES` order, with all five mandatory connector rules intact.
- The shared editorial design system: `references/foundations/style-guide.md`, `onboarding.md` (agent-mediated), `output-spec.md`, and four primitives (annotation callout, sketchy filter, terminal chrome, icon library).
- All 27 diagram-type references under `references/types/type-*.md`, each with a canonical example asset.
- draw.io and Mermaid extraction (`scripts/drawio_extract.py`, `scripts/mermaid_extract.py`, both stdlib-only) plus their redraw references and `references/import-export/export.md`.
- Registration in the `sk-doc` hub: `mode-registry.json`, `hub-router.json`, `command-metadata.json`, and the `/create:diagram` command (router + presentation + auto/confirm workflow).

## Notes

Content ported from the source plugin was restructured, not copied verbatim, to conform to this repository's frontmatter, section-order, and root-metadata-class contracts. The multi-variant example gallery (light/dark/full per type) was trimmed to one canonical example per type plus a small set of special-pattern examples; the source's own CI/lint tooling was not ported since it validates the source repo's release process, not this packet's runtime content. Full trim manifest and rationale: `specs/sk-doc/028-sk-create-diagram/001-inventory-and-skill-contract/decision-record.md`.
