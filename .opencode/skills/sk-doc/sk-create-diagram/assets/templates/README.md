# assets/templates

The 4 base HTML templates a new diagram is built from.

---

## 1. OVERVIEW

Loaded `ON_DEMAND` per `SKILL.md`'s Resource Loading Levels — copy the variant matching the request, then draw into it.

---

## 2. FILES

| File | Variant |
|---|---|
| `template.html` | The default light editorial skin. |
| `template-dark.html` | The dark-mode inversion of the default skin. |
| `template-full.html` | The full/consultant-density layout variant. |
| `template-terminal.html` | The fixed CLI-chrome terminal skin (see [`primitive-terminal.md`](../../references/primitives/primitive-terminal.md)). |
