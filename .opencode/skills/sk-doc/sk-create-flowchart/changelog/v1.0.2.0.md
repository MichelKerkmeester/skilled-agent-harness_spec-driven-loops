# v1.0.2.0 - Purpose-first README rewrite

**Released:** 2026-08-04

The skill README was rewritten purpose-first against the refined skill README template from the sk-doc fleet standard, using the mcp-obsidian README as the exemplar. The README now opens with a one-line pitch and a problem-first OVERVIEW. The tabular reference-card sections were replaced with narrative sections that keep every verified fact from the old version. The frontmatter version field was bumped from `1.0.0.0` to `1.0.2.0` so the README and the changelog head agree. This entry records the release.

## What Changed

#### Documentation

- **README rewritten purpose-first** -- the old README carried a pitch and an OVERVIEW but kept AT A GLANCE, TROUBLESHOOTING, FAQ and VERIFICATION as reference-card tables. The rewrite keeps the pitch and OVERVIEW, dissolves the tables into narrative sections and adds a capability table naming all six pattern assets. Every verified fact survives: the validator contract, the six patterns, the related-skill pointers and the reference links.
- **Version field bumped** -- the frontmatter version field moved from `1.0.0.0` to `1.0.2.0` so it agrees with the changelog head after this release.
- **Changelog entry added** -- this file records the rewrite at `changelog/v1.0.2.0.md`.

## Not Changed

- `SKILL.md` content for create-flowchart stays untouched.
- Pattern assets, references, scripts and the shared validator stay untouched.
- No other skill README, template asset or vault file was modified.
