# system-skill-advisor v0.11.1.0

The advisor now keeps its command bridge descriptions aligned and distinguishes a successful no-match from an unavailable advisor. The release also records the recounted command census, the refreshed scorer evaluation baseline and the full advisor suite result without changing the release floors.

## 1. NEW

- **Command bridge rename alignment:** `/memory:save` was retired for `/speckit:save`, but the rename reached only the bridge list the scorer consults. The inventory projection in `lib/scorer/projection.ts`, which carries `inventoryId` and `routingEnabled`, now uses the renamed slash id and description too. The gap failed both the drift guard, which compares the two descriptions, and the resolution guard, which found the leftover slash id with no command file behind it. The scorer keys `memory:save` and `command-memory-save` stay unchanged.
- **No-match diagnostic:** The hook routes, fails open or skips. Before this change, both an unreachable advisor and a live advisor that answered with no recommendation emitted `errorCode: NON_ZERO_EXIT` and `errorMessage: CLI_ADVISOR_UNAVAILABLE`, even when the call exited zero. A live or stale advisor with no match now carries `reason: no_recommendation` and `errorMessage: CLI_ADVISOR_NO_MATCH`, with no error code or class. An unreachable advisor keeps its previous wording. The pure result builder in `hooks/lib/skill-advisor-cli-fallback.ts` is exported as a test seam because it is a pure function of the CLI response.

---

## 2. CHANGED

- **Command census pin:** Recounted from 21 to 20 after `/deep:skill-benchmark` was retired.
- **Scorer evaluation baseline:** Re-captured at 152 correct of 195, down from 154 after roughly ninety routing inputs changed. Two prompts were added to the accepted parity regression list because they route correctly with a live skill graph and lose only in the pinned no-database regime.
- **Full advisor suite:** 868 passed, 0 failed, 7 skipped of 875.

---

## 3. NOT CHANGED

- **Release floors:** Untouched.
