# v1.4.0.0 — story upkeep as a surface standard

The surface now carries the story-upkeep rule: every renderable component change creates or updates its
co-located `*.stories.ts` (scaffolded by `npm run story:new`), and the coverage gate
(`npm run story:coverage`) enforces it, so the Storybook catalog stays trustworthy on every change.

## Changed

- §3 SURFACE STANDARDS gains a story-upkeep standard, pointing at the repo-root `STORYBOOK.md`.

## Why

The rule was authored on a stranded refactor branch that a fresh rewrite superseded, so it never
reached the live skill — a coverage gate the surface enforces but never taught. This lands the rule
directly, without the branch's superseded divider grammar.
