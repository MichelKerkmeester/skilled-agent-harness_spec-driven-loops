# v1.3.0.0 — folder documentation earns its code map

The mobile-cli surface now teaches the measured folder-documentation threshold: a `CODE.md` is required
for folders with three or more direct source files or child source folders, while smaller leaf folders
keep one `README.md`. The reason is part of the convention because documentation ceremony reads as content
and rots the same way.

## Changed

- Replaced the universal README/CODE requirement with the thresholded rule and its measured rationale,
  including ownership, caller boundary, and change-placement guidance for single-document folders.
- Documented the two-way `scripts/naming/scan-folder-docs.mjs` enforcement so both missing and unnecessary
  code maps are caught.
- Bumped the surface version to `1.3.0.0`.

## Not Changed

- The naming grammar, shared ownership, module and comment grammar, runes guidance, and workflow
  reference topology.
