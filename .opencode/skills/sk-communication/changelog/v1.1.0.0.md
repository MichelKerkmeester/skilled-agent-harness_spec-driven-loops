## [**1.1.0.0**] - 2026-08-28

Adds a second lane. The skill previously adapted an explanation on one axis only -- register, saying the same thing in plainer words. It now also adapts modality and depth, so a request that words cannot carry becomes a picture instead.

---

## What Changed

#### Explanation Lane

- **`/rewrite:explain-visually`** -- explains a named topic, or the previous reply when no topic is given, as the smallest visual that answers the question. Belongs to the rewrite family because the no-topic case re-renders the prior reply, the same act as `/rewrite:response` in a different medium.

- **Modality dial** -- picks the form that fits the content: pseudocode for logic, a call tree for control flow, a component or file tree for structure, Mermaid for flow and sequence, a diff for change, a code block where syntax matters, HTML for dense comparison.

- **Depth dial** -- `expert`, `plain`, or `novice`, deciding how much prior knowledge the explanation may assume. Simplification applies to words and never to facts; a `novice` answer may be incomplete but may not be wrong.

- **Opt-in artifact** -- display-only by default. `--artifact` creates one new self-contained HTML file and never edits an existing one.

#### Skill Contract

- **Two-lane model** -- SKILL.md now states which lane a request belongs to, and why their gating differs: Lane A rewrites a byte stream and may reach a model, Lane B synthesizes in-context and carries neither risk, so the enablement flag and egress rules do not apply to it.

- **On-disk rule disambiguated** -- the bar on rewriting durable files covers editing an existing file. Creating a new explanatory artifact on explicit request is Lane B behavior.

- **Lane-aware smart router** -- routing now selects a lane before selecting resources, so an explanation request loads the visual rubrics instead of the package map.

#### Unchanged

- **Projection lane untouched** -- no change to the package, its adapters, the enablement flags, or the evaluation harness.

- **Still hand-invoked** -- the skill remains on the advisor route-exclusions denylist; both lanes are invoked by command, never by recommendation.
