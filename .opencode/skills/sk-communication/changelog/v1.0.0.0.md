## [**1.0.0.0**] - 2026-08-14

Initial release of the sk-communication skill: a portable projection layer that rewrites terse agent output into plain English while keeping the canonical event stream, transcript, tool data, and model context byte-for-byte unchanged. Projection is off by default for everyone, and every unsafe or failed path returns the exact original.

---

## What Changed

#### Projection Runtime

- **projectMessage orchestrator** -- a provider-transport seam plus a reject-only default judge, so canonical bytes are preserved on every non-approved path.

- **Capability and privacy gate** -- consults the compatibility doctor and fails closed to the exact original on unknown, stale, or incapable routes, and never routes hosted without a fresh, capable, privacy-approved decision.

- **Evaluation and release gate** -- composes a blind non-inferiority signal as a reject-only quality check and blocks a runtime rollout without fresh, dated evidence.

#### Runtime Wiring

- **OpenCode native plugin** -- wires the projection through the chat.message hook, default-off and fail-open.

- **Five CLI-output wrappers** -- Claude Code, Codex, Pi, Devin, and Cursor over a shared wrapper framework and per-runtime stream parsers.

#### Enablement

- **Off by default** -- an operator opts in per machine with COMMUNICATION_PROJECTION_ENABLED or a git-ignored enablement.local.json at the package root.

- **Held out of advisor routing** -- the skill sits on the advisor route-exclusions denylist, so the recommender never surfaces it and you invoke it by hand.
