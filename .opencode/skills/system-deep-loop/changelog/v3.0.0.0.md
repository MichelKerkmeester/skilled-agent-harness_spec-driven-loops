# system-deep-loop v3.0.0.0

Retires the alignment mode and, with it, the conformance-benchmark capability that ran on it. The mode was not standalone: it held the shared conformance engine that `/deep:command-benchmark` and the `/create:benchmark` conformance axis both executed, so removing the mode alone would have left those surfaces pointing at a deleted engine. The operator approved the cascade. The hub now registers six modes instead of seven and exposes six `/deep:*` commands instead of eight. Major version because the removed commands and mode key are public surface.

> Spec folder: `specs/system-deep-loop/036-deep-loop-innovation/025-deprecate-deep-alignment` (Level 2)

---

## Removed

#### The alignment mode

- **Mode packet** — the 126-file `deep-alignment/` packet, including the conformance engine (`scoping.cjs`, `check-convergence.cjs`, the peer adapters) and the command-behavior matrix scheduler.
- **Registry entry** — the `alignment` `workflowMode` and its `alignment-convergence` `backendKind` are gone from `mode-registry.json`. Surviving modes are `research`, `review`, `ai-council`, `agent-improvement`, `model-benchmark`, `skill-benchmark`.
- **Dedicated runtime** — `deep-alignment-ledger-schema/`, `deep-alignment-sealed-artifacts/`, `deep-alignment-reducers/`, `alignment-identity.cjs`, `reduce-alignment-state.cjs`, `deep-alignment-state-deltas-contract.ts`, `leaf-artifact-writer.ts`, and their tests.
- **Agents** — the `deep-alignment` leaf agent across all six runtime directories.

#### The conformance-benchmark capability

- **`/deep:alignment` and `/deep:command-benchmark`** — both commands and every auto, confirm, presentation, legacy and compiled asset behind them; `smoke-command-benchmark.cjs` with them.
- **`/create:benchmark` conformance axis** — the `conformance_benchmark` family branch, leaving `mcp_promotion` as the surviving family.
- **Authoring templates** — the `sk-create-benchmark` conformance family and its `conformance-benchmark/` asset and reference directories.

---

## Changed

- **Shared runtime surgery** — alignment was removed from roughly twenty-five shared files: the mode enums and unions, the `mode-append-gateway`, `shipped-census` (counts reconciled eight to seven), projection manifests, stopping-clocks, path-coverage termination, `compile-command-contracts`, and the compiled-routing `registry-compiler.cjs` with its canary fixtures.
- **Registrations and generated metadata** — `hub-router.json`, `command-metadata.json`, `description.json`, `graph-metadata.json` and `ROUTER.md` were hand-edited; the advisor routing projection, `leaf-manifest.json` and the compiled command contracts were regenerated from their cleaned sources so the drift guards stay green.
- **Documentation** — the hub now advertises six user modes and four workflow families. A follow-up pass closed the references that named `alignment` as a live mode in the runtime and shared-progress READMEs, the behavior-benchmark framework mode enum and budget policy, and the benchmark authoring guide, prefix registry and scenario template. The behavior-benchmark prefix set is now `RSB`, `RVB`, `ACB`, `IMB`.
- **Frozen baseline census** — three alignment state-backend rows were dropped from the packet-001 `state-backend-census.json`. The runtime enforces census-equals-manifest, and the alignment projection contract imports the deleted ledger schema, so leaving the rows would have broken a surviving test.

---

## Not Changed

- The six surviving modes, their convergence math, state shapes and artifacts.
- The behavior, model, skill and agent-improvement benchmark families.
- The shared `shared/behavior-benchmark/` framework, which is independent of the retired mode.
- Historical changelogs, benchmark reports and spec packets, which keep their original references as immutable records.

## Verification

- Repo-wide grep across every active surface — `.opencode`, `.claude`, `.codex`, `.cursor`, `.pi`, `.devin` and the root README — returns zero live references to the removed mode, commands or family.
- `node:test` 715 pass / 16 fail, unchanged against the recorded baseline; the single failing file is pre-existing and carries no alignment reference.
- Runtime vitest 6 failed / 2498 passed, every failure pre-existing and in the timing-sensitive stress and ledger family.
- The routing-registry, command-bridge and contract-drift guards pass, as does the family-registry test with the conformance family removed.
- A ten-iteration independent review of the removal returned PASS on every iteration with zero P0 and zero P1 findings.

---

## Upgrade

Anyone invoking `/deep:alignment` or `/deep:command-benchmark` must stop; there is no replacement, and the capability is retired rather than relocated. `/create:benchmark` still authors `mcp_promotion` packages. A future need for conformance benchmarking requires re-introducing an engine.

## Known Follow-up

Two orphaned prompt mirrors under `.codex/prompts/` and `.pi/prompts/`, plus dangling command-mirror symlinks under `.claude/commands/deep/` and `.cursor/commands/`, survived the first removal pass because the mirror generators were not re-run. Both were found by review and closed in follow-up commits; the prompt-sync generators report in sync for both runtimes.
