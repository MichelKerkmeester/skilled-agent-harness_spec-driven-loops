## [**1.6.0.0**] - 2026-09-11

Every commit now carries a stable address. Before this release a commit was reachable only by a hash nobody remembers or by a human reading `git log`, so finding the commits behind a packet meant searching by eye, and a single commit could not be cited by a short ordinal. This release adds a contiguous trailer paragraph to every commit. Packet work carries `Spec: <track>/<packet>[/<phase>...]`, and every commit carries `Commit-Id: NNNNNNN`, a seven-digit repository-wide ordinal minted once under a lock. A `commit-msg` hook enforces the keys, a `prepare-commit-msg` hook stamps them, and three `git log` queries read them back. Retrofitting the existing history is a separate, operator-gated rewrite.

---

## What Changed

#### Every commit gets a trailer paragraph

- **`prepare-commit-msg` stamps `Spec:` and `Commit-Id:`.** The stamper writes a blank line and the trailer paragraph when a commit has a body. It keeps the id on amend, because the amended commit already owns it, and re-mints on cherry-pick, because the picked commit keeps its own. In a repository without the allocator it exits silently.
- **`commit-msg` polices the keys.** The hook whitelists `Spec:` and `Commit-Id:`, refuses an id that is not exactly seven digits and refuses an id that already belongs to another commit. Its duplicate scan excludes `HEAD`, so an amend never collides with itself.
- **`Refs:` is external links only.** A packet reference now lives in the `Spec:` trailer instead of the `Refs:` line.

#### Ordinal allocation and branch stamping

- **`scripts/commit-id-naming.sh` mints the ordinal.** It allocates the next value under a lock with a history-derived high-water mark, and it exposes `allocate`, `next`, `scan-max`, `validate` and `rebuild-highwater`.
- **`scripts/stamp-branch.sh` stamps a rebased branch.** Given a branch and a base, it stamps an ordinal onto each unique commit so a rebase does not leave the branch's commits unidentified.

#### The feature is documented and searchable

- **Three queries read the trailer.** `git log -E --grep='^Spec: sk-git/028'` lists a packet's commits, `git log --fixed-strings --grep='Commit-Id: 0009113'` finds the commit that owns an ordinal and `git log --format='%(trailers:key=Commit-Id,valueonly)'` lists every stamped id.
- **The catalog and the playbook cover it.** The feature catalog carries a "Commit Identity And Search" subsection and the manual testing playbook carries scenario GIT-044.

## Not Changed

- The Conventional Commit subject and body grammar, the type and scope priority orders and the artifact-filtering rules are untouched.
- The numbered-worktree grammar, the per-namespace allocator and every pre-push and pre-commit gate are untouched.
- The existing history is not rewritten by this release. That retrofit is a separate, operator-gated rewrite.

---

## Migration Notes

New commits pick up the trailer paragraph automatically once the updated hooks are installed. No action is required for a repository that does not ship the allocator, because the stamper exits silently there. Existing commits stay as they are until the operator runs the separate history rewrite.
