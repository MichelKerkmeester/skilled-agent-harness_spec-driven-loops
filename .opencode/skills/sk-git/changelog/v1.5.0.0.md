## [**1.5.0.0**] - 2026-08-15

This release hardens sk-git's git safety layer so no gate can silently strand a push, and adds a SessionStart reconcile that keeps the shared primary checkout current on its live branch without ever touching uncommitted work. A companion helper restores machine-local spec pointers after a destructive clean. Branch grammar, the allocator, and the commit rules are unchanged.

---

## What Changed

#### Loud, classified git gates

- **Every pre-push and commit gate now emits a stable `[gate:<name>]` marker when it blocks.** The naming, remote-permission, mass-deletion, skill-root-metadata, and test-suite gates each name themselves and the exact fix command instead of failing with a generic message. A broken optional validator no longer exits past the independent gates that run after it.
- **`git-sync.sh` classifies and durably logs a blocked autosync push.** It captures the hook output, identifies which gate rejected the publish, replays the diagnostics, prints a loud `AUTOSYNC BLOCKED` line, and appends a `blocked gate=<name> fix=<command>` record to the common-dir log. A gate rejection can no longer be mistaken for a silent push race.

#### SessionStart primary-checkout reconcile (new)

- **New `git-primary-reconcile.sh` keeps the primary checkout current on its live branch.** It acts only in the main checkout, only on the resolved live branch, and only when tracked files are clean. It fast-forwards when behind and rebase-publishes local commits when ahead, so a session that commits directly in the primary no longer strands the checkout ahead of and behind origin.
- **It never touches uncommitted work.** A dirty tracked tree, a linked worktree, a non-live branch, a rebase conflict, or a pre-push gate rejection each stop it safely and loudly. Untracked build output is ignored, a rebase abort is asserted back to the original clean state, and every internal failure is non-fatal so session start always continues.
- **Wired into SessionStart for every runtime** (Claude, Codex, OpenCode, Pi), each backgrounded so startup is never delayed. This replaces the follower daemon that was never auto-started with a reliably wired step.

#### Machine-local spec pointer restore (new)

- **New `relink-local-specs.sh` recreates the gitignored symlinks** for machine-local spec folders whose real content lives outside the working tree. It is idempotent and refuses to invent a link when the target is missing, so a `git clean -fdx` can delete only a re-creatable pointer, never the data behind it.

## Not Changed

- No branch grammar, allocator, or commit rule changed. The owner-first naming and remote-push permission model stay untouched.
- The mass-deletion and remote-permission safety gates stay fully blocking for real violations. The change only guarantees every block is loud and logged.

---

## Migration Notes

The reconcile and autosync loop is on by default in the main checkout. Disable the whole loop with `MK_LIVE_SYNC_DISABLED=1`, the reconcile leg alone with `MK_PRIMARY_RECONCILE_DISABLED=1`, or the publish leg with `SPECKIT_AUTOSYNC=0`. The full gate map and reconcile behavior live in `references/continuous-integration.md`.
