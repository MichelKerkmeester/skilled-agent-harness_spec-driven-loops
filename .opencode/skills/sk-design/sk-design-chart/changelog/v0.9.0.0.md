Three questions the corpus could not answer now have forms: what a number has been doing lately,
whether each period held, and which of these is biggest when the names are long.

## What Changed

#### New Features

- **`spark`.** A trend at KPI size: no axis, no gridlines, no tick labels, three declared variants (line, area, bar), the last reading marked, and the value carried by the metric header. Twenty-four readings in a 176-unit frame.
- **`tracker`.** One block per period across sixty periods, green for held, amber for degraded and the alarm colour for failed, with a legend and a tooltip per block. The status classes are named rather than indexed, so each status takes the colour its meaning asks for.
- **`bar-list`.** A ranked list where the label rides inside its bar and slips outside when the bar is too short, values right-aligned in the mono stack, the largest row emphasised. Long names cost no horizontal room.

#### Notes

- All three pass every existing family; none needed a new one. The catalogue carries a row each with the reader question it answers.
- The corpus is 29 chart forms.
- Built by GLM-5.3-Flash through pi, one form per brief. The conductor moved tracker off the ordered ramp after the capture showed three adjacent steps a reader cannot tell apart at block size.
