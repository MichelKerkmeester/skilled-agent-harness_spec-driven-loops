The Style Reference the stock palette was derived from now lives beside the forms it produced,
instead of being read out of a sibling library of roughly twelve hundred regenerable captures.

## What Changed

#### New Features

- **`assets/style-reference/cursor/`.** The cursor capture, copied verbatim: `DESIGN.md`, `source.md`, `css-variables.css`, `tailwind-v4.css`, `design-tokens.json`, `cursor-canonical.json`. An `origin.md` beside them records where the copy came from and pins every file by hash.
- **`--default` reads the local copy.** `apply-design-md.cjs` no longer reaches across into the sibling skill. Themed output is byte-identical to before the move apart from the provenance line, which now records the local path.

#### Notes

- **Overriding is unchanged.** Pass any `DESIGN.md` path, including one `sk-design-md-generator` has just produced, and the script themes from that instead. The stock reference is a default, not a lock.
- **The copy is severed, not linked.** A regeneration upstream would otherwise change what `--default` produces without a diff, and leave the stock palette derived from a capture that no longer exists. Re-copying is now a deliberate act with a diff; the cost is that a genuine upstream improvement has to be pulled in on purpose.
- **The new directory is inert to every walker.** The corpus check, the gallery builder and the screenshot renderer all filter to `.html`, so a directory of Markdown, CSS and JSON under `assets/` is invisible to them. Verified rather than assumed.
- **`design-tokens.json` keeps its name.** The applicator picks up a sidecar named exactly `tokens.json` beside a `DESIGN.md` and reads `darkMode` from it. The bundle's file is a different schema under a similar name, so renaming it would make the script consult a file that cannot answer, and say nothing.
- The four values that depart from the reference, and why each was moved, are unchanged and still named in the palette source.

## Files Changed

- `assets/style-reference/cursor/**` (new), `scripts/apply-design-md.cjs`, `assets/color/palettes.json`, `references/color-system.md`, `references/design-md-theming.md`, `SKILL.md`, `README.md`.
