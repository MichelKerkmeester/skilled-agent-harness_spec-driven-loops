Everything the last four releases recorded as a gap is closed. Two of them were checks that could
not fire, one was a paragraph describing a palette that no longer ships, and one was the derivation
this packet rests on being documented rather than held.

## What Changed

#### Fixes

- **A checker guard that could never be true.** `metric-block` compared a repository-relative label against a resolved directory, so its first assertion never ran on a shipped form: a form drawing no metric header could drop its declaration entirely and the corpus stayed green. The family now runs over the whole corpus, 122 assertions where it previously reached only deliveries.
- **A colour paragraph describing a palette that was replaced.** `references/color-system.md` illustrated the theme-boundary rule with a categorical rotation into navy, gold and violet-blue. The shipped categorical system rotates nothing: all four hues clear the mark gate on both grounds, and only the fourth value moves, back to its measured tone. Rewritten with the measured ratios.

#### New Features

- **`palette-derivation`.** The palette is a derivation of one Style Reference and nothing held it to that. The four departures are now structure rather than a prose note, each naming the gate it was made to clear and what it is measured against, and the family checks the reference is still the file the palette came from, that every value is published by it or accounted for, and that each departure is still both necessary and sufficient.
- **`points` is held in both directions.** A form promising marks must draw them, and a form declaring none may no longer paint a visible one. A circle built in a form the rule cannot parse is an error rather than a pass, so the check cannot go quiet on a form it did not understand.

#### Notes

- **The four references the test suite borrows are vendored.** They are coverage for the override path, and coverage that fails when an unrelated library is pruned is coverage nobody can trust.
- **Three tests were added for the two carried references,** because nothing in the suite would have noticed if either stopped deriving. One of them asserted a value against itself on the first pass; the constant it wanted is now exported and the assertion is real.

## Files Changed
