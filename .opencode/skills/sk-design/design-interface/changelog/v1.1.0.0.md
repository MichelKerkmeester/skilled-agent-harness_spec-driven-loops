# v1.1.0.0 - Original design guidance, Apache dependency removed

**Released:** 2026-07-27

---

## 1. OVERVIEW

The interface design guidance no longer derives from an upstream skill. `references/design-process/design-principles.md` was re-authored so its wording is this skill's own, and the Apache-2.0 licence that covered the borrowed text was removed along with every citation that pointed at it.

The ordering mattered: the licence could only go once the text it covered was genuinely replaced. Removing it first would have left borrowed wording shipping without its terms, which is a compliance regression rather than a cleanup.

---

## 2. CHANGED

- `references/design-process/design-principles.md` — all six sections re-authored. The guidance is unchanged in substance: ground the work in its subject, treat the hero as a thesis, make structure carry meaning, earn deviation once, budget boldness, and write interface copy as design material. The machine-detectable default-look calibration now points at the mechanical preflight card, which already owns those checks as binary rows, rather than restating a palette inline.
- `SKILL.md` — upstream attribution removed from the frontmatter metadata, the intro, the resource table, and the provenance line.
- `README.md` — provenance answer and the licence row in the file map rewritten.
- `manual-testing-playbook/` — the licensing-and-provenance scenario is deleted. Its pass condition was the presence of the licence file, so it cannot survive the file it existed to protect. Playbook counts reconciled from 31 scenarios across 20 categories to 30 across 19.

---

## 3. REMOVED

- `LICENSE.txt` — the full Apache-2.0 text, removed with `git rm` so it does not return from `HEAD` on the next checkout.
- `manual-testing-playbook/licensing-and-provenance/` — the scenario directory.

---

## 4. NOTES

An earlier de-vendoring pass had already removed the MIT-licensed data files, the search scripts, and the third-party notices, leaving this licence as the last remaining obligation. That obligation is now discharged at its source rather than hidden.

Removing borrowed wording ends the licensing obligation; it does not erase the influence. The principles themselves are general design practice, and this change makes the expression the skill's own.
