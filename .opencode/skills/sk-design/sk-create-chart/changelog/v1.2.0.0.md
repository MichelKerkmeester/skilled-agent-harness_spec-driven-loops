The corpus took a visual overhaul in seven phases. Every chart now carries one chrome, moves once when it opens, answers a pointer, paints on either ground and says so when it has nothing to draw. A twenty-first form landed for the question nothing in the index answered, and the corpus check grew from fifteen named checks to twenty-five, and from one browser-backed check to three, because a rule the tooling does not check is a wish and this release wrote eight rules before it enforced them.

---

## What Changed

#### New Features

- **One chrome across every file.** Twenty-nine files each typed `border-radius: 10px` and another twenty-one corners were typed into drawing code as `rx` values. All fifty are gone. Five corner rungs off one 2px knob live beside the colours in `assets/color/palettes.json`, ride into every file inside the palette block that already existed, and a `radius` check fails a corner typed anywhere else. Every figure a reader compares is set in a system mono face with tabular figures, so an axis rung, a value label and a table cell line up digit under digit. Grids are dashed and drawn below full strength, because the rule token is also the card border and a grid at the same weight competes with the frame around it.
- **Motion that settles, on the nine forms it suits.** Three time-series forms wipe in from the left over one second and six bar forms grow each mark from the anchor it is measured against over half a second, with consecutive marks a twentieth of a second apart. The other eleven forms do not move and carry no fallback, which is why the gate checks that the grep returns nine files rather than at least nine. The stagger is capped rather than accumulated, so a file settles inside one second whatever a reader pastes into its data block.
- **A pointer, on the twelve forms that gain from one.** A hover card on the seven forms whose marks carry a value the picture cannot print, a key inside the figure on the four multi-series forms, and a dim to a third on the five where holding one series against the rest is the reading. Every key entry is a button rather than a label, because the key is also the control for the dim and a control a pointer can reach has to be reachable from a keyboard.
- **A dark ground, answered rather than chosen.** Every file carries a second palette block behind a `prefers-color-scheme` query with its own sentinel pair. The palette source gained a dark ground, dark text roles and dark series values for all three systems, chosen against near-black rather than derived from the light ones, because mixing a colour toward the surface is exactly what makes a mark disappear when the surface is dark. Nothing in a file switches themes: a delivered chart has no state to keep a preference in, so the reader's operating system is the only signal, and a chart printed from a dark browser still goes onto paper the way it always did.
- **Every form says so when the data block holds nothing readable.** An empty frame and a chart whose values are all zero look identical, so a reader shown an empty box had no way to tell which one they were holding. All twenty-one forms now print one line in the middle of the frame and draw nothing else. Readability is what the guard tests rather than length, because a block whose entries all carry values that are not finite numbers has length and still has nothing to draw.
- **`bar-line-composed`, the twenty-first form.** Columns for a count and a line for a rate over the same periods, which is the one question the index had no row for: `waterfall` covers signed steps against a running total and nothing else put two measures with different units on one period axis. The second scale is a condition rather than a setting. The file divides the larger of the two peaks by the smaller, draws a right-hand ladder at a factor of ten or more and one shared ladder below that, so an editor who changes the numbers gets whichever answer the numbers give. A dual axis is the easiest way to lie with a chart, and the arithmetic is what keeps this one honest.
- **A published type scale with a gate behind it.** Six named roles and three named departures, recorded from what the corpus already did rather than proposed. They live in the palette source beside the corner ladder and `type-scale` rejects a size on neither list, which is the point: the size of the next form's axis tick is now a choice out of six rungs rather than a guess.
- **Eleven more checks, every one written after the rule it enforces.** `settled-render` compares two opens of every file as pictures rather than only as documents, because a stylesheet animation never touches the DOM. `dark-render` opens each file a third time with the scheme pinned dark and requires a different picture, because a block pasted outside its media query matches the source in both directions and changes nothing on screen. `palette-source-dark` runs every contrast gate against the dark surface as its own line, so one theme's pass cannot be read as covering both. Then eight more in the closing phase: `empty-notice`, `geometry-block`, `catalog-system`, `type-scale`, `interaction-hygiene`, `interaction-state`, `number-format` and `gradient-sweep`.

#### Fixes

- **`progress-single` declared a colour system it was not using.** It sits on `ordered`, whose whole content is that colour encodes magnitude, and its fill was a fixed value that did not move. The fill now sweeps along the ramp with the value. The ramp is anchored to the whole track rather than to the fill, which is the difference between a shade that says how far along the goal the bar has reached and one that says nothing but the end of the bar.
- **Rule 13 had never once fired on a real file.** It read the stylesheet regions and nothing else, so a motion driven from the drawing code matched none of its patterns and would have shipped with no fallback while the check reported a pass. It now reads three routes and checks each against the guard that route can honour, and it rejects two things it never looked for: a fallback that shortens the motion instead of removing it, and an animation that repeats.
- **The empty-data guard read `null` as a reading.** The first version coerced with `Number()` before testing finiteness, and `Number(null)` is zero, so a block of nulls passed straight through to a drawing with nothing to draw. The corpus already had the right test, in the three time forms that break a line at a gap, and the guard now uses it. A fixture found this, which is the reason the phase wrote fixtures.
- **The gap notice on the composed form was drawn outside its own frame.** A period with no rate prints one line under the plot, and the line landed below the bottom edge of the drawing where a reader saw the top half of it. The notice now grows the frame, which is what the ceiling notices elsewhere in the corpus already do.

#### Notes

- **The chrome was proved on two files before it reached twenty.** A chrome change is a twenty-file change, and finding out afterwards that the operator dislikes it costs twenty reverts. Two forms carried the agreed rows and the one row nobody could settle by argument was rendered three ways on a sheet the operator read.
- **The twenty catalog rows were read against the colour definitions one by one, and no row moved.** The phase was built around a research finding that `grouped-bars` sits on the wrong system, and the reading does not support it: its two series are ordered in time, `categorical` is defined for categories that are unordered, and `neutral` is the documented default that wins a tie. What the reading found instead was `progress-single`, correctly declared and behaving as though it were not. Every verdict is written down, including the seventeen that were never in doubt, because the reason a wrong claim survived that long is that nobody had read both documents against each other.
- **The interaction hygiene borrowed from the reference is one line rather than two.** The focus half is adopted through `:focus-visible`, which drops the ring for a reader who clicked and keeps it for a reader who tabbed. The text-selection half is refused outright, because the numbers in a delivered chart are meant to be copied out of it. `interaction-hygiene` now fails both a widening of the first half and any return of the second.
- **The draggable range window is refused, and for two reasons rather than one.** It is allowed only where a form is genuinely dense, past thirty points on a continuous axis, and no form in the corpus reaches that: `daily-line` has a documented ceiling of thirty readings and ships twenty-eight, `stacked-area` ships twenty-four periods, and the new composed form is documented at six to twelve. The second reason survives a raised ceiling. A range window rescales an axis and moves every mark, which contract section 10 already forbids a handler from doing, so the window would need that clause amended before density mattered at all.
- **The six family deliveries were audited against the headline rule and none needed a word changed.** All six carry a scenario filename and a headline that states a conclusion rather than a label. The audit is the deliverable there, not a rewrite: a rewrite invented to justify the task would have been the failure.
- **Every new assertion was watched failing before it was trusted.** Fourteen mutations across the eight closing checks, each applied to a passing corpus, run, read and restored from a copy taken beforehand. A check nobody has seen fail is a line of code with a comforting name, and the recipes are written into `scripts/README.md` so the next reader can repeat them.
- **Two gate keys still carry names written for one ground.** `rampDarkestOnSurface` and `rampLightestOnSurface` read wrong on a dark ground, where the step this corpus calls the darkest is the brightest one. The check tests the end by its distance from the ground rather than by its position in the array and says which end it tested, so the behaviour is right and the names are not. They land as `rampFarEndOnSurface` and `rampNearEndOnSurface` across `color-system.md`, `palettes.json` and `check-corpus.cjs` in one edit or not at all, and that edit is the one thing this release deliberately carries forward.
- **Each document carries its own version and the packet version sits in `SKILL.md` and `README.md`.** A changelog entry's version names the release it describes rather than the packet's current state, which is why the three files in this directory read three different numbers and all three are correct.
