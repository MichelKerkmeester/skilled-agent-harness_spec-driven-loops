# sk-design changelog: v2.0.0.0

`sk-design` was a single skill. It is now a parent hub that projects one design identity and routes
to the mode owning the decision being asked for.

## 1. NEW

- **Four registered modes** -- `sk-design-fundamentals` (the default), `sk-design-md-generator`,
  `sk-design-chart` and `sk-design-diagram`, declared in `mode-registry.json` and routed by
  `hub-router.json` plus the root `ROUTER.md`.
- **The `/design:` command surface** -- `/design:extract`, `/design:chart` and `/design:diagram`.
  Fundamentals routes by alias and carries no command of its own.
- **Rendered screenshots** for every form the two canvas modes ship, kept beside each mode rather
  than inside `assets/`, so a human-facing picture never enters a mode's loadable leaf set.

---

## 2. CHANGED

- Chart and diagram left `sk-doc` and took this hub's name: `sk-create-chart` became
  `sk-design-chart`, `sk-create-diagram` became `sk-design-diagram`. Both hubs were edited together
  so no phrase was claimed twice.
- **Fundamentals stopped being a UI-only skill.** Slide decks, printed layouts and document surfaces
  are first-class alongside screen UI. The WCAG review pass still applies only where the surface is
  a screen.
- The root `SKILL.md` took the shape `sk-code` and `sk-doc` use: a surface router, a stated
  discriminator, an explicit routing rule and an unknown-input fallback.
- `resourceContractVersion` became the number `1` in `mode-registry.json`, matching every peer hub.
  It had been the string `"1.0.0"`, which reads as absent to a numeric check and silently disabled
  the manifest byte-drift, target-collision and reachability checks.
- The mode table gained a command column, so a reader sees the same command the registry declares.

---

## 3. NOT CHANGED

- Mode tool surfaces. `sk-design-md-generator` remains the only mutating mode.
- The chart corpus contract and its checker, which moved unmodified.
- Authored spec-folder records, benchmark reports and run artifacts, which describe what was on
  disk when they were written and keep the old names.
