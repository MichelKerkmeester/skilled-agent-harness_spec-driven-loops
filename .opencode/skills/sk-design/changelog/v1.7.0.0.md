# sk-design v1.7.0.0 - Purpose-First README Rewrite

> Rewrites the skill README on the refined narrative template: a one-line pitch, a problem-first OVERVIEW, a verification close and a version field that finally matches the release history.

---

## Added

- A purpose-first README on the refined template with a one-line pitch in a blockquote after the H1, an AT A GLANCE table, a problem-first OVERVIEW and a verification close.
- A frontmatter version field aligned with the changelog head at `1.7.0.0`. The old field read `1.4.0.0` while the changelog head was `v1.6.0.0`, so the field lagged the release history.

## Changed

- The README body moved from a tabular reference card to a narrative front door. Every shipped behavior claim survives: the two design modes, the two canonical `/interface:*` creation commands, the style-retrieval adapters and the transport boundaries.
- The Human Voice Rules now hold on the README body: zero em dashes, zero semicolons and zero Oxford commas.

## Preserved

- The runtime surface is untouched. `SKILL.md`, `mode-registry.json`, the mode packets and the shared references keep their exact content.

## Verification

- `validate_document.py --type readme` reports zero issues on the rewritten README.
- The HVR grep returns zero matches on the README body.
- Every relative link in the README resolves on disk.
