# Design Knowledge Layer

A condensed, self-contained layer of general design judgment for `sk-design-md-generator`. The skill extracts a live surface's real, measured CSS into a Style Reference; this layer gives it the vocabulary and principles to read *design intent* off that surface, so a reference captures what makes a design itself instead of flattening it to a generic default.

It is intentionally condensed — distilled from a broader design reference base, trimmed to what a measured-extraction skill needs.

---

## Contents

- [register.md](./register.md) — the Brand-vs-Product operating register and its six dials; the first posture read off any surface. This skill *records* the register a surface expresses, it never authors one from a brief.
- [register-card.md](./register-card.md) — a one-page fill-in card for resolving a surface's register and reading its dial defaults.
- [anti-slop-principles.md](./anti-slop-principles.md) — how to tell deliberate design from generic AI-default decisions, so a reference preserves real intent (or honestly names slop).
- [cognitive-laws.md](./cognitive-laws.md) — eight cognitive laws (Hick, Miller, Fitts, Doherty, and more) as concise rationale for why a captured hierarchy or interaction works.
- [numeric-design-laws.md](./numeric-design-laws.md) — a citable index of numeric thresholds for contrast, motion, spacing, type, and neutral color.
- [design-token-vocabulary.md](./design-token-vocabulary.md) — shared naming for color, type, layout, elevation, motion, and state tokens.
- [design-principles-digest.md](./design-principles-digest.md) — a condensed read of what deliberate design looks like: subject-grounding, a thesis hero, meaningful structure, earned deviation, purposeful motion, restraint, and writing as material.
