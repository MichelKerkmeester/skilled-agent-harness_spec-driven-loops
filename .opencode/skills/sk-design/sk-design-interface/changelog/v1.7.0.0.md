# v1.7.0.0 - interface README rewritten

The `interface` mode README moves from the tabular reference-card style to the purpose-first narrative standard the mcp-obsidian pilot set and the refined skill README template codified. A human reader now gets a one-line pitch, a problem-first OVERVIEW, a capability layer table and a verification close, with every fact from the prior README preserved.

## New

- Purpose-first README: a one-line pitch blockquote after the H1, a problem-first OVERVIEW and the numbered ALL-CAPS H2 section model with `---` dividers.
- `### The Interface Judgment Layer` capability table mapping the token system, the AI-default critique, the mechanical gates, interface copy and corpus grounding to what the skill operates.
- `### What It Does Not Own` boundary section naming the sk-code handoff, the no style-preset-menu rule and the mcp-code-mode transport rule.
- Expected output stated for the QUICK START `cat` command and every VERIFICATION check.

## Changed

- README version field bumped from 1.6.1.0 to 1.7.0.0.
- Five semicolons and twenty-one Oxford comma hits removed so the README passes the Human Voice Rules punctuation checks.
- Procedure card names corrected to their on-disk hyphenated forms (`aesthetic-direction.md`, `wireframe-exploration.md`), with the two quarantined cards named.
- The three AI-default looks and the VARIANCE, MOTION and DENSITY dials now render as bullet lists instead of inline enumerations.

## Not Changed

- The frontmatter identity (`title: interface` with its trigger phrases) and the surface contract facts (Brand-vs-Product register, two-pass process, restraint mechanism, corpus grounding, mechanical gates, real-UI loop).
- SKILL.md, the references, the assets, the corpus and the playbook stay untouched. This release is README-only.
