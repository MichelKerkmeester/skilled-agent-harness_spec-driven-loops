## 1. SUMMARY

### Technical Context

| Aspect | Value |
|--------|-------|
| **Language/Stack** | Markdown changelog entries with YAML frontmatter, JSON hub metadata |
| **Framework** | sk-create-changelog v1.3.1.0 and its template |
| **Storage** | None |
| **Testing** | `validate_document.py`, `hvr_scan.py`, the route guard, the Hermes check and `validate.sh --strict` |

### Overview
The advisor entries are renamed with `git mv` and their frontmatter and headings fixed line by line, leaving their prose as the 059 retrofit wrote it. The new entries are written from the commit bodies and phase summaries of the work they record. Each bumped `SKILL.md` takes its new anchor, and the manifests and Hermes copies that follow it are rebuilt through their own tools.

## 3. ARCHITECTURE

### Pattern
One orchestrator writes every entry from the recorded history. Two fresh reviewers then check each new entry against the commits it cites before the commit.

### Key Components
- **Advisor alignment**: ten `git mv` renames, then line edits to titles, identity phrases, one H1, one topic phrase and the in-body advisor version names.
- **New entries**: compact for fewer than 10 non-breaking changes, expanded otherwise, per the template's decision rule.
- **Version followers**: `SKILL.md` takes the anchor. The cli-external-orchestration hub also restates its version in `ROUTER.md`, `description.json`, `hub-router.json` and `mode-registry.json`.
- **Route manifest re-mint**: `compiled-route-manifest.cjs refresh` writes each runtime manifest, and its bytes are copied to the authored copy.
- **Hermes mirror sync**: `sync-skills-hermes.cjs` writes into a scratch folder at the mirror's own depth, and only the bumped skills' copies come back.
- **Release notes**: a new domain section in `v4.0.0.2.md` with its glance bullets, description and trigger phrases.

### Data Flow
Commit history and phase summaries, then the entry, then the validators, then the version followers, then the guards. Strict validation and the goal checks run last, from the final state.
