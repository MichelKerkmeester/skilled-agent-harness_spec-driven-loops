## 2. PROBLEM & PURPOSE

### Problem Statement
After phase 006, the residue check still lists five generated files. One is `scorer-eval-baseline.json`, whose `env` block records a flag phase 004 deleted. The other four are the trigger index and its three fixtures. A fresh generation of those four still matches the lane vocabulary, because the generator reads every spec doc and the packets under `specs/` stay as history. So regeneration alone cannot bring repo mode to exit 0. One more check is red for a reason outside the lane: the cite-drift label gate has exited 2 since a folder rename, `main` included.

### Purpose
Every generated surface equals its generator's output, every check mode exits 0, no score moves, and the residue check exits 0 in repo mode with each allowlisted generated file proven to carry only `specs/` history.
