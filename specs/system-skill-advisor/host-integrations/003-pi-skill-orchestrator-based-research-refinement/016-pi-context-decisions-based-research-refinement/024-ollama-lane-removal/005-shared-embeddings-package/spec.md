## EXECUTIVE SUMMARY

Once phase 004 lands, the advisor imports nothing from `system-spec-kit/shared/embeddings/`, but the 14-file package, `shared/chunking.ts`, `shared/utils/retry.ts`, the 1,240-line `hf-model-server.cjs`, the 1,660-line `model-server-supervision.cjs`, the launcher's model-server section, 27 files under the spec-kit runtime tests, six shared tests, the doctor orphan check's model-server class, the sk-doc model-reference validator and the `@huggingface/transformers` dependency still ship, and the dependency pulls 72 to 78 packages into two lockfiles. This phase deletes 55 tracked files (14,864 lines) and edits 72 more in one commit: `shared/types.ts` first, so the shared build fails only in files about to go, then the package, the server, the supervision, their tests and every caller, with the three lockfiles regenerated by `npm install --package-lock-only --offline`. Afterwards the shared and spec-kit builds and tests, the advisor clean build, `run-all.sh` and the sk-doc suite pass, `git grep -l "@huggingface/transformers" -- ':!specs'` prints only the residue check that must name it, and the sweeper's `ollama-preserve` guard still stands.

**Key Decisions**: edit `shared/types.ts` before the deletion inside the same commit and clean `shared/dist` so a stale compiled package cannot hide an importer; retire `MEMORY_DB_PATH` forwarding with the factory that read it; keep `launcher-ipc-bridge.cjs` and remove only its model-server probe; regenerate lockfiles offline and treat `npm ci` as the conductor's stop-for-yes; remove the sweeper's model-server lines and add its allowlist row here; merge with phase 004 only if a gate needs a 004-owned edit.

**Critical Dependencies**: phase 004 committed, so no advisor file imports the package; the npm cache holding every tarball the regenerated lockfiles name; the conductor's yes before `npm ci`.

## 2. PROBLEM & PURPOSE

### Problem Statement
After phase 004 the shared embeddings package has no production importer, but it is still compiled, tested and installed. `shared/types.ts` imports `HfLocalDtype` from it at line 5, so deleting the folder first breaks the shared build. The launcher still loads `lib/model-server-supervision.cjs`, forwards `HF_EMBED_SERVER_URL` and `MEMORY_DB_PATH` to the daemon child, and carries about 200 lines of model-server control; the doctor orphan check and the orphan sweeper still classify `hf-model-server.cjs`; the sk-doc validator reads `registry.ts` as its only canonical source; and `@huggingface/transformers` keeps `onnxruntime-node`, `sharp`, `protobufjs` and 70 other packages in the advisor and spec-kit lockfiles, with 22 CI workflows tuning an `onnxruntime-node` install nothing will need.

### Purpose
No package, server, process class, dependency or lockfile row of the local embedding stack is left, and every build and test that ran before still runs.
