The stdout pipe is closed or errors before the write flushes (EPIPE, or any stream error) -> Node invokes the write callback with that error -> the callback ignores it, calls `commitClaudeDirectiveDeliveryReceipt(output)`, and resolves -> the durable store records the full brief as delivered -> the next turn of the same session returns the head alone, so the model never sees the `Directives:` block for the rest of the session.
