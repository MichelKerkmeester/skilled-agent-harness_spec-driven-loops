## What Was Built

A third reading of the same subject, on a model unrelated to the first two, so that agreement becomes evidence instead of coincidence. Four iterations on GLM-5.3-Flash through the LLM Gateway at max thinking, convergence disabled, 47 minutes. It saw neither prior lineage.

### Where the three readings agree

All three land on the same mechanism, each phrasing it differently. This one puts it best: the verification class could not see the failure class. Every check written during the fallback era judged payloads rather than lifecycles, ran against a warm daemon, and read exit codes. The failures that surfaced were cold-start and path-resolution failures. A harness cannot catch what it is not shaped to look at.

Both readings independently reach the same trap underneath that. Graceful degradation means a wrong answer still exits zero, so every exit-code gate stays green while the answer is wrong.

### Where they diverge, which is the point

Each reading named a residue class the other missed. The prior one named claims that assert the removed thing still exists, and files outside the swept corpus. This one names check-side residue: coverage that silently narrows. A sweep can see names that remain but not coverage that departed, because a presence check is present-tense by construction. Three readings produced three partly disjoint answers, which is a better argument for multiple readings than any of them makes on its own.

## How It Was Delivered

The route was settled before dispatch rather than guessed. This model is unreachable through one of its three documented routes, so the wrong choice would have failed at resolution. The gateway route was probed live at max effort and replied.

The first launch was rejected in under a second because the executor accepts no sandbox mode, and the error named the four fields it does accept. Shortly after relaunching, both processes sat at zero percent CPU with no child for 47 seconds, which matches a deadlock signature documented in this repository. Waiting twenty more seconds showed the turn simply had not spawned. The near-miss is recorded because the wrong call there would have killed a healthy run.
