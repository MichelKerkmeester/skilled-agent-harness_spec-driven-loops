ROLE
You write 36 test requests, the kind a developer types to an AI coding assistant in this repository. Each request is one JSON line in one new file.

OUTPUT FILE
.skilled/skills/system-skill-advisor/runtime/scripts/routing-accuracy/behaviour-fresh-prompts.jsonl
Create it once. Write each row once, as one JSON line. Do not rewrite, reorder or replace a row after writing it.

RULES
- Open no other file. Everything you need is in this brief.
- Run no command, script or tool on a draft row, and never run the skill advisor.
- Write each request in plain words, as a user would ask. Never name the slash command in a fit row.
- Each request is new text. Do not copy wording from the listing below beyond the subject itself.

THE THREE CLASSES AND THEIR COUNTS (36 rows)

1. Fit rows: 20 rows, ids fresh-fit-01 to fresh-fit-20.
A fit row is a plain request that one listed command's workflow fits, written as a user asks without naming the command.
- 10 rows whose command has policy start, 5 whose policy is run and 5 whose policy is ask.
- At least 15 distinct commands across the 20 rows.
- Each of the command families create, deep, design, doctor, prompt and speckit (the word after the slash) at least twice.
- expected_command is the command exactly as the listing writes it before the first space (for example /create:readme). expected_policy and expected_top are that line's policy and skill.
Shape:
{"id":"fresh-fit-01","row_type":"plain","split":"fresh","prompt":"<text>","expected_command":"<the command as listed>","expected_policy":"<its listed policy>","expected_top":"<its listed skill>","source":"authored-blind"}

2. Skill-only rows: 8 rows, ids fresh-skill-01 to fresh-skill-08.
A skill-only row is a request that one of the nine skills below owns and that no listed command's workflow fits, such as a code fix, a commit or a question about the code.
- At least four distinct skills across the 8 rows, and at most two rows per skill.
Shape:
{"id":"fresh-skill-01","row_type":"skill-only","split":"fresh","prompt":"<text>","expected_command":null,"expected_policy":null,"expected_top":"<one of the nine skills>","source":"authored-blind"}

3. Decline rows: 8 rows, two of each kind, ids fresh-decline-<kind>-01 and fresh-decline-<kind>-02.
A decline row names or resembles a command's subject and must not start it.
- refusal: the user says not to use the command or its workflow.
- question: the user asks what a command does or whether to use it.
- small-edit: a fix of a few characters in an artifact a create command owns.
- app-problem: a fault in the user's own application that shares words with a doctor target.
Shape (all three expected fields are null):
{"id":"fresh-decline-refusal-01","row_type":"decline","decline_kind":"refusal","split":"fresh","prompt":"<text>","expected_command":null,"expected_policy":null,"expected_top":null,"source":"authored-blind"}
The kinds are refusal, question, small-edit and app-problem, so the ids are fresh-decline-refusal-01, fresh-decline-refusal-02, fresh-decline-question-01, fresh-decline-question-02, fresh-decline-small-edit-01, fresh-decline-small-edit-02, fresh-decline-app-problem-01 and fresh-decline-app-problem-02.
