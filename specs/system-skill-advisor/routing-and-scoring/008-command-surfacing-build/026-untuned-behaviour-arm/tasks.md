- No lane task changes a phrase, a guard, a scorer rule, a renderer, a hook, a plugin or `AGENTS.md`. The B-6 edit is the coordinator's own commit and T038 only checks it.
- Every field an earlier summary prints keeps its name and its value rule. A task adds fields and never renames or redefines one.
- No worker runs the full suite, a capture, a summary over run logs, a daemon or a model session, and no worker writes under the home folder, an arena or another phase folder.
- No code comment may name a spec path, a phase number, a task id, a finding id, a decision id, an ADR or a REQ id. T050 checks it.
- Add no dependency and edit no `package.json`, session reader, hook or other row file.
- A `.md` edit routes through `sk-doc` and a code edit through `sk-code` before the first write. A doc sentence holds no em dash and no semicolon.
- A row written with `PLOG` is cut by that command: the item at 200 characters, the state at 40 and the evidence at 400, with `...` in place of the rest. Keep each cell inside its limit and write a second row rather than a longer one. - Every model session this phase starts counts against the cap of 900, smoke rows and reruns included. No measured session is rerun for its result, and nothing is tuned on a number this phase prints.
- When a verify prints something other than the expected output, do not change code to match it. Mark the task `[B]` with the printed line.
