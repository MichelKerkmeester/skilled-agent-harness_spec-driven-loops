   `.md`, is not `README.md`, does not end `.contract.md` and does not start with `local-`, yield `/<directory>:<name without .md>`. Skip a directory
   whose name starts with `local-`. Files directly in commandsRoot are never commands. Return the sorted list.
2. `validateRiskKeys(record, label)`: throws `Error('[command-bridges] <label> ...')` naming the label and the bad value when `record.mutating` is not
   in MUTATING_CLASSES, when `record.ask_first` is present and is not an array of values from ASK_FIRST_REASONS, or when `record.write_scope` is
   present and not in WRITE_SCOPES. When the third argument `requireTarget` is true it also throws when `record.gate3_location` is not a non-empty string.
3. `derivePolicy(record)`: pure. In this order: `record.ask_first` non-empty array -> 'ask'. `record.doctor === true && record.mutating === 'mutates'` -> 'ask'.
   `record.mutating === 'read-only'` -> 'run'. `record.mutating === 'add-only' && record.write_scope === 'spec-folder'` -> 'run'. Otherwise 'start'.
4. `metadataRiskRecords(skillsRoot = SKILLS_ROOT)`: walks the same skill folders as `metadataEntries` (same `local-` and symlink skip). For every entry of every
   `command-metadata.json` it calls `validateRiskKeys(entry, '<file path>[<index>] <command>', true)` and returns
   `{ command, route: null, mutating, ask_first: entry.ask_first || [], write_scope: entry.write_scope, doctor: false }`.
5. `doctorRiskRecords(routesPath = DOCTOR_ROUTES_PATH)`: parses the manifest with the same lazy `require('yaml')`. Returns one record with `doctor: true` for:
   - each item of `routes`: `command`, `route: item.target`;
   - each item of `mcp_subroutes`: `command: DOCTOR_MCP_COMMAND`, `route: item.sub_action`;
   - each item of `standalone` that has a string `command`: when it has an `actions` object, one record per action key (`route: <key>`, class from the action);
     otherwise one record with `route: null` and the item's own class.
   Each record carries `mutating`, `ask_first` (default []), `write_scope`, and is checked with `validateRiskKeys(record, label)` (no target requirement).
6. `identityViolations({ treeCommands, metadataCommands, doctorCommands })`: pure, three arrays of command strings. Returns a sorted array of strings:
   `<command>: command file has no command-metadata.json entry and no doctor route` for each tree command in neither list, and
   `<command>: declared in command-metadata.json or the doctor manifest but has no command file` for each metadata or doctor command not in the tree.
7. `commandPolicies(skillsRoot, routesPath)`: concatenates 4 and 5, maps each to
   `{ command, route, mutating, askFirst: record.ask_first, policy: derivePolicy(record) }`, sorted by command, then route with null first.
