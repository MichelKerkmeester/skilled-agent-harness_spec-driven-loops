Rules for every task:
- Each task is one change to the files it names. A task that names a module and its test writes the test case first, runs it and sees it fail for the reason the task names, then makes the change and sees it pass. Its verify names both runs. A task that says its case passes today adds a guard and changes no code.
- Re-read every file a task names before the first edit. Phase 016 edited some of them after this plan was written. When a line, string or name the task quotes is not in the file, change nothing and mark the task `[B]` with the line found in its place.
- No test input or expected output names `/create:skill` or `/create:sk-skill`. Use `/create:agent` or `/create:readme`.
- No task reads or prints the prompt text of a row whose `split` is `holdout`, and no task opens `holdout-prompts.jsonl`.
