## 3. ARCHITECTURE

### Pattern
One generated table, many readers. Nothing hand-keeps a command string or a policy.

### Key Components
- **Command table** (`ADV/lib/command-attach.ts`, generated by `derive-command-bridges.cjs`): `COMMAND_ROWS` maps every id a scorer can return for a command entry, the TypeScript id, the Python id and the inventory id, to `{ command, policy, ownerSkillId }`. `COMMAND_POLICIES` maps each runnable string to its policy. Without it each reader would rebuild the join from `commandPolicies`, the doctor details and the projection.
- **Public fields** (`ADV/schemas/advisor-tool-schemas.ts`, `ADV/handlers/advisor-recommend.ts`): `publicRecommendation` copies `kind` and, for a row found in `COMMAND_ROWS`, sets `command`, `policy` and `ownerSkillId`. `enrichCompiledRoutes` adds the policy of an attached command and reads the already-offered set from the `command` fields instead of from bridge keywords.
- **Brief head** (`ADV/lib/render.ts`): a recommendation with a command renders `use <owner> → <command> (<policy>)`, where the owner is `ownerSkillId` or, for a hub with an attached command, the hub id. Fields win, and `COMMAND_ROWS` fills a missing field by id, which covers an older daemon and the Python subprocess path.
- **Degraded contract** (`ADV/skill-advisor-cli.ts`): `degradedRecommendations` keeps a command row's fields only when its bare slash command appears in the prompt, and otherwise replaces it with its owner skill.
- **Reach check** (`.skilled/skills/sk-doc/sk-create-skill/scripts/ci-router-vocabulary-reach.cjs`): `rankShippedFleet` counts a hit when the first shipped entry is the hub or is a command row whose `ownerSkillId` is the hub.

### Data Flow
`command-metadata.json`, `_routes.yaml` and the projection feed the deriver, which writes `commandPolicies` and the new table. At recommend time the scorer ranks rows and the handler copies the fields from the table. The CLI passes them to the hook. The renderer prints the head from the fields, or from the table when a field is missing.

### Head Form
The six golden heads, one per family, each followed by the existing `\nDirectives:` block:

```text
Advisor: live; use sk-doc → /create:readme (start) 0.95/0.12 pass.
Advisor: live; use system-deep-loop → /deep:research (ask) 0.82/0.16 pass.
Advisor: live; use sk-design → /design:chart (start) 0.90/0.12 pass.
Advisor: live; use sk-git → /doctor:git hooks (ask) 0.82/0.12 pass.
Advisor: live; use system-spec-kit → /speckit:save (start) 0.89/0.12 pass.
Advisor: live; use sk-prompt → /prompt:improve (start) 0.89/0.12 pass.
```

The policies come from `commandPolicies` today. A recommendation with no command keeps today's `use <skill>` head. A command row with no table entry keeps its sanitized id. A missing policy drops the parenthesis.
