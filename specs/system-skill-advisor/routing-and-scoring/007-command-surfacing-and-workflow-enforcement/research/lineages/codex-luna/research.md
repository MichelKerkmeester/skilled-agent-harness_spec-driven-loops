## Consolidated Synthesis

### Recommended route model

Treat route selection and execution authority as separate decisions. A typed slash command should bind to its exact command identity. Plain chat should match command goals and skill intent, then resolve to that same identity and its packaged workflow. Once selected, the workflow determines whether to continue, ask for missing inputs, ask for a mode or spec choice, or wait for approval at an effect boundary. Gate 2 requires high-confidence skill invocation, while Gate 3, command-specific startup rules and the reversibility ladder still require questions in their respective cases. The hook itself is advisory and fail-open, so its recommendation cannot authorize an effect.
