This benchmark measures advisor-routing accuracy for `sk-communication`: whether a projection-intent prompt (e.g. "make CLI output readable" or "claudish to english, privacy-first rewrite") routes to `sk-communication` as the advisor's top match. The harness driving it is the skill-advisor scorer at `.opencode/skills/system-skill-advisor/runtime/scripts/skill_advisor.py`, with dated capture runs stored under `reports/`.

Two things it explicitly does not cover: the underlying `cli-communication-projection` package (verified separately via `npm run check` in that package's own directory), and reply quality, which is a separate harness (`reply-harness/`, a frozen case set with a weighted rubric, prompt builder, mechanical scorer, and blinding for condition comparison).
