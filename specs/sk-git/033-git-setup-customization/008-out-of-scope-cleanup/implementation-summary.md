## What Was Built

The sk-code drift guards pass again, every doctor script has a test, no Hermes mirror header breaks the Human Voice Rules, and sk-create-command states one place for the mandatory input gate. All four issues held when checked against the code, and all four are fixed.

### Phase 8: out-of-scope-cleanup

The drift verifier's `--check-router` walk now skips a `SKILL.md` kept under `specs/**/evidence/`. It reuses `is_unscanned_record_path()`, the exclusion its language scan already applied, so the frozen review copy stays as recorded. A shipped `SKILL.md` with a dead route still fails.

`doctor-phrase-reach.cjs` has a node:test suite. One test runs the probe against the built advisor. The other copies it into a throwaway root whose freshness library reports a stale build and expects exit 2 with no verdict.

The Hermes header reads `<!-- generated by sync-skills-hermes.cjs, do not edit -->` and "...the canonical directory. Read `references/`...". The drift verifier matches the marker through `GENERATED_SKILL_COPY_RE`, so that pattern moved with it.

For the gate, the proposed fix was to say "immediately after the frontmatter" everywhere. The shipped commands do the opposite: eight of the nine with a `MANDATORY INPUT GATE` put it after the H1, and only `doctor/git.md` puts it first. The rule is now "after the H1 and its purpose line, before any workflow step", and every prose statement, checklist, skeleton and playbook scenario says so.
