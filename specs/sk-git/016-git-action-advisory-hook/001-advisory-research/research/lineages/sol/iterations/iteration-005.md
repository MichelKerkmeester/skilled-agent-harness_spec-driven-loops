## Focus

Calibrate every candidate retained through iterations 1-4 into a decision-ready advisory rule set. Ranking uses four explicit dimensions: positive-evidence strength (`E3` exact command plus positive local state, `E2` exact command-only destructive/policy intent, `E1` raceable or heuristic positive snapshot), cost of the failure, overlap with a higher-ranked rule, and measured prevalence where Git history legitimately exposes it. ## Probe and Alert Budgets

1. **Stage 0, command-only:** parse direct `git`/`git -C`/eligible `gh`; no subprocess for nonmatches. Exact help, dry-run, recovery, and safer forms are rejected here. [INFERENCE: based on the cheap-probe ordering in iteration 2]
2. **Normal state tier:** at most 3 Git subprocesses, reused across matching rules; target `<=100 ms` observed p95 for ref/worktree/diff checks and hard timeout `250 ms`. On timeout/error, remain silent rather than inventing state. [SOURCE: bounded read-only Git benchmark captured 2026-07-27T19:41:12Z]
3. **Rare mutation tier:** after an exact destructive/selective token, at most 5 subprocesses and `750 ms` total; this admits current status/add/commit dry-runs. No network and no all-worktree sweep. [SOURCE: bounded read-only Git benchmark captured 2026-07-27T19:41:12Z]
4. **Exceptional clean-ignored tier:** exact `clean -fx|-fdx` may use its native dry-run with a `3.5 s` hard cap because the measured maximum was 3.25 s; record latency telemetry and disable/retune if p95 remains above 2 s. [SOURCE: bounded read-only Git benchmark captured 2026-07-27T19:41:12Z]
5. **Alert telemetry:** record only normalized rule id, eligible operation class, predicate matched, emitted/coalesced flag, latency bucket, and timeout—never raw command, paths, refs, URLs, or credentials. Evaluate rates per 100 direct eligible Git invocations. [INFERENCE: this is the minimum data needed to replace unavailable argv/fire-rate history without collecting command content]

## Ruled Out

- Broad operation-family and path-count warnings: measured history proxies exceed the attention budget or fail to prove a hazard.
- Any predicate that calls absent remote containment “safe,” predicts post-fetch/post-hook state, or maps `gh` identity to Git transport authorization.
- Duplicate branch naming/permission advisories already owned by pre-push enforcement.
- Network checks, full object scans, and all-worktree status sweeps in the synchronous hot path.
