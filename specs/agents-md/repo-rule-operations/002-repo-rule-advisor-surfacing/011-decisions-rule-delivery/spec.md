<!-- ANCHOR:problem -->
## 2. PROBLEM & PURPOSE

### Problem Statement
The operator reported that `communication-decisions.md` is ignored on every runtime. The clearest case is the spec-folder question, which arrived as four equal options with no recommendation. The rule loads only when the model decides to read it, and the two texts the model copies for that question, the Gate 3 options in `AGENTS.md` and `GATE_3_MUTATION_NOTICE`, both model a neutral menu.

### Purpose
Every runtime that delivers the Gate 3 question tells the model to lead with one recommended option and its reason.
<!-- /ANCHOR:problem -->

<!-- ANCHOR:scope -->
## 3. SCOPE

### In Scope
- Add "recommend one" to the Gate 3 options label in `AGENTS.md`, within the 16,384-byte delivery prefix
- Add "recommend one option first and say why, never a neutral menu" to `GATE_3_MUTATION_NOTICE`
- Regenerate the doctor AGENTS.md manifest and update the notice's byte pin

### Out of Scope
- A decisions line in the advisor `Directives:` block - commit `f4ead54766` retired constant disposition directives, and the operator kept that decision on 2026-11-07
- `GATE_3_QUESTION`, the human-facing dialog text - a person reads it, not the model
