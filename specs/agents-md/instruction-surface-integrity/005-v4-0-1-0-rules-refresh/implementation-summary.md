## What Was Built

An agent that follows Gate 2 now loads what a skill's `ROUTER.md` resolves, not just its `SKILL.md`. The v4.0.1.0 release moved every skill's routing tables into that sibling file, so the old wording sent an agent to a file that no longer holds them.

### Check whether the v4.0.1.0 release means AGENTS.md or the repo rules need updating

The research found one edit worth making and nothing stale elsewhere. Every path and command that `AGENTS.md`, `REPO RULES.md` and the 13 rule files cite still resolves, and every addition in the release already has an owner. The one gap was the third sentence of the Gate 2 artifact trigger at `AGENTS.md:70`, which said "the router" without naming the file. It now says "its ROUTER.md", three bytes longer, which keeps the delivery budget at 16371 of 16384 bytes.
