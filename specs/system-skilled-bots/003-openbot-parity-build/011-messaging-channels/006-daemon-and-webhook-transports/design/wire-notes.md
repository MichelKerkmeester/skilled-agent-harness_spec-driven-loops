# Signal and WhatsApp wire notes

The Signal and WhatsApp transports are written from this note, not from the reference. The reference is GPL-3.0 and this repository is MIT, so nothing here is copied: every fact is restated in plain words and only short literal wire values such as a path, a field name or a number are quoted. Each fact carries one `[SOURCE: <path>:<line>]` or `[SOURCE: <path>:<first>-<last>]`, where `<path>` starts with `specs/system-skilled-bots/context/tinychannels-main/`. A row whose Value cell says `not stated` carries no citation, because the reference does not answer it.
