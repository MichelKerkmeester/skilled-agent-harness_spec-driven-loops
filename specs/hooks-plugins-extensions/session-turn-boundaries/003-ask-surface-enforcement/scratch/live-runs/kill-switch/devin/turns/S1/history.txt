   • A, amber. It reads as caution, so it suits a pending or degraded state and is unmistakably a status colour. The trade-off is that it competes with your error red and looks alarming even when

   • C, slate. It reads neutral, recedes, and needs no retuning between light and dark themes. The trade-off is that it signals almost nothing, so a badge meant to pull the eye gets skimmed past.
