SYSTEM MESSAGE (T002): confirmed from Claude Code's hooks reference,
https://code.claude.com/docs/en/hooks, fetched 2026-11-13.

"To surface a message to the user on any platform, return `systemMessage` in JSON output."

Universal JSON output fields table:
"| `systemMessage` | none | Warning message shown to the user."

Stop decision control table:
"| `decision` | `\"block\"` prevents Claude from stopping. Omit to allow Claude to stop |"

Stop input, on the payload fields this phase reads:
"The `background_tasks` and `session_crons` arrays let hooks distinguish \"session is done\"
from \"session is paused waiting for background work to wake it back up\"."
Each session_crons entry carries `id`, `schedule`, `recurring` and `prompt`.

So a Stop hook that prints {"systemMessage": "..."} on stdout and exits 0 shows the text
to the operator and, because it carries no `decision` key, does not continue the turn.
