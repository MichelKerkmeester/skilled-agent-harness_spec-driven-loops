   (https://github.com/earendil-works/pi/blob/v1.2.0/packages/coding-agent/docs/settings.md), Models (https://github.com/earendil-works/pi/blob/v1.2.0/packages/coding-agent/docs/models.md),

   (https://github.com/earendil-works/pi/blob/v1.2.0/packages/coding-agent/docs/themes.md).
 - Clipboard copies over remote sessions: PI_CLIPBOARD_OSC52=1 sends copied text to a remote client's clipboard when Pi cannot detect the remote session, such as a multiplexer attached from another
   machine. See Pi Process Configuration (https://github.com/earendil-works/pi/blob/v1.2.0/packages/coding-agent/docs/environment-variables.md#pi-process-configuration).

 - before_agent_start for extension-triggered runs: runs started by pi.sendMessage(..., { triggerTurn: true }) go through the same setup as prompts. See Events and concurrency
   (https://github.com/earendil-works/pi/blob/v1.2.0/packages/coding-agent/docs/extensions.md#events-and-concurrency).

 ### Breaking Changes

 - Published generated configuration schemas for models, settings, keybindings, and themes at https://pi.dev/schemas/*.schema.json. The theme schema moved to https://pi.dev/schemas/theme.schema.json;
   themes loaded during startup now receive the same schema validation as later reloads. Update theme $schema references, define reusable colors under vars, and remove unsupported metadata (#9880
   (https://github.com/earendil-works/pi/pull/9880), #10751 (https://github.com/earendil-works/pi/pull/10751) by @christianklotz (https://github.com/christianklotz))
 - Changed before_agent_start to also fire for runs started by pi.sendMessage(..., { triggerTurn: true }) while idle. BeforeAgentStartEvent is now a union on messageType: "user" events carry prompt
   and images, and "custom" events carry the starting message and no prompt. Messages returned by handlers are added to both kinds of run, and pending deliverAs: "nextTurn" messages are delivered
   with the custom-message run. Handlers that should act only on user prompts must check event.messageType === "user" (#10267 (https://github.com/earendil-works/pi/issues/10267), #5581
   (https://github.com/earendil-works/pi/issues/5581), #10739 (https://github.com/earendil-works/pi/pull/10739) by @davidbrai (https://github.com/davidbrai))
 - Changed the session to count as busy while a run starts, including during before_agent_start handlers: ctx.isIdle() is false, pi.sendMessage() queues into the starting run instead of starting a
   second run that failed with "Agent is already processing", pi.sendUserMessage() requires deliverAs, and an abort requested meanwhile aborts the run once it starts (#10739
   (https://github.com/earendil-works/pi/pull/10739) by @davidbrai (https://github.com/davidbrai))
 - Changed pi mcp list --json to report resources: true for servers that offer resources instead of resources and resourceTemplates counts; Pi no longer lists resources when connecting (#10526
   (https://github.com/earendil-works/pi/issues/10526))
