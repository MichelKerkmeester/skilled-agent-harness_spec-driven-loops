# Guardrail Risk Register

This register carries the seven central rollout risks from the research into named controls. A cell remains `emit` when the required control result or delivery receipt is absent, stale, failed, or ambiguous.

| Central risk | Named control or monitoring entry | Evidence consumed by the gate | Rollback signal |
|---|---|---|---|
| Long-context drift | Run the governor, proof-over-appearance, and comment-hygiene negative controls after long-context growth and at the final response boundary. The governor rubric in `guardrail-negative-controls.test.mjs` checks result-first action, batched tool work, cheap reversibility, and actionable qualification. | `behavioralEvidence` records the scenario set, observed turn/context boundary, and test artifact. | Any missed directive behavior or output difference returns the cell to full baseline emission. |
| Compaction loss | Exercise resume and compaction replay for each applicable runtime, including lifecycle epoch and host receipt. Treat compaction as a delivery-state reset rather than a continuation of suppression state. | `deliveryEvidence` names the runtime receipt and the replay artifact; `observedAt` pins the lifecycle observation. | Missing replay, stale epoch, or receipt ambiguity triggers the rollback template's delivery-state clear. |
| False-negative relevance classifiers | Run advisor-failure and no-match cases with the full baseline as the safe result. A classifier that cannot establish relevance cannot suppress a block. | `behavioralEvidence.status` stays `unknown` or `fail` until the negative-control artifact proves the fallback. | Any false negative changes the verdict to `emit`; no classifier result can activate a cell by itself. |
| Advisory Gate invisibility | Run the advisory, invalid-answer, and child-session cases against the cross-runtime spec-gate candidate. The gate must remain observable when it is advisory and must not be mistaken for a delivered runtime block. | `behavioralEvidence` records the advisory state and visible result; `deliveryEvidence` records the host/runtime delivery lane separately. | A hidden advisory, invalid-answer loss, or child-session leak disables only that runtime/candidate cell. |
| Pi override/preload loss | Keep Pi applicability isolated to candidate 006 and test explicit current-turn overrides, preload behavior, anti-signals, and parent/child dispatch semantics through native Pi receipts. | `behavioralEvidence` names the Pi dispatch matrix; `deliveryEvidence` names the Pi hook or compaction receipt. | Any override, preload, or child-session mismatch clears Pi delivery state and restores the native full replay. |
| Cursor version drift | Monitor the pinned Cursor version and the observed hook lane separately from configured prompt bytes. Re-run delivery probes whenever the host version changes. | `deliveryEvidence.source` identifies the pinned Cursor version and observed hook event; configured-only data is not a pass. | Version change without a fresh receipt changes the cell to `emit` until re-proven. |
| OpenCode transform aliasing | For candidates 002-004, record stable message identity, transform identity, ordering, and multi-transform receipts. The matrix keeps 002/003 OpenCode-only and keeps 004's shared lane explicit. | `deliveryEvidence` includes the OpenCode transform/message receipt; `behavioralEvidence` proves distinct repeated messages are not collapsed. | Any alias, ordering shift, or missing transform receipt disables the local OpenCode cell and clears its state. |
| S3 — Host-observation receipt sink not wired | **IMPLEMENTED** — `recordObservedPolicyDelivery` rejects `lifecycleEpoch <= 0`, requires non-empty `artifactDigest`, and `observationBindsToCell` matches digest parity with `activation-matrix-evidence.mjs`. Adapters call observe strictly after emission commit or `stdout.write` completion. Residual: no post-host-render ack; `observed` means emitted-into-response. | `deliveryEvidence` must name a host-observed artifact digest tied to the cell's runtime, candidate, block hash, and lifecycle epoch (> 0). | Cell stays `emit` until a fresh observed receipt is recorded for that cell; stale, epoch-zero, or unbound receipts do not activate. |
| S10 / M3 — Gate-3 / delivery observer not wired into Claude, Codex, Devin, or Pi adapters | **IMPLEMENTED** — post-emission observers in Claude `user-prompt-submit.ts`, OpenCode `mk-skill-advisor.js`, Pi `prompt-advisor.ts` + `spec-gate-classify.ts`, and Gate-3 classify paths for Claude/Codex/Devin/Cursor/Pi (stdout.write callback) plus OpenCode `mk-spec-gate.js` (after `output.system.push`). Residual: no post-host-render ack; Pi/Claude return-based hooks cannot run code after host consumes the return — observation is the final step before `return` after the output object is committed. | `deliveryEvidence` for 004/005/006 cells must come from the runtime adapter's observed lane, not configuration alone. | Adapter without a fresh observed receipt keeps its cell on `emit`; no cross-runtime receipt may satisfy another cell. |

## Control ownership

The canonical directive block identities remain `policy.comment-hygiene.v1`, `policy.governor.v1`, and `policy.proof-over-appearance.v1`. The negative-control suite exercises the first through the live comment checker, the third through the live completion validator, and the second through the marker-preserving scored rubric. The activation matrix is the shared evidence boundary for candidates 002-006; it does not change any candidate flag.

## Review-surfaced pre-activation controls

A two-executor deep review of the shadow work surfaced additional preconditions. Each is harmless while every candidate ships flag-off, but each MUST hold before its cell may leave `emit`:

| Review concern | Pre-activation control the gate must enforce | Cell that stays `emit` until proven |
|---|---|---|
| S3 — Delivery marked confirmed from configuration or session identity alone, with no evidence the host actually rendered the block | Suppression requires a host-observed delivery receipt for the exact epoch (> 0) and block hash with matching `artifactDigest`; a configured-but-unobserved block is never treated as delivered. **IMPLEMENTED** — sink rejects epoch zero and digest mismatches; adapters observe after emission commit. Residual: no post-host-render callback. | Every candidate whose suppression path lacks an observed receipt |
| S3 — Shadow policy receipts computed but never consumed into an observation stream | The measurement receipts must reach a durable observation sink the gate can read as `deliveryEvidence`; a discarded receipt counts as no evidence. **IMPLEMENTED** — `recordObservedPolicyDelivery` persists cell-bound records with epoch and digest binding readable via `getPolicyObservationRecords` / `deliveryEvidenceFromObservation`. | 002-006 delivery cells |
| S10 / M3 — Gate-3 and delivery-state observer adapters not wired for Claude, Codex, Devin, or Pi | Wire the Gate-3 and delivery-state observer into each applicable runtime adapter so shadow receipts reach the activation matrix. **IMPLEMENTED** — stdout adapters observe in `stdout.write` callback; return-based hooks observe after output object commit before `return`. Residual: return-based hooks cannot observe after host render. | 004/005/006 delivery cells |
| Inspecting delivery state can advance lifecycle state once per block for a direct caller | State inspection is side-effect free; only an explicit delivery transition may advance lifecycle state | 004/005 delivery-state cells |
| A negative-control fixture can inherit outer packet context when its temp dir sits inside a spec tree | Fixtures pin an isolated root outside any repository spec tree, or assert the inherited-context case explicitly | Guardrail behavioral-evidence cell |
| OpenCode identity keys could alias across the join separator | Identity parts carrying the key separator resolve to no identity and fall open to full delivery (now guarded and adversarially tested) | Closed for 003; re-verify for any new identity component |
