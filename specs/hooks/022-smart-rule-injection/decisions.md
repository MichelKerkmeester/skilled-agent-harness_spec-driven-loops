# Decision Record: smart rule injection

Three lineages, ten iterations each, no early convergence.

---

## 1. WHAT WAS REFUSED

**Prompt-vocabulary injection, eighteen candidates.** Nearly all failed the same bar this
repository already set when it retired two directives: a prompt-time injection earns its
slot by naming a specific prohibition a gate enforces, not by restating a disposition the
always-loaded document already carries.

**Completion-presentation injection.** The completion event reaches no rules, and its one
historically model-visible channel lost its reader when a structural index was removed.

**Question-tool triggering.** Refused as structurally impossible rather than merely costly:
a question has no author outside the model, so no surface can compose the ask. A turn-end
nudge can only reach the next turn, which is not the one that needed it.

**The strongest new candidate died on measurement.** An existing gate advisory looked like
the cleanest fit until its state log was read: it fires roughly eight times a minute at
peak while gates sit unresolved for tens of minutes. Rarity was assumed and was false. An
event's frequency must be read from the log, never reasoned about.

---

## 2. WHAT WAS ADMITTED AND BUILT

**The evidence criterion.** A receipt confirms a claim only if the claim being false would
have changed what the receipt showed. Four shapes recur: a search that never hit, a read
that stopped short, a total carried from another analysis, a match that never checked what
the two sides were. Shipped into the always-loaded standards and the evidence rule.

**The post-edit transport gap.** Two runtimes built findings and wrote them where the
assistant never reads. Fixed to use the envelope the rest of the fleet uses.

---

## 3. CLOSED AS DECIDED, NOT BUILT

**Sentinel event placement.** Research argued evaluation belongs at the settled moment
rather than per response; the module's own comment defends its current event as the one
carrying the ending message. No documentation was found settling it, and the sentinel
writes only to a log with no reader. Changing shipped behaviour on contested evidence to
improve an unread log is the wrong trade. Revisit only if that log gains a consumer.

**Spec-gate detector quality.** A real backlog, explicitly owned by a different concern.
Not a defect of this work.

---

## 4. THE STANDING FINDING

Five of six runtimes carry a live completion detector and no model-visible channel from any
completion event. That is one fleet-wide pattern, not four small bugs, and it is the honest
form of the question that started this packet.
