## What Was Built

- **Canonical rename.** `.opencode/commands/design/design-reference.md` -> `extract.md`; its three owned assets renamed to `extract-{auto.yaml,confirm.yaml,presentation.txt}`. ## How It Was Delivered

Before editing anything, the mirror-generation scripts (`sync-runtime-mirrors.cjs`, `sync-prompts.cjs`, `sync-prompts-pi.cjs`, `sync-agents.cjs`, `sync-agents-pi.cjs`) were read in full to confirm their source/output directories and orphan-removal logic, so every runtime mirror was regenerated by the repo's own tooling rather than hand-authored — the one exception (`.claude/commands/interface/`) was confirmed, by reading `findOrphans()`, to be structurally unreachable by that scan (its parent directory is never a key in the orphan map once no canonical `interface/*` source exists), so it was deleted as an explicit, separately-verified step instead.

A pre-change baseline (`find` for every `*interface*design*` mirror, `rg` for the literal old invocation path) was captured before any edit, then re-run after, to prove the delta rather than assume it.

Scope for the doc-reference sweep followed the precedent 016/006 already set: literal command-path/invocation references were updated; purely descriptive prose using "design-reference" as a generic capability description (README.md, README.txt agent-index one-liners, `cli-external-orchestration` docs, `sk-code-handoff.md`) was left, since it remains accurate regardless of the command's name; the `sk-create-command/assets/command-contract.json` worked example (already carrying the pre-016 `/interface:design-reference` alias, already classified illustrative by 016/006) and frozen benchmark/fixture evidence were left untouched.

<!-- ANCHOR:decisions -->
## Key Decisions

- **Regenerate, never hand-author, a mirror.** Every symlink and generated-copy mirror came from running the existing sync scripts in write mode, keeping every mirror a faithful function of the canonical source instead of a fork that silently drifts on the next tooling run.
- **Treat the mirror-sync blind spot as a named, verified exception, not a shortcut.** `.claude/commands/interface/` was deleted by hand only after reading the orphan-scan code and confirming it structurally cannot reach a directory with zero expected mirrors — the exception is documented, not assumed.
- **Bundle the rename with the residual interface-mirror cleanup in the same phase.** Both trace back to the same 016 arc (one is residue 016/006 left, the other is a new naming decision on the same file); reopening 016 twice for two touches of one command file would be worse than one phase covering both.
- **Full internal-consistency rename inside `creation-contract.md`, path-only elsewhere.** That one file exists solely to document this command, so every literal reference (not just the invocation path) was updated for internal consistency; everywhere else, only the literal path/identifier was touched, leaving descriptive prose about the general capability alone.
