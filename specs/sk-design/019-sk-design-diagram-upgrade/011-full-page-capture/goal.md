## 1. DURABLE DIRECTIVE

**Objective:** Captures stop cutting pages off — the shared renderer gains an opt-in full-page flag, every diagram screenshot is re-shot from the merged library with none cropped, and CAP-001 runs a second time with the first report's five findings each closed or carried forward with a reason.

### Decisions

Frozen choices. Changing one is an amendment. Each row refines a named parent decision
(`../goal.md`); none contradicts one.

| ID | Decision |
|----|----------|
| D17 | The flag is opt-in on the shared renderer (`--full-page`), applied corpus-wide to every form under `assets/diagrams/` in one reshoot, not deferred to only the previously-cropped forms; a form shorter than the legacy fixed height also shrinks to its true content height, since "none cropped" is a corpus-wide bar, not a per-file exception list. |
| D12 | `sk-design-chart`'s own capture invocation and README stay unflagged; the byte-identity proof (a fresh unflagged render diffed against the committed chart screenshots) is this phase's standing evidence that the shared script's default path is untouched. |

**Parent:** `../goal.md`

The parent's decisions outrank anything in this file; a conflict between the two is named here
rather than resolved silently.

D1, D3, D5, D10 and D11 are inherited without re-opening: none of them bears on a capture-mechanics
phase. D13 (the merge into `assets/diagrams/`) is 009's signed shape this phase only reads, at
whatever state it is actually in on disk at execution time (spec.md Edge Cases). D16 (every review
