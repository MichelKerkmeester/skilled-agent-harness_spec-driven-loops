# Phase 007 — manual-review-remediation

**Folder:** `specs/sk-design/019-sk-design-diagram-upgrade/007-manual-review-remediation`

**Objective.** Every one of the 34 per-file findings the manual review raised is fixed in the shipped
file with evidence, or recorded with a reason a reader can check. This phase is the per-file defect
work only; the ten systemic patterns belong to 008 and must not be planned here.

**What this phase owns.** F1 through F34 in the review, against the files as they stand today at
`.opencode/skills/sk-design/sk-design-diagram/assets/examples/` and `assets/templates/`. Paths do not
move in this phase — 009 merges them later, and planning around a future path would make every task
unverifiable now.

**Order that matters.** The two P1s first, because both mislead a reader who trusts the drawing:
F1 (`template-full.html` draws its last legend row below the `viewBox`, so a boundary has no key) and
F2 (`example-timeline.html` claims proportional spacing, runs 52–70 px per month, and marks January
2026 at two x positions). Then the 28 P2s, then the 6 P3s.

**Grouping.** Plan the P2s in these lanes, because each lane is one reader's mental model and one
dispatch: geometry and overdraw (F4, F5, F6, F7, F9, F10, F11, F13, F18); legend fidelity (F3, F12,
F14, F15); colour and contrast (F17, F19, F22, F23, F24, F30); meaning-versus-catalog (F8, F16, F28,
F29); skin and token hygiene (F26, F31, F32); polish (F20, F21, F25, F27, F33, F34).

**Measured facts to plan against, verified this session.** On light paper `#f5f5f5`: ink `#2d3142`
is 11.82:1, muted `#4f5d75` is 6.11:1, soft `#7a8399` is 3.48:1, link `#2e5aa8` is 6.13:1. White on
the mustard chip `#b8915a` is 2.90:1 and ink on it is 4.44:1, so neither settles F23 on its own — the
task must measure with `scripts/color-gates.cjs` and pick a fill that clears `textOnPaper`.

**What must still hold after every fix.**
- `node scripts/check-diagram-corpus.cjs` prints `RESULT: PASSED`.
- `node scripts/apply-diagram-tokens.cjs --default --out <tmp>` and `--default --examples --out <tmp>`
  still reproduce every file byte for byte, which means any new colour literal must already be a role
  value of that file's skin. A fix that introduces a new hex is a fix that breaks the corpus.
- `node --test scripts/tests/` stays green; `grid-baseline.json` counts may fall, never rise.
- Every changed file is re-rendered and looked at before its task is ticked. A fix nobody viewed is a
  claim, not evidence.

**Execution model to write into plan.md.** Implementation runs on DeepSeek V4.1 Flash at max thinking
through cli-pi and llmgateway, one lane per dispatch, each brief carrying the exact file, the exact
line and the exact replacement. Verification is the conductor's, never the executor's.
