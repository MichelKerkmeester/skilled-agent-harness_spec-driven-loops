# Phase 009 — one-form-library

**Folder:** `specs/sk-design/019-sk-design-diagram-upgrade/009-one-form-library`

**Objective (parent decision D13).** `assets/templates/` and `assets/examples/` become one directory,
`assets/diagrams/`, holding 38 worked diagrams a reader copies and adjusts. The distinction between a
strict template and a demonstration example goes away: every file is a form, the way the chart skill's
`assets/templates/` holds 29 worked charts rather than skeletons beside demos.

**The naming, decided.** Prefixes are dropped, because a directory of forms does not need to repeat
what the directory is. `example-architecture.html` becomes `architecture.html`, and the four skin
skeletons keep a name that says what they are: `starter-light.html`, `starter-dark.html`,
`starter-terminal.html`, `starter-full.html` (from `template.html`, `template-dark.html`,
`template-terminal.html`, `template-full.html` in that order). Moves are `git mv`, so history follows
the file.

**Everything that names the old paths has to move with them.** Inventory it in plan.md by reading,
not from memory; at minimum: `references/catalog.md` and its sentinel table, the two `README.md` files
which merge into one `assets/diagrams/README.md`, `assets/color/diagram-palette.json` (`pins`,
`examples.skinByFile`, `examples.untokenized`), `scripts/apply-diagram-tokens.cjs`,
`scripts/check-diagram-corpus.cjs`, every file under `scripts/families/`, `scripts/grid-baseline.json`,
`scripts/tests/mutation-cases.cjs`, `.github/workflows/diagram-corpus.yml`, `SKILL.md`, the references
tree, the feature catalog, the manual testing playbook, and the screenshots directory.

**The applicator loses a mode and gains the chart's.** With one library there is no `--examples`
split: `--forms a,b` names forms and `--all` takes every one, matching
`sk-design-chart/scripts/apply-design-md.cjs`. `--default` keeps its meaning and its byte-identity
property. The `skinByFile` map stays, because a skin is still per file.

**Two checker rules need rewording, not weakening.** The marker-vocabulary family exempts a template
from the unused-marker rule because a skeleton defines the trio for its copy; that exemption now keys
on the four starters. The node-budget family skips a specimen; that stays as it is.

**What must hold when the phase closes.**
- `rg -n "assets/(examples|templates)" .opencode/skills/sk-design/sk-design-diagram .github/workflows`
  returns nothing outside a changelog entry that describes the move.
- Checker `RESULT: PASSED`, suite green, `--default --all` byte-identical over all 38 forms.
- `git log --follow` on a moved file still reaches its first commit.
- Screenshots live under `screenshots/diagrams/` and every form has one. The re-shoot itself is 011's
  work; this phase moves the directory and updates what points at it.

**Execution model.** The moves are mechanical and the conductor runs them; DeepSeek V4.1 Flash at max
through cli-pi takes the document rewrites, one document per dispatch.
