## 1. SUMMARY

### Technical Context

| Aspect | Value |
|--------|-------|
| **Language/Stack** | Node scripts; JSON palette source; standalone HTML |
| **Framework** | None |
| **Storage** | None |
| **Testing** | `check-corpus.cjs` static and `--render`; captures read by eye |

### Overview
A derivation script computes the chrome, ladder and three systems from the cursor table using the shared contrast arithmetic and the source gates, moving a value only where nothing measured clears; a rebase script writes the source and regenerates every stock block in the checker's canonical shape. The checker is the proof.

<!-- ANCHOR:architecture -->
## 3. ARCHITECTURE

### Pattern
Single palette source with canonical blocks copied into every file

### Key Components
- **Palette source**: the only place a value lives
- **Stock blocks**: canonical projections the checker compares both ways

### Data Flow
Reference table to source values to canonical blocks to rendered forms; the checker reads source and blocks and errors on disagreement.
