# Chart detail crops

Element-level captures of individual charts, taken at 2x by scrolling each source page and screenshotting the chart element with a small margin. Where the page renders charts inside iframes the frame is captured. Each source has one note; the file suffix is the scheme and the order on the page. The captures are reference material for the chart corpus, not assets it ships.
