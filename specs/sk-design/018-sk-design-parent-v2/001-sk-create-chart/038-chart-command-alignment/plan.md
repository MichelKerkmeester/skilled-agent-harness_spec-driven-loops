## 1. SUMMARY

### Technical Context

| Aspect | Value |
|--------|-------|
| **Language/Stack** | Markdown router, YAML workflows, a text presentation contract |
| **Framework** | None |
| **Storage** | None |
| **Testing** | A path sweep against the disk and a grep for the stale terms |

### Overview
The corpus changed under the command four times this week and nothing re-read the command. The
fix is mechanical: extract every path the four files name, test each against the disk, and read
the rest for names and counts that the corpus no longer matches. Two of the five defects predate
this week — the YAML filenames and the parent skill were never right.
