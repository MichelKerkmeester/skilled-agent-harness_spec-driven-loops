What it does: it counts the `<path>.<ext>:<line>` citations in the prose of every tracked skill doc, read at HEAD (fenced code is skipped). It resolves each against the tracked files (the citing doc's folder, the repository root, the skill root, then a unique basename) and prints per-skill and total counts. A resolved target that is missing on disk, or cited past its last line, is dead and is printed as `cite dead: <doc>:<line> -> <target>:<line>`, with no call. It then measures offline whether a Jev or Deem `noul` flags a drifted citation better than two fixed comparators (flag nothing, and identifier overlap between the sentence and the window around the cited line). It changes no citation, no validator and no cited file.
Labels: `--draw --seed <n>` writes 40 rows to the labels file: 20 live citations with `verdict` and `labeler` null, for the operator to label `supports`, `partial` or `contradicts`, and 20 constructed rows whose window was moved 60 lines down its own file, marked `verdict: contradicts` and `labeler: construction`. `supports` counts as clean, `partial` and `contradicts` as drifted. No model writes a label.

Exit 2, each before any call:
- `--jev` or `--deem` without `--out` prints `--deem and --jev need --out <dir> so every call is recorded` (the same line for either switch).
- `--draw` without an integer seed prints `--draw needs an integer --seed <n>`.
- `--draw` over a labels file that holds any labeler prints `draw: refusing to overwrite <path>, operator labels present`.
- A bad labels row prints its row and fault, for example `labels row 3: not JSON`.
