6. A `census skipped:` line names a finding table the parser cannot read, not every other markdown table. A table without a recognized header counts as skipped only when one of its data rows holds a cell that is exactly `P0`, `P1` or `P2`. On the real tree the design's wording printed 5,620 skipped lines (928 KB of stdout, mostly dashboard and strategy tables); this rule prints 525. And `buildCensus` resolves a file's reviewed commit only when the file holds at least one parsed row, since only rows use it: two `git log` calls per file over 5,862 review files made the default run take about 6 minutes.
