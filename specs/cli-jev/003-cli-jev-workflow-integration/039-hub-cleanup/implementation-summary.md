## What Was Built

The cli-classifier hub now says what it is. The Jev packet folder is `.skilled/skills/cli-classifier/cli-jev/` in place of `cli-usage/`, and `cli-usage` still routes: the compiled replay answers `workflowMode cli-jev` and `packetId cli-jev` for a `cli-usage` prompt (`scratch/verify/c1-route.json`). Every version field in the hub sits below `1.0.0.0`, with seven changelog files renamed by `git mv`, retitled and kept. `cli-deem` gains a `manual-testing-playbook/` package of one root index and ten scenarios in three categories, every one on a stub or a refused call. The compiled routing, the leaf manifest and the Hermes copies were regenerated by their own tools, never hand-edited. The build sits in the working tree at start HEAD `b3964f2a3f`.

### Phase 39: hub-cleanup

**Rename and alias.** `git mv` moved the packet folder to `cli-jev/` and its frontmatter `name:` reads `cli-jev`. `mode-registry.json` maps `packet` and `packetSkillName` to `cli-jev`, and its alias list gained `cli-usage` as the ninth entry; `hub-router.json` resources read `cli-jev/SKILL.md` and its `cli-usage-aliases` vocabulary line stays; `dispatch-audit.mjs` records `packetPath: 'cli-classifier/cli-jev'`. Every other live reference was read and classified before its edit (`scratch/w4-build/design.md` section 1).

**Versions.** The design's table fixed every in-scope version field from its own grep (65 fields; the five recorded `skill-benchmark-report.md` files keep their 1.x values as recorded evidence). Seven changelogs were renamed and retitled: hub v1.0.0.0, v1.1.0.0 and v1.2.0.0 to v0.3.0.0, v0.4.0.0 and v0.5.0.0; cli-jev v1.0.0.0, v1.0.1.0 and v1.0.2.0 to v0.1.0.0, v0.1.1.0 and v0.1.2.0; cli-deem v1.0.0.0 to v0.1.0.0, with their bodies kept as history.

**Deem playbook.** One root index and ten scenarios in three categories: the availability gate (DEE-001 to DEE-004), the judgment subcommands (DEE-005 to DEE-008) and the dormant path (DEE-009 and DEE-010). Every scenario runs on an inline stub or a refused port, and the validator prints `PASS package=cli-classifier/cli-deem tier=FAIL_CLOSED scenarios=10 categories=3 operator=10 routing_gold_excluded=0 violations=0 warnings=0` at exit 0 (`scratch/verify/c4.txt`).

**Regenerated artifacts.** `generate-leaf-manifest.cjs` rewrote the leaf manifest (fresh 15 of 15), the authored harness built the compiled bundle (`status built`), `compiled-route-sync.cjs` promoted 62 closure files, and `sync-skills-hermes.cjs` regenerated the Hermes copies (`PASS: 72`, 5 written and the stale `cli-usage` copy pruned). The trigger-index rebuild waits on the commit, because its generator indexes a git archive of HEAD.

## Key Decisions

| Decision | Why |
|----------|-----|
| Rename with the old name kept as an alias (D1) | Nothing was dropped, so an old `cli-usage` prompt must keep routing while the folder takes the mode's name |
| Continue every line under `0.x` (D2) | The operator asked that no cli-classifier line reach `1.0.0.0`, and the changelog history is kept under the new names |
| Read each reference before repointing it (D3) | Some hits are the alias word rather than the path, so a blind replace would break routing. Closed spec folders keep their history |
| The Deem playbook needs no served model (D4) | The tests must run anywhere, so every scenario uses a stub or a refused call |
| Generated artifacts are regenerated, never hand-edited (D5) | A hand edit goes stale and the guard and the freshness gate exist to catch exactly that |
| DeepSeek writes and MiMo reviews (D6) | Parent D5's roster, with the reverse direction for any MiMo fix and no Claude worker |
| The phase runs before 038's build | Both touch the same packet, so renaming first lets 038's build read `cli-jev` |

## Known Limitations

1. **The trigger index still lists the old paths (recorded P2).** `.skilled/skills/system-spec-kit/runtime/data/trigger-index.json` and its three fixture sidecars carry `cli-classifier/cli-usage` paths. The generator indexes a git archive of HEAD, so it cannot see the rename before the commit; the rebuild runs after the commit (`scratch/verify/review-mimo-r1.txt`, P2 1).
2. **One deep-loop fixture stays with its owner (recorded P2).** `system-deep-loop/runtime/tests/unit/fanout-merge.vitest.ts:1470,1472` keeps two recorded finding strings that name the old packet path. They sit in another session's runtime tree, so this phase leaves them to that owner (`scratch/verify/c2.txt`; `scratch/verify/session-evidence.md`, criterion 2).
3. **The mirror checker cannot load in this worktree (recorded P2).** `check-agent-mirror-sync.cjs` exits MODULE_NOT_FOUND because `@spec-kit/shared` is unresolvable here, pre-existing and unchanged by this diff. MiMo confirmed parity by a full body diff instead: frontmatter-only divergence, identical at HEAD, and all five runtime mirrors carry the same edit (`scratch/verify/review-mimo-r1.txt`, P2 3).
4. **The build is uncommitted at this pass.** Every record comes from the working tree at start HEAD `b3964f2a3f`; the orchestrator commits the build and these docs path-scoped after this pass.
5. **Recorded benchmark reports keep their 1.x values.** Five dated `skill-benchmark-report.md` files carry `version: 1.0.0.0`; they are recorded evidence and are excluded from the version proof by design (`scratch/w4-build/design.md` section 3).
