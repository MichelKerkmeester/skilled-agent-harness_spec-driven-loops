With `--fixture <file>` the run adds, in order: `fixture: rows=<n> sha256=<hex>`, `labels: read_code=<n> run_test=<n> reproduce=<n> instrument=<n>`, one `constant <label>: <right>/<n>` line per label, and `baseline: <label> <right>/<n>` (the constant right most often). Then:
- `no headroom` when the baseline is right on more than nine tenths of the rows (`10*right > 9*n`). No backend is called.
- `stop: fewer than 30 labeled rows` when the fixture holds fewer than 30 rows. No backend is called.
- Otherwise the keep rule line: `keep rule: coverage 10*M>=9*K, kill P(X>=L)<0.05, margin 10*(A-B)>=M, sign P(X>=W)<0.05, flips 10*F<=3*M`.

With both switches the Jev gate and arm run first, then the Deem gate and arm, each regardless of the other's outcome (orchestrator ruling 3). A failed gate prints its skip line and never runs the other backend in its place.
- Jev payload gate: only rows with `jev_ok: true` may leave the machine. Each withheld row leaves three `unmeasured_withheld` records in `calls.jsonl` and is never sent. With no row accepted the run prints `jev arm skipped: payload not accepted`.
- Jev gate: prints `jev: path=<path> provider=<provider>`, then skips with `jev arm skipped: jev not on PATH`, `jev arm skipped: version` (anything but `jev 0.6.2`) or `jev arm skipped: no credential`. A passing arm first prints `jev: payload: operator debug notes marked jev_ok; planned calls: <3K+1>; estimated input tokens: <n>`, where K is the number of accepted rows.
- Deem gate: prints `deem: health backend=<b> model=<m> model_commit=<c> source_commit=<s>`, or skips with `deem arm skipped: <reason>`, such as `stub backend`. A passing arm first prints `deem: nothing leaves the machine; planned calls: <n>; estimated wall time: <s> s at 65.6 ms per call, the 2-option p50 in deem-local.md`.
