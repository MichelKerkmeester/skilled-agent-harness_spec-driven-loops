What it does: it reads one stop-rater report (`<dir>/report.json`, written by `score-stop-rater.cjs --out <dir>`) and scores whether each recorded stop would have made a good confirm-mode hint. It spawns no process and calls no model in any mode: `--jev` and `--deem` only add the rater's recorded `jev` and `deem` columns to the two columns every report carries, `legacy` and `sources`. It changes no gate and no live loop.
Hint rule: a column's recorded stop is a hint only when it lands strictly before the lineage's recorded last iteration. A hint at or after the gold iteration is right and saves the iterations from the hint to the last; a hint before gold is wrong and saves nothing. A column with no recorded stop for a lineage leaves that lineage unmeasured.

Exit 2, each before any output line:
- No `--rater-report` prints `--rater-report <dir> is required`.
- A missing report prints `rater report not found: <dir>/report.json`.
- A report that is not JSON prints `rater report is not JSON: <path>`; one without a lineage list prints `rater report has no lineage list: <path>`; a lineage without numeric gold and last iteration prints `rater report lineage <i> is missing gold or lastIteration`.
- `--out` naming the report's own folder prints `--out <dir> would overwrite the rater report: <dir>/report.json`.
- An unknown switch prints node's own parser message.
`--jev` or `--deem` without `--out` is allowed, since no call is made.
