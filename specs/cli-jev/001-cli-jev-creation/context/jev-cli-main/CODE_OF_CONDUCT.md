# Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, experience, education, socioeconomic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behavior

- Be respectful and constructive.
- Accept feedback gracefully.
- Focus on what is best for the project and its users.
- Do not harass, insult, threaten, or publish another person's private information.

## Enforcement

Report unacceptable behavior through [GitHub private vulnerability reporting](https://github.com/tumf/jev-cli/security/advisories/new). Reports will be reviewed and handled privately.

Project maintainers may remove, edit, or reject contributions and may temporarily or permanently ban contributors whose behavior violates this code.
