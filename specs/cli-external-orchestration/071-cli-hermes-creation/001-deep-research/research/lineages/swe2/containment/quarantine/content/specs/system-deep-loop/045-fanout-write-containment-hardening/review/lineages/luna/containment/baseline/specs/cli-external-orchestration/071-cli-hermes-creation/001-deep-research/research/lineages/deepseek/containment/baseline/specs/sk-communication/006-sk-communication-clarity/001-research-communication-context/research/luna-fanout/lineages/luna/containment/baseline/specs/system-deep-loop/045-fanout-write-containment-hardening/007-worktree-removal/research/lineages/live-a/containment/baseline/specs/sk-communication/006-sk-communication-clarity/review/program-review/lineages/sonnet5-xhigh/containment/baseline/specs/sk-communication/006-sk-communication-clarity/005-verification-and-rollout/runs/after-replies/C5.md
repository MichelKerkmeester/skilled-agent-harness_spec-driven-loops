The benchmark measures advisor-routing accuracy. Each case is a projection-intent prompt, for example "make CLI output readable" or "claudish to english, privacy-first rewrite", and what gets measured is whether the skill-advisor scorer routes it to `sk-communication` as the top match. Runs are captured to dated folders under `reports/`, and the case prompts come from the skill's manual-testing playbook by default. The underlying `cli-communication-projection` package sits outside this, it verifies itself through its own `npm run check` gate.

The folder also holds a second measurement, the reply-harness, which answers a different question: whether the skill's rules change the replies themselves. It builds the rule set twice, from a recorded commit and from the working tree, collects model replies to a frozen case set for each side, scores those replies on seven weighted dimensions plus one blocking class, and compares the conditions with the replies blinded. The comparison fails when the control case moves or a blocking class fires on the after side.
