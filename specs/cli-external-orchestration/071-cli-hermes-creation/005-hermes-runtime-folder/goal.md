## 1. DURABLE DIRECTIVE

**Objective:** A Hermes session started in this repository finds the repo's skills, prompt
templates and plugins through a `.hermes/` folder that mirrors what `.pi/`, `.devin/` and
`.cursor/` do for their runtimes, carrying only what Hermes reads from a project.

### Decisions

Frozen choices for this phase. The parent goal's decisions bind here too; changing one of those is
an amendment to the packet root `goal.md`.

| ID | Decision |
|----|----------|
| P1 | `.hermes/skills/<name>/SKILL.md` is a generated markdown-only copy of every canonical `SKILL.md` (56, flat by frontmatter name, `sync-skills-hermes.cjs`); never a symlink, because Hermes scans a linked directory in full and quarantines it on its scripts and references (whole tree: ten minutes, every hub; one linked skill: 37 findings). Amended 2026-09-15 on the operator's request for full coverage |
| P2 | The flattening is documented, not fought: every nested `SKILL.md` loads as a peer skill in Hermes, and `SYNC.md` says so |
| P3 | `.hermes/prompts/` holds the flattened command templates, generated by a sync script modelled on `sync-prompts-pi.cjs`, carried by `--query-file` |
| P5 | `.hermes/agents/` is a symlink to `.opencode/agents`, the authored source and every agent is also mirrored as the skill `agent-<name>` by the generator, because Hermes has no agent flag and caps a plugin prompt section at 4000 characters (added 2026-09-15 on the operator's request) |
| P4 | `.hermes/plugins/` holds the project plugin phase 006 builds; `.hermes/SYNC.md` and `.hermes/manual-testing-playbook` (symlink to the packet's playbook) match the sibling dotfolders |
| P5 | Nothing that Hermes only reads from `~/.hermes` (config, hooks, MCP, trust) is placed here; the operator steps are listed in `SYNC.md` |

### Completion criteria

1. `ls -la .hermes` shows the playbook symlink resolving and the generated files present.
2. With the repo trusted, `hermes skills list` in a live session lists the repo skills, output recorded.
3. A prompt template dispatched through `--query-file` runs one repo command end to end, output recorded.
4. No hand-written entry in `.hermes/` duplicates a repo file; generated copies carry a generator marker and a `--check` mode.

### Operator copy

The operator holds the parent directive as the session objective. A change here that alters a
parent decision or criterion is an amendment to the parent: apply it there and resend that file.
