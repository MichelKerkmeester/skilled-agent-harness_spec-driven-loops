# Iteration 1: Command Census

## Focus

Build the exact matrix: every authored command in `.opencode/commands` against each of the six
mirrors, marking present, absent or renamed; explain every count difference (why 33 versus 35 versus
46) as either a deliberate exclusion rule or drift; and name the generator that produces each mirror
plus whether it carries a `--check` mode.

### F2. Every count difference is a deliberate exclusion rule, not drift

`command-scope.cjs` is the policy the mirror generators consult:

- `CANONICAL_MIRROR_EXCLUDES = new Set(['goal-opencode.md', 'vision.md'])` — canonical entries that must
  NOT be mirrored into any generated runtime tree.
  [SOURCE: file:.opencode/skills/system-spec-kit/runtime/cli/runtime-mirrors/command-scope.cjs:21]
- `RUNTIME_NATIVE_COMMANDS = { '.cursor/commands': {goal-cursor.md, vision.md}, '.pi/prompts': {goal-pi.md, vision.md} }`
  — real hand-authored entries a generator must never prune nor flag as drift.
  [SOURCE: file:.opencode/skills/system-spec-kit/runtime/cli/runtime-mirrors/command-scope.cjs:27-30]

Arithmetic that closes: 35 authored − 2 excluded = **33** for Claude/Codex/Hermes; **35** for Cursor
and Pi because each re-adds two native entries (a renamed goal command plus its own `vision.md`).

The stated reason is a host-integration asymmetry, not a packaging preference: "Goal and vision are
per-runtime because each host reaches the feature differently: OpenCode uses a plugin hook, Cursor
and Devin use an MCP tool, and Pi uses a hidden extension tool. Claude has no sk-vision integration."
[SOURCE: file:.opencode/skills/system-spec-kit/runtime/cli/runtime-mirrors/command-scope.cjs:8-12]

`.claude/commands` holds **0 regular files and 33 symlinks**; `.cursor/commands` holds **2 regular

### F6. Devin's zero is a documented operator decision, and its command surface is skill-derived

`.devin/SYNC.md` states it directly: "Devin has **no mirrored command surface** (removed by operator
decision). It discovers the repo's `.opencode/skills/` packets on its own — exposed as `/sk-doc`,
`/sk-git`, and so on — with no `.devin/skills/` mirror authored."
[SOURCE: file:.devin/SYNC.md:20] The same file's format contract records what the removed mirror used
to hold: Devin's strict YAML parser "hid 12 of 36 commands from Devin while the other 24 registered
normally" [SOURCE: file:.devin/SYNC.md:74] — i.e. the retired Devin mirror was the full 35-command
set plus one runtime-native entry, and a strict-YAML parse failure was its silent failure mode.

So the chartered framing "Devin carries zero of the 46 authored commands" is **correct as a count and
incomplete as a conclusion**: the absence is a deliberate removal with a named replacement affordance
(skill discovery), not an unported surface. Iteration 2 tests that affordance against the CLI itself.

## Assessment

`newInfoRatio: 0.90` — First pass over a chartered surface. The charter already asserted the raw
counts, so the mirror totals are partly known; what is new is the mechanism behind every count
(the exclusion set and the native-command set), the symlink-versus-copy split that makes enumeration
method load-bearing, the 35-versus-46 correction, and the two unwired `--check` modes.

Confidence: **high**. Every row above is a read of the file or a live census; no inference is
required for the matrix. One inferred claim, marked: that Devin's retired mirror held 35 commands
rather than 36 distinct authored ones — `.devin/SYNC.md:74` says "36 commands" without listing them.
Confirming would need the commit that removed `.devin/commands/`.

## Reflection

Worked: the name-normalized `comm` diff resolved present/absent/renamed in one pass and surfaced the
renames (`goal-opencode` → `goal-cursor` / `goal-pi`) immediately.

Failed: the first census counted with `find -type f` and reported `.claude/commands` as 0. That
number is what the charter's "Claude 33" contradicts, and it is exactly the trap the charter's own
Devin row ("0") resembles — an absence reported by a method that cannot see symlinks. Every later
census in this lineage counts symlinks explicitly.

Ruled out: treating the 33-versus-35 spread as drift. It is policy-driven, encoded in
`command-scope.cjs`, and a "fix" that mirrored `vision.md` into Claude would violate the recorded
host capability ("Claude has no sk-vision integration").
