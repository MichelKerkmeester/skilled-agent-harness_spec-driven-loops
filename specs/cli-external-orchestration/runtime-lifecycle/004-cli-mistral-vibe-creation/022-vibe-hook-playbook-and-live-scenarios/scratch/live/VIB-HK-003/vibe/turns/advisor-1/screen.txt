  Small correction on the framing: a Vibe skill doesn't have a README. The entry point is a single SKILL.md — YAML frontmatter plus Markdown instructions — and that file is the documentation.
  Support files (extra .md, JSON, CSV) sit beside it and get read on demand.

  The skeleton is three fields:

  ┌─ markdown ───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ ---                                                                                                                                                                                              │
  │ name: my-skill                                                                                                                                                                                   │
  │ description: Load this skill when ...                                                                                                                                                            │
  │ ---                                                                                                                                                                                              │
  │                                                                                                                                                                                                  │
  │ # My Skill                                                                                                                                                                                       │
  │                                                                                                                                                                                                  │
  │ Instructions go here.                                                                                                                                                                            │
  └──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

  description is the only part the model sees before deciding to load the skill, so it should say when to use it, not what it contains. name must be a lowercase slug matching the directory name.
