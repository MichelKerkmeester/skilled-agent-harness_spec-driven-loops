  lib/retry.mjs — retry(operation, options) with attempts (total, default 3), delayMs (250), factor (2), plus optional shouldRetry(error, attempt) and onRetry(error, attempt). Backoff is delayMs *    
  factor ** (attempt - 1). attempts is clamped to at least 1 so a zero/negative value still runs once. Also exports sleep and isRetryableStatus (408, 429, 5xx).                                        
                                                                                                                                                                                                        
  src/uploader.mjs — upload now throws a status-tagged error on non-ok responses and retries only when the status is retryable or absent. A rejected fetch has no status, so network failures retry;    
  a 400 fails on the first call.                                                                                                                                                                        
                                                                                                                                                                                                        
  Verified with a throwaway Node script (since deleted) that stubbed fetch: 9/9 checks passed — recovery on attempt 2, exhaustion rethrowing the last error, fail-fast on shouldRetry: false, growing   
  backoff, the attempts: 0 clamp, the status predicate, and the three uploader paths (503→200, 400 fail-fast, network error→200).
