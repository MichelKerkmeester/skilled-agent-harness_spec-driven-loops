  The two checks that mattered:                                                                                                                                                                         
                                                                                                                                                                                                        
  • resolveTargetIdentity (dispatch-guard.cjs:269) reads target_agent=@… out of the prompt text before consulting config_name. So the header is self-authenticating — I could not have routed around    
    the mismatch by passing a different config_name.                                                                                                                                                    
  • declaredModeFromPrompt reads mode= off the Deep Route: line, and Check 1 (:1004–1020) rejects when that mode isn't in the target's registered set. deep-research carries only research.             
                                                                                                                                                                                                        
  Two design details worth noting, since they're what made this a clean refusal rather than a silent pass:                                                                                              
                                                                                                                                                                                                        
  • guardEnv() in the hook defaults SYSTEM_DEEP_LOOP_GUARD_REJECT=1 when the operator hasn't set it. Without that, the same mismatch would have been a stderr warning and the spawn would have          
    proceeded.                                                                                                                                                                                          
  • The guard is deliberately fail-open on core error (allows, reports on stderr) but fail-closed on a judged mismatch. That asymmetry is the right way round.
