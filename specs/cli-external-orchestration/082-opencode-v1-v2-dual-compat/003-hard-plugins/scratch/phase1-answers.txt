## Live re-probe with a real model (2026-10-18, operator-approved, phase 3)
Model llmgateway/deepseek-v4.1-flash, OpenCode 2.0.32, private throwaway databases, the shared service untouched. The probe plugin is live-probe/event-probe.js. It logs every ctx.event.subscribe event type and its data keys, and every firing of session.hook("prompt"), session.hook("context") and tool.hook("execute.before").
- Run 1, `opencode2 run --standalone -m llmgateway/deepseek-v4.1-flash "Reply with the single word ok."` (live-probe/run1-output.txt, exit 0, reply "ok"). Its event log was not kept, so the event claims below rest on run 2, which also runs one full turn.
- Run 2, live-probe/run2.py: a private opencode2 serve, one short turn, then POST /api/session/{id}/compact. Events (live-probe/run2-events.jsonl, 129 lines): the turn ends with session.step.ended then session.execution.succeeded { sessionID }. The compaction gives session.compaction.started, 91 session.compaction.delta, session.compaction.ended { sessionID, reason, model, text, recent, cost, tokens }, then a second session.execution.succeeded. The log holds 0 session.idle and 0 session.compacted events. session.hook("prompt") and session.hook("context") each fired once.
Verdicts, now confirmed live:
- Q5: v2 does not deliver session.idle. The end of a turn is session.execution.succeeded, whose data carries sessionID.
- Q6: v2 does not deliver session.compacted. Compaction is session.compaction.started, .delta and .ended, whose data carries sessionID (schema: event-manifest.d.ts:3829).
- session.hook("prompt") and session.hook("context") fire on a real turn.
