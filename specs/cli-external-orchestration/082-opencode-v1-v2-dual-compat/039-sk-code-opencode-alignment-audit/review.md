# Review: sk-code alignment of every OpenCode plugin and hook file

---

## 1. Scope and Method

The review covers every tracked path under `.opencode/plugins/` and `.skilled/hooks/` (which `.opencode/hooks` links to): 203 real files and 116 symlinks. Each real file was reviewed against sk-code's SKILLED surface and its code-review mode; markdown files were also checked with the sk-doc validator.

DeepSeek v4.1 flash (max thinking, through cli-pi) reviewed the files in 13 batches and wrote every fix from short briefs. GPT-6 Luna (max effort, through cli-codex, read-only) confirmed or rejected each candidate finding and then verified the fixes over four rounds. The orchestrator reran every test and verification itself. A finding counts as fixed only when Luna's latest round says FIXED and the tests pass.

Severity follows `sk-code-review/references/review-core.md` §2: P0 is security or data loss, P1 is correctness or a spec mismatch, P2 is style and maintainability.

A finding whose fix would change behaviour an operator or a runtime sees was not fixed. It is listed in §3 for the operator to decide. Two P0 path escapes were the exception: they were fixed with a test, and are marked fixed (security) below.
