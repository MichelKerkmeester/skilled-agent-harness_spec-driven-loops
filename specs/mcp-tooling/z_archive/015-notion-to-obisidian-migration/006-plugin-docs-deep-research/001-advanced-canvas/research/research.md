## Iteration 3: Workflow Recipes, Gotchas, and Concrete Doc-Update Recommendations

### Structured Gotchas (4 total)

| # | Gotcha | Priority | Key Rule |
|---|--------|----------|----------|
| 1 | **`collapsedData` — Collapsed Group Members Vanish from `nodes[]`** | P0 | When a group is collapsed, member nodes move from top-level `nodes[]` into `groupNodeData.collapsedData` with offset coordinates. `collapsedData` is NOT in the spec — runtime-only. AI reading must check for it; AI writing must never create it from scratch. |
| 2 | **The Dash in Node IDs** | P1 | The plugin uses dashes for composite portal IDs (`portalId-nodeId`). Never use `-` in manually-chosen node IDs. Use underscores, camelCase, or alphanumeric. |
| 3 | **`zIndex` vs Array Order Duality** | P2 | The spec requires `nodes[]` sorted by ascending `zIndex`, but `zIndex` is also a per-node field. When some nodes lack `zIndex`, array position and visual order can diverge. Always read `zIndex` explicitly. |
| 4 | **`ratio` Can Be a String** | P1 | Spec defines `ratio` as `number`, but main.js uses the string sentinel `"No ratio enforcement"`. AI reading must tolerate both. AI writing should use numeric or omit. |
