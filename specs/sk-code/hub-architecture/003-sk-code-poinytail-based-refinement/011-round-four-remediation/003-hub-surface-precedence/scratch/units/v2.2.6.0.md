# v2.2.6.0, Surface Bundles Follow Detection Precedence

A prompt that names two code surfaces now gets them in the hub's documented detection order: OpenCode, then Obsidian, then Webflow. Before this release, `obsidian plugin webflow implementation` listed the Webflow packet first, although an Obsidian plugin outranks Webflow everywhere else in the hub.

> Spec folder: `specs/sk-code/011-sk-code-poinytail-based-refinement/011-round-four-remediation/003-hub-surface-precedence` (Level 1)

&nbsp;

## What's New at a Glance

- **Review and implementation prompts agree.** A review-phrased Obsidian and Webflow prompt already put Obsidian first. Implementation phrasing now does too, and the routing canary checks both.
- **The hub page says why the order reads that way.** `SKILL.md` now states that the router's tie-break list orders surfaces by detection precedence, so a later edit to that list keeps the rule.
