only the hub's authored text and metadata. The decisions below are already made by the operator.

## The change

Remove the `sk-code-mobile-cli` surface mode from the hub, on every authored surface at once:

- `mode-registry.json`: delete the mode's entry and remove it from `routerPolicy.tieBreak`, so the
  permutation still covers exactly the modes that remain (5 modes: two workflow modes and three
  surface modes). Keep `tieBreak` ordering workflow modes before surface modes.
- `hub-router.json`: remove the mode's router signals, any vocabulary class or resource entry that
  exists only for it, and its resources bundle entry.
- `ROUTER.md`: delete the `MOBILE_CLI` intent key block, every `RESOURCE_MAP` entry that points at
  the removed packet, and the prose paragraph that describes `PI_REMOTE` as a live surface.
- `SKILL.md`: delete the mode's row from the mode table in §1, and set the version authority to
  `4.2.3.0` (frontmatter `version`, plus the version-authority paragraph if it names a version).
- `description.json`: drop the removed surface from the description and keywords, and set
  `version`/`lastUpdated` consistently with the hub's new version authority.
- `shared/references/stack-detection.md`: remove the `PI_REMOTE` detection entirely — its marker
  files (`app-mobile/`, `app-relay/`, `packages/pi-rpc-protocol/`), its precedence row, its CWD
  signals, and its frontmatter mentions. Do not retarget it to another surface: after this change
  a request shaped like `app-mobile` work must resolve no mobile surface at all.
- `changelog/v4.2.3.0.md`: create it, as the newest entry, describing the removal (this entry is
  allowed to name the removed packet because it explains what was removed).
- `changelog/v4.2.2.0.md` and `changelog/v3.3.0.0.md`: correct the sentences that present the
  removed surface as a live part of the hub. Do not change their version headings.
- `.skilled/skills/sk-code/benchmark/reports/compiled-routing/2026-07-21--acceptance--luna-high/skill-benchmark-report.json`,
  `.../2026-07-21--real--luna-high/skill-benchmark-report.json`,

  cases from these three reports, keeping each file valid JSON and keeping every other case
