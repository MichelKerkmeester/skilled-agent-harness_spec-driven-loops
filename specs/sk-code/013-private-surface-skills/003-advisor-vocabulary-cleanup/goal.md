## 1. DURABLE DIRECTIVE

**Objective:** Remove the retired Webflow and Obsidian surface vocabulary from the advisor's tracked scorer, plugin, schemas and tests, give all sixteen `.skilled/skills/` scans an explicit rule for a `local-*` private skill that cannot follow a link outside the roots the operator trusts, and let `@code` and `@review` fall back to an advisor-named `local-*` skill when `sk-code` returns UNKNOWN, with the `.claude`, `.codex` and `.pi` mirrors kept in step.

### Decisions

Frozen choices. Changing one is an amendment. These ids are local to this phase and differ from the parent's D1 to D7: D2 restates parent D4 and D3 restates parent D5.

| ID | Decision |
|----|----------|
| D1 | Eight scans include a `local-*` entry for the local advisor and follow a link only inside a trusted root. Eight exclude it: the compiler, the Hermes sync, the CI root gate, the doctor panel, the bridge deriver, the metadata regenerator, the router-signal generator and the cross-skill edge loader. `spec.md` section 3 lists all sixteen. |
| D2 | A followed `local-*` link resolves through `realpathSync` to a directory inside the skills root or a root named in `SPECKIT_PRIVATE_SKILL_ROOTS`; a bare `statSync` directory check is never the rule. |
| D3 | Every tracked writer skips the `local-*` name before its first filesystem probe, so no private byte is read. |
| D4 | `runtime/scripts/skill-graph.json` is regenerated by `skill_graph_compiler.py`, never hand-edited. |
| D5 | `ci-leaf-manifest-freshness.cjs` is screened and recorded as no change, because neither private source tree carries a `leaf-manifest.json`. |
| D6 | `@code` and `@review` fall back to the advisor's top `local-*` pick when `sk-code` returns UNKNOWN, with the `.claude` twins hand-edited and the `.codex` and `.pi` mirrors regenerated. |
