## 2. Executive Summary

- **Q1 — broad coverage, not complete coverage.** Phases 002 and 003 name the hub registries, generated routing outputs, advisor graph, freshness scan, compiler, Hermes sync, CI root-metadata gate, lexical scorer, OpenCode plugin, doctor panel and fallback graph. Two unlisted walkers are absent from that inventory — one runtime reader and one CI walker — and the producer boundary that keeps private bytes out of the retrieval corpus has no test with private bytes present.
- **Q2 — phase 002 is correct against a filtered baseline, not against the repository.** The planner's 93-file count [SOURCE: specs/sk-code/013-private-surface-skills/research/deep-research-strategy.md:117] comes from T003's packet-name-only query, which excludes `specs/`, changelogs and benchmark reports; a fresh broad tracked grep returns 1,303 paths, 1,123 of them under `specs/`, while that query returns 158 at HEAD and silently omits six tracked `.hermes` files because `rg` skips hidden directories. Four generated retrieval artifacts are explicitly deferred to post-push CI.
- **Q2 — the 001 ignore rule and the 003 symlink rule each have one unproven edge.** The slashless `local-*` rules match both a directory-shaped and a symlink-shaped synthetic path, but the guard's six-root matrix omits `.codex` and `.cursor`, and phase 003 follows a `local-*` symlink with `statSync` and no target containment.
- **Q3 — the packet is not executable task by task.** No phase gives every task the full combination of exact file, one change, proving command, AC mapping and rollback; AC IDs appear only in phase 005's T012 and T014 and no task carries a rollback. One P1 defect sits above that: raw table-cell commands give a false zero when copied, because the acceptance criteria escape the pipe for the markdown table and a writer who copies a raw cell runs a literal-pipe regex.
- **Q4 — phase 005's fresh-clone proof is partially sufficient.** The clone is a real `--no-local` clone of the public remote after the first phase push, and T007 pulls after the trigger-index rebuild, but the full sweep never runs after T017 or after the bot's three sidecars, and it proves marker absence rather than arbitrary-byte absence.
- **Q5 — three risks survive.** History retention is documented and history rewriting is left to the operator; the Obsidian Plugin checkout's links back into this hub are documented but never probed; the local CI drift scripts discover `local-*` roots, so a developer rerun can see the private trees even though CI cannot.
- **Net.** No P0 remains after two review rounds; ten P1 and eight P2 amendments, each naming a phase file and, where task-scoped, a task or AC id. No finding demonstrates a present public leak. The highest-severity items are two false-result proof risks and one live export path: a copied raw table cell reads as a zero when its expression matched nothing, T007's post-rebuild zero-count fails on the 69 retained `specs/sk-code/007-sk-code-obsidian-surface/` paths rather than on a leak, and the compiler follows a `local-*` symlink today, so a private skill created before phase 003 lands can be exported into the tracked `skill-graph.json`.
