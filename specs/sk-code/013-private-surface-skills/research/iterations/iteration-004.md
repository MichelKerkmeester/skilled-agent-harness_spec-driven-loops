**P1 amendment — phase 005 tasks.md and acceptance-criteria.md.** Add a full-blob hash comparison for each private skill file against every blob reachable from origin/main. This exact command compares Git blob IDs without printing private file bodies:

~~~sh
python3 - <<'PY'
import os
import subprocess
from pathlib import Path

repo = Path("/Users/michelkerkmeester/MEGA/Development/Code_Environment/Public")
clone = Path("/tmp/psurf-clone-main")
roots = [
    repo / ".skilled/skills/local-webflow",
    repo / ".skilled/skills/local-obsidian",
    repo / ".hermes/skills/local-webflow",
    repo / ".hermes/skills/local-obsidian",
]
private_blobs = {}
for root in roots:
    if not root.exists():
        continue
    for directory, subdirs, files in os.walk(root, followlinks=True):
        for name in files:
            path = Path(directory) / name
            if not path.is_file():
                continue
            result = subprocess.run(
                ["git", "-C", str(repo), "hash-object", "--stdin"],
                input=path.read_bytes(),
                check=True,
                stdout=subprocess.PIPE,
            )
            private_blobs[result.stdout.decode().strip()] = str(path)

objects = subprocess.run(
    ["git", "-C", str(clone), "rev-list", "--objects", "origin/main"],
    check=True,
    text=True,
    stdout=subprocess.PIPE,
).stdout.splitlines()
hits = []
for line in objects:
    parts = line.split(" ", 1)
    if len(parts) == 2 and parts[0] in private_blobs:
        hits.append((parts[0], parts[1], private_blobs[parts[0]]))
for hit in hits:
    print("reachable private blob:", *hit)
raise SystemExit(bool(hits))
PY
~~~

This catches complete file blobs, including a file renamed before staging with --no-verify. Partial fragments still need an explicit sensitive-content scanner or marker inventory; the hash comparison cannot prove arbitrary byte substrings absent.
