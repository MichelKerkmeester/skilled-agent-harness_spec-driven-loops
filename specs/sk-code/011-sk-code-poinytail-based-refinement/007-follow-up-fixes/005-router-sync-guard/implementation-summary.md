## What Was Built

The restored router-sync guard runs the four checks of the deleted sk-code router-sync suite as one CommonJS script, with a sibling replay library and no test-runner dependency. It runs five legs: 1a (router paths and prose maps), 1b (orphan docs), 2 (surface map), 3 (compiled destinations, leaf manifest and code-opencode map) and 4 (playbook expectations). `--checks` selects legs, and with no flag all five run. Each leg prints one PASS or FAIL line, and the guard exits 0 only when every selected leg passes.

The drift-guard umbrella runs legs 1a, 2, 3 and 4 and reports zero errors. Leg 1b fails on nine docs, so the umbrella does not run it. That follows the operator's option A decision, recorded in goal.md.

## How It Was Delivered

The guard and library were built from the recovered sources in `scratch/source/`, not from the prototype. The library keeps lines 26 to 726 of the recovered file, with a new header, the CLI block removed and the export line reduced to the four functions. The guard is the prototype's leg logic with path constants resolved from its own location. Route-gold is read from its `z_archive` path, and a missing gold fails leg 3.

The tasks in `tasks.md` ran in order. Before-images and the umbrella and leg baselines were captured first, then the edits, the generated artifacts and the verification commands. Each criterion's command and result appear in the table below. The guard also passes when run from `/`, which shows the paths resolve from its own location.

## Known Limitations

1. **Leg 1b is unresolved.** Nine docs have no router naming them: `shared/references/workflow-debug.md`, `workflow-implement.md`, `workflow-verify.md`, and `sk-code-obsidian/references/accessibility.md`, `operations/operations.md`, `quality/doc-quality-gate.md`, `setup/setup.md`, `skill-reference-integrity.md` and `theme-variables.md`. Routing or retiring them is an sk-code follow-up. Leg 1b is then added to the umbrella.
2. **Root playbook is not walked.** The one scenario file in the root `manual-testing-playbook/` folder is outside check 4, as it was in the retired suite.
3. **New files are unseen by the alignment scan.** They are untracked, and the alignment drift scan reads git-tracked files only, until they are staged.
4. **Leg 1b is opt-in.** A bare run of the guard runs legs 1a, 2, 3 and 4; leg 1b runs only when named with `--checks 1b`, so the script exits 0 by default until the nine docs are routed. The orchestrator also removed the unused `SCRIPTS_DIR` constant after review.
