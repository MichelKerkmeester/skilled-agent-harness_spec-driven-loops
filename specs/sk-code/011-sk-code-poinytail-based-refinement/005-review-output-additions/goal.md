## 1. DURABLE DIRECTIVE

**Objective:** Give every sk-code-review output a `Not checked:` line directly above its final `Review status:` line, keep the review agent's optional result block above both closing lines, and add a checker that fails any review output where anything follows the status line.

### Decisions

Frozen choices. Changing one is an amendment.

| ID | Decision |
|----|----------|
| D1 | The optional `AGENT_IO_RESULT` block goes after the review body and before the closing `Not checked:` and `Review status:` lines. The status line is never restated after it, so each output holds exactly one status line. |
| D2 | A full review carries one `Not checked:` line, separated from the status line by one blank line, defaulting to `Not checked: nothing material`. The M-1 and M-2 skip outputs are the status line alone. |
| D3 | The final-line check is the new script `.skilled/skills/sk-code/sk-code-review/scripts/check-review-final-line.js`. `check-rule-copies.js` runs it over the example outputs in `SKILL.md` and `README.md`, so CI reaches it with no workflow edit. |
| D4 | `.claude/agents/review.md` is edited by hand. The `.codex`, `.pi` and `.hermes` copies are regenerated by their sync scripts and never hand-edited. |
| D5 | The CR-024 scenario prompt is not changed, because it must stay equal to the prompt in the root playbook index. |
