Follow every command with `; echo "exit=$?"` and read the output together with the exit status. Rules that bind every task:

- Do not run `rm -rf`, `git diff`, `git add`, `git commit`, `git stash`, `git checkout` or `git reset`. Compare a file with its saved copy using `diff` against `$F/scratch/before/`.
- Never run `check-comment-hygiene.sh`, `check-dist-staleness.sh` or `ceiling-report.sh` through `bash`. They are Python programs with a `.sh` name. Only the three `*.test.sh` files run through `bash`.
- Save every copy of a markdown file as `.txt`, so the link checker and the trigger index do not scan it.
- Never read or write anything under `specs/sk-code/011-sk-code-poinytail-based-refinement/001-ponytail-deep-research/`.
- Edit only the three files in the Files to Change table of `spec.md`. Do not edit `$Q/scripts/`, `$Q/assets/`, `$Q/manual-testing-playbook/`, `$Q/benchmark/`, anything under `.skilled/skills/sk-code/sk-code-obsidian/`, any hub file, any `.hermes/` file or any file outside `$Q` and `$F`.
- Each Phase 2 edit replaces one Find block from `plan.md` section 3 with its Replace block, character for character. The inline quote in each task drops leading spaces when rendered, so take the exact text from the `plan.md` block or from `$F/scratch/dispatch-units.json`. Do not reflow, re-wrap or fix anything else on the line.
- Run `sync-skills-hermes.cjs` only with `--check`. The write form is the orchestrator's. Never run a compiled-route re-mint or a leaf-manifest refresh.
- Write no em dash and no semicolon in any text you add.
- If a command prints something other than the expected result, stop and report it. Do not change an expected value to match.
