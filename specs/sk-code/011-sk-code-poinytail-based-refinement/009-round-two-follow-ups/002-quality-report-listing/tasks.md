- Do not run `rm -rf`, `git diff`, `git add`, `git commit`, `git stash`, `git checkout` or `git reset`. Compare a file with its saved copy using `diff` against `$F/scratch/before/`.
- Run `$Q/scripts/ceiling-report.sh` directly, never as `bash $Q/scripts/ceiling-report.sh`. It is a Python program with a `.sh` name. Only `ceiling-report.test.sh` runs through `bash`.
- Save every copy of a markdown file as `.txt`, so the link checker and the trigger index do not scan it.
- Never read or write anything under `specs/sk-code/011-sk-code-poinytail-based-refinement/001-ponytail-deep-research/research/`.
- Edit only the files in the Files to Change table of `spec.md`. Do not edit `$Q/scripts/` (the report, its test, `scripts/README.md`), any `.hermes/` file, the routing diagram or the `INTENT_SIGNALS` block in `SKILL.md`.
- Run `sync-skills-hermes.cjs` only with `--check`. The write form is the orchestrator's.
- Write no em dash, no semicolon and no Oxford comma in any prose you add.
- If a command prints something other than the expected result, stop and report it. Do not change an expected value to match.
