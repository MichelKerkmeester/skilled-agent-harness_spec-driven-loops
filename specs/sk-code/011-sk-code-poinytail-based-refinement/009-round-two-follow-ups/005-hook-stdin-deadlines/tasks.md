Paths of the form `.skilled/hooks/...` below are relative to the repository root. Line numbers are from the planning read, taken before any edit of that file; the quoted text wins if they differ. The design, the per-file table, the reader block and the full test file are in `plan.md` section 3.

Two texts recur in the hook tasks. The **reader block** is these five lines plus the one blank line after them:

```js
async function readStdin() {
  const chunks = [];
  for await (const chunk of process.stdin) chunks.push(chunk);
  return Buffer.concat(chunks).toString('utf8');
}
```

The **import line** is `import { readStdin } from '../../shared/hook-adapter-shared.cjs';`. In a hook task, delete the reader block first and then add the import line on its own new line directly after the quoted anchor line.
