All commands run from the repository root, which is the worktree whose path ends in `092-sk-code-ponytail-refinement` (confirm with `pwd`). Shell state does not persist between calls, so start every shell call with this line, then add the task's command:

`Q=.skilled/skills/sk-code/sk-code-quality; F=specs/sk-code/011-sk-code-poinytail-based-refinement/010-round-three-remediation/003-quality-mode; HUB=.skilled/skills/sk-code;`

Follow every command with `; echo "exit=$?"` and read the output together with the exit status. Rules that bind every task:

- Do not run `rm -rf`, `git diff`, `git add`, `git commit`, `git stash`, `git checkout` or `git reset`. Compare a file with its saved copy using `diff` against `$F/scratch/before/`.
- Never run `check-comment-hygiene.sh`, `check-dist-staleness.sh` or `ceiling-report.sh` through `bash`. They are Python programs with a `.sh` name. Only the three `*.test.sh` files run through `bash`.
- Save every copy of a markdown file as `.txt`, so the link checker and the trigger index do not scan it.
- Never read or write anything under `specs/sk-code/011-sk-code-poinytail-based-refinement/001-ponytail-deep-research/research/`.
- Edit only the files in the Files to Change table of `spec.md`. Do not edit `$Q/scripts/`, `$Q/assets/`, any `.hermes/` file, the `INTENT_SIGNALS` or `RESOURCE_MAP` blocks, `.claude/settings.json` or any file outside `$Q` and `$F`.
- Each Phase 2 edit replaces one Find block from `plan.md` section 3 with its Replace block, character for character. Do not reflow, re-wrap or fix anything else on the line.
- Run `sync-skills-hermes.cjs` only with `--check`. The write form is the orchestrator's.
- Write no em dash in any text you add.
- If a command prints something other than the expected result, stop and report it. Do not change an expected value to match.
