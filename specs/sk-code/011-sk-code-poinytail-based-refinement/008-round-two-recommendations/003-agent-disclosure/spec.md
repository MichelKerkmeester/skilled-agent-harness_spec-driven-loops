This is **Phase 3** of the Round two research recommendations specification.

**Scope Boundary**: The reach list and the disclosure lines in the three agent definitions, their Claude forks and their generated Codex, Pi and Hermes copies. No review, sk-code, repo-rule or contract file changes.

## 2. PROBLEM & PURPOSE

### Problem Statement
The agents that do code work lag their own hub. `@code` has no checklist item for the places a change must reach, though the implement workflow states that list, and its RETURN has no line for what it skipped. `@debug` has no not-checked line in its three response shapes, caps hypotheses without saying how many it dropped, and reads no test harness before it reproduces a failure. `@orchestrate` has Scope and Boundary fields in its Task Format but no reach field, so a leaf starts without the reach set.

### Purpose
Each of the three agents states its reach set and what it did not check, in its canonical file and in every generated copy, and every mirror check stays green.

## 6. RISKS & DEPENDENCIES

| Type | Item | Impact | Mitigation |
|------|------|--------|------------|
| Dependency | Phases 001 and 002 build in parallel. Phase 002 edits `review.md` and its mirrors, and Phase 001 edits sk-code files that may feed the Hermes sk-code copy | Each sync script writes every drifted copy, not only this phase's three, so an unrelated copy would be rewritten | Phase 2 runs each `--check` before its regenerate step and stops on any agent name other than code, debug and orchestrate, or any Hermes path other than the three agent copies |

| Risk | The protected-path diff in T042 can fail because a sibling phase wrote the same path during this build | A false failure blocks the goal | Report the changed line with its path, and do not revert it |
| Risk | The Codex TOML wraps each body in a `'''` literal string | A `'''` in the new text breaks the TOML | The new text contains no `'''` |
| Risk | Claude forks use `.claude/agents` paths where the canonical files use `.skilled/agents` | Path words in the new text would differ between copies | The new lines name no path |
| Risk | The objective is one sentence, while `authoring-standards.md` section 4 asks that criteria repeat in the objective | An evaluator reading only the objective sees no criteria | Follow the brief's one-sentence objective, and flag the conflict to the orchestrator |
