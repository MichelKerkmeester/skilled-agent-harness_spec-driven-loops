## What Was Built

A model that copies a system-spec-kit example or follows the authoring checklist no longer meets a broken line. The 18 example descriptions are whole sentences, the checklist names a packet that exists, the style guide says table in both places, the dead `templates/.hashes` file is gone, and every owner `002` ledger row is fixed.

### Phase 2: template-and-example-defect-repair

`apply_row.py` made every text change. It applied the 25 known rows (`scratch/applied.txt`: 25 `APPLIED`, 25 `extra_paths=0`, 25 `locator=0 expected=1`). The census loop then took the 47 owner `002` ledger rows: 18 applied, 24 already fixed by a known row and 5 left for a worker (`scratch/census.txt`). Those 5 needed no worker. Their phase 1 evidence tested a disk fact that stays true after the fix, so the operator had the five evidence commands rewritten to test the doc itself. The frontier review found four second copies of fixed defects, and the applier fixed those as rows R-1 to R-4. Three compiled deep-loop contracts and one golden snapshot record what the rows changed, so they were regenerated by their own tools.

## How It Was Delivered

The Claude Code conductor ran every scripted block itself, and no worker model edited a file. One read-only review ran on cli-devin swe-2-max under `--permission-mode auto`, which reads files only. The conductor therefore wrote the diff and the check outputs to `scratch/review/` first. Each finding was confirmed in the file before the applier fixed it. The suite ran four times: once cut off by its own time bound, then once each after fixing the two stale generated artifacts it found.

## Key Decisions

| Decision | Why |
|----------|-----|
| Apply exact swaps and review fixes by script | A script refuses unless the old text occurs once, and a model can reword the new text |
| Teach the applier `DELETE LINE` | The one ledger row with that value was written literally into the file by the first applier |
| Keep the four core and addons rows | Operator choice. Phase 003's counts moved to 14 and 217, measured with its own test |
| Rewrite five ledger evidence commands | Operator choice. A disk-fact check can never stop reproducing |
| Regenerate the contracts and the snapshot | Both record the changed text, so leaving them stale fails the suite |
