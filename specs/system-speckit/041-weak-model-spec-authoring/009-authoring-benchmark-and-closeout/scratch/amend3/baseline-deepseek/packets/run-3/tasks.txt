## Phase 2: Implementation

- [ ] T004 Write the failing regression test (`$S/runtime/cli/tests/recommend-level-quiet.vitest.ts`). Cover the quiet line, unchanged default output, JSON precedence, the error paths and `--help`. Verify: the focused run fails only on the `--quiet` assertions and passes the default-output assertion, proving the test observes the missing feature rather than a broken harness.
- [ ] T005 Add `QUIET_OUTPUT=false` beside `JSON_OUTPUT` (`$SCRIPT`). Verify: `rg -n 'QUIET_OUTPUT=false' "$SCRIPT"` prints one line.
- [ ] T006 Add `format_level_line()` and call it from both `output_text()` and the new quiet path (`$SCRIPT`). Verify: `rg -n 'format_level_line' "$SCRIPT"` prints the definition and both call sites.
- [ ] T007 Add `output_quiet()` that prints the shared level line and nothing else (`$SCRIPT`). Verify: `rg -n 'output_quiet' "$SCRIPT"` prints the definition.
- [ ] T008 Add the `--quiet` case to the argument loop (`$SCRIPT`). Verify: `rg -n -A 3 -- '--quiet\)' "$SCRIPT"` shows `QUIET_OUTPUT=true` and `shift`.
- [ ] T009 Change the output dispatch to JSON, then quiet, then text (`$SCRIPT`). Verify: `rg -n -A 7 'JSON_OUTPUT" = true' "$SCRIPT"` shows the three-branch order with JSON first.
- [ ] T010 Add `--quiet` to the file header OPTIONS block (`$SCRIPT`). Verify: `rg -n -- '--quiet' "$SCRIPT" | head -3` includes the header line above the `--json` line.
- [ ] T011 Add `--quiet` and an example to `show_help()` (`$SCRIPT`). Verify: `bash "$SCRIPT" --help | rg -c -- '--quiet'` prints `2`.

<!-- ANCHOR:phase-3 -->
## Phase 3: Verification

- [ ] T012 Check shell syntax (no file). Verify: `bash -n "$SCRIPT"` exits 0 with no output.
- [ ] T013 Check the quiet line shape (no file). Verify: `bash "$SCRIPT" --loc 50 --files 2 --quiet | wc -l` prints `1`, and `bash "$SCRIPT" --loc 50 --files 2 --quiet | od -c | head -2` shows `R e c o m m e n d e d` at offset 0 with no leading newline.
- [ ] T014 Check the quiet line across the level range (no file). For `--loc 50 --files 2`, `--loc 200 --files 5 --api` and `--loc 500 --files 15 --auth --api --db --architectural`, compare the quiet output with the second line of the default output. Verify: `for args in ...; do diff <(bash "$SCRIPT" $args | sed -n '2p') <(bash "$SCRIPT" $args --quiet); done` prints nothing.
- [ ] T015 Check default output is byte-identical (no file). Verify: for each of the eight corpus cases, `diff -u "$P/scratch/baseline/<case>.out" <(bash "$SCRIPT" <args>)` and the same for `.err` print nothing, and each `.code` matches the observed exit status.
- [ ] T016 Check JSON precedence (no file). Verify: `diff <(bash "$SCRIPT" --loc 100 --files 3 --json) <(bash "$SCRIPT" --loc 100 --files 3 --json --quiet)` prints nothing, and `bash "$SCRIPT" --loc 100 --files 3 --json --quiet | jq -e '.recommended_level'` prints the number.
- [ ] T017 Check the error paths (no file). Verify: `bash "$SCRIPT" --quiet --loc` exits 1 and prints `ERROR: --loc requires a numeric value` on stderr; `bash "$SCRIPT" --quiet` exits 1 and prints `At least --loc or --files must be provided`; `bash "$SCRIPT" --quiet --bogus` exits 1 and prints `ERROR: Unknown option: --bogus`.
- [ ] T018 Check the help text (no file). Verify: `bash "$SCRIPT" --help` exits 0, lists `--quiet` in OPTIONS, and shows an example that uses it; the header OPTIONS block lists the same option.
- [ ] T019 Run the focused regression test (no file). Verify: `cd "$S" && npx vitest run runtime/cli/tests/recommend-level-quiet.vitest.ts --config vitest.config.ts` prints `Test Files 1 passed`.
- [ ] T020 Run the full CLI suite (no file). Verify: `cd "$S" && npm run test --workspace=@spec-kit/cli` exits 0, and `runtime/cli/tests/test-phase-system.js` still passes.
