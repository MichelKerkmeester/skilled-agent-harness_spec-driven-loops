<!-- ANCHOR:phase-2 -->
## Phase 2: Implementation

- [ ] T004 Add `QUIET=false` beside `JSON_OUTPUT=false` in the globals block (`$S`). Verify: `rg -n '^QUIET=false' $S` prints one line.
- [ ] T005 Add the `--quiet)` case arm to the argument parser, matching the shape of the `--json|-j` arm (`$S`). Verify: `rg -n '^    --quiet\)' $S` prints one line.
- [ ] T006 Add the conflict check between the parse loop and the numeric validation, rejecting `--quiet` with `--json` (`$S`). Verify: `bash $S --quiet --json --loc 50 --files 2 >/dev/null 2>&1; echo $?` prints `1`.
- [ ] T007 Dispatch the one-line emitter in the output block so `QUIET` prints `Recommended Level: <N> (<Name>)` instead of calling `output_text()` (`$S`). Verify: `bash $S --quiet --loc 500 --files 15 --auth --api --db --architectural` prints `Recommended Level: 3 (Full)`.
- [ ] T008 Document `--quiet` in `show_help()` with its one-line contract (`$S`). Verify: `bash $S --help | rg -c -- '--quiet'` prints `1`.
- [ ] T009 Document `--quiet` in the header OPTIONS block beside `--json, -j` (`$S`). Verify: `rg -n '^#   --quiet' $S` prints one line.
