- [ ] T009 Document the flag in the header OPTIONS block, the `show_help` table and one example (`$S`). Verify: `bash "$S" --help` names `--quiet` in the options table and in one example.
- [ ] T010 [P] Confirm no new error path and no stderr change (`$S`). Verify: `bash "$S" --quiet --loc 0 --files 0 >/dev/null` exits 1 and writes the existing error to stderr.
