So 006's five observables for S2 ("1 line, 1 key, `Amber`, 1 nudge line, nudge file 1") must be collapsed into one shell command's exit status, and its five human actions must map onto `send`/`action`. ### B. Where the contract is incomplete or contradictory

6. **Hard conflict: 006's stage S12 cannot live in the same scenario file or the same run as S0 to S11.** S12 needs a *second* on-disk project (`$K`) with `SYSTEM_DECISION_CAPTURE_DISABLED=1`. The format gives one top-level `env` per script, the runner takes one `--scenario` and one `--scratch` per invocation, and a second fenced `json conversation` block is rejected as `CONVERSATION_SCRIPT_INVALID`. So either S12 becomes a second scenario file plus a second runner invocation, or 065 must accept per-runtime/per-turn `env` or a `reset` action. As written, 006's REQ-001 and AC-001 ("13 stage rows S0 to S12" in one file) and AC-005 (13-row `checkpoints.tsv` from one run) are unsatisfiable. ## Reflection

- What worked and why: reading the *consumer's acceptance criteria* before the provider's plan. AC-005 ("13 rows, each with PASS, FAIL, DEVIATION or N/A") plus T007's `wc -l` is a machine-checkable claim, and it failed against the provider's enumerated evidence list in one comparison. Vague prose would have hidden the same gap; a row count and a closed vocabulary did not.
- What did not work and why: my first pass assumed 006's stage table was the scenario content. It is not — 006's plan states the scenario carries "the setup block, the stage table S0 to S12, the checkpoint commands" while the runner reads only the block. Two documents are competing to be the source of truth for a checkpoint, and only the block is executed. Root cause: 006 was planned before 065's key set existed, so it described its stages in the vocabulary it had.
- What I would do differently: check the provider's *rejection rules* (`REQ-003`'s invalid shapes) before its happy path. The S12 finding fell out of one line — "a second block" is invalid — and that line was cheaper to reach than the plan it invalidated.
