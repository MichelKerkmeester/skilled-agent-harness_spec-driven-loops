export function devinAnswerRecords({ transcript, sessionId, now }):
1. Remember every tool_call with function_name 'ask_user_question' by tool_call_id (its arguments).
2. For each observation result whose source_call_id is remembered and whose content is a string starting with 'User answered your questions:', JSON.parse the text after the first newline; skip on parse error.
3. answers object: for each question text, skip when skipped is true or selected is not an array; answer = selected labels with the label 'Other' replaced by custom_text when custom_text is a non-empty string, joined with ', '; skip an empty result.
4. Call normalizeAskUserQuestion({ runtime: 'devin', sessionId, toolUseId: tool_call_id, toolInput: { questions: each question mapped to { question, header, options, multiSelect: Boolean(q.multi_select) } }, toolResponse: { answers }, source: 'transcript', now }) and collect all records.
