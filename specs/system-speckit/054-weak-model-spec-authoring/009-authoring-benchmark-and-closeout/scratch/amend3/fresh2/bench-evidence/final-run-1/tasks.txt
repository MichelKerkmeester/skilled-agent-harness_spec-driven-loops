<!-- ANCHOR:phase-2 -->
## Phase 2: Implementation

- [ ] T005 Add a `QUIET=false` global beside `JSON_OUTPUT` (`$S`). Verify: `rg -n '^QUIET=false' $S` prints one line.
- [ ] T006 Add the `--quiet` case branch to the argument parser (`$S`). Verify: `rg -n -A 3 -- '--quiet\)' $S` prints the branch that sets `QUIET=true` and shifts.
- [ ] T007 Add `output_quiet()` that prints only `Recommended Level: ${RECOMMENDED_LEVEL} (${LEVEL_NAME})` (`$S`). Verify: `bash -n $S` exits 0.
- [ ] T008 Wire the dispatch so `--quiet` selects the quiet renderer, `--json` keeps precedence and text stays the default (`$S`). Verify: `bash $S --loc 50 --files 2 --quiet | wc -l` prints `1`; `bash $S --loc 50 --files 2 | wc -l` still prints `16`.
- [ ] T009 Add `--quiet` to the `--help` OPTIONS list and add one quiet example, then update the header OPTIONS block (`$S`). Verify: `bash $S --help | rg -c -- '--quiet'` prints `2`.
- [ ] T010 [P] Create the regression test with cases for none, `--quiet`, `--json`, both flags, `--no-recommend-phases`, and the error paths (`T`). Verify: `npx vitest run tests/recommend-level-quiet.vitest.ts` passes from `.skilled/skills/system-spec-kit/runtime/cli`.
