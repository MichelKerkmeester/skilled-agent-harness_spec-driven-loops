## Phase 1: Setup

- [ ] T001 Read the argument-parse loop, `output_text()`, `output_json()`, `show_help()` and the output dispatch in `$S`. Verify: `rg -n 'output_text|output_json|show_help|JSON_OUTPUT|Recommended Level' $S` prints each site.
- [ ] T002 Capture baseline output for the verification-matrix invocations into `$P/scratch/baseline/` — the default report, `--json`, `--no-recommend-phases`, `--help`, and each error case. Verify: `ls $P/scratch/baseline/` lists one file per invocation.
- [ ] T003 [P] Inventory the producers and consumers of the level line. Verify: `rg -n 'Recommended Level' $S` prints one site today, and `rg -ln 'recommend-level' .skilled --glob '*.sh'` finds no caller that parses the report.

<!-- ANCHOR:phase-2 -->
## Phase 2: Implementation

- [ ] T004 Add `QUIET=false` to the globals and a `--quiet)` case to the parse loop in `$S`. Verify: `bash $S --quiet --loc 50 --files 2 >/dev/null && echo OK` prints `OK`, and the same command with `--quiet` placed last also exits 0.
- [ ] T005 Add `output_level_line()` to the output-helper section of `$S` and replace the level literal inside `output_text()` with a call to it. Verify: `rg -n 'output_level_line|Recommended Level' $S` prints the helper definition, both call sites and one literal.
- [ ] T006 Add the quiet branch to the output dispatch in `$S`, after the `--json` check and before `output_text`. Verify: `bash $S --quiet --loc 1000 --files 20 --architectural --api --db` prints exactly `Recommended Level: 3 (Full)` and `| wc -l` prints `1`.
- [ ] T007 Document `--quiet` in the header OPTIONS comment and in `show_help()` in `$S`. Verify: `bash $S --help | grep -c -- '--quiet'` prints `1` or more.
- [ ] T008 [P] Confirm the required-input validation still runs before output selection. Verify: `bash $S --quiet` exits 1, writes the missing-input error to stderr, and leaves stdout empty.
<!-- /ANCHOR:phase-2 -->
