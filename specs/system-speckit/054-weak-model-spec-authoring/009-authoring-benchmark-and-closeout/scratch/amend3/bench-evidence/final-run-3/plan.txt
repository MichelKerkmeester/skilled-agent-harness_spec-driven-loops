### Technical Context

| Aspect | Value |

| **Framework** | SpecKit CLI runtime (`runtime/cli/spec/`) |
| **Storage** | None |

### Overview
Change one script: add a `QUIET` global, a `--quiet` case arm in the existing argument loop, and an early branch in `output_text()` that prints the level line and returns. The branch reuses the same `Recommended Level:` format string as the default report, so the two cannot drift, and the scoring, JSON and error paths are left untouched.

## 3. ARCHITECTURE

### Pattern
Single-script CLI with a render-time mode branch

### Key Components
- **`recommend-level.sh` argument loop**: owns flag parsing; gains one `--quiet` case arm that sets `QUIET=true`
- **`output_text()` renderer**: owns the human report and the level-line format; gains an early quiet branch that prints the same line and returns
- **`show_help()` and the header OPTIONS block**: own the documented CLI surface; both gain one `--quiet` line

### Data Flow
Arguments populate globals (`LOC`, `FILES`, risk flags, `JSON_OUTPUT`, `QUIET`) → the scoring functions read those globals → `determine_level()` sets `RECOMMENDED_LEVEL` and `LEVEL_NAME` → section 7 dispatches to `output_json()` or `output_text()`, and `output_text()` returns the one-line form when `QUIET` is true.

## L3: ARCHITECTURE DECISION RECORD

### ADR-001: Render the quiet form inside `output_text()`

**Status**: Proposed

**Context**: The `Recommended Level: <N> (<Name>)` line is formatted in one place, `output_text()`. A quiet mode that formats the same line anywhere else creates a second format string that can drift from the report operators read.

**Decision**: Add an early branch at the top of `output_text()`: when `QUIET` is true, print the same level line and return before the report body.

**Consequences**:
- The quiet line and the default report's level line share one format site and cannot diverge
- `output_text()` gains a mode branch; the function name still describes what it does

**Alternatives Rejected**:
- A separate `output_quiet()` function: duplicates the format string, which is the exact drift risk this decision avoids
- Branching in the section 7 dispatch: same duplication, with the format string further from the report it must match

---

### ADR-002: `--json` takes precedence over `--quiet`

**Status**: Proposed

**Context**: `--quiet` and `--json` are both output selectors, and a caller may pass both through a generic flag set. The combination has no obvious meaning: JSON is already machine-readable and holds more than the level.

**Decision**: When `JSON_OUTPUT` is true, emit the JSON document unchanged and ignore `QUIET`.

**Consequences**:
- One documented precedence rule; `--json --quiet` never produces the text line
- Scripts that pass both flags keep their JSON contract instead of failing

**Alternatives Rejected**:
- Erroring on the combination: breaks callers that assemble flags generically
- Quiet wins: would need a JSON-to-line path and would silently drop the fields the caller asked for
