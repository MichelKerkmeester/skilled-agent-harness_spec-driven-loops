## Method

- Verify ratio: `rg -c '^- \[[ xB]\] T[0-9].*Verify: ' tasks.md` over `rg -c '^- \[[ xB]\] T[0-9]' tasks.md`, the card's two patterns (`spec-authoring-card.md:122`). `NA` when the packet has no task line.
- Residue: each packet `.md` file is cut into sample rows by the same rule that built `residue-strings.txt` (list or checklist item with its marker, id and priority tags stripped, whitespace-collapsed table row, or a diagram fragment), and a row counts when it equals a residue string exactly. A row the author edited no longer counts. `residue-strings.txt` comes from `rescore.py build-residue L/prep/sandbox-map.tsv`, so its refined tree is the latest prepared refined snapshot, not necessarily the one each old run used. The plan's Definition of Ready and Done defaults lead the hit list; a reader may judge some of them acceptable as kept.
- Line counts: a sentence (a table row is one unit) states a report line count when it gives a number from 2 to 60 before `lines`, `-line` or a `wc -l` of a run of the script, is about the report or output, is not about `--quiet` or `--json`, and the number does not describe a script, breakdown, block, section or other part. The input is the `--loc`, `--files` and flag set named in the same unit; the count is checked against `bash recommend-level.sh <input> | wc -l` from this worktree, whose script is byte-identical in all four sandbox trees. A unit with no `--loc` and `--files`, or with two values for one flag, is UNPARSED and never filled in from another sentence.
- Dangling DR pointers: lines naming `decision-record.md` in a packet folder that holds no such file.
- Quoted claim text writes each em dash as a spaced hyphen.
