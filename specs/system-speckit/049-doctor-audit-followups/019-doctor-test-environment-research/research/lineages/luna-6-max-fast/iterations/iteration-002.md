### 4. Create the long-lived worktree under sk-git’s grammar
The requested `.worktrees/.doctor-update-test-environment` path is not valid for a named worktree: the required path is `.worktrees/{NNN}-{slug}`, paired with branch `worktrees/{NNN}-{slug}`, and the number must come from the allocator. [SOURCE: .skilled/skills/sk-git/references/worktree-workflows.md:140-164] For this long-lived fixture, use a local branch and the allocator, for example `.skilled/skills/sk-git/scripts/worktree-naming.sh create doctor-update-test-environment v4.0.0.0 --no-provision`; it prints the allocated branch/path, with `--no-provision` avoiding unrelated installs/builds. [SOURCE: .skilled/skills/sk-git/scripts/worktree-naming.sh:395-420] Detached HEAD is reserved for a numbered quick experiment (`.worktrees/{NNN}-detached-{slug}`); it is a poor lifecycle home for committed fixture overrides. [SOURCE: .skilled/skills/sk-git/references/worktree-workflows.md:197-202] [SOURCE: .skilled/skills/sk-git/references/worktree-workflows.md:387-395] Keep that branch local and do not push it.
