## Findings

1. **Make sub-track identity explicit and report unregistered folders.** The directory name plus numbered children is not enough to distinguish an intended sub-track from an accidental folder. The earlier detection proposal needs a declaration rule: require a direct child of a recognized track, no spec.md, a paired description.json and graph-metadata.json, description.json level set to sub-track, and registration in the parent track's children_ids. The current description schema accepts a string level, while graph-metadata has packet-shaped identity fields and no container discriminator. The sub-track identity should be track/sub-track; its description and graph spec folder fields should use that identity; its parent_id should point to the track; and its children_ids should list only immediate numbered packet roots. The track should list its direct packets and declared sub-track containers. Packets inside a sub-track keep their full path identity. Existing parent derivation only recognizes a numbered parent, so packet identity and parent derivation must be extended together. A stray non-numbered folder without the declaration must be diagnosed rather than silently ignored or promoted.
