# Changelog digests: merged index

Fifty-four fresh agents, one per skill or mode with a `changelog/` folder, each read that folder's last ten entries and compared them against `../../../CHANGELOG-v4.0.0.0.md`. This index collects every "facts the draft gets wrong or misses" section verbatim, one block per digest, so the correction pass reads one file. The per-digest files beside this one hold the per-version paragraphs and the identity check.

## 1. WHAT THE SWEEP SETTLED

Corrections that recur across digests and hold against the current tree:

- Auth paths the draft never mentions: cli-codex dropped `OPENAI_API_KEY` for ChatGPT OAuth only, cli-claude-code dropped `ANTHROPIC_API_KEY` for subscription OAuth only. Neither is in Upgrade Notes.
- Model rosters are much wider than the draft's four pairings. Codex carries four GPT-5.6 models with effort ceilings, Devin six families including Gemini 3.7 Flash and GPT-5.6 Luna Max, Cursor 21 ids across six families, Pi a closed six-provider roster. The draft's "Gemini retired" is true only of the standalone bridge. Gemini is live through Devin and Cursor.
- The draft's "every CLI kind carries an enforced model allowlist" is false for cli-opencode (no code-enforced list) and only fan-out-enforced for cli-pi.
- Default-model churn absent from Changed Defaults: opencode to `opencode-go/deepseek-v4-flash --variant max` with Terra removed, Pi to `deepseek-v4-flash` with DeepSeek V4 Pro and the direct DeepSeek provider retired, Devin `adaptive` to `swe`.
- Removed surfaces the draft omits: `mcp-webflow`, the Ox Alpha routes, the four `deep_loop_graph_*` MCP tools, the `pi-subagents` directive already noted. The alignment removal also cascaded into `/deep:command-benchmark` and the `conformance_benchmark` family, which the draft does not say.
- `mcp-code-mode` is standalone, so "every bridge lives under mcp-tooling" is wrong, and the draft never names it. `sk-vision` is standalone too and is absent from all 463 lines, including its opt-in default flip.
- sk-doc's four-part frontmatter versioning standard (mandatory `version`, CI gate, 2,210-doc rollout) is missing, and the draft should state that the older sk-doc snake_case rule was reversed by the kebab decision.
- sk-code's pre-v4 shape is described wrongly. It was eight sub-skills collapsed to four packets, not one flat skill. The `sk-code-review` checklists moved from `references/` to `assets/`.
- sk-design-chart's dark-ground support (`prefers-color-scheme`) is the largest chart change and is missing. "Three decisions held by checkers" undercounts a check that grew to 25.
- sk-communication has a second, always-on lane (`/rewrite:explain-visually` with a depth dial). The draft's "off by default" applies to the projection lane only.
- sk-prompt's per-model profile capability was removed with no replacement, not "folded back". The intermediate name `sk-prompt-improve` is missing from the rename list.
- sk-git: the fast-forward follower daemon was never auto-started and `git-primary-reconcile.sh` on SessionStart replaced it. Seven shipped features are absent, including `SPECKIT_WORKTREE_BASE` and the three live-sync disable flags.
- system-skill-advisor: the fail-closed trust gate (`--trusted`, `SYSTEM_SKILL_ADVISOR_TRUST_DEFAULT`) is a breaking change the draft omits, and the RRF fusion spine graduated to a shipping default.
