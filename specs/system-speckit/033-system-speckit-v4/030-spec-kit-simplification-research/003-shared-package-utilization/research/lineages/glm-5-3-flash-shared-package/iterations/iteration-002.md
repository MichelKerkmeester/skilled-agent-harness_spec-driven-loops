# Iteration 2: The embeddings subsystem — the 1,011-line monolith vs the live advisor chain

## Focus

`embeddings.ts` (monolith) vs `embeddings/*` (factory, registry, profile, auto-select, adapter + adapters/ollama, 4 providers, types): which parts have a live consumer after the memory-database retirement; the skill-advisor shim layer (`mcp-server/lib/embedders/*`); the launcher's `MEMORY_DB_PATH`→factory coupling; `bin/hf-model-server.cjs`; the `vec_metadata`/`active_embedder_*` convention; and which of the `generateEmbedding`-family functions have any production caller. Also resolves F1.10 (the chunking edge) and F1.8's pending shim-existence claim.
