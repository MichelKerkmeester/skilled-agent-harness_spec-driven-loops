## Focus

Map C, the second skill group: `cli-external-orchestration` (756 files), `system-skill-advisor` (306), `sk-code` (282), `sk-doc` (280). Same artifact classes and the same per-file code citations as iteration 5.

## Findings

- **Finding 1 — `cli-external-orchestration`'s live code does not name the path; its non-markdown surface is history.** 197 of its 200 non-markdown files are benchmark report JSON/CSV under `*/benchmark/reports/`; the remaining 3 are two permissions-matrix example packets (authored JSON that hardcode `.opencode/specs/...` globs) and `graph-metadata.json` (generated). Its 556 markdown files split 274 freeze (211 benchmark + 63 changelog), 227 playbook, 21 references, 16 feature-catalog, 14 top-level docs, 4 assets. **Classification:** `freeze` for the history, `mechanical` for the live docs, `regenerate` for `graph-metadata.json`. **Consequence:** this skill is cheap to migrate and expensive to get wrong: a rewrite that touches its benchmark history corrupts 274 recorded files for no functional gain. [SOURCE: .opencode/skills/cli-external-orchestration/graph-metadata.json:323]

- **Finding 2 — `system-skill-advisor` is 138 non-markdown files, almost all under `runtime/`, and 136 of them are mechanism.** 121 TypeScript source/test files plus 4 `.mjs`, 4 `.py`, 5 `.sh`, 1 `.cjs`; only `graph-metadata.json` and one lifecycle fixture are non-mechanical. The skill's hook surfaces (`hooks/skill-advisor-hook.md`, `hooks/skill-advisor-hook-validation.md`) and `INSTALL-GUIDE.md` are documentation. **Classification:** `mechanical` 136, `regenerate` 1, `manual` 1. **Consequence:** the advisor's own path resolution is the thing Map C's rewrite has to get right; a missed rewrite here disables the Gate 2 brief that every other surface depends on. [SOURCE: .opencode/skills/system-skill-advisor/runtime/tests/fixtures/lifecycle/index.ts:22]

- **Finding 3 — `sk-code` and `sk-doc` are documentation-heavy with small, shared code surfaces.** `sk-code`: 245 markdown (118 playbook, 51 references, 28+14 freeze, 17 top docs, 13 assets) and 37 non-markdown (24 freeze benchmark JSON, 11 mechanical scripts, 2 regenerate). `sk-doc`: 207 markdown (76 playbook, 35 top docs, 34 references, 24 assets, 29 freeze, 3 fixtures) and 73 non-markdown (30 Python scripts, 14 CJS, 1 mjs, 1 sh, 14 freeze, 2 regenerate). **Classification:** `mechanical` for live scripts and docs, `freeze` for history, `regenerate` for graph metadata. **Consequence:** `sk-doc`'s Python validators are referenced from root docs and hooks (for example `validate_document.py` in `.claude/hooks/README.md`); their paths appear in runnable instructions across other surfaces, so a missed rewrite propagates.

- **Finding 4 — the freeze class across these four skills is 319 non-markdown files and 338 markdown files.** They are benchmark reports, changelogs and recorded scenario data. **Classification:** `freeze` (must not be rewritten). **Consequence:** roughly 650 of the 1,624 files in this iteration are read-only history; the rewrite script must accept an exclusion list, not a blanket rule.

- **Finding 5 — the four skills' generated metadata is uniformly owned by two `sk-doc` generators.** `graph-metadata.json` in `cli-external-orchestration` and `system-skill-advisor` names `regenerate-skill-derived.cjs`; leaf manifests name `generate-leaf-manifest.cjs`; `sk-code`/`sk-doc` carry no other metadata kinds. **Classification:** `regenerate`. **Consequence:** the metadata artifacts regenerate from the tree, so their paths follow automatically once the owning generators are retargeted; editing them directly would be overwritten on the next run.

- **Finding 6 — runnable-versus-prose, measured.** Across the four skills, fenced lines total 1,081 against 5,698 inline lines: the majority of path-bearing documentation is prose citation, not executable instruction. `cli-external-orchestration` is the extreme (189 fenced vs 1,028 inline). **Classification:** `mechanical` for both, `freeze` where classed; the distinction matters because a prose citation can often stay a historical label while a fenced command must work. **Consequence:** the per-class tables below give the split per artifact class, so a later phase can decide which prose keeps a historical path.

- **Finding 7 — the code rows here carry the construct, not just the path.** Examples that show the range: permissions-matrix JSON holds `target_glob` values; the advisor fixture holds `sourcePath` literals; `sk-doc` scripts use Python string constants; `sk-code` shell scripts invoke other repo scripts. **Classification:** `mechanical` per file. **Consequence:** no single rewrite pattern covers all of them; the construct column is the input a rewrite script needs.

- **Finding 8 — the counts reconcile exactly with the seed.** `cli-external-orchestration` 556 + 200 = 756; `system-skill-advisor` 168 + 138 = 306; `sk-code` 245 + 37 = 282; `sk-doc` 207 + 73 = 280. Matching lines: 1,654 + 1,358 + 1,217 + 2,852 = 7,081.
