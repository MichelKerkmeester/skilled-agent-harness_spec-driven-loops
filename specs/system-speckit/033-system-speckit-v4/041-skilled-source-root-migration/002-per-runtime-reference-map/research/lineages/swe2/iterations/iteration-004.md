- **Finding:** Two manifest/tree divergences beyond iteration 1: `.cursor/mcp.json` is a **real file** here (manifest claims a `../.mcp.json` symlink) and carries the launcher arg at :6; `.claude/specs`+`.claude/changelog` don't exist though `.claude/SYNC.md` lists them.
