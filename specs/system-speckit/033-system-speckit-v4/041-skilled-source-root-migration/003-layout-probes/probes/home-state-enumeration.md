# Home-state enumeration (Q8)

**Result:** 563 home files name the repository or `.opencode`, and 435 of them name `.opencode`. Of those, 60 are live configuration: files a runtime or git reads to find repository code. The other 503 are history, backups and caches that record past paths, and they need no change. Phase 002's 36-path map missed two live consumers:
- **Codex prompt stubs:** 38 generated stubs in `~/.codex/prompts/`, each naming its source under `.opencode/commands/`.
- **Codex exec rules:** `~/.codex/rules/default.rules`, whose allow rules name `.opencode/skill/...` paths that already no longer exist.

`crontab -l` exits 1 (no crontab), and `~/.config/git/config` is absent.


All results here ran against worktree 055 at base `d26f0c60ca88dab922752ab3d9ce8a07463934ae`.

## Method

Run by the orchestrator on 2026-09-16. `home-scan.py` (copied to `/tmp/skilled-probes-003/logs/home-scan.py`) walked:
- the 36 map-B paths;
- the trees `~/.claude`, `~/.codex`, `~/.pi`, `~/.config`, `~/.hermes` (without its `hermes-agent/` source), `~/.cursor`, `~/.devin`, `~/.local/share/devin`, `~/.local/share/opencode`, `~/.local/state`, `~/.local/bin` and `~/Library/LaunchAgents`;
- `~/.bashrc`, `~/.profile` and `~/.npmrc`.

It searched for the literal patterns `.opencode`, `Code_Environment/Public` and `worktrees/public`. Per file it printed only counts, link targets naming a pattern, and for JSON, TOML, YAML and plist files the key paths whose values match. Session and transcript stores got one aggregate row each, and 51 files above 20 MB were listed without being read. The first run's store exclusion failed, because `rg -g` globs match relative to the search path, so it was stopped and rerun with the search rooted at each tree. The rerun took 399 s and exited 0: 668 rows, 563 matching files, 8 matching links, 28 stores, 51 files not scanned for size. Surface counts come from `rg -o '\.opencode/[A-Za-z0-9_.-]+'`, cut to the segment after `.opencode/`. `~/Library/LaunchAgents` held no match.

## Implications

- Shape A: every live entry keeps resolving through `.opencode -> .skilled`, so nothing breaks at the move. Criterion 6 still requires the git hooks, `hooks.json`, `config.toml`, `config.yaml`, `.zshrc`, `SYNC.md` and the regenerated Codex prompt stubs to name `.skilled/`. The `default.rules` entries are already dead and stay a separate cleanup.
- Shape B: `.opencode/scripts`, `bin`, `hooks`, `skills` and `commands` are all per-entry links, so every live entry resolves as in shape A.
- Shape C: `scripts` and `hooks` are not opencode-mandated. Dropping them breaks the seven global hooks silently (see `dangling-hook-behavior.md`) and four `hooks.json` commands. Dropping `bin` breaks the Hermes MCP launcher, the `.zshrc` PATH entry and nine further hook commands. Phase 010 would have to rewrite those entries before the move, not after.
