## 1. DURABLE DIRECTIVE

**Objective:** Mark archived paths in the JSON record of a path search, keep `suggest-subtracks.mjs` from printing a map the relocate preflight refuses, and make the archive-search and sub-track advisor signals match only the requests they were written for.

### Decisions

Frozen choices. Changing one is an amendment.

| ID | Decision |
|----|----------|
| D1 | The `paths` field of the path record keeps its type. The archived marker is an added field. |
| D2 | The advisor scorer is not changed in this phase. Signals change by wording only, and no signal added or reworded here contains a skill or track name. |
| D3 | `skill-graph.json` and `scorer-eval-baseline.json` are regenerated by their writers after `origin/main` is taken into the branch, never edited or merged by hand, and every number that moves is listed in section 4. The hand-written `local-native-approved-divergences.json` is not edited: a new divergence stops the signal task. |
| D4 | The code and the signals land as two commits. |
| D5 | Every finding is reproduced before its fix, and no code comment names a spec path, a packet number or a finding id. |
