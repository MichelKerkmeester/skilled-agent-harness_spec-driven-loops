9. Decision for the operator (not changed here)
  resolveRepoRoot() prefers the working directory when it holds a specs folder. The containment check therefore measures against that directory in that case. A run started from a directory outside this repository that has its own specs folder can name that folder's root. Using findRepoRoot on the module location instead would close that case, at the cost of refusing roots under a different working checkout.
