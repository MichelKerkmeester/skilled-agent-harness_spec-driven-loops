What was fixed:
  1. Preview copies use verbatimSymlinks: true at all four cpSync calls, and
     the preview root is realpath'd before containment checks, so an in-packet
     relative link is materialized in the preview while a self-referential or
     escaping link is still refused without recursion.
  2. The manifest-secret test now also scans every sidecar under
     upgrade-legacy.before-images/ (regular files) and rejects the secret's
     digest as a sidecar name.
  3. The README restore script rejects '..' and any escaping sidecar name,
     refuses a sidecar directory reached through a symlink, and reads and
     sha256-checks every sidecar before the first write.
  4. prepareManifest prunes sidecar files the manifest it just wrote does not
     reference; referenced sidecars stay as the undo record.
