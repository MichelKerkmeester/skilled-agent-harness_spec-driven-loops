### Deep Loop
- All deep-loop workflows — research, review, improvement, and AI council — now live in a single unified `system-deep-loop` skill, invoked through a router agent renamed to `@deep-loop` (formerly `deep`) so it no longer collides with `/deep:*` commands or `deep-*` agents.
- Research and review loops gained a divergent convergence mode (verified in 10/10-iteration runs), while a 20-iteration self-review of the unified skill caught and fixed 7 runtime bugs.
- New `/deep:alignment` mode audits your docs, code, designs, or git history against a chosen parent skill's own standards and templates, verify-first, with a per-authority known-deviation list to suppress recurring findings.
- Deep-review and AI council are more robust: strategy files with missing headings now self-heal, iteration state appends deterministically instead of crashing, and council output records per-seat execution provenance while rejecting reserved executor collisions up front.
- Benchmarking broadened: `--executor codex` measures models live over the codex transport (measurement-equivalent to opencode, 86 vs 85), `/deep:command-benchmark` audits the command corpus on structural + behavioral axes, and `create-benchmark` now authors a `conformance_benchmark` family.
- Deep-loop runs gained an append-only, tamper-evident event ledger with versioned replay fingerprints and certified phase receipts, plus live-search fan-out with per-executor tool-policy enforcement.
- AI council now persists a durable, sha256-audited write protocol and a SQLite-backed decision graph (`council_graph_*` MCP tools) that replays provenance up to 13x faster than re-reading sources.
- Improvement and model/skill benchmarking converge on an evaluator-first loop with five-dimension holistic scoring (replacing ~15-20% keyword checks), sha256 mutation dedup, and cross-executor config-dir routing.
- Durability is standard across loops — named stop reasons, legal-stop gates, resume cursors, append-only journals, and duplicate finding/mutation dedup — with `/goal` adding persistent per-session goals and strict verifier auto-completion.
- **Breaking:** the unified `system-deep-loop` skill replaces the old `deep-loop-workflows` hub + `deep-loop-runtime` backend; the router agent is now `@deep-loop`; `multi-ai-council` → `deep-ai-council`, `deep-agent-improvement` → `deep-improvement`, and `@improve-agent` → `@deep-agent-improvement`; `/speckit:deep-review` is now a standalone command replacing `/speckit:deep-research:review`; standalone `/deep:context` is deprecated (its capabilities folded into `/deep:research` and `/deep:review`); and the ai-council agent is now subagent-only.
