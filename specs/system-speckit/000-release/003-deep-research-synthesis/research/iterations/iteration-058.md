#### Deep-agent-improvement: renamed from sk-improve-agent
The `sk-improve-agent` skill is now `deep-agent-improvement`, aligning it with its `deep-*` siblings `deep-review` and `deep-research`. Around 116 files were moved to the new folder and every live reference was migrated, including 156 routing entries in the skill advisor, so prompts like "improve agent loop" still resolve to the right skill (verified at 0.878 confidence). The rename is purely symbolic — no behavior changed — and the `@improve-agent` agent plus `/deep:start-agent-improvement-loop` command keep their familiar names because they already followed modern conventions. The advisor's search index was rebuilt, compiled output was regenerated, and changelog entries v1.3.0.0 and v1.4.0.0 document the milestone. **Breaking:** the old `.opencode/skills/sk-improve-agent/` path is gone; anything referencing that literal path must use `deep-agent-improvement`.

#### Deep AI Council extracted into a dedicated skill
The AI Council workflow is now its own `deep-ai-council` skill (renamed from `multi-ai-council`), and the skill advisor routes natural council prompts to it. The skill ships with a reference library covering scoring, depth dispatch, failure handling, anti-patterns, and seat diversity, plus a new derived council graph backed by SQLite that answers provenance and triage queries by replaying existing council artifacts instead of reading raw files. Value-comparison scenarios measure the payoff on every run: 7–13x fewer lookups for triage, provenance, ranking, and discovery, plus a safety case where the graph blocks a premature stop the no-graph flow would have allowed. Operator playbooks and an automated test gate now cover every tool, query mode, and convergence state, backed by a 32-entry feature catalog and fixed-up test suites. **Breaking:** the skill and its agent were renamed to `deep-ai-council`; the old `multi-ai-council` string survives only for reading older records.

#### Deep-* skills: evolution arc and release cleanup
The deep-* skill family went through a coordinated evolution arc that cleaned up and hardened all four members before this release. `deep-review` reached v1.10.0.0 after closing 56 audit findings, reconciling every documentation surface to the same nine-gate legal-stop model (adding the previously omitted coverage and fallback gates), and teaching its status reducer about paused/recovering states, cross-dimension deduplication, and field-level warnings. `deep-research` split its monolithic reference docs into focused hubs for convergence and state and aligned its routing with the platform's resilient-router pattern. `deep-ai-council` shipped to v2.1.1.0 with two new references and 60 new tests for previously untested scripts, and `deep-loop-runtime` reached v1.2.0 with a corrected node-type list and council coverage now present in its feature catalog and playbook. A family-wide sweep also rewrote 63 stale citations to present tense so documentation stops reading as release-scoped. Most of this is internal documentation and test hardening, with user-visible effect mainly as more accurate routing, corrected references, and more reliable status reporting.
