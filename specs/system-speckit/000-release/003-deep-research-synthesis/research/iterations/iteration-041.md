#### Numbered-H2 divider and anchor standard enforced

The doc skill now has a single navigation standard for the fleet: bare numbered H2 headings, `---` dividers between them, and no table of contents or nav-anchor comments. An investigation found the written rules had drifted from what was actually enforced — 1,015 of 3,667 numbered-H2 files were missing at least one divider (2,725 gaps total) and a handful of READMEs still carried TOCs — because nothing checked them on the general path. A census across 8,645 markdown files quantified the drift and revealed a validator-vs-authority conflict, which is now resolved. Validator enforcement was added behind a `SKDOC_ENFORCE_STRUCTURE` flag so the gate can prove each fix, while the separate continuity-anchor system used by spec documents is explicitly preserved as a distinct required contract. Fleet-wide normalization of the remaining files was specified but still awaits operator go-ahead.

#### Canonical sk-doc rename across repository

The documentation-skill namespace was renamed repo-wide to its canonical `sk-doc` identity, and stale claims for a removed visual skill were purged from live documentation. Path migration processed 17 entries and content migration touched 330 files, driven by an ordered rename map with an explicit log-parity check so every move is auditable. A flatten correction fixed nested-directory leftovers the initial move ordering created, and final remnant counts verified zero for every tracked legacy identifier family. The skill advisor now routes a "create documentation" request to `sk-doc` with high confidence, and strict validation passes with all checks marked complete. This is internal tooling with no user-visible behavior change; the payoff is a clean, collision-free namespace plus a full forensic evidence trail.

#### Template folders reorganized by component type

sk-doc template storage moved from a single flat `assets/opencode/` directory into two purpose-grouped locations: `assets/skill/` for skill-creation templates and `assets/agents/` for agent and command templates, with the old directory deleted. All 26 active files referencing the old paths were updated — 21 from the original plan plus 5 more discovered during verification — spanning sk-doc internals, the command system, install guides, agent definitions, and the skill README. A final grep confirmed the 27 remaining references all live in historical or archived files, preserved as documentation of the state at time of writing. The observable effect is internal; the reorganization aligns template storage with the logical grouping of OpenCode component types.
