#### New deep-alignment mode audits against parent-skill standards
A new mode-packet in system-deep-loop turns conformance into an automated loop: `/deep:alignment` audits docs, code, designs, and git history against the standards of named parent skills (sk-doc, sk-git, sk-design, sk-code) instead of eyeballing compliance. It opens with a structured scoping question (artifact class x authority x scope), expands the answer into one lane per selected authority, and reuses the deep-review runtime engine so the audit converges, iterates, and reports like a review — with the loop's `reduce-state.cjs` promoted to the shared runtime to power it. Each authority plugs in behind a `discover/standardSource/check` adapter contract: deterministic checks for sk-git (conventional-commit grammar, `wt/NNNN` branch naming) and sk-doc, a hybrid deterministic-plus-reasoning check for sk-code, and for sk-design both a static audit rubric and a live-render wrapper that consumes caller-supplied render evidence (the design MCP surface has no URL-rendering tool, a disclosed gap). Non-interactive runs take a `--lane-config` JSON file, and the mode is reachable via a `/deep:alignment` command, a `@deep-alignment` agent in both runtimes, and advisor routing wiring, plus a behavior-benchmark extension. In a dogfood pass, its own 83 shipped docs were audited against the very sk-doc bar the mode enforces and brought into conformance — category folders renamed to snake_case and stale "not yet built" claims reconciled.

#### Post-sync verification fixes and deep-review hardening
Internal tooling. While verifying a large 3,801-file sync commit, a syntax sweep came back clean but running the touched vitest suites surfaced 5 real assertion failures across 3 test files, each root-caused individually: two stale test expectations corrected (including dropping a deep-review `.toml` mirror path that never existed anywhere in git history), one test fixture completed to match the reducer's established `gateClass` contract, and a genuine input-validation gap closed in deep-ai-council's `orchestrate-session.cjs` by reusing the repo's `EXECUTOR_KINDS` constant instead of inventing a new list. Wiring deep-ai-council into a real checked-in vitest config expanded the suite from 2 files/12 tests to the full 10 files/94 tests that had never run automatically, surfacing two more pre-existing bugs — `execution_provenance` silently dropped on its way to the persisted record, and `route_fields` missing the `requested`/`effective` identity split — both fixed additively. Two later amendments hardened `/deep:review`: a deterministic stdin-append helper replaced a patch-anchored `append_jsonl` step that had halted runs at claim adjudication, and the reducer now self-heals agent-authored strategy files in numbered or un-numbered heading dialects instead of fail-closing on a missing anchor. No user-facing behavior change; this is verification and reliability work under the hood.

#### Benchmark models live over the codex transport
The skill-benchmark now supports a second live transport: pass `--executor codex` to benchmark a GPT-5.6 model over the codex CLI side by side with the existing opencode transport. A single-shot `codex-dispatch.cjs` helper lives in the deep-loop runtime so the repository keeps exactly one place that spawns `codex exec` — honoring cli-codex's runtime-hosted rule — while a thin `codex-executor.cjs` reuses the opencode path's prompt builder and reply parsers, so both transports ask the identical routing question and parse it identically. Because codex emits no `tool_use` stream, activation is recorded as unmeasured (`null`) rather than as a miss, so codex scores are not depressed on a channel it cannot report. The Tier-1 comparison shows the transports agree within one aggregate point (opencode 86, codex 85), with 7 of 9 scenarios scoring identically and the entire gap a single scenario at N=1. A Tier-2 extension swept three skills with gpt-5.6-luna over opencode — sk-doc failing at 20/100 and sk-code conditional at 65/100 on resource recall — and a SOL-ULTRA deep-review reconciled 12 adjusted recommendations scoped to the fitted-suite caveat, with artifacts and raw reports saved under the packet.
