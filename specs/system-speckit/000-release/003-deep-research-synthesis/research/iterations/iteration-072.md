#### Skill advisor reference docs aligned to frontmatter contract
The 15 reference docs of the skill-advisor skill now all carry the canonical frontmatter contract that drives memory-trigger matching and doc priority. Before this, every doc lacked a `contextType`, eight lacked an `importance_tier`, and the hook operator contract had no trigger phrases at all. The contract reserves `important` for true contract/invariant docs, so the legacy tool bridge was promoted (it states a compatibility invariant) while five operational references (decisions history, reconciliation runbook, query cookbook, tuning guide, validation baselines) were demoted to `normal` to keep the tier meaningful. Trigger phrases were repaired where they were single-token or generic, replacing `lib/skill-graph` and `skill graph database` with distinctive multi-word phrases. This is internal tooling with no direct behavior change, but it sharpens retrieval signal so the right docs surface at the right priority; the coverage check passed with 15/15 docs carrying the detailed block and zero violations.

#### Hardened orchestration: stall detection and dispatch preflight
The skill-advisor hardening phase shipped two reliability changes for the orchestration runtime. Deep-loop runs now default to stall detection on: the lag ceiling went from 0 to 300000ms and the progress heartbeat from 0 to 60s, so a hung run no longer reports success. Any signal-kill that is not a clean SIGTERM is now classified as a loud failure instead of a masked exit-0, with stall and abort events mirrored to stderr. A dispatch preflight linter enforces `hard_rules` frontmatter on the cli-opencode and cli-claude-code skills through a warn-first, fail-open Bash hook, flagging a rule-violating dispatch before the command runs. Both acceptance tests met: 49/49 deep-loop-runtime suites and 6/6 linter tests. Users get honest failure reporting for hung or killed orchestration runs rather than false success.

#### Scorer tuning: default-off seams, root fix, verdicts
The skill-advisor scoring campaign shipped benchmark verdicts plus a set of default-off refinement seams behind feature flags. The RRF fusion cluster benchmarked against the weighted-sum baseline lifts routing top-1 correctness from 37/42 (0.8810) to 38/42 (0.9048) with zero regressions and 0.9762 agreement: the RRF core paired with the conflict-rerank seam graduated, while the self-recommendation guard was cut as redundant with the implicit penalty. The default-off seams cover RRF fusion, lane-health degrade (a degraded-empty lane is now distinguished from one that matched nothing and is excluded from confidence normalization), an embedding-staleness signal that fails the semantic-shadow lane closed on stale vectors, and conflict demotion, query-class weighting, and top-K exact rerank. The workspace-root fix replaced cwd-based resolution with a deterministic module-relative walk-up, so the advisor always writes to the canonical `.advisor-state` path and nine stray nested `.advisor-state` directories were cleaned. The implicit -0.25 self-recommendation penalty is documented with a durable WHY comment and locked by a regression test that fires in the production-default state, including the previously missed `skill-advisor` alias. One correction: the outcome-weighted ranking follow-on's claims of a durable outcome store and re-rank were found to be drift, only a non-functional fold-tick script exists in the tree, so no live ranking change was claimed.
