#### New read-only Refero design-reference MCP transport

The Refero design-reference library is now reachable as a read-only MCP transport, the mcp-tooling hub's second design-research source alongside Figma. Where the framework previously had no Refero access at all, the hub now routes design-reference prompts to an eight-tool surface (search_styles, search_screens, search_flows, get_style, get_similar_screens, get_screen_image, get_screen, get_flow) whose exact callable names were captured live in a dated registry fixture rather than guessed. The transport pairs with the design skill for judgment, forbids file mutations outright, and surfaces plan limits up front (Pro gets 8,000 MCP calls a month; Free has no MCP access). Authentication is a browser OAuth handshake, and the docs honestly mark the authenticated path as unverified until an operator authorizes it; an earlier research dispute over the naming scheme is now resolved as negative knowledge.

#### New read-only Mobbin design-research MCP transport

The Mobbin app-design research library is now reachable as a read-only MCP transport, the hub's third design source after Figma and Refero. Live verification corrected the core assumption behind this addition: research had assumed a single public search tool, but the real registry exposes three (search_screens, search_flows, search_sections), so agents can now run real flow research instead of the one-tool baseline. Flow analysis is the big win: search_flows returns ordered actions, screen counts, and per-screen previews, making returned ordering retrieval fact. Authentication uses OAuth/DCR/PKCE with no API key, and the packet was flipped from "not registered" doctrine to registered-state truth, including a doctor check that now fails if the transport goes missing.

#### Deterministic skill routing with route-gold enforcement

The mcp-tooling hub's routing was rebuilt to be deterministic and testable, fixing a regression where only 6 of 13 hub scenarios reached their intended skill. Deterministic replay now matches 13 of 13 hub intents and 49 of 49 packet scenarios, with the pre-fix state frozen as a regression anchor so every later change is provably isolated. Router fallback behavior is now explicitly "fallback-only": zero-signal prompts defer with a suggestion instead of guessing a tool, and generic design phrases no longer silently privilege one provider. Skill benchmarks gained a hard route-gold gate that fails with exit code 3 when a scenario routes to the wrong intent, catching future regressions automatically. The Figma transport's mutation metadata is now honest and the design-skill pairing is a named precondition on design-affecting operations. This is largely internal framework tooling; the user-visible effect is predictable routing plus benchmarks that block routing regressions.
