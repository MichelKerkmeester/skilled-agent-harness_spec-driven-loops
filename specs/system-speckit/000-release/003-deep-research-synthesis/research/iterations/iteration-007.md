#### New cli-codex skill and simplified cli-gemini model reference
Codex CLI now participates in the same documentation-driven bridge pattern as the other CLI skills: a new `cli-codex` skill package was introduced as a peer to the existing bridge skills, giving framework users a consistent route to send work to Codex CLI from their preferred assistant. At the same time, `cli-gemini` was normalized from multiple model references to a single canonical model reference, removing avoidable model-selection ambiguity from its bridge guidance. Registration surfaces were updated alongside the new skill so discovery stays consistent, and the spec folder itself was later normalized to the current compliance template without altering the original implementation meaning. For a framework user, the CLI bridge family stays uniform as it grows, with one unambiguous model target to follow. The change is additive plus an internal normalization; nothing user-facing was removed or renamed.

#### New cli-claude-code skill with reversed orchestration
External AI assistants — Gemini CLI, Codex CLI, and Copilot — can now delegate work to Claude Code CLI through a new `cli-claude-code` skill, completing the cross-AI trilogy alongside cli-gemini and cli-codex. The orchestration is reversed: the external AI stays the conductor while Claude Code executes, the inverse of the sibling skills where Claude Code conducts. The skill ships an 8-section entry point with intent-based routing across seven signals — defaulting to deep reasoning rather than generic generation — plus four reference files covering CLI flags, nine agent profiles, Claude Code's capabilities against its peers, and integration patterns, alongside ten prompt-template categories. Documented constraints include a nesting guard preventing Claude Code from running inside itself and the explicit absence of a web-search flag. For framework users this extends cross-AI delegation to a third CLI with structured routing and three model tiers (opus/sonnet/haiku) for cost-quality trade-offs.

#### New cli-copilot skill completing the four-CLI ecosystem
Any AI assistant can now delegate tasks to GitHub's Copilot CLI through the new `cli-copilot` skill, completing the four-CLI cross-AI ecosystem alongside cli-gemini, cli-codex, and cli-claude-code. Copilot's distinct value is captured end to end: multi-provider model access across 7+ models from Anthropic, OpenAI, and Google, cloud delegation to GitHub infrastructure, and autonomous autopilot execution. The skill routes on seven intent signals that emphasize planning and cloud delegation in place of deep-reasoning signals, and its capability reference uses a four-way comparison across all four CLIs for the first time. It was also the project's first cross-AI implementation: Gemini CLI generated the skill files from the spec docs, followed by review for structure, AI-agnostic language, and model accuracy. Routing registration was updated in both the Public and Barter repositories. For framework users this closes out a uniform, routing-based bridge across every major CLI assistant.
