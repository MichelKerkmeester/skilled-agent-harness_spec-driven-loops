#### Skill-advisor routing quality program and calibrations

The 065 program established a routing baseline and then fixed everything the stress campaign exposed. A skill reindex advanced advisor generation and restored live freshness, then six scenario prompts were run across copilot/codex/gemini executor slots, finishing PASS=1 WARN=1 FAIL=4; the failures drove five calibration phases. Memory-save routing gained a next-session preservation boost while plain file-save prompts like "save the file I'm working on" were capped so they no longer pass as confident `memory:save` routes. Testing-playbook creation prompts now get a dedicated route instead of falling through to generic `sk-doc`, and explicit alias groups let capability matches score without depending on exact id shapes. Ambiguous "what's wrong with my code" prompts now boost `sk-code-review` with a supporting `sk-deep-review` boost while dampening broad `sk-code`, without stealing clear implementation requests. All changes landed in the native TypeScript scorer, its Python fallback, and matching regression tests. This is internal routing infrastructure, but the visible effect is that the advisor stops misfiring on memory saves, playbook creation, and debugging requests.

#### Ambiguity detection widened to dual-margin OR

The advisor's ambiguity detector now clusters a candidate when EITHER the score gap OR the confidence gap to the top candidate is within 0.05, instead of only the score gap. Before, the documented 0.05 confidence window was ignored, which made a live pair like `sk-code` (0.798/0.929) vs `sk-prompt` (0.720/0.889) score as unambiguous despite nearly tied confidence. Now both axes are honored: score-margin keeps the ranking-alignment invariant while the confidence-margin restores the feature-catalog behavior and closes the SAD-002 gap. All 37 scorer and 40 handler vitest tests pass, including a new SAD-002 regression and updated fixtures that pin both gaps outside their margins. One caveat: Node does not hot-reload, so the running MCP server must be restarted before the fix goes live.

#### Skill graph infrastructure and advisor extraction

Built the graph infrastructure behind the advisor across seven child packets: per-skill `graph-metadata.json` for all 20+ skills, a compiler producing the compiled graph, and graph-derived routing signals (transitive enhances/siblings/depends_on boosts, family affinity, conflict penalties). A later phase shipped the native TypeScript advisor daemon with five-lane fusion scoring, MCP tools, Python and plugin compatibility shims, and promotion gates. A metadata quality audit scored an average 21.6/25, found family-level vocabulary reuse among the `cli-*` and deep-loop skills as the real weakness, and the follow-up fixes sharpened descriptions plus populated `intent_signals` and manual relationships across all 17 skills. The advisor was then extracted into a standalone `system-skill-advisor` package with its own MCP server and launcher registered across runtimes, bridged through a temporary memory-MCP proxy that was later removed. Finally, spec-kit's metadata index moved to `graph-metadata-index.sqlite`, leaving `skill-graph.sqlite` exclusively to the standalone advisor — an internal rename that keeps the `skill_graph_*` tools and their MCP ids unchanged, so no configuration migration is needed for tool consumers.
