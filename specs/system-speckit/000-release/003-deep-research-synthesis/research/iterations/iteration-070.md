#### Skill-advisor documentation aligned, drift fixed, decoupled

The skill-advisor package's documentation was brought into line with its shipped code and configuration across a multi-part wave. Hook invocation is now documented as the primary path, with the direct Python CLI kept as a documented fallback; a new hook-surface catalog category with 12 entries and six hook-routing smoke scenarios were added, and two fixture-folder READMEs plus TOC anchors in five existing ones closed the sk-doc coverage gap. A config-drift fix restored a clean build by correcting an invalid TypeScript deprecation option, and reconciled the tool count — "8 public + 1 internal trusted-caller" — across SKILL.md, ARCHITECTURE.md, README.md and the opencode.json registration comment. A documentation-quality refactor then closed the deferred backlog: 943 Oxford-comma instances cleared package-wide, a context-aware semicolon sweep cut 137 instances to 30, four new reference guides (query cookbook, validation baselines, daemon lease contract, skill-graph drift) were added, a catalog/playbook cross-reference table landed, and the old hook READMEs got deprecation banners with a 90-day window. Finally, cross-skill documentation was decoupled: the spec-kit README and ARCHITECTURE no longer describe sibling skills, and all three ARCHITECTURE files now share one 8-section template with table-free, prose-first opening sections.

#### Playbook run surfaced and fixed routing regressions

A full 46-scenario manual-testing run across the skill-advisor surfaces — native MCP tools, CLI hooks, Python/daemon, scorer, indexing and lifecycle — was executed with CLI delegation (Devin SWE-1.6 in an isolated worktree, OpenCode DeepSeek) and recorded verdicts of 21 PASS, 10 PARTIAL, 2 FAIL, 13 SKIP. The run did what a test pass should: it surfaced a real corpus-accuracy regression (advisor_validate reporting 50.78% against a documented 80.5% baseline, confirmed by three independent harnesses) plus two failing Python-suite scenarios. Remediation restored accuracy with no scorer change — alias-aware gold matching lifted the reported figure to 74.09%/65.0% — and made both regression harnesses resolve old skill aliases (sk-deep-* to live deep-* IDs) without touching ground-truth fixtures. Scorer routing fixes landed in both the TypeScript and Python implementations: explicit slash-command routes now hit their owning skill, code-mode prompts disambiguate, and low-information ambiguous prompts abstain; a five-class P1 tuning pass then took both harnesses to zero failures across all 50 cases. Docs and gates were corrected alongside: the bench scenario now documents its required --dataset flag with recalibrated p95 gates, the OpenCode plugin bridge gained a verified native compat route (a cold-environment residual remains flagged), and stale vitest paths plus the semantic-shadow attribution docs were synced to the live lane. The run's "release NOT READY" verdict was resolved by the remediation phase.

#### Pluggable embedder stack, spec-memory parity, zombie fix

Skill-advisor gained a pluggable embedder architecture, ending its status as the only system in the repo still hardwired to the gemma model. A new embedder layer provides a registry of six manifests — jina-embeddings-v3 as default, nomic-embed-text-v1.5, embeddinggemma-300m, jina-embeddings-v2-base-code, mxbai-embed-large-v1, and bge-m3 — plus vector-table migrations and a reindex dispatcher that writes per-skill vectors through the active adapter while keeping the legacy gemma path as fallback. The shared embedder logic was aligned with mk-spec-memory: an 'auto' sentinel with a content-type-aware provider cascade, provider persistence, a cross-server database-path leakage fix, and an ONNX shutdown-crash mitigation; INSTALL_GUIDE §12 and a README subsection document the choices, with the actual swap still operator-driven via setActiveEmbedder(). A launcher fix closed a zombie-process regression by adding the missing pre-spawn PID guard that had let duplicate launchers survive while only one daemon writer stayed active. Confidence and uncertainty thresholds were consolidated to a single compat-contract source, and interface/environment work closed the remaining audit findings — all internal plumbing with no user-facing CLI surface. The active default remains gemma until an operator executes the documented swap runbook.
