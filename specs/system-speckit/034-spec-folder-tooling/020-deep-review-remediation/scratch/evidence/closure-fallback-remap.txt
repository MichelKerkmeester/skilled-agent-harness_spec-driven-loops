Definition, unchanged from closure-fallback-map.txt. A fallback is a path the code takes when its primary resolution is absent or fails. A fallback case is adversarial when a link or a dangling target sits on that fallback path and the test asserts that nothing is written through it. A parity case with no link is not adversarial.
