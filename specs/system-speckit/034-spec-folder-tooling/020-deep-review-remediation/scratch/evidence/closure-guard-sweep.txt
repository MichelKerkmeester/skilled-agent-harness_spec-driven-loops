CLOSURE GUARD SWEEP: mutation check of the changed guards named in closure-guard-red-map.txt

Scope. Guards with no recorded failing mutant in the red map: backfill prune report
writer (K-a, K-b1, K-b2), the upgrade baseline link guard (O-1 to O-4), the archive
destination and restore checks (A-arch-L, A-rest-L, A-arch-e, A-rest-e), and the
heal-spec-docs link guards (H-doc, H-lane-a, H-lane-b, report only).

Method. Each mutant is one exact-match replacement in a scratch copy of the skill tree
(scratch/gs/mirrors/<name>), built by scratch/gs/mkmirror.mjs. The copy holds real
files, so relative imports from the copied test files resolve to the mutant. Nothing
under the repository was mutated. Each mutant is run with the EXISTING test files of
that guard; a test file copied into a mirror is the repository's current copy at build
time. A red run is a run whose failing set includes a test that passes on the
repository code. Mutant specs are scratch/gs/mut/*.mjs; logs are scratch/gs/mut/<name>.log.

Mirror caveat. In every scratch mirror, four cases in archive-track.vitest.ts (describe
"archive.sh round trip with the real tools") fail with the unmutated skill too. They pass
in the repository. Each archive mutant was therefore judged by its failing set against
the unmutated mirror (scratch/gs/mut/control-cli-2.txt): a mutant counts as killed only
when a failing case outside those four appears.
