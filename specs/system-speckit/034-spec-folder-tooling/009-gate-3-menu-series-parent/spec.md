<!-- ANCHOR:problem -->
## 2. PROBLEM & PURPOSE

### Problem Statement
The menu text in `spec-gate-core.mjs` offers "C) Use a related spec folder, including a phase child" with no series parent, and the Pi dialog says only "Use a related folder or phase child". An agent answering the menu never sees the rule, so it picks B and opens another singleton packet.

### Purpose
The menu itself steers a different change to the same artifact toward option C.
<!-- /ANCHOR:problem -->
