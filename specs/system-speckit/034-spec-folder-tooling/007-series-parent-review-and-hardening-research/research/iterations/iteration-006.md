## Findings

**f-iter006-001 — Seeding is doubly silent: a one-line marker gate decides whether the function runs at all, and the write step requires the full four-line placeholder block byte for byte.** The gate is a fixed-string grep for the first placeholder only (`grep -qF '  - "feature specification"'; return 0` on miss) [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/spec/create.sh:401]; the writer is a perl substitution whose left side is the exact newline-joined four-line block [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/spec/create.sh:420]. So a partially customized block — any one of the four lines edited, reindented, or split — either fails the gate (nothing runs) or passes it and matches nothing (perl exits 0, file unchanged). Both paths print nothing, and the failure is invisible downstream: the surviving placeholders are only ever reported as `template-default` warnings, never as failures [SOURCE: specs/system-speckit/034-spec-folder-tooling/006-series-parent-rule-and-sibling-listing/implementation-summary.md:112]. The function is called on all four creation paths (normal [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/spec/create.sh:1816], phase-one children [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/spec/create.sh:823], the phase loop [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/spec/create.sh:1610], versioned sub-folder [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/spec/create.sh:1028]). Fix direction: emit a one-line stderr note on both no-op paths and replace the two exact-string dependencies with per-line matching confined to judge-classed placeholders.

**f-iter006-002 — Non-English descriptions are dropped by construction, and default phase-child scaffolds seed "phase N" phrases that pass every quality gate.** The description channel maps every non-alphanumeric byte to a space before the 8-token cut (`tr -c 'a-z0-9' ' '`), so a description written in a non-Latin script yields an empty description phrase and the fallback silently seeds the slug phrase alone [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/spec/create.sh:407] [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/spec/create.sh:411]. The slug phrase itself stays ASCII because `slugify_token` strips non-ASCII to hyphens before the folder name exists [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/spec/create.sh:379]. Phase children are the sharper case: the phase loop seeds the folder leaf and `"Phase ${_phase_number}: ${_child_folder}"` [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/spec/create.sh:1610], so the default `001-phase-1` scaffold seeds `"phase 1"` and `"phase 1 phase 1"` — 2–4 tokens, not stop-word-only, not numeric-only, no sentence punctuation, therefore admissible under every judge class [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/retrieval/lib/phrase-judge.mjs:89] [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/retrieval/lib/phrase-judge.mjs:131]. The sanitizer does carry a `phase \d+` suspicious-prefix rule [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/lib/trigger-phrase-sanitizer.ts:47], but no consumer sits on the creation path: its production callers are the memory pipeline and the residual migration [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/core/post-save-review.ts:438] [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/continuity/migrate-trigger-phrase-residual.ts:459], and the index reads phrases straight from frontmatter [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/retrieval/generate-trigger-index.mjs:5]. Consequence: default phase scaffolds ship two generics that can never match a topic prompt — the exact shape `template-default` exists to catch, under names no class catches.

**f-iter006-003 — The template-default class is robust to case and separators but blind to concatenations, and every judgement it can make is warning-only.** Membership is a frozen four-phrase set tested after normalization [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/retrieval/lib/phrase-judge.mjs:89], and normalization maps non-alphanumeric separators to spaces [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/retrieval/lib/normalize.mjs:31], so case, hyphen and trailing-punctuation variants of the four placeholders collapse onto the set; sentence punctuation is a separate class [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/retrieval/lib/phrase-judge.mjs:112]. What escapes: concatenated variants ("feature specification and problem statement" is five tokens and passes every class), and non-English phrases, which normalize to nothing and are rejected under the misleading class `generic-workflow-word` rather than as empty [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/retrieval/lib/phrase-judge.mjs:78]. Very short descriptions have no value floor: a one-token phrase lands in `single-token` or `folder-token-fallback` (warnings only), and a two-token generic phrase passes everything [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/retrieval/lib/phrase-judge.mjs:124]. None of these judgements fails a run — `template-default` "warn[s] without failing" [SOURCE: specs/system-speckit/034-spec-folder-tooling/006-series-parent-rule-and-sibling-listing/implementation-summary.md:112].

**f-iter006-004 — No backfill executor exists for spec-packet trigger phrases; the safe path is an opt-in, dry-run-first tool that clones the memory residual-migration contract, followed by a derived/index refresh.** The only phrase-corpus migrator is scoped to memory files: its default scan roots are the repo's memory tree and the global auto-memory directory [SOURCE: .skilled/skills/system-spec-kit/runtime/cli/continuity/migrate-trigger-phrase-residual.ts:130], and spec packets are excluded by its allowed-target helpers.
