<!-- ANCHOR:problem -->
## 2. PROBLEM & PURPOSE

### Problem Statement
Child 015 said the README's reader table was generated from the code, but no generator existed in the tree: the table was hand-written from a one-off scan, and its text-helpers row named consumers that do not import the helpers. Two exports had no importer outside their own tests. The validator declared a `ParsedFrontmatter` interface with a different shape from the package's exported one and the orchestrator imports both modules. A comment claimed a re-export that a round-two fix had removed. The parity workflow built the package for a checker that imports a checked-in source file, while the mirror job ran scripts that require the package with no install. Two helper modules were tested only from the runtime.

### Purpose
A claim that a table is generated is backed by the generator, a check and a test; the package exports what something imports; CI does what its comments say.
<!-- /ANCHOR:problem -->
