- Do not delete, move, rename, refactor, or repair audited files.
- Do not report findings under `.opencode/specs/`.
- Do not treat third-party dependency contents as findings unless a stray dependency tree is committed in a source surface.
- Do not infer deadness from import graphs alone; dynamic string and documentation contracts count as reachability.

## 5. Stop Conditions

- Complete all ten iterations unless state corruption prevents valid lineage artifacts.
