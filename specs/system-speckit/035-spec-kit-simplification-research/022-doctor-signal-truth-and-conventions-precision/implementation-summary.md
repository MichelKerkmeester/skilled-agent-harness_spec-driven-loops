## What Was Built

The retrieval lane's third round, the one lane that finished on GLM 5.3 Flash max, audited the doctor retrieval target signal by signal and found it declared nine staleness signals while computing six. No activity produced a fresh manifest, so that signal is gone; the four-way compare of the committed artifacts, which is real, stays as the pair-mismatch signal. The ambient-config signal now has its second, flagless recipe run; the lookup pass policy that named a frozen prompt set now has an activity that runs every prompt in it; the anchor-drift signal is counted on the five sampled packets; the mtime cross-reference names the node read of the index's own path list, because a find over the recipe roots would count lineages and fixtures the index excludes; and a missing fixture has a named status. The route's recipe gained the two flags section 2.2 lists.

### Conventions with the judge's numbers

The conventions said the two lanes share no mechanism while their own section 5 names the shared helpers; the sentence now says which mechanism they do not share. One loss was booked in two rows; it is one row. The warn-on list named the classes in prose; it now names the seven the judge reports, with the 10-token prose budget, the 37-word stop list and the 120-character oversize variant, and the doctor's pollution row lists the same seven. One allowlist reason described an engine tree that no longer exists, the README called the residue sweep a one-shot check and said nothing about where the Gate 1 instruction lives; both are corrected. The extension guide and sk-doc's catalog examples, where authors learn to write trigger phrases, each point at section 8.

### Rows that did not reproduce

The `barter/` allowlist row names an entry that does not exist. The nodeterm block in `.codex/AGENTS.md` that hard-codes a workstation path is generated by an external tool between its own markers and is recorded, not edited.

<!-- ANCHOR:decisions -->
## Key Decisions

| Decision | Why |
|----------|-----|
| Remove the fresh-manifest signal rather than implement it | A fresh manifest needs a corpus walk the doctor's philosophy forbids; the committed four-way compare is the honest signal |
| Add activities for the other kept signals | Each costs one read or one lookup and turns a promise into a measurement |
| Put the judge's numbers in the conventions | A threshold a reader cannot see is a rule they cannot apply |
| Record the nodeterm block | It is generated between its own markers; an edit would not survive |
