**Objective:** Close every confirmed finding from the retrieval lane's third round so that the doctor asset declares only the signals it computes and computes the ones it declares, its recipe matches the convention, and the conventions carry the judge's real classes and thresholds, with nothing deferred.

### Decisions

Frozen choices. Changing one is an amendment.

| ID | Decision |
|----|----------|
| D1 | A declared signal with no possible activity is removed; a declared signal worth keeping gains the activity that produces it |
| D2 | Convention text carries the code's numbers and class names, never a paraphrase |
| D3 | A block generated by an external tool between its own markers is recorded, not edited |
| D4 | The root AGENTS.md is the single Gate 1 surface; no runtime file gets a copy |

### Operator copy

The operator holds this directive as the session objective, and that copy is
what judges completion, not this file. Whenever anything above the log changes
(objective, a decision, the binding table, a criterion), resend the full text
of this file in chat so the operator can update their copy. A child goal change
that alters a parent decision or criterion is an amendment to the parent: apply
it there first, then resend the parent.
