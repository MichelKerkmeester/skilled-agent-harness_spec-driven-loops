D2 FIX
------
upgrade-legacy.mjs
- saveBeforeImage copies one dirty file into its own sidecar beside the
  manifest in 1 MiB chunks, hashing the same bytes in the same pass, and names
  the sidecar <sha256>.bin under <git-dir>/upgrade-legacy.before-images/.
- beforeImagesFor stores, for each file image:
    { "path": "<repo-relative>",
      "beforeImage": { "kind": "file-bytes",
                       "sidecar": "upgrade-legacy.before-images/<sha256>.bin",
                       "sha256": "<hex>", "mode": 420 } }
  No "content" and no "encoding" key is written. absent and symlink-target
  entries are unchanged.
- prepareManifest creates the sidecar directory (mode 0o700) before saving.
- schema stays 1; readManifestIfExists does not inspect beforeImages, so old
  and new manifests are read alike.

Example entry, exactly the shape the new tests assert (values illustrative):
  {
    "path": "specs/bulk-dirty/001-packet/payload-3.bin",
    "beforeImage": {
      "kind": "file-bytes",
      "sidecar": "upgrade-legacy.before-images/6f1c...e2.bin",
      "sha256": "6f1c...e2",
      "mode": 420
    }
  }

README.md (the restore script and its docs)
- The script reads sidecar paths relative to the manifest file, refuses a path
  that escapes the manifest directory or is a symbolic link, checks sha256
  before writing, and still restores a manifest that inlines base64 "content".
- Docs describe the sidecar entry, the digest refusal, and remove the sidecar
  directory when the manifest is deliberately discarded.
