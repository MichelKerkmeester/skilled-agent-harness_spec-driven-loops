## Questions Answered

- **Q7:** Which UX changes across Gate 3 wording, the speckit commands and create.sh output would make grouping the default choice while keeping the operator in control? — Answered as a three-surface change set with explicit pre-condition handling. Verdict: "default" cannot mean pre-selection (the never-select guardrail at quick-reference §9 and the stable-label rule at AGENTS.md already forbid it) and cannot mean dynamic text inside the byte-pinned Gate 3 constant (f-iter003-002); it means one canonical C sentence byte-identical across AGENTS.md, both runtime constants and quick-reference §9, B gated to new/unrelated in the runtime copy as it already is in prose, a ranked related-packet proposal at plan intake delivered through the presentation assets, and a match-aware, structured create.sh listing whose silent paths are closed first by the iter-2 shortlist (items 3, 4, 6, gated by 1, 2, 5, 7 for trustworthiness). The byte-pinning constraint converts the wording fix into a single coordinated change-set requirement (constants + frozen baseline + hash fixtures), and the drift finding is sharpened rather than superseded: the human-facing runtime menu is the weakest of three diverging surfaces.
