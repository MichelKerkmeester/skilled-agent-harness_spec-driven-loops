Question: on which axes were the path lanes tested, and for each row, which test file and case name covers it.
Axes: target kind (plain, link inside, link outside, dangling link, dot segment, linked parent dir,
linked folder argument, linked output file) x mode (dry run, apply) x tool.

Method. No test was run here, so a COVERED row means a case with that target kind and mode exists in the
suite, not that it passes. The suite run is T029, outside this file.
  1. Every link setup in each suite is enumerated (rg of symlinkSync, ln -s, symlink() with line numbers).
     Heal suites create links through a helper (linkedPacket), so its calls are enumerated too.
  2. Each link setup is mapped to its enclosing case by scratchpad/classify.awk (outside the repository).
     The case starts at the nearest it, it.each, test, describe or function test line.
     A run call inside a link case is labelled APPLY when its own line carries the apply marker, otherwise DRY.
     The label reads the call's line only: a multi-line call is not labelled from later lines, so each label
     below was checked against the source line it names.
     In the leaf suite the APPLY marker is runWrite (the write path); a DRY label there is a read or a
     generate-without-write call. In the backfill suite the call is a write-path function, not the CLI, and
     carries no mode marker.
  3. Each COVERED row is backed by an rg -F receipt of its case name. A missing name prints nothing and exits 1.
  4. Each MISSING row is backed by a search over its file and, where the search could have matched, a positive
     control: the same search on a place where the pattern is known to match.

5. THE MATRIX
==================================================================
Format: ID | axis | mode | STATUS | test file | case name, or the section above that shows the gap.
COVERED = a case with that axis and mode exists and its name is receipted in section 3.
PARTIAL = a case covers some modes or some targets of the axis, and the gap is named.
MISSING = no case; the search or enumeration in section 4 (or section 1) is the evidence.
Mode words: apply = --apply on the run (or the write function); dry = run without --apply; read = read path; plan = layout planner.
The archive tool has no mode flag; its rows are apply, except the list row.
