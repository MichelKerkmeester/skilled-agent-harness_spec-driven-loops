## 1. SUMMARY

### Technical Context

| Aspect | Value |
|--------|-------|
| **Language/Stack** | Bash (bash 3.2-compatible, `set -euo pipefail`) |
| **Framework** | None — single CLI script |
| **Storage** | None |
| **Testing** | Manual shell verification (`bash -n`, `diff`, `wc -l`, `rg`); regression via `tests/test-phase-system.js` and `tests/test-phase-validation.js` |

### Overview
The change adds one `QUIET_OUTPUT` global, one `--quiet|-q` case to the option parser, and one early branch in the output dispatch that prints `Recommended Level: N (Name)` before the text/JSON selection. Scoring, level determination, and every existing output path run unchanged, which keeps the default report byte-identical.

## L3: ARCHITECTURE DECISION RECORD

### ADR-001: Quiet prints the existing `Recommended Level: N (Name)` line

**Status**: Accepted

**Context**: `--quiet` must print the recommended level in a form callers can parse. The text report already emits exactly that line.

**Decision**: The quiet branch echoes `Recommended Level: ${RECOMMENDED_LEVEL} (${LEVEL_NAME})`, the identical label `output_text` uses.

**Consequences**:
- One label serves humans and machines; REQ-001's regex pins it
- A label change would now break quiet callers too — mitigated by the pinned regex

**Alternatives Rejected**:
- Bare digit (`2`): loses the level name and diverges from the label a caller may already match
- `level=2` key=value form: invents a second contract where one already exists

---

### ADR-002: `--quiet` takes precedence over `--json`

**Status**: Accepted

**Context**: `--quiet --json` is ambiguous — quiet promises one line, JSON promises a parseable document.

**Decision**: When `QUIET_OUTPUT` is true, the script prints the single text line regardless of `JSON_OUTPUT`.

**Consequences**:
- Quiet's contract stays absolute: exactly one line, always
- A JSON-expecting caller that adds `--quiet` gets non-JSON — mitigated by documenting the rule in help; no current caller passes both flags

**Alternatives Rejected**:
- Minimal JSON `{"recommended_level": N}`: a third output format for no current caller; the strict JSON tests parse the full document anyway
- Rejecting the combination with an error: breaks normal flag composability for no safety gain
