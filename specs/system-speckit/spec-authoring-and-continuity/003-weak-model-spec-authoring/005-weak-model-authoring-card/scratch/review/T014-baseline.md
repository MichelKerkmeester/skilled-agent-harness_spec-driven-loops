# Card bench baseline

- strict_passed: `1` when strict validation printed `RESULT: PASSED`, `0` otherwise.
- leftover_tokens: count of unfilled `YOUR_VALUE_HERE` tokens in the four documents.
- missing_anchors: anchors missing from the packet against `anchors-level1.txt`.
- out_of_scope_writes: changed paths outside the bench track and this phase.
- seconds: wall-clock seconds for the run.

## Range
strict_passed 1 to 1
leftover_tokens 0 to 0
missing_anchors 0 to 0
out_of_scope_writes 0 to 0
seconds 143 to 266
