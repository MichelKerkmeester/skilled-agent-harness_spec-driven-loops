## What Was Built

Research and review fan-out now refuses a matrix that expands to one lineage unless the caller explicitly opts in. The refusal points to the matching single-executor workflow before fan-out side effects begin.

### Phase 3: refuse-single-lineage-fanout-run

The guard keeps a one-lineage matrix from silently running every iteration in one process. Intentional direct callers can retain that behavior with the registered `--allow-single-lineage` flag. The flag is wired through the known unit, stress, timestamp-window and runbook callers.
