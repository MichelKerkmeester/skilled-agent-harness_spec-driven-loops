## 2. PROBLEM & PURPOSE

### Problem Statement
Studies 1–3 (agent-swarms, graphene-main, graph-arch) built and hardened the graph-based deep-loop design from executable code. `graph-engineering-master` is the fourth and final reference — but it is DOCUMENTARY (a teaching/skill package with no runnable implementation). ### Purpose
Produce a research foundation (`research/research.md`) that extracts the canonical knowledge-graph + task-graph doctrine, tests whether the studies-1–3 design already covers it (framed as confirm/refine/extend/contradict), fills the one real gap with a knowledge/evidence-plane production methodology, and states an honest program completeness verdict.
