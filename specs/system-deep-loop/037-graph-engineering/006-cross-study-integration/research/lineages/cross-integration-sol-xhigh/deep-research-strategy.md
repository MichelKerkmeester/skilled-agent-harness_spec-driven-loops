# Deep Research Strategy — Cross-Study Integration

## 1. Overview

This lineage integrates the five completed graph-engineering syntheses. It does not reopen their internal research. Every round starts from `orientation.md`, must connect at least two studies, and treats convergence before iteration 10 as telemetry.

## 2. Topic

Design a graph-based agent-loop engine whose planning, scheduling, harness, memory, knowledge, belief, governance, and evaluation layers remain subordinate to the designated authority plane in packet 036. Describe both the current dark mode and the target authoritative mode.

## 3. Key Questions

- [x] P1 — What single authority-subordination contract joins graph admission, harness validation, belief/convergence, legacy authority, and dark 036? Answered in iteration 1.
- [x] P2 — What conjunctive promotion-evidence model prevents one green evidence family from masking another? Answered in iteration 2.
- [x] P3 — How do memory, knowledge, and belief remain non-colliding while supporting read-through and never-forget classes? Answered in iteration 3.
- [x] P4 — Which assumed 036 primitives are present, shadow-only, missing, or adapter-owned, and what is the minimum cutover-critical build? Answered in iteration 4.
- [x] P5 — Where is the graph/subgraph/LEAF execution boundary, including sealed recursion and a closed action/escalation vocabulary? Answered in iteration 5.
- [x] P6 — What typed state machine joins return admission, evidence, belief, convergence, ASK, human approval, and 036 authorization? Answered in iteration 6.
- [x] P7 — What dependency DAG reconciles all five rollout models while preserving rollback assets and retained legacy readers/writers? Answered in iteration 7.
- [x] P8 — What measurements and owner-disagreement arbitration close the design? Answered in iteration 8.

## 4. Non-Goals

- Re-derive any one study's internal contracts.
- Claim that 036 is live merely because dark primitives exist.
- Implement production runtime code or mutate any parent packet.
- Collapse shape validity, evidence sufficiency, policy approval, and transition authorization into a generic `validated` flag.

## 5. Stop Conditions

- Execute exactly 10 iterations; stop reason must be `maxIterationsReached`.
- Convergence below 0.05 broadens the next review angle and never permits early synthesis.
- Synthesis begins only after P1–P8 plus a cross-angle contradiction audit and capstone closure audit.

## 6. Answered Questions

- P1 — Upstream layers emit typed candidate evidence; only legacy (current mode) or 036 authorize-and-append (target mode) mutates authority.
- P2 — Promotion requires six independent families D/C/G/H/R/M; the earliest causal owner owns remediation.
- P3 — Memory locates, knowledge asserts, belief settles usability; read-through is digest-closed and fail-closed.
- P4 — Reuse present 036 ledger/control primitives; build six graph adapters/producers; keep authority dark until measured evidence closes.
- P5 — LEAF tactics use six actions and five escalations; sealed subgraphs only narrow authority and conserve budget.
- P6 — Seven typed stages preserve owner/reason and terminate in shadow record or 036 append, never a generic validation flag.
- P7 — A thirteen-node DAG merges all rollout plans, permits one constrained parallel wave, and binds rollback assets at every stage.
- P8 — Seven metric families use explicit denominators; owner conflict is jurisdictional, restrictive, recorded, and fail-closed.
