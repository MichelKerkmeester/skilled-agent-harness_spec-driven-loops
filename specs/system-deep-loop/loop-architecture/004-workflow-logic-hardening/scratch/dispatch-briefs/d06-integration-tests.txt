=== THE --stop-decision MODE OF convergence.cjs (input reading rules) ===

New flags (the parser turns `--config-path` into `configPath`):
  --stop-decision                  boolean switch. Without it the script behaves exactly as today.
  --config-path <file>             REQUIRED with --stop-decision. Loop config JSON.
  --state-log <file>               REQUIRED with --stop-decision. JSON-lines state log.
  --registry-path <file>           optional. Findings registry JSON. Missing file = {}.
  --iteration-count <n>            optional. Default: number of distinct iteration records.
  --stuck-count <n>                optional. Default 0.
  --security-sensitive-fix-scope <true|false>   review only, default false.
  --fix-replay-required-rows <n>   review only, default 0.
  --fix-replay-passing-rows <n>    review only, default 0.

Errors (all through the existing `inputError`, so the script exits 3 with {"status":"error"}):
  --stop-decision with a loop type other than research or review;
  --config-path or --state-log missing, or naming a file that does not exist or is not JSON.

Output: the normal payload plus one extra top-level key `stop_decision`, which is
`buildStopDecision(input)`. Both existing output paths get it: the empty-graph early return
(graphDecision is then 'CONTINUE') and the normal path.

Graph failure rule: with --stop-decision, an error thrown while opening or evaluating the
graph that is NOT an input error (err.code !== 'INPUT_VALIDATION') must not fail the script.
The script then prints {"status":"ok","data":null,"graph_decision":null,"graph_error":"<message>",
"stop_decision":{...}} with graphDecision null, and exits 0. Without --stop-decision the
existing error behavior is unchanged (the tests around DEEP_LOOP_TEST_FAULT still pass).

Building the input object:
  loopType           the --loop-type value.
  config.maxIterations        config.maxIterations (number), else Infinity is NOT allowed: use null.
  config.minIterations        config.minIterations, else config.antiConvergence.minIterations, else 0;
                              never above maxIterations.
  config.convergenceThreshold config.convergenceThreshold (number) else null.
  config.stopPolicy           config.stopPolicy when it is 'convergence' or 'max-iterations', else 'convergence'.
  config.stuckThreshold       config.stuckThreshold (number), else 3 for research and 2 for review.
  config.convergenceMode      the value the existing `readConvergenceModeConfig(args)` resolves when the
                              --convergence-mode flag is given, else config.antiConvergence.convergenceMode,
                              else 'default'.
  State log: one JSON object per line. Skip blank and unparsable lines.
    iteration records = rows with type === 'iteration'. The iteration number is `iteration`, else `run`.
    When two rows share a number keep the later one. Order by number ascending.
    evidence records = iteration records whose status is not 'thought'.
  ratios             research: `newInfoRatio` of each evidence record. review: `newFindingsRatio`.
                     Skip records where it is not a finite number.
  iterationCount     --iteration-count, else the number of iteration records.
  stuckCount         --stuck-count, else 0.
  graphDecision      the graph decision ('STOP_ALLOWED' | 'STOP_BLOCKED' | 'CONTINUE'), null on graph failure.
  graphBlockers      the graph blockers array, [] when none.
  research (null for review):
    answeredCount    registry.metrics.resolvedQuestions (number), else registry.resolvedQuestions.length, else 0.
    totalQuestions   answeredCount + (registry.metrics.openQuestions (number), else registry.openQuestions.length, else 0).
    iterationRecords evidence records mapped to { answeredQuestions, keyQuestions } (copy the field only when it is an array).
    answeredQuestionSourceCounts
                     null when the graph has no QUESTION node that is the target of an ANSWERS edge, or on graph failure.
                     Otherwise an object keyed by the question node's id: for each QUESTION node that is the
                     target of at least one ANSWERS edge, the number of distinct SOURCE nodes cited (CITES edge,
                     finding -> source) by the FINDING nodes that ANSWER it. Keys sorted alphabetically.
  review (null for research):
    totalDimensions / missingDimensions
                     dimensions = config.reviewDimensions (array), else the keys of registry.dimensionCoverage.
                     missing = the dimensions whose registry.dimensionCoverage[name] is not true.
    coverageAge      walk the evidence records in order, accumulating each record's `dimensions` array.
                     Find the first record after which every dimension is covered. coverageAge = the number
                     of evidence records AFTER that one. 0 when coverage is never complete.
    traceabilityCovered
                     true when registry.traceability.summary.gatingFailures is 0 (or the summary is absent
                     and config.crossReference.core is empty or absent) AND every id in
                     config.crossReference.core has an entry in registry.traceability.results whose
                     `protocolId` equals it and whose `status` (lowercased) is not '', 'pending',
                     'deferred' or 'skipped'. Otherwise false.
    activeP0, activeP1   registry.findingsBySeverity.P0 / .P1 (numbers), else 0.
    evidenceBackedP0P1   count of registry.openFindings entries with severity 'P0' or 'P1' whose `file`
                         and `line` are both non-null.
    hotspotSaturated     true/false = the `passed` value of the graph trace entry with signal
                         'hotspotSaturation'; null when the graph is empty or failed.
    lastClaimAdjudicationPassed
                     the `passed` value of the LAST state-log row with type 'event' and event
                     'claim_adjudication' when it is a boolean, else null.
    securitySensitiveFixScope, fixReplayRequiredRows, fixReplayPassingRows   from the three flags.
    reviewDepthSchemaVersion, reviewDepthApplicability   from the last iteration record, else null.
    searchDebt           registry.searchDebt (array) else [].
    candidateCovered     registry.candidateCoverage.covered (array) else [].
    requiredBugClasses   registry.searchCoverage.requiredBugClasses (array) else [].
    graphCoverageMode    registry.searchCoverage.graphCoverageMode (string) else null.
    fallbackCoveredBugClasses
                     distinct `bugClass` values of `searchLedger` rows, across all iteration records, that
                     have a non-empty `evidenceRefs` array and at least one `searchActions[].method` in
                     direct_read, exact_grep, semantic_search, producer_consumer_trace,
                     negative_test_inspection. Sorted alphabetically.
