## 3. ARCHITECTURE

### Pattern
Say what the gate checks: the runner already fails closed, so the leaf is told exactly what it will be held to.

### Key Components
- **Lineage prompt** in `buildLoopPrompt`: verbatim-path sentence always; stop-reason sentence under `max-iterations`.
- **Agent contract** Write Safety rules: the same two duties.
- **Determinism tests**: child vitest resolved from the runtime's own `node_modules`.

### Data Flow
Runner composes prompt → leaf writes under the given directory and records the stop reason → runner's containment and stop-policy checks pass.
