## F2 — Shared Gateway Identity Is Not Default-Deny

The shared gateway's public option contract calls `identityResolver` optional and explicitly says fields that are not pinned, including all fields when no resolver exists, are stored with `..._verified: false` (`.opencode/skills/system-deep-loop/runtime/lib/authorized-ledger/authorized-ledger-types.ts:319-352`). The evaluator calls `#checkIdentity` only when a resolver exists (`.opencode/skills/system-deep-loop/runtime/lib/authorized-ledger/transition-authorization-gateway.ts:747-751`). `#checkIdentity` returns no denial for a missing resolver, a null result, or an omitted field; it only denies a field that is present and mismatched (`.opencode/skills/system-deep-loop/runtime/lib/authorized-ledger/transition-authorization-gateway.ts:779-823`).

The tests make the behavior unambiguous. A no-resolver forged identity is allowed with all three verification markers false; a null resolver result is also allowed; and a partial resolver can verify only actor while capability remains unverified (`.opencode/skills/system-deep-loop/runtime/tests/unit/authorized-ledger.vitest.ts:542-678`). This confirms F2 for the shared gateway. The correction is scope: `AuthorityFlipCoordinatorOptions` now requires an independent actor/capability resolver (`.opencode/skills/system-deep-loop/runtime/lib/per-mode-authority-flip/cutover-coordinator.ts:61-82`), and its tests deny null, absent, partial, or mismatched results (`.opencode/skills/system-deep-loop/runtime/tests/unit/per-mode-authority-flip.vitest.ts:1596-1674`). That stricter coordinator control does not change the generic gateway default used by other consumers.

## F7 — Rollback Certificates Do Not Require Verified Identity

The shared strict decision matcher recomputes request and decision digests and requires raw `actor_id` and `capability_id` equality, but it never requires `actor_id_verified`, `capability_id_verified`, or `evidence_digest_verified` to be true (`.opencode/skills/system-deep-loop/runtime/lib/mode-contracts/strict-gate-validator.ts:147-217`). This matters because the generic gateway can return `allow` with those flags false, as confirmed in F2. The authorization-event schema requires the flags to exist as booleans, not to be true (`.opencode/skills/system-deep-loop/runtime/lib/authorized-ledger/authorization-decision-event.ts:90-139`).

All eight rollback switches were opened. Each accepts a gateway `allow`, validates mode/epoch/evidence or the shared matcher, and builds a certificate from decision/request/evidence digests without checking the verification flags: deep research (`.opencode/skills/system-deep-loop/runtime/lib/deep-research-rollback-gate/rollback-switch.ts:258-329`), deep review (`.opencode/skills/system-deep-loop/runtime/lib/deep-review-rollback-gate/rollback-switch.ts:308-385`), deep AI council (`.opencode/skills/system-deep-loop/runtime/lib/deep-ai-council-rollback-gate/rollback-switch.ts:286-357`), deep-improvement common (`.opencode/skills/system-deep-loop/runtime/lib/deep-improvement-common-rollback-gate/rollback-switch.ts:388-468`), agent improvement (`.opencode/skills/system-deep-loop/runtime/lib/agent-improvement-rollback-gate/rollback-switch.ts:372-450`), model benchmark (`.opencode/skills/system-deep-loop/runtime/lib/model-benchmark-rollback-gate/rollback-switch.ts:372-450`), skill benchmark (`.opencode/skills/system-deep-loop/runtime/lib/skill-benchmark-rollback-gate/rollback-switch.ts:372-455`), and deep alignment (`.opencode/skills/system-deep-loop/runtime/lib/deep-alignment-rollback-gate/rollback-switch.ts:321-404`).

The finding also needs an authority-mutation correction. These certificates set `authorityMutation: false`; they are evidence for an external restorer, not the restoration itself. A durable reverse CAS now exists in `AuthorityRegistry.compareAndSwapRollback` (`.opencode/skills/system-deep-loop/runtime/lib/per-mode-authority-flip/authority-registry.ts:325-403`) and has unit coverage (`.opencode/skills/system-deep-loop/runtime/tests/unit/per-mode-authority-flip.vitest.ts:904-1035`), but repository-wide call-site search found no rollback switch or production composition root invoking it. F7 is therefore confirmed and is coupled to the broader unwired-cutover gap.
