# Iteration 3: Make the Evidence Decision-Grade and Bound Default-On

## Focus

Specify a more trustworthy comparison, quantify the measured Pi-side unit cost without overstating it, and define what must be true before enabling Pi by default.

The current adopt result is useful as an opt-in feasibility signal for one choice corpus and one Pi model version, but its one-row agreement margin and older CLI arm do not justify a default change. A same-time labeled comparison plus failure-inclusive telemetry is the minimum evidence for that decision.
