What it does: it reads every tracked deep-review findings registry and measures offline whether a Jev or Deem severity choice would separate real P0 findings from false ones better than the recorded severity. It changes no severity, no registry and no review gate. The default run makes no model call and writes no file, and the script holds and reads no credential.
Labels: `--write-label-sheet <path>` writes one JSONL row per P0 finding (`registry`, `finding_id`, `title`, `dimension`, `evidence_refs`, `label`), every `label` empty, for the operator to fill with `real`, `P1`, `P2` or `not_a_finding`. `--labels <file>` reads the filled sheet back. A negative is any label but `real`.

Exit 2, each before any census line:
- `--jev` without `--out` prints `--jev needs --out <dir> so every call is recorded`; `--deem` without `--out` prints `--deem needs --out <dir> so every call is recorded`.
- A label-sheet path inside the repository prints `refusing to write the label sheet inside the repository` and writes no file.
- A bad labels row prints its row and fault, for example `labels row 3: label must be "", real, P1, P2 or not_a_finding, got "x"` or `labels row 3: duplicate row <key>`.
Zero model calls by default: logging stubs for `cli-deem` and `jev` first on PATH were never called.
