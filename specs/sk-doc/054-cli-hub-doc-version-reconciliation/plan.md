# Implementation Plan: cli hub doc version reconciliation

<!-- SPECKIT_LEVEL: 2 -->

---

<!-- ANCHOR:summary -->
## 1. SUMMARY

Run the versioning contract's own generator once over the `cli-external-orchestration` hub, so
every doc declares the era of the skill it belongs to. One pass, one path-scoped commit, no amend.

<!-- ANCHOR:architecture -->
## 2. APPROACH

The contract owns the derivation and the tool implements it, so this packet adds no logic. It
selects the scope (one hub), the mode (`apply --update`), and what is deliberately skipped (the
convergence amend). Verification is the tool's own `gate` and `verify`, plus a diff assertion that
nothing but `version:` moved.
