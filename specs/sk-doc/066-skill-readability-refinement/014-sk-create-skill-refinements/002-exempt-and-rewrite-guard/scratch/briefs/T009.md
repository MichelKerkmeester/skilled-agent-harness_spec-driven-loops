Create one CLI script and its test file. Change no other file.

Purpose: when someone rewrites existing Markdown docs for form (readability, layout), nothing may silently change what the docs say. Seven throwaway tools did these checks during a past refinement; read them first, they are the reference behavior: specs/sk-doc/066-skill-readability-refinement/010-sk-prompt/scratch/tools/frontmatter-diff.py, code-blocks.py, citations.py, inbound-anchors.py, scope-links.py, lost-lines.py, intro-diff.py. Also read .skilled/skills/sk-doc/shared/scripts/render_exempt.py: `load_exempt()` and `load_pinned()` return doc path (relative to `skills_root()`, i.e. `.skilled/skills/`) -> consumer.

Create .skilled/skills/sk-doc/shared/scripts/doc-rewrite-guard.py (standard library only; import render_exempt from its own folder via sys.path). Usage: `python3 doc-rewrite-guard.py --base <git-ref> [paths...]`, run from the repository root. It compares every changed `.md` file under the given paths (default: the whole repo; use `git diff --name-only <base> -- <paths>` and include untracked files from `git ls-files --others --exclude-standard -- <paths>` as added) between the base and the working tree, skipping any path containing `/changelog/`. For a file absent at base, only the exempt/pinned check applies.

HARD checks (each finding prints `HARD <kind> <file>[:<line>]: <detail>`; any hard finding makes the exit code 1):
- `frontmatter`: the leading `---` YAML block differs from base after removing `version:` lines.
- `code-block`: the multiset of fenced blocks (``` or ~~~ fences, the full block text including fences) differs from base: report blocks that are missing or edited.
- `citation`: a source citation present at base is gone (same regex as citations.py).
- `cited-section`: another tracked `.md` file (outside specs/ and .hermes/, not under changelog/) links to an anchor `#x` of this file and that anchor's heading no longer exists (compute GitHub-style anchors from headings: lowercase, drop punctuation except hyphens and spaces, spaces to hyphens), or another file cites `<this file name> §N` / `section N` and the numbered H2 `N` changed title or disappeared. Compare base vs now for this file's headings only; never report anchors that were already missing at base.
- `protected`: the file is in the exempt map or the pinned list and changed at all (`exempt doc, read by <consumer>` / `pinned doc, pinned by <consumer>`).
ADVISORY checks (print `ADVISORY <kind> <file>: <detail>`, never change the exit code):
- `lost-line`: a removed prose line whose sentences no longer appear in the file (same normalization as lost-lines.py).
- `intro`: the first paragraph after the H1 changed (print base and now, each cut to 200 chars).
End with one line `doc-rewrite-guard: <files> files, <h> hard, <a> advisory`. Exit 0 when no hard finding, 1 otherwise, 2 on a usage error or an unknown base ref. `--help` prints the usage and exits 0. Docstrings and comments give the reason for each check (a form-only rewrite must keep every claim, code sample, citation and cited section); no task or spec ids.

Tests: .skilled/skills/sk-doc/scripts/tests/test_doc_rewrite_guard.py, pytest.
