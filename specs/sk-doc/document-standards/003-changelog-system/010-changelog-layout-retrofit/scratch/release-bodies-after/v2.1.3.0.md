This release is the spec Kit Memory bug audit. It is the most comprehensive bug-fix release in project history. It fixes 85+ bugs across all severity levels. It focuses on fixing important problems. It explains the results in clearer terms. The goal is to make the workflow easier to follow and easier to trust.

&nbsp;

## What's New at a Glance

- The memory decay rate is corrected.
  - The FSRS formula carried an 18.45x decay rate error.
  - So memories were decaying at the wrong rate.
  - That is because of an incorrect factor calculation.
- The MacOS crash in database operations is fixed.
  - During SQLite operations a platform-specific crash could happen.
  - It could happen while concurrent database access was underway.
- Silent database writes are fixed.
  - Some writes silently did nothing.
  - That caused data loss without errors.
