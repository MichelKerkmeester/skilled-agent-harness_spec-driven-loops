# v2.0.6.1, Copilot Model IDs and Dispatch Recovery

This release updates the OpenCode environment with agent work.

- It restores canonical model ids.
- It recovers subagent dispatch.
- It aligns conventions.

The goal is to make the platform clearer, more reliable and easier to use day to day.

- Agent behavior is more consistent across the supported runtimes.
- The same instructions now behave more predictably in different runtimes.

&nbsp;

## Why This Release

This release closes gaps in how pinned Copilot agents run across runtimes.

- Each part makes agent behavior more consistent across the supported runtimes.
- Pinned Copilot subagents used a model id that was not provider-valid.
- Subagent dispatch hit a runtime `ProviderModelNotFoundError`.
- Stale model reference text in `copilot/review.md` risked future drift.
