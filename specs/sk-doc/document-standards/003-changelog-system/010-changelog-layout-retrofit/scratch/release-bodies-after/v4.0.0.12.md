v4.0.0.12 connects the skill advisor to the doctor commands. A prompt like "help me set up skilled" used to get no suggestion. Now the advisor names the doctor command to run. A new `/doctor:setup` command gives a fresh clone one place to start.

&nbsp;

## What's New at a Glance

- Setup and health prompts name a doctor command.
  - "Help me set up skilled" suggests `/doctor:setup`.
  - "check my environment variables" suggests `/doctor:env list`.
  - Both are lines you can paste and run.
  - Deep-loop and MCP problems suggest `/doctor:deep-loop`, `/doctor:mcp install` or `/doctor:mcp debug`.
- One command to start with.
  - `/doctor:setup` lists all 17 doctor commands and targets.
  - `/doctor:setup` runs five read-only setup checks in any runtime.
  - `/doctor:setup` names the doctor command that fixes each failing one.
  - A stale advisor build fails with the build command instead of passing quietly.
- A matching skill stays first.
  - When a skill fits, it keeps first place.
  - The doctor command shows as a second line, even when three skills match.
  - A doctor command never changes how a skill scores.
- Asking to run a command puts it first.
  - "run /doctor:setup" counts as typing it.
  - So do execute, start, launch, use and kick off.
  - A command you only quote stays second.
- More short prompts find their skill.
  - These short prompts now reach their skill instead of nothing.
  - They are "pre-push hook", "squash commits", "cherry pick", "env vars", "mcp tools", "validate spec" and "environment variables".
  - A short word no longer matches inside a longer one.
  - So "list" stops reaching "allowlist".
- A setup prompt with no match gets a hint.
  - The hint names `/doctor:setup`, even when the advisor itself is down.
  - An unrelated prompt gets none.
  - Claude, Pi and OpenCode show the same text.
- An offline rebuild keeps your packages.
  - When the advisor build is stale but its packages already match the lockfile, the launcher rebuilds without reinstalling.
  - So a failed install can no longer empty `node_modules`.
- Fewer false alarms.
  - `/doctor:git setup` follows `export default plugin;` to its declaration.
  - So an adapter written that way passes when it really binds the advisory.
  - The sk-code drift guards skip `scratch/` and archived folders under `specs/`.
  - The guards' warnings fall from 278 to 8 and point at real code.
- The skill-advisor doctor steps run again.
  - They called the advisor status check without the workspace root it requires.
  - That failed.
  - They now pass it.

&nbsp;

## Upgrade

No migration required. Rebuild the advisor runtime (`npm --prefix .skilled/skills/system-skill-advisor/runtime run build`). Then run `/doctor:setup` to check a fresh clone.
