## Skill Descriptions

These changes shorten two SKILL.md descriptions. They cut the tokens each description adds to the system prompt.

#### Descriptions Are Shorter <a id="c-descriptions-are-shorter"></a>

- `System-spec-kit SKILL.md` description trimmed from ~430 to ~220 chars.
- It was trimmed to reduce system prompt token usage.
- `Workflows-documentation SKILL.md` description trimmed from ~290 to ~200 chars.
- It was trimmed for the same reason.
- That matters because people can understand the system faster and use it more confidently.

&nbsp;

## Sk-git

This change adds a hint to the sk-git skill. It helps people find the right command.

#### Sk-git SKILL.md <a id="c-sk-git-skillmd"></a>

- Added argument-hint: `"[worktree|commit|finish]"` to `Sk-git SKILL.md` for improved user discoverability.
- That matters because it makes the environment easier to use and maintain.
