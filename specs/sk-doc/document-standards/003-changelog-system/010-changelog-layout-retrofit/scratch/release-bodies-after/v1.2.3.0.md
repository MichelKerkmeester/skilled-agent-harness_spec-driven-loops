This release brings post-modularization alignment to the test suite. It corrects file paths and the README exclusion logic. It focuses on instructions and release notes that non-developers can follow. The goal is a workflow that is easier to follow and easier to trust.

&nbsp;

## What's New at a Glance

- File paths now match the modular lib structure.
  - The vector index, memory parser and generate context modules moved.
  - The rate limiting and database check functions now live in db state.
  - Query validation is in validators.
  - This change reduces confusing failures.
  - The change makes the system more dependable.
- The file counting logic now leaves README files out.
  - They no longer add to the template counts.
  - This makes the release notes and instructions easier to read and trust.
