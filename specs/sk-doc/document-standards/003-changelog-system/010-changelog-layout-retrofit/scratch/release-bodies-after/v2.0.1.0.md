## Memory System

The memory system handles how the environment saves, finds and uses context. It now uses a 4-source indexing pipeline.

#### Memory System Integration (Spec 111) <a id="c-memory-system-integration-spec-111"></a>

- This part of the release improves how the environment saves, finds and uses context.
- The 4-source Indexing Pipeline now indexes from `specFiles`, `constitutionalFiles`, `skillReadmes` and `projectReadmes`.
- It was 2-source.
- README Content Discovery uses `findProjectReadmes()` and `findSkillReadmes()` to auto-discover READMEs.
- Discovery uses a `README_EXCLUDE_PATTERNS` exclusion.
- Anchor Prefix Matching matches summary-049, summary-111 etc.
- It uses exact-match priority and shortest-prefix fallback.
- That matters because saved context is easier to find, easier to trust and less likely to get in the way.

## Documentation

Documentation now spans 74 READMEs in.opencode/ with ~473 anchor tags.

#### Documentation Alignment (Specs 112-115) <a id="c-documentation-alignment-specs-112-115"></a>

- This part of the release improves how the environment saves, finds and uses context.
- ~473 Anchor Tags are embedded across 74 READMEs in.opencode/.
- They support precise memory retrieval via the Spec Kit Memory tool connection layer.
- The README Template `readme_template.md` is reduced 1589→1058 lines (-33%).
- Sections go 16→14.
- It added 5 evolved patterns: badge shields, ASCII diagrams, innovation tables, before/after comparisons and anchor placement rules.
- The Root README is restructured 7→9 sections (756→1118 lines).
- It is enriched with tool connection layer tools, cognitive features, search architecture and usage examples.
- Substantive content from the tool connection layer server and `system-spec-kit` READMEs is embedded (+148 lines).
- That matters because saved context is easier to find, easier to trust and less likely to get in the way.

## Commands and Prompts

Commands and prompts were cut to make agent behavior more consistent across the supported runtimes.

#### Command And Prompt Optimization (Specs 116-117) <a id="c-command-and-prompt-optimization-specs-116-117"></a>

- This part of the release makes agent behavior more consistent across the supported runtimes.
- Structured Config Files Reduction covers 13 structured config files.
- The prompt assets go 13,333→5,378 lines (-59.7%).
- It uses compact flow notation.
- Mermaid diagrams and decorative separators were removed.
- Prompt Reduction covers `7.md` command files.
- Those files go 3,746→2,239 lines (-40.2%).
- All routing logic and workflow steps are preserved.
- `/create: folder_readme` cuts structured config files 765→611 lines (-20%).
- It aligns 4 README types with the canonical 9-section structure.
- That matters because the same instructions now behave more predictably in different runtimes.
