# Documentation Validation Enhancements

New validation rules for ALL CAPS section headers.

- H2_not_uppercase Rule validates H2 headers are ALL CAPS.
- Toc_not_uppercase Rule validates Table of Contents entries match.
- Use --fix flag to automatically correct.

This release focuses on making the environment easier to use and easier to trust.

- This part of the release fixes rough edges and makes the environment more dependable.
- That matters because the environment is easier to maintain and less likely to break in everyday use.
