## Specs and Folders

This area resolves specs folders and discovers specs. It now handles more forms and avoids dual-root confusion.

#### Spec Folder Resolution Fixed <a id="c-spec-folder-resolution-fixed"></a>

- This part of the release fixes rough edges.
- It makes the environment more dependable.
- JSON `SPEC_FOLDER` values now support absolute, specs/... and .opencode/specs/... forms.
- They work without fallback misrouting.
- That matters because the environment is easier to maintain and less likely to break in everyday use.

#### Shortcut Link-safe Specs Discovery <a id="c-shortcut-link-safe-specs-discovery"></a>

- This part of the release improves shortcut link-safe specs discovery.
- Specs roots are de-duplicated by realpath.
- This avoids dual-root warnings and selection ambiguity when specs is symlinked.
- That matters because it makes the environment easier to use and maintain.

&nbsp;

## Session Memory

This area saves, finds and uses context. It now keeps memory in the right folder and index.

#### Session Memory Corrected <a id="c-session-memory-corrected"></a>

- This part improves how the environment saves, finds and uses context.
- Misrouted memory was moved into .opencode/specs/04--agent-orchestration/021-codex-orchestrate/memory/.
- It was normalized to the correct spec metadata.
- That matters because saved context is easier to find, easier to trust and less likely to get in the way.

#### Index Consistency Restored <a id="c-index-consistency-restored"></a>

- This part improves how the environment saves, finds and uses context.
- New corrected memory was indexed.
- Wrong-folder entries were removed.
- That matters because saved context is easier to find, easier to trust and less likely to get in the way.
