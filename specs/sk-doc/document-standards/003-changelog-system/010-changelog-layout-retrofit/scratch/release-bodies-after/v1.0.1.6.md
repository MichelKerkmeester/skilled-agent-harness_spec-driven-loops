# Spec Kit Memory System Upgrade

This is a major release for the Spec Kit memory system.

- It adds 7 new tools.
- It adds checkpoint support.
- It adds 30+ metadata fields for advanced filtering.
- It focuses on making the environment easier to use and easier to trust.

The context changes matter to everyday use.

- That matters because saved context is easier to find.
- It is easier to trust.
- It is less likely to get in the way.

The fixes make everyday use more reliable.

- That matters because the environment is easier to maintain.
- It is less likely to break in everyday use.

## Connection Layer Tools

This part of the release improves how the environment saves, finds, and uses context.

#### 7 Connection Layer Tools <a id="c-7-connection-layer-tools"></a>

- 7 new Connection Layer tools were added.
- `memory_health`, `memory_delete` and `memory_update` are included.
- `memory_validate` and `memory_index_scan` are included.
- `checkpoint_create`, `checkpoint_list` and `checkpoint_delete` are included.

&nbsp;

## Metadata and Ranking

The release adds 30+ metadata fields and smart ranking.

#### 30+ Metadata Fields <a id="c-30-metadata-fields"></a>

- 30+ metadata fields support advanced filtering.
- The fields are `specFolder`, `level`, `status`, `tags[]` and `priority`.
- They also include `git_branch`, `author`, `related_specs[]`, `dependencies[]` and `blockers[]`.

#### Smart Ranking <a id="c-smart-ranking"></a>

- Smart ranking uses time-decay scoring.
- The scoring has configurable weights.

&nbsp;

## Memory Storage

This part of the release improves how the environment saves, finds, and uses context.
