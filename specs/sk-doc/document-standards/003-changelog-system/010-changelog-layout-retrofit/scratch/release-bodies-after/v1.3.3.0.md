- Eight OpenCode agent files were duplicated to `.claude/agents/`.

## Claude Code Subagents

Claude Code now has its own copies of the OpenCode agents. Their bodies match the source, and the structured config frontmatter stays in place.

#### Eight Agent Files Duplicated <a id="c-eight-agent-files-duplicated"></a>

- Eight OpenCode agent files were duplicated to `.claude/agents/`.
- They are context, Debug, Handover, Orchestrate, Research, Review, Speckit and Write.
- They carry Claude Code-compatible structured config files frontmatter.
- Frontmatter fields are name, Description, Tools, Model and McpServers.
- Previous symlinks were replaced with standalone files.
- Body content was byte-identical to the OpenCode source.
- All agents were configured with `spec_kit_memory` and `code_mode` tool connection layer servers.
- Model assignments: opus for orchestrate, research, debug and review.
- sonnet for context, speckit, write and handover.
- permissionMode: plan for review (read-only agent).
- That matters because saved context is easier to find, easier to trust and less likely to get in the way.

#### Orchestrate Body Synced <a id="c-orchestrate-body-synced"></a>

- The `.claude/agents/orchestrate.md` body was replaced with updated OpenCode source.
- That source was post-TCB and post-bloat-reduction.
- Claude Code structured config files frontmatter was preserved.
- That matters because the same instructions now behave more predictably in different runtimes.

&nbsp;

## Agent Orchestration

Orchestration rules gained a budget guard and shed bulk. Both changes aim at consistent behavior across runtimes.

#### Tool Call Budget Added <a id="c-tool-call-budget-added"></a>

- A new §26 in `orchestrate.md` adds a 3-layer defense against runaway agent dispatches.
- It adds an estimation heuristic table.
- Thresholds: 1 - 8 safe, 9 - 12 caution, 13+ must split.
- It adds a batch sizing rule.
- It adds an Agent Self-Governance Footer for mid-flight scope reporting.
- A 6-step "Aborted Task Recovery" protocol goes in §14.
- A TCB estimation field was added to task decomposition (§10) and PDR templates.
- That matters because the same instructions now behave more predictably in different runtimes.

#### Orchestrate Trimmed by 15% <a id="c-orchestrate-trimmed-by-15"></a>

- `orchestrate.md` shrank by 15% through targeted merges.
- Lines fell from 892 → 758.
- Sections fell from 31 → 26.
- §3+§4+§15 → unified §3 (Agent Routing).
- §25+§26+§27+§28 → unified §23 (Context Window Budget).
- §26 (Output Verification) was absorbed into §23.
- §2 (Capability Scan), §8 (Command Suggestions) and §30 (Related Resources) were compressed.
- All ~32 internal §N cross-references were renumbered.
- Zero stale references were verified.
- That matters because the same instructions now behave more predictably in different runtimes.
