## Context Handling

This area covers saved and found context.

#### Critical Fixes <a id="c-critical-fixes"></a>

- `Workflow.js` line 19 added the missing `collectSessionData` import.
- The missing import would cause a runtime error.
- An empty catch block in `Workflow.js` line 63 now logs database notification errors instead of silently swallowing them.
- `Input-normalizer.js` at 113,299 changed the default descriptions.
- They moved from "Modified during session" to meaningful defaults.
- The new defaults are "File modified (description pending)", "Edited via edit tool" and "Created via write tool".
- That matters because saved context is easier to find, easier to trust and less likely to get in the way.

## Diagram Generation

#### Code Quality Improvements <a id="c-code-quality-improvements"></a>
