## Memory Search

The program first defined the overall architecture. It made the 5-channel, 4-stage pipeline the single production search path. That replaced earlier isolated experiments.

#### Five Channels Search at Once <a id="c-five-channels-search-at-once"></a>

- Vector search converts your query into a mathematical representation.
- It finds memories with similar meaning, even when they use different words.
- It supports multiple embedding providers: Voyage, OpenAI and HuggingFace.
- Full-text search (FTS5) is SQLite's built-in search.
- It matches exact phrases and word combinations.
- Keyword search (BM25) is a ranking algorithm.
- It scores results by how important your search terms are within each document.
- Causal graph traversal follows cause-and-effect links between memories, for example "this decision led to that implementation".
- Graph importance scoring ranks memories by how connected they are to other memories.
- Limits keep overly connected "hub" memories from dominating results.
- A minimum representation is enforced for each search channel.

#### Four Stages From Candidates to Results <a id="c-four-stages-from-candidates-to-results"></a>

- Gather runs all channels in parallel.
- It injects "constitutional" memories, always-relevant rules that should appear in every search.
- This stage also carries expansion guards.
- Score and Fuse combines results using ranked fusion plus 8 additional scoring signals.
- Ranked fusion merges ranked lists fairly.
- The signals include how recently a memory was accessed.
- They include how related memories reinforce each other.
- They include how well a result matches what the system thinks you are trying to do.
- This stage also carries graph calibration.
- Rerank optionally re-scores the top results using a local AI model for higher accuracy.
- Filter applies the final checks.
- It removes results below a confidence threshold.
- It respects memory lifecycle states such as active and archived.
- It makes sure scores from earlier stages are not silently changed.
- The fallback starts with simpler search methods and progresses to broader queries.

#### Retrieval Becomes Pressure-Aware and Measurable <a id="c-retrieval-becomes-pressure-aware-and-measurable"></a>

- Retrieval is now pressure-aware.
- A new shadow evaluation runtime measures retrieval.

## Saving and Sharing Memory

#### A Full Manager for Constitutional Rules <a id="c-a-full-manager-for-constitutional-rules"></a>

- `/memory:learn` is now a full constitutional memory manager.
- Before this release, `/memory:learn` was a simple "create a rule" tool.
- You can list, edit and remove always-relevant rules.
- You can control their budget.
- Constitutional memories get a 3x search boost.
- They never decay over time.

#### One Index Entry and Automatic Upkeep <a id="c-one-index-entry-and-automatic-upkeep"></a>

- The same document could be indexed multiple times under different paths.
- It could be broken into overlapping sections.
- The file watcher for indexing and refresh was updated as well.
- After any memory change, cache invalidation, hooks and safety checks now happen automatically.
- A memory change is a save, update, delete or checkpoint.
- Cache invalidation, hooks and safety checks used to be scattered across different code paths.

#### Saves Pass Stricter Checks <a id="c-saves-pass-stricter-checks"></a>

- Prediction-error gating stores information only when it adds value beyond what is already stored.
- Alongside prediction-error gating, the save pipeline now runs structural validation.
- It also runs semantic sufficiency checks and duplicate detection.

<details>
<summary><b>Smaller fixes</b></summary>

- The save flow gained fixes and governance.
- Structural and semantic validation were fixed as well.

</details>

#### Shared Spaces Deny Access by Default <a id="c-shared-spaces-deny-access-by-default"></a>

- Shared memory spaces are deny-by-default.
- You must be explicitly granted access.
- A server-owned admin identity handles administrative operations on shared memory spaces.
- Multi-tenant database operations were hardened as well.
- Checkpoints are scoped per tenant.
- Graph search results get proper composite scoring.

#### Sessions Carry Less Redundant Content <a id="c-sessions-carry-less-redundant-content"></a>

- Sessions follow the cognitive model.
- Attention scores decay over time.
- Follow-up messages deduplicate roughly 50% of redundant content.
- Anchor-based retrieval can reduce payload sizes by about 93%.
- The spec folder hierarchy was repaired as part of the same work.
- Session continuity and working-memory behavior were updated too.
