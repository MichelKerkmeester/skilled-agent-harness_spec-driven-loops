## Validation and Checks

This area makes agent behavior more consistent across the supported runtimes. It also improves the five checks framework.

#### Two Thresholds Gate Readiness <a id="c-two-thresholds-gate-readiness"></a>

- READINESS formula: (confidence >= 0.70) AND (uncertainty <= 0.35).
- Confidence alone is insufficient.
- READINESS now requires both dimensions.
- "Confident Ignorance" detection: high confidence + high uncertainty triggers investigation protocol.
- The protocol allows max 3 iterations before escalate.
- The 4-factor Uncertainty Model lists Epistemic gaps (0.30) and Model boundaries (0.25).
- It also lists Temporal variability (0.20) and Situational completeness (0.25).
- That matters because the same instructions now behave more predictably in different runtimes.

#### Five Checks Guide Architecture <a id="c-five-checks-guide-architecture"></a>

- Architectural Validation is required for Level 3/3+ specs.
- It is recommended for Level 2.
- There are 5 Checks.
- Solving actual need: Necessary?
- Alternatives explored: Beyond Local Maxima?
- Simplest approach: Sufficient?
- On critical path: Fits Goal?
- Long-term aligned: Open Horizons?
- A new reference lands at `references/validation/five-checks.md`.
- That matters because it makes the environment easier to use and maintain.

## Script Layout

This area improves how the environment saves, finds and uses context.

#### Context Scripts Change Folders <a id="c-context-scripts-change-folders"></a>

- `Decision-tree-generator.js` moved from `extractors/` to `lib/`.
- It is a generator, not an extractor.
- `Opencode-capture.js` moved from `lib/` to `extractors/`.
- It captures session data.
- Import paths updated in 5 files.
- Those files are `decision-extractor`, `diagram-extractor` and `data-loader`.
- They also include `index.js` and the test file.
- That matters because saved context is easier to find, easier to trust and less likely to get in the way.
