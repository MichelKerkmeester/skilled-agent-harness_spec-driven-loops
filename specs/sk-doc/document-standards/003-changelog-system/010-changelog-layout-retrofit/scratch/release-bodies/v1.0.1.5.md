# JavaScript Limitations

This release documents JavaScript-specific Narsil limitations found during testing.

- The call graph is empty for JavaScript.
- The security scan is limited to backend-focused rules.
- Neural search is stale after an index clear.

This release focuses on making the environment easier to use and easier to trust.

- find_symbols is for symbol discovery.
- get_symbol_definition is for definitions.
- get_file is for file content.

## Known Issues

Testing with JavaScript surfaced the limitations this release documents.

#### Call Graph Limitation Documented <a id="c-call-graph-limitation-documented"></a>

- The call graph is empty for JavaScript (tree-sitter limitation).
- That matters because it makes the environment easier to use and maintain.

#### Security Scan Scope Noted <a id="c-security-scan-scope-noted"></a>

- Security scan is limited (backend-focused rules).
- That matters because the environment is easier to maintain and less likely to break in everyday use.

#### Neural Search Staleness Explained <a id="c-neural-search-staleness-explained"></a>

- Neural search is stale after an index clear.
- That matters because saved context is easier to find, easier to trust and less likely to get in the way.
