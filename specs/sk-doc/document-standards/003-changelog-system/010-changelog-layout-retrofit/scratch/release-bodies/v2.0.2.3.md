## Dependencies

Dependencies moved to the folder where they belong. The move changes install settings and package files.

#### Node Modules Relocation <a id="c-node-modules-relocation"></a>

- Node modules moved from the workspace root into `mcp_server/`.
- 12+ files were updated.
- `npm install-strategy=nested` was adopted (spec 120).
- `.npmrc` is new.
- `install-strategy=nested` disables workspace hoisting.
- The root `package.json` removed redundant better-sqlite3 from its dependencies.
- `Mcp_server/package.json` added sqlite-vec-darwin-arm64 as an `optionalDependency` for nested installs.
- That matters because the environment is easier to maintain and less likely to break in everyday use.

&nbsp;

## Documentation

The guides and scripts were updated for the new layout. They keep saved context easy to find.

#### Documentation Path Updates <a id="c-documentation-path-updates"></a>

- `Mcp_server/INSTALL_GUIDE.md` changed every `system-spec-kit/node_modules/` path to `mcp_server/node_modules/`.
- `Install_guides/README.md` had its HuggingFace cache path corrected.
- Install, rebuild and verify commands in `Install-spec-kit-memory.sh` target `mcp_server/`.
- That matters because saved context is easier to find, easier to trust and less likely to get in the way.

## Source Code
