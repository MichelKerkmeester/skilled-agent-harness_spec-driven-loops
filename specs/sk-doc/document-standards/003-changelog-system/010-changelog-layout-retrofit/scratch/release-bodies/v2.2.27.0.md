## Claude Code Agents

Claude Code subagent conversion updates the OpenCode environment. It improves how the environment saves, finds and uses context.

#### Agents Converted for Claude Code <a id="c-agents-converted-for-claude-code"></a>

- All 8 OpenCode agent files were duplicated to `.claude/agents/`.
- The agents are `context`, `debug`, `handover`, `orchestrate`, `research`, `review`, `speckit` and `write`.
- They use Claude Code-compatible structured config files frontmatter.
- The fields are `name`, `description`, `tools`, `model` and `mcpservers`.
- Previous symlinks were replaced with standalone files.
- Body content is byte-identical to the OpenCode source.
- All agents are configured with `spec_kit_memory` and `code_mode` tool connection layer servers.
- Model assignments set `opus` for orchestrate/research/debug/review.
- They set `sonnet` for context/speckit/write/handover.
- Review uses `permissionMode: plan` (read-only agent).
- That matters because saved context is easier to find, easier to trust and less likely to get in the way.

## Agent Orchestration

Orchestration changes make agent behavior more consistent across the supported runtimes.

#### Tool Call Budget Added <a id="c-tool-call-budget-added"></a>

- Tool Call Budget, or TCB, adds §26 in `orchestrate.md`.
- It provides 3-layer defense against runaway agent dispatches.
- An estimation heuristic table is included.
- Thresholds are 1 - 8 safe, 9 - 12 caution, 13+ must split.
- A batch sizing rule is included.
- It adds an Agent Self-Governance Footer for mid-flight scope reporting.
- An "Aborted Task Recovery" 6-step protocol is added in §14.
- A TCB estimation field is added to task decomposition (§10).
- It is also added to PDR templates.
- That matters because the same instructions now behave more predictably in different runtimes.
