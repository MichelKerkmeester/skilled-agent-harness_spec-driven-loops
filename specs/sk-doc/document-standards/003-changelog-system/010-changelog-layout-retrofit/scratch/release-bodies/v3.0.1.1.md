# Deep Research and Review Split Apart

The unified `sk-deep-research` skill previously handled investigation and code auditing.

- That blurred ownership across commands, workflows and runtime docs.
- One skill owned both jobs.

This release splits that surface into 2 independent skills.

- It touches 75 files across 2 commits.
- It adds 45 new files.
- It records 5,837 insertions / 1,327 deletions.

Research and review workflows stay aligned.

- Review work moves into `sk-deep-review`.
- Investigation stays in `sk-deep-research`.

> [!IMPORTANT]
> 2 changes can break an existing setup. Read these before you update.
>
> 1. Review command renamed. [Review command split](#c-review-command-split)
> 2. Review routing changed. [Workflow routing updated](#c-workflow-routing-updated)

&nbsp;

## Why This Release

## Skills

Two skills now share the work that one skill once did. Research stays focused and review gets a standalone package.

#### Standalone review skill <a id="c-standalone-review-skill"></a>

- Extracted the review-mode half of the old unified skill.
- It is a standalone review and code-audit package.
- It has its own command and YAML workflows.
- It has reference documentation, assets and a manual testing playbook.
- It has runtime wrappers.
- Added dedicated review-mode YAML workflows `spec_kit_deep-review_auto.yaml` and `spec_kit_deep-review_confirm.yaml`.
- The package is in `.opencode/skill/sk-deep-review/`.
- It includes `SKILL.md` and `README.md`.

#### Focused research skill <a id="c-focused-research-skill"></a>

- Review-mode content was removed from `sk-deep-research`.
- So it now handles iterative investigation only.
- Cross-references point review work to `sk-deep-review`.
- It lives in `.opencode/skill/sk-deep-research/`.

&nbsp;

## Commands and Routing

The review command and its routing both move to the new skill. The old command no longer works.

#### Review command split <a id="c-review-command-split"></a>

> [!WARNING]
> `/spec_kit:deep-research:review` is no longer supported. Use `/spec_kit:deep-review`.

- Added `/spec_kit:deep-review`.
- It has `:auto` and `:confirm` modes.
- It replaces `/spec_kit:deep-research:review`.

#### Workflow routing updated <a id="c-workflow-routing-updated"></a>

> [!WARNING]
> Skill-advisor review keywords now resolve to `sk-deep-review` instead of `sk-deep-research`.

- Review keywords now route to `sk-deep-review` instead of `sk-deep-research`.
- They include `"deep review"`, `"review mode"`, `"iterative review"`, `"code audit"` and `"review loop"`.
- Old `:review*` suffixes now route to `sk-deep-review` too.

## Upgrade Notes

Two steps apply when you use the old command or review routing.

#### Before You Start <a id="c-before-you-start"></a>

1. Replace all uses of `/spec_kit:deep-research:review` with `/spec_kit:deep-review`.
2. Update any review automation or keyword-based routing that still targets `sk-deep-research` so it points to `sk-deep-review`.
