## Readiness Rules

Two additions help the spec kit. They judge when work is ready to move forward.

#### Clearer Confidence Checks <a id="c-clearer-confidence-checks"></a>

- The project needed a simple way.
- That way decided when the assistant had enough confidence to continue.
- This release introduced a two-part check.
- It looks at both confidence and uncertainty.
- It runs before work moves ahead.
- This makes decisions more consistent.
- This reduces the chance of pushing ahead on weak assumptions.

#### A Stronger Review Checklist <a id="c-a-stronger-review-checklist"></a>

- Larger specs needed more structure than a quick yes-or-no check.
- This release added the Five Checks Framework.
- So bigger changes are reviewed for fit, quality and maintainability.
- This happens before they move forward.
- This helps the team catch risky or overcomplicated work earlier.

## Session Memory

#### Session Learning Support <a id="c-session-learning-support"></a>

- The system needed a better way.
- It was for remembering what happened during a working session.
- This release added a session learning handler for the memory workflow.
- This gives later steps more context.
- This makes follow-up work easier.

## Script Organization

Two helper scripts move into more appropriate internal folders.

#### Script Organization Cleanup <a id="c-script-organization-cleanup"></a>

- Some helper scripts were sitting in the wrong folders.
- That made the codebase harder to navigate.
- This release moved the decision tree generator and the capture script.
- Both went into more appropriate locations.
- This makes the internal structure easier to understand and maintain.
