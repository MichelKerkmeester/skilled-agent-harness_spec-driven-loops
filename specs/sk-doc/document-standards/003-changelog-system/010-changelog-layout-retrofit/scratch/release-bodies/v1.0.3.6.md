## Tool Connection Layer

The tool connection layer carries messages between tools. A logging bug was breaking that channel.

#### Protocol Errors Prevented <a id="c-protocol-errors-prevented"></a>

- This part of the release improves how the environment saves, finds and uses context.
- It changed `Console.log` to `Console.error` in 3 places.
- The change prevents "invalid Character 'v'" JSON-RPC errors.
- `embeddings.js` at line 282: Provider warmed up message.
- `factory.js` at line 58: Using provider message.
- `factory.js` at line 110: Warming up message.
- Tool connection layer servers use stdout for JSON-RPC communication.
- Any `console.log()` output corrupts the protocol.
- That causes Antigravity quota and other tool connection layer tools to fail.
- That matters because saved context is easier to find, easier to trust and less likely to get in the way.

## Skill Assets

One asset carries utilities that were validated in production.

#### Timing Utilities Added <a id="c-timing-utilities-added"></a>

- This part of the release improves the performance patterns asset with production-validated timing utilities.
- The asset is `performance_patterns.js`.
- It adds throttle/debounce constants.

- It adds IntersectionObserver patterns with a 0.1 threshold.
