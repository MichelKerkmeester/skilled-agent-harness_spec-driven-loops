# Create Command Dispatch Fix And Hardening

A critical fix removes a two-factor vulnerability from one create command.

- `create/skill.md` had the same two-factor vulnerability.
- `Task` sat in `allowed-tools` with `@write` agent references.
- `Task` was removed because slash command chaining does not need it.
- An imperative guardrail block was added.

Every create command now carries execution protocol guardrails.

- All 6 create commands now have execution protocol guardrails.
- The guardrails prevent phantom dispatch.
- They hold even if `Task` is re-added in the future.
- All 6 structured config files workflow assets are marked as REFERENCE ONLY.

An orphaned file is flagged for future cleanup.

- `create_agent.yaml` exists but `agent.md` never loads it.
- An inline workflow is used instead.
- The file is flagged for future cleanup.
