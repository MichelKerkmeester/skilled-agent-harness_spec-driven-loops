## Validation

Validation decides readiness and checks architectural choices. This release updates both.

#### Readiness Now Uses Two Thresholds <a id="c-readiness-now-uses-two-thresholds"></a>

- Dual-threshold validation is part of gate 2.
- It makes agent behavior more consistent across the supported runtimes.
- READINESS Formula: (confidence >= 0.70) AND (uncertainty <= 0.35).
- Confidence alone is insufficient. It now requires both dimensions.
- "Confident Ignorance" detection pairs high confidence with high uncertainty.
- It starts an investigation protocol of max 3 iterations before escalation.
- The 4-factor uncertainty model lists four weighted sources.
- Epistemic gaps (0.30), Model boundaries (0.25).
- Temporal variability (0.20), Situational completeness (0.25).
- That matters because the same instructions now behave more predictably in different runtimes.

#### Five Checks Guide Architecture <a id="c-five-checks-guide-architecture"></a>

- It improves the five checks framework.
- Architectural validation is required for Level 3/3+ specs.
- It is recommended for Level 2.
- The 5 checks start with Necessary? (solving actual need).
- Beyond Local Maxima? (alternatives explored).
- Sufficient? (simplest approach).
- Fits Goal? (on critical path).
- Open Horizons? (long-term aligned).
- A new reference sits at references/validation/five-checks.md.
- That matters because it makes the environment easier to use and maintain.

## Context Handling

#### Scripts Move Between Folders <a id="c-scripts-move-between-folders"></a>

- It improves how the environment saves, finds and uses context.
- Decision-tree-generator.js moves from extractors/ to lib/.
- It is a generator, not an extractor.
- Opencode-capture.js moves from lib/ to extractors/.
