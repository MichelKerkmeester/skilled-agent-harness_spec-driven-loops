# OpenCode Environment Updates

Agent files and commands were updated in this release.

- Core agent docs were aligned for section order and routing language.
- The ChatGPT agent set now uses shared hard-block and formatting rules.
- Command routing uses `[runtime_agent_path]` placeholders.

Architecture, documentation and testing were updated in this release.

- Runtime resolution targets canonical `.opencode/agent*` roots.
- Claude agent paths and layout were aligned.
- The modified config files were parsed and checked for leftover paths.

&nbsp;

## Why This Release

This release updates the OpenCode environment with work on agent files, commands and architecture. The goal is to make the platform clearer, more reliable and easier to use day to day.

- This part of the release improves how the environment saves, finds and uses context.
- This part of the release makes agent behavior more consistent across the supported runtimes.

## Agent Files

That matters because saved context is easier to find, easier to trust and less likely to get in the way.

#### Core Agent Docs Normalized <a id="c-core-agent-docs-normalized"></a>

- Aligned eight core agent docs for section order and routing language consistency.
- The docs are `.opencode/agent/context.md`, `.opencode/agent/debug.md`, `.opencode/agent/handover.md` and `.opencode/agent/research.md`.
- They also include `.opencode/agent/review.md`, `.opencode/agent/speckit.md`, `.opencode/agent/write.md` and `.opencode/agent/orchestrate.md`.

#### ChatGPT Agent Set Aligned <a id="c-chatgpt-agent-set-aligned"></a>

- The ChatGPT agent set now uses the same illegal-nesting hard-block placement.
- It now uses the same output-tail ordering and summary formatting conventions.
- This covers `.opencode/agent/chatgpt/{context,debug,handover,orchestrate,research,review,speckit,write}.md`.

#### Claude Agent Runtime Path Finalized <a id="c-claude-agent-runtime-path-finalized"></a>

- Moved active Claude definitions to `.opencode/agent/claude/{context,debug,handover,orchestrate,research,review,speckit,write}.md`.
- Kept `.claude/agents` as a compatibility shortcut link.

## Commands

That matters because saved context is easier to find, easier to trust and less likely to get in the way.

#### Runtime-aware Command Routing <a id="c-runtime-aware-command-routing"></a>

- Replaced hardcoded command-side agent references with `[runtime_agent_path]` placeholders.
- This applies across create and spec_kit structured config files assets.

#### Command Docs Path Resolution <a id="c-command-docs-path-resolution"></a>

- Added explicit runtime mapping guidance in command markdown.
- Default/Copilot maps to `.opencode/agent`.
- ChatGPT maps to `.opencode/agent/chatgpt`.
- Claude maps to `.opencode/agent/claude`.

#### Memory Continuation Alignment <a id="c-memory-continuation-alignment"></a>

- Expanded `/memory:continue` path detection to include all runtime agent roots.
