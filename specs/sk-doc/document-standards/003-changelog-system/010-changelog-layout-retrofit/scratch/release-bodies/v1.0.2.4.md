## Security

This part of the release improves how the environment saves, finds and uses context.

#### Safer Command Lines and Tool Inputs <a id="c-safer-command-lines-and-tool-inputs"></a>

- CWE-22: path traversal protection in command-line interface `CONFIG.DATA_FILE` and DB-stored paths.
- CWE-400: input length limits for tool connection layer tool parameters.
- The limits are query 10K, title 500 and paths 500 chars.
- MEDIUM severity issues reduced from 4 to 1.
- That matters because saved context is easier to find, easier to trust and less likely to get in the way.

## Context and Memory Reliability

This part of the release improves how the environment saves, finds and uses context.

#### Critical Fixes for Memory and Databases <a id="c-critical-fixes-for-memory-and-databases"></a>

- SQLite Transaction Nesting: an error occurred in `memory_index_scan`.
- `indexMemory()` now uses a composable `database.transaction()` wrapper.
- Race Condition: database changes weren't visible across tool connection layer/script connections.
- A file-based notification was added with `reinitializeDatabase()`.
- Orphaned Metadata: failed vector insertions left orphaned metadata.
- Explicit transaction control with rollback was added.
- That matters because saved context is easier to find, easier to trust and less likely to get in the way.

#### High Priority Fixes for Context <a id="c-high-priority-fixes-for-context"></a>

- Wrong Dimensions: the schema was created with wrong embedding dimensions before provider warmup.
- The fix uses `getConfirmedEmbeddingDimension()` with polling.
- Cache Invalidation: the constitutional cache didn't invalidate on external database edits.
- mtime tracking was added.
- Rate Limiting: state was lost on server restart.
- State moved to a persistent config table in SQLite.
- That matters because saved context is easier to find, easier to trust and less likely to get in the way.

## New Capabilities

This part of the release introduces the main capabilities added in this version.

#### Install Scripts for Every Server <a id="c-install-scripts-for-every-server"></a>

- Shell-based installers cover all 6 tool connection layer servers.
- They include a shared utilities library with 33 functions.
- That matters because the environment can do more useful work without extra setup.

#### Sub-agents Take Heavy Work <a id="c-subagents-take-heavy-work"></a>

- `/spec_kit:handover` and `/memory:save` now delegate heavy work to sub-agents.
- They do this for token efficiency.

#### Flags Control Response Verbosity <a id="c-flags-control-response-verbosity"></a>

- `-brief`, `--verbose`, `--debug` flags control response verbosity.
