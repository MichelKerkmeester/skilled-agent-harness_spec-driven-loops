The tool connection layer gains a richer memory_stats and a database fix.

- memory_stats gains 3 new API response fields.
- A SQLite write-ahead logging contention fix lands.
- This release includes 1 concurrency fix.

- 2 FAQ sections are added.
- Two skills move to an index.md and nodes/ format.

This release focuses on the environment.

- It makes the environment easier to use.

## Memory and Database

This area covers saved context and its SQLite database. This release enriches the stats response and fixes database contention.

#### Memory_stats() Enriched <a id="c-memorystats-enriched"></a>

- This part of the release introduces the main capabilities added in this version.
- It returns tierBreakdown, databaseSizeBytes and lastIndexedAt.
- It eliminates the raw sqlite3 command-line interface fallback for the /memory:manage stats dashboard.
- That matters because the environment can do more useful work without extra setup.

#### SQLite SQLite Write-ahead Logging Contention Resolved <a id="c-sqlite-sqlite-writeahead-logging-contention-resolved"></a>

- This part of the release improves how the environment saves, finds and uses context.
- It adds busy_timeout = 10000 PRAGMA to database initialization.
- It fixes intermittent "no such table: memory_index" errors under concurrent access.
- That matters because saved context is easier to find, easier to trust. It is less likely to get in the way.
