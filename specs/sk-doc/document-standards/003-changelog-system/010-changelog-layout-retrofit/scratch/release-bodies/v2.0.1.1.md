# OpenCode Environment Security, Style and Cleanup Release

This release updates the OpenCode environment's command dispatch security.

- It fixes a command dispatch vulnerability.
- It improves how the environment saves, finds and uses context.
- A hard stop blocks any phantom dispatch text before it could be processed.

The release also standardizes the environment's header style.

- It adds emojis to all 112 H2 headers.
- It removes non-standard decimal step numbering.
- Written guidance becomes easier to follow and trust.

It also audits AGENTS.md and cleans the repository.

- Agent behavior becomes more consistent across the supported runtimes.
- The same instructions now behave more predictably in different runtimes.

&nbsp;

## Why This Release

This release closes gaps across the OpenCode environment. The goal is a clearer, more reliable platform that is easier to use day to day.

- The environment needed better context saving, finding and use.
- Written guidance needed to be easier to follow and trust.
- Agent behavior needed to be consistent across runtimes.

## Command Dispatch

This area covers how command files load instructions and dispatch agents. The release adds guardrails and moves loading instructions to the top.

#### Security - Command Dispatch Vulnerability Fix <a id="c-security-command-dispatch-vulnerability-fix"></a>

- This part improves how the environment saves, finds and uses context.
- That matters because saved context is easier to find.
- It is easier to trust and less likely to get in the way.

<details>
<summary><b>Smaller fixes</b></summary>

- Added lines 7-18 to all 7 command files.
- The lines carry an explicit DO NOT dispatch agents directly instruction.
- This creates a hard stop before any phantom dispatch text could be processed.
- Moved the "load structured config files and execute" instruction from lines 140-183.
- It sits at the top of each command file.
- It is the first substantive instruction the LLM processes.
- 4 command files (complete, debug, research, plan) had raw dispatch template text.
- That text could be interpreted as live instructions.
- Wrapped in explicit code fences with REFERENCE ONLY labels.

</details>
