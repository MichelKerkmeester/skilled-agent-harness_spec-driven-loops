# Comprehensive System Hardening

This release fixes critical embedding dimension problems in the Spec Kit Memory system.

- Checkpoints now use dynamic dimension detection instead of hardcoded 768.
- `getEmbeddingDimension()` now correctly detects dimension from provider, environment variables or API keys.
- Dimension validation mismatches are fixed for memory indexing.

The release also hardens security around paths and inputs.

- CWE-22: Added path validation to command-line interface `CONFIG.DATA_FILE`.
- CWE-22: Added `validateFilePath()` checks for DB-stored paths.
- CWE-400: Added input length limits to tool connection layer handler parameters.

It also makes embeddings faster and consolidates shared code.

- An LRU cache of 1000 entries reduces redundant API calls.
- Parallel embeddings run 3-5x faster with configurable concurrency.
- Shared modules moved to `shared/` with re-export wrappers.

## Memory and Embeddings

This part of the release improves how the environment saves, finds and uses context. That matters because saved context is easier to find, easier to trust and less likely to get in the way.

#### Dynamic Dimension Detection <a id="c-dynamic-dimension-detection"></a>

- Embedding Dimension Mismatch was critical.
- Checkpoints now use dynamic dimension detection instead of hardcoded 768.
- That fixes failures with Voyage (1024) and OpenAI (1536) providers.

#### Automatic Dimension Detection <a id="c-automatic-dimension-detection"></a>

- Dimension Detection was critical.
- `getEmbeddingDimension()` now correctly detects dimension from provider, environment variables or API keys.
- That runs before falling back to default.

#### Memory Indexing Fixed <a id="c-memory-indexing-fixed"></a>

- Fixed dimension validation mismatches behind memory indexing failures.

#### Embedding Cache Cuts API Calls <a id="c-embedding-cache-cuts-api-calls"></a>

- An LRU cache holds 1000 entries.
- It reduces redundant API calls.

#### Parallel Embeddings Run Faster <a id="c-parallel-embeddings-run-faster"></a>

- Parallel embeddings run 3-5x faster.
- Concurrency is configurable and defaults to 5.
