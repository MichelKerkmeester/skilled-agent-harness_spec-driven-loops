- The platform becomes clearer.

- Saved context is easier to trust and less likely to get in the way.
- That matters because the environment can do more useful work without extra setup.

## Composition And Modularization

This area covers how the environment composes and builds context. This release makes composition dynamic and splits large scripts into modules.

#### Compose.sh Dynamic Templates <a id="c-composesh-dynamic-templates"></a>

- Replaced all 12 hardcoded L3/L3+ heredoc composition paths with dynamic fragment assembly from `templates/addenda/`.
- Zero heredocs remain.
- `compose.sh --verify` validates all fragment paths at runtime.

#### Create.sh Modularization <a id="c-createsh-modularization"></a>

- Extracted 3 shell libraries: `shell-common.sh`, `git-branch.sh` and `template-utils.sh`.
- Also extracted 5 externalized sharded templates.
- `validate.sh` is also wired to shared libs.

#### Workflow.ts Module Extraction <a id="c-workflowts-module-extraction"></a>

- Extracted 4 focused modules from Workflow.ts.
- `quality-scorer.ts`: 122 lines of content.
- `topic-extractor.ts`: 88 lines of content.
- `file-writer.ts`: 33 lines of content.
- `memory-indexer.ts`: 159 lines of content.

## Shared Utilities And Templates

This area holds the utilities and templates the environment reuses. This release adds a shared JSONC stripper, shell libraries and template fragments.

#### Shared JSONC Comment Stripping <a id="c-shared-jsonc-comment-stripping"></a>

- Added `Shared/utils/jsonc-strip.ts`, a shared JSONC comment-stripping utility (95 lines of content).
- `config.ts` and `content-filter.ts` now use the shared utility instead of inline regex.
- Fixed a latent bug in the `content-filter.ts` naive regex that could corrupt strings containing `//`.

#### Shell Libraries <a id="c-shell-libraries"></a>

- `scripts/lib/shell-common.sh`: 54 lines of content.
- `scripts/lib/git-branch.sh`: 134 lines of content.
- `scripts/lib/template-utils.sh`: 80 lines of content.

#### Template Fragments <a id="c-template-fragments"></a>

- 5 addenda fragments cover `level3-arch/` prefix, suffix and guidance.
- They also cover `level3plus-govern/` suffix and guidance.
- 5 sharded templates: `spec-index.md`, 01-overview.md, 02-requirements.md, 03-architecture.md and 04-testing.md.

## Portability And Reliability

This area keeps scripts portable and code reliable. This release fixes POSIX issues and hardens code quality.

#### Sed And Grep POSIX Fixes <a id="c-sed-and-grep-posix-fixes"></a>

- 5 GNU-specific fixes target sed and grep.
- 3 sed fixes: `sed 's/-\+/-/g'` → `sed 's/--*/-/g'` because BSD treats `\+` as literal.
- 1 fragile `sed i\` rewrite to `printf+sed`.
- 1 `grep -P '\b'` → `grep -w` (POSIX compliant).

#### Code Quality Hardening <a id="c-code-quality-hardening"></a>

- 11 untyped Catch (e) → Catch (e: unknown) with proper `instanceof Error` guards.
- 8 non-null assertions (`!`) replaced with explicit null checks across 10 files.

#### IsMemoryFile README Guard <a id="c-ismemoryfile-readme-guard"></a>

- The `isSkillReadme` check in `memory-parser.ts` incorrectly matched `README.md` files inside `constitutional/` directories.
- Added `!normalizedPath.includes('/constitutional/')` guard.
