# OpenCode Environment Update

This release improves how the environment saves, finds and uses context.

- Added typed retrieval traces and artifact-aware routing.
- Added intent-adaptive fusion and extraction/provenance hardening.
- Added extended retrieval telemetry and an append-only mutation ledger.
- Landed wave-based spec documentation and completion evidence.

This release makes agent behavior more consistent across the supported runtimes.

- Standardized runtime guidance to `/.claude/agents`.
- Aligned `AGENTS.md` and command runtime mapping sections.
- Updated `/create:*` and `/spec_kit:*` command docs.
- Published targeted release notes for subcomponents.

This release makes the written guidance easier to follow and easier to trust.

- Removed old top-level changelog fragments.
- Removed them in favor of subfoldered component changelogs.
