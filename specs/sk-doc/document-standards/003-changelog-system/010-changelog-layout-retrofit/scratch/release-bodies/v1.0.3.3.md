# Security and Documentation Hardening

This part of the release fixes rough edges and makes the environment more dependable.

- URL validation now rejects `Javascript:` and `data:` schemes.
- 35 broken markdown links are fixed across 16 reference files.
- `debounce()` was missing a default delay.
- Its default delay is now 180ms.

This part of the release makes the written guidance easier to follow and easier to trust.

- The deprecated `SafeDOM` class is removed.
- That cut 107 lines of unused code.
- Deprecated `Debounce` and `Raf_throttle` exports are removed from `wait_patterns.js`.
- Lenis Smooth Scroll Pattern Routing is added to `SKILL.md`.

&nbsp;

This release covers security hardening and documentation quality improvements for workflows-code skill. It focuses on making the environment easier to use and easier to trust.
