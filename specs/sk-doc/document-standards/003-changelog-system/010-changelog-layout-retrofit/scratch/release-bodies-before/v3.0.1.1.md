The unified `sk-deep-research` skill previously handled both investigation and code auditing, which blurred ownership across commands, workflows, and runtime documentation. This release splits that surface into **2 independent skills**, touches **75 files across 2 commits**, adds **45 new files**, and includes **5,837 insertions / 1,327 deletions** while keeping the research and review workflows aligned.


---

## What Changed

#### Features
- **New `sk-deep-review` skill**: Extracted the review-mode half of the old unified skill into a standalone review and code-audit package with its own command, YAML workflows, reference documentation, assets, manual testing playbook, and runtime wrappers.
- **Focused `sk-deep-research` skill**: Removed review-mode content so the original skill now handles iterative investigation only, with cross-references pointing review work to `sk-deep-review`.


#### Commands
- **Review command split**: Added `/spec_kit:deep-review` with `:auto` and `:confirm` modes to replace `/spec_kit:deep-research:review`.
- **Workflow routing updated**: Review keywords such as `"deep review"`, `"review mode"`, `"iterative review"`, `"code audit"`, `"review loop"`, and the old `:review*` suffixes now route to `sk-deep-review` instead of `sk-deep-research`.


#### Architecture
- **Runtime definitions synchronized**: Updated all `@deep-review` agent definitions across the 4 runtimes to point at `/spec_kit:deep-review` and `sk-deep-review`.
- **Wrapper files added**: Added `.agents/commands/spec_kit/deep-review.toml` and synced `.claude/commands/spec_kit/deep-review.md` to the new release flow.


#### Documentation
- **Framework docs refreshed**: Updated `CLAUDE.md`, `AGENTS.md`, `AGENTS_example_fs_enterprises.md`, `README.md`, `.opencode/skill/README.md`, `.opencode/command/README.txt`, and `.opencode/README.md` to split research and review into separate entries.
- **Stale references cleaned up**: Removed remaining `deep-research:review` references from `.opencode/command/README.txt` and the Barter `AGENTS.md` after the main split landed.


#### Breaking Changes
- **Review command renamed**: `/spec_kit:deep-research:review` is no longer supported; use `/spec_kit:deep-review`.
- **Review routing changed**: Skill-advisor review keywords now resolve to `sk-deep-review` instead of `sk-deep-research`.
