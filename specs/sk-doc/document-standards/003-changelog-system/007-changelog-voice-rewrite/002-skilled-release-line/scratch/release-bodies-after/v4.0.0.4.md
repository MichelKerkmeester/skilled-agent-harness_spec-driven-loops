## What's New at a Glance

- **New work joins the packets it belongs to.** A packet in the same track already changed a file, script or command. A second fix to that file, script or command becomes a child of one series parent. Gate 3 option C names that parent. `create.sh` lists the packets made in the same track in the last 14 days. It writes trigger phrases from the packet's name. Option C reads the same in every runtime.
- **Agents keep checked answers, and Devin reads the current rules.** A settled conclusion reopens only for a reason you can name. That reason could be a failing check or a contradicting fact. Agents answer first instead of restating the request. Devin no longer loads the main checkout's `AGENTS.md` through `~/.claude/CLAUDE.md`. So a worktree session follows its own checkout's rules.
- **The bundled runtimes are patched and ClickUp works again.** Six lockfiles carry fixes for a critical advisory in proxy-addr. They also carry high ones in the MCP SDK, sharp, source-map-js and nanoid. The ClickUp manual now starts ClickUp's hosted server. It asks for one OAuth approval in the browser.
- **Removed flags name what replaces them.** `heal-spec-docs --lane-modes` refuses `--mode` and `--json`. `check-template-staleness.sh --auto-upgrade` and `quality-audit.sh --fix` are gone. Each exits 2 and says what to run instead.

## Upgrade

- **Reinstall dependencies.** An existing install keeps the vulnerable versions until it reinstalls. Rerun the `npm --prefix <package> install` commands from the README setup. Do this for each package you installed.
- **Move personal skills Devin should see.** Devin no longer reads `~/.claude/`. So a personal skill kept only in `~/.claude/skills` stops reaching it. Put that skill in `~/.agents/skills` instead.
- **Reconnect ClickUp.** Restart your client. Approve ClickUp's OAuth prompt once in the browser. The old ClickUp key lines in your own `.env` are unused and safe to delete.
- **Replace two removed flags with upgrade-legacy.** `check-template-staleness.sh --auto-upgrade` and `quality-audit.sh --fix` were removed. Each now exits 2. Each names `upgrade-legacy` as the replacement.
- **Drop `--mode` and `--json` from healer lane runs.** Each now exits 2 with a message that tells you to drop the flag. Without `--mode`, all five modes run.
