After the phase-013 card relocation and phase-015 path repoint, the `sk-prompt` manual-testing-playbook still depended on sibling skills. This release makes it fully forkable by removing that dependence. The playbook now tests only `sk-prompt`'s own surface. So a standalone fork runs clean.

> Spec folder: `.opencode/specs/skilled-agent-orchestration/130-prompt-knowledge-layering/016-sk-prompt-playbook-forkability-decouple/` (Level 1)

## What's New at a Glance

- **The inline fast-path and escalation scenarios are reframed.** They previously tested the CLI prompt-quality card's fast-path and escalation thresholds. That was a CLI-dispatch concern. It left `sk-prompt` when the card moved to the hub. The inline fast-path scenario verifies that a low-complexity prompt passes the CLEAR check inline. It is anchored on `references/patterns-evaluation.md`. It does not dispatch `@prompt-improver`. The escalation scenario verifies that a high-risk prompt escalates to `@prompt-improver`. It is anchored on the `SKILL.md` §7 contract and §4 ESCALATE IF. Both `rg` steps now target files under `sk-prompt/`.
- **The playbook drops nine hub-card references.** It removes its references to `sk-prompt-models` and the relocated `cli_prompt_quality_card.md`. Source-ref rows for `SP-019` and `SP-021`, plus `SP-025` and `SP-026`, were removed or repointed. They were removed as redundant with the adjacent `patterns_evaluation.md` row. Or they were repointed to `SKILL.md` §7. Card references are gone from the root playbook's coverage note and Realistic Test Model. The Global Preconditions disk-resolution list and §12/§15 descriptions also drop the card.
- **Stale and cross-skill references are scrubbed.** The root playbook's reference to the `§8 fast-path asset section` now points to §7. That §8 section was removed from `SKILL.md` in phase 014. The wave-planning operational rules replace the `cli-claude-code`/`cli-codex`/`cli-opencode`/`cli-copilot` names with "available executor skills".

## Upgrade

No migration required. The two reframed scenarios keep their existing playbook identifiers. The `cli-card-five-question-fast-path.md` filename slug is retained to avoid catalog-link churn. Its title and content now describe the inline fast path.
