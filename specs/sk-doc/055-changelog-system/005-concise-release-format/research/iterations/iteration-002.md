## Reflection

- **What worked and why**: reading every candidate file in full rather than grepping. Q2's target is a set of absences as much as statements, and an absence cannot be grepped. Finding 3 (no expanded total) and finding 7 (no container for small fixes) are the load-bearing findings and each required seeing the whole table or the whole Drop list to be sure nothing elsewhere supplied the missing rule. Pre-lining all seven files with `cat -n` is what made the full read affordable inside the call budget.
- **What did not work and why**: the first framing ordered the findings by file, which produced a flat list that obscured that the template is the source and everything else is a mirror. Reordering by leverage, and demoting the four neutral files into one negative-result finding, is what turned a file inventory into an answer to "where does the push come from".
- **What I would do differently**: check the interaction between two rules in the same file before recording either alone. Findings 10 and 12 were only visible as contradictions, and contradictions are what Q5 must adjudicate. A per-file contradiction pass should run before the cross-file ranking pass, not after.
