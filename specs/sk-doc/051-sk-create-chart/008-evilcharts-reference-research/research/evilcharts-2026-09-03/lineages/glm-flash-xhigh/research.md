## 3. WHAT WAS ESTABLISHED ACROSS THE FOUR ANSWERED QUESTIONS

1. **KQ1 — component architecture.** A chart is a declarative shell over Recharts: the root owns data/config/loading/brush, visuals are composed children reading one shared context (`recharts-line-chart.tsx:83-149`); a container-level CSS blob restyles the library's built-in SVG (`recharts-chart.tsx:112`); per-series multi-colour arrays become CSS variables and gradient indicators (`recharts-chart.tsx:145-206`, `recharts-legend.tsx:154-168`); tooltip, legend (click-to-select, 0.3 dim, 7 indicator variants), dots (3 variants), brush, background patterns, loading state and the mask-wipe intro reveal are all first-class shared components; ECharts runs as a parallel pipeline with the same API surface (`echarts-chart.tsx:18-95`). The corpus has no restyle layer, gradients, interactive legend, dot variants, brush, patterns, loading or reveal; it is ahead on the writing layer (four-part card).
2. **KQ3 — theming.** One radius knob with a calc ladder (`globals.css:47-56`); pure oklch zero-chroma neutrals; a full dark twin with white-alpha borders (`globals.css:102-147, 118-121`) and re-hued (not lightened) chart hues (`:75-79` vs `:122-126`); SVG focus suppression + text user-select none (`globals.css:318-337`); 12px chart-text baseline. Corpus audit: 20/20 `border-radius: 10px` uniform and unenforced, an undocumented 11-21px type scale, 0/20 dark support, zero `rx` marks. Corpus colour gates are stricter than evilcharts' (4-hue cap vs 5-hue default; greyscale-survival spread).
3. **KQ2 — catalog of forms.** 8 forms × 2 engines (area, bar, composed, line, pie, radar, radial, sankey; brush wired only into cartesian forms) plus 22 scenario-named demo blocks and per-form docs pages with no question→form index. Versus the corpus: 4 exist-in-both (area/line/bar/radial), 4 only-there (pie deliberate refusal, `catalog.md:131`; composed, sankey, radar), 13 only-here. Corpus ahead: in-figure shape-violation notices.
4. **KQ4 — beauty physics.** Dashed `3 3` grid at border/50, no axis/tick lines (recharts) or width-3 round tick dots (echarts), `DEFAULT_BAR_RADIUS 2`, 0.5s cubic-out bar grow, `SELECTION_DIM`/`HOVER_BLUR` 0.3, 4-layer glow constants, 8px canvas margins, locale-dependent value formatting. Corpus: solid 1px rule grid, no ticks, 2px round-capped stroke, square marks, no motion, no hover, fixed-comma deterministic formatter. The adoptions and rejections above are the delta, with the formatter correction applied.
