# 010-todos — research brief

**Feature:** Support pi’s todos in the PWA
**Tier:** NO — net-new surface, reach desired UX

**Goal:** Render pi’s todo/plan list in the mobile chat with a UX better than the desktop terminal — clear task states, progress, and grouping — referencing how Manus and Claude present agent task lists.
**Current state:** pi maintains a todo list on the desktop terminal; the PWA has no todo surface, so task progress is invisible from the phone.
**Desired:** A first-class todo surface: task rows with state (pending / active / done / blocked), progress affordance, grouping, and live updates, in the fixed ink-on-parchment system — ideally clearer than the terminal version.

**Target bar:** Manus and Claude task/todo lists; plus Mobbin/Refero reference flows.
**Reference apps:** Manus, Claude, plus Dot, Perplexity, Copilot, Grok, Pi, Meta AI, ChatGPT, Gemini, Genie via Mobbin/Refero.
**Sources:** Mobbin (code mode) + Refero (code mode) real reference screens, general web crawl, and the named apps’ docs.
**Budget:** reference-screen research loop (to be run); no early convergence.

Each research pass captures/cites real reference screens and derives adoptable
patterns. `research.md` (written after) is the build-ready decision.
