## Considered and rejected

- **Remove verification instructions (`opus-5:61`, `opus-5:81`).** `AGENTS.md:151-161` and `evidence-and-proof.md:101-113` exist because green runs have been wrong here in four recorded ways. The same file also steers models that do not verify on their own.
- **Import the minimize-markdown block (`claude:358-378`).** Formatting already has an owner (`communication.md:91-99`, `:165-190`), and Fable 5.1 formats less by default (`fable-5-1:776`), so a blanket block would pull two model families in opposite directions.
- **Add a parallel-tool-call instruction to AGENTS.md (`claude:491-513`).** The Claude Code harness already injects one, and `uncertainty-and-honesty.md:118` already says to batch tool calls.
- **Drop CRITICAL and MANDATORY from the AGENTS.md §1 and §2 headings.** They label blocks that are genuinely hard, and this lens found no repo evidence that the headings cause over-triggering. Row 9 fixes the one sentence that reads wrong when taken literally.
- **Re-add per-model profiles to sk-prompt.** v3.0.0.0 removed them, and model behavior moves faster than the files were kept. Row 7 adds only techniques both vendors state for all their current models.
- **Mark pasted text and time budgets (`opus-5-5:135`, `opus-5-5:113`).** Both are harness features. `AGENTS.md:284` already holds the posture for pasted content.

## Contradictions inside the reviewed files

- `AGENTS.md:104` (questions before any analysis or tool calls) against `uncertainty-and-honesty.md:51` (investigate up to three passes before asking). A literal model asks before reading the file that would have answered its question.
- `AGENTS.md:47` (pass all gates before ANY tool) against `AGENTS.md:50` (Gate 3 does not fire on read-only work). A literal model treats a read as needing Gate 3.
- `sk-prompt/SKILL.md:329` and `:351` (ask one question, then wait) against `prompt-improver.md:44` (non-interactive leaf, blocked package). The agent path cannot wait, so a model reading both either stalls or ignores the skill.
- `sk-prompt/SKILL.md:360` (no second person) against `cli-prompt-quality-card.md:153` ("You are dispatched AS"). The skill's own dispatch template breaks the skill's rule.
