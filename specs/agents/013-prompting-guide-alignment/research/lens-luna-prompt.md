- Do not generalize Opus 5’s self-verification exception into a fleet-wide removal of checks: the advice is model-specific, and the prompt-improver eligibility table excludes Opus and Fable (`specs/agents/013-prompting-guide-alignment/scratch/sources/prompting-claude-opus-5.md:59-61,79-81; .skilled/agents/prompt-improver.md:48-72`).
- Do not import Opus 5.5 API effort or token settings into the shared text-prompt framework; the skill explicitly excludes direct API calls that need no prompt optimization (`specs/agents/013-prompting-guide-alignment/scratch/sources/prompting-claude-opus-5-5.md:36-46; .skilled/skills/sk-prompt/SKILL.md:43-49`).
- Do not apply GPT-6’s delegation advice as a blanket rule for `@prompt-improver`: that agent is leaf-only and denies nested dispatch (`specs/agents/013-prompting-guide-alignment/scratch/sources/openai-gpt-6.md:118-132; .skilled/agents/prompt-improver.md:35-44,193-197`).
- Do not require three-to-five examples for every prompt; examples help with output consistency, while the skill excludes simple edits and its RACE pattern supports compressed single-output tasks (`specs/agents/013-prompting-guide-alignment/scratch/sources/claude-prompting-best-practices.md:79-91; .skilled/skills/sk-prompt/SKILL.md:43-49; .skilled/skills/sk-prompt/references/patterns-evaluation.md:188-195`).

## Contradictions inside the reviewed files

- `.skilled/skills/sk-prompt/SKILL.md:340` defines RICCE as Role, Instructions, Context, Constraints, Examples; `.skilled/skills/sk-prompt/references/depth-framework.md:261-273` maps it to Relevance, Correctness, Coherence, Clarity, Efficiency. A model asked to apply RICCE may build prompt sections from one definition and score against the other.
- `.skilled/skills/sk-prompt/SKILL.md:463-464` allows up to three total improvement cycles; `.skilled/agents/prompt-improver.md:83,188-189` says exactly one retry or at most one. Without precedence, a model may stop after one retry or continue for three cycles.
- `.skilled/skills/sk-prompt/SKILL.md:305-316` places RCAF at complexity 1–4 and CIDI at 4–6; `.skilled/skills/sk-prompt/references/patterns-evaluation.md:100-106` permits RCAF through complexity 6. A model may select different frameworks for the same task.
- `.skilled/skills/sk-prompt/references/patterns-evaluation.md:411-415` labels CRAFT plus all techniques “maximum power”; `.skilled/skills/sk-prompt/references/patterns-evaluation.md:822-825` says to start simple and prefer framework fit over sophistication. A model may over-stack techniques despite the simplicity rule.
- `.skilled/skills/sk-prompt/SKILL.md:329-332` requires asking and waiting for one question; `.skilled/agents/prompt-improver.md:44,80-84` requires a blocked package when `raw_task` is absent. For missing input, the model may ask in the skill flow but block in the agent flow.
