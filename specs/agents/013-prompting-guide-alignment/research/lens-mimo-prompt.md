## Considered and rejected

- OpenAI's autonomy prompts (bias toward action, never stop at proposing a plan — `scratch/sources/openai-gpt-6.md:57`, `:65`): wrong here because this repo mandates stop-for-yes waits on blast-radius and workspace decisions (`AGENTS.md:116`, `AGENTS.md:126`).
- OpenAI's "no unsolicited warnings, disclaimers, or checklists over hypothetical risk" (`scratch/sources/openai-gpt-6.md:73`): wrong because this repo requires surfaced uncertainty and escalation notes (`prompt-improver.md:27`, `:198`) — the disclaimers are contracted deliverables, not hedging.
- "Prefer general instructions over prescriptive steps" (`scratch/sources/claude-prompting-best-practices.md:777`): wrong as a dispatch default because the card measures that skipping pre-planning is the largest cause of weak output on smaller executors (`cli-prompt-quality-card.md:56`).
- Model self-knowledge prompt asserting the assistant is Claude (`scratch/sources/claude-prompting-best-practices.md:309`): wrong because dispatches run GPT Luna and open-weight flash models too (`prompt-improver.md:58`, `:61`), so a hardcoded identity misleads them.
- Fable 5.1's client-side compaction preservation prompt (`scratch/sources/prompting-claude-fable-5-1.md:836`): wrong because continuity writing is owned by `/speckit:save` through `generate-context.js` (`SKILL.md:494`), a different mechanism from prompt text.
- GPT-6's "delegate whenever parallelism saves time" (`scratch/sources/openai-gpt-6.md:123`): wrong for the prompt-improver path, which is leaf-only with the task tool denied (`prompt-improver.md:15`, `:193`).

## Contradictions inside the reviewed files

- `.skilled/skills/sk-prompt/SKILL.md:329` / `:351` (always ask one question, never self-answer, wait) vs `.skilled/agents/prompt-improver.md:92` (proceed, surface gaps as assumptions) with `prompt-improver.md:15` (`task: deny`) — a model reading both either blocks on a question no one can answer or silently drops the ask-first rule on the agent path.
- `.skilled/skills/sk-prompt/SKILL.md:464` (up to 3 improvement cycles) vs `.skilled/agents/prompt-improver.md:83` and `:189` (retry exactly once) — the same input gets a different iteration budget depending on path; a model will pick one arbitrarily.
- `.skilled/skills/sk-prompt/SKILL.md:360` (never second-person) vs `.skilled/skills/sk-prompt/assets/cli-prompt-quality-card.md:153` (mandated "You are dispatched AS …" persona block) — a dispatch builder will strip or rewrite the persona framing the card requires.
- `.skilled/skills/sk-prompt/references/depth-framework.md:110` and `:130` (mandatory phase-status updates during work) vs `.skilled/agents/prompt-improver.md:187` (exact structured block, no wrapper prose) — running the agent under both either emits forbidden chatter or suppresses required transparency.
- `.skilled/skills/sk-prompt/assets/cli-prompt-quality-card.md:59` (verbose strict constraint language measurably produces defensive output) vs `.skilled/agents/prompt-improver.md:304`–`:350` (five MANDATORY checklists plus SELF-CHECK) — the deep path the card escalates to is written in the register the card measures as harmful, so prompts get damped on the fast path and inflated on the deep path.
