## 4. Current Rule Design and Load Path

AGENTS.md says Gate 5 fires on the first write in a repository with REPO RULES.md, then loads the root rule file and every rule named by its trigger table. The rules document says triggers are keyed to the action about to be taken and matching rules compose. AGENTS.md also has reply-time pointers to five communication rules. This is an action-routed design, not a blanket rule load. [SOURCE: AGENTS.md:93-101,259-261; REPO RULES.md:12-18,36-52]

The current rule anatomy separates when a rule fires, one binding sentence, numbered body sections, and a final self-check. Its guidance ties self-check items to the obligations in the body. That structure gives a compression test concrete fidelity targets: preserve triggers, operative obligations, exceptions, procedures, and their self-check coverage. ## 6. Prompt Caching and Compaction

OpenAI API documentation describes prompt caching as reuse of key-value state for matching prompt prefixes. This can lower repeated API input charges, but cached text remains part of the input and context; caching is not a reduction in the number of rule tokens occupying the prompt. Compaction may change the reusable prefix. These API mechanics do not reveal the cache-hit rate, billing, or context capacity of this Codex invocation. ## 7. Observed Compliance

The prep pack reports table-pattern detection in 20.3% of 1,063 long replies after communication.md was read and 11.6% of 86 replies in never-read sessions. Semicolon detection was 17.0% of 1,015 replies after communication-prose.md was read and 43.7% of 215 never-read replies. These are rates from non-randomized cohorts; the script's patterns can count legitimate tables in requested documents and semicolons in unfenced code. They do not establish that reading caused either outcome. [SOURCE: specs/agents/016-repo-rule-advisor-surfacing/002-rule-concision-and-loading/prep/evidence-pack.md:43-51; specs/agents/016-repo-rule-advisor-surfacing/002-rule-concision-and-loading/prep/measure-rule-compliance.py:19-39,52-54,82-106]

Read frequency is also not a miss rate. The wider count found answer-the-actual-request.md in 4 of 82 sessions, and there were 104 re-reads after compaction boundaries, but the data does not identify each eligible trigger opportunity or whether a rule had already arrived by another route. A single other lineage observed one Devin instruction delivery cut at 16,384 bytes before AGENTS.md's reply-rule pointer; this is runtime-specific evidence, not a fleet-wide pointer failure. ## 8. Rule-Writing Implications

Keep a clear trigger, one direct binding sentence, the complete numbered obligations and exceptions, and a final self-check that covers those obligations. The existing anatomy document supports this structure. The two compliance observations do not establish a general rule that shorter literal wording works better: they compare different prohibitions, exception structures, baselines, task mixes, and non-randomized cohorts. Treat wording length as an experimental variable, not as a settled causal principle. [SOURCE: .skilled/skills/sk-doc/sk-create-repo-rule/references/rule-anatomy.md:51-66,74-85; .skilled/repo-rules/communication-prose.md:109; .skilled/repo-rules/communication.md:91-99; specs/agents/016-repo-rule-advisor-surfacing/002-rule-concision-and-loading/prep/evidence-pack.md:43-51; specs/agents/016-repo-rule-advisor-surfacing/002-rule-concision-and-loading/research/lineages/luna-advocate/iterations/iteration-002.md:57-65]

## 10. Compression and Enforcement Adjudication

The measured card savings support testing a smaller payload. They do not justify dropping operative requirements without a fidelity check. The card-plus-self-check figure is a derived byte scenario, not a measured behavior-preserving compression ratio. A randomized paired test of full files against the exact card-plus-on-demand fallback, over tasks spanning all 13 rules, would settle whether it preserves obligation-level behavior and how often the fallback is needed. [SOURCE: specs/agents/016-repo-rule-advisor-surfacing/002-rule-concision-and-loading/research/lineages/swe-2-max/iterations/iteration-002.md:17-25; specs/agents/016-repo-rule-advisor-surfacing/002-rule-concision-and-loading/research/lineages/luna-advocate/iterations/iteration-002.md:15-23,67-77]

The current Claude Stop completion hook is async and advisory: it checks completion-claim evidence, returns approve, and does not rewrite a delivered response. It is not evidence that a reply linter can enforce punctuation or table rules. A new pre-delivery linter could be cause-independent only if it can prevent or correct output, recognize requested-table exceptions, and keep false positives low; those effects are unmeasured. 1. Keep the current action-keyed Gate 5 as the default loading path while measuring eligible opportunities, rule delivery, misses, and resulting violations. Do not build a prompt-injection hook from raw read counts alone. 2. Keep always-binding clauses and compact rule-family pointers in AGENTS.md. Measure delivery/truncation by runtime and put any required clause before each runtime's confirmed delivery boundary; one observed 16,384-byte Devin cut does not establish a universal cap. [SOURCE: AGENTS.md:259-261; specs/agents/016-repo-rule-advisor-surfacing/002-rule-concision-and-loading/research/lineages/deepseek-v4-1-flash-max/iterations/iteration-004.md:17,22,28-45]
3. Preserve triggers, obligations, exceptions, and self-check coverage when editing rules. Do not adopt card-only loading as behavior-preserving based on byte savings. [SOURCE: .skilled/skills/sk-doc/sk-create-repo-rule/references/rule-anatomy.md:51-66,74-85; specs/agents/016-repo-rule-advisor-surfacing/002-rule-concision-and-loading/research/lineages/swe-2-max/iterations/iteration-002.md:17-25]

Separate raw detections from corrected outputs and measure false positives, false negatives, correction cost, and latency. 6. Capture per-request input/cache telemetry and usable context capacity for the actual runtime before claiming affordability or monetary savings.
