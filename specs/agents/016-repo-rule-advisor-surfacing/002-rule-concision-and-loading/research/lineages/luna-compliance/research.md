## Answer

The evidence does not identify a causal explanation for why semicolon use falls after a rule read while tables do not. It supports a measured association for one short punctuation rule, no table reduction, and no clear improvement for the other three checks. For the next experiment, keep the rule path and trigger fixed, randomize current versus shorter action wording, and audit task-type detector errors. For rule compression, test a card that retains the file's self-check; a bare card drops operative norms. Load rules through their relevant existing triggers and record delivery receipts instead of treating “read” as equivalent to injected context. ## Conclusion and Limits

For rule text, the best-supported next candidate is a concise, concrete action plus the existing checkable self-audit, tested against the current text at the same path. Keep longer rationale or examples available by trigger rather than loading all rule files every response. This is an experiment design recommendation: the observational measurements establish one read-associated reduction, not a causal writing recipe. The table sentence test should retain the current no-table reply policy and only its named in-flight exception. The current analysis cannot resolve these because exposures are not randomized, the script only tracks tool-use path reads, and its patterns have known false positives.
