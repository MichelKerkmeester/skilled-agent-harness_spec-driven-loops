## 2. PROBLEM & PURPOSE

### Problem Statement
The `orchestrate` agent carries no documented policy for the six external CLI executor modes under
`cli-external-orchestration`. Nothing in its body states that an external executor is opt-in, that the
skill-owned route still governs the work, or that an external run's own `COMPLETE` is a claim rather
than evidence. An orchestrator reading only its own definition could self-select an executor, let the
executor name displace the skill route, and quote back an exit status as proof.

### Purpose
The orchestrator dispatches an external CLI executor only when the user names one, keeps the
skill-owned route and frozen scope authoritative, and treats what the run returns as unverified.

## 3. SCOPE

### In Scope
- One new row in the `orchestrate` §2 Agent Selection table (priority 9, external CLI execution).

- One new §9 anti-pattern row, and two new §10 related-resource entries.

### Out of Scope
- Any change to either file's frontmatter - the two schemas differ by design (`permission:` under

- Restructuring, renumbering, or editing any other section of the agent - frozen scope.
- Any change to the `cli-external-orchestration` hub or its six mode packets - the rule points at the
  hub and deliberately does not copy it; a second copy is what goes stale.
- Hand-editing `.codex/agents/orchestrate.toml` or `.pi/agents/orchestrate.md` - both are generated.

<!-- ANCHOR:edge-cases -->
## L2: EDGE CASES

### Data Boundaries
- User names no executor: no external dispatch; route to a native LEAF agent as usual.
- User names a mode that is not one of the six: not covered by Rule 7; report rather than improvise.
- Advisor scores `cli-*` highly but the user named nothing: still not a request; do not dispatch.

### Error Scenarios
- Requested model tier unavailable on a transport: report and ask; never substitute a near-sounding id.
- codex `exec` run left at its `read-only` default for an edit task: edits silently no-op, so the brief
  must pass `--sandbox workspace-write`.
- A run reports `COMPLETE` with a clean exit status but wrote nothing: verify artifacts, not the return.

### State Transitions
- Partial completion: the external run is a LEAF at depth 1; it returns partial findings rather than
  widening scope or dispatching further.
- Self-invocation: a mode dispatching itself is blocked by the packet-owned self-invocation guard.
